Card 02 论文概述

论文概述

  • 本文面向自动驾驶场景下的高动态范围（HDR，24-bit）物体检测任务，解决HDR RAW图像与现有面向LDR sRGB输入的检测网络之间的不兼容问题。

Card 03 核心贡献

核心贡献

  • 提出一个面向视觉任务的新型色调映射框架，桥接高比特HDR RAW数据与LDR sRGB输入需求之间的差距，专为嵌入式平台设计。
  • 引入神经光度校准（Neural Photometric Calibration）方法，通过辐射空间统一化动态正则化极端动态范围，提升跨场景泛化能力。
  • 设计基于尺度不变（scaling-invariant）原理的轻量化局部色调映射模型，在不含偏置项的网络中保持特性，提升检测性能并降低运行时间。
  • 提出性能迁移微调策略，利用LDR sRGB预训练权重以最小成本适配HDR RAW域，仅优化色调映射器和检测头。
  • 通过端到端优化，在自动驾驶HDR场景中超越传统色调映射算法和先进AI-ISP方法，并在Jetson平台上实现4K HDR输入的实时处理。
Card 04 方法描述

方法描述

  • 所属模块：HDR RAW图像处理前端（色调映射模块），与下游物体检测器端到端联合优化。
  • 输入传感器：采用SONY IMX490 HDR传感器（140 dB动态范围）采集的24-bit HDR RAW图像（原始文章提到IMX490支持最多140 dB，数据为24-bit）。
  • 场景表示：HDR RAW图像经线性去马赛克恢复颜色通道并resize到1280×1280分辨率，处理后输入色调映射网络。
  • 模型结构：包含两个子模块——（1）神经光度校准模块：3层Conv-ReLU加sigmoid激活，预测场景关键辐射权重图；（2）尺度不变色调映射器（TM_SI）：4层Conv-BN-ReLU，每层32通道（Lite变体为16通道），去除所有偏置项以保证尺度不变性。
  • 关键技术：

- 动态范围正则化：用GMM建模像素分布，证明梯度与动态范围的平方成正比，从而引入光度校准压缩动态范围。

- 神经光度校准：用可学习变换Ī = (K-b)·R + b，其中K通过日/夜关键辐射的线性插值生成，并使用log域回归（S = log K）提高数值稳定性。

- 尺度不变色调映射：证明无偏置CNN（含BN和ReLU）满足f_SI(αx) = α·f_SI(x)，从而在不同动态范围下保持一致复现。

- 端到端优化：使用NLPD损失预训练色调映射器，之后用检测损失（位置回归+分类损失）联合微调；性能迁移策略仅微调色调映射器和检测头（占总参数33.6%）。

Card 06 评估与结果

评估与结果

  • 评估基准：RoD数据集（混合场景、白天场景、夜间场景），以及RoD到RhoVision的跨数据集迁移评估。
  • 评估指标：mAP、mAR、AP50、AP75，以及推理延迟（ms）和FLOPs。
  • 关键数值（Faster R-CNN）：Ours达到mAP 49.8、AP50 73.3、AP75 55.6、mAR 58.7；Ours（Lite）达到mAP 47.8、AP50 71.7、AP75 52.9、mAR 56.9，延迟8.8ms，FLOPs 23.40G。
  • 对比方法：HDR ISP（mAP 45.7）、Mantiuk08（mAP 45.6）、CLAHE94（mAP 44.2）、ReconfigISP21（mAP 41.4）、Zero-DCE++21（mAP 28.6）、SCI22（mAP 26.1）、AnscombeNet21（mAP 26.8）、IANet22（mAP 37.6）、RAODNet23（mAP 46.1）、RawOrCooked23（mAP 34.8）；直接输入HDR RAW导致NAN不收敛。
  • 场景泛化结果：白天场景Ours mAP 40.3（对比HDR ISP 32.0、IANet 43.4、RAODNet 35.9）；夜间场景Ours mAP 45.8（对比HDR ISP 37.9、IANet 31.6、RAODNet 45.6）；混合场景Ours mAP 49.8（对比HDR ISP 45.7、IANet 37.6、RAODNet 46.1）。
  • 性能迁移结果：使用COCO预训练权重时Ours mAP 30.6（对比RAWAdapter24 12.6、AdaptiveISP24 22.5）；使用Object365预训练权重时Ours mAP 38.8（对比RAWAdapter24 15.7、AdaptiveISP24 24.7）；RoD到RhoVision迁移时Ours mAP 26.5（无尺度不变时为14.3）。
  • 高级检测器：Sparse-RCNN上Ours mAP 51.3（对比HDR ISP 45.0，+6.3）；Deformable DETR上Ours mAP 55.0（对比HDR ISP 50.2，+4.8）。
  • 开环/闭环/仿真/实车条件：本文为开环物体检测评估；除数据集测试外，还进行了真实世界评估（硬件原型集成HDR相机和NVIDIA Jetson平台）；4K输入在Jetson上以16位浮点精度实现45 FPS（Ours Lite变体）。
