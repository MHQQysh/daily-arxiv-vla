Card 03 核心贡献

核心贡献

  • 对在线托管语言模型与本地部署语言模型进行语音命令分类对比，评估推理延迟与意图识别准确率。
  • 提出一套针对轻量级本地模型的微调与部署流程，在意图识别准确率上优于在线替代方案，同时降低推理延迟。
  • 提出开源、离线的语音助手架构，集成唤醒词检测、语音转写与命令分类，并在资源受限的移动硬件上演示（github.com/TUM-AVS/jarvis_voice_assistant）。
  • 构建并扩展了面向赛车的命令数据集，包含 17 个命令类别、1,645 个样本，并加入 out-of-scope（OOS）类别以提升对无关输入的拒绝能力。
  • 展示 QLoRA + 4-bit 量化微调可在资源受限硬件上把 7B 级模型的准确率从 27.06% 提升到 97.63%。
Card 04 方法描述

方法描述

  • 所属模块：Jarvis 作为独立模块扩展基站（base station），基站是人与车端软件之间的接口，负责遥测与诊断信息，并通过 ROS2 与感知、规划、检测等模块通信。
  • 输入传感器：麦克风音频流（唤醒词持续监听音频流）；原文未报告其他传感器输入。
  • 场景表示：原文未报告以地图、栅格或向量等形式的环境场景表示；系统以预定义行为命令空间（速度目标、启动/停止、退出或返回维修区等）作为命令表示。
  • 模型结构：

- 唤醒词检测：基于 openWakeWord 框架，触发短语为 “Hey Jarvis!”，采用 keyword spotting 技术；激活后以合成语音 “Hi!” 回应并进入命令监听状态。

- 语音转文本：本地使用 OpenAI Whisper 的轻量英文 “base.en” 变体，实现低延迟、不依赖网络的转写。

- 文本到命令分类器：核心组件为 LLM，将自然语言输入映射为预定义行为命令；最终方案为 Mistral 7B 的领域微调版本（Mistral-7B-v0.3-bnb-4bit）。

- 语音合成反馈：基于 Coqui TTS 框架与 VITS 神经语音合成模型；高频使用的回复预录制以降低延迟。

  • 关键技术：

- 微调采用 Unsloth 框架实施 QLoRA，适配所有线性模块，具体为注意力投影层（q, k, v, o）与 MLP 层（gate, up, down）。

- 超参数网格搜索范围：学习率 1×10⁻⁵ 与 5×10⁻⁵，epoch 2 与 3，梯度累积步数 4 与 8，LoRA rank 16 与 32（α 相应缩放）。

- 微调分两阶段：第一阶段在 17 类中抽取 5 类子集上评估三个模型对微调的接受度；第二阶段在完整训练集上对 Mistral 7B 进行完整微调。

- 最终配置：学习率 5×10⁻⁵，epoch 2，LoRA rank 32，LoRA alpha 32，梯度累积步数 4，优化器 AdamW 8-bit。

  • 部署与安全流程：识别后的命令需人工操作员确认，只有确认的命令才经 ROS2 传输至基站，在基站进行额外安全检查与状态验证后再通过移动网络连接转发给赛车；每条语音命令都会在基站界面可视化以便操作员核验。
  • 原文未报告：目标检测网络、轨迹预测模型、规划算法细节等。

Card 06 评估与结果

评估与结果

  • 评估基准：专家整理的赛车高层命令数据集（初步评测 85 样本）；微调后使用完整扩展数据集（1,645 样本，17 类，80/20 划分）的测试集。
  • 评估指标：

- 意图分类准确率：正确分类命令数与测试样本总数之比。

- 推理时间：从 tokenized 输入送入模型开始，到生成最终 end-of-sequence token 为止的端到端处理时间。

  • 初始基准测试关键数值（无任务特定微调）：

- 在线模型：GPT-4o-2024-11-20 为 76.47% / 3.38 s；GPT-4o-2024-08-06 为 74.12% / 4.16 s；o3-mini-2025-01-31 为 85.88% / 21.08 s；GPT-4-turbo-2024-04-09 为 81.18% / 15.73 s；GPT-3.5-turbo-0125 为 57.65% / 5.12 s。

- 本地模型：Llama3.1-8B 为 8.24% / 0.61 s；Llama3.2-3B 为 2.35% / 0.44 s；Deepseek-R1-7B 为 5.88% / 4.07 s；Deepseek-R1-14B 为 16.47% / 9.86 s；Deepseek-R1-32B 为 21.18% / 34.96 s；Gemma2-9B 为 8.24% / 0.82 s；Gemma2-27B 为 27.06% / 1.82 s；Gemma3-12B 为 18.82% / 1.14 s；Mistral-7B 为 27.06% / 0.64 s；Mistral-small-22B 为 16.47% / 1.31 s；Mistral-small-24B 为 24.71% / 1.15 s。

- 作者结论：在线模型准确率较高但响应时间过长；本地模型准确率较低但延迟显著降低；因目标应用对快速响应要求高，优先考虑延迟，故选择 Mistral 7B、LLaMA-3.1 8B、LLaMA-3.2 3B 进入微调。
