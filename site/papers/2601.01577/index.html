Card 03 核心贡献

核心贡献

  • 提出统一视角的 HanoiWorld 世界模型，强调表征层面的预测建模优于观测层面的模拟。
  • 建议一种基于 V-JEPA-2 微调的编码策略，用于从大规模视频数据中学习决策相关的潜在表征。
  • 集成基于 RSSM 的潜在长期记忆，以支持部分可观测条件下的近似马尔可夫状态转移。
  • 证明简单的基于 MLP 的 Actor-Critic 控制器可在学习到的潜在世界模型中有效训练，避免了昂贵的规划算法和复杂的策略架构。

Card 04 方法描述

方法描述

  • 所属模块：世界模型、表征编码器、长期动力学推理、Actor-Critic 控制头，属于端到端模型。
  • 输入传感器：原文报告使用“Bird-Eye-View RGB 图像”以及包含 agent 动作、自车动作、奖励等元数据；编码器预先在由 NuScene 数据集渲染的 2D 鸟瞰视图数据上微调。
  • 场景表示：潜在表征空间（1024×128 维退化潜在空间），基于 V-JEPA-2 编码器输出的嵌入；时序表征通过 RSSM 的确定性状态 h_t 与随机状态 z_t 组合表示。
  • 模型结构：由三部分构成——

- 编码器：基于 V-JEPA-2 预训练编码器（冻结）作为骨干，配合可训练的瓶颈 MLP，将高维表征投影到 1024×128 的紧凑表征空间；还包括一个带 2D CNN 模块的学生分支用于空间表征预测，采用 EMA 教师-学生机制（动量系数 τ=0.996），使用 ℓ1 对齐损失与 VICReg 正则化。

- RSSM 动力学模型：基于 DreamerV3 代码库的循环状态空间模型，包含确定性记忆 f_θ(h,z,a)，随机潜变量 z_t，以及产出预测的 reward、continue 信号和观测嵌入的 MLP 解码器。

- Actor-Critic 头：基于 REINFORCE 与 DreamerV3 想象 rollout 机制，Actor 输出连续动作（加速度与转向角），Critic 输出值函数；熵系数 β=3e-4。

  • 关键技术：掩码表征预测（masked representation prediction）、EMA 教师（参数动量更新）、VICReg 方差与协方差正则化、KL 动态损失、潜在空间想象 rollout（想象水平 H）、λ-return 目标。
