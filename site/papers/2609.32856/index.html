Card 02 论文概述

论文概述

  • 论文面向从遥感影像生成矢量多边形的任务，服务于自动驾驶、矢量地图构建和遥感应用等场景。
  • 研究问题：现有方法多聚焦简单外轮廓，难以表示或保持带孔（interior rings）的复杂多边形拓扑；已有评测也多以区域重叠或外边界质量为主，不能保证内环正确。
  • 论文提出 PolyTopoBench，一个统一评测框架，明确以复杂矢量多边形（一个外环加零个或多个内环）为中心，同时评估外环与内环。
Card 03 核心贡献

核心贡献

  • 提出 PolyTopoBench，一个面向复杂矢量多边形生成而非简单外边界提取的统一遥感评测基准。
  • 构建大规模、多类别基准：近 300K 多边形实例、超过 10K 复杂多边形、超过 42K 内环，覆盖建筑、道路、植被、无植被区域四类地物。
  • 对 11 个公开矢量多边形生成模型进行可复现比较，涵盖 segmentation-then-polygonization、视觉基础模型辅助、表示学习到矢量和直接矢量解码方法。
  • 提出 hole-aware 评测协议，分别评估整体多边形、外环和内环，并引入 Hole-F1 与 Topo-EM 等环结构正确性指标。
  • 实验揭示现有方法常能恢复简单外边界，但在带孔或多环多边形上显著退化，复杂多边形生成仍未解决。
Card 04 方法描述

方法描述

  • 所属模块：遥感影像矢量多边形生成评测基准与统一评测器，原文未报告具体自动驾驶车载模块。
  • 输入传感器：输入为遥感/航空影像，形式为 I ∈ R^{H×W×3}；原文未报告其他传感器。
  • 场景表示：每个多边形实例表示为 (c, s, G)，其中 c 为类别，s 为置信度，G 为几何，包含恰好一个外环 e(G) 和零个或多个内环 I(G)；H(G)=\|I(G)\|，R(G)=1+H(G)。
  • 模型结构：PolyTopoBench 本身不是单一新模型，而是标准化 11 个基线输出的评测框架；基线包括 U-Net + Poly.、Mask R-CNN + Poly.、SAM2 + Poly.、HiSup、ACPV-Net、FFL、GCP、HoliTracer、Pix2Poly、PolyWorld、RoIPoly。
  • 关键技术：统一将预测归一化为一个外环加零个或多个内环的多边形；采用 role-specific ring matching，外环直接配对，内环通过 Hungarian assignment 以 per-ring BIoU 为代价一一匹配，并设置 BIoU 阈值接受孔匹配。
  • 评测指标：区域一致性 AP50；矢量边界质量 BIoU、POLIS、MTA，并在 Overall、Exterior、Hole 三种 ring-aware scopes 下报告；环结构正确性 Hole-F1 和 Topo-EM。
  • 默认设置：BIoU 使用一像素边界缓冲，环匹配阈值 γ=0.1；原文未报告模型规模、训练资源和网络结构细节。

数据集与资源

  • 数据集：Inria building dataset 与 Deventer land-cover polygon dataset；Inria 用于建筑轮廓生成，Deventer 用于道路、植被、无植被区域。

Card 06 评估与结果

评估与结果

  • 评估基准：PolyTopoBench 四个单类任务，包括 Inria Building、Deventer Road、Deventer Vegetation、Deventer Unvegetated。
  • 评估指标：AP50、BIoU、POLIS、MTA、Hole-F1、Topo-EM；AP50、BIoU、Hole-F1、Topo-EM 越高越好，POLIS、MTA 越低越好。
  • 评估条件：原文报告为遥感影像上的开环基准评测；未报告闭环、仿真或实车条件。
  • 对比方法：11 个基线，包括 U-Net + Poly.、Mask R-CNN + Poly.、SAM2 + Poly.、HiSup、ACPV-Net、FFL、GCP、HoliTracer、Pix2Poly、PolyWorld、RoIPoly。
  • Inria Building 关键数值：Mask R-CNN + Poly. AP50=0.720，U-Net + Poly. AP50=0.670；GCP AP50=0.631，ACPV-Net AP50=0.575，HiSup AP50=0.496；Pix2Poly AP50=0.102，PolyWorld AP50=0.016，RoIPoly AP50=0.001，HoliTracer AP50=0.034。
  • Inria Building 环结构结果：Hole-F1 由 ACPV-Net 0.527、U-Net + Poly. 0.514、HiSup 0.473 领先；Mask R-CNN + Poly. 0.167、GCP 0.015、FFL 0.000。Topo-EM 中 U-Net + Poly. 0.531，Mask R-CNN + Poly. 0.519，GCP 仅 0.065。
  • Deventer Road 关键数值：U-Net + Poly. AP50=0.520、BIoU(O)=0.328、BIoU(E)=0.311、BIoU(H)=0.337、POLIS(O)=5.16、Hole-F1=0.466、Topo-EM=0.144；Mask R-CNN + Poly. AP50=0.113、Hole-F1=0.010、Topo-EM=0.081；SAM2 + Poly. AP50=0.023、Topo-EM=0.012。
  • Deventer Vegetation 关键数值：U-Net + Poly. AP50=0.382、BIoU(O)=0.340、BIoU(H)=0.208、POLIS(O)=4.41、Hole-F1=0.022、Topo-EM=0.222；Mask R-CNN + Poly. AP50=0.357、Topo-EM=0.273。
  • Deventer Unvegetated 关键数值：U-Net + Poly. AP50=0.247、BIoU(O)=0.222、BIoU(H)=0.253、Hole-F1=0.428、Topo-EM=0.088；Mask R-CNN + Poly. AP50=0.181、Topo-EM=0.099。
  • 主要结论：现有方法常能恢复简单外边界，但在带孔或多环复杂多边形上显著退化；区域一致性 AP50 与环结构正确性在 Inria 上基本不相关，仅返回外环也可能获得接近完美的 AP50，Hole-F1 与 Topo-EM 能暴露该失败模式。
