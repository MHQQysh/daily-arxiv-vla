Card 02 论文概述

论文概述

  • 任务：面向基于视觉语言模型（VLM）的端到端自动驾驶规划器，研究其 GRPO 风格强化学习（RL）的训练调度问题。

Card 03 核心贡献

核心贡献

  • 揭示 VLM 驾驶 RL 中的两种不同优化机制：进度机制（Run-GRPO）积极探索高进度但牺牲安全，安全机制（Walk-GRPO）保持安全但进度提升缓慢。
  • 提出 Run-then-Walk 两阶段 RL 训练策略：先在放宽约束下扩展进度分布，再通过端点（endpoint）与安全相关目标修复不安全行为，区别于单阶段混合目标 RL 与通用“易到难”课程学习。
  • 给出一套与规划器无关的奖励接口与理论性方向解释（理想化分析），指出 Run 需产生高进度质量、Walk 需降低安全失败、以及参考策略需保留该质量。
  • 在自回归规划器 AutoDrive-P³ 与扩散规划器 ReCogDrive 上验证同一算法的通用性。
  • 在 NAVSIMv1、NAVSIMv2、Navhard、nuScenes 上报告更好的驾驶性能，并相比基线减少 40–50% 的 RL 训练轮数。
Card 04 方法描述

方法描述

  • 所属模块：VLM 驾驶策略的 RL 微调/训练调度模块，不改变规划器原有架构与原生辅助目标，只改变时间调度与基于解码轨迹分布的规划奖励。
  • 输入传感器：原文未报告具体传感器配置；表格中仅标明各方法是否使用 Image / Lidar，本方法在表格中标记为使用 Image、不使用 Lidar。
  • 场景表示：以“驾驶查询 q”为单位，策略采样完整输出 x_i（自回归响应或扩散轨迹头的连续样本），再经解码器映射为轨迹 τ_i。
  • 模型结构：在两类 VLM 规划器上实现——自回归 AutoDrive-P³（fast-mode）与扩散式 ReCogDrive；方法保持其原生辅助监督与架构。
  • 关键技术：

- Run 阶段：使用进取型规划奖励 R_plan^run(τ_i)=PDMS(τ_i)，有意放宽安全修复，鼓励跳出 SFT 的保守解、发现更高进度模式。

- Walk 阶段：用端点奖励与安全项替换进取型规划奖励，R_plan^walk(τ_i,τ_i*)=I_safe(τ_i)(R_safe(τ_i)+R_end(d_E))；不安全 rollout 的规划奖励置零。

- 端点距离：d_E=‖p_T−g_T‖_1；端点奖励为分段衰减形式 R_end(d_E)=1−ηk(d_E)，k(d_E)=min(K, max(0,⌊(d_E−2Δ)/Δ⌋+1))，K=⌊1/η⌋。

- 实现中 R_safe(τ_i)=NC(τ_i)+DAC(τ_i)；I_safe(τ_i)=1 仅当 NC(τ_i)>0 且 DAC(τ_i)>0。

- 奖励组合：R_i^(s)=R_aux(x_i)+λ_plan R_plan^(s)(τ_i)，s∈{run, walk}；组相对优势 A_i^(s) 由组内奖励归一化得到。

- 优化目标：GRPO 目标（含 clip 与 KL 项），Run 阶段以 π_sft 为参考策略，Walk 阶段以选定的 Run checkpoint π_run 为新参考策略。

- 规划器无关性：奖励仅依赖解码轨迹与闭环反馈；自回归规划器奖励赋给包含轨迹的采样 token 序列，扩散规划器奖励赋给采样到的连续轨迹。

Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIMv1（PDMS）、NAVSIMv2/Navtest（EPDMS）、Navhard（两阶段协议 EPDMS）、nuScenes（L2 轨迹误差与 Collision 碰撞率）。
  • 评估指标：PDMS、EPDMS、NC、DAC、DDC、TLC、EP、TTC、Comf、LK、HC、EC；nuScenes 使用 L2 (m) 与 Collision (%)，并按 1s/2s/3s 与均值报告。
  • 对比方法：Human、Constant Velocity、Ego Status MLP、VADv2、UniAD、TransFuser、PARA-Drive、Hydra-MDP、DiffusionDrive、WoTE、DriveVLA-W0、DriveFuture、DriveWorld-VLA、ReCogDrive、AutoDrive-P³、LTF、GoalFlow、ST-P3、VAD、Ego-MLP、InsightDrive、GPT-Driver、DriveVLM、OpenEMMA、RDA-Driver、OmniDrive、OpenDriveVLA、AutoVLA、AutoDrive-R²、Latent-WAM 等。
  • 关键数值（由原文报告）：

- 整体：相比基线减少 40–50% 的 RL 训练 epoch；AutoDrive-P³ 仅 5 个 RL epoch 达到 PDMS 91.8，基线 10 epoch 为 90.2（图 1）。

- NAVSIMv1：ReCogDrive（Run-then-Walk）PDMS 从 90.6 提升至 91.0；AutoDrive-P³（Run-then-Walk）PDMS 从 90.2 提升至 91.8（EP 88.9、TTC 95.5、Comf 100.0）。

- NAVSIMv2：ReCogDrive EPDMS 从 82.7 提升至 83.7；AutoDrive-P³ EPDMS 从 88.7 提升至 89.6，其中 EP 为 92.8。

- Navhard：ReCogDrive 聚合指标从 26.5 提升至 28.2；AutoDrive-P³ 从 29.3 提升至 31.3。

- nuScenes：AutoDrive-P³（Run-then-Walk）平均 L2 从 0.34 降至 0.33，平均 Collision 从 0.08% 降至 0.06%（原文表格中基线 1s 碰撞为 0.00%、本方法为 0.01%，平均值下降）。

  • 对比结论：ReCogDrive 对比中所有安全相关指标提升，仅 EP 有小幅下降；AutoDrive-P³ 对比中进度提高同时保持较强安全。
