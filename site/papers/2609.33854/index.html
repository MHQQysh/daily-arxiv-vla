Card 03 核心贡献

核心贡献

  • 提出 ReDrive 端到端驾驶框架，通过未来表示预测塑造面向规划的视觉表示，推理阶段不需要感知头或未来预测器等辅助模块。
  • 提出三阶段训练策略：驾驶视频预训练、联合世界建模与规划训练、规划器自适应，逐步将未来预测监督引入轨迹学习。
  • 在联合训练中对轨迹生成与未来表示预测进行解耦优化，避免预测目标将轨迹策略引向“更易预测”而非“更适合规划”的动作。
  • 在规划器自适应阶段冻结视频编码器与未来预测器，仅用策略自身 rollout 轨迹条件下的未来表示建模监督优化规划器。
  • 在 NAVSIM v1 与 NAVSIM v2（含 NavHard）基准上验证方法有效性，取得 91.0 PDMS 与 90.8 EPDMS。
Card 04 方法描述

方法描述

  • 所属模块：端到端驾驶规划框架，包含视频编码器、未来表示预测器与动作 DiT 轨迹生成器。
  • 输入传感器：相机输入；NAVSIM 实验为纯相机、无显式感知模块。
  • 场景表示：基于视频历史片段提取的潜在时空视觉表示（history representation），未来片段由 EMA 目标编码器提供预测目标表示。
  • 模型结构：

- 视频编码器由视频预训练 V-JEPA2 初始化。

- 未来预测器包含 12 个 Transformer block、12 个注意力头、隐藏维度 768。

- 轨迹生成采用 Action DiT，通过 cross-attention 以历史表示作为视觉条件，并用 AdaLN 注入噪声水平与自车状态。

  • 关键技术：

- 驾驶域预训练：在驾驶视频上进行 latent masked visual modeling 风格的自监督持续预训练，最小化被掩码时空 token 的预测表示与 EMA 目标表示的 L1 距离。

- 联合训练：未来预测分支以真值自车轨迹编码的 action token 为条件预测未来表示；规划分支以 flow matching 目标从历史表示直接生成轨迹；总损失为规划损失加未来特征预测损失加权和。

- 规划器自适应：冻结编码器与未来预测器，Action DiT 从高斯噪声多步 rollout 生成轨迹，将其编码为 action token 并输入冻结预测器，用未来特征预测损失反向监督规划器；同时使用 flow-matching 损失与最终轨迹 L1 损失。

Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM v1、NAVSIM v2、NAVSIM v2 NavHard。
  • 评估指标：

- NAVSIM v1：PDMS 及其组成 NC、DAC、TTC、EP、Comfort。

- NAVSIM v2：EPDMS 为主聚合指标，报告中列出 NC、DAC、DDC、TLC、EP、TTC、LK、HC、EC。

- NavHard：各指标分量、Stage-1/Stage-2 分阶段分数及合并 EPDMS。

  • 关键数值：

- NAVSIM v1：ReDrive 取得 PDMS 91.0，NC 99.1，DAC 97.9，EP 84.3，C 100，TTC 97.2；相比前最佳 ReWorld 的 90.4 高 0.6 分。

- NAVSIM v2：ReDrive 取得 EPDMS 90.8，高于第二名 SparseDriveV2 的 90.1；NC 99.1，DAC 97.8，DDC 99.6，TLC 99.9，EP 87.6，TTC 98.7，LK 98.2，HC 98.3，EC 86.4。

- NavHard：ReDrive 在 Stage-1 的碰撞避免、可行驶区域合规、行驶方向合规、TTC、车道保持方面领先对比方法；Stage-2 在碰撞避免与可行驶区域合规方面优于 Metis；原文未给出 NavHard 中 ReDrive 的完整合并 EPDMS 数值（表格被截断）。

- 消融相关：完整训练流水线相比未使用完整流水线学习的表示带来 3.5 点 PDMS 提升。

  • 对比方法：NAVSIM v1 包括 Transfuser、VADv2、UniAD、Hydra-MDP、Hydra-MDP++、DiffusionDrive、GoalFlow、DriveDPO、DriveSuprim、LAW、World4Drive、Epona、Drive-JEPA、DriveLaW、ReWorld、DAWN；NAVSIM v2 包括 DiffusionDrive、DiffusionDriveV2、WAM-Diff、DreamerAD、Latent-WAM、DriveFuture、CoWorld-VLA、SparseDriveV2；NavHard 包括 LTF、DiffusionDrive、GTRS-DP、GuideFlow、ReCogDrive、SGDrive、Metis。
  • 评估条件：论文在 NAVSIM 仿真基准上进行开环轨迹规划评估；未报告闭环或实车评估。
