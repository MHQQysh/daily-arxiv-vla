Card 01 研究单位

研究单位

  • 机构：Munich University of Applied Sciences, Intelligent Vehicles Lab (IVL), 80335 Munich, Germany；作者：Katharina Winter、Stefan Englmeier、Fabian B. Flohr
Card 02 论文概述

论文概述

  • 该论文研究自动驾驶场景中视觉语言模型（VLM）从视觉输入中恢复动态物理状态（速度）的能力。
  • 应用场景为自动驾驶系统的感知与规划，涉及周围车辆速度、当前自车速度以及短时未来自车速度建议三个任务。
  • 研究问题在于：模型是否真正编码并利用动态状态信息，还是仅依赖语言先验、提示信息或静态线索；并区分“编码”“读出”和“时间 grounding”三个失败阶段。
  • 论文在 nuScenes 数据集上，对开放权重通用 VLM、Physical-AI VLM 以及驾驶专用 VLA（Alpamayo-1.5）进行零样本评估、线性探测与任务特定适配分析。
Card 03 核心贡献

核心贡献

  • 提出一个面向驾驶场景 VLM 的受控评估协议，围绕三个速度任务（周围车辆速度 T1、当前自车速度 T2、3 秒后自车速度 T3），在单帧、有序/无序多帧以及自车速度提示条件下进行评估。
  • 结合线性探针、查询条件解码和受控扰动，将模型失败分解为编码、读出和时间 grounding 三个层面。
  • 发现周围车辆速度在智能体特定形式下编码较弱，而当前自车速度在隐藏表示中比语言输出中更易获取：连续探针 MAE 为 4.7–5.8 km/h，而语言输出 MAE 为 10.2–16.8 km/h。
  • 发现多帧输入相对单帧没有一致收益，帧顺序很少被利用；未来速度预测甚至不如持续性基线（最差比持续性差 6.5 km/h）。
  • 表明 QLoRA 任务特定适配可显著提升自车速度读出（如 Qwen3-VL 自车速度估计从 40.9% 提升至 90.1% macro-F1），但未来速度的时间 grounding 仍然有限。
Card 04 方法描述

方法描述

  • 所属模块：论文属于 VLM 可解释性与动态感知评估研究，不提出新的自动驾驶端到端模型，而是对已有 VLM/VLA 进行诊断分析。
  • 输入传感器：nuScenes 前视相机图像；未报告使用激光雷达、雷达等其他传感器。
  • 场景表示：单帧（1F）或五帧（5F，2 Hz 采样，约 2 秒历史）图像输入；可选在提示中提供数值自车速度提示（+S）。
  • 模型结构：评估多个开放权重 VLM，包括 Cosmos-Reason2-8B、Cosmos-Reason1-7B、Qwen2.5-VL-7B、Qwen3-VL-8B、InternVL2-8B、InternVL2.5-8B、LLaVA-Video-7B、LLaVA-1.5-7B、Phi-3.5-Vision (4B)、MiniCPM-V-2.6 (8B)，以及驾驶专用 VLA Alpamayo-1.5-10B；视觉编码器包括 SigLIP-2、Qwen2.5-VL ViT、InternViT、CLIP ViT-L 等，语言骨干包括 Qwen3-8B、Qwen2.5-7B、internlm2_5-7b-chat、Vicuna-7B、Phi-3.5 Mini、Qwen2-7B 等。
  • 关键技术：闭集问答、分类与连续 km/h 两种输出形式；确定性 JSON 解析；线性探针；查询条件解码；反事实自车速度提示；帧顺序打乱扰动；QLoRA 任务特定适配。
  • 原文未报告：具体视频 tokenization 细节、探针网络层数、LoRA 秩与目标模块等实现细节。
Card 05 数据集与资源

数据集与资源

  • 数据集：nuScenes 官方训练与验证划分，训练与验证场景互不重叠。
  • 验证集：150 个场景、6,019 个关键帧；排除每场景前四关键帧后得到 5,419 个样本用于 T2 和单帧评估；T1 保留 4,429 个有可见前视目标车辆的样本；T3 保留 4,519 个有有效 3 秒未来轨迹的样本。
  • 线性探针训练：使用 nuScenes 训练集中 547 个场景的 6,000 个样本（约每类 2,000，联合分层）。
  • QLoRA 适配：使用完整合格训练集 20,275 个样本、560 个场景，采用加权采样平衡目标类别。
  • 模型规模：见“方法描述”中列出的各模型参数量，从 4B 到 10B。
  • 训练与推理资源：零样本推理和特征提取在单张 NVIDIA A40 48 GB 或 A100-SXM4 80 GB GPU 上完成，具体取决于模型大小；原文未报告 QLoRA 训练的具体 GPU 数量与总训练时长。
  • 实车平台：原文未报告。
Card 06 评估与结果

评估与结果

  • 评估基准：nuScenes 验证集上的三个速度任务（T1 周围车辆速度、T2 当前自车速度、T3 3 秒后自车速度）。
  • 评估指标：三分类与二分类 macro-F1；连续预测使用 MAE、RMSE、Spearman ρ；以随机基线（三分类 33.3%，二分类 50%）、最优常数基线（T1–T3 分别为 0.7、20.2、20.7 km/h）和持续性基线（T3：v̂_{t+3s}=v_t）作为参考。
  • 关键数值：

- 视觉单帧/多帧下，三分类最优结果为 T1 43.3%、T2 44.9%、T3 55.1%，分别超过随机基线 10.0、11.6、21.8 个百分点。

- 连续 MAE 最优结果为 T1 10.5 km/h、T2 10.2 km/h、T3 10.6 km/h，仅比最优常数基线好 1.2、0.3、0.1 km/h。

- T3 持续性基线 MAE 为 4.1 km/h，显著优于最佳 VLM 的 10.6 km/h。

- 连续探针 MAE 为 4.7–5.8 km/h，语言输出 MAE 为 10.2–16.8 km/h。

- 正确自车速度提示下 Qwen3-VL 在 T2 达到 82.0% macro-F1，InternVL2.5 在 T3 达到 73.0% macro-F1；反事实提示下 T2 和 T3 的中位 macro-F1 降至 11% 和 19%，低于随机基线。

- QLoRA 适配后 Qwen3-VL 自车速度估计从 40.9% 提升至 90.1% macro-F1。

- 分类与连续输出存在硬矛盾：单帧 18.4%、五帧 15.6% 的预测出现非相邻类别冲突。

  • 对比方法：开放权重通用 VLM、Physical-AI VLM、驾驶专用 VLA Alpamayo-1.5，以及随机基线、最优常数基线和持续性基线。
  • 评估条件：全部为零样本、闭环/开环未报告、仿真或实车未报告；论文在 nuScenes 离线数据集上进行开环式问答评估，未进行闭环规划或实车测试。
