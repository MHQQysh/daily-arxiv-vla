Card 04 方法描述

方法描述

  • 所属模块：候选轨迹规划、动作条件未来建模、轨迹评分。
  • 输入传感器：前视相机（两帧历史图像）。
  • 场景表示：V-JEPA 2.1 编码器提取的潜变量 token。
  • 模型结构：在线编码器 E_θ（V-JEPA 2.1 骨干 + LoRA 适配）；EMA 目标编码器 E_θ̄（仅训练时使用）；动作条件预测器 P_φ（共享参数，以动作表示 a_i 为查询、当前场景 token Z_t 为键值进行注意力）；未来潜变量条件评分器 S_ψ（编码器 + 因子化规划头 + 效用头）。
  • 关键技术：LoRA 适配在线编码器；EMA 目标编码器提供监督信号；动作条件预测器通过交叉注意力生成每个候选独立的未来潜变量；专家匹配（基于 ADE）限定预测损失仅用于专家对应候选；硬负样本从离线轨迹库检索（几何距离 < ε_geo、安全差异 > ε_safety）；因子化评分头输出 NC、DAC、EP、TTC、Comfort 因子及总效用；训练损失包含预测损失、因子损失、分数损失与排序损失。

Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM-v1 navtest、NAVSIM-v2 navtest。
  • 评估指标：PDMS 及其五分量（NC、DAC、EP、TTC、Comfort），NAVSIM-v2 使用 EPDMS 及额外指标（DDC、TL、LK、HC、EC），所有分数 ×100。
  • 关键数值：NAVSIM-v1 上 DA-WAM 获得 93.7 PDMS（NC 99.1、DAC 98.9、TTC 96.8、Comfort 99.8、EP 90.0）；NAVSIM-v2 上获得 87.7 EPDMS（TTC 97.9、LK 97.6）。
  • 对比方法：NAVSIM-v1 对比 PDM-Closed、Human driver、Ego-stat. MLP、UniVLA、DrivingGPT、UniAD、DriveX-S、World4Drive、VAD-v2、PRIX、DiffusionDrive、DIVER、AutoVLA、DriveVLA-W0、ReCogDrive、Hydra-MDP++、DiffusionDriveV2、iPad、SparseDriveV2、Centaur、DrivoR、DriveSuprim；NAVSIM-v2 对比 Ego Status MLP、TransFuser、Hydra-MDP++、DriveSuprim、ARTEMIS、DiffusionDriveV2、SparseDriveV2。
  • 实验条件：开环仿真评估（NAVSIM 基准）；匹配消融研究固定训练数据、初始化、候选生成器、优化策略与评估协议。
  • 消融结果：动作条件未来（含硬负样本）达 93.68 PDMS，优于无未来预测（93.31）、共享全局未来（92.81）、当前潜变量（93.25）；LoRA 适配优于冻结和全微调；EMA 目标编码器达 93.68 PDMS；候选数量从 1 增至 32 时 PDMS 单调提升至 93.68，64 时持平。
