Card 02 论文概述

论文概述

  • 论文面向端到端自动驾驶的轨迹规划任务，从当前四路相机图像、自车状态和导航命令直接生成并选择执行轨迹。

Card 03 核心贡献

核心贡献

  • 提出 FPD-Drive，利用录制的未来观测帮助教师生成额外高质量轨迹，再蒸馏给视觉学生模型，部署阶段只需要学生模型。
  • 提出 Future-Privileged Multi-Target Distillation，把未来条件教师生成的多条多样化、高质量轨迹迁移给学生，使监督超越单条录制演示轨迹。
  • 提出 Safety-Aware Score Correction，修正不安全—安全候选对之间的相对安全评分，并提高被低估的安全轨迹的安全分数。
  • 在 NAVSIM v1 与 NAVSIM v2 上取得所比较方法中的 SOTA：基础模型 94.9 PDMS、55.9 EPDMS，FPD-Drive-Pro 提升至 95.5 PDMS、58.1 EPDMS。
  • 在 HUGSIM 上进行零样本闭环评估，HD-Score 为 45.1、RC 为 55.3。
Card 04 方法描述

方法描述

  • 所属模块：端到端轨迹规划，包含粗到细轨迹建模、未来特权教师学习、多目标蒸馏和安全感知分数修正。
  • 输入传感器：规划时刻输入为四路当前相机视图、当前自车状态和导航命令；训练片段额外提供演示轨迹和录制的未来相机观测，未来观测仅作为教师特权输入。
  • 场景表示：视觉编码器将多视图图像编码为场景 register tokens；教师复用视觉编码器处理未来图像，并由可训练全局场景编码器融合当前与未来 token，形成全局场景表示，通过空间、时间与交叉注意力共享给精化器和评分器。
  • 模型结构：教师与学生共享粗到细视觉规划器，包括视觉编码器、提议解码器、扩散精化器和评分器；提议解码器生成 M=64 条轨迹提议，每条含 H=8 个未来位姿（位置与朝向）；Diffusion Transformer 以提议为条件预测残差修正；评分器用自注意力建模候选间关系、交叉注意力接入场景 token，并用独立 MLP 头估计 PDMS 五个分量，聚合为选择分数。
  • 关键技术一：未来特权多目标蒸馏。教师用记录的未来观测条件化精化与评分；冻结教师后为每个场景采样候选库，用 PDM-closed 指标评估器赋标签，保留通过 PDMS 安全检查的候选，以最高分轨迹初始化目标集，并迭代加入与已选轨迹最小平均位移误差最大的候选，要求两两 ADE 至少 1 m，每场景最多 K=4 个目标；用最优二分匹配将目标分配给不同学生提议，最小化总 ADE，未匹配提议按最近教师目标构造残差；轨迹损失只监督匹配上的 J 对。
  • 关键技术二：安全感知分数修正。用二元交叉熵在全部 M 条学生轨迹上监督五个指标分量；对预测分数高但未通过安全检查的候选，配对同场景中 ADE 最近且通过安全检查的候选，在 NC、DAC 安全分量 logit 上施加成对 margin 损失；对通过全部安全检查但某安全分量预测概率低于 0.9 的候选，额外施加正标签二元交叉熵损失以提高其安全分数。
  • 训练与部署：三阶段训练——先训练基础粗到细视觉规划器；再从基础模型初始化教师并引入未来观测；最后冻结教师并缓存其选中目标，从第一阶段基础模型初始化学生，用多目标蒸馏与安全感知分数修正微调。未来观测、教师和指标评估器仅用于训练或目标准备。

Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM v1 navtest、NAVSIM v2 navhard（分 Stage 1 与 Stage 2 报告）、HUGSIM 零样本闭环。
  • 评估指标：NAVSIM v1 使用 PDMS 及其分量 NC、DAC、EP、TTC、C；NAVSIM v2 使用 EPDMS 及其分量 NC、DAC、DDC、TLC、EP、TTC、LK、HC、EC；HUGSIM 使用 RC 与 HD-Score，并按 Easy/Medium/Hard/Extreme 分难度报告及平均值。
  • 关键数值：NAVSIM v1 navtest 上 FPD-Drive 达 94.9 PDMS（NC 99.2、DAC 99.5、EP 91.3、TTC 97.5、C 99.9），FPD-Drive-Pro 达 95.5 PDMS（NC 99.3、DAC 99.3、EP 93.1、TTC 97.4、C 100.0）；NAVSIM v2 navhard 上 FPD-Drive 达 55.9 EPDMS，FPD-Drive-Pro 达 58.1 EPDMS；HUGSIM 上 FPD-Drive 的 RC 平均 55.3、HD-Score 平均 45.1。
  • 对比方法：NAVSIM v1 对比 Human Driver、MeanFuser、ReCogDrive、WA-JEPA、DriveFine、DriveSuprim、CLOVER、Drive-JEPA、DrivoR、DrivoR-Scale、ChainFlow-VLA、DriveZero、DriveZero-Scale；NAVSIM v2 对比 RAP、ZTRS、GuideFlow、SimScale、DrivoR、DrivoR-Scale、DriveZero、DriveZero-Scale；HUGSIM 对比 VAD、LTF、UniAD、DrivoR、GigaPixel、DriveZero。
  • 开环结果：NAVSIM v1 上 FPD-Drive-Pro 的 95.5 PDMS 为表中最佳，FPD-Drive 的 94.9 PDMS 与 ChainFlow-VLA、DriveZero 并列；NAVSIM v2 上 FPD-Drive-Pro 的 58.1 EPDMS 为最佳，DriveZero-Scale 的 56.8 EPDMS 为第二。
  • 闭环结果：HUGSIM 上 FPD-Drive 的 RC 平均 55.3 为最佳，高于 DriveZero 的 53.9；HD-Score 平均 45.1 为最佳，高于 DriveZero 的 39.4。
  • 消融实验：在 NAVSIM v1 上消融轨迹解码器、精化 DiT、全局场景编码器、未来 token、评分器、FPMT 与 SASC 等组件；附录还报告教师未来 token 注入、token 级与多目标蒸馏对比、蒸馏目标来源消融、SASC 各组件消融及 DiT 去噪步数消融。
