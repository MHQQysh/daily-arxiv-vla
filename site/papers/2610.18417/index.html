Card 03 核心贡献

核心贡献

  • 提出一种资源高效的两阶段 3D 形状与朝向估计方法，利用 2D 相机包围盒与关联的 3D 雷达点构建 3D 有向包围盒。
  • 通过大量消融实验，为行人、骑车人和汽车确定最优的 3D 尺寸模板参数（长度/宽度/高度缩放因子或范围）。
  • 以激光雷达人工标注的 3D 包围盒为真值，对 3D 位置、3D 尺寸和偏航角估计精度进行定量验证。
  • 针对自行车与汽车，设计并训练仅含少量参数的轻量网络 YawPredictionNet 预测地点特定的偏航角；行人则采用 0° 中性朝向。
  • 与仅相机的单应性（homography）方法进行对比评估（原文该贡献条目在 HTML 中被截断）。
Card 04 方法描述

方法描述

  • 所属模块：路边感知的两阶段 3D 目标检测框架；第一阶段为 2D 相机检测与 3D 雷达关联，第二阶段为 3D 形状与朝向估计。
  • 输入传感器：RGB 单目相机（IDS UI-5260CP-C-HQ Rev.2，8 mm 镜头 Tamron M112FM08）与 3D 汽车雷达（ARS548）；激光雷达（OS1-64）仅用于真值验证与 YawPredictionNet 训练，不参与推理。
  • 场景表示：单目图像帧 I ∈ R^{H×W×3} 与稀疏雷达点云 P（含 3D 坐标、多普勒速度、RCS）；输出状态向量 Θ_i = (x_i, y_i, z_i, l_i, w_i, h_i, ψ_i, v_{r,i}, s_i, c_i)，类别为行人、自行车、汽车。
  • 第一阶段：采用 YOLOv11（置信度阈值 ≥ 0.5）提取 2D 包围盒，用 DBSCAN 空间聚类关联 3D 雷达点；无关联或空簇时退化为单目地平面单应性深度估计；输出 D = {(b_i, c_i, s_i, P_i)}。
  • 第二阶段公共预处理：3D 质心取雷达簇均值（式 1）、径向多普勒速度取簇均值（式 2）、深度尺度 s 取簇最小纵向坐标；借助投影矩阵 P = K·T_RC 及其 4×4 齐次形式，将 2D 包围盒角点经 T_RL 与 T_LG 反投影到地面坐标（式 3），高度由上下边缘 z 坐标差的绝对值得到（式 4）。
  • 类别相关处理：行人令 ψ=0°，用 2D 框左右边缘投影差乘经验长度/宽度缩放因子 (α_ped,l, α_ped,w)（式 6、7）；自行车在雷达点 K_i ≥ 2 时测量簇内 Δx、Δy 并用模板上下界截断（式 8、9），K_i = 1 时取最小值；汽车沿用相同的有界分段公式与专用模板范围，并额外沿传感器视线方向平移质心以对齐可见表面反射。
  • YawPredictionNet：双流轻量多模态网络，图像 ROI 裁剪为 224×224×3 并以 ImageNet 统计量归一化，雷达点字段 (x, y, v_x, v_y) 按传感范围 x∈[0,80] m、y∈[−40,40] m、v_x,v_y∈[−25,25] m/s 归一化到 [−1,1]，其中 v_x、v_y 由多普勒速度与方位角、俯仰角计算（式 10）；网络融合两路特征后回归 (sinψ, cosψ)；汽车变体去掉最终 256 单元隐藏层。
  • 训练细节：AdamW（初始学习率 10^{-3}、batch size 1、梯度裁剪 0.5）、ReduceLROnPlateau（patience 50 epochs）；损失为 L_total = L_MSE(sinψ) + L_MSE(cosψ)。
Card 05 数据集与资源

数据集与资源

  • 数据集：自采路边数据集，真值为激光雷达人工标注的 3D 包围盒；独立验证集 500 帧，含 451 个行人、360 辆自行车、299 辆汽车，共超过 1100 个动态目标实例，距离传感器 0–50 m；数据划分按序列不重叠以避免时间泄漏。
  • YawPredictionNet 训练数据：自行车 262 训练/66 验证样本，训练 400 epochs，权重衰减 0.3，可训练参数 73,442；汽车 329 训练/76 验证样本，训练 100 epochs，权重衰减 0.2，可训练参数 40,162。
  • 模型规模：两阶段框架中的神经网络仅为上述微型网络；YOLOv11 作为现成 2D 检测器，其规模原文未报告。
  • 采集平台：实验室三脚架将传感器组架高至约 3.5 m；三传感器以 ROS 1 近似时间同步，录制频率 10 Hz；相机内参用棋盘格法标定，外参（T_RC、T_LC、T_RL）按文献方法标定，T_LG 通过沿 Z 轴垂直平移补偿安装高度。
  • 训练资源与实车平台：原文未报告（训练硬件与部署车辆平台均未说明）；实时性在 NVIDIA Jetson ORIN 上验证。
