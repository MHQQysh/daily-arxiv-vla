FIVE-VLA: Fast and EffectIVE Autonomous Driving with Recurrent Action Memory

2026-09-16 · 原文 · 翻译 · 2609.18623

论文面向自动驾驶（Autonomous Driving, AD）中的视觉-语言-动作模型（Vision-Language-Action, VLA）任务，目标是在车载边缘设备上高效、有效地完成驾驶轨迹预测。 应用场景包括闭环驾驶（如 Bench2Drive、Fail2Drive 基准）与开环非反应式仿真（如 NVIDIA Physical AI AV 真实世界数据集），涉及超车、让行、紧急制动等对时序上下文敏感的场景。 研究问题主要有三：现有 VLA 参数量过大（如 7B）、推理时生成文本（CoT 或冗余 token）导致多轮前向传播、缺乏时序记忆机制；且已有记忆机制多在视觉域操作，破坏 VLM 预训练知识迁移。 论文提出 FIVE-VLA（Fast and EffectIVE VLA）与循环动作记忆（Recurrent Action Memory, RAM），在单次前向传播中直接预测轨迹，并轻量地引入动作域时序上下文。

Card 03 核心贡献

核心贡献

  • 提出 FIVE-VLA，一种高效 VLA，在 Bench2Drive 与 Fail2Drive 泛化基准上相比此前 SOTA VLA（SimLingo）成功率绝对提升至少 10%（分别约 77% 与 67%）。
  • 提出 RAM，一种轻量记忆机制，通过在上一步动作 token 条件下递归预测当前动作，选择性提升时序推理关键能力，包括让行、超车、紧急制动与驾驶平顺性。
  • 采用高效视觉编码器 FastVLM/FastViTHD，在 448×896 高分辨率图像上仅生成 98 个视觉 token，比既有方法减少 5 倍以上，并支持完全绕过文本生成的单次轨迹预测。
  • 在真实世界 NVIDIA Physical AI AV 数据集开环非反应式仿真中，单视图与四视图设置下碰撞违规率分别比 SimLingo 低 10.2% 与 7.7%。
  • 效率上，FIVE-VLA 仅 641M 参数，在 A100 上约 30 fps、在 T4（边缘设备代理）上约 4 fps，相比此前方法实现 8–30 倍加速。
Card 04 方法描述

方法描述

  • 所属模块：完整自动驾驶 VLA 系统，包含视觉编码器、视觉-语言适配器、文本 tokenizer、目标点适配器、LLM、RAM 模块与动作解码器；RAM 为新增轻量记忆模块。
  • 输入传感器：单视图配置下使用前视相机图像，分辨率 448×896×3；同时输入文本格式的自车速度、两个后续导航目标点（X_route ∈ R^{2×2}）以及文本输入 T。原文未报告 LiDAR 输入的使用。
  • 场景表示：不显式构建 BEV 场景表示；直接由前视图像与文本/目标点条件生成自车轨迹。输出轨迹分解为路径路点 O_path（自车坐标系下按 1 米间隔采样的位置，用于转向控制）与速度路点 O_speed（固定未来时间间隔的自车坐标系位置）。
  • 模型结构：以 FastVLM 为 VLM 骨干，由 FastViTHD 视觉编码器与 Qwen2 LLM 组成；FastViTHD 结合卷积与注意力层，部分卷积层以 stride 2 逐步降低空间维度，从 448×896 图像仅生成 98 个 token，参数约 125M；使用最小 FastVLM 约 620M 参数，最终 FIVE-VLA 共 641M 参数。
  • RAM 结构：包含两个轻量组件——RAMEncoder（一个带自注意力的 transformer block，编码上一时刻动作查询 Q̂_action^{t-1} 得到 RAM 状态 Q_RAM^{t-1}）与 RAMDecoder（一个带交叉注意力的 transformer block，动作查询 Q_action 作为 query 对 RAM 状态做交叉注意力，输出馈入 LLM 的动作 token Q_RAMaction^t）；RAM 仅含 2 个 transformer block，小于视觉域记忆机制常用的 8 个 block。交叉注意力前对未归一化的 Q_action 做 layer normalization，馈入 LLM 前不再归一化。
  • 关键技术一（高效驾驶模式）：将固定不变的输出文本 token（如 “Waypoints:” 共 4 个 token）直接附加到输入 token 序列，使 O_text = ∅，从而绕过自回归文本生成，单次前向传播即可由 Eq.(1) 得到轨迹。
  • 关键技术二（驱动能力）：支持三种能力——无 CoT 的高效驾驶（默认模式）、带 CoT 推理的驾驶（输入“What should the ego do next?”先生成 CoT 文本再生成轨迹）、VQA 自由问答以增强可解释性。训练样本组织为长度为 T 的时序流，每条流仅含单一能力的样本，由输入文本 T 决定。
  • 关键技术三（RAM 微调）：先在不含 RAM 的情况下完成初始微调，再第二阶段引入 RAM 微调，以规避时序数据流训练因批次内多样性下降导致的性能退化；微调时将交叉注意力、自注意力的线性输出投影层及 MLP 第二线性层初始化为零，保证初始化时 Q_RAMaction^t = Q_action，仅通过跳连接传播动作查询；RAM 微调阶段只优化动作解码器、LLM 与 RAM 模块，并使用梯度累积与时序维度上的 stop gradient。
  • 关键技术四（RAM 累积推理）：训练序列长度受 GPU 内存限制通常设为 T=4，而驾驶场景远长于 T；推理时采用 RAM 累积策略，使用一个辅助实例从空 RAM 开始积累信息，每 T/2 步替代主实例，主实例负责生成路点，避免简单地每 T 步重置 RAM 造成时序信息丢失。
Card 05 数据集与资源

数据集与资源

  • 闭环训练数据集：SimLingo 数据集，在 CARLA 中用 PDMLite 专家采集，约 200 万张 4 fps 图像，提供约 140 小时驾驶数据，含 CoT 与 VQA 标注。
  • 开环训练与测试数据集：NVIDIA Physical AI AV 真实世界数据集，约 860 小时用于训练、约 350 小时用于测试，仅使用驾驶监督，无语言监督；训练与评估中对由记录未来自车轨迹导出的导航目标点施加 Student’s t 分布扰动。
  • 仿真器/平台：闭环实验使用 CARLA 仿真器，通过两个 PID 控制器从路径与速度路点得到转向与加速度；开环评估采用 NAVSIM 风格非反应式仿真。原文未报告实车平台。
  • 模型规模：FIVE-VLA 共 641M 参数；FastViTHD 视觉编码器约 125M 参数；使用的最小 FastVLM 约 620M 参数，预训练图像分辨率最高 1024×1024。
  • 训练资源：原文未报告具体 GPU 型号、数量与训练时长；仅提及受 GPU 内存限制批次大小固定为 B=32，训练序列长度自然设为如 T=4，并做流长度从 T=1 到 T=16 的消融。
  • 推理硬件：NVIDIA A100 与 T4 GPU（T4 作为边缘设备代理）。
  • 评估数据集/基准：Bench2Drive、Fail2Drive（含 In-Distribution 与 Generalisation 划分）、NVIDIA Physical AI AV；附录另报告 Fail2Drive 与 Bench2Drive 的进一步结果以及 DriveLM-CARLA VQA 评估。
