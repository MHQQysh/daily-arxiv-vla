Card 03 核心贡献

核心贡献

  • 提出 CrossLiDAR，一个统一的基于 Transformer 的扩散框架，通过 Inter-sensor Module 实现多传感器 LiDAR 生成，并通过 ControlNet 分支支持基于几何线索（如 BEV 先验或 3D 边界框）的可控合成。
  • 提出 4D 生成策略：用 LiDAR Sequence Module 联合生成短多帧序列，并以自回归方式扩展，减少时间漂移、提升长时域一致性。
  • 在 Waymo（多传感器）和 nuScenes（单传感器）上，对单帧生成与 LiDAR 序列生成展示 SOTA 性能。
  • 摘要报告在 nuScenes 与 Waymo 上平均 JSD 提升 29.56%、MMD 提升 15.36%（相对于基线）。
Card 04 方法描述

方法描述

  • 所属模块：LiDAR 生成/仿真框架，包含冻结 VAE 压缩模块、rectified flow 生成主干、Inter-sensor Module、LiDAR Sequence Module、ControlNet 风格条件分支以及自回归生成机制。
  • 输入传感器：S 个不同视角的 LiDAR 传感器；每个传感器点云投影为距离图像，通道包括距离、强度、elongation 等特征；多传感器张量形状为 S×H×W×C，序列张量为 K×S×H×W×C。
  • 场景表示：range image 潜在空间；VAE 仅沿空间维度压缩，编码器对每个传感器帧独立处理，生成潜在 z∈R^{c×h×w}，空间下采样因子为 f。
  • 模型结构：以 MM-DiT 为生成主干，采用 rectified flow 目标；包含时间注意与 inter-sensor 注意分离设计；ControlNet 分支复制 MM-DiT 块并保持原生成权重冻结，通过零初始化残差接入主干。
  • 关键技术：rectified flow 线性桥 z_t=(1-t)z_0+tz_1，训练向量场回归损失 L_RF；推理时积分 ODE dz/dt=v_θ(z,t,c)；LiDAR Sequence Module 使用联合自注意力与沿时间轴的因果掩码；Inter-sensor Module 在传感器维度上做联合注意力，3D RoPE 应用于传感器索引与空间坐标，且不使用因果掩码；ControlNet 使用 BEV 图与投影 3D 边界框作为结构条件；自回归训练时对初始条件帧加入噪声，固定噪声水平 t∈[0.7,1]。
