论文概述

  • 论文面向端到端自动驾驶中的轨迹规划任务，研究世界模型与规划器所依赖的状态表示接口问题。

  • 核心主张：视频预训练阶段应直接学习适合下游世界建模与规划的状态表示，而非由下游训练去适配继承的视觉特征。
Card 03 核心贡献

核心贡献

  • 识别并提出“状态接口不匹配”问题，通过在视频预训练中学习共享状态接口来加以应对。
  • 提出运动导向寄存器（motion-oriented registers），将时间对齐的自车运动注入一小组寄存器，并将其作为掩码 patch 预测的唯一上下文。
  • 提出寄存器介导的掩码 patch 预测与块状寄存器掩码两个预训练分支，分别促进信息充分性与预测结构。
  • 在下游联合训练中复用同一寄存器空间：世界模型以非自回归方式预测未来寄存器，规划器以观测与预测寄存器构成共享场景记忆进行轨迹生成与打分。
  • 在 NAVSIM、NAVSIM-v2 及 HUGSIM 闭环仿真上进行评估，报告了精度与效率两方面的收益。
Card 04 方法描述

方法描述

  • 所属模块：基于 V-JEPA 框架的视频预训练（第一阶段）与联合世界建模/规划训练（第二阶段）。
  • 输入传感器：前左、前、前右三路相机图像堆叠为 256×1024 分辨率输入；原文未报告使用 LiDAR 等其他传感器。
  • 场景表示：将视频 tokenize 为 τ×p×p 的 tubelet 网格，每时间块引入 N_r≪N_p 个可学习寄存器，经自注意力后仅保留寄存器作为共享状态接口；寄存器组织为 N_t×N_r 的时间块–槽位网格。
  • 模型结构：ViT-L 编码器（由 V-JEPA 2 初始化）、在线编码器与 EMA 目标编码器、共享预测器 P_φ、世界模型 F_ψ、轨迹生成器 D_γ、独立打分器 S_ω；τ=2、每 tubelet 8 个寄存器。
  • 关键技术：

- 自车运动条件化：以相邻帧相对运动 (Δx, Δy, Δψ) 投影后加到寄存器嵌入上，按时间块对齐。

- 寄存器介导掩码 patch 预测：在线编码器处理可见 patch 与全部寄存器后丢弃 patch 输出，仅用寄存器与位置查询预测被掩码 patch 的 EMA 目标。

- 块状寄存器掩码：保留全部 patch、掩码连续寄存器块，用共享预测器恢复被掩码寄存器状态。

- 联合训练：未来寄存器查询 Q_f 与观测寄存器、零填充的运动条件、当前自车状态一起经世界模型单次非自回归预测；K=64 条候选轨迹由共享场景记忆生成，打分器用停止梯度对候选打分，训练时以 NAVSIM/PDM 准则构造 oracle 目标。

- 损失：预训练为 patch 与寄存器的 ℓ1 损失之和；联合训练为预测、轨迹、打分三项损失加权之和，权重均为 1。

- 推理：选择得分最高的候选轨迹执行。

Card 05 数据集与资源

数据集与资源

  • 数据集：预训练使用 OpenScene（nuPlan 的紧凑重分发，约 120 小时城市驾驶、2 Hz）；联合训练使用 NAVSIM navtrain；评估使用 NAVSIM v1 与 v2 的 navtest 划分。
  • 仿真器：闭环评估在 HUGSIM 中进行，共 436 个场景、四个难度等级。
  • 模型规模：编码器为 ViT-L，初始化自 V-JEPA 2 权重；其他模块规模原文未报告。
  • 训练资源：预训练 22,000 步，32 张 NVIDIA A100，全局 batch size 256，AdamW，学习率 1.5×10⁻⁴ 余弦衰减至 10⁻⁶，权重衰减 0.04，EMA 动量 0.996→0.999；联合训练 10 个 epoch，8 张 NVIDIA RTX 4090，全局 batch size 128，基础学习率 2×10⁻⁴（在线编码器乘 0.1）。

Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM-v2（主表）、NAVSIM-v1、HUGSIM 闭环仿真；NAVSIM 为开环评估协议，HUGSIM 为动作影响后续状态的闭环评估。
  • 评估指标：NAVSIM-v2 报告 NC、DAC、DDC、TLC、EP、TTC、LK、HC、EC 与 EPDMS；NAVSIM-v1 报告 NC、DAC、TTC、C、EP 与 PDMS；HUGSIM 报告各难度（Easy/Medium/Hard/Extreme）及平均的 RC 与 HD-Score。
  • 关键数值：

- NAVSIM-v2：EPDMS 92.5，为表中最高，分别超过 DrivoR 2.2、CoWorld-VLA 2.5、Discrete-WAM 2.1；同时取得最佳 EP 91.7、DDC 99.8、HC 98.4。

- NAVSIM-v1：PDMS 93.2，分别超过 iPad 1.5、SGDrive 2.1、DriveFuture 2.5；EP 最高为 90.7。

- HUGSIM：零样本闭环，无基准特定训练或微调，平均 RC 51.6、HD-Score 39.4，均为最高。

- 效率：摘要报告在 EPDMS 优于当前最优 1.6 的同时，推理延迟仅为 DriveLaW 的 1/10。

  • 对比方法：包括 TransFuser、ARTEMIS、Hydra-MDP++、DiffusionDrive、Drive-JEPA、SparseDriveV2、DrivoR、NTR 等端到端方法；ReCogDrive、WAM-Flow、DriveVLA-W0、DriveWorld-VLA、CoWorld-VLA 等 VLA 方法；WoTE、DreamerAD、DriveLaW、EponaV2、Latent-WAM、Discrete-WAM 等世界模型方法；HUGSIM 上对比 UniAD、VAD、LTF、GTRS-Dense、DrivoR、Latent-WAM。
  • 条件说明：NAVSIM 结果为开环评测；HUGSIM 结果为闭环仿真评测；消融实验与可视化在原文第 4.2、4.3 节及附录中，但提供的 HTML 文本已截断，具体消融数值与可视化结论原文未在可用部分报告；实车结果原文未报告。
