Card 02 论文概述

论文概述

Card 03 核心贡献

核心贡献

  • 提出CRISP，首个以未来LiDAR点云预测为预训练目标的CR融合框架，LiDAR仅在预训练时作为特权监督，推理时完全不需要。
  • 设计增强型雷达编码器，包含自车运动感知和残差空间校准，使雷达特征对自车状态和模态差异更鲁棒。
  • 提出雷达增强的时间自注意力，通过门控查询初始化将雷达距离和多普勒线索注入BEV时间传播，并引入查询条件时间门代替均匀平均。
  • 提出多模态特征渲染，由两个独立的跨注意力分支（相机与雷达）生成残差更新，再通过Modality Innovation Gate（MIG）选择性融合。
  • 在nuScenes上验证CRISP在多任务（三维检测、跟踪、建图、运动预测、未来占用预测、规划）上的可迁移性，优于相机和CR基线。
Card 04 方法描述

方法描述

  • 所属模块：预训练骨干（相机-雷达时空BEV编码器）+ 预训练解码器 + 下游任务头。
  • 输入传感器：多视角相机图像和雷达扫描（预训练时另需LiDAR作为监督）。
  • 场景表示：BEV（200×200 网格，范围 [-51.2, 51.2] m），垂直占用 bin 数 Z=16。
  • 模型结构：基于 BEVFormer 时空编码器，包含 ResNet-101 + FPN 作为图像骨干，增强型雷达编码器（PointPillars 基础上加入自车运动注入和残差校准）；时间自注意力中先做门控雷达条件化再执行可变形时间注意力；多模态渲染中相机用空间交叉注意力、雷达用 BEV 可变形交叉注意力，MIG 采用8个通道组用于组间门控融合；预测解码器为三个 transformer 层，自回归输出未来占用。
  • 关键技术：

- 门控特征更新：时间门和模态门均由当前 BEV 查询预测，避免均匀融合。

- 雷达增强时间注意力：雷达特征投影后经门控与查询相加，使后续偏移和注意力权重预测雷达感知。

- 独立而非竞争的模态门：相机门和雷达门独立预测，可同时启用或同时抑制。

- 预训练损失：稀疏占用分类损失 + 密集体素占用重建损失，仅监督当前帧和3个未来帧，推理时 rollout 到6帧。

Card 06 评估与结果

评估与结果

  • 评估基准：nuScenes 数据集，采用 ViDAR 和 UniAD 风格协议。
  • 评估指标：点云预测用 Chamfer Distance（CD，0.5s至3.0s）；下游任务包括检测（mAP、NDS）、跟踪（AMOTA、AMOTP、Recall）、建图（IoU）、运动预测（minADE、minFDE、MR、EPA）、未来占用（IoU、VPQ）、规划（avg L₂、碰撞率）。
  • 关键数值：

- 点云预测：历史0s、1.5s CD 0.67，优于HERMES（0.95）、LRS4Fusion（0.75）；历史和未来3.0s CD 0.91（最佳），优于ViDAR（1.97）；历史1s、1.5s CD 0.67（最佳），优于ViDAR（1.40）。

- 与LRS4Fusion相比，CRISP在短时（0.5s、1.0s）略差（0.52 vs 0.35，0.59 vs 0.57），但在长时（1.5s以后）全面占优。

- 与HERMES相比，CRISP在多数时间点更优，且HERMES为语言增强世界模型。

  • 对比方法：HERMES、LRS4Fusion、4D-Occ、ViDAR。
  • 条件：开环评估（无闭环实验报告），仿真和实车条件原文未明确区分。
