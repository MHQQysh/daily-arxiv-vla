Card 03 核心贡献

核心贡献

  • 提出 CARLAverse 的总体系统架构、软件框架与跨域集成方法，使异构 HITL 节点能在共享虚拟环境中交互。
  • 提出分布式物理架构：延迟敏感的自身动力学与高频力反馈在客户端本地节点计算，中心 CARLA 服务器负责 NPC 物理与全局交通协调。
  • 在既有模块化硬件抽象框架基础上扩展出三种人类交互域节点：DrivoCARLA（车辆）、CycloCARLA（自行车）、WalkoCARLA（行人）。
  • 在通信上绕过 ROS/DDS 中间件用于主动控制，改用 CARLA 原生 API RPC（TCP/IP）进行可靠状态更新，并以专用无连接 UDP 传输高频率力反馈与运动提示数据，ROS 仅用于后台数据记录（rosbag）。
  • 提供跨领域支撑组件，包括 CARLAverse 工具库、YAML 编排、基于 Web 的 HMI/遥测、空间音频（CARLAcoustics）、力反馈服务器与运动平台服务器等。
