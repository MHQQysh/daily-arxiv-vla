IRGNN: Efficient Invariant Radar Graph Neural Network for Radar Point Cloud Object Detection

2026-08-14 · 原文 · 翻译 · 2608.14394

本文提出 IRGNN（Invariant Radar Graph Neural Network），用于自动驾驶场景下的雷达点云目标检测任务。 针对雷达点云稀疏、无序、信息量少且对坐标变换敏感的问题，IRGNN 将雷达点云重构为具有平移不变和旋转不变特征的图结构，并采用改进的消息传递神经网络进行特征学习和目标检测。 实验在 RadarScenes 数据集上进行，IRGNN 在检测精度上优于现有雷达目标检测方法，并显著降低推理时的计算成本和显存占用。

Card 03 核心贡献

核心贡献

  • 提出 IRGNN，一种面向雷达点云目标检测的不变图神经网络框架。
  • 设计平移不变与旋转不变的图表示，包括将坐标转换为相对坐标、引入时间索引与连通性信息，并提出基于局部参考坐标系（LRF）的增强点对特征（EPPF）方法。
  • 在消息传递神经网络（MPNN）基础上加入残差连接和虚拟节点层，以缓解过平滑问题并增强全局上下文建模。
  • 通过后处理优化（向量化、中间张量释放），在 RTX 2060 12GB 上降低了 38.69% 的总耗时和 62.39% 的显存占用。
Card 04 方法描述

方法描述

  • 所属模块：感知模块中的雷达点云目标检测（图神经网络方法）。
  • 输入传感器：毫米波雷达点云（RadarScenes 数据集，使用 x, y, vx, vy, timestamp, RCS 六类特征）。
  • 场景表示：将雷达点云构建为图 G(V, E)，节点为点，边由 KNN（σ=20）生成；节点和边特征经过平移/旋转不变设计后用于 GNN 处理。
  • 模型结构：包括特征嵌入层（MLP 扩展维度）、虚拟节点层（与首层节点特征相加）、MPNN 消息传递层（由 MLP 生成和聚合消息）、残差块（含批归一化和 ReLU）、分类头与边界框预测头（两层 MLP 加 ReLU）。
  • 关键技术：平移不变性通过将坐标转为相对坐标 (dx, dy) 实现；旋转不变性通过 EPPF 实现，EPPF 基于加权协方差矩阵的特征分解构建局部参考轴（LRA），计算节点距离、相对角度等特征；损失为加权分类交叉熵损失与 Huber 边界框损失。

Card 06 评估与结果

评估与结果

  • 评估基准：RadarScenes 数据集，IoU 阈值为 0.3。
  • 评估指标：平均精度（AP）、均值平均精度（mAP）。
  • 关键数值：IRGNN 达到 mAP 0.591（Car 0.696、Pedestrian 0.286、Pedestrian Group 0.600、Two-Wheeler 0.639、Large Vehicle 0.735），优于 RadarGNN（0.567）、PointNet++（0.459）、PointPillars（0.392）、DOG（0.327）。
  • 对比方法：RadarGNN、PointPillars、PointNet++、DOG（主对比）；EGNN、EGNNVel、MPNNVel（图卷积层对比）；RIConv++（旋转不变管道对比）。
  • 消融实验：加入残差块使 mAP 从 0.567 提升至 0.578；再加虚拟节点层使 mAP 提升至 0.591。
  • 后处理优化：相对基线，向量化将提取耗时从 131.43 秒降至 30.19 秒；中间张量释放将原始框生成耗时从 224.23 秒降至 176.28 秒，VRAM 从 8.11GB 降至 3.05GB。
  • 评估条件：均为离线开环实验，原文未涉及闭环或实车测试。
