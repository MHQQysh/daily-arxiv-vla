Towards Real-Time Full-Waveform LiDAR Transformers via Intensity-Guided Token Reduction and Physics-Aware Augmentation

2026-11-05 · 原文 · 翻译 · 2611.07613

Card 02 论文概述

论文概述

  • 论文面向自动驾驶与机器人中的 LiDAR 感知任务，针对全波形 LiDAR（FWL，Full-waveform LiDAR）数据的体素级分类识别（包含 Noise、Object、Glass、Ghost 等类别），具体以 Ghost-FWL 中的鬼影检测作为代表性实时感知挑战。
  • 研究问题有两个：一是 FWL 数据体量大、绝大多数为低强度背景区域，导致 Transformer 模型推理速度远低于实时要求；二是公开带峰级标注的 FWL 数据稀缺、玻璃和积水等少数类样本不足，导致模型对未见场景泛化能力有限。
  • 论文目标是构建首个实时 FWL Transformer，并同时提升精度与分布外泛化能力。
Card 03 核心贡献

核心贡献

  • 提出 FWL-ToPM，一种面向 FWL 数据的 token 剪枝与合并机制：依据强度分布剪除低强度背景 token，并对剩余 token 进行空间结构感知的合并，在保留关键波形内容的同时降低计算量。
  • 发现与图像 Transformer 中激进剪枝会破坏训练稳定性不同，对 FWLT 剪枝最多 70% 的 token 可稳定提升精度，说明低强度 token 稀释了目标相关信号。
  • 提出 FWLAug 数据增强框架（含 FWLShiftMix 与 FWLCutMix），在保持每条射线 ToF 波形结构和视锥几何的前提下扩充训练多样性并缓解类别不平衡。
  • 在 Ghost-FWL 基准上取得 53.2 FPS、F1-mean 0.592，相对此前最优方法约 8 倍加速与近 9 个点 F1 提升，建立了首个实时 FWLT。
  • 构建了完全位于 Ghost-FWL 采集地点之外的 OOD 测试集，FWLAug 在该集合上取得所比较配置中最优 F1-mean。
Card 04 方法描述

方法描述

  • 所属模块：感知中的 FWL 体素级分类前端，包含推理加速模块 FWL-ToPM 与训练正则化模块 FWLAug。
  • 输入传感器：FWL LiDAR，输入为按 (u×v×t) 格式组织的完整回波直方图张量 V∈R^{H×W×T}，H、W 对应仰角与方位角，T 为 ToF 轴；输出为体素类别 logits y∈R^{H×W×T×C}。原文未报告具体传感器型号参数（仅致谢中说明使用 Sony LiDAR 传感器）。
  • 场景表示：以 LiDAR 原点为顶点的视锥形射线观测结构，每个像素保留沿 T 轴的连续时序强度波形。
  • 模型结构：以 Vision Transformer 为骨干；输入划分为 3D patch（p_H×p_W×p_T），经核大小与步长均为 p 的 3D 卷积投影为 E 维 token，加 3D 位置编码，送入 N_L 个 Transformer 块（多头自注意力 + MLP），末层经单层线性解码器逐 token 预测 patch 内体素类别并重排为原布局。原文说明 token 选择与聚合机制可适用于任意 token-based 模型。
  • 强度引导剪枝：记录每个 patch 内最大信号强度 m_i，升序排序后将最低比例 ρ_low 的 patch 划为 P_low（移除），其余为 P_high 送入编码器；训练时排除被剪 patch 的损失，推理时这些区域全部预测为 noise 标签；不改变任何权重，可免训练用于预训练模型。
  • 稀疏感知 token 合并：将剪枝后的稀疏不规则 patch 集合沿空间填充曲线（实验采用 Morton 序）序列化以保持 3D 空间邻近性，按 dst token 比例 ρ_d 等间隔选取目标 token，按余弦相似度将源 token 分配给最相似目标 token，并按合并比例 ρ_m 进行平均合并；注意力计算后将目标特征复制回原 token 位置以保持残差一致；同样不改变参数权重。
  • FWLAug：FWLShiftMix 将各像素峰值位置转成 3D 点，沿射线方向按 Δd∼U(−3,15) 米平移后重投影回距离视图并相应平移 T 轴波形，再用另一场景中含玻璃的区域 Ω_src 填补平移产生的空白区域 Ω_blank；FWLCutMix 将 CutMix 扩展到 FWL，按混合比例 λ 确定裁剪尺寸，优先从源帧选取少数类（玻璃）区域整体沿 T 轴粘贴到目标帧随机位置。
  • 训练目标：沿用 Ghost-FWL 的 focal loss，优化器为 AdamW，学习率 1.0×10⁻⁴，训练 50 epochs。
Card 05 数据集与资源

数据集与资源

  • 数据集：Ghost-FWL（原文称为目前唯一公开的带峰级标注 FWL 数据集），原始尺寸 (H×W×T)=(512×400×700)；去除上下各 88 bins、前 25 bins、后 375 bins 后全帧为 (336×400×300)；因对比方法显存限制，所有方法统一使用四分之一裁剪输入 (168×200×300)。
  • OOD 测试集：作者自建，采集地点与 Ghost-FWL 完全分离，使用相同 FWL 传感器平台与采集配置、相同标注协议；500 帧，含 300 个以上玻璃实例及 Ghost-FWL 中不存在的多空间分离玻璃区域场景。
  • 模型规模：patch 尺寸 (8×4×20)，Transformer 块数 N_L=6，注意力头数 N_h=6，特征维度 E=240，dst token 比例 ρ_d=0.1；FWL-ToPM 主要实验取 ρ_low=0.7、ρ_m=0.9。原文未报告总参数量。
  • 训练资源：Intel Core i9-14900K CPU 与单张 RTX 6000 Ada Generation GPU；原文未报告训练总时长。
  • 仿真器：原文未报告（无仿真器使用）。
  • 实车/实采平台：数据由 Sony LiDAR 传感器平台采集（致谢中提及 Sony Semiconductor Solutions 提供），原文未报告车载部署或嵌入式平台实验。

Card 06 评估与结果

评估与结果

  • 评估基准：Ghost-FWL 分布内测试，以及作者构建的 OOD 测试集；评估为离线开环的体素分类精度与吞吐测试，原文未报告闭环仿真或实车闭环评估。
  • 评估指标：排除 Noise 类后的各类平均 F1（F1-mean）、玻璃类 F1、全尺寸帧每秒推理数（FPS）。
  • 主要结果（表 1，均未使用 FWLAug）：FWL-ToPM（剪枝+合并）F1-mean 0.592、53.2 FPS；无 FWL-ToPM 时为 0.555、2.01 FPS；仅剪枝 0.591、20.3 FPS；仅合并 0.565、18.0 FPS。
  • 对比方法（FWL 类）：Scheuble et al. F1-mean 0.497、1.97 FPS；Ikeda et al.（此前最优）0.503、6.54 FPS；即约 9 个点 F1 提升与 8 倍以上加速。
  • 对比方法（图像 token 缩减类）：DynamicViT 0.480、20.0 FPS；ToMe 0.543、5.24 FPS；本文剪枝与合并各自均优于对应图像方法。
  • 消融结论：剪枝单独在约 20 FPS 内保持约 0.59 的 F1，但比例提高至约 80 FPS 时精度明显下降；合并单独抑制精度下降但加速有限（约 18 FPS）；两者互补后超过 50 FPS。
  • 免训练适用性：不做额外训练直接剪枝时精度随缩减比例急剧下降；直接合并在约 20 FPS 下 F1-mean 仍高于 0.5，说明合并方法可免训练降低计算量。
  • FWLAug 消融（表 2）：无增强时 Ghost-FWL F1-mean 0.592、Glass 0.352，OOD F1-mean 0.406、Glass 0.491；仅 FWLShiftMix 时 0.622/0.376、OOD 0.425/0.494；两者合用 0.617/0.385、OOD 0.452/0.575；仅 FWLCutMix 时 0.586/0.315、OOD 0.434/0.606。完整 FWLAug 取得最大 OOD F1-mean 增益（相对基线 4.6 个点），玻璃类提升 8.4 个点。
  • 原文报告的局限：低强度剪枝可能误删远处、低反射率或恶劣天气下的弱信号并造成漏检；仅单一传感器平台、未做跨传感器评估；FWLAug 不是光学仿真器，未建模距离
