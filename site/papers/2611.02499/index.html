Card 03 核心贡献

核心贡献

  • 提出 EvoOcc 快速-慢速演化占用预测框架，将现有部署友好与性能导向占用预测器视为互补的冻结异步 logits 来源，联合利用二者优势改善精度-延迟平衡。
  • 将演化占用预测建模为连续时间受控动力系统，以处理不规则快系统间隔与变化的慢系统延迟，并可在两种运行模式间切换。
  • 设计双状态演化：自我状态演化补偿自我运动引起的确定性坐标偏移，场景状态演化建模真实的几何与语义场景变化；并含状态锚点校准器以慢系统 logits 刷新高质量残差锚点。
  • 在 Occ3D-nuScenes 上针对三组快慢系统对（两组同质、一组异质）与不规则到达条件开展实验，显示相对快系统持续提升且保持远低于慢系统的延迟。
Card 04 方法描述

方法描述

  • 所属模块：位于冻结的快速与慢速占用预测器之后的后处理演化模块，直接作用于 logits；任务为学习演化映射 F_θ：{慢系统 logits O^s_{t_m}，t_m 至 t_n 间的快系统 logits 流} → 精炼占用预测，通过补偿慢快 logits 间差距实现。
  • 输入传感器：原文未报告具体车载传感器配置与输入模态细节（仅说明输入为快速与慢系统的占用 logits 及其编码特征）。
  • 场景表示：体素化 3D 语义占用（占用与语义标签的语义体素体）；状态为慢系统与快系统 logits 编码特征之差（残差），在世界坐标与自我坐标中表述；使用自我运动引起的表观速度场 u_t 与卷积局部空间算子 G_θ 定义演化。
  • 模型结构与关键技术：

- 连续时间受控动力系统：在世界坐标定义 dH^w_t = G^w_θ(H^w_t, X^w_t) dX^w_t；转换到自我坐标后得到包含“自我变化项 + 输运项 = 受控项”的形式，其中控制增量 dU_t := dX^e_t + (u_t·∇X^e_t) dt。

- 状态锚点校准器：慢 logits 到达时，用慢分支编码器 E_s 与快分支编码器 E_f 计算 H^e_{t_m} = E_s(O^s_{t_m}) − E_f(O^f_{t_m})。

- 自我状态演化：用 W_ego 将上一时刻状态锚点与快特征变换到当前自我栅格，补偿确定性坐标偏移。

- 场景状态演化：以 ΔU_{t_n} = X^e_{t_n} − X̃^e_{t_n} 作为控制增量的离散近似，按前向欧拉步 H^e_{t_n} = H̃^e_{t_n} + G^e_θ(H̃^e_{t_n}, X^e_{t_n}) ΔU_{t_n} 更新状态。

- 将最终状态解码为对当前快系统 logits 的残差修正；采用算子分裂思路依次执行自我状态演化与场景状态演化。

- 训练目标：体素级语义损失（加权 focal 与 Lovász 损失组合）加射线终止似然损失 L_term = −log(Σ q_{r,i})，总损失为各监督时间戳上的加权和，权重 λ_term；原文未报告 λ_term 的具体数值。
