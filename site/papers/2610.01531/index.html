Card 03 核心贡献

核心贡献

  • 评估了五个参数量不超过 10B 的 VLM（Qwen3.5-9B、Gemma4-E4B、LLaVA-OneVision-7B、DriveFusion/DriveFusionQA-4B、NVIDIA Alpamayo-1.5-10B）在四个驾驶相关 QA 数据集上的表现。
  • 覆盖单帧、多视角、多帧和单目等不同视觉输入设置，分析视觉损坏对准确率和置信度可靠性的影响。
  • 使用 glare、fog、motion blur、lens occlusion 四类视觉损坏，代表光照、天气、运动传感器效应和部分可见性退化。
  • 应用推理时方法 Visual Evidence Augmentation（VEA）检验其能否在退化视觉条件下改善模型可靠性。
  • 发现 VEA 对部分模型和数据集有提升，但增益并不在所有设置下保持一致。

方法描述

Card 06 评估与结果

评估与结果

  • 评估基准：DrivingVQA、NuScenes-QA-mini、STRIDE-QA Bench、Open Spatial Reasoning (OSR)。
  • 评估指标：Accuracy、AUROC（使用 VAUQ）、Expected Calibration Error (ECE)、Brier score。
  • DrivingVQA 和 OSR 使用 exact-match accuracy；NuScenes-QA-mini 使用 GPT-4 judge 处理开放式答案；STRIDE-QA Bench 按原始定位准则，预测距离误差在 ±25% 内且朝向误差在 ±10° 内视为正确。
  • 评估条件：clean 输入与四类损坏输入（glare、fog、motion blur、lens occlusion）；涉及单帧、多视角、多帧、单目等视觉输入设置。原文未报告闭环或实车评估。
  • DrivingVQA 上，Qwen3.5-9B clean 结果为 Acc 55.8、AUROC 53.6、ECE 21.5、Brier 29.3；DriveFusionQA-4B clean 为 Acc 50.4、AUROC 49.0、ECE 13.5、Brier 27.2；Gemma4-E4B clean 为 Acc 55.2、AUROC 55.1、ECE 19.5、Brier 28.4；LLaVA-OV-7B clean 为 Acc 53.8、AUROC 51.3、ECE 21.9、Brier 30.2；Alpamayo clean 为 Acc 45.5、AUROC 56.6、ECE 24.0、Brier 30.8。
  • DrivingVQA 上，多数模型准确率变化较小，但置信度指标变化明显；DriveFusionQA-4B 的 AUROC_VAUQ 接近 chance；Gemma4-E4B 在部分损坏下准确率变化中等，但 AUROC_VAUQ 下降更大。
  • NuScenes-QA-mini 上，损坏影响更强。Qwen3.5-9B clean 为 Acc 42.1、AUROC 67.0、ECE 49.5、Brier 47.5；DriveFusionQA-4B clean 为 Acc 35.3、AUROC 61.6、ECE 23.8、Brier 27.2；Gemma4-E4B clean 为 Acc 38.0、AUROC 63.5、ECE 54.7、Brier 51.7；LLaVA-OV-7B clean 为 Acc 44.5、AUROC 64.7、ECE 29.5、Brier 30.6；Alpamayo clean 为 Acc 50.0、AUROC 51.7、ECE 19.1、Brier 28.6。
  • NuScenes-QA-mini 上，Qwen3.5-9B、Gemma4-E4B、LLaVA-OV-7B 在多种损坏下仍保持高于 chance 的 AUROC_VAUQ；DriveFusionQA-4B 在部分损坏下准确率略升且 ECE 降低，但 AUROC_VAUQ 持续下降。
  • VEA 效果总结：VEA 可提升部分模型和数据集性能，并在部分损坏下保持增益，但增益并非在所有模型和数据集组合中一致。
  • VEA 在 DrivingVQA 与 NuScenes-QA-mini 上对 Alpamayo-1.5-10B 有较大且一致的准确率提升，但 AUROC_VAUQ、ECE 和 Brier 变差。
  • VEA 在 STRIDE-QA Bench 上存在限制：其重新加权空间证据，但不添加时间运动信息，因此不能直接解决依赖时间线索的推理；Alpamayo-1.5-10B 在 DrivingVQA 和 NuScenes-QA-mini 上收益强、在 OSR 上多有提升，但在 STRIDE-QA Bench 上一致损失准确率。
  • 对比方法：论文将结果与 DriveBench 和 USB 的相关发现进行比较，指出既有工作显示 VLM 在视觉输入退化时仍可给出看似合理的答案，而本文结果显示模型仍能利用部分损坏视觉输入，但其置信度并不总能反映视觉证据是否支持正确预测。
