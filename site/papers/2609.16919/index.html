NeuroSymbEAD: A Large Scale Neuro-Symbolic Caption Dataset for Omni-Directional Embodied Autonomous Driving

Card 03 核心贡献

核心贡献

  • 提出 NeuroSymbEAD，据原文称为首个面向户外 3D 自动驾驶场景的自我中心神经符号描述数据集。
  • 构建自我中心知识图谱，对静态和动态对象标注类别、类别层级、朝向、方向以及相对自我车辆的距离等信息。
  • 在 KITTI-360 上生成多层次文本描述，包含对象级描述和组级描述，形成轻量级自我中心场景地图表示。
  • 提供数据标注流程与算法，可将 3D 驾驶场景转换为结构化自我中心语言，并支持对象级与组级注释生成。
  • 使用预训练 grounding 和自回归 captioning 网络进行基准测试，为交通场景解释、3D 推理和可解释自动驾驶感知提供评测基准。
Card 04 方法描述

方法描述

  • 所属模块：面向 3D 视觉语言中的 captioning 与 grounding，构建神经符号描述数据集与基准。
  • 输入传感器：原文说明基于 KITTI-360 的 LiDAR 记录驾驶序列；具体传感器配置原文未报告。
  • 场景表示：以自我车辆为中心的局部坐标系，原点映射到 Velodyne 传感器，x 轴指向车辆前方，y 轴指向左侧，z 轴向上。
  • 知识图谱生成：先提取对象 3D 真值边界框及语义类别、中心、尺寸等参数，再计算对象与自我车辆的距离、朝向和 heading，最后结合语义属性与本体符号生成对象级和组级描述。
  • 对象级描述生成：描述包含对象标签、动态状态、距离、相对角度、速度、heading、heading class 与 residual 等信息。
  • 组级描述生成：根据语义类别、动态状态以及粗略自我中心位置（前/后、左/右）对对象进行聚类，生成组级描述。
  • 基准模型：采用 3DJCG 进行训练与评估；原文指出使用真值边界框而非 VoteNet 预测框。
  • 关系模块修改：移除检测头，将真值边界框参数通过全连接层融入增强特征，并在 Relation Encoding Module 中计算对象与自我车辆的距离。
  • 特征处理：增强特征在边界框中心处进行分组与聚合，类似 Set Abstraction 层，但兴趣点预定义为边界框中心；随后经过多头自注意力层输入 grounding 与 captioning 头。
  • 原文未报告：具体传感器融合方式、完整端到端模型规模、推理实时性。
Card 05 数据集与资源

数据集与资源

  • 数据集：KITTI-360。
  • 数据集规模：39,723 个自我中心描述场景，覆盖 9 个 KITTI-360 驾驶序列；共 692,081 条文本描述，其中 486,844 条对象级描述、205,237 条组级描述。
  • 场景统计：平均每场景 12.26 个对象、17.42 条描述；包含 4,450 个唯一对象、10 个对象级语义类别、2 个组级类别（human 和 vehicle）。
  • 静态/动态统计：对象级描述中 400,974 条为静态对象，85,870 条为动态对象；组级描述中 151,092 条为静态组，54,145 条为动态组。
  • 类别统计：cars 占 375,250 条对象级描述；person 与 rider 共 47,114 条；其他车辆相关类别共 64,480 条；组级中 vehicle groups 为 172,859 条，human groups 为 32,378 条。

  • 模型规模：原文未报告模型参数量或规模。
  • 训练资源：单张 A100 GPU，16 个 worker，batch size 为 64。
  • 实车平台：基于 KITTI-360 真实驾驶数据；具体实车平台信息原文未报告。
Card 06 评估与结果

评估与结果

  • 评估基准：NeuroSymbEAD 数据集上使用 3DJCG 进行 3D captioning 与 3D visual grounding 基准评估。
  • 评估数据划分：训练使用序列 0、4、5、6、7；评估使用序列 9、10；序列 2 和 3 因 3DJCG 预处理与评估流程中的数据不一致被排除在 captioning 和 grounding 基准之外。
  • 评估指标：captioning 使用 BLEU-4 与 ROUGE；grounding 使用 language accuracy 与 reference accuracy。
  • 关键数值：3DJCG 在验证集上取得 BLEU-4 54.67、ROUGE 61.45、Language Accuracy 99.71%、Reference Accuracy 96.42%。
  • 对比方法：原文主要报告 3DJCG 的基准结果；未报告与其他方法的完整对比数值。
  • 评估条件：使用真值 3D 边界框，不使用 VoteNet 预测框，因此无需计算 IoU；论文报告的是验证集结果。
  • 开环、闭环、仿真或实车条件：原文未报告开环、闭环或仿真评估；评估基于 KITTI-360 真实驾驶数据，属于真实数据上的离线基准评测。
  • 限制：数据集当前聚焦交通相关 human 和 vehicle 类别，本体较稀疏；描述由结构化模板生成，语言多样性有限；基准仅使用真值框和一个 captioning/grounding 基线，未来将扩展到预测检测和现代驾驶 VLM。
