Card 02 论文概述

论文概述

  • 任务：实时交通标志检测（traffic sign detection）。
  • 应用场景：智能交通系统、高级驾驶辅助系统（ADAS）与自动驾驶车辆。
  • 研究问题：在光照变化、恶劣天气、运动模糊、部分遮挡等条件下，小尺寸或视觉退化交通标志检测性能下降，重要空间信息易丢失；同时需要在嵌入式/资源受限平台上保持实时推理效率。
Card 03 核心贡献

核心贡献

  • 提出一种 SE（Squeeze-and-Excitation）增强的三瓶颈（triple-bottleneck）特征提取模块，将自适应通道重校准与渐进式多尺度表示学习结合，放置在网络输入端做早期特征细化。
  • 提出统一的架构增强，将重参数化分层特征提取（RepHMS）与高效多尺度特征融合（MAFPN 中的 SAF、AAF）协同结合，促进跨语义层的信息交换。
  • 在 BTSD、CCTSDB2021、GTSDB 三个地理区域、标志类别体系和采集条件不同的基准上独立训练与评估，验证方法的一致性。
  • 提供逐类失败分析，刻画性能提升与回退发生的类别（增益集中在基线表现差的类别，回退集中在基线已解决的类别）。
  • 保持轻量化：参数量约 2.2M，与基线参数量相当，兼顾精度与实时性。
Card 04 方法描述

方法描述

  • 所属模块：基于 YOLOv10 的单阶段检测框架，扩展为 SE 增强输入阶段、分层骨干网络和多分支特征金字塔颈部；并采用 MHAF-YOLO 的 RepHMS 与多分支融合策略。
  • 输入传感器：原文未报告（仅使用图像数据集，未说明具体车载传感器配置）。
  • 场景表示：输入图像经 letterbox 缩放至 640×640，像素值归一化至 [0,1]，标注为归一化 YOLO 格式；网络在 P2–P5 四个阶段提取分层特征。
  • 模型结构：

- SE 增强三瓶颈块：双分支设计，第一分支用 1×1 卷积、步长 2 下采样保留 shortcut 信息；第二分支经同样卷积后串联 Type-1、Type-2、Type-1 三个瓶颈（Type-1 使用 1×1 卷积加 3×3 与深度卷积；Type-2 使用 5×5 卷积扩大感受野），每个瓶颈含自适应平均池化（AAP）、全连接层与跳跃连接；两分支通道拼接后经 1×1 卷积投影回 C_out 通道。

- SE 机制：Squeeze 用全局平均池化得到通道描述子，Excitation 用 W1（降维比 r）、SiLU、W2、Sigmoid 生成通道权重，Recalibration 做通道乘法；计算复杂度为 O(2C²/r)，r 取 8 或 16。

- 分层骨干：四阶段（P2–P5），RepHMS 模块使用 3×3、5×5、7×7、9×9 异构卷积核捕获局部与全局上下文。

- 多分支特征金字塔：SAF 将深层信息与浅层空间特征融合以利小目标检测；AAF 聚合浅层高分辨率、浅层低分辨率、同级与上一层信息；融合前各分支经最近邻上采样 U(·)、步长卷积下采样 Down(·)、全局平均池化 GAP 与 1×1 卷积对齐到目标分辨率 H_n×W_n，通道拼接后再经 1×1 卷积投影回 C_n。

- RepHMS：输入经 1×1 卷积后分成 N 个并行分支，首个分支保留原始特征，其余分支用 M 个级联 RepHDWConv 逐步细化并逐级传递；输出通道拼接后由 1×1 卷积融合；RepHDWConv 训练时使用多种核尺寸的深度卷积，推理时重参数化为单一深度卷积。

  • 关键技术：通道注意力（SE）、多尺度异构卷积、结构重参数化、多分支辅助特征金字塔融合。
  • 原文未报告：传感器类型、具体部署硬件平台、模型各层的精确通道数配置。
Card 05 数据集与资源

数据集与资源

  • 数据集：

Card 06 评估与结果

评估与结果

  • 评估基准：BTSD、CCTSDB2021、GTSDB，每个数据集独立训练与评估（非跨域迁移）。
  • 评估指标：Precision、Recall、F1-score、逐类 AP、mAP@IoU=0.5；另报告 GFLOPs、参数量与分阶段运行时间。
  • 关键数值（mAP@0.5）：

- BTSD：Squeeze-Aware-YOLO 0.747，对比 YOLOv8 0.663、YOLOv10 0.679、YOLOv11 0.668、MHAF-YOLO 0.685（较次优模型提升 6.2 个百分点）。

- CCTSDB2021：Squeeze-Aware-YOLO 0.794，YOLOv8 0.794、YOLOv10 0.792、YOLOv11 0.804（最高）、MHAF-YOLO 0.769。

- GTSDB：Squeeze-Aware-YOLO 0.840（最高），YOLOv8 0.809、YOLOv10 0.826、YOLOv11 0.836、MHAF-YOLO 0.816。

  • 逐类结果：

- BTSD 15 类中在 5 类取得最佳；Sharp Bend (Right) 0.894、No Horn 0.952、SL60 0.950、Side Rd. (L) 0.831 等；Sharp Bend (Left) 仅 0.320、U-Turn 0.514。

- GTSDB 在 Mandatory 类领先（0.760），Others 与 YOLOv11 持平（0.825），Danger 和 Prohibitory 略低于 YOLOv8/YOLOv10。

  • 失败分析：按基线难度分组，4 个困难类（基线 <0.60）平均提升 0.359 mAP（4/4 提升）；7 个中等类平均 +0.004（3/7 提升）；4 个简单类（≥0.90）平均下降 0.310（0/4 提升）。镜像对称标志（左右急弯）的回退被归因于 SE 的朝向无关性与水平翻转增强。
  • 消融实验（mAP@0.5）：

- MHAF 基线：BTSD 0.685 / CCTSDB2021 0.769 / GTSDB 0.816。

- 加 TLB：0.722 / 0.783 / 0.832（分别 +3.7、+1.4、+1.6）。

- 加 TLB+SE：0.747 / 0.794 / 0.840（分别 +6.2、+2.5、+2.4）。

  • 运行时：Squeeze-Aware-YOLO 在 CCTSDB2021 上 9.7 ms、BTSD
