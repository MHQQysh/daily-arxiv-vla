Card 03 核心贡献

核心贡献

  • 提出显式–隐式实例匹配机制，结合结构亲和度初始化与选择性语义精炼，建立高效且自适应的软对应关系。
  • 提出统一的匹配–融合形式化框架，支持空间 LiDAR–相机交互和时间 past–current 交互，结合场景特定几何先验与共享语义精炼及单一残差聚合算子。
  • 在多种前端配置上展示一致的感知增益，并提升计算与内存效率。
  • 证明其与 E2EAD 框架兼容，例如将时间 MatchFusion 集成到 SparseDrive，在不增加额外监督的情况下改进感知。
Card 04 方法描述

方法描述

  • 所属模块：MatchFusion 是实例级匹配与融合模块，运行在上游基于 query 的感知模型输出的稀疏实例表示上，与前端特征提取解耦。
  • 输入传感器：涉及 LiDAR 与相机；也涉及时间维度的历史帧与当前帧实例。
  • 场景表示：实例由结构化目标状态和 query embedding 组成；目标状态包含 3D 中心、尺寸、yaw 角和预测类别。
  • 模型结构：包括显式结构初始化、隐式语义精炼、matchmap 引导的残差融合。
  • 关键技术：使用几何相似度与类别一致性初始化亲和度矩阵；类别一致时保留几何亲和度，不一致时设为负无穷；对结构上合理的关联使用实例 embedding 进行语义修正；通过 Sigmoid 得到软 matchmap；软 matchmap 引导多对多残差特征聚合。
  • 空间 LiDAR–相机交互：将两种模态的 3D box 投影到图像平面，使用归一化位置偏移和对数尺寸比构成相对几何描述子；通过正弦位置编码与 MLP 得到视角特定几何亲和度，并在共同可见视角上做可见性感知平均。
  • 时间 past–current 交互：通过目标运动补偿和自车运动变换对齐历史实例；在 BEV 空间构造几何亲和度；使用单向残差聚合将历史证据融入当前 query。

Card 06 评估与结果

评估与结果

  • 评估基准：nuScenes 验证集，用于检测、跟踪、规划与效率评估。
  • 评估指标：检测使用 NDS 和 mAP；跟踪使用 AMOTA 和 MOTA；规划使用轨迹 L2 误差和碰撞率 CR；效率使用 FLOPs、GPU 内存和推理延迟。
  • 感知结果：MatchFusion-ST 在多个前端配置上相比更强单模态前端取得一致提升，NDS 提升 1.9–3.1%，mAP 提升 4.3–5.5%。
  • 弱相机检测器结果：使用 DETR3D 时，融合将 NDS 从 70.1 提升到 72.0，mAP 从 65.1 提升到 69.4。
  • Sparse4Dv3 配置：MatchFusion-ST 将 NDS 提升到 73.0，mAP 提升到 70.4，并改善 AMOTA 和 MOTA。
  • 效率结果：MatchFusion-ST 系统达到 73.0 NDS、62.3 AMOTA、254.2 GFLOPs、3.7 GB 内存；相比 SparseFusion，FLOPs 降低 55.3%，GPU 内存降低 39.3%。
  • 延迟结果：相机前端、LiDAR 前端和 MatchFusion-ST 分别需要 47.3 ms、283.3 ms 和 12.9 ms；包含跟踪操作时，MatchFusion-ST 仅占总延迟的 3.7%。
  • E2EAD 结果：将 MatchFusion-T 集成到 SparseDrive 后，NDS 提升 0.8，mAP 提升 0.5，AMOTA 提升 2.7，MOTA 提升 1.7；CR 从 0.123% 降至 0.119%，L2 误差从 0.63 m 略微增加到 0.64 m。
  • 消融结果：仅结构匹配达到 72.2 NDS、69.1 mAP；结构加语义提升到 72.4 NDS、69.2 mAP；使用多视图图像平面几何的结构加语义达到 72.5 NDS、69.6 mAP。
  • 融合策略消融：直接 concat 为 69.4 NDS、64.8 mAP；self-attention 为 71.3 NDS、67.3 mAP；cross-attention 为 71.8 NDS、67.9 mAP；MatchFusion-S 为 72.5 NDS、69.6 mAP。
  • 类别一致性消融：不启用类别一致性为 72.1 NDS、69.0 mAP；启用后为 73.0 NDS、70.4 mAP。
  • 鲁棒性：空间旋转扰动 1°、2°、4° 时，NDS 分别降至 71.9、71.8、71.7；即使 4° 扰动仍比 LiDAR-only 基线高 1.6 NDS 和 2.9 mAP；时间扰动下 MatchFusion-ST 至少保持 72.3 NDS、69.2 mAP、61.2 AMOTA、60.1 MOTA。
  • 对比方法：包括 TransFusion、DeepInteraction、SparseFusion、DeepInteraction++、StreamCMT、SparseDrive、DETR3D、StreamPETR、Sparse4Dv3、SimPB 等。
  • 评估条件：主要为 nuScenes 数据集上的开环感知、跟踪与规划评估；原文未报告闭环仿真或实车测试结果。
