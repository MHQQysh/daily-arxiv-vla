Card 02 论文概述

论文概述

  • 论文面向自动驾驶中的长时程视觉里程计（Visual Odometry）任务，目标是从单目视频序列中前馈预测每帧的相机到世界位姿。
  • 应用场景包括自动驾驶中的建图、定位、运动预测、长时程场景理解，以及将未整理视频转化为轨迹-视频配对数据以训练驾驶世界模型。
  • 研究问题在于：现有前馈联合重建模型（如 π³）虽然局部几何精度较高，但在长时程驾驶序列上相机位姿估计存在抖动、碎片化和漂移，导致跨帧点图不对齐；同时标准注意力机制在长序列上计算复杂度呈二次增长，且无约束全局注意力在重复场景结构、运动模糊和动态智能体下容易产生歧义。
Card 03 核心贡献

核心贡献

  • 提出紧凑相机 token 设计：每帧用一小组相机 token 作为位姿查询，避免密集的全对全时序注意力，降低长轨迹处理的计算复杂度。
  • 提出局部到全局的时序注意力策略：先在短时序窗口内聚合稳定运动线索，再进行序列级全局整合，以缓解长时程几何歧义并减少抖动和漂移。
  • 提出中间局部轨迹监督：在中间层附加辅助相对位姿损失，鼓励相机 token 编码局部一致运动，提升时序稳定性。
  • 在 Waymo Open Dataset、KITTI 和大规模私有数据集上验证方法优于现有前馈方法，并大幅降低抖动和漂移；结合 VGGT-Long 后优化流程可提升超长距离轨迹保真度。
Card 04 方法描述

方法描述

  • 所属模块：在预训练 π³ 风格前馈联合重建架构上进行位姿专门化适配；冻结几何特征聚合模块和点图路径，从头训练专用相机位姿分支。
  • 输入传感器：单目视频序列，不假设已知相机内参，采用无标定、无参考帧设置。
  • 场景表示：每帧由冻结骨干产生图像 token，并通过粗网格区域平均池化初始化为紧凑相机 token，作为位姿查询。
  • 模型结构：相机 token 化模块；局部到全局时序位姿解码器，交替进行帧内自注意力和时序跨注意力；相机 token 查询时序邻域，经两个局部窗口阶段和一个全局整合阶段；最后将相机 token 池化为单表示，经轻量 MLP 头预测平移和 6D 旋转表示，并组装为 SE(3) 位姿。
  • 关键技术：相对位姿监督避免固定参考帧；测地旋转距离和 ℓ1 平移损失；在第二个局部窗口时序跨注意力阶段后附加辅助位姿头，对局部邻域相对位姿轨迹进行中间监督；总损失为相对位姿损失与辅助损失之和。

Card 06 评估与结果

评估与结果

  • 评估基准：WOD、KITTI Odometry、私有 PDD；KITTI 上还评估长时程前馈流程 FFVO-Long。
  • 评估指标：ATE（RMSE，米，经每序列 Sim(3) 对齐）；RPE（Δ=1 帧，平移 RMSE 米、旋转 RMSE 度）；WOD 和 PDD 报告序列均值。
  • 关键数值：

- WOD：FFVO w/o augmentation 的 ATE 为 0.714 m，RPE_t 为 0.118 m，RPE_r 为 0.124°；FFVO 的 ATE 为 0.862 m，RPE_t 为 0.114 m，RPE_r 为 0.128°；π³ 的 ATE 为 1.150 m，RPE_t 为 0.156 m，RPE_r 为 0.113°；VGGT 的 ATE 为 1.359 m。

- PDD：FFVO 的 ATE 为 2.494 m，RPE_t 为 0.621 m，RPE_r 为 0.195°；FFVO w/o augmentation 的 ATE 为 2.779 m，RPE_t 为 0.619 m，RPE_r 为 0.184°；π³ 的 ATE 为 7.928 m；π³-finetuned 的 ATE 为 5.720 m；VGGT 的 ATE 为 10.194 m。

- KITTI：表中列出多方法逐序列 ATE；FFVO-Long 与 π³-Long、DA3-Streaming 等对比，定性显示 FFVO-Long 更好保持局部轨迹分离和整体形状。

  • 对比方法：WOD 和 PDD 上对比 VGGT、π³、π³-finetuned；KITTI 上对比 VGGT-Long、π³-Long、DA3-Streaming，以及 SCE-SLAM、VGGT-Motion、Scal3R、HyVGGT-VO、LingBot-Map、DPV-SLAM++ 等已报道单目 RGB VO/SLAM 结果；WOD 还列出 DROID-SLAM、MASt3R-SLAM、CUT3R、VGGT-Long 等仅 ATE 结果。
