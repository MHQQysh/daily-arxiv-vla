Card 02 论文概述

论文概述

  • 任务：面向自动驾驶、监控与公共安全场景的行人检测，聚焦密集场景下的遮挡行人检测。
  • 应用场景：拥挤真实场景，存在严重遮挡、剧烈尺度变化以及严格实时性要求。
  • 研究问题：现有轻量检测器难以在精度与效率之间取得平衡，且常忽视质量感知特征建模以及分类与定位之间的一致性，导致拥挤条件下性能不稳定。
Card 03 核心贡献

核心贡献

  • 识别出轻量检测器在密集场景失效的根源：无法在遮挡导致的信息歧义下自适应调整行为，表现为置信度、空间覆盖、尺度一致性三类耦合失效模式。
  • 提出统一的质量感知自适应框架，在三个关键失效点同时打破失效循环，而非孤立处理单一症状。
  • 提出三种机制：UQE 通过分布方差显式建模定位不确定性并引入可学习惩罚权重；MPSC 通过双向空间冗余与自适应质量感知门控恢复空间覆盖；CTDM 通过“稳定-验证-精化”闭环增强多尺度一致性。
  • 在 CityPersons 与 CrowdHuman 上验证了相较近期轻量方法更优的精度-效率权衡。
  • 通过消融实验验证三种机制的耦合效应，说明任一机制缺失都会限制其余机制的效果。
Card 04 方法描述

方法描述

  • 所属模块：整体为单阶段轻量检测框架，基于 YOLOv11n 实现；MPSC 部署于 P4/P5，CTDM 与 SPPF 集成，UQE 替换标准检测头。
  • 输入传感器：原文未报告（论文未明确说明具体传感器类型）。
  • 场景表示：基于多尺度特征金字塔的特征表示，涉及 P3、P4、P5 等尺度层级；输入为 640×640 图像。
  • 模型结构：以 YOLOv11n 为基线，包含 UQE 检测头、MPSC 多路径空间补全模块、CTDM 多尺度一致性保持模块。
  • 关键技术：

- UQE：将预测方差显式纳入得分，公式为 S_final = σ(S_cls + f_θ(TopK(B_reg)) − λ·Var(B_reg))，其中 Var(B_reg) 表示定位不确定性，λ 可学习，采用减法施加单调惩罚；检测头卷积采用深度可分离卷积分解以保持轻量；方差计算复杂度为 O(N×C_reg)，C_reg=4。

- MPSC：在 C3k2 多分支框架中引入标准扫描与移位扫描两条互补路径，使用可学习门控 α、β 进行质量感知路径选择，并进行加权融合 F_final = Σ W_i·Path_i(F_{i−1})；部署于 P4/P5 以降低小特征图（20×20 对比 80×80）上的开销。

- CTDM：包含 Token Statistics Self-Attention（T）、DynamicTanh（D）、Mona normalization（M），通过稳定、验证、精化三阶段闭环增强多尺度一致性，并采用双路径融合 Y = Conv_1×1(Concat[X_loc, E]) 保留原始局部细节。

  • 复杂度：UQE 通过深度可分离卷积将复杂度从 O(C_in×C_out×K²×H×W) 降至 O(C_in×K²×H×W + C_in×C_out×H×W)，参数从 Θ(C_in×C_out×K²) 降至 Θ(C_in×K² + C_in×C_out)，当 K²<C_out 时收益显著；MPSC 与 CTDM 复杂度分别为 O(L×D²) 和 O(N×C²)。

Card 06 评估与结果

评估与结果

  • 评估基准：CityPersons 与 CrowdHuman。
  • 评估指标：遵循 COCO 协议，采用 AP@0.50（AP50）、AP@0.50:0.95（AP）、Recall、Precision 评估精度；GFLOPs 与 Parameters 评估效率。
  • 关键数值：

- CrowdHuman：DensePed-Lite 达到 80.9% AP50、50.3% AP、71.3% Recall、85.8% Precision，5.5 GFLOPs、2.53M 参数。

- CityPersons：DensePed-Lite 达到 62.1% AP50、38.6% AP、52.9% Recall、79.7% Precision。

- 消融（CityPersons）：baseline 59.6 AP50，+M 60.2，+U 61.3，+T 60.5，+M+U 61.2，+T+U 61.5，+M+T 61.3，完整模型 62.1 AP50、38.6 AP、52.9 Recall、79.7 Precision，5.5 GFLOPs / 2.53M。

- CTDM 消融（CityPersons）：baseline 59.6 AP50，+T 59.8，+D 59.7，+M 59.9，+T+D 60.2，Full CTDM 60.5 AP50、Precision 79.9。

- UQE 消融（CityPersons）：Baseline（仅 cls）59.6 AP50，+TopK pooling 60.4，+Variance（无 λ）60.8，+UQE（可学习 λ）61.3 AP50。

- MPSC 消融（CityPersons）：单路径 baseline 59.6 AP50，双路径等权 59.9，MPSC 自适应门控 60.2 AP50。

  • 对比方法：YOLOv11n、YOLOv5n、YOLOv8n、YOLOv10n、YOLO26n、YOLOv12n、YOLOv13n、YOLOv8-CB、Hyper-YOLO-n、D-FINE-N、DEIM-D-FINE-N、Mamba-YOLO-T、YOLOv11s、RT-DETR-R18、SSD、Faster R-CNN、RetinaNet。
  • 对比结果：DensePed-Lite 在 CrowdHuman 上较 DEIM-D-FINE-N 高 0.8% AP50 和 0.5% AP，参数约为其 60%；Recall 较基线提升 3.5 个百分点，较 DEIM-D-FINE-N 高 2.5 个百分点；Precision 同时提升至 85.8%。RT-DETR 达到 80.8% AP50 但需 56.9 GFLOPs 和 19.9M 参数；YOLOv11s 达到 81.4% AP50，需 21.3 GFLOPs 和 9.4M 参数；Mamba-YOLO-T 达到 81.8% AP50 但需 12.4 GFLOPs 和 5.66M 参数。
