Card 03 核心贡献

核心贡献

  • 提出 M-GMP 与机动路由的 M³F 结合的场景自适应机动生成器，将运动定义的机动分量显式保留为可评估、可修正的独立候选假设，并一步生成意图条件化轨迹。
  • 提出共享未来 BEV 场上的轨迹引导证据探针，将每个候选投影到当前与预测 BEV 中提取轨迹特定证据，用于 PDM 因子对齐打分，避免逐候选未来推演。
  • 提出 Metric Prism 进行分因子 PDM 打分，并提出 ECFR 使用同一证据在 Frenet 坐标系预测局部残差，修正后的候选与保留候选在同一打分函数下联合重打分选择。
  • 以轻量 ResNet-34 TransFuser 感知骨干，ManeuverFlow-TF 在 NAVSIM v1/v2 navtest 上达到 90.58 PDMS 与 90.14 EPDMS；相机-only LTF 变体在 WorldEngine 闭环基准上取得 75.19（logged traffic）与 74.58（IDM-controlled traffic）的 PDMS*。
Card 04 方法描述

方法描述

  • 所属模块：统一的“Hypothesize–Verify–Improve”规划框架，包含感知编码与规划上下文、M-GMP、M³F 生成器、共享未来 BEV 世界模型、Metric Prism 打分器与 ECFR 修正器。
  • 输入传感器：TF 配置输入三路相机图像、LiDAR BEV 栅格、自车状态与导航指令；LTF 配置输入三路相机图像、自车状态与导航指令，并以学习潜变量张量替代 LiDAR。原文未报告其他传感器输入。
  • 场景表示：编码器输出 BEV 地图特征、agent/机动查询与状态—导航上下文；世界模型每个规划步预测一次候选无关的多步未来 BEV 特征场，包含绝对特征与时间残差特征。
  • 模型结构：M-GMP 将专家轨迹按位移、平均航向与速度趋势分为 M 个运动族并拟合因子化高斯先验，推理时按场景条件权重分配候选；M³F 采用 iMF 的边界场与 JVP 构造，轨迹状态 token 依次查询 BEV—自车特征与 agent 记忆，时间条件 AdaLN 调制，机动路由的专家参数化区间平均场并一步输运；证据探针将候选航点投影到当前与时间对齐的预测 BEV 采样聚合；Metric Prism 以集合自注意力与证据交叉注意力预测五类 PDM 因子（NC、DAC、EP、TTC、Comf）并按固定 log-PDM 组合打分；ECFR 在路径对齐 Frenet 系预测残差并更新轨迹。
  • 关键技术：一步 MeanFlow 式轨迹输运、机动路由混合专家、共享未来场上的轨迹特定证据检索、基于同机动索引最优参考轨迹的 Frenet 残差监督、修正与保留候选的联合重打分；推理时保留 Top-3 机动分量并按最大余数法分配 N 个候选。

Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM v1 navtest（12,146 场景）与 NAVSIM v2 navtest，均在单一官方基准版本下评估；WorldEngine 全部场景闭环评估。
  • 评估指标：NAVSIM v1 使用 NC、DAC、TTC、Comf.、EP 与 PDMS；NAVSIM v2 使用 NC、DAC、DDC、TLC、EP、TTC、LK、HC、EC 与 EPDMS；WorldEngine 使用 SR、EP 与 PDMS*。
  • 关键数值：NAVSIM v1 上 TF 变体 PDMS 90.58（NC 98.42、DAC 98.01、TTC 95.19、Comf. 99.99、EP 85.36），LTF 变体 PDMS 89.98；NAVSIM v2 上 TF 变体 EPDMS 90.14，LTF 变体 EPDMS 89.70；WorldEngine 闭环上 logged traffic PDMS* 75.19（SR 87.48、EP 60.68）、IDM traffic PDMS* 74.58（SR 87.92、EP 60.89）。
  • 对比方法：NAVSIM v1 对比 UniAD、TransFuser、World4Drive、GoalFlow、DiffusionDrive、WoTE、MeanFuser、VADv2、DriveSuprim；NAVSIM v2 对比 Ego Status MLP、TransFuser、DriveSuprim、DiffusionDrive、MeanFuser；WorldEngine 对比 VADv2、DiffusionDrive、MeanFuser。基线使用官方结果。
