Card 02 论文概述

论文概述

  • 面向自动驾驶场景的多相机视频输入，研究前馈式（feed-forward）动态 4D 驾驶场景重建任务，支持从输入视角渲染与插值新视角合成。

Card 03 核心贡献

核心贡献

  • 提出 IGRecon4D 前馈框架，将动态 4D 高斯重建与实例级语义学习统一在自动驾驶场景中。
  • 提出实例-动态一致性约束（Instance-Dynamic Consistency Constraint, IDC），利用实例级语义线索作为“潜在动态参与者先验”监督动态掩码预测，提高易发生动态-静态泄漏的交通参与者区域的高召回定位与重建。
  • 引入 LiDAR 引导的深度估计以获得可靠高斯位置，实现 LiDAR 锚定的高斯定位，提升几何精度与多视角一致性（由新视角合成与消融实验验证）。
  • 在 Waymo Open Dataset 上进行实验并在 nuScenes 上做零样本评估，显示主基准全图重建提升以及跨数据集交通参与者区域重建更强。
Card 04 方法描述

方法描述

  • 所属模块：前馈式动态场景重建框架，包含共享主干的重建分支与实例级语义分支；重建分支含高斯属性预测头、动态掩码预测头、LiDAR 引导深度估计与动态-静态高斯渲染模块。
  • 输入传感器：多相机视频、相机参数、稀疏 LiDAR 深度图（LiDAR 点按相机参数投影到图像平面得到）；原文未报告其他传感器输入。
  • 场景表示：逐帧像素对齐的 3D 高斯集合（每像素 15 维，含颜色、位置、旋转四元数、尺度、不透明度与正寿命参数），寿命参数通过高斯衰减调制不同时刻不透明度；渲染时分离为逐帧动态高斯、全局静态高斯集合以及天空半球高斯。
  • 模型结构：ViT 编码器（DINOv2 特征）加交替注意力层（帧注意力 + 全局注意力，沿用 VGGT 设计）得到分层特征；高斯参数由 DPT 风格预测头从分层特征与 DINO 特征联合预测；动态掩码由单独预测头从注意力特征预测；实例级语义分支使用可学习实例查询（含跨注意力与自注意力更新，策略沿用 SegVGGT）与 DPT 风格稠密特征图做点积得到实例掩码。
  • 关键技术：以 InfiniDepth 从稀疏 LiDAR 深度恢复稠密深度并反投影得到高斯位置（不直接回归位置）；动态掩码将高先验交通参与者区域分配给逐帧高斯，其余累积为静态高斯；动态、静态与天空高斯由 Gsplat 可微光栅器联合渲染。
  • 训练目标：两阶段训练。第一阶段用伪实例标注（SAM3 生成）与匈牙利匹配训练实例分支，损失为分类损失 + BCE + Dice；第二阶段冻结实例分支与第一阶段模块，用实例掩码并集作为动态掩码先验监督（BCE），并优化 ℓ2 图像损失、LPIPS、逆寿命 ℓ1 正则与天空掩码 BCE。
  • 原文未报告：显式运动场/变形建模细节、模型总参数量、推理时是否需要额外逐场景优化。

Card 06 评估与结果

评估与结果

  • 评估基准：Waymo Open Dataset 验证集（所有方法统一输入视角、输入帧数与指标协议）；nuScenes 零样本评估；新视角合成为相机 0 与相机 1、相机 0 与相机 2 之间的插值视角。
  • 评估指标：全图 PSNR、SSIM、LPIPS；交通参与者区域（TPR）PSNR 与 TPR SSIM（在 SAM3 生成的交通参与者掩码上计算）；深度 RMSE（D-RMSE，与投影 LiDAR 稀疏深度线性对齐后计算）；运行时间与显存；新视角合成以 FID 为代理指标；实例分支以 mAP、mAP50、mAP25、PQ、mIoU 对齐 SAM3 伪标注。
  • 关键数值（Waymo，Table 1）：Ours 取得 TPR PSNR 26.76、TPR SSIM 0.858、PSNR 29.51、SSIM 0.869、LPIPS 0.102、D-RMSE 4.610、时间 16.20 s、显存 69.27 GB；相较最强基线 DGGT（PSNR 26.93、LPIPS 0.116、D-RMSE 7.470），PSNR 提升 2.58 dB。
  • 新视角合成（Table 2）：Ours 左视 FID 117.73、右视 FID 132.41，DGGT 分别为 129.47、151.10。
  • 消融（Table 3）：w/o IDC 时 TPR PSNR 23.81、TPR SSIM 0.774；w/o LiDAR 引导深度时 PSNR 25.20、LPIPS 0.213、D-RMSE 11.584；两者均去除时 TPR PSNR 21.02、PSNR 24.77。
  • 零样本 nuScenes（Table 4）：Ours 取得最佳 TPR PSNR 25.05 与 TPR SSIM 0.809，但全图 PSNR 25.93、SSIM 0.752、LPIPS 0.172 低于 AnySplat（27.89、0.857、0.120）。
  • 实例分支对齐伪标注（Table 5）：Ours mAP 0.540、mAP50 0.808、mAP25 0.898、PQ 0.574、mIoU 0.918，其中 PQ 与 mIoU 优于 Mask2Former、VidEoMT 等对比方法中的部分指标（原文说明专用分割模型在 mAP/PQ 上可更高）。
  • 对比方法：AnySplat、STORM、DGGT、NoPo4D、DrivingForward；实例分割对比 Mask2Former、DVIS++、VidEoMT。
  • 实验条件：全部为数据集上的开环重建/渲染评估（含新视角合成与零样本跨数据集评估），原文未报告闭环规划评估或实车实验。
