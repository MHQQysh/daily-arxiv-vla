Card 02 论文概述

论文概述

  • 论文针对自动驾驶与道路养护场景，解决“车道标线质量评估”问题：现有自动驾驶数据集通常面向车道检测与场景理解，缺少面向维护的车道标线可见性、连续性、退化标签。

  • 研究问题：在缺少密集人工标注的条件下，如何构建开放数据集与透明、无参考的车道标线质量指标与基线模型，并验证其与人类感知排序的一致性。
Card 03 核心贡献

核心贡献

  • 提出据称为首个公开的车道标线质量评估基准，由南德州采集的超过 63,000 帧地理参考行车记录仪帧及评估框架组成，融合 egocentric 手机视频与同步 GPS。
  • 提出三个互补、透明的车道质量指标：Contrast Stability Index（CSI，基于 Laplacian 响应刻画车道–背景对比）、Line Continuity Ratio（LCR，基于边缘与 Hough 线段聚合刻画几何连续性）、Regression Lane Confidence Score（RLCS，回归车道计数与 OSM 地图标签一致性的语义置信度）。
  • 构建基于 OSM 车道计数弱监督的匹配子集（3,339 帧），并对车道计数采用回归而非分类，以保留序关系、处理类别不平衡并支持置信度输出。
  • 使用 50 张人工排序图像开展试点验证，将所提指标与 PSNR、SSIM、BRISQUE、NIQE、LPIPS 对比，显示 LCR、CSI 与人类排序一致性更强。
Card 04 方法描述

方法描述

  • 所属模块：数据采集与帧提取、地理空间弱监督标签获取、车道线分割、指标计算与学习式基线回归。
  • 输入传感器：Android 智能手机（Samsung Galaxy S16 PM 相机）固定前向安装，使用 GPS Map Camera（v1.7.2）采集同步视频与 GPS 元数据；假设相机内参已由设备预标定、镜头畸变可忽略、GPS 与视频时间同步。
  • 场景表示：逐帧 RGB 图像 I_t∈R^{H×W×3} 与 GPS 坐标 g_t=[纬度,经度]^T；学习式基线将帧缩放至固定分辨率（如 96×96）。
  • 地理空间标签：通过 OpenStreetMap Overpass API 在 15 m 半径内查询最近道路段，优先使用 lanes 标签，否则用 lanes:forward+lanes:backward；无标签记为 N/A；构建 Matched 与 Unmatched 两个帧集。
  • 分割与指标：使用现成预训练 YOLOP 仅保留车道线分割掩码；CSI 为分割车道灰度图 Laplacian 响应的标准差（可选按均值归一化）；LCR 为 Canny 边缘图上概率 Hough 线段总长度除以边缘像素数；RLCS=exp(−d_i²/τ²)，其中 d_i=\|ŷ_i−y_i\|，τ>0。
  • 学习式基线：以 ImageNet 预训练 MobileNetV2 为骨干，用 MSE 损失训练连续车道计数回归及 CSI、LCR 的百分位归一化（[0,1]）回归；车道计数使用类别权重处理不平衡。
  • 原文未报告：CSI/LCR 百分位模型的具体训练轮数、τ 的取值、MobileNetV2 的具体参数量与模型规模。

数据集与资源

Card 06 评估与结果

评估与结果

  • 评估基准：Matched 子集（OSM 车道计数弱标签）用于车道计数回归与 RLCS；Unmatched 帧用于训练 CSI/LCR 百分位回归，Matched 集上定性查看分数分布；另设 50 张人工排序图像作为人类基准。
  • 评估指标：MSE、MAE、R²、Spearman ρ、Kendall τ。
  • 车道计数回归：MSE 0.096，R² 0.751（20 epoch，含类别权重）。
  • CSI 百分位回归：MAE 0.039，MSE 0.0021，R² 0.97。
  • LCR 百分位回归：MAE 0.093，MSE 0.013，R² 0.84。
  • 人类排序一致性（50 张图像）：LCR ρ=0.7316、τ=0.5472；CSI ρ=0.6112、τ=0.4400；NIQE ρ=−0.5699、τ=−0.3959；LPIPS ρ=−0.5251、τ=−0.3878；SSIM ρ=−0.4504、τ=−0.3469；PSNR ρ=−0.2526、τ=−0.1804；BRISQUE ρ=−0.2279、τ=−0.1535。
  • 对比方法：PSNR、SSIM、BRISQUE、NIQE、LPIPS；负相关对 BRISQUE、NIQE、LPIPS 属预期（其分数越低表示质量越好）。
  • 条件说明：全部为离线开环评估，基于预训练 YOLOP 分割结果，未进行闭环控制、仿真或自动驾驶实车测试；作者指出人工验证仅 50 张、属试点证据，且结果受限于南德州白天场景与分割误差传播。
