Card 02 论文概述

论文概述

  • 解决的自动驾驶任务：面向自动驾驶感知的数据生成，即“仿真到真实”（sim-to-real）视频转换，用生成模型把仿真器渲染的驾驶视频转换为照片级真实风格视频，同时保持与原场景的几何与标注一致性。

  • 研究问题：仿真器可大规模产生带自动标注的数据，但仿真渲染的外观真实度不足（纹理/材质制作成本高、实时渲染简化光照），造成与真实数据的域差；真实视频有真实外观但缺乏准确的 G-buffer 标注；核心问题是既要学到可靠的几何与材质条件控制，又要适配真实世界外观，且不破坏场景结构与标注一致性。
Card 03 核心贡献

核心贡献

  • 提出 NeuralSRender：一个参数高效的 G-buffer 引导仿真到真实视频转换框架，将稠密几何与材质条件注入预训练视频扩散模型，相对主干仅引入 1.45% 参数开销。
  • 设计两阶段训练策略：第一阶段在具有准确 G-buffer 的合成视频上联合训练 G-buffer 投影器与 Stage-I LoRA 学习条件控制；第二阶段在带估计 G-buffer 的真实视频上冻结投影器与 Stage-I LoRA，仅训练额外 LoRA 做外观风格适配，以抑制估计噪声干扰。
  • 构建 GenReal 大规模驾驶视频数据集：包含两个合成域（GenReal-City、GenReal-CARLA）与一个真实域（GenReal-DV），每样本含 RGB 视频、basecolor/depth/normal/metallic/roughness 序列及描述性文本提示，用于训练与跨域评估。
  • 验证转换数据对下游感知训练的价值：用其转换视频替代原始仿真渲染训练感知模型，可提升在真实基准上的检测与分割性能。
  • 公开代码、数据与模型权重（原文给出 GitHub 链接）。
Card 04 方法描述

方法描述

  • 所属模块：生成式数据合成/神经渲染模块，用于感知训练数据增强；不涉及规划控制模块。
  • 输入传感器：输入为仿真器导出或逆渲染估计的 G-buffer 序列（depth、normal、basecolor、metallic、roughness，共 n=5 个属性序列）与文本提示；不含激光雷达、IMU 等其它传感器信息（原文未报告）。
  • 场景表示：以稠密 G-buffer（几何：深度、法线；材质：basecolor、金属度、粗糙度）作为合成域与真实域共享的结构表示，与 RGB 视频在空间和时间上对齐。
  • 模型结构：基于预训练视频扩散 Transformer Wan2.2-TI2V-5B；冻结视频 VAE 编码器将每个 G-buffer 属性序列分别编码到与视频潜变量相同的时空分辨率，与含噪视频潜变量按通道拼接，经轻量 3D 卷积投影器融合并映射回原潜变量通道维度，再连同时间步与文本提示送入 DiT 主干；在 DiT 注意力层插入 LoRA，主干权重 W0 与 VAE 全程冻结。
  • 关键技术：Flow Matching 训练目标（z_t=(1−t)z0+tε，u_t=ε−z0），以预测速度与目标速度的 L2 损失分别定义 Stage I 的 L_syn 与 Stage II 的 L_real；Stage I 训练投影器 θ_proj 与 ΔW_syn，Stage II 以 W_II=W0+ΔW_syn*+ΔW_real 仅优化 ΔW_real；文本提示控制天气、光照与时段等全局外观。
  • 原文未报告：投影器的具体层数/通道数等网络细节，以及传感器标定、多相机配置等信息。
Card 05 数据集与资源

数据集与资源

  • 数据集：自建 GenReal，含 GenReal-City（Unreal Engine 5 CitySample + MatrixCity 插件，训练 1,795 段、测试 140 段，81 帧，G-buffer 准确）、GenReal-CARLA（1,143 段测试，CARLA 多地图，81 帧，G-buffer 准确）、GenReal-DV（源自 OpenDV，训练 5,819 段、参考集 7,903 段，G-buffer 由 DiffusionRenderer 估计）；下游评估使用 nuImages 与 Cityscapes。

Card 06 评估与结果

评估与结果

  • 评估基准：生成质量在 GenReal-City 与 GenReal-CARLA 测试集上评测，FVD 以 GenReal-DV 参考集计算；下游迁移在 nuImages（检测）与 Cityscapes（分割）上评测，且不做目标域微调。
  • 评估指标：FVD↓、CLIP-T↑（LongCLIP 文本-视频对齐）、NDE↓（用 Video Depth Anything 估计相对深度后的归一化平均绝对差）、VLM-BT↑（Gemini 3 Flash、GPT-5.4 mini、Qwen3.6-Plus 成对偏好经 Bradley–Terry 聚合）、峰值显存 VRAM↓ 与 FPS↑（1280×704×81，单张 NVIDIA RTX Pro 6000）；下游为 AP、AP50、mIoU、mAcc。
  • 关键数值（对比）：GenReal-City 上 FVD 979.69、CLIP-T 0.3007、NDE 0.0243、VLM-BT 0.2783；GenReal-CARLA 上 FVD 599.71、CLIP-T 0.2949、NDE 0.0324、VLM-BT 0.2346；效率为 13.67 GB 显存、0.598 FPS。下游：检测 AP50 由原始 CARLA 渲染训练的 35.1 提升至 40.6（AP 16.7→19.4），分割 mIoU 由 32.4 提升至 40.8（mAcc 42.3→50.2）。
  • 对比方法：DiffusionRenderer、TC-Light、Cosmos-Transfer 2.5（边控制变体）；所有方法使用相同测试片段与输出分辨率，文本条件方法使用相同提示，DiffusionRenderer 无文本条件。Ours 在两个测试集上取得最佳 FVD 与 VLM-BT，同时保持有竞争力的 CLIP-T 与 NDE。
  • 消融结果：仅 Basecolor（FVD 669.41、NDE 0.0410、VLM-BT 0.0557）、仅 Depth（812.12、0.0602、−0.1499）、仅 Edge（775.24、0.0401、−0.0986）、单阶段（653.45、0.0347、0.1088）、两阶段但不冻结（730.49、0.0387、−0.0328）、完整模型（599.71、0.0324、0.1168）；完整模型取得最佳 FVD、NDE、VLM-BT。
  • 评估条件：全部为离线视频生成评估与离线感知训练/评测（在真实基准上直接测试），属于仿真数据生成与跨域迁移实验；原文未报告闭环规划评测或实车在线实验。
