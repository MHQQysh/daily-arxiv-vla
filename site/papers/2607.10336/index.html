PrismAD: Decoupled Planning via Semantic Mixture-of-Planners for End-to-End Autonomous Driving

Card 02 论文概述

论文概述

  • 该论文解决端到端自动驾驶中的规划问题。
  • 现有规划器通常将异构场景 token 聚合到一个耦合的表示空间中，导致单个规划分支被迫同时建模智能体交互、道路几何和驾驶意图，从而削弱因子特定推理并模糊不同规划线索的贡献。
  • 论文提出 PrismAD，一个基于语义混合规划器（Semantic Mixture-of-Planners）的解耦端到端自动驾驶框架。
  • 应用场景涵盖标准开环轨迹预测、安全关键场景的闭环规划评估以及转弯场景的规划鲁棒性评估。
Card 03 核心贡献

核心贡献

  • 提出语义 token 分区策略，将场景 token 显式解耦为交互（interaction）、几何（geometry）和意图（intent）三组，实现因子感知的规划表示学习。
  • 设计语义混合规划器，每个专家都是一个完整的运动规划分支，而非插入中间网络层的通用专家，使专业化发生在规划层面而非低层特征变换阶段。
  • 引入语义感知路由器，为运动预测和自车规划生成独立的专家权重，支持自适应融合和稀疏专家激活，并通过带噪声门控的稀疏 top-K 激活提升路由鲁棒性并减少不必要的专家计算。
  • 在 nuScenes、NeuroNCAP 和 Turning-nuScenes 三个基准上验证 PrismAD 能一致地提升强规划基线（SparseDrive 和 DiffusionDrive）的开环准确率、闭环安全性和转弯场景鲁棒性。
Card 04 方法描述

方法描述

  • 所属模块：端到端自动驾驶中的规划模块（decoupled planning）。
  • 输入传感器：仅使用多视角相机图像作为视觉输入，配合导航指令信息。
  • 场景表示：稀疏场景 token，划分为交互 token（来自高置信度动态目标 query）、几何 token（来自地图元素 query）和意图 token（来自指令嵌入和自车状态 token），每个组与自车 token 拼接。
  • 模型结构：基于 SparseDrive 或 DiffusionDrive 框架；包含感知主干、语义 token 分区、三个独立参数的规划专家（交互专家、几何专家、意图专家）和语义感知路由器。每个专家包含时间注意力、分支内 token 交互、前馈层及运动与规划解码器；专家间不进行交叉专家注意力，防止语义泄漏。
  • 关键技术：语义 token 分区；解耦专家表示学习（每个专家学习因子级规划表示）；语义感知路由器（以自车查询和场景 token 估计专家重要性，为运动和规划产生独立路由权重）；带噪声门控的稀疏 top-K 激活（交互专家始终激活，几何和意图专家按得分选择）；采用三阶段训练策略（基础端到端训练 → 专家独立训练 → 冻结专家仅训练路由器）。
Card 05 数据集与资源

数据集与资源

  • 数据集：nuScenes 验证集（大规模真实世界驾驶数据集，1000 个场景，每个约 20 秒）；NeuroNCAP 闭环基准（从 nuScenes 日志构建安全关键闭环节景，含 stationary、frontal、side 三类碰撞场景）；Turning-nuScenes（由 nuScenes 验证集转弯样本构建，17 个场景，680 个样本）。

Card 06 评估与结果

评估与结果

  • 评估基准：nuScenes 验证集（开环规划）、NeuroNCAP（闭环安全）、Turning-nuScenes（开环转弯规划）。
  • 评估指标：开环采用平均 L2 位移误差和碰撞率；闭环采用 NeuroNCAP 分数和碰撞率，按场景类型分别报告并给出平均值。
  • 关键数值：

- nuScenes 开环：PrismAD-SparseDrive 平均 L2 从 0.61m 降至 0.59m，碰撞率从 0.08% 降至 0.07%；PrismAD-DiffusionDrive 平均 L2 从 0.57m 降至 0.55m，碰撞率从 0.08% 降至 0.04%。

- NeuroNCAP 闭环：PrismAD-SparseDrive 平均分从 0.92 升至 1.83（相对提升 98.9%），平均碰撞率从 93.9% 降至 82.0%（相对降低 12.7%）；PrismAD-DiffusionDrive 平均分从 3.00 升至 3.28（相对提升 9.3%），碰撞率从 51.9% 降至 44.1%（相对降低 15.0%）。

- Turning-nuScenes：PrismAD-SparseDrive 平均 L2 从 0.86m 降至 0.71m，碰撞率从 0.40% 降至 0.07%；PrismAD-DiffusionDrive 平均 L2 从 0.62m 降至 0.59m，碰撞率从 0.06% 降至 0.01%。

- 消融实验：三专家全用时碰撞率最低（0.042%）；噪声门控融合优于均匀融合（碰撞率 0.04% vs 0.12%）；Top-2 稀疏激活在效率与质量间取得较好权衡（L2 0.55m、碰撞率 0.05%、FPS 6.0）。

  • 对比方法：VAD、UniAD、GenAD、MomAD、UncAD、BridgeAD、BEV-Planner、CausalVAD、FlowAD、SparseDrive、DiffusionDrive、Drive-WM、LAW、OccWorld、ORION、OmniDrive、UniDriveVLA、Impromptu-VLA、Reasoning-VLA 等。
  • 条件：开环评估在 nuScenes 和 Turning-nuScenes 上进行；闭环评估在 NeuroNCAP 仿真基准上进行；推理速度（FPS）在 NVIDIA Tesla A100 GPU 上测量。
