Card 03 核心贡献

核心贡献

  • 提出 VFlash，一种面向物理 AI 的通用解码框架，同时支持文本（如子任务规划）与多种视觉基元，包括边界框、变长轨迹和稠密 3D 点运动预测。
  • 提出 Flash Primitive Decoding（FPD）：利用视觉基元的已知结构（类型、维度、长度）将整个基元对齐为一个预测块，通过轻量扩散 drafter 一次前向并行预测全部坐标。
  • 研究发现轻量扩散 drafter 在视觉规划的空间精度上可以超过其自回归目标模型，同时解码速度显著更快。
  • 训练时使用标注基元坐标而非目标模型续写作为监督信号，优化空间精度而非 token 级一致；推理时直接接受结构合法的基元（保留文本的验证式推测解码）。
  • 在 2D/3D 机器人轨迹任务中相较自回归解码持续降低预测误差；下游 MolmoSpaces 操作任务中，以 VFlash 规划为条件的 world action model 四套任务平均成功率为 70.2%，基线为 62.6%。
Card 04 方法描述

方法描述

  • 所属模块：VLM 的视觉规划解码阶段，以推测解码和 DFlash 块扩散 drafter 为基础，替换其中的 token 级验证接受规则。
  • 输入传感器：视觉观测与任务指令（图像由原生分辨率 MoonViT 编码）；原文未报告具体传感器配置清单。
  • 场景表示：视觉基元由 schema 定义类型、坐标维度与范围；布局包括 <box> u1 v1 u2 v2 </>、<2D> (u v)×P </> <3D> (x y z)×P </>、<Dense> t1 t2 [k (s d1…d5)×3]×P </>；每个块以起始 token a0 开始，后接 B(s)−1 个 mask token。
  • 模型结构：定制具身 VLM 由 Qwen3-4B、MoonViT 编码器和 MLP connector 组成；冻结目标 VLM，训练五层非因果轻量 drafter，将目标层特征融合后作为各 drafter 层的 key/value 注入。
  • 关键技术：

- 边界对齐（Boundary alignment）：每个 draft block 覆盖一个完整基元，由 tool call 声明变长预测规模；

- 位置对齐（Position alignment）：每个位置角色（航点、轴、分隔符）解码前已知，支持逐位置约束；

- 坐标表示：基座模型每个坐标使用 1,001 个特殊 token 之一；文本 token 化目标采用符号加五位数字的固定宽度网格，再渲染回目标文本格式；

- 训练损失：对块内位置使用均匀权重的加权交叉熵，标签来自标注坐标或渲染网格；

- 推理：16 位置 DFlash 块运行至接受基元起始 token，随后一次前向草拟长度 B(s) 的完整块；逐位置约束和跨位置规则仅作用于已计算 logits；接受测试 As 为 schema 校验器，边界框另加 LocateAnything 的空间置信度守卫；被接受基元无需 token 级一致即提交，一次目标前向更新缓存与上下文特征；文本仍走验证式推测解码。

  • 原文未报告：模型参数量细节（除五层 drafter 与 4B 目标外）、传感器硬件规格、显存占用等。

Card 06 评估与结果

评估与结果

  • 评估基准与指标：

- 2D 轨迹：ShareRobot-Bench、VABench-V，指标 DFD、HD、RMSE（归一化图像坐标，越低越好）；

- 边界框：COCO、Dense200，指标 F1@IoU（Mean、0.50、0.95）与 boxes per second（BPS）；

- 3D 机器人轨迹：InternA1、AgiBot、MolmoBot，指标 ADE、FDE（米）与 SR@5、SR@10（5 cm/10 cm 内航点比例）；

- 稠密运动：PointMotionBench，指标 ADE、FDE、PWT；

- 下游操作：MolmoSpaces 四套任务（Pick、P&P、Open、Close）成功率；

- 延迟：单 rollout 生成吞吐/时延。

  • 关键结果：

- 2D 轨迹：VFlash 相对其 AR 目标降低全部六项误差，HD 降低约 7%，DFD 与 RMSE 降低 3–6%；VABench-V 上相较最佳先前模型 LoHo-Manip 各误差降低约 40%；ShareRobot-Bench 上仅次于 RoboBrain-2.0。

- 边界框：VFlash（AR fallback）平均 F1 与 AR 持平，解码快 2.6–2.8×；IoU 0.50 下 F1 更高（Dense200 61.78 vs 60.10；COCO 47.79 vs 41.32），IoU 0.95 下更低；无 fallback 时 Dense200 平均 F1 下降约 20 点。

- 3D 轨迹：三种目标变体、三个数据集上四项指标全部改善；3D-only 目标 ADE 降低 18–49%，2D+3D 目标 ADE 降低 28–61%；AgiBot 上 SR@5 从 50% 升至 73%（3D-only）及从 40% 升至 74%（2D+3D）；腕部相机训练使 ADE 再降 3–12%，评估仍只用主相机。

- 稠密运动：DAVIS ADE/FDE 降低 27%/19%，HOT3D FDE 降低 8%；HOT3D 与 WorldTrack 的 ADE 排第二（次于 AR、优于 flow-matching 变体）；WorldTrack FDE 增加 15%，三个数据集 PWT 低 7–12%；单 rollout 生成约 25× 更快。

- 下游操作：MolmoSpaces 平均成功率 70.2% vs 基线 62.6%；VLM 在所有配置中冻结，对比中动作模型架构保持一致。

- 延迟：下游机器人操作流水线在 Jetson Thor 与 DGX Spark 上推理时延降低约 80%。

  • 评估条件：以上主要为开环预测评估（2D/3D 轨迹、边界框、稠密运动）与下游闭环/策略成功率评估（MolmoSpaces）；原文可见内容未报告实车道路测试结果，NAVSIM/Waymo 的具体闭环或开环数值未在提供内容中给出。
