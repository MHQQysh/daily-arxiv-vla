Card 02 论文概述

论文概述

  • 论文针对端到端自动驾驶中的轨迹规划任务，研究视觉-语言-动作（VLA）世界模型应基于何种“世界状态”进行推理。

Card 03 核心贡献

核心贡献

  • 揭示现有世界 VLA 模型的瓶颈来自大量用于未来生成、但与规划无关的视觉 token，从而引出紧凑、结构化、面向规划的潜在世界建模设计。
  • 提出面向规划的“以智能体为中心的潜在状态”，将驾驶场景表示为随时间演化、并锚定 3D 几何、运动、语义与交互上下文的智能体。
  • 提出 AgentWorld：用以离散 agent token（<agent_i>）实例化该世界状态的世界 VLA 模型，token 同时用于推理与轨迹规划。
  • 通过显式几何锚定、面向推理的监督微调（SFT）和面向智能体的强化学习（GRPO）三阶段学习 agent token。
  • 在开环与闭环基准上报告了规划性能提升与更可解释的世界状态，并通过消融与干预分析支持 agent 中心表示的有效性。
Card 04 方法描述

方法描述

  • 所属模块：端到端自动驾驶 VLA 世界模型，包含世界状态构建与策略学习两部分。
  • 输入传感器：多视角图像作为视觉输入；自车状态（ego-status）与导航目标；原文未报告激光雷达等其它传感器输入。
  • 场景表示：在世界状态中使用固定数量 N 个特殊 agent token 组成 𝒯_agent={⟨agent_1⟩,…,⟨agent_N⟩}，以 MLLM 在这些位置的隐状态 h_t^i 构成 agent-centric 潜在状态 S_t^agent；每个槽位可动态锚定到周围交通参与者或“无目标”状态。
  • 模型结构：以 Qwen2-VL 与 Qwen2.5-VL 系列初始化 MLLM；agent token 由特殊 token 的可学习嵌入初始化（不引入独立 object query 集）；多模态路由锚定模块将查询分别路由到 4D 几何分支（离线 VGGT 风格特征）和 2D 视觉分支（MLLM 视觉编码器），各分支用 token 级门控调制后做交叉注意力，再融合并投影回 MLLM 隐空间插入对应 token 位置；训练时用轻量 agent head 预测类别/存在性、3D bbox 与未来轨迹，并以 DETR 式匈牙利匹配监督。
  • 关键技术：物理锚定目标；策略输出结构化响应 y=(ξ,a,τ)，即 <think> 简洁理由、<action> 高层动作、<answer> 未来自车航点；以 <perception> 字段暴露 agent token；面向推理的 SFT 使用标准自回归目标；面向智能体的 RL 使用 GRPO，复合奖励覆盖格式、感知、动作、轨迹与交互上下文（惩罚碰撞、间距不足、短 TTC），RL 仅更新 MLLM 策略，辅助 agent head 作为冻结奖励生成器。
  • 推理阶段不需要辅助锚定模块与 agent head；原文未报告具体网络层数、隐藏维度等超参数数值。

Card 06 评估与结果

评估与结果

  • 评估基准：nuScenes 开环（ST-P3 与 UniAD 两套协议）与 Bench2Drive 闭环；另有 nuScenes 感知与元动作评估。
  • 评估指标：L2 误差（1s/2s/3s 及平均）、碰撞率（%）、3D 检测 mAP 与 NDS、横向/纵向动作 F1、闭环 Driving Score、Success Rate、Efficiency、Comfortness。
  • 关键数值（开环，表 1）：AgentWorld 平均 L2 为 0.27 m（ST-P3 协议）、0.45 m（UniAD 协议），平均碰撞率 0.08%（ST-P3）、0.12%（UniAD）；带自车状态版本（AgentWorld*）平均 L2 为 0.25 m 与 0.40 m，平均碰撞率 0.07% 与 0.11%。
  • 关键数值（感知，表 2）：mAP 0.318、NDS 0.416，优于 CenterNet、FCOS3D、DETR3D、PGD。
  • 关键数值（元动作，表 3）：横向 forward 95.14、left 77.63、right 78.41；纵向 keep 63.85、acc. 84.17、dec. 82.93、stop 84.56，多数类别优于 VLA-World 与 Qwen2-VL-2B 基线。

  • 对比方法：ELM、FeD、OccWorld、Doe-1、RDA-Driver、EMMA、OmniDrive、FSDrive、VLA-World（开环与感知/动作）；AD-MLP、UniAD-Base、VAD、TCP-traj、DriveAdapter、Orion、AutoVLA（闭环）。
