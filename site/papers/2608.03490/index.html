Card 02 论文概述

论文概述

  • 解决自动驾驶与机器人导航中 LiDAR 三维物体检测任务，面向车载嵌入式环境的实时感知需求。
  • 核心研究问题是：如何在资源受限平台上实现计算开销与检测精度之间的平衡，即如何构建高精度的教师模型并通过知识蒸馏压缩得到轻量级学生模型。
Card 03 核心贡献

核心贡献

  • 提出多分支 Mamba 3D 骨干网络作为教师模型，通过浅层与深层双分支融合增强多尺度稀疏体素特征表示。
  • 提出 Mamba 自适应蒸馏策略，结合检测头输出蒸馏与基于体素空间的框感知潜在状态对齐，实现对象级特征知识迁移。
  • 设计基于 Mamba 编码器的特征投影模块，将学生特征映射到教师特征空间，解决师生模型间特征维度不一致问题。
  • 改进 CPR 评估指标，以实测推理延迟替代激活数量，并采用 mAP 作为精度指标，用于指导学生模型的剪枝选择。
  • 在公开数据集 nuScenes 与自采真实世界数据集 Livox-Legged 上验证，表明轻量学生模型在显著降低计算开销的同时保持竞争力精度。
Card 04 方法描述

方法描述

  • 所属模块：3D 物体检测（背骨提取、BEV 编码、检测头输出）。
  • 输入传感器：LiDAR 点云。
  • 场景表示：稀疏体素（voxel）表示，采用 3D 稀疏窗口划分策略组织体素序列。
  • 模型结构：教师模型由多分支 Mamba 3D 背骨（MBB 结构）、BEV 背骨和检测头构成；学生模型通过对教师网络各模块的宽度（通道数）和深度（层数）按比例剪枝得到；特征投影模块采用轻量 Mamba 编码器（对比实验中还考察 MLP 投影器、Transformer 投影器、1×1 卷积投影器等替代方案）。
  • 关键技术：

- Mamba 层基于选择性状态空间模型，体素特征沿 X、Y 两个正交方向进行序列化处理与线性循环状态更新。

- 多分支块（MBB）包含浅层 Mamba 分支（标准 Mamba 层+层归一化+3D 卷积）与深层 Mamba 分支（引入体素合并与体素扩展操作，来自 LION），两分支输出经残差连接融合后送入 BEV 背骨。

- Mamba 自适应蒸馏：检测头蒸馏（分类、回归、热图输出按最高 IoU 匹配对齐）；潜在空间蒸馏仅对地面真值 3D 框内的共有体素索引特征计算 L2 损失，通过投影函数将学生特征映射至教师特征空间。

- 总损失函数为真值监督损失加 Mamba 蒸馏损失（权重 α，设为 1.0）与检测头蒸馏损失（权重 β，设为 0.5）。

Card 05 数据集与资源

数据集与资源

  • 数据集：nuScenes LiDAR-only 赛道，1,000 场景，约 28,000 个 LiDAR 关键帧，10 个目标类别，训练 700 场景、验证 150 场景。
  • 真实世界数据集：Livox-Legged（自采，多台 Livox Mid-360 LiDAR 安装在腿式机器人上，空间标定后融合为统一表示），2,000 训练场景、500 测试场景，包含行人、汽车、摩托车三类，训练与测试共含行人 13,933 实例、汽车 3,971 实例、摩托车 1,617 实例。
  • 仿真器：原文未报告。
  • 模型规模：教师模型参数 23.52M，激活 339.2M；学生模型参数范围为 1.74M（student-f）至 11.60M（student-a），其中 student-h 4.11M 参数、student-d 11.04M 参数。
  • 训练资源：4 块 NVIDIA L40 GPU；推理延迟测量平台为单块 NVIDIA A4000 GPU；嵌入式平台为 NVIDIA Jetson Orin NX。
  • 框架与工具：OpenPCDet 框架，PyTorch 深度学习后端；BEV 背骨与检测头设计沿用 DSVT。
  • 实车平台：腿式巡逻机器人（安装 Livox Mid-360 多 LiDAR），用于真实场景部署验证。
  • 训练配置：师生模型均训练 36 epochs，批大小 16，点云范围、体素化网格、数据增强、优化器与学习率调度遵循 DSVT 配置；训练采用固定随机种子。
Card 06 评估与结果

评估与结果

  • 公开基准：nuScenes 验证集。
  • 评估指标：mAP、NDS、mATE、mASE、mAOE、mAVE、mAAE；Livox-Legged 测试集上报告 mAP 与推理延迟。
  • 关键数值（nuScenes 全量训练、验证集 mAP）：

- 教师模型（多分支 Mamba）：mAP 68.2%，参数 23.52M，延迟 199 ms（A4000 GPU）。

- Student-d：mAP 67.9%，参数 11.04M，延迟 108 ms。

- Student-g：mAP 67.1%，参数 10.50M，延迟 97 ms。

- Student-h：mAP 65.6%，参数 4.11M，延迟 71 ms。

  • 关键数值（20% 训练数据、student-d 对比）：

- 学生模型无 KD：mAP 58.54，NDS 65.25。

- 学生模型 + FitNet：mAP 60.93，NDS 67.30；+ Mimic：mAP 60.27，NDS 66.83；+ FG：mAP 61.00，NDS 67.36；+ SparseKD：mAP 61.07，NDS 67.54；+ PointDistiller：mAP 59.84，NDS 66.32；+ itKD：mAP 60.35，NDS 66.92。

- 学生模型 + 所提方法（Ours）：mAP 63.00，NDS 68.59，均优于其他 KD 方法且超过无 KD 教师基线。

  • 剪枝结果（20% 训练数据）：

- Student-a：mAP 56.70，CPR 0.55；Student-b：mAP 54.76，CPR 0.53；Student-c：mAP 53.73，CPR 0.62；Student-d：mAP 58.54，CPR 0.72；Student-e：mAP 54.50，CPR 0.70；Student-f：mAP 50.73，CPR 0.69；Student-g：mAP 57.48，CPR 0.73；Student-h：mAP 54.56，CPR 0.72。

  • 消融研究（student-d，20% 训练数据）：

- 无 KD：mAP 58.54；全量体素 KD（无框感知）：mAP 59.50，NDS 66.63；框感知 KD + 1×1 卷积投影器：mAP 61.85，NDS 67.23；+ MLP：mAP 62.28，NDS 68.25；+ Transformer：mAP 61.40，NDS 67.65；+ Mamba 编码器（最终方案）：mAP 63.00，NDS 68.59。

- 教师骨干结构消融（全量训练）：浅层分支单独：mAP 67.39，NDS 71.78；深层分支单独：mAP 67.52，NDS 71.96；浅层+深层：mAP 68.22，NDS 72.13。
