Card 03 核心贡献

核心贡献

  • 提出一个快速、特征丰富的对象级交通仿真器，基于可配置的 C 引擎，支持 CPU 仿真与 GPU 策略推断间的零拷贝数据通路，吞吐量显著高于现有对象级仿真器（单个服务器级 GPU 上达 1.3M agent-steps/s，8-GPU 节点上达 2.8M）。
  • 提出程序化场景生成器，将真实地图几何与随机化初始化、目标采样、智能体密度与尺寸随机化、规则型道路使用者（如施工区、事故车辆、行人）以及三种信号控制器结合，使单个地图产生近似无限的训练场景。
  • 提出鲁棒的自博弈训练配方：采用显著性优先采样、V-trace off-policy 修正、PopArt 值归一化、奖励与运动学域随机化、目标丢弃（goal dropout）以及种群博弈（population play），在零人类演示条件下从随机初始化权重学习。
  • 验证了同一训练栈同时适用于规划器与仿真智能体：一个检查点在 nuPlan val14 与 InterPlan 交互式长尾基准上均达到领先水平，并在 WOSAC 上优于其他无演示方法。
  • 训练出的策略具有跨城市与跨数据集的零样本泛化能力，并涌现出无显式监督的左舵交通驾驶行为。
Card 04 方法描述

方法描述

  • 所属模块：仿真器（对象级）、程序化场景生成器、强化学习训练栈。
  • 输入传感器：原文未报告（对象级仿真，直接基于结构化状态，不涉及原始传感器输入）。
  • 场景表示：车道拓扑图、道路几何、信号灯与停止线、智能体状态（位置、速度、朝向、尺寸、类型）。
  • 模型结构：

- 规划器：紧凑型 MLP，约 3.5M 参数，包含 ego MLP 与对道路、伙伴、交通集合的置换不变 Deep Sets 编码器，后接三层 1024 单元共享 MLP，用于 actor 和 value head。

- 仿真智能体：约 6.7M 参数，采用分离的按类型动作头（车辆 jerk 网格、行人 unicycle 网格、骑行者紧凑自行车网格）。

  • 关键技术：

- CPU/GPU 分工：C 引擎在 CPU 运行仿真，PyTorch 在 GPU 运行策略推断与学习，基于 PufferLib。

- 零拷贝数据路径：16 位观测、按实际受控智能体数尺寸化缓冲区、NUMA 感知编排。

- 可组合仿真基板：每个智能体类别拥有独立动力学模型（行人 unicycle、自行车 bicycle、卡车带轮胎侧偏力的自行车模型），车辆按 jerk 控制。

- 交通规则执行：碰撞与偏离道路通过分离轴测试与路缘边界检测；车道方向合规通过航向残差衡量；信号灯与停止线基于几何通行测试，红灯违规为边沿触发判定，停止线需低于速度阈值并保持停留时间。

- 场景初始化：log、random、hybrid 三种模式，随机模式下采用拒绝采样进行程序化放置，确保无碰撞且合规。

- 目标分配：沿车道拓扑图前向行走采样目标，支持目标丢弃概率。

- 非玩家角色：反应式车辆（IDM 与 PDM-Closed 风格闭路规划器）、静态角色（停放车辆、事故车辆簇、施工区、静态障碍物）、行人（ORCA 避碰、交叉口过街与中途乱穿）。

- 信号控制：NEMA 双环八相位控制器、Christmas 控制器（默认，每停止线独立循环）、round-robin 控制器。

- 训练：PPO 与 GAE，配合显著性优先采样（按优势绝对值加权）、V-trace 修正、PopArt 归一化、奖励与运动学系数域随机化、目标丢弃（默认 0.3 车辆）、种群博弈（奖励随机化与规则型 NPC 混合）。

- 分布式训练：数据并行，跨 rank 同步归一化统计量。

Card 05 数据集与资源

数据集与资源

  • 数据集：Waymo Open Motion Dataset（WOMD，约 576K 场景，训练分割约 487K）、nuPlan（约 262K 场景，四城市：拉斯维加斯、匹兹堡、新加坡、波士顿）、CARLA（五个合成小镇）。
  • 仿真器：TerraZero 自身（程序化对象级仿真器）。
  • 模型规模：规划器约 3.5M 参数；仿真智能体约 6.7M 参数。
  • 训练资源：规划器在 16 张 NVIDIA A100 80GB GPU 上以 bf16 混合精度分布式训练；仿真智能体在 32 张 GPU 上训练。
