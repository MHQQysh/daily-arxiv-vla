Card 03 核心贡献

核心贡献

  • 将失效预判形式化为对冻结驾驶策略的轻量级监控，通过其 actor、ego、map 结构化表征接口进行读取。
  • 提出 SRP，将每个来源的独立线性风险方向、基数归一化的 log-mean-exp 证据池化，以及按事件类型的辅助监督整合到单一通用告警监控器中。
  • 使用事件窗口监督将读出结果与未来硬失效关联，并以事件类型辅助头联合训练各来源风险方向，同时在线告警只使用单一通用分数。
  • 在 DriveTransformer、UniAD、VAD 三种策略和多种评估设置上评估 SRP，结果显示相较所评估的运行时监控基线，帧级区分能力和告警提前量均有提升，并报告了探针在新路线上的泛化能力。
Card 04 方法描述

方法描述

  • 所属模块：附加在冻结端到端驾驶策略表征接口之上的轻量级运行时监控/告警读出模块；在线告警仅使用单一通用分数，不修改驾驶策略。
  • 输入传感器：原文未报告具体传感器输入类型；SRP 的输入是策略内部导出的结构化表征，而非原始传感器数据。
  • 场景表示：将导出表征按来源组织为 actor 证据 A_t、ego 证据 E_t、map 证据 M_t 三个无序元素集合，元素维度分别为 d_a、d_e、d_m；该记法描述来源角色而非特定张量名。
  • 模型结构：每个来源在各自表征空间学习一个线性风险方向（w_s, b_s），对元素计算 logit ℓ = ⟨w_s, x̃⟩ + b_s；来源内使用基数归一化的 log-mean-exp 池化得到 ρ_t^s；通用告警对所有来源元素做基数归一化 log-mean-exp 池化得到 g_t，再经 sigmoid 得 r_t；辅助事件类型头以三个池化来源分数为输入做线性读出，输出各事件类型分数 r_{t,c}。
  • 关键技术：log-mean-exp 池化对元素顺序置换不变，满足均值下界与最大值上界，τ→0⁺ 时趋于 max，重复同一集合不改变归一化分数，从而保持对显著证据的敏感性并降低对 token 数量的依赖；温度 τ 控制读出锐度。
  • 训练监督：由记录到的硬失效构造事件窗口标签（通用标签与三类事件标签），目标事件为碰撞、闯红灯、停车标志违规和路线偏离，辅助监督将其分为 dynamic collision、static collision、rule violation 三类；损失为加权二元交叉熵，含通用项与按事件类型平均的辅助项，λ 控制辅助项强度。
  • 在线推理：复用保存的特征统计与探针参数，将 r_t 与验证集上选出的通用阈值比较发出告警；来源分数和辅助分数仅作为可选诊断输出。

Card 06 评估与结果

评估与结果

  • 评估基准：Bench2Drive 测试路线，闭环仿真条件；默认训练与评估窗口为 40 个仿真步（2 秒，20 Hz）。
  • 评估指标：帧级 PR-AUC、ROC-AUC、帧召回 R_F、事件召回 R_E、惩罚提前时间 pLead（秒）；@5%FPR 表示在评估划分上选择使帧召回最大且帧级 FPR 不超过 5% 的阈值；部署阈值另在验证集上选取。
  • 对比方法：Temporal Consistency（TC，受 MomAD 启发）、Task-Aware Risk（TAR）、Task-Relevant Failure Detection（TRFD）。
  • 主要结果（2 秒窗口，Bench2Drive 测试路线）：

- DriveTransformer：SRP 的 PR-AUC 0.261、ROC-AUC 0.833、R_F 0.300、R_E 0.497、pLead 0.701 s；TC 为 0.127/0.715/0.145/0.505/0.633 s；TAR 为 0.088/0.570/0.060/0.431/0.532 s；TRFD 为 0.080/0.496/0.046/0.320/0.337 s。

- UniAD：SRP 为 PR-AUC 0.339、ROC-AUC 0.868、R_F 0.439、R_E 0.725、pLead 1.124 s，均为该模型下最优；TC 为 0.167/0.751/0.175/0.573/0.768 s。

- VAD：SRP 为 PR-AUC 0.320、ROC-AUC 0.853、R_F 0.559、R_E 0.713、pLead 1.229 s；TAR 的 R_E 最高（0.739）；TC 为 0.131/0.810/0.280/0.723/1.159 s。

- 总体：SRP 在三种策略上均取得最高的 PR-AUC、ROC-AUC 和 R_F，并在三种策略上均取得最高 pLead；事件召回仅在 UniAD 上最高。

  • 窗口敏感性：固定训练窗口 40 步、评估窗口改为 20/40/60 步时，扩大评估窗口提高 PR-AUC 与 pLead、降低 ROC-AUC，帧召回变化不大或下降；例如 DriveTransformer 从 1 秒到 3 秒，PR-AUC 由 0.176 升至 0.315，pLead 由 0.376 s 升至 0.984 s。改变训练窗口的效果随策略和指标不同而异。
  • 事件类型诊断（辅助头，2 秒窗口）：不同策略下召回最高的事件类型不同（DriveTransformer 为 rule violation，UniAD 与 VAD 为 static collision）；VAD 上 static collision 的 R_E 为 0.867，rule violation 的 pLead 最长（1.671 s）。
  • 消融（重新训练的 DriveTransformer 探针，表中可读部分）：No actor 变体 PR-AUC 0.250、ROC-AUC 0.813、R_F 0.291、R_E 0.506、pLead 0.712 s；No ego 变体 0.229/0.784/0.261/0.310/0.504 s；其余消融与泛化、部署开销结果在提供的原文中未完整给出。
  • 定性分析：SRP 在闯红灯、车辆碰撞和护栏碰撞等案例中于失效前提升通用风险分数；图 3 显示三种策略下正事件窗口帧的 logit 分布整体向高值偏移。
