ZIL: Zero-shot Image-to-LiDAR Registration

2026-09-19 · 原文 · 翻译 · 2609.22716

论文研究图像到 LiDAR 配准（Image-to-LiDAR registration）任务，即在给定查询图像和 LiDAR 点云的条件下估计相机在点云坐标系中的 6-DoF 位姿。 应用场景包括自动驾驶、机器人导航和混合现实等。 论文针对现有 SOTA 方法的两个问题：一是多数假设图像与点云同帧采集，难以处理远距离帧的非同步输入；二是依赖特定域训练，难以泛化到未见场景。 论文提出 ZIL，定位为首个面向零样本非同步图像到 LiDAR 配准的基础模型，目标是在不微调、不适配的情况下跨未见室外相机–LiDAR 系统完成配准。

Card 03 核心贡献

核心贡献

  • 提出 ZIL，首个面向图像到 LiDAR 配准的基础模型，具备强零样本泛化能力，可用于非同步图像–点云配准。
  • 设计双编码器–双头 Transformer 架构：Vision Transformer 编码图像，Point Transformer V3 编码点云，除回归相机位姿外，还通过代理任务预测图像像素在 LiDAR 坐标系中的 3D 坐标，在不增加标注的情况下显著提升位姿精度。
  • 发现朴素混合数据训练无法带来零样本泛化，提出相机内参归一化与 LiDAR 垂直轴原点归一化，以统一跨数据集的几何约定。
  • 在 7 个公开数据集、140 万 LiDAR 帧上训练单一模型，在 5 个域内与零样本基准上持续显著超越此前 SOTA，最多降低平移误差 87%、旋转误差 76%。
  • 首次在全部 5 个评估数据集上达到亚米级精度。
Card 04 方法描述

方法描述

  • 所属模块：图像到 LiDAR 跨模态配准模块；输入为图像与 LiDAR 点云，输出相机到 LiDAR 的相对位姿。
  • 输入传感器：相机图像与 LiDAR 点云；论文未报告具体实车传感器型号。
  • 场景表示：图像经 Vision Transformer 编码为 patch token；点云经 Point Transformer V3 编码为稀疏 3D 点特征及其 3D 坐标；两类 token 拼接后由全局注意力块处理。
  • 模型结构：编码器–解码器 Transformer，双编码器（Vision Transformer、Point Transformer V3）与双头（位姿头、逐像素 3D 坐标 DPT 头）。引入模态特定可学习 token（cam/lidar）与 register token；图像 token 使用 2D RoPE，点 token 使用归一化坐标构造的 3D RoPE 及稀疏卷积位置嵌入。位姿 token 由最终层 cam token 与 lidar token 相加构成，经 4 层额外自注意力与线性层回归 7 维位姿（3 维平移 + 4 维旋转四元数）。
  • 关键技术：相机内参归一化（统一到 518×280 分辨率、水平视场角 45.5°、f_x=f_y=617.49 的规范针孔相机）；LiDAR Z 轴归一化（将最低点 z 坐标平移至零，并对真值平移与点图目标施加同样平移）。
  • 代理任务：将点 token 全局平均后加到每个图像 patch token 上，由 DPT 头聚合多解码层特征预测 LiDAR 坐标系下的逐像素 3D 坐标；真值点图来自训练语料中查询时刻已有的 LiDAR 扫描，无需新数据采集或人工标注。
  • 训练损失：总损失为位姿损失与点损失加权和（λ_pose=5，λ_point=1）；位姿损失为平移与旋转四元数的 ℓ1 损失之和；点损失为有效像素集合 Ω 上预测点图与真值点图的 L2 损失。
  • 训练细节：冻结两个模态编码器；点编码器输出下采样至每场景 2048 个 token；梯度累积 5 个 micro-batch；共 128K 次迭代。
  • 原文未报告：具体网络参数量、推理时延、实车部署平台信息未在原文中报告。

Card 06 评估与结果

评估与结果

  • 评估基准：域内评估为 KITTI 与 nuScenes；零样本评估为 KITTI-360、Lyft、PandaSet。
  • 评估协议：按先前工作协议，在 ±10 m 范围内以固定种子随机采样非同步图像–点云对。
  • 评估指标：平均相对平移误差（RTE）、平均相对旋转误差（RRE）、注册召回率（RR，RTE 与 RRE 同时小于 (2 m, 5°) 视为成功）。
  • 零样本结果（KITTI-360 / Lyft / PandaSet）：ZIL 注册召回率分别为 96.9%、98.3%、98.6%；RTE 分别为 0.53±0.81 m、0.63±0.60 m、0.67±0.40 m；RRE 分别为 1.93°±8.76°、0.77°±0.38°、1.60°±0.36°。
  • 零样本对比方法：DeepI2P、CorrI2P、VP2P、CoFiI2P、CoFiI2P-cross、I2PReg、I2PReg-cross；多数基线在零样本数据上严重退化，同帧训练方法注册召回率低于 20%，KITTI-360 上多个方法出现灾难性失败（零召回、平均 RTE 超 1000 m，表中以“–”表示）。
  • 域内结果（KITTI / nuScenes）：ZIL RTE 为 0.39±0.46 m / 0.57±1.03 m，RRE 为 1.08°±2.95° / 0.88°±2.17°，RR 为 97.5% / 95.8%。相比此前最佳 GraphI2P（各数据集分别训练），ZIL 用单一模型将 KITTI 的 RTE 从 0.68 m 降至 0.39 m，将 nuScenes 的 RRE 从 2.21° 降至 0.88°。
  • 域内对比方法：DeepI2P (2D)、CorrI2P、VP2P、2D-3D Matr、RetrI2P、FreeReg、CoFiI2P、GraphI2P、I2PReg-cross；除 ZIL 与 I2PReg-cross 由本文训练外，其余结果来自 Bie et al. (2025) 在非同步设置下的报告。
  • 消融结果（KITTI-360 / Lyft / PandaSet）：单数据集训练 RR 为 82.0% / 22.5% / 9.2%；朴素混合数据训练 RR 为 14.7% / 24.6% / 18.5%；去掉 K-norm 的 RR 为 37.8% / 7.9% / 53.2%；去掉 Z-shift 的 RR 为 84.6% / 73.4% / 42.1
