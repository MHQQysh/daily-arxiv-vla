Card 02 论文概述

论文概述

  • 论文解决自动驾驶中车道拓扑感知输出的结构不稳定性问题，这些不稳定包括漏检、连接（LCLC）丢失或错误、过检测以及边界标签闪烁。
  • 应用场景为车载实时（10 Hz / 20 ms / 最多 200 条输入车道）自动驾驶感知后处理环节。
  • 研究问题是如何在车载实时约束下，通过帧间跟踪和后处理，稳定感知模型输出的车道段及其相互连接关系（LCLC）。
Card 03 核心贡献

核心贡献

  • 提出 Segment Tracking with Connectivity：将车道段及其连接拓扑（LCLC）作为联合跟踪目标，进行时间序列上的稳定性处理。
  • 提出 Noise-Robust Topology-Aware Refinement：在输入端进行帧内预处理（去重、连接补充），在输出端进行车道选择与拓扑修正，保持道路结构一致性。
  • 提出 Resource-Constrained Real-Time Design：通过早期终止回退和计算效率改进，满足 10 Hz / 20 ms / 最多 200 条输入车道的实时约束。
  • 在同一评估框架下，将感知模型输出与 WASABI 后处理结果进行对比，验证了在检测、几何、属性、拓扑和跨帧稳定性方面的全面提升。
Card 04 方法描述

方法描述

  • 所属模块：感知后处理（post-processing）模块，输入为感知模型的单帧车道拓扑输出（最多 200 条车道段和 40,000 个 LCLC 候选连接）以及自车姿态（delta pose 和 world pose），输出为供下游规划器使用的 NodeEdgeTopology。
  • 输入传感器：原文未报告，但感知模型基于 360 度 BEV 视角的车载传感器。
  • 场景表示：将车道段表示为带几何与语义属性的折线，LCLC 表示车道段之间的连接关系（FromID, ToID）。
  • 模型结构：WASABI 本身不是学习模型，而是一条规则与优化结合的处理管线，包含 ego-motion 补偿、帧内预处理、代价计算与匈牙利算法关联、状态管理（Tentative, Tracking, TemporaryLost, Delete）、LCLC 滑窗多数投票、输出车道选择、拓扑修正与端点 Bézier 平滑，最终转换为 NodeEdgeTopology。

Card 06 评估与结果

评估与结果

  • 评估基准：内部验证数据集（16 条序列），与感知模型原始输出进行对比；评估框架分解为检测（D）、几何（G）、属性（A）、拓扑（T）四个维度，另附基于真值的跨帧稳定性指标。
  • 评估指标：车道段检测 Precision/Recall/F1、中心线及边界横向误差、属性准确率、LCLC 的 Precision/Recall/F1、LCLC 翻转率、边界标签闪烁率。
  • 关键数值：

- 检测 F1：0.345 → 0.412（+0.067，+19.2%）；FP 减少 24.6%（328,459 → 247,639）。

- 中心线横向误差：2.50 m → 0.95 m；边界横向误差：3.21 m → 1.06 m。

- 属性准确率：四项从 0.738/0.782/0.740/0.824 提升至 0.755/0.799/0.757/0.831。

- LCLC F1：0.834 → 0.948（+0.114，+13.6%）；FP 边缘 -70.1%，FN 边缘 -50.6%。

- LCLC 翻转率：0.00365 → 0.00134（-63.3%）；边界标签闪烁率：0.0389 → 0.0271（-30.2%）。

  • 对比方法：感知模型原始输出（baseline）；消融变体包括 w/o Tracking、w/o Refinement、w/o Preprocessing、w/o Output Sel./Corr.、Exact Fréchet。
  • 开环/闭环/仿真/实车条件：全部为开环离线评估（后处理效果对比）；原文未报告闭环或实车测试结果。
