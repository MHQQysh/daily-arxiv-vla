CL3DOD: Understanding the Stability-Plasticity Dilemma in Outdoor Class-Incremental 3D Object Detection

2026-11-02 · 原文 · 翻译 · 2611.03229

研究面向自动驾驶户外场景的类增量 3D 目标检测（class-incremental 3D object detection），输入为 LiDAR 点云。 关注的核心问题是稳定性-可塑性困境（stability-plasticity dilemma）：在仅提供当前任务类别标注、旧类物体仍共现于场景但无标注的情况下，模型如何在保留旧类知识的同时有效学习新类。 指出现有户外类增量 3D 检测研究仅在单一基准上评估（SDCoT++ 在 KITTI、CL2OD 在 nuScenes 且增量设定不同），缺乏跨基准的统一分析。 论文提出跨 KITTI 与 nuScenes 的统一分析，并覆盖两任务与多阶段增量设定。

Card 02 论文概述

论文概述

  • 研究面向自动驾驶户外场景的类增量 3D 目标检测（class-incremental 3D object detection），输入为 LiDAR 点云。

Card 03 核心贡献

核心贡献

  • 提供首个跨多个自动驾驶基准的户外类增量 3D 目标检测统一分析，覆盖两任务与更长增量序列。
  • 联合分析知识保留与新类获取，使用任务级检测性能、Average Forgetting 与 Intransigence Measure，并在两个基准上一致使用后两者。
  • 提出 CL3DOD 框架，结合 Old-Class Supervision、Query-Wise Knowledge Distillation 与 Temporal Consistency Regularization。
  • 实验显示 CL3DOD 相比受控增量基线与已发表先验方法在报告的基准比较中取得更有利的稳定性-可塑性平衡，且在 nuScenes 三任务序列中优势持续。
  • 消融表明恢复的旧类监督是最一致的保留机制，而蒸馏与时间一致性的效果在不同数据集间存在差异。
Card 04 方法描述

方法描述

  • 所属模块：户外 LiDAR 类增量 3D 检测；基础检测器为 Uni3DETR（DETR 风格、仅 LiDAR）。
  • 输入传感器：LiDAR 点云（原文未报告相机等其他传感器）。
  • 场景表示：点云输入 P∈R^{N×d}；Uni3DETR 使用可学习查询与基于最远点采样（FPS）的非可学习查询点，输出解码器查询的分类响应与 3D 框。
  • 问题设定：任务序列 {T1,…,TN}，各任务类别集合互斥；第 t 任务仅提供当前类标注，旧类物体可能无标注共现；同一底层场景可在任务间重叠但仅暴露当前任务标注。
  • 模型结构：学生检测器 f_θt 由上一阶段 f_θ(t-1) 初始化；冻结的上一阶段教师 f_θ(t-1) 提供旧类知识；EMA 教师由学生初始化并按指数移动平均更新。
  • Old-Class Supervision：冻结的上一阶段教师对当前任务点云预测旧类目标，保留置信度超过阈值 γ_conf 的检测，并剔除与当前任务真值 3D IoU 超过 γ_IoU 的冲突预测，得到旧类伪标签，与当前标注合并为 Y^merge，几何增强同步作用于点云与合并标注，再用标准 Uni3DETR 监督目标训练学生。
  • Query-Wise Knowledge Distillation：给学生与上一阶段教师输入相同增强数据并共享 FPS 采样的非可学习查询点以建立查询对应；对第 2 至 L 层解码器分类 logits 取平均，仅在旧类维度 C_old 上做类别维均值中心化，以对齐查询间旧类响应的 RMSE 作为蒸馏损失；仅蒸馏分类响应。
  • Temporal Consistency Regularization：使用 EMA 教师（参数 θ_EMA^(k)=αθ_EMA^(k-1)+(1-α)θ_t^(k)）提供跨优化迭代（非连续 LiDAR 帧）的慢变一致性目标；将 EMA 教师预测按学生输入的几何增强变换到同一坐标系，分别用对称 Chamfer 距离约束目标中心、KL 散度约束类别分布、L1 损失约束 3D 框尺寸，加权求和为一致性损失。
  • 增量训练目标：L_inc = λ_sup·L_sup(Y^merge) + λ_KD·L_KD + λ_cons·L_cons；梯度仅更新学生，上一阶段教师冻结，EMA 教师按公式更新；启用时间一致性时用 EMA 教师评估，而学生 f_θt 用于初始化下一阶段。
  • 原文未报告：各损失权重 λ 的具体取值、伪标签置信度阈值与 IoU 阈值的具体数值、EMA 系数 α 的具体数值（在提供的正文中未给出）。
