Card 03 核心贡献

核心贡献

  • 提出 WAC 模型，联合学习未来预测与后果评估，用于反事实动作推理，并利用 critic 监督塑造面向决策的预测表征。
  • 设计带非对称注意力的循环 transition–critic 架构与互补监督：真实未来监督执行动作的预测，候选质量目标指导包括反事实动作在内的候选学习。
  • 提供理论分析：刻画 critic 监督如何促进决策相关预测特征的保留，并在评估器精度与候选覆盖假设下给出候选选择遗憾界。
  • 在 NAVSIM-v1 上取得 93.4 PDMS，并在消融中考察真实未来监督、循环 rollout 与 critic 梯度回传至预测特征的作用。
Card 04 方法描述

方法描述

  • 所属模块：动作提议、世界模型未来预测与 critic 后果评估的统一框架；不属于端到端直接回归轨迹的单一策略，而是“多候选生成 + 候选评估选择”。
  • 输入传感器：原文报告每个输入由两帧连续前视相机观测构成，并结合自车状态与驾驶指令；原文未报告激光雷达等其他传感器。
  • 场景表示：以编码器得到潜在状态 z，状态包含场景潜变量与自车动力学，并保留于历史记忆；未来以潜在状态序列表示，而非显式 BEV 或图像重建。
  • 模型结构：多模态策略提出 32 条候选轨迹（每条含 4 秒内 8 个未来位姿）；动作编码器将完整候选动作映射为 token；共享的 L 层联合 Transformer 循环预测候选条件未来并累积 critic token；预测与 critic 使用独立注意力投影和前馈网络；动作与任务条件通过 AdaLN 注入，旋转位置编码编码时空坐标；最终由预测头将最终 critic token 映射为标量质量分及辅助质量分量。
  • 关键技术：非对称联合注意力——预测 token 只能访问潜在历史与动作 token，critic token 可读取更新后的预测特征、完整历史、动作 token 及自身表示，而历史 critic token 被排除在预测之外；循环执行 H 步后按最高预测质量分选择候选。
  • 训练目标：真实未来监督采用带 stop-gradient 的潜在预测损失；critic 损失覆盖 N 个提议候选与记录动作共 N+1 个样本；策略采用 best-of-N 回归损失；三者加权联合优化。推理时并行评估候选并选择最高分动作。
  • 理论部分：线性设定下给出预测重要性与决策重要性组成的 importance 矩阵及最优预测子空间结论；并给出候选选择遗憾上界，涉及 critic 拟合误差、评估器误差与候选覆盖。

Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM-v1 规划评估，指标为 PDMS，包含无责任碰撞 NC、可行驶区域合规 DAC、碰撞时间 TTC、自车进度 EP 与舒适性 C；PDMS = NC·DAC·(5EP+5TTC+2C)/12。
  • 开环/闭环条件：在 NAVSIM-v1 上进行开环评估；原文未报告闭环仿真或实车测试结果。
  • 主要结果：WAC 取得 93.4 PDMS，为对比方法中最高；分项为 NC 99.0、DAC 98.3、TTC 95.9、Comfort 100.0、EP 91.0，其中 EP 为对比方法中最高。
  • 对比方法：包括端到端规划方法（DiffusionDriveV2、iPad、SparseDriveV2、NaviHydra、DrivoR、Drive-JEPA）、VLA 方法（AutoVLA、DriveVLA-W0、ReCogDrive、DriveWorld-VLA、DynVLA、HybridDriveVLA、LatentVLA、WCog-VLA）以及世界模型/世界动作方法（Epona、WorldRFT、WoTE、DriveLaW、DriveDreamer-Policy、DriveWAM、ReWorld、DriveFuture、Auto-JEPA、SimWAM）。
  • 候选评分质量：与 Drive-JEPA 相比，Spearman 相关 0.551 对 0.468，成对排序准确率 77.11% 对 74.02%，低分高估 34.02 对 44.16（越低越好）。
  • 消融：原文报告在相同四步预测间隔、无 focal weighting 条件下，比较去除循环预测、去除真实未来监督、去除 critic 到 transition 梯度等变体，以 PDMS 报告结果；具体数值在提供的原文截断处未完整给出。
  • 定性分析：原文展示城市跟车、信号交叉口与湿滑交叉口场景下 WAC 与 Drive-JEPA 的 32 条候选及所选轨迹对比，并包含安全性排序、避免高估选择与进度–安全权衡等定性结果。
