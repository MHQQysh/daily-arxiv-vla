Card 03 核心贡献

核心贡献

  • 提出 CLFTv2：基于层次化 Swin 的相机-激光雷达融合架构，配备轻量逐尺度残差解码器，原生提取多尺度几何线索，避免通用查询式解码器在闭集语义分割中的沉重计算开销。
  • 通过 ZOD、Waymo、ISEAuto 多数据集基准，展示 CLFTv2 在稀疏或伪标签监督下取得与先进查询解码器相当的精度，同时所需 GFLOPs 显著更低、吞吐量高 2.2×。
  • 模态隔离研究揭示实际权衡：Swin 的层次结构改善小目标分辨率，但局部窗口注意力相比 ViT 全局感受野在充分利用密集、局部化 LiDAR 回波时略逊，提示混合全局-局部架构为未来方向。
  • 证明所学多模态表示可跨不同传感器特性与地理数据集泛化，跨数据集初始化可加速收敛并提升早期轮次精度。
Card 04 方法描述

方法描述

  • 所属模块：整体为三分量架构——Siamese Swin Transformer 编码器、由粗到细残差融合解码器、轻量分割头。
  • 输入传感器：前视相机 RGB 图像与激光雷达点云；LiDAR 点被投影到图像平面并编码为三通道坐标图（每像素对应投影 3D 点 (X, Y, Z)）。
  • 场景表示：完全在 2D 透视投影域操作，图像输入为 256×256×3（Tiny，M=16），Base/Large 支持 384×384（M 从 12 到 24）。原文未报告 BEV 或其他 3D 原生表示。
  • 模型结构：SwinV2 骨干，4×4 patch 划分、四阶段层次结构、移位窗口（SW-MSA）自注意力；逐级 Patch Merging 使空间减半、通道翻倍，形成步长 {4,8,16,32} 的四级特征金字塔；嵌入维度 Tiny 为 {96,192,384,768}，Base 为 {128,256,512,1024}，Large 为 {192,384,768,1536}。W-MSA 复杂度为 Ω(W-MSA)=4hwC²+2M²hwC（O(hw)）。
  • 关键技术：权重共享的 Siamese 编码器并行处理 RGB 与 LiDAR；各级经 1×1 卷积投影到统一维度 D=256；逐模态 ResConv 单元（两个 3×3 卷积 + ReLU + 恒等跳连）独立精炼，逐元素相加融合，并逐级累加 2× 双线性上采样得到的上—层上下文；分割头由 3×3 卷积 + BN + ReLU + 1×1 卷积构成，再 4× 上采样输出 logits。
  • 设计消融：去掉递推项 Up_{2×}(A_{i+1}) 使 ZOD mIoU 从 35.9% 降至 23.1%（绝对下降 12.8%）；将逐元素相加替换为五种门控或注意力加权方案，单次运行配置下 mIoU 变化不超过 ±0.7%。
  • 训练损失与优化细节原文未报告。

数据集与资源

  • 数据集：Waymo Open Dataset（22,000 帧切片，含 13,199 训练 / 4,400 验证 / 4,400 测试，四类：背景、车辆、人、标志，密集人工验证标注）；ISEAuto 数据集（2,400 帧切片，两个前景类：人、车辆，原生像素级人工验证标注）；Zenseact Open Dataset（ZOD，2,300 帧精选切片：1,150 训练 / 1,150 验证，四类，掩码经 SAM 半自动投影流程生成，属伪标签，训练 1,148 帧 / 验证 573 / 测试 579）。

Card 06 评估与结果

评估与结果

  • 评估基准：ZOD、Waymo、ISEAuto 三个驾驶数据集；对比方法为 Swin 版 Mask2Former 适配、MaskFormer、DeepLabV3+ 基线，以及前作 CLFT。
  • 评估指标：mIoU、各类 IoU、VRU 召回率、GFLOPs、吞吐量；含模态隔离研究与窗口大小消融。
  • ZOD 上 CLFTv2-Large 达 53.5% mIoU，行人 IoU 由前作 CLFT 的 35.5% 提升到 44.9%。
  • Waymo 上 CLFTv2 达 61.7% mIoU。
  • 相比 Swin 版 Mask2Former 适配，CLFTv2 所需 GFLOPs 少 1.4×，吞吐量高 2.2×，总体精度相当。
  • 模态隔离研究显示，ViT 全局感受野仅在 LiDAR 回波密集时带来更强的融合增益。
  • 消融去递推项导致 ZOD mIoU 从 35.9% 降至 23.1%。
  • 评估条件：开环、仿真或实车条件下的具体划分在提供的原文片段中未完整报告。
