论文概述

Card 03 核心贡献

核心贡献

  • 指出并分析了现有启发式与几何基聚合方法的局限，说明固定手工合并规则难以泛化到不同道路结构和检测器噪声模式。
  • 提出 MapMergeLLM，将矢量化地图聚合建模为条件序列生成任务，使用大语言模型（LLM）作为序列建模骨干，直接从序列化的局部矢量片段预测全局地图折线。
  • 引入检测器无关的合成训练数据构造方式，通过对干净矢量地图施加结构化损坏（实例重复、端点损坏与碎片化、非结构化逐点扰动、结构化局部几何扰动）来模拟代表性预测误差。
  • 提出坐标分词（coordinate tokenization）将每个离散坐标值编码为单一 token，并配合几何感知的坐标 token 预训练，提升坐标表示与生成精度。
  • 提出线级关联损失（line-level association loss），显式监督同一地图元素局部观测之间的对应关系，辅助片段关联并减少重复预测。
Card 04 方法描述

方法描述

  • 所属模块：属于矢量化 HD 地图构建流程中的全局地图聚合模块，位于上游逐帧矢量地图检测器之后。
  • 输入传感器：原文未报告直接使用原始传感器数据；输入为上游检测器输出的局部矢量化地图预测，并假设可利用自车位姿对齐到统一坐标系。
  • 场景表示：地图元素表示为类别 c_k 与有序折线 P_k=(p_k,1,…,p_k,N_k)，点为二维坐标；地图表示为 M=[(P_1,c_1),…,(P_K,c_K)]，元素数量 K 与采样点数 N_k 可变。
  • 问题表述：将聚合建模为条件序列生成，M̂=F_θ(M̃^(1),…,M̃^(L))，由局部预测生成全局干净地图；训练数据由检测器无关损坏分布 q_φ 合成。
  • 模型结构：采用 Qwen3.5-4B 作为骨干，扩展词表加入坐标 token，并扩展输入嵌入矩阵与语言建模头对应行；使用 LoRA 对骨干选定线性层进行参数高效适配。
  • 坐标分词：给定空间分辨率 δ，将坐标量化为整数 z̃_i=round(z_i/δ)，并为坐标范围内每个整数值加入一个 token ⟨n⟩；解码时按 z=nδ 还原为米。
  • 两阶段训练：Stage 1 为坐标 token 预训练，仅优化新增坐标 token 的嵌入行与 LM 头行，冻结原预训练参数，使用坐标平移、中点预测、点排序等几何/算术任务及序列化局部地图的下一 token 预测；Stage 2 为地图聚合训练，仅优化 LoRA 参数，冻结 θ_0 与 Stage 1 学得的坐标 token 参数。
  • 线级关联损失：对每条输入折线的坐标 token 最终隐状态做均值池化得到线嵌入，并以同一全局元素相邻帧观测为正样本、不同全局元素为负样本构造对比损失。
  • 总体损失：Stage 2 目标为 L=L_agg+λ_line L_line，其中 L_agg 为 token 级自回归交叉熵。
  • 推理：将上游检测器局部预测变换到统一坐标框架并序列化，自回归生成全局地图序列，再解析为折线并将坐标 token 还原为坐标值。
