Safety4DM: A Vision-Language Framework for Risk-Aware Dynamic Maps in Vehicle-Road-Cloud Collaborative Driving

Card 03 核心贡献

核心贡献

  • 提出 Safety4DM，用于打通从真实世界视觉感知、结构化风险表示到自然语言安全查询的完整流程，并支持对车辆风险与道路环境风险的自然语言安全查询。
  • 构建 RoadRisk 真实道路图像数据集，覆盖四类道路状况与四个风险等级，用于微调视觉语言模型进行具有显式视觉推理的道路安全风险感知，输出可被 DM 直接接收的结构化风险表示。
  • 设计 SafeVRC-Sim 车–路–云协同仿真框架，用于模拟协同感知交通场景并注入道路环境风险；在其上构建包含 1,600 个混合交通场景和 23.5K 问答对的安全问答基准 SafeDM-QA。
  • 提出 SafeStep 分步提示机制作为 DM 的自然语言查询接口，将空间关系与安全指标计算卸载到查询工具箱，使 LLM 能精确回答结构化场景上的安全查询并结合常识生成可执行驾驶建议。
Card 04 方法描述

方法描述

  • 所属模块：Safety4DM 包含道路安全风险感知模型、RoadRisk 数据集、SafeVRC-Sim 仿真框架、SafeDM-QA 数据工程与 SafeStep 提示机制五个关键组件。
  • 输入传感器：风险感知模型输入为真实道路图像；仿真中的感知节点包括车载（AV）节点与路侧（RSU）节点，均感知车辆风险与环境风险；SafeVRC-Sim 通过 SUMO/TraCI 获取交通数据流，原文未报告具体物理传感器配置。
  • 场景表示：DM 按更新频率分为静态、半静态、半动态和动态四层；车辆信息属于动态层，道路风险实体填充半动态层。云端构建数字向量场景（DVS），并以 JSON 组织语言场景（LS）供下游 LLM 使用。OI 模式包含 id、时间戳、坐标、速度、加速度、航向、尺寸、类型、颜色、车道与道路等字段；EI 模式包含道路、风险类别、风险等级（0–3）、受影响车道、检测传感器与时间戳等字段。
  • 模型结构：道路风险感知被建模为带显式视觉推理的条件生成问题，视觉编码器与文本嵌入层分别编码图像与指令并拼接为统一上下文，生成推理链与结构化答案（道路状况类别、风险等级）。风险等级按积水最深处深度、积雪车道覆盖率与厚度、障碍物横向占道比例等物理量分级。
  • 关键技术：SafeStep 包括查询解析、风险计算与安全响应三个步骤；SafeDM-QA 数据工程包括目标关联与关系计算、属性–实体–关系图构建、问题模板设计与细化（自我车锚定问答与道路锚定问答）以及问答实例化；共定义 18 类安全相关查询任务，包括道路风险类别、风险等级、TTC、THW、安全速度与制动距离等。
  • 原文未报告：视觉编码器与语言模型的具体骨干网络细节、模型参数规模、训练资源与实车平台。
Card 05 数据集与资源

数据集与资源

  • 数据集：RoadRisk 为 6,000 张真实道路图像构成的问答数据集，覆盖四类道路状况与四个风险等级，图像来源包括 BDD100K、Lost and Found 及网络采集；场景涵盖城市街道、高速公路、小巷、村庄、隧道与城镇，包含白天与夜间、行车记录仪、CCTV、行人视角与无人机视角。
  • 基准：SafeDM-QA 包含 1,600 个混合交通语言场景与 23.5K 问答对，覆盖 18 类安全相关查询任务。
  • 仿真器：SafeVRC-Sim 基于 SUMO、ROS2 与 PyQt6 构建。
  • 模型规模：实验涉及 Qwen3-VL-4B 等紧凑模型，以及五个模型家族中 20B 及以上的中大型模型；原文未报告各模型的具体参数配置细节。
  • 训练资源与实车平台：原文未报告。
Card 06 评估与结果

评估与结果

  • 评估基准：RoadRisk 上的道路风险感知任务，以及 SafeDM-QA 上的自然语言安全查询任务。
  • 评估指标：风险感知使用准确率；自然语言查询使用查询准确率；SafeDM-QA 统计中使用归一化香农熵衡量答案分布平衡性。
  • 关键数值：紧凑的 Qwen3-VL-4B 经微调后在风险感知任务上达到 89.83% 准确率；SafeStep 在五个模型家族的中大型模型（20B 及以上）上均取得超过 93% 的自然语言查询准确率。
  • 对比方法：原文实验设置部分包含 Baselines，但所给 HTML 内容未报告具体基线名称与逐项对比数值；论文概述表格中与 DriveGPT4、DriveVLM、DriveLM、Talk2BEV、PromptTrack、NuScenes-QA、LMDrive、V2X-VLM、V2V-LLM 等研究进行了任务覆盖比较。
  • 实验条件：风险感知基于真实道路图像；SafeDM-QA 评估基于 SafeVRC-Sim 生成的语言场景，属于仿真条件下的问答评估。开环、闭环与实车评估：原文未报告。
