Card 02 论文概述

论文概述

  • 论文解决机场地面运动预测任务，即预测飞机和地面车辆在机场跑道、滑行道等地面区域的未来轨迹。

  • 研究问题聚焦于机场地面运动相较于自动驾驶场景的动态异质性，即飞机在滑行、起飞、着陆等不同运行阶段的速度和空间尺度差异巨大，而传统自动驾驶轨迹预测方法的地图采样策略无法有效适应这一特点。
Card 03 核心贡献

核心贡献

  • 提出一种基于 Potential Reachable Set (PRS) 的场景上下文采样机制，通过遍历机场道面拓扑图并依据语义类型和累计距离确定遍历深度，自适应地收集机场环境上下文，解决固定区域或最近邻采样无法覆盖长距离、多尺度运动的问题。
  • 将 PRS 采样策略集成到新型轨迹预测模型 DESCENT 中，模型采用 transformer 架构，结合空气场段编码、运动编码、场景编码和检测 transformer 风格解码器，在 Amelia-10 基准上取得最先进性能。
  • 在 Amelia-10 基准上进行了全面评估，证明该方法在安全关键场景（临界智能体）下性能提升尤为显著，同时保持较低推理延迟并有效捕获长时域场景上下文。
Card 04 方法描述

方法描述

  • 所属模块：运动预测（轨迹预测）模块。
  • 输入传感器：原文未明确说明具体传感器，使用 SWIM 提供的运动数据；输入特征包括 3D 位置、速度和偏航角（D_a=5）。
  • 场景表示：将原始机场地图预先处理为具有语义的空气中段，并重组为有向边图；每个段由最多 P_s=20 个 2D 点表示，段类型分为滑行道（taxiways）、跑道（runways）和等待线（hold lines），段类型用于确定最大段长（跑道 0.8 km，其他 30 m）。
  • 模型结构：DESCENT 采用 transformer 架构，包括空气场段编码器 f_A（PointNet 类）、运动编码器 f_M（自注意力，沿时间维度应用后池化）、场景编码器 f_S（注意力机制，4 个注意力块）和解码器 f_D（检测 transformer 风格，使用可学习模式查询 k=4 和因子化交叉注意力，深度为 3）。
  • 关键技术：PRS 上下文采样机制，通过深度优先遍历道面图，受领域特定长度阈值约束，预计算每个段出发的所有可行路径并存储为元数据；使用潜在可达集而非瞬时速度来决定可达距离，涉及跑道段时包含整条跑道以覆盖起飞和着陆长时域轨迹；采用 SDF 正则化损失项，以 5m 分辨率栅格化 SDF 惩罚偏离有效区域的预测；训练使用 winner-takes-all 目标和 NLL 损失，层维度 D=128。

Card 06 评估与结果

评估与结果

  • 评估基准：Amelia-10 基准测试集，采用两种 focal agent 选择策略（随机选择和基于数据集中 criticality 分数的最关键智能体选择）。
  • 评估指标：mFDE（最小最终位移误差）和 mADE（最小平均位移误差），报告 20s 和 50s 两种预测时域的结果，误差单位为米。
  • 关键数值（critical agent 设置，mFDE@50s 平均）：Amelia-TF 105.40 m，DESCENT 66.90 m（排除无官方检查点的 KSFO 和 KSEA 后平均）；单机场如 KBOS 从 81.61 降至 64.49，PANC 从 170.48 降至 67.13。
  • mADE@50s（critical agent 平均）：Amelia-TF 39.01 m，DESCENT 28.20 m；mFDE@20s 平均：Amelia-TF 19.05 m，DESCENT 15.70 m。
  • 随机 agent 设置（mFDE@50s 平均）：Amelia-TF 54.52 m，DESCENT 38.11 m；mADE@50s 平均：Amelia-TF 22.37 m，DESCENT 16.91 m。
  • 消融实验：PRS-based 采样（KBOS 64.49、KSFO 56.60、PANC 67.13，平均 62.74）优于 Top-K closest（平均 140.83）和 Radius-based 0.3km（平均 91.70）采样。
  • 延迟分析：DESCENT 在推理 32/64/128 个智能体时延迟为 32/68/132 ms，高于 Amelia-TF 的 16/36/76 ms，但后者地图上下文极为有限。
  • 对比方法：Amelia-TF（Amelia 框架的基线模型），另因自动驾驶方法迁移需要大量架构修改而限制比较公平性，仅与 Amelia-TF 比较。
  • 评估条件：全部为开环离线评估，基于测试集上的轨迹预测误差，未报告闭环或实车实验。
