Card 03 核心贡献

核心贡献

  • 提出 WorkIng-Highway：一个 360° LiDAR-相机-RTK 的施工区基准数据集，包含同步的六路 RGB 相机、128 线 LiDAR 与 RTK-GPS，覆盖 19.3 km 白天与 12.7 km 夜间驾驶，产出 12,000+ 标注帧、227,399 个 3D 包围框和 6,044 个 track ID。
  • 提出 WorkIng-CARLA：一个程序化仿真框架，基于六种典型拓扑与两种交互模式生成 24 个安全关键施工区场景，并通过 region 参数替换 100+ 自定义 3D 资产以适配六种国际交通标准。
  • 在统一类目体系下对代表性 3D 检测器（CenterPoint、PETR、BEVFusion）与端到端规划器（UniAD、VAD）进行双域基准评测，并给出四项发现：真实数据是性能主要驱动因素；夜间 LiDAR 感知更强、多模态优于纯相机；矢量化 VAD 碰撞率低于查询式 UniAD；场景分层的合成数据增强对 2D 识别、3D 检测与轨迹规划均有一致增益。
  • 开源数据集与资源（https://github.com/cvims/WorkIng）。
Card 04 方法描述

方法描述

  • 所属模块：数据集构建与基准评测，涵盖 3D 目标检测、2D 施工区资产识别与端到端轨迹规划。
  • 输入传感器：真实数据使用 1 个 128 线 LiDAR（20 Hz，360° 水平 FOV，−25° 至 15° 垂直 FOV，≥10% 反射率下最远 240 m）、6 个 RGB 相机（1920×1080 @ 20 FPS，4 个 60° 水平 FOV、2 个 100° 水平 FOV）、1 个 RTK-GPS/IMU（100 Hz，厘米级精度）；仿真数据的自车传感器套件镜像真实采集车。
  • 场景表示与标注：真实数据以 5 Hz 人工标注，每个实例为 (x,y,z)、(l,w,h)、yaw 的 3D 包围框，具有跨序列一致的跟踪 ID，共九类；人脸与车牌做高斯模糊匿名化。仿真数据包含同步 RGB、深度与语义分割标注，CARLA 资产类目映射到 nuScenes 兼容类目，仅排除 Trailer。
  • 仿真框架关键技术：基于 CARLA Leaderboard 的参数化场景，六种典型布局为单车道封闭、多车道封闭、半幅封闭（对向交通）、内部施工区、横向车道偏移、路肩施工区；两种交互模式为无遮挡接近与前车遮挡接近；支持 Australia、China、Nordic、USA、Europe（Vienna Convention）、DACH 六种法规。轨迹由增强的 PDM-Lite 智能体生成，加入施工区限速调整、响应临时标志变道、沿锥桶边界跟踪等法规合规导航行为。
  • 检测与规划基线：CenterPoint（纯 LiDAR，100 m×100 m 网格、体素 (0.1,0.1,0.2) m、25 epoch）、PETR（纯相机，FCOS3D V2-99-eSE、384×960 输入、75 epoch）、BEVFusion（多模态，Swin-Tiny 图像编码器、VoxelNet LiDAR、体素 (0.075,0.075,0.2) m、50 epoch）；UniAD-Tiny（查询式端到端，10 epoch、queue 3、体素 (0.2,0.2,8) m）与 VAD-Tiny（矢量化端到端，10 epoch、体素 (0.2,0.2,8) m），两者由原始纯相机设计改造为相机-LiDAR 融合，且省略 HD 地图分支，因为 WorkIng-Highway 不提供 HD 地图真值。
  • 2D 资产识别基线：Mask R-CNN（ResNet-50-FPN）与 Mask DINO（DETR 系），与 ROADWork 报告的基线对齐以便直接比较。

Card 06 评估与结果

评估与结果

  • 评估基准与协议：3D 检测沿用 nuScenes 评测协议与类目映射（Car/Van 映射为 Car，Cyclist 并入 Motorcycle），指标为 mAP、ATE、ASE、AOE 与 NDS（×100）；轨迹估计在 0.5/1.0/2.0 s 及时间平均上报告 L2 误差（m）与碰撞率（%）；2D 资产识别在 ROADWork 留出真实测试集上报告 COCO 风格 mask AP（IoU 0.5:0.95）。因标注密度不足，Night 排除 Bus、Motorcycle、Pedestrian，CARLA 排除 Trailer。
  • 3D 检测 within-domain 结果（Table 4，真实为仅用 WorkIng-Highway 训练，CARLA 为仅用 WorkIng-CARLA 训练）：Day 上 CenterPoint mAP 0.76 / NDS 79.40，BEVFusion 0.75 / 76.59，PETR 0.37 / 43.52；Night 上 CenterPoint 0.78 / 81.55，BEVFusion 0.78 / 77.71，PETR 0.33 / 44.04；CARLA 上 CenterPoint mAP 0.97 / NDS 94.65，BEVFusion 0.93 / 85.12，PETR 0.56 / 61.35。结论为纯 LiDAR 与多模态在昼夜均优于纯相机，CenterPoint 的 NDS 略高于 BEVFusion，差距来自尺度与朝向误差（ASE、AOE）而非定位误差（ATE）；CARLA 中带 LiDAR 的检测器接近饱和，纯相机差距缩小。
