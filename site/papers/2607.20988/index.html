论文概述

  • 该论文提出 HyWorldVLA，一种用于端到端自动驾驶的视觉-语言-动作（VLA）模型，旨在解决自动驾驶中的轨迹规划任务。

Card 03 核心贡献

核心贡献

  • 提出 HyWorldVLA，建立混合世界模型范式，在单一框架中统一了像素级世界模型和潜变量世界模型的互补特性。
  • 引入语言引导（text guidance）和潜变量条件化（latent conditioning）机制，有效引导模型关注与动作生成相关的语义信息。
  • 在 NAVSIM v1 与 v2 基准上实现最先进性能，显著优于像素级和潜变量级世界模型基线。
  • 首次对自动驾驶中世界模型的噪声鲁棒性进行全面的定性和定量分析，为评估未来架构建立新基准。
Card 04 方法描述

方法描述

  • 所属模块：端到端轨迹规划，包含世界模型预训练与联合微调。
  • 输入传感器：单目前视摄像头（1x Cam），结合历史驾驶命令。
  • 场景表示：混合表示，包括视频 VAE 压缩的潜变量特征，以及 VQGAN 离散化的视觉 token、FAST 离散化的动作 token 与 Emu3 语言 token。
  • 模型结构：基于 Emu3 统一多模态自回归骨干网络，并结合查询式动作专家（action expert）与联合注意力机制。
  • 关键技术：采用三个训练阶段——（1）文本引导的视频 VAE 训练，用于压缩和重建视频帧；（2）预训练阶段，同时进行像素级帧重建和视频 VAE 潜变量预测，采用双重监督；（3）协同微调阶段，仅预测潜变量特征并馈入动作专家生成轨迹。潜变量预测通过可学习的查询 token Q 实现。

Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM v1 与 NAVSIM v2。
  • 评估指标：v1 为 PDMS（NC、DAC、TTC、Comfort、EP）；v2 为 EPDMS（额外包括 DDC、TLC、LK、HC、EC）。
  • 关键数值：v1 PDMS 为 90.59；v2 EPDMS 为 89.71。
  • 对比方法：包括端到端方法（UniAD、TransFuser、PARA-Drive、Hydra-MDP、DiffusionDrive 等）、VLA 方法（AutoVLA、ReCogDrive 等）、像素级世界模型方法（DriveVLA-W0、PWM、DriveLaW 等）、潜变量世界模型方法（LAW、Epona、DreamerAD、Latent-WAM 等）。
  • 评估条件：NAVSIM v1 与 v2 均为闭环评估。
  • 消融研究：移除像素回归（Pure LWM）降至 87.50，移除潜变量能力（Pure WAM）降至 89.91，去除语言引导降至 90.35，去除动作专家中潜变量条件降至 90.29，去除协同微调中潜变量监督降至 90.17。
