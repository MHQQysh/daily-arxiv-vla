Card 03 核心贡献

核心贡献

  • 提出 RoGS 框架，采用网格分布的 2D 高斯面片（surfel）显式建模道路表面，同时编码颜色、语义与几何信息，符合道路薄表面特性，并减少冗余基元与优化过程中的重叠。
  • 提出道路结构感知的自适应网格策略，根据局部几何与语义复杂度在车道标线、路缘、道路边界、高度不连续等区域分配更密集的高斯面片，在平坦区域保持紧凑表示。
  • 提出轨迹一致性引导的位姿鲁棒初始化与精化策略，从多个邻近车辆位姿估计局部表面先验，并根据几何一致性自适应加权位姿引导的高度正则化，降低位姿噪声影响。
  • 在 KITTI 与 nuScenes 上开展实验，相比现有基于网格的方法，迭代一个 epoch 时获得 53× 加速，迭代两个 epoch 时获得 27× 加速，同时保持准确的 RGB、语义与高程重建。
Card 04 方法描述

方法描述

  • 所属模块：大规模道路表面重建与建图框架，包含场景表示、自适应网格生成、位姿鲁棒初始化与可微优化。
  • 输入传感器：环视相机图像、语义分割结果、车辆位姿；可选 LiDAR 点云用于高程监督。语义分割结果由预训练 Mask2Former 模型获得。
  • 场景表示：在车辆轨迹扩展出的 xy 平面区域上建立基础网格，将 2D 高斯面片放置在网格顶点。每个面片参数化为中心坐标、RGB 颜色、切平面尺度、不透明度、旋转矩阵和语义向量；沿法线方向尺度设为零以形成 2D 面片。最终面片集为基础网格面片与自适应细分产生的额外面片之并集。
  • 模型结构：可微 2D 高斯渲染，RGB 与语义渲染采用与 3DGS 相同的 alpha 合成公式；针对不同相机曝光差异引入每个相机的可学习曝光参数。
  • 关键技术：自适应网格策略按下式计算结构复杂度得分，其中 Gm 为 RGB 梯度响应、Sm 为语义边界/熵响应、Zm 为局部高度变化（LiDAR 可用时由点云俯仰变化得到）；得分超过阈值则细分网格。位姿鲁棒初始化中，对每个面片搜索 K 个邻近车辆位姿，按距离加权聚合得到位姿共识高程与轨迹一致性方差，进而得到轨迹一致性置信度。优化损失包括颜色损失、语义交叉熵损失、高程平滑损失、轨迹一致性引导的高度正则化损失，以及可选的 LiDAR 高程监督损失。
  • 训练策略：默认 BEV 分辨率为 0.05 m/pixel；不透明度、尺度、旋转学习率设为 1×10⁻⁴，高程学习率随场景尺寸比例初始化 1.6×10⁻⁴ 并衰减至 1.6×10⁻⁶，颜色与语义学习率分别为 0.008 与 0.1，曝光参数学习率为 0.001；最大细化层级设为一。

Card 06 评估与结果

评估与结果

  • 评估基准：nuScenes 5 个场景定量评估，以及 KITTI 实例展示；另评估两个由 4 个 nuScenes 场景拼接成的大规模场景重建效果。
  • 评估指标：RGB 重建用 PSNR，语义精度用 mIoU（百分比），几何精度用高程 RMSE（单位米）；时间效率以分钟计。伪真值由 LiDAR 点云按车辆位姿拼接构建，投影到最近相机图像确定颜色与语义标签，并在半径 0.1m 邻域内查询最近 LiDAR 点计算高程误差。
  • 关键数值：无 LiDAR、迭代 1 个 epoch 时平均 PSNR 23.90、mIoU 85.56、高程 RMSE 0.147，时间 30.7 分钟（53× 加速）；无 LiDAR、迭代 2 个 epoch 时平均 PSNR 23.57、mIoU 85.41、高程 RMSE 0.151，时间 61.1 分钟（27× 加速）；使用 LiDAR、迭代 1 个 epoch 时平均 PSNR 24.56、mIoU 90.59、高程 RMSE 0.095，时间 32.1 分钟（51× 加速）；使用 LiDAR、迭代 2 个 epoch 时平均 PSNR 24.42、mIoU 91.61、高程 RMSE 0.092，时间 63.9 分钟（25× 加速）。
  • 对比方法：与基于网格的道路重建方法 RoMe 对比，RoMe 在 nuScenes 上的平均 PSNR 23.63、mIoU 84.95、高程 RMSE 0.176、时间 1630 分钟。
  • 开环/闭环：本文方法为离线建图任务，不涉及闭环控制与规划；属于开环重建与评估。仿真与实车条件：实验基于真实数据集（KITTI 与 nuScenes）的实车采集数据进行，非仿真环境。
  • 消融研究：验证了网格布局、位姿初始化、自适应网格和轨迹一致性精化各组件；完整配置在该消融实验场景达到 PSNR 24.56、mIoU 90.59、高程 RMSE 0.095，优于各消融变体。
