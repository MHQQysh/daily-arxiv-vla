GeoWM: Efficient Direct World Modeling in Explicit Geometry

2026-10-05 · 原文 · 翻译 · 2610.07381

研究任务是自动驾驶与机器人场景下的世界模型（world model）几何预测：给定最近 K 帧 RGB 观测，预测指定未来时刻 t+h 的深度图 D_{t+h} 与相对相机位姿 T_{t→t+h}，并由深度与位姿导出 3D 点云。 应用场景覆盖城市驾驶、航拍飞行与动态机械臂操作三类领域。 研究问题：现有世界模型多预测未来图像或潜特征、再从中恢复几何，未显式建模几何结构；且依赖对短期预测的递归 rollout 到达长时域，导致误差累积与推理成本随时域增长。 论文提出的思路是把未来预测直接放在显式几何空间（几何基础模型的深度输出空间）中，并把预测时域 h 作为模型输入，支持对任意时域的一次性直接查询。

Card 03 核心贡献

核心贡献

  • 提出 GeoWM 几何世界模型，在由观测 RGB 帧经冻结几何基础模型提取的显式几何空间中直接预测未来 3D 场景几何，提供结构化、可解释的未来状态表示。
  • 设计时域条件化的流匹配扩散 Transformer（horizon-conditioned flow-matching transformer），对指定未来时域直接预测几何，不做递归 rollout，从而缓解误差累积，且单次预测代价不随时域增长。
  • 使用轻量相机运动预测器估计未来视点，并把观测几何投影到预测视点，得到作为未来几何预测有效先验的“anchor”几何条件。
  • 在驾驶、航拍与机械臂操作四类数据集上跨多个时域验证，在深度、相机位姿与 3D 点云三类指标上优于所评估的世界模型，并在长时域显著降低推理时间。
  • 通过受控消融验证各设计选择（原文摘要与贡献列表声称进行了 ablation，正文对应细节在所提供的截断内容中未完整报告）。
Card 04 方法描述

方法描述

  • 所属模块：世界模型/未来几何预测模块，用于为依赖 3D 理解的规划与控制类任务提供未来场景几何；原文未报告具体的下游规划或控制模块集成。
  • 输入传感器：RGB 相机图像序列 I_{t-K+1:t}（K 帧）。KITTI 使用 LiDAR 真值作监督，Cityscapes 使用立体序列，DOMINO 使用静态头部相机且原文为获得真值深度在 SAPIEN 中重新渲染。
  • 场景表示：显式几何表示，即深度图与相机位姿；论文说明选择预测深度而非点图，因为给定相机时像素已固定视线方向，深度是每像素唯一自由量，点图可由预测深度与位姿推出。
  • 几何历史提取：使用冻结的前馈重建骨干（实验中为 VGGT-1B）将观测帧映射为深度图 D_{t-K+1:t}、相机内参与相机位姿，并取 K−1 个相邻帧相对运动。
  • 相机运动预测：将 K−1 个观测相对运动编码为旋转向量与归一化平移特征，用轻量预测器一次性映射到 H 中每个未来步的相对相机位姿；旋转采用 ridge regression，平移采用小型回归器，参数量至多数万。
  • 几何条件（anchor）：由预测位姿 T̂_{t→t+h} 与骨干内参，把 D_t 以最近深度可见性处理前向投影到预测相机，得到 A_h = W(D_t, T̂_{t→t+h})，作为“从预测未来视点看到的最后一次观测”的条件，仅作条件输入，网络仍需预测完整未来深度并学习吸收观测深度误差、运动预测误差、场景动态与新可见区域。
  • 主干结构：在深度图上运行的普通 diffusion transformer；条件 c_h = (D_{t-K+1:t}, A_h)，共 K+1 个条件通道与噪声目标在 256×256 分辨率堆叠，切为 16×16 patch 后线性投影为 256 个 token 并加可学习位置嵌入；随后 14 个 pre-norm transformer block，宽度 896，线性头与 unpatchify 输出；空间条件仅用通道拼接，时域与 flow time 通过归一化层注入。
  • 时域与时间的注入方式：flow time τ 与 log h 分别做正弦嵌入、拼接、经小 MLP 映射，并通过 adaLN-zero 自适应层归一化注入每个 block，使 horizon 调制每一层。
  • 训练目标：flow-matching，使用 clean-target prediction 与 velocity 空间的加权 L1 损失；插值 z_τ = τx + (1−τ)ε，x = D_{t+h}/σ_h，σ_h 为按 horizon 在训练集上计算的固定归一化常数；逐像素权重 w_p ∝ m_p / max(D_{t+h,p}, d_min)，为有效像素掩码下的逆深度权重；flow time 取 logit-normal 分布 τ = sigmoid(u)，u ~ N(−0.8, 0.8²)；固定比例训练样本设为 τ=0 以显式训练推理时的纯噪声状态。
  • 训练细节：每个训练样本为观测窗口加从 H 均匀采样的 horizon，目标为 t+h 的真值深度，同一网络以观测输入在所有时域被监督；Transformer 从零训练，无自编码器或 tokenizer，除冻结骨干外无预训练权重。
  • 推理：在 τ=0 从纯噪声单次前向得到 clean 估计，并平均 N=4 次独立噪声的前向结果后反归一化；无需 ODE 积分；每个请求时域所需网络评估次数固定且与预测距离无关，不同时域查询可批处理，不计算也不反馈中间未来；预测相机位姿 T̂_{t→t+h} 直接输出。DOMINO 静止相机时 anchor 与 D_t 重合故省略，仅以 K 个深度图作条件。
  • 原文未报告：模型是否输出不确定性、是否引入显式地图或 BEV 表示、是否使用时序状态缓存等，原文未报告。
Card 05 数据集与资源

数据集与资源

  • 数据集：KITTI（10 Hz 驾驶序列，LiDAR 真值；训练用 KITTI depth benchmark 的 138 个训练 drive，测试其 13 个验证 drive，共 3,257 个窗口，stride 2，20 个 horizon，0.2 s 到 4.1 s）。
  • 数据集：Cityscapes（17 Hz 立体序列；训练集训练，500 个验证窗口评估，stride 3，5 个 horizon，0.18 s 到 0.88 s）。
  • 数据集：TartanAir（航拍仿真飞行，18 个照片级真实环境，快速 6-DoF 相机运动；从 369 条轨迹中留出 37 条，7,314 个窗口，预测 1 到 20 帧共 20 个 horizon）。
  • 数据集：DOMINO（机械臂操作数据集，35 个任务、5 种机器人形态；公开版本只有 RGB，论文在 SAPIEN 中重新渲染存储轨迹以得到真值深度；训练 23 个任务并留出一种形态，测试四组：同任务同机器人、新任务、新机器人、新任务且新机器人，共 37,360 个窗口、157,325 个 window–horizon 对，7 个 horizon，0.24 s 到 7.7 s）。
  • 骨干模型：冻结的 VGGT-1B，一次前向返回观测帧的深度、内参与位姿；其深度按窗口有尺度不确定性，训练时用最后一帧观测计算尺度把真值对齐到该尺度，DOMINO 上用训练集拟合的单一常数把骨干深度转换为米，使网络以真实尺度预测深度。
  • 模型规模：Transformer 为 206M 参数，从零训练；相机运动预测器至多数万参数（原文表述为 at most a few tens of thousands of parameters）。
  • 训练资源：单块 GPU，训练数小时（原文仅报告“a single GPU in a few hours”，未报告 GPU 具体型号、显存与总卡时）。
  • 训练配置：AdamW，恒定学习率 10^{-4}，weight decay 0.01，batch size 16，梯度裁剪 1.0，bf16 精度，训练 100k steps，报告结果使用权重 EMA（decay 0.999）；纯噪声样本比例 0.4，逆深度权重深度下限 d_min = 0.05；驾驶数据集真值深度上限 80 m，TartanAir 为 100 m；TartanAir 上省略逆深度权重以避免抑制稀疏远距离结构。
  • 仿真器：SAPIEN（用于 DOMINO 重新渲染以获得真值深度）；TartanAir 本身为仿真航拍数据。
  • 实车平台：原文未报告实车平台，实验均在上述公开数据集（含仿真数据）上进行。
