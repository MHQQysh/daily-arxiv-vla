Card 03 核心贡献

核心贡献

  • 提出几何是驾驶世界动作模型的天然状态表示，直接对齐场景动态与驾驶动作所在的三维空间。
  • 预训练一个视觉几何世界模型，从历史多视角观测预测未来场景几何，捕捉驾驶场景的空间结构与时序动态。
  • 引入 GeoWAM，通过类逆动力学公式从预测几何中推断未来自车运动并将其映射为自车轨迹。
  • 通过未来几何预测、开环和闭环规划实验验证了视觉几何世界建模对自动驾驶规划的有效性。
  • 与基于图像的 WAM 相比，基于几何的世界建模显著提升了驾驶策略性能，将未来几何预测确立为自动驾驶的有效预训练目标。
Card 04 方法描述

方法描述

  • 所属模块：世界动作模型（视觉几何世界模型 + 动作头）。
  • 输入传感器：仅多视角 RGB 相机图像（原文未报告使用其他传感器）。
  • 场景表示：未来密集点地图（point map）与逐像素置信度图。
  • 模型结构：

- 采用 DVGT-2 作为几何编码器，输出多层级的历史几何 token 与 ego token。

- 未来几何解码器包含 6 层 transformer（隐藏维度 1024，16 注意力头），采用因果时序自注意力与对历史记忆的交叉注意力，将查询解码为未来几何潜在表征，再经共享几何头（Point DPT）解码为密集点地图。

- 动作分支中，未来 ego-token 解码器采用因果时序自注意力并交叉注意力到历史几何记忆与预测的未来几何 token（带 stop-gradient 连接），随后轨迹头对历史与未来 ego features 进行因果时序 transformer 精化，轨迹查询交叉注意力后回归单一未来轨迹。

  • 关键技术：

- 未来几何监督包含：预测特征与目标特征（由同一几何编码器处理未来图像得到、带 stop-gradient）之间的余弦距离损失；点图目标包含欧氏点回归、置信度感知回归和多尺度表面法线一致性损失；外加对当前帧的点图目标损失。

- 规划微调保留几何目标，另加轨迹 ℓ1 回归损失和辅助的历史帧相对位姿 ℓ1 损失 。

- 轨迹头直接回归一条轨迹，不使用轨迹锚点、模式分类或迭代采样。

- 通过 stop-gradient 连接防止轨迹损失回溯影响预测几何，保持预训练几何预测能力。

Card 06 评估与结果

评估与结果

  • 评估基准：nuScenes 验证集（未来几何预测）、NAVSIM v2 navtest（开环/闭环规划）与 navhard 两阶段伪闭环基准。
  • 评估指标：

- 未来几何：绝对相对误差（Abs Rel）、阈值精度 δ<1.25，按八个未来步长及完整预测视界（1–4 秒）计算。

- 规划：Extended Predictive Driver Model Score（EPDMS），聚合无责任碰撞（NC）、可行驶区域合规（DAC）、行驶方向合规（DDC）、交通灯合规（TLC）、自车进度（EP）、碰撞时间（TTC）、车道保持（LK）、历史舒适性（HC）和扩展舒适性（EC），按官方人类惩罚协议报告。

  • 关键数值：

- 未来几何预测：GeoWAM 在均值 Abs Rel 上达到 0.257（对比最强基线 Epona+DVGT 为 0.274），均值 δ<1.25 从 0.655 提升到 0.754，在 2–4 秒显著更优，仅 1 秒阈值精度略低于 Epona+DVGT。

- navtest 规划：GeoWAM EPDMS 达 90.2，为表中最高，较 DVGT-2 初始化提升 0.6 分，并匹配最佳 DDC 和 TLC 得分。

- navhard 两阶段：原文表格展示了 CV、Ego MLP、LTF、DriveVLA-W0、DriveLaW、DVGT-2、LTFv6† 等方法的两阶段分数；GeoWAM 与部分方法的完整单组件数值在提供的表格文本中未完整列出，原文未报告 GeoWAM 在 navhard 上的最终 EPDMS 数值。

  • 对比方法：未来几何预测对比 VGGT-World、Epona+DVGT、Cosmos 3+DVGT；规划对比 Transfuser、Hydra-MDP++、DriveSuprim、ARTEMIS、DiffusionDrive、WoTE、DriveVLA-W0、PWM、DriveLaW、DVGT-2、EponaV2 等。
  • 开环、闭环、仿真条件：navtest 规划为开环评估，navhard 采用两阶段伪闭环评估（第一阶段为原始场景，第二阶段为合成反应式场景）；未来几何预测为开环评估。
