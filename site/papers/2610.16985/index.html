AUGUstus: Autonomous Driving VLA Model with Unified Generation and Understanding

2026-10-12 · 原文 · 翻译 · 2610.16985

论文面向端到端自动驾驶的视觉-语言-动作（VLA）模型规划任务，目标是在保持低延迟可部署的同时，利用视觉语言模型（VLM）的空间理解能力生成安全、可解释且准确的轨迹。 应用场景为基于相机视频的端到端驾驶规划，输入包括相机视频、自车状态、路线指令和历史轨迹。 研究问题在于现有 VLA 方法难以兼顾 VLM 理解与低延迟控制：回归头方法退化为视觉-动作（VA）模型，缺乏动作分布且难以做强化学习后训练；扩散/流匹配专家未充分利用 VLM 空间理解，产生不安全、不可解释的动作；自回归方法串行生成思维链（CoT）和动作 token，延迟高、难以实时部署。

Card 02 论文概述

论文概述

  • 论文面向端到端自动驾驶的视觉-语言-动作（VLA）模型规划任务，目标是在保持低延迟可部署的同时，利用视觉语言模型（VLM）的空间理解能力生成安全、可解释且准确的轨迹。
  • 应用场景为基于相机视频的端到端驾驶规划，输入包括相机视频、自车状态、路线指令和历史轨迹。
  • 研究问题在于现有 VLA 方法难以兼顾 VLM 理解与低延迟控制：回归头方法退化为视觉-动作（VA）模型，缺乏动作分布且难以做强化学习后训练；扩散/流匹配专家未充分利用 VLM 空间理解，产生不安全、不可解释的动作；自回归方法串行生成思维链（CoT）和动作 token，延迟高、难以实时部署。
Card 03 核心贡献

核心贡献

  • 提出 AUGUstus，将基于扩散（流匹配）的动作生成与自回归 CoT 理解统一在单个 Transformer 中，共享表示保留 VLM 空间理解以服务动作生成，避免 VLA 退化为 VA。
  • 提出 AUGUstus-mode，采用“动作先生成、CoT 后生成”的顺序，使 CoT 在训练时监督并改善动作生成，而推理时只需输出动作，从而保持低延迟。
  • 提出 AUGUstus-GRPO，一种联合优化连续动作与自回归 CoT 的统一 GRPO 算法，结合使用闭式高斯重要性采样比与 KL 项的 JaT-GRPO 和 token 级 CoT-GRPO，使推理流服务于规划。
  • 在多个自动驾驶基准上验证了方法的有效性与通用性，并通过大规模训练、内部驾驶数据集验证和实车部署展示了实际可扩展性。
Card 04 方法描述

方法描述

  • 所属模块：端到端自动驾驶规划，统一生成（动作）与理解（CoT）的 VLA 框架。
  • 输入传感器：相机视频 S，另含自车状态 E、路线指令 C 和历史轨迹 H，共同构成驾驶上下文 c=(S,E,C,H)。
  • 场景表示：连续目标轨迹 x0∈R^{T×3}，每个路点由平面位置和朝向表示；CoT 为描述关键物体边界框与未来位置的自回归 token 序列。
  • 模型结构：单个共享 Transformer；上下文 token 为因果注意力，动作 token 构成双向注意力块并关注完整上下文及彼此，CoT token 为因果注意力并额外关注完整动作块，而动作 token 不能关注 CoT token。
  • 关键技术：条件流匹配采用 x0 参数化，模型直接预测干净轨迹而非速度，支持少步与真正的单步策略；SFT 损失联合流匹配动作重建与教师强制 CoT 似然；AUGUstus-GRPO 采用两阶段 RL（Stage I 以 PDMS 为规划奖励关注进度，Stage II 以终点与安全奖励关注安全），两分支共享归一化组相对优势；JaT-GRPO 基于线性条件流路径与反向 SDE 推导闭式对数比与 KL。
  • CoT 设计：实验发现描述场景中其他智能体具体位置与未来朝向的“预测型” CoT 对动作最有益。

Card 06 评估与结果

评估与结果

  • 评估基准：闭环 NAVSIMv1、NAVSIMv2；开环 nuScenes；另有内部 1,000 km 数据评估与实车初步部署。
  • 评估指标：NAVSIMv1 使用 NC、DAC、EP、TTC、Comf.、PDMS；NAVSIMv2 使用 NC、DAC、DDC、TLC、EP、TTC、LK、HC、EC、EPDMS；nuScenes 使用平均 L2 误差与平均碰撞率。
  • 关键数值：NAVSIMv1 上 1 步去噪达 94.0 PDMS、3 步去噪达 94.6 PDMS（NC 98.9、DAC 98.9、EP 91.9、TTC 97.1、Comf. 100.0）；NAVSIMv2 上 EPDMS 为 90.7；nuScenes 上平均 L2 误差 0.27 m、平均碰撞率 0.05%，均为对比方法中最优；实车部署达到 12 Hz。上述 NAVSIM 结果均为无 scorer 模块条件下取得。
  • 对比方法：包括 Human、端到端小模型（TransFuser、PARA-Drive、Hydra-MDP、WoTE）、回归式 VLA 规划器（ImagiDrive、PWM、DriveVLA-W0）、自回归 VLA 规划器（AutoVLA、AdaThinkDrive、AutoDrive-R²、AutoDrive-P³、VGGDrive）、流匹配 VLA 规划器（ReCogDrive）等。
  • 评估条件：NAVSIM 为闭环评估，nuScenes 为开环评估，另有仿真/基准之外的内部数据与实车初步验证。
