OPTED: On-Policy Fine-Tuning for End-to-End Driving using a Render-Free Teacher

2026-09-17 · 原文 · 翻译 · 2609.20756

论文针对自动驾驶中的端到端驾驶策略，研究其闭环部署时的后训练（post-training）问题。 端到端策略通常以行为克隆（BC）在人类演示上开环预训练，但闭环执行时误差会累积，使车辆进入训练数据分布之外的状态，增加安全风险。 闭环后训练可缓解该问题，但对基于传感器的策略而言需要昂贵的仿真渲染；直接 RL 后训练样本效率极低。 OPTED 将强化学习与端到端策略后训练解耦：在无渲染的向量化仿真器中用 RL 训练特权教师，再由教师对学生在闭环仿真中的自身 rollout 进行监督。 目标是在最小化渲染交互的前提下恢复并提升闭环性能，同时保留学生预训练的人类数据先验。

Card 02 论文概述

论文概述

  • 论文针对自动驾驶中的端到端驾驶策略，研究其闭环部署时的后训练（post-training）问题。
  • 端到端策略通常以行为克隆（BC）在人类演示上开环预训练，但闭环执行时误差会累积，使车辆进入训练数据分布之外的状态，增加安全风险。
  • 闭环后训练可缓解该问题，但对基于传感器的策略而言需要昂贵的仿真渲染；直接 RL 后训练样本效率极低。
  • OPTED 将强化学习与端到端策略后训练解耦：在无渲染的向量化仿真器中用 RL 训练特权教师，再由教师对学生在闭环仿真中的自身 rollout 进行监督。
  • 目标是在最小化渲染交互的前提下恢复并提升闭环性能，同时保留学生预训练的人类数据先验。
Card 03 核心贡献

核心贡献

  • 提出 OPTED：一种简单通用的驾驶策略闭环后训练方法，特权教师经无渲染 RL 训练后为学生在视觉输入闭环 rollout 上提供监督，桥接教师与学生的不同输出表示，且不限制学生架构或输出表示。
  • 将 OPTED 应用于两种架构不同的公开模型 TransFuser（LTFv6）与 VaVAM，在 AlpaSim 仿真器结合真实日志的神经重建上进行微调，两轮微调后闭环场景得分分别提升 1.6 倍与 9.5 倍，开环位移误差相对人类轨迹仅有适度增加。
  • 在 PufferDrive 上基于 WOMD 的向量化策略控制实验中，展示 OPTED 以约三个数量级更少的闭环仿真交互达到与 RL 微调相当的闭环性能，且比 RL 微调更接近人类先验。
  • 刻画学生输出表示与教师设计对蒸馏学生策略性能的影响，并对控制器选择等失效因素进行了分析。
Card 04 方法描述

方法描述

  • 所属模块：端到端驾驶策略的闭环后训练（规划层面），涉及特权教师训练与 on-policy 蒸馏两个阶段。
  • 输入传感器：教师使用特权向量化输入（自车运动学、周围智能体位姿与速度、局部道路图）；学生使用相机图像（LTFv6 另用自车速度与加速度；VaVAM 用单前视相机）。
  • 场景表示：教师为向量化表示（HD 地图折线与智能体包围盒）；学生在 AlpaSim 中基于 NuRec 3D 高斯泼溅对真实驾驶日志的神经重建进行渲染。
  • 模型结构：教师用 PPO 在 PufferDrive 2.0 无渲染仿真器中训练，将原最大池化 MLP+LSTM 策略改为注意力编码器，自车嵌入分别对智能体 token 与地图元素 token 交叉注意力，无循环结构；学生为预训练模型，仅训练规划解码器、冻结骨干，以缓存骨干潜变量。
  • 关键技术：教师奖励在稀疏终局奖励基础上加入按车道对齐门控的密集路线进展奖励（式 2）；学生对自身闭环 rollout 的状态由教师从该状态以平均动作在自行车模型与日志回放交通下展开 K 步，再重采样为学生预测时刻的目标轨迹；蒸馏损失按学生输出头匹配，动作头用前向 KL（式 3），轨迹回归头用加权 L1（式 4）；训练使用有界 FIFO 缓冲区保存近期 rollout，迭代交替收集与更新。
  • 原文未报告：教师注意力编码器的层数、隐藏维度等具体结构细节，以及学生解码器的具体网络层配置。
Card 05 数据集与资源

数据集与资源

  • 数据集：PAI-AV NuRec 公开数据集（1669 个训练场景，441 个公开挑战划分评估场景）；nuPlan（学生预训练与开环 ADE 评估）；nuScenes（VaVAM 相关预训练数据）；OpenDV（VaVAM 预训练）；CARLA（LTFv6 预训练）；WOMD（向量化学生实验，80000 训练场景与 10000 测试场景，其中 PufferDrive 评估因数据格式不兼容仅用 420 个场景子集）。
  • 仿真器：AlpaSim（渲染 NuRec 重建，10 Hz，20 秒片段，非反应式日志回放交通）；PufferDrive 2.0（无渲染向量化仿真器）。
  • 模型规模：学生策略参数量约 62–356M；作为参照的 VLA 模型为 5.1–10B。
  • 训练资源：8 卡 NVIDIA H100 节点（一次 OPTED 迭代：采集 32 个 20 秒场景 524 秒，教师标注 13.5 秒，512 缓冲场景梯度更新 6 秒，两轮 epoch 共 17 小时）；教师在一张 NVIDIA RTX 4090 上训练约 24 小时，另加 6 小时 PAI-AV NuRec 适配；教师训练用 PPO 共 2B 环境交互、22M 闭环 episode；教师适配 PAI-AV 继续 PPO 500M 无渲染交互。
  • 实车平台：原文未报告，实验均在仿真中进行。
Card 06 评估与结果

评估与结果

  • 评估基准：AlpaSim 在 NuRec 公开评估划分的闭环评估与 AlpaSim 端到端挑战排行榜（私有场景集）；PufferDrive 上 WOMD 测试划分的闭环评估。
  • 评估指标：AlpaSim 场景得分（Scene score）、km/infr.（每违规行驶公里数）、at-fault 碰撞率、off-road 率、corridor 出界、路线进展、开环 ADE@3s（NuRec 与 nuPlan）、单步规划推理延迟；WOMD 实验另用绝对纵向/横向 jerk 与人类分布间的 Wasserstein-1 距离。
  • 关键数值：LTFv6 场景得分从 26.5 提升至 41.8（+OPTED），km/infr. 从 0.23 提升至 0.43，ADE（NuRec/nuPlan）为 1.67/1.22；VaVAM 场景得分从 3.9 提升至 37.1，km/infr. 从 0.08 提升至 0.25，ADE 为 6.20/3.40。对照 BC 微调：LTFv6 12.8、VaVAM 25.2；RoaD-recovery：LTFv6 32.9、VaVAM 30.7。挑战排行榜：LTFv6 从 25.1 提升至 32.2，VaVAM 从 6.7 提升至 35.8。教师自身场景得分 64.8%、0.78 km/infr.，以原生动作执行时达 1.75 km/infr.。VLA 参照：Qwen-Drive 1.0 场景得分 25.4、km/infr. 0.21、延迟 1181 ms；Alpamayo 1.5 为 55.2、0.92、940 ms。控制器分析中，加入摩擦圆约束使 OPTED 后 VaVAM 场景得分从 37.1 提升至 50.6。向量化实验中，OPTED 在 6.8k episode 达到教师场景得分的 95%，RLFT 需 6.2M；两者最终收敛到教师水平（OPTED 160k episode 时 93.0，RLFT 22M 时 93.9）。
  • 对比方法：Base 发布检查点、BC 开环微调、RoaD-recovery（RoaD 恢复模式在 CAT-K 闭环 SFT 框架内的复现）、直接 RL 微调（RLFT）、Qwen-Drive 1.0 与 Alpamayo 1.5 两个 VLA 参照。
  • 实验条件：所有结果均为三个训练种子在最终检查点的均值与标准差（Base 与参照策略仅有单一检查点，改为三次独立评估运行统计）；端到端实验为 AlpaSim 中的闭环仿真评估，并报告开环 ADE；WOMD 实验为 PufferDrive 中的向量化闭环仿真评估。
