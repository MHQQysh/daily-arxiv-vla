Card 02 论文概述

论文概述

  • 本论文解决端到端自动驾驶中传统级联“感知到规划”流水线带来的信息瓶颈问题。

Card 03 核心贡献

核心贡献

  • 提出 MOJITO，一个完全统一的多模态端到端驾驶框架，通过新颖的 Modal Joint Attention 机制让动作 token 与密集的传感器特征在每个块中深度交互。
  • 开发了简化、无锚点的架构，消除了对辅助监督和预定义轨迹锚点的依赖，与标准 ViT 和 DiT 设计保持一致。
  • 在 NAVSIM-v1 和 NAVSIM-v2 基准上取得领先性能，超越现有强基线方法。
  • 通过大量实验展示了 MOJITO 在可扩展性、指令跟随和多样化轨迹生成方面的强大能力。
Card 04 方法描述

方法描述

  • 所属模块：端到端规划框架，包含图像分支、LiDAR 分支和动作规划分支。
  • 输入传感器：多视角相机图像（3 个下采样视角，拼接为 1024×256 分辨率）和原始 LiDAR 点云。
  • 场景表示：图像分成 16×16 图像块；LiDAR 采用 BEV Grid Patchify（PillarGroup）tokenizer，将点云划分为 32×32 固定网格，选择前 512 个非空 pillar，每个 pillar 采样 64 个点。
  • 模型结构：三个平行的 Transformer 分支，每分支 12 个块，隐藏维度 384；图像分支采用 DINOv3-S+，LiDAR 分支采用 Uni3D-S，动作规划器采用 Diffusion Transformer (DiT)。
  • 关键技术：Modal Joint Attention 机制，在各块中将图像、LiDAR 和动作 token 拼接后通过共享多头自注意力处理，实现多模态的双向信息流动；扩散步嵌入通过 MLP 结合高层命令，使用 Adaptive Layer Normalization (adaLN) 注入动作 token；训练目标为预测真实轨迹的扩散损失。

Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM-v1 navtest、NAVSIM-v2 navtest、NAVSIM-v2 navhard（两阶段协议）。
  • 评估条件：非反应式闭环评估。
  • 评估指标：PDMS（含 NC、DAC、TTC、Comf.、EP）、EPDMS（增加 DDC、TLC、LK、HC、EC）。
  • 关键数值：NAVSIM-v1 navtest 达 88.9 PDMS（NC 98.6、DAC 96.9、TTC 94.5、Comf. 100、EP 83.5），超过 DiffusionDrive（88.1）和 WoTE（88.3）；NAVSIM-v2 navtest 达 88.4 EPDMS，超过 DiffusionDriveV2（85.5）、ARTEMIS（83.1）、DriveSuprim（83.1）；NAVSIM-v2 navhard 两阶段达 29.0 EPDMS，超过 GuideFlow（27.1）、DiffusionDrive（24.2）、LTF（23.1）。
  • 对比方法：Constant Velocity、Ego Status MLP、UniAD、Transfuser、DRAMA、VADv2、Hydra-MDP、DiffusionDrive、WoTE、ReCogDrive、AutoVLA、AdaThinkDrive、Hydra-MDP++、DriveSuprim、ARTEMIS、DiffusionDriveV2、GTRS-DP、GuideFlow。
  • 消融实验：相机-only 86.8 PDMS；加入 FPS+KNN LiDAR tokenization 后降至 86.1；使用交叉注意力替代自注意力降至 85.7；完整配置（PillarGroup + 自注意力）达 88.9 PDMS。
  • 可扩展性研究：块数从 3 增至 12，PDMS 从 80.5 提升至 88.9，模型大小从 33.4M 增至 127M。
  • 推理延迟：单块 H200 GPU、BF16 精度、2 步扩散下为 187.65ms，对比 Transfuser 88.15ms、DiffusionDrive 123.22ms、ReCogDrive 331.68ms。
