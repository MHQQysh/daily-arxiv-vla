Card 02 论文概述

论文概述

  • 论文任务：针对自动驾驶中 LiDAR 语义分割网络的对抗性攻击。
  • 应用场景：LiDAR 点云经球面投影得到的 2D range image 空间的语义分割。
  • 研究问题：现有对抗攻击大多针对图像分类或 3D 点云分割，2D range image 空间的无约束对抗样本（UAE）研究尚属空白。论文提出首个基于扩散模型的无约束对抗攻击，用于 2D range-image 语义分割。
Card 03 核心贡献

核心贡献

  • 提出首个针对 LiDAR range image 语义分割的扩散模型无约束对抗攻击，利用分割损失梯度引导潜在扩散模型的反向去噪过程。
  • 攻击强度可通过引导尺度（guidance scale）调整，实现可控的模型性能退化。
  • 生成的对抗样本具有良好的跨分割网络架构的可迁移性（transferability）。
  • 生成的对抗场景在统计上保持与真实 LiDAR 数据的接近性，保留数据流形上的真实性，同时诱导结构化分割错误。
Card 04 方法描述

方法描述

  • 所属模块：感知安全（对抗攻击 / 生成模型）。
  • 输入传感器：LiDAR（3D 点云，投影为 2D range image，尺寸 64×1024）。
  • 场景表示：2D range image（球面投影），作为扩散模型的生成目标。
  • 模型结构：基于预训练的潜在扩散模型（sem2lidar 条件变体）、VQ-VAE 编码器-解码器、DDIM 采样器、预训练冻结的分割网络（surrogate，如 CENet 或 RangeNet++）。
  • 关键技术：训练无关引导（Training-Free Guidance, TFG），在反向去噪过程中通过分割损失（逐像素交叉熵）的梯度对 DDIM 更新后的潜在表示施加对抗引导，使用 L2 归一化的引导步长；引导在轨迹的指定起始比例后激活。支持无目标（untargeted）和有目标（targeted）两种攻击模式。原文未报告开环/闭环控制等自动驾驶规划相关信息。

Card 06 评估与结果

评估与结果

  • 评估基准：SemanticKITTI 数据集（序列 08，1024 个样本条件生成）；开环评估（生成样本的分割性能），非闭环或实车。
  • 评估指标：相对 mIoU 下降（WB drop % 与 Transfer drop %）、逐类 IoU、L∞、MSE、Chamfer Distance（CD）、Fréchet Range Image Distance（FRID）。
  • 关键数值：Ours(s=3) WB drop 25.7%、Transfer drop 18.7%、CD 0.52、FRID 98.6；Ours(s=6) WB drop 46.8%、Transfer drop 40.1%、CD 1.02、FRID 108.6；Ours(s=10) WB drop 64.2%、Transfer drop 58.4%、CD 1.38、FRID 136.1。与 FGSM (ε=0.120) 相比，Ours(s=10) FRID 136.1 vs 207.5、CD 1.38 vs 2.39；与 SegPGD (ε=0.004) 相比，Ours(s=6) WB drop 46.8% vs 53.3%、Transfer drop 40.1% vs 21.7%、FRID 108.6 vs 106.9。
  • 对比方法：FGSM、SegPGD（norm-bounded）；Ours 提供不同的“有效性-真实性”权衡，在相近白盒强度下转移性更优。
  • 条件：开环生成评估（未提及闭环或实车测试）。
