Card 02 论文概述

论文概述

  • 任务：面向自动驾驶，利用对周围车辆换道意图的预测来改进自车决策，并评估由此带来的乘坐舒适性。
  • 应用场景：车辆合流/加塞风险场景——目标车辆接近前车后向自车所在车道实施风险换道（CARLA 仿真）。
  • 研究问题：换道预测带来的提前响应，究竟应转化为纵向制动还是横向避让；两类预测驱动策略在安全性、响应时机、车辆运动与振动舒适性上与纯反应式驾驶相比有何差异。
Card 03 核心贡献

核心贡献

  • 将基于知识图谱嵌入与贝叶斯推断的换道预测模型接入自车决策流程，在目标车实际开始换道前即把它分配到预期目标车道。
  • 提出基于车道风险评分（各车道相关车辆正有限 TTC 倒数之和）的选道决策，并结合 IDM–PID（车道保持/纵向）与 MPC（换道轨迹跟踪）执行。
  • 在 CARLA 中对比三种策略：反应式驾驶、预测驱动纵向动作、预测驱动横向动作，覆盖安全性、响应时机、加速度与 jerk。
  • 引入基于 ISO 2631-1 的水平振动加权 RMS 加速度指标，在安全性之外给出乘坐舒适性的指示性评估。
  • 揭示安全与舒适权衡：横向避让总体运动最平顺，但会引入额外横向运动；纵向制动减少纵向冲击但幅度有限。
Card 04 方法描述

方法描述

  • 所属模块：换道意图预测 + 决策规划 + 乘坐舒适性评估。
  • 输入传感器：原文未报告具体传感器配置；预测模型使用 12 个特征——横向速度与加速度、车道身份、车道线偏移、车头时距、与周围车辆的 5 个 TTC 值、吸引力得分最高的车道与最大前向间隙车道。
  • 场景表示：数值输入被转换为语言类别并表示为知识图谱三元组；采用 TransE（基于 AmpliGraph 实现）学习 100 维嵌入，再由贝叶斯推断输出左换道、车道保持或右换道。
  • 决策结构：按 \(R_{\ell}=\sum_{j\in\mathcal{N}_{\ell}}1/\mathrm{TTC}_{\ell j}\) 计算各车道风险（仅计正的有限接近 TTC），在车道可用约束下选择风险最低车道；车道保持时用 IDM 计算期望纵向加速度、PID 生成油门/制动；换道时用 MPC 跟踪五阶换道轨迹，机动之外的纵向运动由 IDM–PID 控制。
  • 反应式基线：同样使用 IDM–PID 纵向控制，但仅在目标车进入自车车道后才予以考虑，因而响应更晚。
  • 舒适性评估：对纵向、横向加速度施加 ISO 2631-1 的 \(W_d\) 频率加权（phonometry 3.3.0 实现），按式(1)合成加权 RMS 加速度 \(a_{v,h}\)，评估窗口为反应式碰撞前 3 s；原文注明未完整表征垂向、转动及高频振动，属指示性水平舒适估计。

Card 06 评估与结果

评估与结果

  • 评估基准：CARLA 中目标车风险换道合流场景，对比反应式驾驶、预测驱动纵向制动、预测驱动横向避让。
  • 评估指标：碰撞结果、最小 TTC、制动响应时间、纵向/横向加速度与 jerk 的峰值及 RMS、组合 RMS、ISO 2631-1 加权 RMS 加速度 \(a_{wx}\)、\(a_{wy}\)、\(a_{v,h}\)。
  • 预测时机：所选场景中提前约 2.5 s 预测到目标车跨越车道线（其他场景曾展示 3–4 s）；预测策略比反应式提前约 3.5 s 制动，而反应式仅在碰撞前 0.97 s 制动，多出约 2.5 s 响应时间。
  • 安全性：反应式发生碰撞，最小 TTC 为 0.015 s；预测纵向最小 TTC 为 3.9 s；预测横向最小 TTC 为 1.3 s（原文指出 TTC 不反映横向间距，低值不必然意味着碰撞）。两种预测策略在评估记录中均无碰撞。
  • 碰撞相关运动：反应式碰撞产生 18.8 m/s² 峰值纵向减速度与 41.0 m/s³ 纵向 jerk。
  • 碰撞前 3 s（排除碰撞诱发运动）：峰值减速度 6.427 / 4.406 / 0.578 m/s²（反应式/预测制动/横向避让），相比反应式分别降低 31.5% 与 91.0%；峰值 \(\|a_y\|\) 0.131 / 0.130 / 0.530 m/s²；峰值 \(\|j_x\|\) 11.853 / 4.116 / 1.087 m/s³；\(A_{xy,\mathrm{RMS}}\) 3.366 / 2.659 / 0.451 m/s²；\(J_{xy,\mathrm{RMS}}\) 4.674 / 1.929 / 0.569 m/s³。
  • 组合 RMS 对比：相对反应式，预测制动使组合 RMS jerk 降低 58.7%，横向避让降低 87.8%；两种预测策略之间，横向避让使组合 RMS 加速度降低 83.0%、组合 RMS jerk 降低 70.5%。
  • ISO 加权结果：\(a_{v,h}\) 为 1.52 / 1.42 / 0.53 m/s²（反应式/预测制动/横向避让），横向避让相对前两者分别降低 65% 与 63%；按 Annex C 近似区间，前两者落在“uncomfortable”与“very uncomfortable”重叠区，横向避让落在“a little uncomfortable”与“fairly uncomfortable”重叠区。
  • 条件说明：全部结果为闭环仿真结果，无开环评测与实车验证；作者指出需在更多交通场景与座椅振动实测下进一步验证泛化性与舒适性结论。
