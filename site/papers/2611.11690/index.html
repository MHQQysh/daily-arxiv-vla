论文概述

  • 任务：构建物理自驱动实验室（SDL）测试台，在最小闭环颜色配方任务中，自主调配红、黄、蓝染料与水的混合液，以匹配目标吸光度光谱。

Card 03 核心贡献

核心贡献

  • 搭建并集成了由商用实验室机器人（Trilobot）、商用吸光度读板仪（Absorbance 96 Automate）与可替换优化器组成的物理闭环测试台，实现从移液、微孔板操作到光谱测量、模型更新与下一次配方选择的全程无人干预。
  • 在六个独立运行批次（campaign）中实现累计超过 24 小时的连续无人值守闭环运行，每批次 48 次闭环迭代、约 4 小时。
  • 在该平台上验证最小闭环发现任务：系统平均 RMSE 达 9.95×10⁻³ OD，六批次中五批次在测量误差范围内匹配目标光谱。
  • 在同一实验回路内比较 BO 与 LLM 智能体优化，报告智能体在三个目标上均以更少迭代匹配目标（最多减少 52%），并在 BO 48 次迭代内未匹配的目标 3 上于 11 次迭代内收敛。
  • 提出该商用组件测试台可作为评估既有与新兴 AI 决策策略（含 LLM 引导优化）的参考物理平台。
Card 04 方法描述

方法描述

  • 所属模块：硬件自动化层（机器人移液、孔板搬运、读板测量）与 AI 决策层（可替换优化器），二者构成设计—构建—测试—学习（DBTL）闭环。
  • 输入传感器：Byonoy Absorbance 96 Automate 吸光度微孔板读板仪，使用其已安装滤光片在 400 nm、600 nm、700 nm 三个波长测量吸光度，光度范围 0.0–4.0 OD；原文未报告其他传感器。
  • 场景表示：输入为四种液体体积 x=(x₁,x₂,x₃,x₄)（红、黄、蓝染料与水，单位 µL），受约束 x₁+x₂+x₃+x₄=250 µL 且 xᵢ≥0；输出为目标三维吸光度向量 y=(y₁,y₂,y₃)；优化目标为 min‖S(x)−y‖₂。原文指出三个波长不能唯一确定完整光谱（存在同色异谱），但因现有仪器限制仍采用三波长表示。
  • 模型结构：

- BO：使用 BoTorch 实现，对三个波长各拟合一个独立高斯过程（RBF 核、GaussianLikelihood 噪声模型），将输入参数降为三种染料体积（和不大于 250），水体积取剩余量；前 12 个点随机采样，其后用 qLogExpectedImprovement 采集函数逐点选择 36 个点；目标函数为模型三输出与目标间负均方误差；超参数为 num_restarts=32、raw_samples=512、batch_limit=5、max_iter=200。

- 智能体优化：使用 Claude Opus 5 模型（thinking effort 设为 “high”，经 Claude Messages API），单次运行维持一段连续对话容纳全部 48 次迭代上下文；提供 run_python 工具在本地 Python 沙箱（NumPy、SciPy、pandas、scikit-learn、BoTorch）中执行代码，并通过 propose_setting 提交下一配方；提示词以黑箱方式给出（仅用 x、y 变量名），不告知颜色配方任务，且禁止外部工具（如网络搜索）与访问历史实验数据以保证与 BO 公平比较。

  • 关键技术：商用仪器的 Python API 集成、机器人末端执行器自动换装（移液与抓取）、孔内反复吸打混匀、基于器件测量精度规格的“误差带内匹配”判定、智能体自主选择并拟合多种模型（线性模型、Hill 曲线、幂律响应曲线、Michaelis–Menten 曲线）、近期加权、漂移检查、输出通道噪声相关性分析与蒙特卡洛采样策略。
  • 原文未报告：智能体底层模型的参数规模、训练细节与网络结构。

Card 06 评估与结果

评估与结果

  • 评估基准：最小闭环颜色配方任务，三个随机生成的目标吸光度光谱（目标 1、2、3）；以读板仪测量精度规格定义误差带（400 nm：0.0–2.0 OD 内 ≤1.5%+0.010 OD，2.0–3.0 OD 内 ≤3.0%+0.010 OD；≥450 nm：0.0–2.0 OD 内 ≤1.0%+0.010 OD，2.0–3.0 OD 内 ≤1.5%+0.010 OD）。
  • 评估指标：三波长吸光度的 RMSE（OD）；达到误差带所需迭代次数；单次候选生成耗时与 API 成本。
  • 关键数值：

- 六批次平均 RMSE 为 9.95×10⁻³ OD，六批次中五批次在测量误差内匹配目标。

- 各批次最终最优 RMSE：BO 目标 1 为 5.47×10⁻³ OD、目标 2 为 4.00×10⁻³ OD、目标 3 为 2.92×10⁻² OD；智能体目标 1 为 2.98×10⁻³ OD、目标 2 为 8.08×10⁻³ OD、目标 3 为 1.00×10⁻² OD。

- 达到误差带的迭代次数：BO 目标 1 为 21、目标 2 为 34、目标 3 未达到（48 次内失败）；智能体目标 1 为 10、目标 2 为 23、目标 3 为 11。

- 相对改进：目标 1 减少 52%，目标 2 减少 32%，目标 3 由 BO 失败转为 11 次迭代收敛。

- 时间与成本：智能体平均 19 秒/次生成候选，BO 平均 16 秒/次；物理回路约 4.5 分钟/次；智能体三次运行 API 总费用 20.83 美元。

  • 对比方法：传统贝叶斯优化（BoTorch + 三个独立高斯过程 + qLogExpectedImprovement）与 LLM 智能体优化（Claude Opus 5 + Python 沙箱 + 连续上下文），在同一物理闭环中对比。
  • 实验条件：全部为实物闭环实验，累计超过 24 小时无人值守运行，每批次 48 次迭代、约 4 小时；原文未报告开环评估或仿真评估结果。
