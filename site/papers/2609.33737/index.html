MomWorld: Momentum-Aware Latent World Model for Long-Horizon Autonomous Driving

2026-09-27 · 原文 · 翻译 · 2609.33737

论文针对自动驾驶中的长时域规划任务，目标是让自动驾驶车辆预测未来场景演化与潜在风险，从而在复杂交互中做出安全稳定的决策。 论文关注长时域规划中运动趋势难以从观测历史传播到未来、单潜在状态长展开会衰减有效动力学、保留过时运动模式并干扰近端可靠规划等问题。 论文提出 MomWorld，一种面向长时域规划的动量感知潜在世界模型，将场景配置与运动趋势同时作为潜在状态联合向前传播，并通过 MoFlow 对基础轨迹进行动量条件化的流匹配细化。

Card 03 核心贡献

核心贡献

  • 提出 MomWorld，通过 Latent World Rollout（LWR）将观测历史与未来想象连接起来。
  • 提出 MoLWM，用于维护、更新和重置潜在动量以建模未来动力学，并构造 Future World Memory。
  • 提出 MoFlow，将预测的世界演化转化为有界、时域感知的轨迹修正，以支持稳定规划。
  • 在 NAVSIM、nuScenes 和 Bench2Drive 上进行了广泛评估，报告在 nuScenes 1–6 s 时域上相对 MomAD 平均碰撞率相对降低 12.2%。
Card 04 方法描述

方法描述

  • 所属模块：端到端自动驾驶框架，包含感知监督（Map/Det heads）、潜在世界建模、候选规划选择与轨迹细化；原文未报告该框架在完整自动驾驶系统中的具体部署模块划分。
  • 输入传感器：NAVSIM 设置中输入两帧相机图像和四次 LiDAR 扫描；nuScenes 使用 camera-only 设置；原文未报告其他传感器输入。
  • 场景表示：历史与当前多视角图像编码为 Scene Queries；MoLWM 使用场景状态 z_k ∈ R^D 与动量 p_k ∈ R^D 表示潜在驾驶世界；NAVSIM 中 D=256。
  • 模型结构：MomWorld 包含 Momentum-Aware Latent World Modeling（MoLWM）与 Momentum-Conditioned Flow Matching（MoFlow）。MoLWM 包含 History-Conditioned Initialization、Scene-Adaptive Momentum Dynamics（SMD）、Latent World Rollout（LWR）和 Future World Memory（FWM）。MoFlow 包含 Momentum-Guided Residual Flow（MGRF）与 Horizon-Aware Residual Fusion（HARF）。
  • 关键技术：SMD 预测保留门 ρ_k、重置门 g_k 和动量提案 u_k，并通过式(3)更新未来动量；LWR 通过式(4)递归更新状态，训练时使用未来观测编码为 detached target Scene Queries，推理时不使用未来观测；FWM 通过式(6)-(7)构造未来记忆 token 并自注意力聚合；MoFlow 在 p_0 与 M_t 条件下学习残差向量场，训练目标为式(10)，推理时用 J 步显式 Euler 积分；HARF 对残差进行裁剪并按 γ_k 从 0.05 到 1.0 线性增加长时域修正强度。
  • 训练目标：世界预测损失为 L_world = L_future + 0.5 L_p + 0.2 L_aux；MoFlow 损失为 L_MoFlow = L_FM + L_τ；完整目标为 L = L_percep + L_plan + L_world + L_MoFlow。

Card 06 评估与结果

评估与结果

  • 评估基准：nuScenes 官方 train/validation split；NAVSIM v1 navtest 共 12,146 个索引场景；NAVSIM v2 navhard 两阶段伪仿真；Bench2Drive 结果在附录。
  • 评估指标：nuScenes 报告 horizon-wise L2 与 predicted collision rate（越低越好），TPC 衡量连续轨迹预测的数据集级欧氏差异；NAVSIM v1 报告 PDMS 及其组件；NAVSIM v2 报告 EPDMS 与 navhard 分阶段分解（越高越好）。
  • 关键数值：6 秒 nuScenes 规划中，MomWorld 平均 L2 为 1.17 m，平均碰撞率为 0.79%；1–6 s 各时域 L2 为 0.27、0.52、0.86、1.28、1.76、2.31 m，碰撞率为 0.02、0.17、0.42、0.83、1.36、1.97%。相对最佳先前平均 L2 1.37 m，降至 1.17 m；平均碰撞率相对最佳先前 0.79% 提升 8.1%。4–6 s TPC 为 0.93、1.19、1.46 m，平均 1.19 m，优于 MomAD 的 1.42 m。NAVSIM v1 navtest PDMS 为 90.2，比 DriveLaW 高 1.1 分。NAVSIM v2 navtest EPDMS 为 90.1，比 Latent-WAM 高 0.8 分。NAVSIM v2 navhard EPDMS 为 42.8。论文摘要报告在 6 秒规划时域上相对 MomAD 平均碰撞率降低 12.2%；正文另报告平均碰撞率相对先前最佳提升 8.1%，两者口径不同。
  • 对比方法：nuScenes 6 秒对比 UniAD、SparseDrive、MomAD、LAW、Epona、World4Drive、DIVER、GuideFlow；TPC 对比 UniAD、VAD、SparseDrive、MomAD；NAVSIM v1 对比 VADv2、TransFuser、TransFuser_mmt*、UniAD、PARA-Drive、DRAMA、Hydra-MDP、FUMP、DiffusionDrive、DIVER、DriveSuprim、GoalFlow、ReCogDrive-IL、AutoVLA、ReCogdrive、DriveWorld-VLA 等；NAVSIM v2 对比 TransFuser、DiffusionDrive、Latent-WAM、DriveLaW、World4Drive、VLA 方法及其他世界模型方法。
  • 条件：nuScenes 为 camera-only 开环规划评估；NAVSIM v1/v2 为非反应式伪仿真开环评估；FPS 报告使用 A100 用于 UniAD、RTX 3090 用于 LAW、RTX 4090 用于 SparseDrive、MomAD 和 GuideFlow；MomWorld 在 6 秒 nuScenes 上 FPS 为 7.2。原文未报告实车闭环评估结果。
