Card 03 核心贡献

核心贡献

  • 提出概率验证方法，在随机且不可控智能体下的最坏情况公式中量化 STL 违反率。
  • 将可行性修复建模为 Pareto 优化问题，直接刻画不同智能体特定目标之间的权衡。
  • 在 MPC 中采用采样最坏情况公式，并将 STL 规格编码为 MILP 约束。
  • 通过独立验证集给出 STL 违反概率的概率证书，无需显式分布模型。
  • 在两个自动驾驶案例研究中展示框架有效性，并报告了安全行为表现。

方法描述

  • 所属模块：模型预测控制（MPC）框架，包含基于采样的最坏情况 MPC-STL 优化、概率证书以及基于 Pareto 优化的可行性修复。

  • 场景表示：采用离散时间动态 x_{t+1}=f(x_t,u_t)；不可控智能体以联合采样轨迹 ω=(x̂^1_T,...,x̂^l_T) 表示，可从概率轨迹预测器获得或通过施加高斯噪声生成。
  • 模型结构：机器人动态在 MILP 编码中线性化；STL 规格使用 big-M 与二进制变量编码为 MILP 约束，支持否定、合取以及 always、eventually 等时序算子；原始优化为采样最坏情况 MPC，要求所有采样轨迹下的 STL 鲁棒性 ρ≥0。
  • 概率证书：定义真实 STL 违反概率 p_viol，在成功通过独立验证集后，以至少 1-β 置信度给出 p_viol ≤ ε，所需验证样本数满足 M ≥ ceil(log(1/β)/(-log(1-ε)))。
  • 可行性修复：对每条 STL 规格引入非负松弛变量 ξ_k，约束为 ρ(φ_k,x_T,ω^(n)) ≥ -ξ_k 且 0 ≤ ξ_k ≤ ξ̄_k；将各智能体代价 J_i 组成集体目标向量，形成 Pareto 优化问题。
  • 关键技术：采用 ε-约束方法保持 MILP 结构，选择一个主目标 J_p，其余目标施加上界 ε_i；构造均匀 ε 网格并求解 l·d^{l-1} 个子问题，过滤非支配解得到离散 Pareto 前近似，最终选择与名义控制 u^nom_T 偏差 L1 最小的解。
