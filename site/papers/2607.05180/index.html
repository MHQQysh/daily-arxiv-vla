VLM-CASE: Vision-Language Model Enabled Context-Adaptive Safety Envelopes for Anticipatory Safe Autonomous Driving

Card 02 论文概述

论文概述

  • 论文任务：在恶劣驾驶条件下（如雨、雪、雾、夜间等）保证自动驾驶的安全性。
  • 应用场景：结合车道保持和车辆跟随的自动驾驶任务。
  • 研究问题：解决现有自动驾驶系统在恶劣条件下缺乏人类驾驶员“预见性”的问题，即系统无法提前根据场景理解调整速度、跟车距离和转向，且其安全极限（如RSS参数）通常是固定离线标定的，无法适应变化的道路摩擦力和能见度。
Card 03 核心贡献

核心贡献

  • 提出了 VLM-CASE 框架，让 VLM 的场景理解直接设定车辆的形式化安全极限，而不是仅用于引导驾驶决策，从而赋予自动驾驶前瞻性安全能力。
  • 设计了上下文自适应安全包络，该包络由物理摩擦力和 RSS（责任敏感安全）约束共同定义，通过共享的摩擦力预算耦合纵向与横向安全约束。
  • 提出了异步架构，将秒级语义推理（VLM）与毫秒级安全约束控制（MPC）解耦，保证实时性。
  • 在闭环仿真中验证了该框架，表明在恶劣条件下引入预测性、类人谨慎驾驶行为（如雪地弯道前减速、夜间雨天保持更大车距）能显著提升安全性，并优于传统MPC基线和最新的VLM集成控制器。
Card 04 方法描述

方法描述

  • 所属模块：由 VLM 上下文推断模块、上下文参数映射模块和 MPC 控制器模块构成完整框架。
  • 输入传感器：前视摄像头图像。
  • 场景表示：VLM 输出离散语义上下文，包括道路表面（干/湿/雪）、天气（晴/大雨/浓雾）、时段（白天/夜晚）、照明辅助（无/部分/强），通过映射函数转换为轮胎-道路摩擦系数和前方可观测性两个连续参数。
  • 模型结构：

- VLM：采用 Qwen3-VL-8B 模型，使用 LoRA 进行监督微调，适配器秩为16，缩放因子为32，应用于最后十二个Transformer层的查询和值投影。

- 上下文自适应安全包络：由三个约束集的交集构成，包括基于共享摩擦预算的物理能力约束、考虑能见度的纵向安全跟车距离约束，以及面向车道保持的 RSS 横向安全规则。

- VLM-CASE-MPC：以运动学自行车模型为预测模型，在每一预测步施加安全包络约束，并在目标函数中加入弯道惩罚项以提前降低低摩擦路面弯道前的车速。

  • 关键技术：VLM 异步实时推理（每2秒更新一次）、上下文到参数的映射、基于 LoRA 的 VLM 微调，以及融合物理摩擦力上限与 RSS 保证的安全包络构建。

数据集与资源

Card 06 评估与结果

评估与结果

  • 评估基准：在 CARLA 的 Town03（城市）和 Town04（高速公路）地图上，使用闭环仿真评估，共 66 个场景、198 次评估运行。
  • 评估指标：场景完成率、VLM 上下文分类准确率（分字段和总体）及推理时间。
  • 关键数值：

- VLM 评估：零样本 Qwen3-VL-8B 总体准确率为 42.5%，经 LoRA 微调后总体准确率提升至 98.3%，推理时间约 1.18 秒。

- 控制器评估：VLM-CASE-MPC 完成所有试验，优于 Base MPC 和 VLM-MPC 基线。

  • 对比方法：Base MPC、VLM-MPC、Fixed-Envelope MPC 以及仅适应摩擦力或仅适应能见度两个变体。
  • 测试条件：全部为闭环仿真。实验分为三组：无前车驾驶（测试横向安全，不同摩擦系数）、恒速前车跟随（测试纵向安全，不同能见度）以及前车制动（综合恶劣条件测试）。
