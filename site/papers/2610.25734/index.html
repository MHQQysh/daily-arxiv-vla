Card 03 核心贡献

核心贡献

  • 提出“Think Densely, Act Sparsely”驾驶建模范式：在潜空间中先构建稠密世界理解，再生成稀疏动作，为 VLA 框架中的稠密信息损失问题提供原则性解决思路。
  • 提出高效且可解释的潜在专家认知链（Latent Expert Cognitive Chain），通过注入紧凑的任务特定潜变量 token，渐进式内化视觉表征（DINOv3）、语义结构（SAM3）与空间几何（DepthAnything3）知识。
  • 设计三个轻量级稠密感知能力头，分别用于表征对齐、交通相关语义分割与度量深度预测，并以课程式方式组织监督。
  • 面向轨迹预测设计混合公式，将离散运动基元检索与连续偏移精化相结合，以提升鲁棒性与精度。
  • 在多个自动驾驶基准上验证 LECDrive 对基础 VLM 性能的一致性提升，覆盖开环与闭环轨迹规划以及语言驱动的感知与预测任务。
Card 04 方法描述

方法描述

  • 所属模块：整体框架由 VLM 骨干（Qwen2.5-VL）、潜在专家认知链与稠密感知能力头三部分组成。
  • 输入传感器：nuScenes 系列基准使用当前帧六路环视相机图像（C=6）；NAVSIM 轨迹规划使用前左、前、前右三路前视相机（C=3）；轨迹规划任务还将自车状态与高层导航命令并入语言指令。
  • 场景表示：不依赖显式 3D 点云输入；通过注入任务特定潜变量 token 在 VLM 隐空间中构建稠密世界表征，并由感知头输出语义分割与度量深度等稠密预测。
  • 模型结构：在每一视角的视觉 token 之后插入三组紧凑任务特定潜变量 token（<DINO_TOKEN>、<SAM_TOKEN>、<DEPTH_TOKEN>，每组 n 个）；这些 token 经 VLM 的 28 层 Transformer 产生层级隐状态，从第 4、10、18、28 层按固定位置 ID 掩码抽取任务特定嵌入并跨层聚合（维度为 B×C·n×4·D），再送入对应稠密感知头。
  • 关键技术：三阶段认知链按“视觉表征→语义结构→空间几何”渐进组织，且各阶段并非独立多任务目标，而是相互依赖的潜空间推理链；训练采用标准交叉熵损失与三类稠密监督的联合目标，权重为 λ1=1、λ2=0.5、λ3=0.5、λ4=1.5。
  • 感知头细节：表征头通过 Pixel Shuffle 与线性投影将嵌入上采样为 2D 特征图，并以 MSE 对齐 DINO 特征；语义头以加权交叉熵监督六类交通相关语义（背景权重 0.2，其余类别 1.0）；几何头以掩码 Smooth L1 损失监督深度，仅在 0<深度≤60 的有效区域计算损失，并在生成深度伪标签时引入相机参数。
  • 轨迹输出形式：将轨迹数据聚类为 2048 个运动基元，把直接航点预测转化为离散运动基元检索加连续偏移精化的混合形式；具体细节原文称见附录 A.3。
  • 推理效率：原文强调该设计仅增加极少的推理开销，但未报告具体推理时延或吞吐数值。
