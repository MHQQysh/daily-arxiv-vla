Card 02 论文概述

论文概述

  • 面向自动驾驶多传感器视觉的下游微调任务，研究在物理传感器（RGB、LWIR、NIR、Event）与模型派生模态（Stereo Depth、Segmentation）混合、且模态稀疏可用的条件下，哪种预训练骨干权重迁移效果最好。

  • 应用场景：自动驾驶中语义分割与目标检测等传感器融合任务，包括雾、雨雪、恶劣光照等挑战条件。
Card 03 核心贡献

核心贡献

  • 系统评估多种预训练权重初始化（ViT、MAE、DINO、MultiMAE 及域内变体）在多传感器下游微调中的表现，发现现成 MultiMAE 是意外强健的基线，可有效迁移到其从未见过的模态；域内预训练主要在涉及非 RGB 模态时带来增量增益。
  • 构建大规模多传感器预训练集合，包含 16 个公开数据集、约 80 万样本、282 万张图像，覆盖 4 种硬件传感器模态与 2 种模型派生模态，作为研究物理传感器迁移的现实测试平台。
  • 针对物理传感器的稀疏样本改进标准 MultiMAE 预训练：测试面向稀疏样本的损失公式、评估用于模态对齐的编码器瓶颈、并引入稠密重建损失（SSIM、FFT）。
  • 发布 Base、Small、Tiny 三种规模的 多传感器预训练权重，以支持计算受限的机器人与自动驾驶平台上的传感器融合视觉，并公开基准工具与数据复现脚本。
Card 04 方法描述

方法描述

  • 所属模块：多模态掩码自编码预训练（以 MultiMAE 为直接基线并扩展），下游用于语义分割与目标检测的传感器融合微调。
  • 输入传感器：6 种模态——RGB、模型派生 Stereo Depth、LWIR、NIR、Event 流、Segmentation 掩码；样本模态稀疏，无样本包含全部模态。
  • 场景表示与预处理：ROS bag 数据抽取为标准图像/数组；用外参标定做空间对齐并裁剪到共同视场；异步传感器仅在 50ms 窗口内匹配；序列数据降采样到 3Hz–5Hz；Event 在图像时间戳前 50ms 窗口内生成 2D 帧，按 10ms 区间与正负极性编码为 C=10 通道；LWIR/NIR 使用 CLAHE 增强局部对比度；Stereo Depth 由校正后左右 RGB 通过 FoundationStereo 生成；宽度超过 800px 的图像切成 640px 宽的重叠竖直裁剪，保持原高度。
  • 模型结构：每个模态有独立 tokenizer 将输入 patch 化并投影到共享嵌入维度，加学习位置编码；仅保留约 1/6 token（通过 Dirichlet 分布随机变化各模态保留比例）；稀疏可见 token 拼接后送入共享 ViT 编码器；各模态独立解码器以可见 patch 与学习 mask token 为 Query、编码器输出为 Key/Value 做 cross-attention 重建。
  • 关键技术改动：输入空间扩展到 6 种模态；采用每样本固定 98 token 的预算而非严格掩码比例，以应对样本间传感器可用性不一致；每个可用模态至少保留 1 个 token 以区分存在与缺失；掩码在 token 投影前执行以加速训练；可选地在编码器与解码器之间注入 MLP 瓶颈，将各活跃模态 token 按空间维度对齐后拼接（缺失模态补零矩阵）并线性投影为统一共享空间表示，替代解码器级 cross-attention 以促进模态无关表示。
  • 重建损失：MSE 仅在掩码空间区域计算；SSIM 损失在整个空间网格上计算（式 1）；FFT 损失在对数压缩幅度谱上计算 L1 距离（式 2）。
  • 损失平衡：研究三种批内归约策略——策略 A 无平衡（式 7，样本内模态损失求和后对样本平均）、策略 B 模态平衡（式 8，各模态独立平均后求和）、策略 C 样本平衡（式 9，样本内按有效模态数归一化后平均）；模态损失为加权和并乘模态权重 α_m（式 6）。

Card 06 评估与结果

评估与结果

  • 评估任务与指标：STF 上按标准 KITTI 协议报告 2D 边界框 AP_R40（%），为 easy/moderate/hard 难度及全类别平均；DSEC 上语义分割用 mIoU、目标检测用 COCO 评估指标。
  • 评估条件：开环离线评估（在下游数据集测试集上评测），非闭环仿真或实车部署实验；模型选择仅在各自验证集上进行，测试集仅用于最终报告；DSEC 测试集在预训练中保留不参与。
  • 对比方法：ViT、MAE、DINO、MultiMAE 现成权重，以及共享同一域内预训练流程、仅初始化不同的 Our-ViT 与 Our-MM（分别以标准 ViT 权重与 MultiMAE 权重初始化）。
