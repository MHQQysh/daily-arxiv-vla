Card 03 核心贡献

核心贡献

  • 提出 ScaleDrive，一个仅使用大规模原始行车视频、无需动作标注或任务特定监督的可扩展自监督预训练框架，用于学习可迁移的驾驶表征。
  • 提出面向驾驶的预测式预训练策略，将 patch 级掩码与完整时间切片（temporal-slice）掩码结合，以同时建模空间场景结构与时间动态。
  • 系统研究表征随数据规模的扩展：随着视频预训练数据增加，下游规划性能提升，且自运动与深度探针显示冻结表征中的时间运动与空间几何信息逐步增强。
  • 在冻结视觉编码器的条件下取得有竞争力的端到端规划性能，并一致地改进回归、扩散与自回归规划器，且在 NAVSIM、HUGSIM 与 Bench2Drive 等不同基准上泛化。
Card 04 方法描述

方法描述

  • 所属模块：自监督视频表征预训练模块 + 下游端到端规划模块；预训练采用联合嵌入预测架构（JEPA），预训练后丢弃 predictor，仅保留并冻结视频编码器用于下游规划。
  • 输入传感器：原始无动作行车视频帧序列（图像序列），输入张量形如 T×H×W×3；不依赖轨迹或感知标注。原文未报告其他传感器输入。
  • 场景表示：将视频切分为不重叠的时空 patch 并投影为视觉 token，使用 3D RoPE 编码时间与空间坐标；在潜空间（而非 RGB 像素）中预测被掩码区域的表征。
  • 模型结构：上下文编码器 E_θ 仅处理可见 token，预测器 P_φ 推断被掩码位置的表征，目标由动量目标编码器 E_θ̄（与上下文编码器同架构、EMA 更新、停止梯度）产生。
  • 关键技术：patch 级空间掩码（采样空间连续 token 组）提供稠密空间监督；完整时间切片掩码移除选定时间索引上的全部空间 token，消除同帧空间捷径并强化时间预测；两者合并为总掩码集合，采用 L1 潜空间回归损失；下游使用可学习 ego query 与轨迹解码器，以冻结表征与 ego 状态预测未来轨迹；跨规划器集成时，BEV 类策略融合原生 BEV 特征，相机视角类策略替换原生视觉表征。
  • 理论分析：通过驾驶动态系统建模与局部线性化，给出两个命题，分别说明空间冗余下 patch 级预测存在同帧捷径的充分条件，以及完整时间掩码下在局部可观测条件下目标可由时间分布上下文恢复。

Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIMv1、NAVSIMv2，以及 HUGSIM、Bench2Drive；另含自运动与单目深度探针评估；跨策略评估覆盖 LTF、DiffusionDrive、DrivoR、ChainFlow。
  • 评估指标：NAVSIMv1 使用 NC、DAC、EP、TTC、Comf.、PDMS；NAVSIMv2 使用 NC、DAC、DDC、TLC、EP、TTC、LK、HC、EC、EPDMS；HUGSIM 使用 Route Completion 与 HD-Score（按 Easy/Medium/Hard/Extreme 及平均）；探针评估指标原文未在提供内容中完整报告。
  • 关键数值：NAVSIMv1 上 ScaleDrive 达到 PDMS 93.8（NC 99.3、DAC 98.4、EP 90.6、TTC 97.0、Comf. 100.0）；NAVSIMv2 上 EPDMS 90.5（NC 99.3、DAC 98.9、DDC 99.7、TTC 98.9 等）。数据扩展实验中，视频片段从 0.5M 增至 6M 时 PDMS 从 92.77 提升至 93.61，官方 V-JEPA2 表征为 92.40；引入时间切片掩码在同数据规模下进一步提升规划性能。跨策略结果：LTF(ScaleDrive) PDMS 86.2（+2.4）、DiffusionDrive(ScaleDrive) 88.1（+1.5）、DrivoR(ScaleDrive) 93.4（+0.3）、ChainFlow(ScaleDrive) 93.2（+0.6）；V-JEPA2 在多数策略上未带来一致提升（如 LTF −0.6、DrivoR −0.8、ChainFlow −0.5）。HUGSIM 上 LTF 使用 ScaleDrive 的 Route Completion 平均为 0.448、HD-Score 平均为 0.315；ChainFlow 使用 ScaleDrive 的 Route Completion 平均为 0.500、HD-Score 平均为 0.442。
