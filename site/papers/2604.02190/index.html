UniDriveVLA: Unifying Understanding, Perception, and Action Planning for Autonomous Driving

Card 03 核心贡献

核心贡献

  • 提出 UniDriveVLA，一个基于 Mixture-of-Transformers（MoT）架构的统一 VLA 模型，通过任务专家解耦（understanding、perception、action 三个专家）减轻空间感知与语义推理间的优化冲突。
  • 引入稀疏感知范式（Sparse Spatial Perception），直接从 2D VLM 特征中提取空间先验，避免注入稠密 3D/BEV 表示对 VLM 推理能力的破坏。
  • 设计三阶段渐进式训练策略，在保持模型语义理解能力的同时，逐步装备感知与规划能力。
  • 大量实验表明，UniDriveVLA 在 nuScenes 开环评测与 Bench2Drive 闭环评测上取得最优表现，并在 3D 检测、在线建图、运动预测及驾驶 VQA 等多个任务上展示出较强的通用性。
Card 04 方法描述

方法描述

  • 所属模块：端到端自动驾驶 Vision-Language-Action（VLA）统一模型，涵盖感知、理解与规划模块。
  • 输入传感器：原文主要报告多视角相机图像（multi-view camera），未报告激光雷达等其他传感器输入；规划模块另使用历史自车轨迹与导航指令。
  • 场景表示：采用稀疏查询驱动的感知范式（感知 token），并结合 VLM token 进行语义理解；没有采用稠密 BEV 或体素表示作为主要场景表征。
  • 模型结构：基于 Qwen3-VL 作为基础视觉-语言骨干，采用 Mixture-of-Transformers（MoT）架构。模型中包含三个专家：driving understanding expert（承载自回归语言建模）、perception expert（承担结构化的稀疏感知任务）、action expert（执行基于 flow matching 的轨迹生成）。
  • 关键技术：

- 专家级 Q/K/V 投影与 Masked Joint Attention（遮蔽联合注意力）：理解专家采用因果掩码且不关注后续感知/动作 token；感知 token 可关注此前理解 token 获取语义上下文；动作 token 聚合语义与空间两类信息。

- 稀疏感知模块：任务专属稀疏 queries 由实例库（K-Means 聚类）初始化，经时间交互、任务内推理、任务间通信、可变形特征聚合与任务级精炼完成 3D 检测、在线建图、自车状态、运动预测等任务；occupancy 作为辅助潜在分支。

- 感知特征提升到 VLM 隐空间并与理解/动作分支交互，再投影回稀疏感知空间继续精炼，形成语义增强的闭环。

- 动作分支采用 flow-matching 插值生成轨迹（Gaussian noise 向目标速度序列插值）。

- 三阶段训练：Stage 1 大规模多模态预训练（冻结 VLM）；Stage 2 联合优化（对 VLM 使用 LoRA 与减半学习率）；Stage 3 冻结 VLM 后对感知专家与动作专家精调并引入运动预测目标。

Card 06 评估与结果

评估与结果

  • 评估基准：nuScenes（开环）、Bench2Drive（闭环）、DriveBench（驾驶 VQA）、通用 VQA 若干。
  • 评估指标：

- Bench2Drive 闭环：Driving Score、Success Rate (%)、Efficiency、Comfortness；开环：Avg. L2（2 秒 horizon、2 Hz）。

- Bench2Drive 多能力：Merging、Overtaking、Emergency Brake、Give Way、Traffic Sign、Mean（%）。

- nuScenes 规划：ST-P3 与 UniAD 两套协议下的 L2（1s/2s/3s/Avg.）与碰撞率（1s/2s/3s/Avg.）。

  • 关键数值（原文报告的重点结果）：

- Bench2Drive 闭环：Driving Score 78.37、Success Rate 51.82%、Efficiency 198.86、Comfortness 11.78；开环 Avg. L2 0.72。

- Bench2Drive 多能力：Merging 38.75%、Overtaking 80.00%、Emergency Brake 50.00%、Give Way 30.00%、Traffic Sign 58.95%、Mean 51.53%。

- nuScenes 开环（无 ego status 协议）：UniDriveVLA-Large 在 UniAD 协议下 L2 1s/2s/3s/Avg. 为 0.27/0.49/0.77/0.51；ST-P3 协议下相应指标报告为 0.27/0.49/0.77/0.51 等（表格中并列两协议数据）。
