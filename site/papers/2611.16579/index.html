Card 03 核心贡献

核心贡献

  • 提出 ActWorld-JEPA，一个用于端到端自动驾驶的联合嵌入预测框架，将计划条件化的潜在未来建模与轨迹选择相连接，使候选决策能够纳入预测后果。
  • 提出 Plan-Conditioned JEPA（PC-JEPA）：使用全局与逐步轨迹意图条件化循环潜在预测，并通过门控交叉注意力将预测未来与当前场景融合，得到候选特定的未来感知表示。
  • 提出 Relational Residual Reranking（R³）：建模候选计划与其未来感知表示之间的一致性与差异，在规划监督下产生有界、门控的残差修正以细化基座规划分数。
  • 在 NAVSIM v1 navtest 上报告 94.1 PDMS，在 NAVSIM v2 navtest 与 navhard 上分别报告 91.6 与 42.7 EPDMS；在 nuScenes 上报告 1–6 s 平均 L2 误差 1.20 m、预测碰撞率 0.76%。
Card 04 方法描述

方法描述

  • 所属模块：整体为候选轨迹重排序/选择模块，架构包含预训练驾驶编码器、基座规划器、PC-JEPA 与 R³，并叠加在基座规划器目标之上进行联合训练。
  • 输入传感器：原文报告输入为多帧驾驶观测（multi-frame driving observations），由预训练驾驶编码器提取当前表示 Z_t；具体传感器配置原文未报告。
  • 场景表示：使用预训练驾驶编码器输出的当前场景隐表示 Z_t；候选轨迹以未来航点序列表示；未来监督使用观测未来帧编码得到的 stop-gradient 目标隐表示。
  • 模型结构：

- PC-JEPA：航点经 MLP 投影并加入 horizon 特定的时间嵌入，经轻量时序 Transformer 聚合为全局条件 C_t^k，同时保留逐步条件 C_{t,h}^k；通过候选相关调制初始化循环 JEPA 预测器的隐状态，逐步预测候选特定潜在未来；再以 Z_t 为 query、候选 rollout 为 key/value 做交叉注意力，并用候选特定门控做残差融合与归一化得到 H_t^k。

- R³：将计划条件与池化后的未来感知特征投影到共同空间，拼接二者、逐元素乘积与方向差构成关系特征 r_t^k；轻量 MLP 输出分数修正 Δs_t^k 与置信 logit ρ_t^k；最终分数为 b_t^k + λ·σ(ρ_t^k)·tanh(Δs_t^k)，经 softmax 归一化后取最高概率候选。

  • 关键技术：计划条件化潜在 rollout、门控交叉注意力当前-未来交互、有界门控残差重排序、stop-gradient 未来隐目标监督、基于与专家轨迹平均位移误差最小候选的选择监督。

Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM v1 navtest、NAVSIM v2 navtest、NAVSIM v2 navhard、nuScenes 1–6 s 开环规划。
  • 评估指标：NAVSIM v1 使用 NC、DAC、TTC、Comf.、EP 与 PDMS；NAVSIM v2 使用 NC、DAC、DDC、TL、EP、TTC、LK、HC、EC 与 EPDMS；nuScenes 使用平均 L2 误差与预测碰撞率。
