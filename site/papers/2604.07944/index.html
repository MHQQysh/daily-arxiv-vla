Card 03 核心贡献

核心贡献

  • 首次将广义知识蒸馏（GKD）应用于自动驾驶运动规划场景，证明以 5 倍参数压缩（8B 教师到 1.7B 学生）可获得接近教师水平的性能。
  • 在保持所有实验条件一致的受控设置中，对 GKD 与使用教师对数概率作为逐 token 奖励的密集奖励 RL 基线进行了原理性对比，隔离了学习算法带来的影响。
  • 实验表明 GKD 学生在轨迹精度与碰撞避让方面均接近教师水平，在所有评估指标上显著优于 RL 基线。
  • 揭示完整词表分布监督相较于采样 token 稀疏奖励在航点生成任务中的关键优势，为 LLM 规划器的高效部署提供了实用路径。
Card 04 方法描述

方法描述

  • 所属模块：运动规划模块（将规划重构为条件自回归语言建模问题）。
  • 输入传感器：原文未报告具体传感器；输入为语言提示，编码上游感知预测系统输出的场景目标描述与自车状态，以及高层驾驶任务目标。
  • 场景表示：将异构观测与自车状态转化为自然语言句子，包含感知与预测目标描述、自车速度、加速度、横摆角速度及过去 2 秒的历史轨迹。
  • 模型结构：教师模型为 Qwen3-8B，学生模型为 Qwen3-1.7B；二者均采用条件自回归解码器 LLM 架构。
  • 关键技术：教师经监督微调学习，采用 qwen3_nothink 聊天模板生成结构化规划输出；GKD 训练学生生成自身 on-policy 输出，使用教师逐 token 词表分布（JSD 散度，β=0.5）监督；对比 RL 基线使用教师对数概率差的逐 token 优势信号进行策略梯度更新。

数据集与资源

  • 模型规模：教师 Qwen3-8B（8 亿参数），学生 Qwen3-1.7B（1.7 亿参数），压缩率约 5 倍。

Card 06 评估与结果

评估与结果

  • 评估基准：nuScenes 官方运动规划基准（5,119 帧验证样本）。
  • 评估指标：L2 位移误差（米，1s/2s/3s 及各时段平均，STP-3 与 UniAD 约定），碰撞率（%，STP-3 约定），格式错误率（）。
  • 评估条件：开环数据驱动评估；所有模型采用贪婪解码，训练 5 轮并按验证集选最优检查点（教师第 3 轮，GKD 第 3 轮，RL 第 1 轮）。
  • 关键结果：教师 STP-3 平均 L2 0.355 m / UniAD 0.730 m / STP-3 平均碰撞率 0.101%；GKD 学生 0.373 m / 0.772 m / 0.138%；RL 学生 0.579 m / 1.092 m / 0.363%。GKD 学生与教师差距仅 5%-6%，较 RL 学生优势达 41%-55%。两学生均无格式错误，教师格式错误率约 0.08%。
  • 定性结果：在左转挑战场景中，教师正确完成转弯，GKD 学生虽错过弯道但更接近真实轨迹（ADE 3.09 m），RL 学生偏差更大（ADE 6.29 m）。
