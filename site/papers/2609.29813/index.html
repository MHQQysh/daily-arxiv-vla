Card 02 论文概述

论文概述

  • 论文面向端到端自动驾驶中的运动规划任务，目标是利用场景观测、自车近期运动和历史导航指令，直接选择可行的未来轨迹。
  • 应用场景为基于三路前视相机、自车运动历史和当前驾驶命令的相机与自车状态联合规划。
  • 研究问题在于：能否不依赖显式 BEV 预测头或固定轨迹词库，而是直接在候选轨迹点附近的标定投影位置采样多尺度图像特征，并迭代精化轨迹。

Card 03 核心贡献

核心贡献

  • 提出以轨迹为中心的解码器：通过自车状态条件初始化粗候选轨迹，并在标定后的多尺度相机特征位置进行采样与迭代更新。
  • 明确说明拼接相机输入中的特征如何与各相机的独立标定矩阵关联，并指出图像接缝处跨视角注意力的局限性。
  • 给出探索性 NAVSIM v1 组件研究，并明确说明其检查点由 navtest 测试集选择，因此结果属于探索性、测试集选择后的观测。
  • 提出后续采用基于 navtrain 的日志不重叠验证子集进行验证选择、重复运行、未曝光数据评估和计算性能测量的协议。
  • 报告了一个之前获得的 NAVSIM v1 navtest 结果：88.03 PDMS，但强调该数字不能解释为无偏测试估计。
Card 04 方法描述

方法描述

  • 所属模块：端到端轨迹规划器，包含语义感知多尺度场景编码器与由粗到细轨迹解码器。
  • 输入传感器：前左、前、前右三路 RGB 相机；非图像输入包括当前自车速度、纵向加速度、自车坐标系下的近期位姿历史和驾驶命令。原文未报告 LiDAR。
  • 场景表示：将三路图像各自缩放后按前左、前、前右顺序拼接为一张大图输入 DINOv3；下游投影使用每台原始相机的标定矩阵。原文未报告对拼接图采用单一针孔视角假设。
  • 语义特征提取：使用基于 DINOv3 预训练并微调的主干，收集选定 DINOv3 块的 spatial 输出作为特征；原文未报告具体 DINOv3 变体、检查点和位置编码细节。
  • 多尺度表示：采用 DEIMv2 中的 Spatial Tuning Adapter，将中间 DINOv3 特征转换为多尺度层级；每个尺度特征宽度被分成三个相机条带，采样坐标在各自相机条带内归一化。
  • 轨迹初始化与 token 化：学习轨迹 token 集合，M 为候选模式数，L 为未来路点数，D 为 token 维度；不使用固定轨迹词库，但粗预测路点仍作为注意力的参考点。
  • 初始轨迹编码：用 MLP 编码自车历史并通过交叉注意力注入轨迹 token；随后使用受 DiT 启发的 scale-and-shift 条件 transformer 块，以自车速度、纵向加速度和驾驶命令生成调制参数。原文说明该块不执行扩散采样。
  • 空间 Transformer：堆叠 K 次，包含轨迹自注意力与空间交叉注意力。轨迹自注意力在候选路点之间交换信息；空间交叉注意力将当前路点转换到当前自车度量坐标系，通过多个高度生成 3D 参考点并投影到各相机，再用可变形注意力采样多尺度特征。
  • 轨迹更新与评分：每个空间 Transformer 阶段后通过 MLP 预测更新后的轨迹坐标，更新后的点作为下一阶段参考点；最终 token 经 MLP 输出各模式分数，返回最高分模式。
  • 损失：包含多阶段中间轨迹损失，采用 Minimum over N 损失；最终阶段使用预测最优、标签最优和二者一致性的平均轨迹损失，并加入基于 BCE 的分数监督；总损失为最终损失与中间损失之和。原文未报告 λ、α、K、M、L、N_ref 等具体配置值。

Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM v1 navtest；评估协议为四秒非反应式仿真。
  • 评估指标：PDMS，由 NC、DAC、EP、TTC 和舒适度 C 构成，公式为 PDMS = NC × DAC × ((5EP + 5TTC + 2C) / 12)。
  • 关键数值：原文之前报告的 S2Planner navtest 运行结果为 88.03 PDMS；NC 98.2，DAC 96.5，TTC 94.3，C 100，EP 82.2。
  • 对比方法：Transfuser 84.0 PDMS、DRAMA 85.5 PDMS、VADv2-V8192 80.9 PDMS、Hydra-MDP-V8192 83.0 PDMS、Hydra-MDP-V8192-W-EP 86.5 PDMS、DiffusionDrive 88.1 PDMS、UniAD 83.4 PDMS、PARA-Drive 84.0 PDMS、LTF 83.8 PDMS。
  • 对比条件：原文强调 S2Planner 结果由 navtest 选择检查点，属探索性测试选择观测；与 DiffusionDrive 的 88.1 接近，但传感器、状态通道、计算预算和选择流程均未匹配，因此不能得出孰优孰劣的结论。
  • 消融结果：A0 ResNet 72.4 PDMS；A1 DINOv3 84.9 PDMS；A2 DINOv3 + STA 86.3 PDMS；A3 完整模型 88.0 PDMS。原文称 A1 比 A0 高 12.5 分，A2 比 A1 高 1.4 分，A3 比 A2 高 1.7 分，但均为 navtest 测试引导开发下的探索性比较，无不确定性估计。
  • BEV 辅助头比较：A1 直接回归 84.9 PDMS；A1.1 加 BEV 辅助头 83.5 PDMS。原文强调该实验只测试了一种 BEV 头设计和损失设置，不能支持 BEV 表示一般不必要的结论。
  • 开环、闭环、仿真或实车条件：原文只报告 NAVSIM v1 非反应式仿真结果，未报告开环、闭环交互、实车测试结果；原文明确指出交互式仿真或实车测试仍是后续必要步骤。
