研究单位

Card 02 论文概述

论文概述

  • 本论文解决自动驾驶系统（ADS）开发中的驾驶场景提取问题，即从无标注的真实世界传感器数据流中自动定位关键驾驶场景。
  • 应用场景为基于场景的 ADS 数据集覆盖度分析，帮助开发人员判断数据集对目标运行设计域（ODD）内场景的覆盖程度。
  • 研究问题为：如何在保留传统规则方法可解释性、确定性的同时，提取基于视觉语义（如天气、道路条件、校车停车标志状态等）的复杂场景——这是仅依赖轨迹标注的现有方法无法实现的。
Card 03 核心贡献

核心贡献

  • 提出了一种基于场景图与线性时序逻辑（LTL）的场景提取方法，相较于现有最先进方法，能够提取依赖于视频数据视觉语义的场景（如天气、道路条件、物体特征），同时保留规则方法的确定性白盒优势。
  • 对开源场景图生成器 RoadScene2Vec (RS2V) 进行了改进，实现了两个关键增强：(1) 通过基于轨迹的标签实现跨帧一致的对象跟踪；(2) 细化了原本粗糙的三车道识别，利用 HD 地图数据实现更精确的车道分配。
  • 强调了方法的集成性质——不引入新算法，而是将现有多系统（目标检测、跟踪、多模态大模型、模型检查器）进行整合并增加必要的支撑工具链。
  • 发布了全部源代码（匿名 GitHub 仓库），支持结果复现与后续扩展。
Card 04 方法描述

方法描述

  • 所属模块：数据驱动的自动驾驶道路场景分析与场景提取模块。
  • 输入传感器：单目前视相机图像流、可选的轨迹标注（含多传感器融合的状态估计）、可选的 HD 地图数据。
  • 场景表示：采用场景图（Scene Graph）序列。单个场景图编码一帧图像中的物体节点、属性及空间关系；整个场景被表示为跨时间的场景图序列。
  • 模型结构：流程分为四步：(1) 场景图生成：使用 RoadScene2Vec (RS2V)（基于 Detectron2 目标检测 + 规则启发式关系推理）生成原始场景图序列，并通过 Kalman Filter 与 Hungarian 算法实现多目标跟踪，建立时间一致的对象标签（perception tracks）；通过 Hungarian 算法将感知轨迹关联到数据集提供的标注轨迹上，以获得噪声更低的运动状态（位置、速度、朝向）并修正空间关系；利用 HD 地图修正车道分配并增加道路几何边（如 opposes、toLeftOf）；使用多模态大语言模型 (MLLM) gemini-2.5-flash-lite 进行视觉问答以提取天气、道路表面状况及校车停车标志是否展开等视觉语义属性添加到场景图中；(2) 场景图富化——将上述来自传感器状态与 HD 地图的语义信息与 MLLM 视觉语义加入场景图中，但以功能、逻辑、具体三个抽象层次定义场景，其中天气等条件可作为元数据嵌入每个场景图中；(3) 场景规格化——使用 LTL 公式（基于自定义原子谓词）在语义层面正式定义感兴趣场景，可将多个场景事件组合为时序谓词链；(4) LTL 检查——使用现成的模型检查器 SceneFlow 的修改版本（改为标记满足而非违反），评估每个场景图序列是否满足 LTL 规范。
  • 关键技术：场景图序列 + LTL 模型检查；多目标跟踪（卡尔曼滤波 + Hungarian）；感知轨迹与标注轨迹关联；HD 地图车道校正；MLLM 视觉问答富化（非确定性在场景图生成后即不再传播）。
  • 原文未报告：具体的多模态大模型网络架构细节及训练信息（使用 API 服务）；视觉问答的具体提示词细节。

Card 06 评估与结果

评估与结果

  • 评估基准：基于 AV2 轨迹标注与 HD 地图构建的规则基准（该基准为场景提取的基线方法），与论文方法进行一致性比较。人类人工验证了随机子集。
  • 评估指标：实例级精确率、召回率、F1 分数（含 track-aware 判定，需正确识别关键轨迹及≥50% 时间覆盖）以及时间戳级 temporal localization 的精准率、召回率、F1；日志级 log-balanced accuracy 及 TP/TN Rate。
  • 关键数值（Level III 场景图，即含跟踪/状态/地图增强的场景图，多数指标为最优配置）：

- 纵向跟驰场景（30 m 跟随距离）：F1（track-aware）0.607，非 track-aware F1 0.802；long-following 对应日志级 log-balanced accuracy 0.822。

- 纵向跟驰场景（60 m 跟随距离）：F1（track-aware）0.552，非 track-aware F1 0.827；log-balanced accuracy 0.819。

- 从右侧切入场景（cut-in）：F1 0.855；log-balanced accuracy 0.901。

- 校车出现场景：F1 0.721（Level I）；log-balanced accuracy 接近 1；precision 0.969 明显高于 recall 0.574，反映检测器对部分被遮挡校车的漏检。

- 校车停驶（停车标志展开）场景：interval matching F1 0.400（Level I），temporal localization F1 0.742；日志级 TP Rate 1.0、TN Rate 0.992、log-balanced accuracy 0.996。

- 对 MLLM 在天气及路面估计的单独评估：在 AV2 图像统计显著样本上，天气分类 F1=0.94，路面估计 F1=0.98。

- 跟踪质量：平均每个 AV2 轨迹产生 1.587 个感知轨迹片段；34.1% 的 AV2 轨迹存在多个感知片段；主导感知轨迹对轨迹生命周期的平均覆盖率为 63.6%。

  • 对比方法：与 LLM/VLM 方法 RefProg（在轨迹标注上的 log-balanced accuracy 0.811）进行了间接比较，三个场景（30m 跟驰、60m 跟驰、切入）的 log-balanced accuracy 均略高于该数值，但作者指出二者基准与场景集合不同，并非直接可比。
  • 开环/闭环/仿真/实车条件：实车数据开环评估（基于公开数据集与行车记录视频离线回放）；无闭环或仿真器评估。
