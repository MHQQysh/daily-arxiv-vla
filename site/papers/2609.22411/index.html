Card 02 论文概述

论文概述

  • 论文针对材料微观结构表征中的高通量瓶颈问题，提出面向扫描电子显微镜（SEM）的自主成像流程。

  • 研究问题在于现有自动化电镜流程多为任务特定，依赖预定义特征、已知属性或先验材料知识，难以直接用于未知样品的通用形态调查。
  • 论文将任务重新定义为任务无关的“形态调查”，即在无领域特定预训练、微调或人工提示条件下，捕捉未知样品的多尺度形态分布。
Card 03 核心贡献

核心贡献

  • 提出 AutoRASOR，一个无需领域特定预训练、微调或人工提示的自主多尺度 SEM 成像流程，可直接对未知样品进行表征。
  • 在实时闭环采集循环中直接使用视觉基础模型 DINOv3 的稠密嵌入驱动区域选择，而不是依赖分割掩码、目标检测或任务特定规则。
  • 提出 Latent Farthest Point Sampling（LFPS），在 VFM 潜空间中选取形态多样区域，以在有限采集预算下恢复样品的形态分布。
  • 提出基于形态歧义（morphological ambiguity）的主动学习策略，将歧义定义为给定低倍邻域时高倍特征的條件方差，用于优先放大高倍尺度上不可预测或未解析的区域。
  • 在真实 SEM 微图和合成相场图像上验证 LFPS 与歧义主动学习的采样效果，并报告了在 DINOv3 潜空间和相场参数空间中的多样性、代表性和覆盖结果。
Card 04 方法描述

方法描述

  • 所属模块：自主 SEM 采集与区域选择流程，包含显微镜控制、VFM 特征提取、LFPS 区域选择、歧义估计和主动学习采集。
  • 输入传感器：SEM 微图；实验在 Hitachi SU7000 FE-SEM 上进行，并使用相机捕获全样品图像供用户选择样品位置。
  • 场景表示：将显微图缩放到 224×224 像素，经 DINOv3 vits16plus 提取 14×14×384 的张量，每个 16×16 像素 patch 对应 384 维嵌入；提取 Layer 5 表示以减少位置偏差；使用余弦相似度评估 patch 间形态相似性。
  • 模型结构：使用 DINOv3 ViT-S+ 作为视觉基础模型，ONNX Runtime 在 SEM 计算机 CPU 上快速推理；主动学习使用 BoTorch 中的高斯过程回归代理模型，常数均值、Matérn-5/2 协方差核和 ARD。
  • 关键技术：LFPS 贪心选择与已选 patch 在 384 维嵌入空间中余弦距离最大的 patch；歧义通过 k-NN（k=10）加高斯核权重的 Nadaraya–Watson 方差估计计算；使用 leave-one-neighbor-out jackknife 方差构造异方差观测噪声；采集函数为 qLogNEI，批次大小 q=2。
  • 采集流程：在每个放大倍率转换处分为两阶段；阶段 1 用 LFPS 选择当前倍率下形态多样区域并放大；阶段 2 用高斯过程预测未观测区域歧义并用批量采集函数选择下一批区域，更新归档和代理模型。
  • 显微镜自动化：使用 Python 脚本、PyAutoGUI 控制 GUI，并使用 Hitachi hihi API 直接控制仪器；实现光学对准、高倍自动对焦、自动消像散、自动微图采集与读取、样品台控制和束移。
  • 原文未报告：论文未报告自动驾驶相关的车辆平台、传感器配置、道路场景表示或驾驶任务模型结构；本文不属于自动驾驶论文。

Card 06 评估与结果

评估与结果

  • 评估基准：合成基准使用 OPMD 相场图像生成双倍率数据并提供 ground-truth 高倍形态；真实 SEM 评估使用 6 个完整高倍网格数据集作为 exhaustive reference。
  • 评估指标：主动学习合成基准报告 top-20 recall、top-20 discovery rate、best ambiguity discovered；真实 SEM 网格报告 variance、Sliced Wasserstein Distance（SWD）、local ground-truth sparsity；相场参数空间报告 variance、SWD、convex hull volume。
  • 对比方法：随机采样、LFPS、EI（q=1）、qLogNEI（q=2）；真实 SEM 上比较 random、LFPS、带 LFPS warmup 的歧义主动学习、无 warmup 且随机初始化的歧义主动学习；附录还评估 qUCB 和 UCB。
  • 合成主动学习结果：qLogNEI 在每个采样百分比下与 EI 相当或更好；两种贝叶斯采集策略比 random 和 LFPS 更准确预测高歧义区域并更高效采样高歧义区域；LFPS 也优于随机采样且不需要高倍采集。
  • 真实 SEM 结果：歧义主动学习和 LFPS 在 diversity-oriented 指标上优于随机采样；歧义主动学习获得更高 variance 和 local GT sparsity，但 SWD 低于 random 和 LFPS，表明分布代表性较低；LFPS 的 variance 和 local GT sparsity 高于 random，同时 SWD 与 random 相当，表明在较大程度上保持参考分布。
  • 相场参数空间结果：歧义主动学习在超过 2% 采样预算后获得最高 variance，并与 LFPS 具有可比的 convex hull coverage；LFPS 的 SWD 与 random 相当，同时 variance 和 convex hull coverage 高于 random；主动学习分布代表性较差，与其偏好稀有和独特形态一致。
  • 形态-倍率流形结果：500× 下分布为两个小而紧凑的簇；3500× 下为一个较大簇及多个较小簇；24500× 下为几个密度不同的大连通簇。
  • 效率结果：在合成数据集上，若随机采集要达到与 LFPS 或歧义主动学习在早期迭代相同的 convex-hull-volume 覆盖，平均需要约 1.7× 更多样本和时间。
  • 开环、闭环、仿真或实车条件：AutoRASOR 在真实 SEM 上以闭环采集流程运行并完成真实样品验证；合成基准为仿真条件；原文未报告开环评估和自动驾驶实车条件。
