Card 03 核心贡献

核心贡献

  • 提出紧凑的状态空间“沿射线深度”3D 精化器，在冻结光流与单目深度之上仅修正逐点深度，学习模块参数量低于 1M，且流程可解释。
  • 提出深度尺度精化器（depth scale refiner）：指出更大的度量深度骨干并非单纯更好，它会用可学习的远场偏差换取帧间尺度闪烁，而逐轨迹精化器无法观测该闪烁，因此在精化前直接读取深度图以稳定逐帧深度尺度。
  • 提出 VSSD-2pool，即非因果折叠中的第二个独立读取池：使 Mamba-3 非因果会损失其 β 频带，需要第二个独立读取池来恢复，该算子将 TAPVid-3D minival 上的绝对度量精度从 0.248 提升至 0.255。
  • 在相同单张消费级 GPU 条件下评估，所提跟踪器取得最高绝对度量精度，平均 metric Average Jaccard（AJ）为 0.256。
  • 明确说明在尺度不变排行榜上，强深度基线与前馈跟踪器 DELTA 仍领先，作者对此进行了显式报告。
Card 04 方法描述

方法描述

  • 所属模块：整体为模块化流水线，包含冻结的 2D 光流前端、冻结的单目度量深度骨干、以及唯一可学习的深度精化模块。
  • 输入传感器：单目视频（monocular），无位姿（pose-free）；原文未报告使用其他传感器。
  • 场景表示：逐轨迹的时序表示，沿每条轨迹的时间轴应用状态空间模型；2D 跟踪结果由光流链式组合得到，并通过前向–后向一致性检查设置可见性 v。
  • 模型结构：

- 2D 跟踪（冻结）：SEA-RAFT 或 WAFT 提供稠密光流，通过 flow chaining 组合为全长 2D 轨迹，并输出可见性。

- 度量深度与反投影：Depth-Anything-3（DA3-l 或 DA3-g）提供单目度量深度；也可选 MegaSaM 作为深度来源。

- 两个 3D 精化器变体：Mamba-3 3D refiner（沿射线深度修正）与 vmamba3 3D refiner（外观与几何条件化修正，并对 2D 轨迹施加小的有界修正）。

- 深度尺度精化器：在精化前稳定逐帧深度尺度。

- 可见性头（visibility head）。

  • 关键技术：

- 将 Mamba-3 视为掩码线性注意力（SSD），利用其固定大小递归状态，使内存成本随帧数恒定，而 softmax 注意力需线性增长的 KV cache。

- 移除因果性：通过非因果折叠将 T×T 掩码折叠为单 T 向量 m；进一步提出 VSSD-2pool 以恢复非因果下丢失的 β 频带。

- 精化器条件输入包括：光流轨迹特征 r(u_t)、原始深度 z_raw、可见性 v，以及冻结的 DINOv3 外观特征。

- 在序列长度 1025 tokens 时，该算子运行峰值内存为 softmax 注意力的 30%–54%。
