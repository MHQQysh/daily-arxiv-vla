Guiding End-to-End Driving Models with Endpoint-Constrained Trajectory Optimization

Card 02 论文概述

论文概述

  • 论文研究的任务是端到端（end-to-end）自动驾驶轨迹规划，即由预训练驾驶策略根据传感器观测与导航指令预测未来轨迹，并由控制器执行。
  • 应用场景为闭环（closed-loop）自动驾驶仿真与实车部署下的轨迹执行。
  • 研究问题聚焦于开环行为克隆训练与闭环执行之间的不匹配（open-loop/closed-loop gap）：论文指出除协变量偏移与因果混淆外，还存在一个互补因素，即基于路点的监督与位移指标无法保证中间轨迹的物理连贯性或易于控制器跟踪，且这些不一致主要集中在中间路点，而预测终点相对可靠。
Card 03 核心贡献

核心贡献

  • 分析开环/闭环差距，表明标准位移指标可能忽略物理不一致的路点序列，且多数运动约束违规出现在轨迹中段而非端点。
  • 提出 Endpoint-Constrained Optimization（ECO），一个无需训练的后处理层，固定已执行历史与策略预测的终点，仅修复其间的中间路点。
  • ECO 不需要地图、特权仿真器状态或额外训练，可插入任意输出路点的策略与其控制器之间（生成式或回归式头均可）。
  • 在两种闭环仿真器中提升全部六个被评估的生成式与回归式驾驶策略的聚合闭环得分，且当基础规划越频繁违反运动限值时收益往往越大。
  • 在 HUGSIM 闭环驾驶挑战中取得第一名，并在 AlpaSim 上提升 VaVAM 与 DiffusionDrive 的场景得分。
Card 04 方法描述

方法描述

  • 所属模块：ECO 作为后处理层置于策略与控制器之间，在推理之后、控制之前应用。
  • 输入传感器：策略接收来自仿真器的相机图像输入与导航指令；ECO 本身只使用输出的规划与已执行的 ego 历史。
  • 场景表示：以固定时间间隔 Δt 的 N 个路点表示轨迹，每个路点为 x_i=(p_i, θ_i)，位置 p_i=(x_i, y_i)，航向 θ_i；对仅预测位置的路点，θ_i 定义为从前一路点到当前路点线段的航向。车辆已执行位姿以同样的 (p, θ) 形式表示为 h_{-K},...,h_{-1}，当前位姿 h_0=(0,0,0) 位于 ego 坐标系原点。
  • 模型结构：ECO 在优化前将最近两个已执行位姿 h_{-2:-1} 与当前位姿 h_0=(0,0,0) 拼接到预测轨迹前，固定这些历史位姿与最后预测路点 x_{N-1}，优化其余路点 x_{0:N-2}。
  • 关键技术：目标函数由平滑项 S(z)（惩罚位置与航向的二阶差分，角度差包裹到 [-π,π]）、转弯惩罚项 C(z)（用相邻轨迹段叉积惩罚急转弯，仅当 \|c_i\|>c_0=0.5 m^2 且两段长度大于 0.1 m 时应用）、偏离项 D(x, x^{(0)})（限制优化轨迹偏离策略原预测）组成，位置与航向联合优化；受约束 x_{N-1}=x^{(0)}_{N-1}。使用 L-BFGS-B 求解，初始化为预测规划。
  • 其他信息：原文未报告使用地图或特权仿真器状态；原文未报告实车平台。
Card 05 数据集与资源

数据集与资源

  • 数据集：nuScenes、Waymo、KITTI-360、PandaSet，以及 AlpaSim NuRec set。
  • 仿真器：HUGSIM（基于 3D Gaussian Splatting 重建的真实驾驶日志的闭环仿真器，含 345 场景“train”划分与 185 场景“test”划分，提供四个难度等级的反应式交通）与 AlpaSim（NVIDIA 的神经重建闭环仿真器，含 441 场景 NuRec 验证集）。
  • 模型规模：VaVAM 使用发布的 VaVAM-B 检查点，另有 VaVAM-S/-L 为同一架构与训练配方的更小与更大检查点。
  • 训练资源：ECO 不涉及训练；求解用 Xeon Gold 6238R CPU，中位数 31 次迭代、20.7 ms；对比 VaVAM 在 L40S GPU 上前向传播 44.7 ms；HUGSIM 与 AlpaSim 的控制周期分别为 250 ms 与 100 ms。

Card 06 评估与结果

评估与结果

  • 评估基准：主要闭环基准为 HUGSIM，另在 AlpaSim 评估；消融研究使用 HUGSIM test 划分的 nuScenes 子集。
  • 评估指标：HUGSIM 主指标 HD-Score（结合路线完成度 R_c 与逐步得分，其中无碰撞 NC 与可行驶区域 DAC 作为门控，TTC 与舒适度 COM 计入剩余得分）；AlpaSim 使用 e2e_challenge 分支标准指标，包括 scene score、route progress、m/incident、in corridor、off-road、at-fault collision；轨迹可行性定义“violating a limit”为预测轨迹有限差分超过 HUGSIM 运动限值（横摆角速度 0.95 rad/s、横摆角加速度 1.93 rad/s²、纵向加速度 [-4.05,4.89] m/s²、加加速度 8.37 m/s³），并定义 kinematic deficit 为违反至少一个限值的路点比例。
  • 关键数值：在 HUGSIM test（185 场景，3 个评估种子均值）上，VaVAM HD-Score 从 18.1±0.5 提升至 31.0±0.6（+12.9，+71%），UniAD 从 26.8±0.8 提升至 32.4±0.8，LTF 从 17.9±1.1 提升至 20.7±0.3，VAD 从 15.7±0.9 提升至 17.4±0.4，DrivoR 从 34.6±0.8 提升至 36.2±0.3；在 HUGSIM 的 nuScenes 子集（34 场景）上，VaVAM 的 HD-Score 从 23.1 提升至 39.6（+16.5），UniAD 从 27.8 提升至 37.3（+9.5），配对 ADE 变化仅 -0.03 m（VaVAM）与 +0.03 m（UniAD），配对 FDE 变化均为 +0.00 m；在 AlpaSim NuRec 验证集（441 场景）上，VaVAM（非线性 MPC）scene score 从 11.0 提升至 24.5（+123%），VaVAM（线性 MPC）从 32.8 提升至 39.2，DiffusionDrive 场景得分提升 22%。
  • 对比方法：生成式规划头包括 VaVAM（流匹配）与 DiffusionDrive（截断扩散）；确定性或基于提案的规划器包括 DrivoR、UniAD、VAD、Latent TransFuser（LTF）；后处理基线在同一终点约束下用替代轨迹整形算子替换 ECO。
  • 评估条件：主要为闭环仿真评估（HUGSIM 与 AlpaSim），另报告开环指标 ADE/FDE 作为对比；原文未报告实车评估。
