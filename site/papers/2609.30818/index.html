Card 03 核心贡献

核心贡献

  • 识别并刻画了多模态规划中的生成–评估不对称问题：强候选生成器已提供较高 oracle 潜力，但不完善的轨迹评估阻碍其被充分利用。
  • 提出 iDriveVLA 多模态规划框架，包含统一轨迹评估器：Safety-aware Scorer 用于候选质量与风险估计、过滤低质量候选，VLM-guided Modulator 用于场景自适应语义评估。
  • 提出 oracle 对齐的渐进式训练策略，包含候选模仿预训练、候选空间精炼和语义排序对齐三个阶段，同时提升候选质量与排序对齐。
  • 在公开 NAVSIM v1 榜单上取得 94.95 PDMS（论文摘要与结论口径）并排名第 1，超过人类专家参考分数 94.8 PDMS。
  • 在 NAVSIM v2 上取得 87.4 EPDMS 的最先进性能。
Card 04 方法描述

方法描述

  • 所属模块：多模态规划框架，由候选轨迹生成器与轨迹评估器构成；评估器包含 Safety-aware Scorer 与 VLM-guided Modulator。
  • 输入传感器：多视角视觉观测（multi-view observations）与前向视图图像；候选生成器输入为多视角视觉观测与自车状态（ego state）。原文未报告其他传感器类型。
  • 场景表示：由冻结 VLM 从前向视图图像和预定义驾驶提示词提取高层语义表示 z；Scorer 构建场景条件下的候选轨迹表示。
  • 模型结构与关键技术：

- 候选生成器：采用 DrivoR 的多模态规划器，生成 K 条未来轨迹候选（含未来位置与航向）。

- Safety-aware Scorer：由度量头预测六项结构化规划准则分数（NC、DAC、TTC、EP、DDC、Comf.），并由轻量安全头预测碰撞与偏离道路风险；通过安全掩码过滤高风险候选后，按场景自适应权重加权聚合分数并选取得分最高轨迹。

- VLM-guided Modulator：使用冻结 VLM（InternVL3-2B，以 ReCogDrive 预训练权重初始化）提取语义表示，由 DiT Modulator 在语义表示与候选特征条件下采样场景自适应准则权重向量；该模块仅改变准则加权方式，不修改候选轨迹本身。

- 训练策略：Stage 1 候选模仿预训练（best-of-K 模仿损失加评估器 BCE 监督）；Stage 2 候选空间精炼（奖励加权 RFT，权重为 exp(βR⋆)，加评估器监督）；Stage 3 语义排序对齐（冻结生成器、Scorer 与 VLM 主干，以 STAPO 优化 Modulator 作为语义排序策略）。

  • 原文未报告的信息：具体感知网络结构细节、传感器融合方式、轨迹时间步长 T 的数值。

Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM v1 与 NAVSIM v2。
  • 评估指标：NAVSIM v1 使用 Predictive Driver Model Score（PDMS）；NAVSIM v2 使用 Extended Predictive Driver Model Score（EPDMS），并报告 NC、DAC、DDC、TLC、EP、TTC、LK、HC、EC 等子指标（v2 采用原始评估代码、未加入人类行为过滤修正）。
  • 关键数值：NAVSIM v1 上 iDriveVLA 取得 94.9 PDMS（摘要写 94.95 PDMS），排名第 1，超过人类专家参考 94.8 PDMS；NAVSIM v2 上取得 87.4 EPDMS。文中指出 oracle 候选为 99.21 PDMS，而 DrivoR 学习评估器为 93.67 PDMS。
  • 对比方法：包括 PDM-Closed、人类驾驶员参考、UniAD、LTF、PARA-Drive、DriveX-S、World4Drive、DRAMA、DiffusionDrive、iPad、DrivoR、RAP、CLOVER、TOAD 等端到端方法，以及 UniVLA、FSDrive、AutoVLA、DriveVLA-W0、AdaThinkDrive、SpanVLA、ReCogDrive、ELF-VLA、SGDrive、FLARE、CLEAR、ChainFlow-VLA 等 VLA 方法；v2 上还对比 Ego Status、TransFuser、Hydra-MDP++、LaST-VLA 等。
  • 消融结果：从 DrivoR 基线 93.7 PDMS 出发，加入 Safety-aware Scorer 提升至 93.9，加入候选空间精炼提升至 94.2，再加入 VLM-guided Modulator 达到最佳性能。
  • 评估条件：论文报告的是 NAVSIM 上的闭环仿真评估结果；原文未报告开环评估或实车测试结果。
