Card 03 核心贡献

核心贡献

  • 提出 PriorMaskMap 鲁棒框架，核心为 Prior-Aware Confidence Estimator（PACE），将栅格化先验的每个网格相对当前视觉观测分类为可靠、错误、空白，生成逐网格置信图，自适应识别偏置先验中的可信区域。
  • 提出 Dual-Prior Query Generator（DPQG），以置信图引导掩蔽，分别编码栅格化与矢量化先验，过滤不可靠结构并融合为融合先验特征，通过交叉注意力初始化先验感知的地图查询。
  • 提出 Confidence-Guided Prior Fusion（CGPF），对初始置信进行空间传播（Spatial Confidence Propagation）与置信精化（Confidence Refinement Module），用精化掩码控制 BEV 特征与先验地图的融合，为地图解码器提供上下文表示。
  • 扩展 nuScenes 数据集，补充一组模拟多车道结构偏差的偏置矢量化地图，并实验表明 PriorMaskMap 相比现有方法具有更高精度和对不准确先验的更强鲁棒性。
Card 04 方法描述

方法描述

  • 所属模块：在线矢量化 HD 地图构建，属于先验增强的在线建图框架；整体由 PACE、DPQG、CGPF 三部分组成。
  • 输入传感器：多视角环视 RGB 相机图像（nuScenes 六路相机）以及带偏置的先验地图（栅格化先验与矢量化先验）。
  • 场景表示：鸟瞰图（BEV）栅格表示；BEV 特征为 F_BEV ∈ R^{H×W×C}，栅格化先验为 M_R ∈ R^{H×W×3}，置信图为 M_conf ∈ R^{H×W×3}（reliable / erroneous / empty 三类）。
  • 模型结构：

- PACE：将 F_BEV 与栅格化先验沿通道拼接后输入 U-Net 头，输出逐网格置信；训练时以图像块级 Bernoulli(α) 混合真值栅格与偏置栅格构造输入，标签始终由 (M_Rgt, M_Rerr) 网格级对比生成，使用 Focal Loss 缓解类别不平衡。

- DPQG：矢量化支路对点的实例索引、顺序、2D 位置、语义类型做嵌入，采用类内与类间分层注意力；依据置信得到栅格掩码与点级掩码，将不可靠/空白区域点特征置零；栅格支路用位置嵌入与标签嵌入得到 F_Ras 并仅保留置信网格；两路 token 拼接为 F_fuse，通过交叉注意力更新可学习基础查询得到 Q_map。

- CGPF：Spatial Confidence Propagation 计算非空条件下的可靠比例 r(u)，分 T 个置信带，用不同核参数 D_κℓ 与权重 w_ℓ 做扩散得到 D_m，并以 F_enh = F_BEV + D_m ⊙ F_PV 注入多视角证据；Confidence Refinement Module 将 F_enh 与栅格化先验拼接经浅层 CNN 与 sigmoid 得到 G(u)，与 m_rel 相乘得精化置信 β(u)，仅对先验支路加权后与 F_enh 融合得到 BEV 地图上下文 F_ctx，作为地图解码器的 Key 和 Value。

  • 关键技术：先验可靠性显式估计、置信引导掩蔽、双先验（栅格+矢量）查询生成、置信带扩散式空间传播、晚期融合权重精化；解码器与损失沿用 MapTRv2 系列设置。
  • 原文未报告：网络各模块的具体通道数、U-Net 与注意力层数、推理时延等细节原文未报告。
Card 05 数据集与资源

数据集与资源

  • 数据集：nuScenes（1000 个城市驾驶场景，约 20 s/场景，2 Hz，六路环视相机，官方 700/150/150 划分）；Argoverse2 仅提及含少量偏置地图但规模不足，未作为主要数据。

Card 06 评估与结果

评估与结果

  • 评估基准：nuScenes 验证集在线矢量化地图构建基准；使用官方 Chamfer 距离阈值 {0.5, 1.0, 1.5} m 的 class-wise AP 与 mAP，预测范围为 X 轴 [-15,15] m、Y 轴 [-30,30] m；评估仅输入偏置地图（Err. 标记）。
  • 评估指标：AP_ped、AP_div、AP_boun 与 mAP。
  • 关键数值：PriorMaskMap（R50，24 epoch，偏置先验）AP_ped 78.1、AP_div 85.1、AP_boun 80.9、mAP 81.4；110 epoch 设置下 AP_ped 81.7、AP_div 88.9（其余数值在提供的原文中被截断，原文未完整报告）。
  • 对比方法：第一类为不依赖先验/历史的方法（StreamMapNet 58.1、MGMap 64.8、HIMap 66.7、MapQR 66.4、Mask2Map 71.6、MapTRv2 61.5、DAMap 72.6，均为 mAP）；第二类为先验/历史方法（SQD-MapNet 63.9、P-MapNet 53.1、MapTracker 76.1、PriorMapNet 67.1、PriorDrive 65.7、HRMapNet 67.2、PrevPredMap 67.6、UniPrevPred 74.0、PriorFusion 70.4）；第三类为在相同混合偏置设置下重训的基线（SQD-MapNet† 55.5、PrevPredMap† 64.3、HRMapNet† 79.7（24 epoch）、HRMapNet† 83.4（110 epoch））。
