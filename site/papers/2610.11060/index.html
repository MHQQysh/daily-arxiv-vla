Card 03 核心贡献

核心贡献

  • 提出 AffordDrive3D，一个基于 VLA 框架的可行驶性与几何感知世界-动作模型，将未来世界建模从视觉外观扩展到与规划目标更对齐的空间结构。
  • 联合建模未来几何与时间维度的驾驶可行驶性：以 RGB 世界模型潜变量为条件的未来深度预测刻画预测场景的空间结构，可行驶性预测识别可行驶区域与碰撞关键区域，将未来空间信息与自车运动联系起来。
  • 在 NAVSIM 基准上取得 91.3 PDMS 和 89.9 EPDMS 的新 SOTA（相比同样使用未来深度预测的 ExploreVLA 提升 0.9 PDMS、1.1 EPDMS）。
  • 消融与定性实验支持时间可行驶性预测和未来几何建模对轨迹规划的有效性。
Card 04 方法描述

方法描述

  • 所属模块：端到端 VLA / 世界-动作模型；包含四个共享骨干下的分支——可行驶性分支、RGB 世界模型分支、几何分支和动作分支。训练时辅助分支（可行驶性、未来 RGB、RGB 条件深度）塑造共享表示，推理时只需动作分支解码轨迹。
  • 输入传感器：多视角相机图像（C=3 个视角）、导航命令、自车状态；原文未报告使用 LiDAR 或雷达等其他传感器。
  • 场景表示：未来 RGB 以视频 VAE 编码的时序潜变量表示（T=3 个潜变量组，含当前帧 anchor 与未来序列）；几何以潜空间深度表示；可行驶性以图像视觉 token 网格上的稠密图表示（可行驶区域图为 [0,1] 软值，碰撞关键区域图为二值）。
  • 模型结构：以 Qwen3-VL-2B 为共享因果 VLM 骨干，联合四组可学习 token（可行驶性 token 27 个、RGB 世界 token 64 个、几何 token 64 个、动作 token 8 个）。RGB 世界模型为 Wan2.1-Fun-1.3B-InP 视频扩散模型（inpainting 形式、flow matching）；几何分支将几何 token 隐状态映射为粗时空特征网格，三线性上采样后与经 3D 卷积映射的去噪 RGB 潜变量融合（带 stop-gradient），再由 3D 残差块细化，并用 anchor/future 两个独立深度解码器；可行驶性分支通过 affordance 隐状态与视觉 token 的点积注意力解码出每个相机视角的稠密图；动作分支用 DiT 以 flow matching 生成轨迹，并对 RGB/几何隐状态附加基于 GRU 的轻量轨迹头监督。
  • 关键技术：以未来 RGB 潜变量为条件的深度预测（避免几何分支独立预测未来动态，并保持 RGB 与几何预测落在同一未来场景）；时间可行驶性预测（当前帧与未来帧的可行驶区域、碰撞关键区域）；可行驶性监督采用加权软 BCE（可行驶区域）与类别归一化 BCE + Dice（碰撞区域）；总损失为可行驶性、RGB、几何、动作及 RGB-动作、几何-动作辅助损失的加权和；SFT 后使用 GRPO 强化学习仅优化动作扩散模型。

Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM v1（PDMS 及 NC、DAC、TTC、Comf.、EP）与 NAVSIM v2（EPDMS 及 NC、DAC、DDC、TLC、EP、TTC、LK、HC、EC），遵循官方评测协议；另用平均精度 AP 评估时间可行驶性预测（可行驶比例大于 0.5 视为可行驶）。
  • 关键数值（NAVSIM v1）：PDMS 91.3、NC 98.6、DAC 99.0、TTC 96.3、Comf. 100.0、EP 84.7，为表中最佳 PDMS；ExploreVLA 为 90.4 PDMS，DriveVLA-W0 为 90.2 PDMS，ReCogDrive 为 90.8 PDMS。
  • 关键数值（NAVSIM v2）：EPDMS 89.9，为表中最佳；相比 ExploreVLA（88.8）提升 1.1，相比 DriveDreamer-Policy（88.7）提升 1.2；DDC 99.7、TLC 99.9、HC 98.3 为表中最佳。
  • 消融（无 RL 训练，NAVSIM v1）：仅动作 88.1 PDMS；+Affordance 89.2；+RGB 88.9；+Geometry 89.1（RGB 仅提供潜变量上下文且梯度不回传骨干）；完整模型 89.6 PDMS，NC/DAC/EP 最优。
  • 时间可行驶性评估：当前帧碰撞关键 AP 0.918、可行驶区域 AP 0.986；近程（0.5–2 s 平均）分别为 0.846 和 0.983；远程（2.5–4 s 平均）分别为 0.732 和 0.971，碰撞预测随预测时域下降更明显。
  • VLM 表示中的可行驶性信息：冻结 VLM 时当前帧碰撞/可行驶 AP 为 0.782/0.931，解冻后提升至 0.912/0.985。
  • 对比方法与定性结果：与 DRAMA、Hydra-MDP、DiffusionDrive、AutoVLA、ReCogDrive、WoTE、ResWorld、DrivingGPT、Epona、PWM、DriveVLA-W0、DriveDreamer-Policy、FSDrive、ExploreVLA、OWMDrive 等比较；定性上在窄弯道场景中基线驶离道路而本方法保持车道中心，在前车制动场景中基线发生碰撞而本方法保持安全距离，碰撞关键预测在各未来时域正确突出前车。
  • 评估条件：全部为 NAVSIM 开环仿真评测，原文未报告闭环评估或实车实验。
