Card 03 核心贡献

核心贡献

  • 提出前馈 4D Segment Anything 模型：将共享的视觉-几何表示转换为穷举的类无关 4D 实例掩码，每个持久对象查询在整个观测集合中绑定同一实体身份，无需种子掩码或时间顺序。
  • 支持统一提示接口：在穷举分割之外，允许通过来自一个或多个观测的点/框提示选择任意已发现实例，且不破坏无提示实例发现能力。
  • 提出面向 4D 观测空间的智能体式语言定位框架：结合 VLM 视觉先验与几何一致的实例特征，通过双流 Grounder、Active Tree Search 和比较式 Critic 选择最终 4D 掩码。
  • 构建跨静态与动态场景的大规模训练数据与自蒸馏训练策略：整合 19 个多视图与视频数据集，共 33,220 个场景/片段和 6.05M 观测，并将穷举标注教师模型用于部分标注和无标注数据的掩码稠密化。
  • 在统一评测下报告了 4D 实例分割的最优性能和较强的语言引导定位性能，覆盖静态多视图与动态视频基准。
Card 04 方法描述

方法描述

  • 所属模块：S4VY 由 4D 分割器（Space-Time Query Decoder + Prompt Encoder）和语言定位框架（Grounder、Active Tree Search、Critic）组成。
  • 输入传感器：仅使用 RGB 观测，论文未报告其他传感器输入；观测可时间稀疏或非时序排列。
  • 场景表示：基于前馈视觉几何骨干（VGGT-Ω，Wang et al., 2026a），每个观测由 patch tokens、camera token 和 register tokens 表示，并通过帧内与跨帧交替注意力联合上下文化；分割器解码上下文化的 patch tokens，register tokens 保留给语言定位接口。
  • 模型结构：Space-Time Query Decoder 采用 Mask2Former 式端到端集合预测，使用全局可学习对象查询联合关注 LoRA 适配后的 patch tokens，输出每个查询的完整 4D 掩码；训练时通过二分匹配将每个真值 4D 实例分配给唯一可学习查询，未匹配预测归为 no-object。Prompt Encoder 从上下文化 patch tokens 中采样点/框提示的局部视觉特征，聚合为可提示对象查询，并通过单向自注意力让其与对应可学习查询匹配，同时阻止提示信号影响可学习查询；多观测提示使用学习到的相关性权重抑制遮挡、不精确或不一致的局部证据；训练时扰动点和框坐标以提升定位误差容忍度。
  • 语言定位：Grounder 以表达式、图像、camera token 和 register token 为输入，输出每帧对象查询匹配与框提示预测；采用几何引导的思维链监督，注入物体尺寸、高度、物体间距离等场景线索。双流分别产生查询匹配掩码候选和框提示掩码候选。Critic 使用独立 VLM 对两个候选的叠加渲染进行成对偏好判断，选择与表达式更匹配的最终 4D 掩码；Grounder 用查询交叉熵和自回归语言建模损失优化，Critic 用二元交叉熵优化。
  • Active Tree Search：从覆盖全观测集的全局窗口开始，每层均匀采样 N_w 个观测，Grounder 预测每个采样观测的目标存在性；围绕正预测的相邻采样位置确定下一层子范围，递归重采样形成新的 Grounder 窗口，直到窗口内仅含相邻帧或达到最大深度；所有窗口预测通过投票聚合形成两个流的候选掩码，再交由 Critic 比较。
  • 训练与数据：整合 19 个多视图/视频数据集分为四组（穷举多视图、穷举视频、部分标注视频 masklet、无标注多视图）；先利用穷举数据训练教师模型，再以时序一致 masklet 稠密化部分标注并监督无标注数据，人工标注优先，重叠教师预测被移除，不确定区域忽略；分割器经匈牙利匹配后使用物体分类、二元交叉熵和软 Dice 损失训练，训练逐步从伪标注池转向穷举数据；Prompt Encoder 可在分割器冻结时单独训练，报告结果采用该设置。

Card 06 评估与结果

评估与结果

  • 评估基准：无提示实例分割在 ScanNet 验证设置、DAVIS、LVOS、VIPSeg 上评测；语言引导定位在 ScanRefer、ScanNet++、Ref-DAVIS、MeViS 上评测。
  • 评估指标：ScanNet 使用 T-mIoU、T-SR、J&F；DAVIS 和 LVOS 使用 4D-IoU、4D-SR、J&F；VIPSeg 使用 STQ 和 mAP；静态场景语言定位使用 3D 掩码 mIoU 与 IoU 0.25 下的框/掩码准确率，视频使用 J&F。
  • 关键数值：S4VY 在 ScanNet 上达到 0.803 T-mIoU 和 0.792 T-SR；在 DAVIS 和 LVOS 上分别达到 0.803 和 0.602 J&F；论文称在表中所有分割基准上领先，STQ 和 mAP 的提升将结果扩展到密集全景评测。原文还报告在 100 个观测上测量延迟（s/clip，A100-80GB），但所给表格内容截断，未显示 S4VY 的具体延迟数值。
  • 对比方法：分割对比包括 SAM3D、DEVA、GLEE、OMG-Seg、SAM 2、PanSt3R 等；语言定位对比覆盖 VLM–分割器与 3D 提议管线、端到端图像/视频指代模型、多视图几何–语言对齐方法，包括 VLM+SAM 2、MVGGT、Z3D、SAM 3 等。官方检查点接收相同观测，不使用语义标签、目标提示或首帧真值；SAM 2 使用自动掩码发现并周期性重新发现，内存密集型基线保留全部观测进行全序列或流式推理。
  • 实验条件：论文报告的是开环离线评测，包含静态多视图与动态视频的仿真/数据集评测；原文未报告闭环控制、实车部署或在线机器人实验。
