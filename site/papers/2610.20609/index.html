SafeDriveVLA: Navigation-Conditioned World Model Dreaming for Conflict-Aware End-to-End Autonomous Driving

2026-10-14 · 原文 · 翻译 · 2610.20609

Card 02 论文概述

论文概述

  • 论文面向端到端自动驾驶中的 Vision-Language-Action（VLA）模型，研究其以自然语言指令等开放式导航信号作为输入时的安全问题。

Card 03 核心贡献

核心贡献

  • 提出首个同时评估导航跟随与冲突感知（并包含对抗鲁棒性）的基准套件，包含 CARLA-F、B2D-C、NavSim-C 和 B2D-Adv。
  • 设计显式的三级导航遵从模式（strict、cautious、fallback），对每个专家帧进行重标注，并在动作 token 之前输出模式 token，从而将冲突推理与动作生成解耦。
  • 提出导航条件化的世界模型 dreaming：与先前在世界模型中回放专家或规划动作不同，该方法在严格遵循导航信号所隐含动作的条件下推演未来潜变量，以显现跟随是否安全。
  • 构建基于 InternVL3-1B 的自回归 VLA，结合离散动作码本与辅助路径头，并支持命令、目标路点、语言指令三种导航模态。
  • 在 Bench2Drive 取得 88.16 DS 与 68.64% SR，将闭环语言跟随平均 NCR 提升至 83.0%，并在 B2D-C 上将碰撞从 60 降至 38。
Card 04 方法描述

方法描述

  • 所属模块：端到端驾驶 VLA，包含驾驶模式归因、潜在世界模型、VLA 三个组件；输入为前视相机帧与导航信号（离散命令、目标路点或自然语言指令）。
  • 场景表示：世界模型基于冻结的 V-JEPA 2 ViT-L 目标编码器，使用连续两帧编码一个潜变量（携带 0.25 s 运动信息），在 2.5 s 时域、2 Hz 下进行动作条件化预测。
  • 世界模型结构：Transformer 动作条件预测器从零训练，采用教师强制与自回归损失；训练时冻结，推理时按导航信号隐含的 meta-command 选择动作锚点，从当前潜变量向前推演 5 步得到 dreamed latents。
  • VLA 结构：InternVL3-1B 主干经 LoRA 微调，输出模式 token（<STRICT>、<CAUTIOUS>、<FALLBACK>）后接 <ACTIONS> 分隔符及 T=10 个离散动作 token（4 Hz，对应 2.5 s），动作来自 N=2048 的运动基元码本；轻量 MLP 头在 <ACTIONS> 隐状态上回归 20 个自车坐标系路径点，供横向 PID 控制，纵向速度由离散动作 token 积分得到。
  • 关键技术：按 meta-command 预计算动作锚点（对 2.5 s 训练轨迹取平均，变道锚点经标定）；语言指令通过词表匹配解析为 meta-command；未来专家轨迹仅用于构造训练标签，推理时不使用。
  • 原文未报告明确的世界模型参数量与 VLA 总模型规模。

Card 06 评估与结果

评估与结果

  • 评估基准：Bench2Drive 闭环、CARLA-F 闭环、B2D-C 闭环、B2D-Adv 闭环，以及 NavSim-C 的评估型诊断（作者说明因 SafeDriveVLA 为 CARLA 训练的单视图模仿模型而未在其上评测）。
  • 评估指标：DS、SR、Efficiency、Comfortness；CARLA-F 使用 Navigation Compliance Rate（NCR）与 Speed Error（SE）；NavSim-C 使用 NC、DAC、TTC、comfort、EP 与 PDMS；B2D-C 额外报告碰撞、交通违规、偏离路线次数。
  • Bench2Drive 结果：SafeDriveVLA 在 WP 导航下达到 88.16 DS、68.64% SR、264.51 Efficiency、30.14 Comfortness；在 CMD 导航下为 87.29 DS、68.18% SR；相较 SimLingo（同源 PDM-Lite 数据）平均提升 +2.15 DS 与 +1.89% SR。
  • CARLA-F 结果：语言指令下平均 NCR 83.0%（左变道 63.6%、右变道 72.4%），SimLingo 系列最高仅 55.6% 且两个变道方向均为 0%；命令输入下 SafeDriveVLA 为 78.8%，SimLingo 为 73.6%；命令专用模型 ORION 平均 NCR 为 87.8%，高于 SafeDriveVLA，作者归因于其容量集中于少量离散命令。
  • B2D-C 结果：SafeDriveVLA 达到 85.9 DS、67.3% SR，碰撞 38（较最佳 SimLingo 变体降低 36.7%）、交通违规 9（降低 85.2%）、偏离路线 4（降低 63.6%）；SimLingo-Safe 为 72.8 DS、38.0% SR、60 次碰撞。
  • NavSim-C 诊断：所有被测模型在冲突命令下显著退化；AutoVLA PDMS 从 88.2 降至 70.7、DAC 降至 79.0；DriveVLA-W0 与 ReCogDrive 分别下降 10.1 与 8.8 PDMS；CuriousVLA 表现最好，PDMS 84.4（下降 6.2）、EP 85.4。
  • B2D-Adv 结果：对抗指令使 SimLingo DS 从 95.7 降至 76.0，SafeDriveVLA 从 94.7 降至 83.9（退化 10.8 对 19.7）；无模式 token 与世界模型输入的同主干模型退化最大（93.0 降至 69.7）。
  • 世界模型探针：预测潜变量在 0.5–2.5 s 各时域的危险 AUC 均高于首帧潜变量（如 1.5 s：0.73 对 0.65，oracle 0.75，恢复 78%），并恢复 oracle 增益的 49–78%；真值动作回放的 ℓ1 距离小于零动作与镜像动作。
  • 消融：论文以 CARLA-F NCR 对 B2D-C DS 的 Pareto 前沿分析各设计选择，指出提示与数据扩增等朴素干预会在两个目标间此消彼长（如 SimLingo-IF 仅提升 NCR 3.2 点，却使 B2D-C DS 下降 16.5、碰撞从 66 增至 166）。
