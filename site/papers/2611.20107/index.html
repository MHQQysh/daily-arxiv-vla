Card 03 核心贡献

核心贡献

  • 形式化了自动驾驶中世界模型规划的探索–利用困境，指出超出模型覆盖范围的搜索可能改进数据，但模型误差会偏置动作选择，并在方法部分形式化陈述该偏置及其导致的后悔。
  • 提出由专家评判的“他人失败”数据配方：部分训练智能体与脚本化、可恢复扰动在仿真中产生失败并运行至后果，专家对每个访问状态标注其动作与价值，使数据覆盖规划器将要探索的多数区域。
  • 提出快速分块隐空间世界模型及碰撞风险头，风险头在制动方向上训练为单调，可在真实记录的行驶中提前预见碰撞且无误报；并配合风险感知 MPPI 规划器，以预测回报减去有界碰撞惩罚评分候选动作块，在单 GPU 上实时规划。
  • 提出在线自适应规则，用规划器自身行驶扩展覆盖范围：微调动力学、奖励评分器与风险头，规划时使用慢速移动的 EMA 副本，且自适应这些头而非仅动力学可使各类碰撞更少。
  • 完成闭环评估，在 CARLA（含无训练数据的城镇）逐阶段隔离贡献，并在 MetaDrive 常规与安全关键交通中与基线对比；一轮针对离线语料覆盖最少场景的数据飞轮可进一步提升安全性。
Card 04 方法描述

方法描述

  • 所属模块：基于世界模型的闭环规划框架，包含四部分：Stage/Annotate 数据生成与专家标注、Foresee 分块隐空间世界模型与碰撞风险头、Evaluate 风险感知 MPPI 规划、Refine 在线自适应。
  • 输入传感器：CARLA 使用特权鸟瞰视图（BEV）掩码栈与自车状态，BEV 为 15×192×192 的通道栈，覆盖 38.4 m×38.4 m、5 像素/米，含 3 个静态通道与 3 组动态通道在 4 个时间偏移上的栅格化，自车状态为 6 维；MetaDrive 使用 101 维向量观测（30 束车辆激光、30 束道路边缘、12 束车道线、自车状态、导航值、横向偏移及最近三辆车信息）。原文未报告使用摄像头或激光雷达原始点云。
  • 场景表示：POMDP 形式化，动作由加速度命令与转向命令组成，范围 [-1,1]；上下文长度 C=16、规划时域 H=16，在 0.1 s 步长下对应 1.6 s 历史与 1.6 s 时域。
  • 模型结构：观测编码器输出 256 维隐状态并由专家特征提取器初始化；2C 个上下文 token 含隐状态 token、动作 token、类型嵌入与正弦位置编码；4 层、宽度 256、4 头的因果 Transformer 解码器在一次前向中预测整块未来隐状态；奖励与价值评分器为小时间 Transformer；预测奖励分布、5 个物理奖励因子、延续概率与 K=5 个价值头；行为克隆动作先验为独立的 3 层 Transformer 解码器，输出压缩高斯参数。
  • 关键技术：碰撞风险头仅用仿真器记录结果监督，并训练为制动更强不提高预测风险，规划中以有界碰撞惩罚引入；MPPI 以行为克隆先验为种子，每 0.1 s 对 135 个候选动作块评分、两次迭代、每次保留 16 个最优候选并执行首个动作；在线自适应更新动力学、奖励评分器与风险头，编码器、先验与价值保持冻结，规划使用 EMA 评分目标。

数据集与资源

Card 06 评估与结果

评估与结果

  • 评估基准：CARLA Leaderboard 路线与 MetaDrive/CAT 闭环基准，包含常规交通与安全关键交通；CARLA 闭环消融还包含无训练数据的城镇。
  • 评估指标：路线完成度、每步奖励、回合奖励、碰撞等安全事件，以及开环/闭环对比与计算效率分析。
  • 关键数值：在 CARLA Leaderboard 路线闭环对比中取得最高路线完成度与每步奖励，分别为 0.95 与 0.77（特权鸟瞰视图）；在 MetaDrive 中取得最高回合奖励，常规交通为 53.4，安全关键交通为 49.0。
  • 对比方法：离线消融中与行为克隆先验单独执行等变体对比；闭环对比中与学习型驾驶策略、基于世界模型的规划方法等基线比较，具体基线名单见原文实验部分。
  • 实验条件：开环分析包括风险预测的可达性视角与世界模型想象的可解释性；闭环评估在 CARLA 与 MetaDrive 仿真中进行，原文未报告实车验证。
