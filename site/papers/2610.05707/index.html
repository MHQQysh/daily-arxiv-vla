Card 02 论文概述

论文概述

  • 论文面向自动驾驶感知中的视觉目标跟踪（Visual Object Tracking, VOT）任务，用于对行人、自行车、车辆等周围交通参与者进行连续定位，支撑交互预测、换道规划、碰撞避免、跟车控制等安全关键功能。
  • 应用场景强调车载跟踪模块需在严格的计算、散热和时延预算下运行，同时保持复杂动态环境中的鲁棒性。
  • 研究问题：Transformer 跟踪器精度高但计算与内存开销大，难以部署在实时、资源受限平台；现有跟踪知识蒸馏方法主要为实例级（instance-wise），只让学生逐样本模仿教师的绝对特征图，忽略了教师特征空间中跨样本的批内拓扑（inter-sample relational knowledge）。
  • 论文提出 Difference Feature Map Knowledge Distillation（DFM-KD，差异特征图蒸馏），通过迁移样本间特征差异来对齐教师与学生的关系结构。
Card 03 核心贡献

核心贡献

  • 提出一种新的蒸馏机制，通过对齐样本间差异特征图来迁移教师的批内拓扑，捕获实例级方法忽略的结构知识。
  • DFM-KD 灵活，可选择性地应用于任意 Transformer 层，使实践者能针对信息量最大的层进行蒸馏并减少开销。
  • 证明 DFM-KD 可无缝集成到现代 Transformer 跟踪器（如 STARK、MixFormerV2），并在最小计算成本下显著提升跟踪精度和成功率。
  • 通过消融实验表明 DFM 项与标准特征级蒸馏项互补，二者结合取得最佳整体性能。
  • 指出差异特征图仅沿 batch 维度用相邻样本差分构造，将复杂度由 O(B²) 降到 O(B)，保持轻量。
Card 04 方法描述

方法描述

  • 所属模块：知识蒸馏框架，作用于 Transformer 跟踪器的中间层输出 token embeddings，可跨编码器-解码器结构（STARK）与纯 Transformer 堆栈（MixFormerV2）使用。
  • 输入传感器：原文未报告具体传感器类型；数据为 LaSOT 视频序列的 tracking pair（template, search area）或 triplet（template, online template, search area）。
  • 场景表示：对某一 Transformer 层 ℓ，教师与学生特征张量表示为 F^T_ℓ ∈ R^{B×N×C} 与 F^S_ℓ ∈ R^{B×N×C}，其中 B 为 mini-batch 大小，N 为 token 数（template 与 search token 合计），C 为通道/embedding 维度。
  • 模型结构：不修改跟踪器主干结构；学生模型通过减少 Transformer 层数构造（STARK 12→6 层；MixFormerV2 12→8 层）；教师与学生层按固定规则（如均匀间隔选择教师层）一一对齐，蒸馏直接作用于对应 Transformer 输出。
  • 关键技术一：基线特征级蒸馏，按逐样本方式最小化教师与学生激活之间的 MSE：

L^(ℓ)_feat = 1/(BNC) Σ_b Σ_n Σ_c (F^S_{ℓ,b,n,c} − F^T_{ℓ,b,n,c})²。

  • 关键技术二：差异特征图构造，沿 batch 维度取离散差分：

D^T_{ℓ,i,n,c} = F^T_{ℓ,i+1,n,c} − F^T_{ℓ,i,n,c}，i = 1,…,B−1；

D^S_{ℓ,i,n,c} = F^S_{ℓ,i+1,n,c} − F^S_{ℓ,i,n,c}，i = 1,…,B−1。

得到 D^T_ℓ, D^S_ℓ ∈ R^{(B−1)×N×C}，可理解为沿样本维度的“有序 batch-wise 导数”，编码外观变化、上下文相似性和结构关系。

  • 关键技术三：DFM loss，对教师与学生的差异特征图计算 MSE：

L^(ℓ)_DFM = 1/((B−1)NC) Σ_{i=1}^{B−1} Σ_n Σ_c (D^S_{ℓ,i,n,c} − D^T_{ℓ,i,n,c})²。

  • 关键技术四：多层级聚合与总体目标：

L_DFM = Σ_{ℓ∈L_d} α_ℓ L^(ℓ)_DFM；

L_total = L_track + λ_feat L_feat + λ_DFM L_DFM。

  • 设计说明：不对 D^T_ℓ 与 D^S_ℓ 做归一化，以同时保留方向和相对强度信息；使用数据加载器提供的随机打乱 mini-batch 顺序，因此相邻差分编码通用样本间关系而非特定时间顺序；未采用全对差分以避免 O(B²) 复杂度。

Card 06 评估与结果

评估与结果

  • 评估基准：LaSOT-RoadUsers（基于 LaSOT2019 构建），遵循官方 LaSOT 协议。
  • 评估指标：AUC、Precision（P）、Normalized Precision（NP）。
  • 条件：论文报告的是跟踪精度与成功率评估，原文未明确报告开环、闭环、仿真或实车测试条件。
  • MixFormerV2 对比（TABLE I）：教师 75.33 AUC / 81.10 P / 86.66 NP；学生 MixFormerV2 73.21 / 77.90 / 84.27；TDSC-KD 73.78 / 78.39 / 84.74；DFM-KD 74.03 / 78.85 / 85.25。DFM-KD 相较 vanilla student 提升 NP +0.98，相较 TDSC-KD 提升 NP +0.51。
  • STARK 对比（TABLE II，FLOPs 仅计 Transformer 部分）：教师 68.63 / 72.91 / 79.95；Student-baseline 64.20 / 62.77 / 72.07；Conventional KD 65.94 / 67.98 / 74.59；DFM-KD 68.76 / 72.17 / 78.65。DFM-KD 显著缩小师生差距并在 AUC 上超过教师，且未增加参数或 FLOPs。
  • STARK 消融（TABLE III）：Baseline 64.20 / 62.77 / 72.07；Feat-only 65.94 / 67.98 / 74.59；DFM-only 67.81 / 70.70 / 77.75；DFM-KD（combined）68.76 / 72.17 / 78.65。DFM-only 提升大于 Feat-only，两者结合在三个指标上均最佳。
  • 定性结果：在 bicycle、bus、truck 等序列上，DFM-KD 相比学生基线在遮挡、视角变化和干扰物条件下给出更稳定、更紧致的定位；基线在遮挡增加时框逐渐缩小并最终跟踪失败，而 DFM-KD 保持准确定位。
