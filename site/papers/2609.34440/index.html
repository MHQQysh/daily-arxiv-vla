Card 03 核心贡献

核心贡献

  • 提出对评分过程“执行—测量—子分数映射—聚合”的分解，并用该分解定位分数不敏感性可能出现的三类盲点：遗漏、子分数映射不敏感、请求与被打分运动之间的变换。
  • 通过受控干预构造并验证被评分忽略的行为维度：PDMS 对驾驶方向合规（DDC）聚合权重为零，错向轨迹在保持其他被打分属性近似不变时，平均 PDMS 差异仅约 1.9×10⁻⁵。
  • 展示阈值化会掩盖通过区间内的连续行为差异，并通过固定输出重打分、分数并列分析和连续运动诊断揭示在通过区域内仍存在行为变化。
  • 通过闭环比较说明优化收益依赖执行接口：在两个执行接口下比较 IL 与 RL 规划器时，分数增益可能反转，表明增益会随请求如何被执行并作为反馈返回而变化。
  • 在 NAVSIM 和 nuPlan 上对多个已发布检查点进行大规模配对分析，给出分数提升与行为诊断不一致的实证证据，并讨论指标应保留哪些行为区分以及在优化后如何重新评估指标有效性。

Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM-v1 navtest 使用 PDMS；NAVSIM-v2 navhard 使用 EPDMS，并将驾驶方向合规作为门控，加入车道保持与舒适度组件；nuPlan val14 使用闭环分数 CLS；WorldEngine 用于闭环重规划诊断。
  • 评估指标：聚合分数（PDMS、EPDMS、CLS）、EPDMS 组件（DDC、LK、HC/HC 舒适度）、行为诊断（DDC-v1/v2、Jitter、Smoothing、Adherence、历史舒适度、纵向 jerk 峰值等）；统计上使用场景与日志 bootstrap 区间以及 Holm 调整检验。
  • 关键数值：PDMS 公式中 NC/DAC 为惩罚项，EP/TTC/C 权重为 5/5/2，NC 对静态物体碰撞赋 0.5，DDC 聚合权重为零；匹配错向轨迹在 37 个 navhard 场景、42 对样本中平均逆行驶 8.80 m，平均 PDMS 差仅 1.9×10⁻⁵。
  • 关键数值：在 NAVSIM 评测配置中舒适度仅在 0.14% 的 planner–scene 评估中失败；DiffusionDrive v2 在 450 个 navhard 场景中有 274 个场景存在多个 PDMS 最大化解且 heading jitter 不同。
  • 关键数值：ReCogDrive-2B IL→RL 的 PDMS 从 0.863 提升至 0.905（+0.042），但 DDC-v2 从 0.993 降至 0.982（−0.011），HC 从 0.980 降至 0.967（−0.013），Jitter 从 0.50 升至 1.69（+1.19），Smoothing 从 0.105 升至 0.288（+0.183），Adherence 从 0.575 升至 0.893（+0.319）。
  • 关键数值：ReCogDrive-8B IL→RL 的 PDMS 从 0.869 提升至 0.903（+0.035），DDC-v2 从 0.994 降至 0.989（−0.005），LK 从 0.857 降至 0.832（−0.025），Jitter 从 0.64 升至 1.56（+0.92）。
  • 关键数值：Qwen-Drive IL→RL 的 PDMS 从 0.879 提升至 0.905（+0.026），EPDMS 从 0.854 提升至 0.873（+0.019），但 DDC-v2 从 0.996 降至 0.995（−0.001）、LK 从 0.863 降至 0.851（−0.012）、Jitter 从 0.48 升至 0.55（+0.07）、Smoothing 从 0.116 升至 0.212（+0.097）。
