Card 02 论文概述

论文概述

  • 论文面向端到端自动驾驶，研究视觉中心潜在世界模型（latent world model）中每帧数千个图像 token 的计算与注意力开销问题。
  • 应用场景为带 LiDAR 与雷达的自动驾驶车辆（L4 类平台），在 nuScenes 与 NAVSIM 上进行轨迹规划、运动预测与安全关键覆盖评估。
  • 核心研究问题：能否在视觉骨干网络编码之前，仅依据 LiDAR/雷达测得的 3D 几何决定哪些图像 patch 值得编码，从而同时降低计算量并缓解规划器的注意力稀释。
Card 03 核心贡献

核心贡献

  • 提出 Geometry-Aware Token Selection（GATS）：用 LiDAR 几何、多帧运动残差与雷达径向速度三路打分，在视觉骨干运行前选出固定比例的图像 token（如 10% 或 25%），使被丢弃的 patch 完全不产生视觉编码开销。
  • 指出并验证“注意力稀释”瓶颈：随机丢弃 75% token 已优于稠密模型（3 s L2 0.550 m vs. 0.573 m），说明瓶颈在于无关内容对规划器注意力的竞争。
  • 提出 3D 锚定 token 与自监督潜在世界模型：每个保留 token 以其 LiDAR 点中值 3D 位置为锚点，实现跨相机关联、基于里程计的历史帧对齐，并通过特征-几何匹配生成伪流目标来预测未来特征与 3D 位移，无需框标注。
  • 报告安全关键覆盖优势：在 739 个意图关键场景中覆盖 95.8% 的危险车辆（随机 81.5%、学习式选择器 70.0%），碰撞率 0.09%，比稠密模型（0.34%）低 73.5%。
  • 报告端到端效率：25% 预算下 nuScenes L2 0.520 m、NAVSIM EPDMS 88.9，均优于稠密基线，总 FLOPs 减少 6.6 倍；10% 预算（24 GFLOPs，18 倍减少）仍在两个基准上超过稠密基线。
Card 04 方法描述

方法描述

  • 所属模块：端到端规划流水线，包含几何感知 token 选择、3D 锚定、自监督潜在世界模型与规划头四个阶段。
  • 输入传感器：多相机图像（nuScenes 6 相机、NAVSIM 8 相机）、多帧 LiDAR 点云、雷达检测（NAVSIM 无雷达，雷达流置零）。
  • 场景表示：稀疏图像 token 集合；每个 token 携带当前自车坐标系下的 3D 锚点与 16 维几何统计向量，并加入傅里叶特征 3D 位置编码；不使用 BEV 网格或 3D 骨干网络。
  • 模型结构：视觉骨干为带 register token 的 DINOv2-Small（D=384，12 层，输入 252×448，patch 14，nuScenes 每帧 N=3,456 token / NAVSIM N=4,608）；世界模型 d=256，含 4 层世界模型编码器、3 层预测器、2 层特征读出与 2 层规划头（约 10M 参数）；历史深度 T_h=2，预测时域 H=4、步长 0.5 s；规划头含 V=256 轨迹词表、top-M=8 候选重打分与碰撞代价筛选。
  • 关键技术：三路打分（障碍流约 55%、道路流约 30%、视觉保留约 15%），Gumbel 噪声加直通式门控实现可微 top-K；稀疏骨干从稠密骨干蒸馏；LiDAR 只提供几何路由信号与度量坐标，不作学习式特征融合（消融显示融合无益）。

Card 06 评估与结果

评估与结果

  • 评估基准：nuScenes val 与 NAVSIM v2 navtest；开环评估（规划 L2、碰撞率、EPDMS、运动预测 EPE、安全关键覆盖与注意力熵），未报告闭环或实车测试。
  • 评估指标：3 s 平均位移误差 L2（m）、碰撞率 Col%（排除 GT 碰撞时间步）、EPDMS、运动 token EPE@2s 与相对零运动基线的 Rel.%、危险车辆覆盖率、规划器交叉注意力熵（bit）。
  • 关键数值：25% 预算下 nuScenes L2 0.520 m / Col 0.04% / 25.9 GFLOPs，优于稠密融合（0.573 m / 0.09% / 248 GFLOPs）与随机（0.550 m）；10% 预算下 L2 0.537 m、7.6 GFLOPs。NAVSIM 上 25% 预算 EPDMS 88.9、10% 预算 87.9，稠密融合 85.9。安全关键 739 场景覆盖 95.8%、碰撞率 0.09%。运动预测 Rel.% 55.5%，优于随机 42.9%、DINOv2-Attn 42.4%、稠密融合 44.5%。注意力熵 GATS 5.7 bit，稠密 7.0、随机 6.5。
  • 对比方法：稠密融合、稠密纯相机、随机、Grid、DINOv2-Attn、Learned、Distance（深度启发式，仅选择原则层面参照 LaTP）、Register、Pool；已发表方法 UniAD、VAD-Base、SparseDrive、WoTE、DiffusionDrive、DiffusionDrive-v2 作为参考（不同骨干与监督）。
  • 消融与鲁棒性：移除 3D 锚定导致 L2 恶化 84.2%，移除道路流 17.1%、移除学习式修正 16.5%、移除世界模型 10.4%、移除历史流 9.4%、移除雷达速度 7.9%；加入 LiDAR 特征融合后 25% 预算 L2 为 0.569 m，差于不融合的 0.520 m；图像损坏（severity 3）鲁棒性结果见表 7，原文提供段落在此处被截断，具体数值原文未完整报告。
