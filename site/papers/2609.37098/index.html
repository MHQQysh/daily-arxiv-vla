Card 03 核心贡献

核心贡献

  • 提出 V2X-WAM 协同世界–动作框架，显式耦合动作生成与未来世界建模：规划动作条件化未来交通演化，预测的世界后果再反馈用于细化最终轨迹。
  • 提出可靠性感知协同场景表示，通过紧凑量化基础设施消息整合时序车端与路侧观测，并用学习到的空间可靠性与时间置信度共同调节协同信息贡献。
  • 提出动作条件化未来世界建模机制，联合预测未来占据栅格与动态流，并引入流引导的占据栅格传输以刻画周围交通的空间与动态演化。
  • 在大规模真实世界协同驾驶数据集上开展实验，验证 V2X-WAM 的有效性；消融研究进一步考察关键组件贡献。
  • 摘要报告该方法在提升规划精度与安全性的同时，实现更强的未来世界预测与显著更低的通信开销。
Card 04 方法描述

方法描述

  • 所属模块：整体包含可靠性感知协同场景编码与耦合世界–动作建模两大阶段。
  • 输入传感器：自车与基础设施的相机观测（当前帧）和 LiDAR BEV 历史序列；历史 BEV 观测统一变换到当前自车坐标系。
  • 其他输入：历史自车位置、当前自车运动状态、高层路径指令、车–路相对几何、可行驶区域地图。
  • 场景表示：通过共享的相机编码器与时序 BEV 编码器得到各智能体特征，经协同融合与可靠性加权后，压缩为固定规模共享场景隐变量 Z，供规划与未来世界建模共享。
  • 关键技术一（时序多模态智能体编码）：对 BEV 历史做逐帧差分，并用最近两帧 BEV 特征计算相关体以捕获局部运动对应，再与当前特征、带符号时序差分及差分幅值融合。
  • 关键技术二（可靠性感知 V2X 通信与融合）：将基础设施特征投影为紧凑消息并用通道级对称 INT8 量化传输，训练时使用直通估计器；由车–路相对几何得到时间置信度，与从自车时序特征和解码基础设施消息估计的空间可靠性图相乘，共同加权基础设施消息。
  • 关键技术三（场景 token 化与隐重采样）：将协同特征转为场景 token 并加入二维坐标嵌入，另设三类条件 token（历史自车位置、当前自车状态与配对几何、高层路径指令）；用若干可学习 latent query 经交叉注意力将稠密 token 重采样为固定规模场景隐变量。
  • 关键技术四（多模态动作提议）：并行预测 K 条轨迹假设；以模式嵌入、时间嵌入和场景隐变量构造规划查询，结合恒速轨迹先验与有界残差生成候选轨迹，并由模式打分头选出初步轨迹，同时由相邻航点增量得到前瞻动作序列。
  • 关键技术五（动作条件化未来世界建模）：将几何导向特征与场景隐变量构成公共世界状态；用前瞻动作与未来时间嵌入经调制网络生成通道级缩放与偏置，逐未来时域调制世界状态；再由占据与流分支联合解码，占据分支直接预测未来占据 logit，流分支在占据特征停止梯度残差支持下预测位移场与运动置信度，并通过自适应死区抑制静态区域残余运动。
  • 关键技术六（流引导占据栅格传输）：用可微 BEV 双线性采样按预测流将上一时刻占据传输到当前未来时刻，并与直接解码占据按逐时域学习系数融合；每个未来时域再产生紧凑世界后果 token。
  • 关键技术七（世界感知轨迹细化与联合优化）：将选中规划 token 与世界后果 token 配对，预测有界轨迹修正并裁剪到容许规划范围；采用跨任务梯度路由算子控制场景→规划、动作→世界、世界→动作连接的反向梯度强度；在规划、安全与未来世界监督下单阶段联合训练。
