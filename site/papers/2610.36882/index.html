Card 02 论文概述

论文概述

  • 任务：面向自动驾驶（AD）的强化学习（RL）智能体设计，具体是在 Unity3D 仿真三车道椭圆赛道中，用 PPO 训练由前置摄像头语义分割图像输入、输出未来轨迹点的驾驶策略。
  • 研究问题：RL 智能体的性能同时取决于神经网络结构与训练超参数，但既有 EMNAS 工作只搜索卷积结构，忽略了学习率、批量大小、折扣因子、时间步长等 RL 超参数对收敛性与稳定性的影响。
  • 目标：在一个统一的多目标进化搜索框架中同时进行神经架构搜索（NAS）与超参数优化（HPO），在最大化累积奖励的同时控制参数量与 FLOPs。
Card 03 核心贡献

核心贡献

  • 提出 HPNAS 双分支进化框架，在统一多目标搜索策略下并行演化离散网络架构（针对策略网络的卷积层，负责视觉特征提取）与连续 RL 超参数。
  • 架构分支沿用 EMNAS 的基因型编码、NSGA-II 非支配排序与拥挤度选择；超参数分支引入多项式变异与模拟二进制交叉（SBX）处理连续变量。
  • 引入并行评估与教师—学生策略迁移机制（基于行为克隆的 Optimized Transfer Learning），以加速收敛并提升泛化。
  • 在 Unity3D 高保真驾驶仿真中验证：联合 NAS-HPO 在较大搜索预算下相较仅 NAS 取得更高奖励、更少参数并提升稳定性。
  • 展望中提出将贝叶斯神经网络代理模型用于搜索后期引导采样，但明确说明尚未集成到本工作。
Card 04 方法描述

方法描述

  • 所属模块：策略网络的卷积特征提取部分（NAS 分支）与 PPO 训练超参数（HPO 分支）；策略梯度算法为 PPO。
  • 输入传感器：前置摄像头图像，转换为语义分割图像作为网络输入（分辨率 84×84×3）；输出为未来轨迹点，由外部黑盒车辆控制器执行油门、刹车与转向。
  • 场景表示：Unity 3D 引擎构建的仿真三车道椭圆赛道，多智能体并行训练；奖励函数鼓励轨迹预测准确、惩罚碰撞与车道偏离、鼓励低抖动平稳运动。
  • 模型结构：NASNet 风格的有向无环图（DAG）单元编码，染色体由 normal cell 与 reduction cell 交替组成，每个 cell 含四个基因 LA1LA2、LB1LB2、LC1LC2、LD1LD2，基因指定操作 L 与连接索引 (A,B,C,D)；连接索引递归定义为 PreviousIndex = index − 2 以保证无环；搜索空间含 3×3/5×5 深度可分离卷积、3×3/5×5 空洞卷积、3×3/5×5 逆卷积、7×7 卷积、最大池化、平均池化与跳连；网络深度 8（8 个交替堆叠的 cell）。
  • 多目标优化：最小化 {−Reward, FLOPs, Params}，用 NSGA-II 进行非支配排序与拥挤度保持，各目标等权。
  • 遗传操作（架构分支）：均匀交叉（p_c = 0.5）、基因替换变异（p_m = 0.1）、逆转变异（p_inv = 0.1）、精英保留式生存机制；Early Exit Parameter Initialization（EEPI）以最大参数约束 β_max 丢弃并重初始化超限个体（实验阈值 5M 参数）。
  • 超参数搜索空间：批量大小 64–512、折扣因子 0.95–0.999、学习率 10^-5–10^-2、时间步长 32–256；PPO epochs 与熵系数分别固定为 3 与 0.01。
  • 双分支演化流程：首代超参数在范围内均匀采样；从第二代起保留最优配置，其余以交叉或变异等概率（各 0.5）生成子代，并保留 10% 纯随机个体以维持多样性；连续空间使用多项式变异（分布指数 η_m）与 SBX（分布指数 η_c），并随代次调度从探索转向开发。
  • 迁移学习（OTL）：每代结束时从最优策略采集专家轨迹，用行为克隆损失 L_BC(θ) = E[−log π_θ(a\|s)] 初始化下一代各架构，并保留上一代优化器状态（最终学习率与 PPO 裁剪值）。
  • 原文未报告：策略网络除卷积单元外的具体头结构细节、奖励函数的具体数学形式与权重。

Card 06 评估与结果

评估与结果

  • 评估基准：与原始 EMNAS（仅 NAS）基线对比；最终最佳模型另与 NAS-only（1190）、HPO-only（1190）和人工调参基线（1140）比较；未与先前独立超参数调优基线在搜索阶段对比，原因是其模型按完整 RL epochs 训练，与本文低保真设置不兼容。
  • 评估指标：最终 PPO 累积回合奖励、参数量（百万）、FLOPs（GFLOPs）；以多目标适应度按代内相对排名评估。
  • 条件：全部为仿真闭环训练与评估，原文未报告开环评估或实车结果。
  • 六组实验关键数值（NAS → HPNAS，奖励 / 参数量 M / FLOPs G）：(6,6)：538/1.29/1.26 → 233/1.27/1.25；(10,4)：585/1.34/1.32 → 415/0.94/0.93；(10,10)：569/0.94/0.97 → 621/0.87/0.84；(10,15)：753/1.45/1.44 → 745/0.77/0.76；(15,15)：584/0.60/0.52 → 682/0.84/0.82；(15,20)：604/0.51/0.42 → 787/0.53/0.44。
  • 结果分析：小规模实验（Exp 1、2）中 HPNAS 结果更分散，作者归因于代数有限而搜索空间更大；部分情形 NAS 奖励更高但模型更大，提示缺少超参数协同优化时出现过参数化；搜索预算增大后（Exp 5、6）HPNAS 在奖励上稳定优于 NAS，模型规模相当或略大。
  • 最终完全训练结果：最佳架构与最优超参数组合（批量大小 216、时间步长 88、学习率 2.8×10^-3、折扣因子 0.976）取得峰值累积奖励 1205，超过 NAS-only（1190）、HPO-only（1190）与人工调参（1140）。
