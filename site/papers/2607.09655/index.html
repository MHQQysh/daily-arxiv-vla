Card 03 核心贡献

核心贡献

  • 提出 OpenLongTail，一个开源生成式数据引擎，可将异构长尾驾驶视频转换为位姿接地（pose-grounded）的多视角数据，支持从异构来源进行可扩展的 VLA 策略学习。
  • 在生成过程中集成 Plücker 射线相机几何和跨视角记忆库，使合成目标视图共享空间接地潜在上下文，并增强目标相机配置下的跨视角一致性。
  • 在 AlpaSim 中进行下游闭环 VLA 评估，验证生成数据显著提升长尾驾驶策略的鲁棒性，并将普遍存在的单目长尾视频解锁为可扩展的训练数据源。
  • 通过外推视角合成和位姿恢复指标，验证了 OpenLongTail 在视觉保真度、跨视角一致性和自我轨迹恢复方面的有效性。
Card 04 方法描述

方法描述

  • 所属模块：数据生成引擎，包含自我轨迹恢复模块和位姿信息外推视角合成模块。
  • 输入传感器：单目前置摄像头视频；原文未报告其他输入传感器。
  • 场景表示：目标相机配置（target camera rig）下的多视角视频，包含前置、前长焦、左右侧视和后部视图；场景通过 Plücker 射线几何、深度 warp 和跨视角记忆进行几何接地表示。
  • 模型结构：基于 Wan 2.1-VACE DiT 1.3B 骨干网络，使用 LoRA 适配器进行微调；训练在 Wan 2.1 VAE 潜在空间中进行；包含三个核心条件模块：几何编码器、时间深度 warp 和跨视角记忆库。
  • 关键技术：

- 使用 MapAnything 恢复度量尺度相机轨迹，并用前向卡尔曼滤波和后向 Rauch-Tung-Striebel 平滑器进行运动一致稳定化。

- 几何编码器将每个时空 token 的 3D 射线编码为 Plücker 射线，结合相机身份、角色嵌入和轨迹 MLP，生成统一的 token-wise 几何偏置。

- 时间深度 warp 使用冻结的 DepthCrafter 提取深度，对不同目标视图采用空间 warp（同帧内）或时间偏移 warp（回望前帧）以提供几何对齐的 RGB 先验。

- 跨视角记忆库通过有向自回归依赖图传播前序生成视图的信息，采用 64-query Perceiver 风格重采样器压缩为语义记忆，并在 DiT 层中进行跨注意力。

- 训练目标为流程匹配（flow-matching）目标，最小化速度预测的均方误差，后视长焦视图有额外权重。

Card 06 评估与结果

评估与结果

  • 评估基准：AlpaSim 闭环长尾事件仿真；Unseen-scenario 外推视角评估；Waymo E2E 分割；度量尺度位姿恢复评估；seen-scenario 视图合成评估。
  • 评估指标：AlpaSim Score（AS，越高越好）、碰撞率（CR，越低越好）、PSNR、LPIPS、GeoKPM μ（跨视角几何一致性，越接近 100 越好）、ATE、RPE-r、RPE-t、RotErr、Jerk、Acc.Var、LDJ、RotAnc、TrErr。
  • 关键数值（闭环 AlpaSim 评估）：

- 基线 Alpamayo R1 平均 AS 为 0.534，CR 为 58.8%；Alpamayo 1.5 平均 AS 为 0.501，CR 为 61.1%。

- 使用超微调数据（SFT）的 Alpamayo R1 平均 AS 提升至 0.716，CR 降至 11.1%。

- 使用 NVIDIA GT + Syn 数据：NV Syn 平均 AS 达 0.748，CR 降至 0.0%；NV GT 平均 AS 为 0.764。

- 使用 NV + Waymo Syn 数据：平均 AS 达 0.748，CR 为 5.6%。

- 加入外部 Waymo 数据后，罕见车辆指标从 0.717 提升至 0.765，骑行者从 0.662 提升至 0.689，工作区从 0.935 提升至 0.950。

  • 关键数值（Unseen-scene 外推视角评估）：

- OpenLongTail 在五个目标视图上 PSNR 为 11.71–13.28，LPIPS 为 0.597–0.643，GeoKPM μ 为 82.41。

- 对比方法包括 TrajectoryCrafter、Gen3C、ReCamMaster、Vista4D，GeoKPM μ 分别为 10.77、8.61、16.58、18.86。

  • 关键数值（位姿恢复评估）：在度量尺度评估中，OpenLongTail 的 ATE 为 2.212，RPE-r 为 0.129，RPE-t 为 23.05，Jerk 为 0.340，Acc.Var 为 283.9，LDJ 为 5.96；对比方法包括 DROID-W、MegaSAM、VGGT、ViPE 和 MapAnything。
  • 评估条件：闭环仿真评估在 AlpaSim 中进行，每个策略和事件运行两次独立 rollout 取平均；外推视角和位姿评估可能为离线评估，原文未明确区分开环条件。
