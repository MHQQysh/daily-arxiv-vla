Card 03 核心贡献

核心贡献

  • 提出 DeltaForge，据作者所知是首个面向驾驶的后验（post-hoc）混合专家 VLA，仅用各领域权重与约 1% 代理集即可将独立微调的领域模型整合为单一多域 VLA，并支持新领域免端到端重训练接入。
  • 提出后验专家分解（PEF），用联合 SVD 将各领域微调增量（task vector）分解为冻结的共享技能基与低秩域特定核心，使路由只需移动小核心而非稠密专家块。
  • 提出两级技能混合路由器：一个位于输入层用于 VLM 推理专家，一个位于中间层用于流匹配动力学专家，二者在 clip 级别进行无域标签路由，可跨域自由组合场景推理与车辆动力学技能。
  • 在覆盖城市、越野、高速及乘用车、卡车、ATV 的六个领域上评估，DeltaForge 接近逐领域专家精度，并以接近单模型的参数与计算成本超越所有合并、路由、集中式与联邦基线，且展现出对未见域组合的组合泛化能力。
Card 04 方法描述

方法描述

  • 所属模块：基于 Alpamayo 1.5（10B）驾驶 VLA，包含 8B Cosmos-Reason VLM 主干与 2B 流匹配动作专家，分两阶段微调，故每个领域贡献一个推理专家与一个动力学专家。方法可推广到任意“推理+动作”双组件 VLA。
  • 输入传感器：默认轨迹模式下输入前视相机图像与 10Hz 的 16 步自车历史，预测 64 步未来轨迹；各微调领域使用单前视相机，基座模型使用四相机。
  • 场景表示：原文未报告显式的 BEV 或 3D 场景表示，模型为基于视觉 token 与自车运动学历史的端到端轨迹预测形式。
  • 模型结构与关键技术：

- 后验专家分解（PEF）：对每个待分解权重矩阵，先计算域任务向量 Δ_i = W_i − W_0，再用截断 SVD 联合提取所有域增量的低秩共享列空间 U 与行空间 V 作为冻结共享技能基；每个领域仅保留核心 C_i = U^T Δ_i V ∈ R^{r×r}，重构权重为 W_0 + U C_i V^T；基座模型以零核心 C_0 = 0 免费加入专家池作为默认路由。PEF 应用于 ViT、LLM 和流匹配动作专家的注意力与 FFN 矩阵，其余模块（token 嵌入、LM head、norm 等）合并为单一共享副本不参与路由。

- 技能混合路由：每个输入 clip 计算一次专家混合权重 w，所有分解层共享该混合，按 W̄^(ℓ) = W_0^(ℓ) + U^(ℓ)(Σ_i w_i C_i^(ℓ))V^(ℓ)^T 组合，混合在参数空间一次性完成，无额外推理开销，且 w 保留在计算图中以支持端到端训练。路由采用 top-k 截断并重归一化的软混合。

- 输入级 VLM 路由：输入为冻结基座 ViT 视觉 token 的均值特征 v 与自车历史速度、加速度、曲率的 z-score 统计量 m，经小 MLP 与 softmax 得到路由分布。

- 中间层动力学路由：输入为 VLM 最后一层隐状态的均值池化 h 与相同运动学统计量 m，经 MLP 与 softmax 选择动力学专家；两路由解耦，使一个领域的场景推理可与另一领域的车辆动力学自由配对。

- 基于代理集的组合训练：路由监督由专家自身生成软 oracle 标签，VLM 专家以教师强制 token 损失、流匹配专家以生成轨迹 ADE 作为专家得分，经温度 τ 的 softmax 得到软标签，路由器以 KL 散度拟合；随后冻结路由器与共享基，仅在与 top-k 混合下优化被选中的核心以补偿 SVD 截断损失。训练分两阶段：先训练 VLM MoE，再冻结并训练流匹配 MoE。

- 新领域接入：将新域任务向量投影到冻结基上得到新核心，在其代理集上以锁定路由到该专家进行核心修复，再重新生成软 oracle 标签并在扩展代理集上联合刷新路由器与所有核心，无需端到端重训练。

Card 05 数据集与资源

数据集与资源

  • 基座模型：Alpamayo 1.5（10B），8B Cosmos-Reason VLM + 2B 流匹配动作专家。
  • 六个领域数据集：Urban China 使用 ONCE（训练 24,885 / 评估 2,769），Urban Japan 使用 CoVLA（26,987 / 2,893），Off-road ATV 使用 TartanDrive（17,470 / 1,484），Off-road car 使用 ORAD-3D（34,801 / 4,897），Highway truck EU 使用 TruckScenes（33,305 / 3,172），Base 域使用 PhysicalAI-AV（19,545 / 3,000）。
  • 额外留出数据集：ParkRecon3D 用于新领域接入（5,753 / 745），Torc TruckDrive 与 BeVIS 用于零样本泛化（分别为 23,593 / 3,031 与 4,485 / 297）。
  • 训练资源：每个领域专家在八块 H100 GPU 上训练；阶段 1 全量微调 VLM（AdamW，学习率 10^-5，batch 32），阶段 2 冻结 VLM 训练动作专家（学习率 10^-4，batch 8），各至多 10 个 epoch。
  • 组合训练配置：PEF 核心秩 r=256，软 oracle 温度 τ=0.3，路由器与核心分别在代理集上训练 200 与 500 步；代理集每域 200 个 clip（约训练数据 1%），评估集从不使用。
  • 模型规模：部署系统（N=5）总参数 12,547M，其中训练参数 122.7M（约 1.0%）；共享基 U,V 共 1,257M（闭式求解），路由器（×2）2.1M，每域核心与投影 42.0M。
