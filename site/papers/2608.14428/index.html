GhostPoint: Self-Supervised Representation Learning by Hallucinating Occluded LiDAR Structure

2026-08-14 · 原文 · 翻译 · 2608.14428

本文针对自动驾驶中基于LiDAR点云的3D物体检测任务。 核心研究问题是自监督学习（SSL）预训练表征在3D检测上的迁移效果显著弱于语义分割等逐点任务，作者将这一“迁移鸿沟”归因于现有SSL目标函数仅约束可见LiDAR表面，而未建模被遮挡和未观测区域的结构。 为此，本文提出GhostPoint框架，通过在发现实例的局部邻域内“幻觉”（hallucinate）未观测区域的潜在特征，显式学习超出可见表面的物体结构，以提升下游3D检测性能，尤其是在稀疏扫描和标注有限场景下。

Card 03 核心贡献

核心贡献

  • 系统分析并实证了LiDAR SSL中的“迁移鸿沟”：预训练表征在语义分割上接近监督水平，但在3D检测上存在明显差距，并将其归因于稀疏表面对齐的SSL目标与检测所需的稠密体素空间之间的表征不匹配。
  • 提出GhostPoint自监督学习框架，通过创新的“实例体素膨胀”（instance voxel dilation）在已发现实例周围生成包含可见、掩码和未观测体素的局部邻域，并在此邻域上训练轻量级预测器。
  • 引入预测器级蒸馏监督方案：观测/掩码体素匹配教师编码器目标，而未观测体素匹配教师预测器的幻觉目标，统一了伪遮挡体素与真实未观测体素的学习目标，直接缓解遮挡偏差。
  • 在nuScenes和Waymo两个基准上证明，GhostPoint在解码器探测和全参数微调两种协议下均取得SOTA性能，尤其在稀疏扫描和有限标签条件下增益最大，同时不牺牲分割等逐点任务的迁移性。
Card 04 方法描述

方法描述

  • 所属模块：自监督预训练（self-supervised pretraining）方法，用于下游3D物体检测。
  • 输入传感器：LiDAR点云。
  • 场景表示：稀疏体素（voxel），由LiDAR点云体素化得到，分为可见体素（V_vis）、掩码体素（V_mask）和无返回体素（V_unobs）。
  • 模型结构：采用教师-学生自蒸馏框架。编码器（F_θ）可选PTv3或CenterPoint稀疏卷积骨干；轻量级预测器（G）实现为两个PTv3式Transformer块；附带Softmap头（语义）和中心偏移头（几何）用于生成伪实例。
  • 关键技术：

- 实例发现：利用教师编码器特征预测中心偏移并聚类，形成伪实例。

- 邻域采样：保留学生视图中至少含一个可见体素的实例，用3D核（默认ks=5）膨胀其占据网格，形成候选邻域集合并采样固定大小子集Q。

- Token初始化：对Q中非可见体素，用距离加权KNN插值（k=3）从最近可见占据体素初始化特征；也可用可学习mask token。

- 预测器蒸馏：学生预测器仅在非可见体素（Q_mask ∪ Q_unobs）输出，并对可见体素做恒等覆盖；教师预测器在无返回体素上幻觉目标，在占据体素上使用教师编码器特征。

- 训练目标：总损失为L_sem,vis + λ·L_geo,vis + L_sem,¬vis + λ·L_geo,¬vis（λ=0.1），其中可见体素用KL散度（语义）和L1+余弦（几何），非可见体素用相同目标但匹配教师预测器输出。

- 两阶段热身：前10% epoch只训练Softmap分支，后10%激活偏移和预测器分支并分离梯度，之后端到端联合优化。

Card 06 评估与结果

评估与结果

  • 评估基准：nuScenes（mAP、NDS）、Waymo Open Dataset（L2难度AP，按类别和mAP）。
  • 评估指标：nuScenes采用mAP和NDS；Waymo采用Level 2 AP（Vehicle/Pedestrian/Cyclist/mAP）。
  • 关键数值：

- 解码器探测协议（PTv3骨干冻结）：GhostPoint在nuScenes达59.5 mAP / 64.2 NDS，超越第二好SSL方法2.8 mAP / 1.7 NDS；在Waymo达60.0 mAP，领先2.5 mAP。

- 全量微调协议：GhostPoint在nuScenes达67.5 mAP / 71.2 NDS，超越监督基线3.7 mAP；在Waymo达70.1 mAP。

- 标签效率（nuScenes）：0.1%标签下36.9 mAP / 52.1 NDS；1%下53.1 mAP / 62.5 NDS；10%下63.5 mAP / 68.8 NDS。

- 分割迁移（nuScenes线性探测）：语义分割74.2 mIoU（接近PointINS的74.4）；全景分割62.8 PQ（超越PointINS +0.6、DOS +5.4），SQ/RQ为84.6/73.2。
