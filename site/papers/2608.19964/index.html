G-MARK: Grounded Multi-Agent Reasoning for Cooperative Driving via Knowledge Graphs

2026-08-20 · 原文 · 翻译 · 2608.19964

论文解决自动驾驶系统中因部分可观测性（如遮挡、视野受限）导致的安全决策问题，聚焦于车对车（V2V）协同驾驶场景。 研究问题：现有协同驾驶方法将多智能体证据压缩为潜在特征或隐藏多模态状态，无法保留"哪个智能体观测了对象""对象是否对自车可见""冲突证据如何影响下游决策"等关键信息。 提出 G-MARK，一个基于知识图谱（KG）的接地多智能体推理框架，将协同对象级观测转换为显式、具备来源可追溯性的知识图谱，以支持对象推理、运动预测、控制选择与轨迹预测。

论文概述

  • 论文解决自动驾驶系统中因部分可观测性（如遮挡、视野受限）导致的安全决策问题，聚焦于车对车（V2V）协同驾驶场景。

Card 03 核心贡献

核心贡献

  • 提出一种来源可追溯的协同知识图谱，保留对象假设、来源智能体支持、可见性、不确定性、冲突、空间关系、运动线索与规划上下文。
  • 提出任务条件化的延迟证据融合，保留弱伙伴独有观测，使下游任务能自主决定哪些证据相关。
  • 展示该方法以紧凑的结构化通信，支持对象推理、运动预测、控制选择及未来轨迹预测。
  • 相比最先进基线 V2V-GoT，将遮挡推理精度提升 42.2%，控制选择误差降低 13.1%，并以约 25.6 倍更小的结构化通信载荷实现与基线相当的轨迹规划精度。
Card 04 方法描述

方法描述

  • 所属模块：作为协同感知流水线上的推理层，运行时输入为已处理的多智能体感知输出，而非原始摄像头或激光雷达流。
  • 输入传感器：原文未报告原始传感器类型；直接消费对象检测/轨迹、智能体位姿、置信度分数及规划上下文。
  • 场景表示：来源可追溯的知识图谱，包含智能体节点、观测节点和对象假设节点，以及类型化关系（如来源、支持、空间关系、规划上下文、证据一致性）。
  • 模型结构：四阶段流程——协同 KG 生成、保守关联、协同上下文增强、统一 KG 任务头。
  • 关键技术：使用确定性门控规则进行跨智能体观测关联（类型精确匹配加类相关距离阈值）；采用有界 noisy-or 式置信度聚合；置信度加权平均融合位置；保留未匹配观测为弱候选；任务头基于 KG 导出特征向量，采用确定性检索/排序函数或轻量学习预测器。

Card 06 评估与结果

评估与结果

  • 评估基准：V2V-GoT-QA，覆盖感知、预测和规划任务（Q1–Q9）。
  • 评估指标：对象选择与可见性推理使用定位感知的精确率、召回率和 F1@0.5m；运动与轨迹使用 L2 误差；智能体运动使用二分类准确率；控制选择使用归一化动作误差（Action L1）。
  • 关键数值（G-MARK vs V2V-GoT）：可见对象接地 F1 0.586 vs 0.525（+11.6%）；遮挡推理 F1 0.428 vs 0.301（+42.2%）；隐藏对象发现 F1 0.494 vs 0.440（+12.3%）；规划相关推理 F1 0.614 vs 0.608（+0.9%）；对象运动 L2 3.822 vs 8.050（+52.5%）；智能体运动准确率 0.905 vs 0.874（+3.5%）；对象运动 L2 3.822 vs 7.610（+49.8%）；控制选择 Action L1 0.076 vs 0.088（+13.1%）；未来轨迹 L2 2.710 vs 2.620（-3.4%，近持平）。
  • 通信成本分析：G-MARK 使用 0.0159 MB/样本，相比中间融合（0.4008–0.4068 MB/样本）约低 25.2 倍，较 V2V-GoT 低 25.6 倍；对比方法包括 No Fusion、AttFuse、V2X-ViT、CoBEVT、V2V-LLM 和 V2V-GoT。
  • 延迟：任务求解时间低于 1.4 ms/样本，当前帧任务总 CPU 延迟 10.3–14.2 ms，时序运动任务 32.4–33.4 ms。
  • 消融实验：移除伙伴观测使隐藏对象 F1 从 0.494 降至 0.000；移除来源信息使隐藏对象 F1 降至 0.396 且控制 Action L1 从 0.076 增至 0.152；用非结构化对象表示替代 KG 使隐藏对象 F1 降至 0.443 且控制 Action L1 增至 0.089。
  • 实验条件：基于离线验证集评估，非闭环；未报告实车测试。
