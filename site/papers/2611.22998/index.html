论文概述

Card 03 核心贡献

核心贡献

  • 提出轻量决策层：在冻结世界模型与候选生成器前提下学习上下文相关候选偏好，部署时仅新增 11,725 参数的排序网络。
  • 提出候选–残差联合策略：训练时通过局部轨迹变化获取反馈，推理时保持候选几何不变；微调仅更新 16,106 个 actor 与 critic 参数。
  • 在 nuScenes 验证集开环评估中，平均 L2 相对 RiskWorld 基线降低 3.99%，并给出更低的碰撞率点估计。
  • 在匹配反馈访问与 actor 更新预算下，残差探索相较无残差的 categorical PPO 进一步降低 L2 0.83%（消融小节亦报告约 0.8%）。
  • 在风险特征置零或打乱时，方法仍保持比 RiskWorld 更低的 L2。
Card 04 方法描述

方法描述

  • 所属模块：规划/轨迹选择模块（决策层），位于冻结的 RiskWorld 世界模型与固定候选库之上；原文未报告感知前端的具体结构细节。
  • 输入传感器与场景表示：使用相机（C）、地图（M）与真值 actor 状态（GT-Tr）；RiskWorld 将 RiskExpert 表示与 GeoBEV 的 BEV 特征融合为候选对齐输入 W₀ = R_Risk + G⊙Δ；每个候选含 T=6 个状态（0.5 s 间隔），d_x=64 维特征（25 项预测 + 39 项状态/导航描述，覆盖碰撞、道路风险、间隙、运动、导航）。
  • 排序网络：将特征分为风险特征 r_ik（d_r=2T）与其余特征 v_ik，与有效候选均值 v̄_i 拼接得 h_ik；共享两层宽 64 的 ReLU MLP 输出 u_ik；得分头输出 1+d_r 个值（基础偏好 b_ik 与风险权重偏移 a_ik），得分为 ℓ_ik = b_ik − γ_ikᵀ r_ik，γ_ikj = ln2 + 0.5a_ikj；掩码 softmax 定义 π_θ(k\|X_i)。
  • 残差探索：仿射残差头将 [u_ik; r_ik] 映射为二维对角高斯均值 μ_ik，共享 log σ 裁剪到 [−3, 0.5]；联合策略 p_θ(k,z\|X_i) = π_θ(k\|X_i)·N(z; μ_ik, diag(σ²))；位移 d = (1.0, 0.5)⊙tanh z（米），沿轨迹按 smoothstep 权重 3s_t²−2s_t³ 施加；若违反加速度、曲率或前向运动约束则做几何投影逐步缩小位移，若无满足约束的缩小步则使用原候选。
  • 奖励与优化：U = −e + λ_P P − λ_C C，R = U − ωᵀc，其中 c 四项分别量化碰撞暴露、任一碰撞事件、道路违规与小幅平移下的平均碰撞暴露；λ_P=λ_C=10⁻³，ω=(1500, 20, 3, 500)ᵀ；独立 critic V_φ 用一层宽 64 MLP 估计上下文价值，优势按批标准化；PPO 使用联合概率比 ρ_i 的裁剪目标，并加入对固定参考策略的 KL 正则项与类别熵项。
  • 推理：风险信号 q_ik = p̂_{ik,T−1} + p̂_{ik,T}；对有效候选计算得分降序秩 r^s_ik 与风险升序秩 r^q_ik；最小化 J_ik = (1−w)r^s_ik + w r^q_ik 选候选，w=0.25（由训练场景 OOF 评估确定，受精度约束）；输出所选候选的存储坐标，残差头与 critic 在推理时移除。

Card 06 评估与结果

评估与结果

  • 评估基准与条件：nuScenes 验证集开环评估；所有学习类方法共享同一冻结预测与 K=12 候选；相机输入的已发表结果（UniAD、VAD、SparseDrive-S、DiffusionDrive）仅作参考，因输入设置不同。
  • 评估指标：L2 轨迹误差（1/2/3 s 及均值）与碰撞率 CR（%，基于标注 agent 框）；相对变化由未舍入数值计算；95% 置信区间由 2,000 次按场景配对 bootstrap 重采样估计。
