Card 03 核心贡献

核心贡献

  • 提出 MM-Future，一种多模态联合世界–动作模型，通过 mixture conditional flow 从单一结果训练片段中学习多个配对的场景–动作假设。
  • 提出 planning-oriented MM-Tokens，用紧凑的多视角场景表示支持高效的多模态未来 rollout。
  • 提出 future-conditioned proposal scorer，根据观测历史与每个候选配对的预测未来对轨迹进行排序，实现未来感知的动作选择。
  • 在 NAVSIM navtest 上取得 94.0 PDMS 与 91.5 EPDMS，并在 HUGSIM 零样本闭环评估中取得 32.3 HD-Score。
  • 消融显示多模态联合世界–动作建模相较单模态和仅动作变体具有一致提升。
Card 04 方法描述

方法描述

  • 所属模块：整体为 world–action model，包含 MM-Encoder、modality-aware Transformer 生成器与 future-conditioned proposal scorer。
  • 输入传感器：同步的多相机图像序列，以及历史自车状态向量和高层导航命令；原文未报告激光雷达或毫米波雷达等其他传感器。
  • 场景表示：将多视角视频压缩为 planning-oriented MM-Tokens；每个时间 chunk 使用可学习 query 与各视角 register tokens 进行 self-attention 交互，得到 chunk-wise MM-Tokens，不再向下游传播 dense patch tokens，也不进行 RGB 或 BEV 重建监督。
  • 模型结构：视觉 backbone 提取 register tokens，MM-Encoder 输出历史 MM-Tokens，EMA target encoder 在训练时提供未来目标；modality-aware Transformer 在 action tokens 与 future MM-Tokens 上进行联合条件流生成，并使用 modality-specific AdaLN 与 feed-forward 分支。
  • 关键技术：结构化配对源，包括基于 K-means 聚类的 Gaussian-mixture noise 动作先验与独立未来 token 噪声；joint conditional flow，action 与 future 使用独立 flow time 和 asymmetric block mask，实现历史为干净前缀、动作与未来相互注意；Best-of-Many 监督，根据解码轨迹选择 winner mode，并对同一 mode 的动作与未来流进行监督；推理时用 Euler schedule 积分生成 M 个配对 rollout；future-conditioned proposal scorer 使用历史条件 decoder 与未来条件 decoder，未来注意力按 mode 块对角，输出 PDMS 分量 logits。

Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM-v2 navtest、NAVSIM-v1 navtest、HUGSIM 零样本闭环迁移。
  • 评估指标：NAVSIM 使用 NC、DAC、DDC、TL、EP、TTC、LK、HC、EC、EPDMS、PDMS 等；HUGSIM 使用 HD-Score，并报告 Route Completion 等分量；消融还报告 latency。
  • 开环结果：NAVSIM-v2 navtest 上 MM-Future 达到 94.0 PDMS 与 91.5 EPDMS；表中 NC 99.0、DAC 98.8、DDC 98.8、TL 99.4、EP 92.2、TTC 98.6、LK 95.4、HC 96.3、EC 89.2。
  • 开环结果：NAVSIM-v1 navtest 上 MM-Future(trainval) 达到 94.0 PDMS；MM-Future(train) 达到 93.4 PDMS；表中 trainval 设置为 NC 98.7、DAC 99.0、TTC 95.8、Comf. 100、EP 91.6。
  • 闭环结果：HUGSIM 零样本闭环评估中取得 32.3 HD-Score。
  • 对比方法：包括 E2E 方法 DiffusionDriveV2、MeanFuser、UniTeD、DiffusionDrive、GaussianFusion、DriveSuprim、DrivoR；VLA 方法 DriveWorld-VLA、IRR-Drive-4B、DriveFine、AutoVLA、DriveVLA-W0、ReCogDrive；WAM 方法 Latent-WAM、GraphWorld、DriveFuture、Epona、WoTE 等。
  • 消融结果：多模态生成方面，action-only 多模态从 16 到 32 个假设 PDMS 为 91.1 到 92.3，paired 多模态从 16 到 32 个假设 PDMS 为 91.7 到 92.9；模态感知场景–动作交互方面，Mixture-of-DiT bidirectional 达到 92.9 PDMS，优于 one-way 的 92.5；future-conditioned scoring 方面，仅历史为 92.9 PDMS，历史加配对未来为 93.3 PDMS。
  • 效率方面：32 个配对多模态假设延迟为 132 ms；单模态动作模型延迟为 52 ms，16 个 action-only 多模态为 51 ms，32 个 action-only 多模态为 65 ms，16 个 paired 多模态为 79 ms。
  • 评估条件：NAVSIM 为非反应式评测；HUGSIM 为零样本闭环评测；原文未报告实车评测结果。
