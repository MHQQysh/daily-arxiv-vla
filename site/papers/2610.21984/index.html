论文概述

  • 应用场景：复杂多智能体交互的城市场景，尤其是合流、让行、交叉口冲突等“规划关键”（planning-critical）的高风险长尾情形。

Card 03 核心贡献

核心贡献

  • 提出 GRID-Planner 统一图-奖励融合扩散规划框架，将场景图从仅作为输入表征改为直接塑造优化优先级与轨迹价值。
  • 提出面向规划的关系学习机制，包含图感知重要性加权（Graph-Aware Importance Weighting）与关系奖励代理（Relational Reward Surrogate），前者聚焦规划关键轨迹，后者按安全、车道/路线一致性与舒适性对候选轨迹打分。
  • 提出统一在策略扩散目标，将优势加权扩散损失与优势门控的在策略自蒸馏（OPSD）结合，支持稳定的在策略精化并巩固高回报行为。
  • 在 nuPlan 与 interPlan 闭环仿真上相对扩散基线取得一致提升。
Card 04 方法描述

方法描述

  • 所属模块：运动规划模块（轨迹生成与策略改进），采用扩散生成模型 + 关系奖励塑形 + 在策略自蒸馏的框架。
  • 输入传感器：原文未报告具体传感器配置；仅报告场景编码保留最多 32 个邻近智能体、70 条车道折线、25 条路线车道折线、5 个静态控制元素，并使用 2 秒历史（21 个时间戳含当前帧）预测 8 秒、10 Hz 的 80 步未来轨迹，路点表示为自车坐标下的 (x, y, cosθ, sinθ)。
  • 场景表示：以关系图 G=(V,E) 表示场景，节点包括自车、周围智能体、车道折线与交通信号，边编码几何关系与交通规则优先权；RRS 沿候选轨迹逐步查询时间索引的自车中心图 G_t；GA-IW 另用轻量快照交互图（仅用于加权，区别于模型条件图）。
  • 模型结构：基于分数扩散的轨迹分布 π_θ(τ\|G)，以 DSM 去噪损失训练；价值基线 V_φ(G)；教师-学生自蒸馏；总损失为 L_total = L_AWD + λ_OPSD·L_OPSD。
  • 关键技术：

- 图感知重要性权重 w(τ)=exp(α1·CentFeat(τ)+α2·CollProb(τ))，CentFeat 由 RBF 边权加权度 s_ego 与车道/静态/红灯元素计数的对数项组成，CollProb 由未来最小距离 r_dist 与 t=0 的逆 TTC 风险 r_ttc 取最大得到；w 裁剪到 [w_min, w_max] 并按批均值归一化，仅作训练期因子而非冒险奖励。

- RRS：R_RRS(τ) = 对 T 步平均的 (r_safety + r_rule + r_comfort)，各分量为非负惩罚的负值（即 R_RRS ≤ 0）；安全项含碰撞指示、iTTC 与距离的光滑障碍惩罚；规则项含红灯、横向偏差、超速惩罚；舒适项惩罚加速度、jerk、横摆角速度。

- 轨迹回报 R_traj(τ)=w(τ)·R_RRS(τ)，优势 A(G,τ)=R_traj−V_φ(G)（stop-gradient，仅用于重加权与门控，不作策略梯度估计）。

- 优势加权扩散损失 γ(G,τ)=clip(exp(A/λ_A), γ_min, γ_max) 调制逐样本去噪损失；OPSD 用多步去噪采样多个候选并选最高回报者为教师，门控 ω=min(ReLU(A), ω_max)，蒸馏距离为未来状态的平均 ℓ2 距离。

评估与结果

  • 评估基准：nuPlan 的 Val14/Test14-hard/Test14 在 NR 与 R 协议下的闭环分数（CLS）；interPlan 的总体分数及 Nudge Around、High Traffic Density、Jaywalk 子类分数；诊断指标包括 Collision Rate、Lane Deviation、Jerk、Latency（红灯违规因信号状态提取受限未单独评估）。
  • 对比方法：PDM-Open、UrbanDriver、GameFormer w/o refine、PlanTF、PLUTO w/o refine、Flow Planner（本地用官方实现复现）、Diffusion Planner（interPlan 上）。
  • 关键数值：

- nuPlan（Table 1）：GRID-Planner 在六个划分中五个最优；Val14-NR 89.92、Val14-R 82.59、Test14-hard-NR 73.86、Test14-hard-R 71.15、Test14-NR 89.45、Test14-R 85.18；相对 Flow Planner，Val14-R 从 79.90 提升到 82.59，Test14-hard-R 从 66.88 提升至 71.15（+4.27）。

- interPlan（Table 2）：总体分数 57.25，高于 Diffusion Planner 52.90 与 Flow Planner 54.83；High Traffic Density 65.37（Flow Planner 56.41）；Jaywalk 43.20（Flow Planner 41.64，Diffusion Planner 26.20）；Nudge Around 58.77，略高于 Flow Planner 58.02 但低于 Diffusion Planner 60.48。
