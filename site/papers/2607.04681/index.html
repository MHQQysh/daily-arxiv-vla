Card 03 核心贡献

核心贡献

  • 对自动驾驶领域的先进（SoTA）推理模型进行人类评估，揭示推理质量与下游轨迹改进之间存在不一致且不确定的耦合关系。
  • 将具身推理的忠实性形式化为可操作的行为一致性目标，从结构化推理轨迹上的成对语义一致性约束推导出可扩展的替代目标，用于强化学习后训练。
  • 提出一个学习型评判器（critic）“Pinocchio”，用于识别观测、中间推理与动作之间的不一致性，并作为稠密奖励信号来改进具身推理。
  • 在大型驾驶基准和合成分布外场景上评估所提出的方法，发现针对具身忠实性进行优化可提升推理一致性、策略可信度和分布偏移下的鲁棒性。
Card 04 方法描述

方法描述

  • 所属模块：自动驾驶中的推理策略后训练（RL post-training），具体用于路径规划与决策。
  • 输入传感器：多视角相机图像（第一视角摄像头视图）以及自我状态信息；在评判器中还使用鸟瞰轨迹可视化与自我速度曲线。
  • 场景表示：一个生成式有向无环图（DAG）模型 G_gen，其节点为结构化推理轨迹变量，包括观测 o、场景描述 z₁、动作理由 z₂、元动作 z₃（包含纵向与横向决策）以及最终低层动作 a。
  • 模型结构：策略为一个推理型 VLA 模型，其生成过程分解为 πθ(a,z\|o)=πθ(z₁\|o)∏πθ(z_k\|z_{k-1})·πθ(a\|z_K)；忠实性评判器 Pinocchio 使用 Qwen3-VL-4B-Instruct 微调而成，在每条图边上预测“CONSISTENT”或“INCONSISTENT”二元判断。
  • 关键技术：提出机械忠实性（mechanistic faithfulness）与行为忠实性（behavioral faithfulness）的区分，并以轨迹一致性作为行为替代指标。用五个成对一致性边（(o,z₁),(z₁,z₂),(z₂,z₃),(z₃,a),(z₂,a)）定义轨迹一致性函数 F(τ)=∏R(u,v)，并通过拉格朗日松弛将约束优化转化为带有忠诚度稠密奖励的策略梯度目标，优化采用 GRPO（Group Relative Policy Optimization）。评判器在训练时固定，梯度通过策略的推理 token 传递。

Card 06 评估与结果

评估与结果

  • 评估基准：公开验证集中包含专家驾驶数据的驾驶基准，以及一个合成的分布外（OOD）反事实场景集。
  • 评估指标：平均位移误差（ADE，包含横向与纵向分量）、忠实性得分（一致性边上的判断结果）、胜率（对比 RL 与 SFT 基线在不同分层上的表现）、平衡准确率；在 OOD 场景中还评估策略对反事实情景的响应程度。
  • 关键数值：在 Pilot 评估中，Gemini 与人类多数共识在五个忠实性边上的准确率为 87–95%，Cohen's κ 介于 0.385 至 0.720；Pinocchio 在各边上的平衡准确率介于 0.78 至 0.94，总体达到 0.87。后训练后的规划器在忠实性上相较于先进对齐方法和轨迹误差后训练基线分别提升 4% 和 18%，同时保持竞争性的下游任务表现。在合成的 OOD 测试集上，针对忠实性的后训练将策略对罕见反事实场景的响应提升至 SoTA 策略的 1.6 倍。
  • 对比方法：ADE（仅轨迹误差的后训练基线）、RL 后训练检查点（SoTA 对齐）、SFT 基线，以及 VLM-Judge、ADE-Reason、ADE-Swap 等实现细节中提到的各类基线。
  • 开环/闭环条件：基于驾驶员数据集进行开环轨迹评估（以 ADE 与专家轨迹比较）；OOD 评估属于合成反事实场景下的测试。
