Card 03 核心贡献

核心贡献

  • 提出 DriveZero 系统，将驾驶解耦为感知模型与动作模型，分别预训练后通过蒸馏统一为纯相机端到端规划器，实现无人类轨迹监督的驾驶行为学习。
  • 提出 DriveRL，一种混合智能体闭环强化学习框架，将 nuPlan 真实驾驶日志转化为交互式世界，利用 PPO 训练特权教师策略，其行为可超越日志回放专家。
  • 引入值引导的测试时动作搜索，利用策略与评论家网络在推理阶段对候选动作进行一步前向搜索与保守式选择，提高闭环驾驶分数。
  • 提出 DriveVFM，通过聚合多个冻结视觉基础模型（DINOv3、SigLIP2、SAM、Depth Anything V2）的特征蒸馏，从原始图像中学习统一驾驶骨干，无需任何任务级标注。
  • 利用目标条件化教师模型进行目标增强，生成多样且目标一致的监督信号，显著扩充了单一日志轨迹无法提供的训练数据。
Card 04 方法描述

方法描述

  • 所属模块：端到端自动驾驶系统，涵盖闭环强化学习动作模型（DriveRL）、视觉表征预训练模型（DriveVFM）和纯相机蒸馏规划器（DriveZero）三部分。
  • 输入传感器：DriveRL 使用特权化结构化场景状态（车辆、地图、交通灯等）；DriveVFM 预训练输入为原始图像；DriveZero 输入为多视角相机图像、自车运动学信息和导航指令。
  • 场景表示：DriveRL 的教师以结构化向量场景状态为表示，包含自车与周围参与者（当前帧加前四帧，共 5 帧，最多 96 个参与者）、局部矢量地图（最多 256 个 token）和交通灯状态；DriveZero 则以 DriveVFM 图像特征为基础，叠加 3D 位置编码与可学习寄存器压缩为场景 token。
  • 模型结构：DriveRL 教师策略包含三个编码器（agent、ego-kinematics、map，嵌入维度 256）与多层交叉注意力网络，策略头输出 Beta 分布的纵向 jerk 与方向盘转角速率，总参数量为 5.70M；DriveVFM 采用共享 Vision Transformer 并结合每模型专用投影适配头；DriveZero 以 DriveVFM（LoRA 微调）为编码器，采用轨迹解码器以 WTA 方式生成 M 条轨迹候选，另设独立评分解码器预测 PDM 六项得分。
  • 关键技术：混合智能体仿真（日志回放 + IDM 规则行为 + 自博弈学习策略并存）、场景一致性演员插入约束、并行 PPO 训练、值引导测试时动作搜索（短视距闭合反馈、奖励一致评分、保守选择策略）、PHI-S 标准化的异构特征蒸馏、有界形状参数 Beta 动作分布。
Card 05 数据集与资源

数据集与资源

  • 训练数据集：nuPlan trainval 分割共 922,703 个场景（10 Hz 导出，训练时降采样至 5 Hz）；DriveVFM 预训练使用 LAION-2B、ImageNet-21K、SA-1B 与 OpenDV、nuPlan、Waymo 驾驶图像混合。
  • 评测基准：nuPlan（Val14、Test14-hard、Test14-random）、NAVSIMv1、NAVSIMv2、HUGSIM 闭环基准。
  • 训练资源：DriveRL 在 96 块 GPU 上并行训练，每 rank 2,048 个世界，PPO 共 2,400 次更新，总耗时约 21 小时；DriveVFM 分两阶段，分别以 256×256 与 512×512 分辨率预训练，全局 batch size 为 2,048 张图像。
  • 模型规模：DriveRL 教师策略约 5.70M 参数；DriveZero 学生规划器参数量原文未报告。

Card 06 评估与结果

评估与结果

  • 评估基准：nuPlan 三个社区划分（Val14、Test14-hard、Test14-random）在非反应（NR）与反应（R）模式下评估；DriveZero 在 NAVSIMv1 navtest、NAVSIMv2 navhard 与 HUGSIM 闭环基准上评估。
  • 评估指标：nuPlan 使用闭环分数（CLS，0–100）；NAVSIM 使用 PDMS / EPDMS；HUGSIM 使用 HD-Score。
  • 关键数值：DriveRL 在 nuPlan 六项设置上的平均得分为 93.01，经值引导测试时搜索提升至 93.57（DriveRL-TTS），且在全部三项划分上均超过 Log-Replay 专家；DriveZero 在 NAVSIMv1 上达 95.3 PDMS（超过人类驾驶者 94.8），在 NAVSIMv2 上达 57.1 EPDMS，在 HUGSIM 上 zero-shot 达 46.6 HD-Score。
  • 对比方法：Log-Replay、IDM、PDM-Closed、UrbanDriver、PlanTF、PLUTO、Diffusion Planner、Flow Planner、Pi-DiMT、Plan-R1、PlannerRFT，以及无需人类数据的 CaRL 和 GigaFlow。
  • 实验条件：DriveRL 为闭环仿真评估；DriveZero 在 NAVSIM 为 pseudo closed-loop 基准，在 HUGSIM 为真实闭环基准；（3.3 节提及实车部署配置，具体实车评估结果原文未报告）。
