Card 03 核心贡献

核心贡献

  • 提出共享 5B 可控视频主干，包含双向与因果两种发布形式，同时支持文本到视频与图像到视频生成；前者面向高质量离线生成与监督，后者面向可缓存、持续、少步交互。
  • 提出统一控制接口：通过 PRoPE 注入完整相机内参和外参，用 64 维连续动作流与具身 ID 调制每个视觉层；支持在 rollout 指定位置插入文本事件，并保留可后训练的动作序列输出接口。
  • 提出五阶段训练流程：双向控制适配、block-causal teacher forcing、在线 UniPC 轨迹蒸馏、混合域因果 SFT、非对称 DMD/DMD2，并报告整个流程可在两张 NVIDIA L20 48 GB GPU 上运行。
  • 在 WBench（Navi 158 与 Full 289）和部分 VBench 1.0 上评估，报告 5B 模型在两张 L20 GPU 上后训练后达到 13.6B 到 22B 模型的 WBench Full 分数范围。
  • 发布网站、GitHub 与 Hugging Face 资源，并提供双向 checkpoint restore-2200 与因果 checkpoint DMD1545 等模型形式。
Card 04 方法描述

方法描述

  • 所属模块：论文属于视频世界模型基础模型，包含数据层、模型层、训练层、推理与评估层。
  • 输入传感器：原文报告输入包括文本提示、初始观测图像、首帧、相机内参与外参、64 维连续动作和具身 ID；未报告真实传感器硬件细节。
  • 场景表示：RGB 片段经 Wan2.2 VAE 编码为 48 通道视频 latent；latent 满足 N=4(F−1)+1，第一帧单独编码，后续每个 latent 帧覆盖 4 个 RGB 帧；patch embedding 为 1×2×2。
  • 模型结构：基于 Wan2.2-TI2V-5B，30 层 DiT，隐藏宽度 3072，head 24，FFN 宽度 14336，latent 通道 48，权重 bfloat16，参数量 5,351,000,000。
  • 关键技术：双向模型使用 full temporal attention；因果模型使用 block lower-triangular 时间注意力、跨 block KV 缓存、8 latent 帧一个推理 block、20 latent 帧局部窗口与 4 个持久 sink 帧。
  • 相机控制：PRoPE 注入全部 30 层的相机内参与外参；WBench adapter 处理 c2w、w2c 与归一化内参约定，并反转 extrinsic。
  • 动作控制：64 维连续动作经两层 MLP 变换，加入具身 embedding，并投影为每帧六组调制，即 attention 与 FFN 的 shift、scale、residual gate；最终动作投影零初始化。
  • 文本与事件：文本由冻结的 UMT5 编码器编码并经 cross-attention 注入；事件在指定 latent 帧 s 处以 p⊕e 形式重新编码，前序帧保留在 KV cache 中，因此编辑局部发生。
  • 输出接口：action_output 可将每 latent 帧空间视觉 token 池化后经 LayerNorm-MLP 解码为 [B,F,64] 动作序列；WBench 视频生成 checkpoint 使用 use_action=true、action_dim=64、num_embodiments=32。
  • 采样：默认 UniPC，八步，CFG 3.0；蒸馏目标为四步，论文报告八步质量最佳。
  • 原文未报告的模型结构细节：未报告文本编码器层数、VAE 具体网络结构、PRoPE 的完整公式展开、动作调制 MLP 隐层宽度。

Card 06 评估与结果

评估与结果

  • 评估基准：WBench Navi 158、WBench Full 289，以及部分 VBench 1.0；WBench 评估因果模型，VBench 评估因果模型；推理不将一次生成拆分给双向 teacher 与因果 student。
  • 评估指标：WBench 五维分数、WBench Navi、WBench Full、VBench 1.0 部分指标、事件与视角切换相关分数、RGB 差异、内部运动诊断、平均相邻帧 latent 变化。
  • 关键数值：Astronex-World 1.0 在 WBench Navi 得分 73.5，在 WBench Full 得分 70.0；因果模型以 832×480、24 fps 生成，使用八步 UniPC、八 latent 帧 block、local history 与 persistent sink frames。
  • 对比方法：WBench Full 上，5B 模型高于 13.6B LongCat-Video 与 14B Helios，与 22B LTX-2.3 相差约 1 分以内，并高于 YUME 1.5；YUME 1.5 基于同一 5B Wan2.2 prior 在 NVIDIA A100 GPU 上后训练。
  • 事件局部性结果：与无事件 rollout 对比，switch 前帧 RGB 平均差异 1.8/255，switch 后帧平均差异 9.5/255。
  • 结果条件：论文报告 WBench 与 VBench 评估因果模型，生成输出为 832×480 时用于 benchmark，模型也支持 1280×704、24 fps 输出。
  • 开环/闭环/仿真/实车：原文报告 WBench、VBench、部分 VBench 1.0 与流式生成评估；未报告闭环控制评估、仿真器评估或实车评估。
  • 分析限制：当前 adapter 仅暴露一个最早文本切换点，同一 case 的多个定时事件会被合并；论文指出该接口限制有助于解释 WBench Full 289 上事件与视角切换分数较低。
