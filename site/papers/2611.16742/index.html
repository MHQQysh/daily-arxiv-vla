Fog-FWL: A Large-Scale Full-Waveform LiDAR Dataset for Recovering Fog-Hidden Objects

论文概述

  • 任务：面向自动驾驶的雾天全波形 LiDAR（FWL）感知，在峰值检测转换为点云之前直接从原始接收波形中恢复被雾遮挡弱化的物体回波，并支撑下游 3D 目标检测评估。

Card 03 核心贡献

核心贡献

  • 构建 Fog-FWL-Real：首个大规模真实雾天 FWL 数据集，包含 8 个场景、58 个序列、7,527 帧，比唯一已有真实雾天 FWL 数据大 579×，并提供直方图级 Object/Fog/Noise 标签、10,719 个 3D 边界框和基于物体反射衰减的三级难度划分。
  • 开发 Fog-FWL-Simulator：融合 CARLA 驾驶场景、非均匀雾密度场、基于 Mitsuba 3 的时间分辨体积光传输渲染（含多次散射）以及光子计数 SPAD 接收机模型，并据此构建 12,000 帧训练集 Fog-FWL-Sim。
  • 使真实与仿真两个子集采用相同传感器格式与标注协议，从而支持严格的 sim-to-real 评测（训练不使用任何真实波形）。
  • 通过数据分析量化峰值检测造成的信息损失：Hard 条件下仅有 34.9% 的物体射线的物体回波进入最强三个峰。
Card 04 方法描述

方法描述

  • 所属模块：数据与仿真基础设施（数据集构建 + 物理仿真管线），非端到端感知网络；原文未报告恢复方法或检测网络的具体结构（作者称基准结果将在后续版本报告）。
  • 输入传感器：自研 SPAD 全波形 LiDAR，从 FPGA 直接获取时间分辨光子计数直方图；每帧 400（方位）×512（俯仰）×700（时间）像素，角分辨率 0.1°（方位）/0.05°（俯仰），视场 40°×25.6°，时间分辨率 1 ns。商用 LiDAR 因内部处理仅输出点云，无法获取峰值检测前波形。
  • 场景表示：真实数据在室外停车场采集，8 个场景改变背景（建筑、树木）与车辆布置（1–3 辆车，距传感器 10–20 m）；仿真使用 CARLA 的 Town01–07 与 Town10 共 8 个城市场景，传感器俯仰在 −3° 到 3° 间变化，车辆置于传感器前方 ±17° 方位、距离至少 15 m 且中心在 25 m 内。
  • 雾生成（真实）：使用 STAGE EVOLUTION PFOG1500 烟雾机，在传感器与目标车辆之间生成局部雾（而非均匀雾舱），通过改变烟雾机工作间隔控制雾浓度。
  • 雾场与渲染（仿真）：采用烟羽模型定义消光系数 σ_t(x)，烟羽半径 R(s)=r₀+as+b√(s/U)，内部 σ_t(x)=c(r₀/R(s))²(1−ρ²/R(s)²)²M(x)，M(x) 为多尺度分形噪声；雾源位于视线侧方、以相对视线 80–88° 方向平流；雾作为参与介质置于场景，单次散射反照率 ω 与 Henyey–Greenstein 相位函数定义散射，传感器处放置时间脉冲点光源，通过含介质多次散射、单次表面反弹的路径追踪计算时间分辨响应，再与真实激光脉宽（FWHM 匹配）卷积。
  • SPAD 接收机模型：以 N 个 SPAD 单元/像素建模，单元 n 在 bin k 探测光子的伯努利概率 a_k=1−e^(−λ_k/N)，复现计数饱和；单元探测后输出保持 T_d 个 bin 的抑制期，复现 pile-up 与 tailing；像素计数 C_k 为输出为 1 的单元数。
  • 难度控制与标注：真实数据用 r=I_fog/I_clear 表示框内物体峰值强度比，按序列取 20 帧等间隔中值，Easy r≥0.70、Moderate 0.40≤r<0.70、Hard r<0.40；仿真以残差比目标 0.80/0.50/0.25 通过对数尺度二分确定密度尺度 c，再用与真实数据相同流程重评难度。标注上，Object 以无雾参考波形（约 100 帧求和）最大峰 bin k_ref 为基准，雾天波形中 ±2 bin（±0.30 m）内最近峰标为 Object，否则标 k_ref 本身；Fog 用区间检测（背景 λ 为物体后方均值，超过 λ+5√λ 且 ≥3 并连续 5 bin 以上），排除 k_ref 前三 bin 之前及地面以下 0.15 m 的标签；Object/Fog 按半高全宽时间延展，其余为 Noise。3D 边界框在 FWL 转换点云上人工标注并由专家核验，仿真中框来自场景布局。
Card 05 数据集与资源

数据集与资源

  • 数据集：Fog-FWL-Real（8 场景、58 序列、7,527 帧；含约 9.4 亿 Object 标签与 10,719 个 3D 框；仅用于评测）；Fog-FWL-Sim（1,500 视角/城镇 × 8 城镇 = 12,000 帧，每视角 1 帧，目标与雾分布逐视角变化）；全集合共 19,527 帧。按难度：Real 为 Easy 4,007 / Moderate 2,451 / Hard 1,069；Sim 为 1,857 / 3,969 / 6,174；合计 5,864 / 6,420 / 7,243。
  • 仿真器/渲染器：CARLA（场景构建）、Mitsuba 3 与 mitransient（时间分辨体积渲染）。
  • 实车平台：室外停车场采集，使用自研 SPAD LiDAR 与 PGOG1500 烟雾机；未报告具体车辆型号与安装方式。
  • 模型规模与训练资源：原文未报告（未提出或训练具体网络，也未报告 GPU/训练时长等信息）。
  • 数据公开：论文称数据集将在录用后公开发布。
Card 06 评估与结果

评估与结果

  • 评估基准：Fog-FWL-Real 作为真实雾天评测基准，分为 Easy/Moderate/Hard 三档；提出严格的 sim-to-real 设定（Fog-FWL-Sim 训练、Fog-FWL-Real 评测，不使用真实波形训练）。
  • 评估指标：物体射线中 Object 标签落入最强 k 个峰的比率（Top-1/Top-2/Top-3）；用于下游评估的 3D 边界框指标原文未报告；对比方法原文未报告具体恢复/检测方法。
  • 关键数值：Easy 条件 Top-1/2/3 = 60.7%/79.7%/87.1%（4,007 帧）；Moderate = 26.4%/53.4%/65.8%（2,451 帧）；Hard = 11.6%/25.5%/34.9%（1,069 帧）。仅取最强峰（等价单回波点云）时 Hard 下物体回波仅被捕获 11.6% 的射线。
  • 条件说明：结果为真实数据（Fog-FWL-Real）上的统计分析，属数据层面开环评估；未报告闭环实验、仿真到真实的定量迁移结果、实车闭环测试或恢复方法与检测方法的基准数值，作者明确表示这些结果将在后续版本报告。
