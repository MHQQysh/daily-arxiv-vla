Card 03 核心贡献

核心贡献

  • 提出 DriveOSS，据作者所述为首个专门面向 3D 开集语义分割的真实世界多模态数据集，提供同步 LiDAR、环视 RGB 与逐点标注，覆盖多种天气与光照条件。
  • 建立 3D 异常分割与 3D 开集语义分割基准，并在 ID 子集上补充闭集语义分割评估。
  • 将 open-IoU 从像素域扩展到 3D 点域，用于联合评估已知类识别与未知物体检测。
  • 使用后处理异常评分方法与基于特征的方法，对代表性纯 LiDAR 模型与 LiDAR–相机融合模型进行基准评测，揭示闭集精度、异常排序与开集性能之间的显著差距。
Card 04 方法描述

方法描述

  • 所属模块：数据集构建、标注流程与基准评测协议；论文本身不以提出新感知网络为主要方法贡献。
  • 输入传感器：Ouster OS1-128 128 线 LiDAR、6 个 Basler 环视 RGB 相机、Certus GPS/IMU；各传感器同步到统一 GPS 时间参考，相机 10 Hz、LiDAR 20 Hz、GPS/IMU 600 Hz。
  • 场景表示：以 LiDAR 点云为主，可选配同步 RGB 图像；逐点语义/异常标注，包含 19 个与 SemanticKITTI 对齐的 ID 类及第 20 类 outlier。
  • 标注流程：Mask4Former 在 SemanticKITTI 上预训练生成已知类粗预标注，KISS-ICP 配准连续扫描并载入 SemanticKITTI Point Labeler，标注员进行大量人工修正；每条序列由至少一名额外标注员独立交叉检查。
  • 关键技术：相机内参使用 Zhang 方法估计，LiDAR–相机外参通过人工选取 2D–3D 对应后使用 PnP 求解；评测涵盖闭集 mIoU、异常分割 AUROC/AP/FPR@95、开集 open-IoU/mOpen-IoU 与 outlier IoU。
  • 异常评分方法包括 MSP、MaxLogit、Energy、Entropy、RbA，以及 LIDO 的基于特征的异常评分；开集阈值在 OOD 验证集上按 95% OOD 真阳性率校准后固定用于测试集。

Card 05 数据集与资源

数据集与资源

  • 数据集：DriveOSS 共 12,661 帧同步标注数据、75,966 张相机图像、12,661 条 GPS/IMU 数据，涵盖 52 个真实驾驶场景；含 19 个 ID 序列与 33 个 OOD 序列，采集地点地理上不重叠。
  • 数据划分：9 个 ID 训练序列（2,240 帧）、10 个 ID 验证序列（2,384 帧）、17 个 OOD 验证序列（4,278 帧，366,288 个 OOD 点）、16 个 OOD 测试序列（3,759 帧，1,156,460 个 OOD 点），共 1,522,748 个标注 OOD 点。

Card 06 评估与结果

评估与结果

  • 评估基准：DriveOSS-ID 验证集与 DriveOSS-OOD 测试集；三个任务分别为闭集 3D 语义分割、3D 异常分割、3D 开集语义分割。
  • 评估指标：闭集使用 19 类 IoU 与 mIoU；异常分割使用 AUROC、AP、FPR@95；开集使用类级 open-IoU、mOpen-IoU 与 outlier IoU。
  • 对比方法：纯 LiDAR 模型 Mask4Former3D（M4F3D）、P3Former、LCPS-lidar、LIDO；LiDAR–相机融合模型 LCPS 与作者扩展的 Mask4Former3D*（M4F3D*）；异常评分使用 MSP、MaxLogit、Energy、Entropy、RbA。
  • 闭集结果：LIDO 在 ID 验证集与 OOD 测试集 ID 点上均取得最高 mIoU，分别为 58.35% 与 40.99%，在 OOD 上领先第二名 6.99 个点；LCPS 相比 LCPS-lidar 在 ID 上提升 2.11 点，但在 OOD 上仅提升 0.25 点；M4F3D* 相比 M4F3D 在 ID 上提升 13.46 点，但在 OOD 上下降 2.65 点；所有方法从 ID 到 OOD 均出现退化（如 LIDO 下降 17.36 点）。
  • 异常分割结果：LIDO 取得最佳 AUROC 91.70% 与最低 FPR@95 32.66%；M4F3D+RbA 取得最高 AP 12.57% 但 FPR@95 为 100%；RbA 在 P3Former 上 AUROC 为 89.80%，在 LCPS-lidar 上为 50.65%，在 M4F3D* 上为 45.43%；M4F3D* 相对 M4F3D 在 Energy 与 RbA 上 AUROC 分别下降 23.50 与 22.48 点。
  • 开集分割结果：LIDO 取得最高 mOpen-IoU 22.98% 与 outlier IoU 1.07%，但其 mOpen-IoU 比同场景闭集 mIoU 低 18.01 点；M4F3D 最佳 mOpen-IoU 为 9.58%，M4F3D* 最佳为 11.27%，两者 FPR@95 均较高（约 96.85%–100%）；M4F3D*+RbA 将 mOpen-IoU 从 9.58% 提升到 11.27%，但 outlier IoU 从 0.32% 降至 0.21%。
  • 总体结论：多模态融合提升域内闭集识别，但在异常与开集分割上无一致优势，已知类识别、异常排序与阈值化开集预测之间存在不匹配。
  • 实验条件：全部为真实数据上的离线评测（ID 验证集与 OOD 测试集），不涉及闭环仿真或闭环实车测试；推理效率在原文目录中出现对应小节，但正文内容未在给定原文中报告。
