论文概述

Card 03 核心贡献

核心贡献

  • 提出统一的动态 LiDAR 仿真框架 URL-Sim，将刚性车辆、SMPL 行人以及无模板非刚性对象（如骑行者）纳入同一动态高斯场景图进行建模。
  • 提出受调控高斯致密化（RGD）策略，通过二次预算分配和多维重要性评分，在总基元数有界的前提下平衡仿真精度与计算开销。
  • 在 Waymo 和 KITTI-360 数据集上验证了对非刚性交通参与者几何与位姿的准确恢复，并在相近基元预算下取得优于现有基线的 2D 感知质量与 3D 几何精度。
Card 04 方法描述

方法描述

  • 所属模块：LiDAR 仿真与动态场景重建；整体流程包括动态高斯场景图构建、可微 LiDAR 光线追踪渲染、RGD 训练期致密化以及后处理 U-Net。
  • 输入传感器：原始 LiDAR 点云与目标跟踪边界框；原始数据被解析为深度图和强度图。
  • 场景表示：以 2D 高斯泼溅（2DGS）为基本图元，参数包括均值位置、缩放、旋转四元数、不透明度、强度以及射线丢失概率；强度与射线命中/丢失对数通过球谐系数建模方向依赖。场景被分解为静态背景、刚性实例、SMPL 行人和一般可变形实例。
  • 模型结构：刚性对象在对象中心规范空间建模并按时戳做刚体变换；行人高斯绑定到 SMPL 网格顶点，通过 LBS 和可优化体素变形器驱动蒙皮变形，初始姿态参数由图像域观测获得；无模板非刚性对象由轻量变形网络预测位置、旋转与尺度残差，网络参数全局共享并以实例级嵌入区分不同对象。
  • 关键技术：RGD 按二次增长曲线分配每轮致密化预算，并以属性重要性、射线渲染贡献、距离、交叠频率和 geo-semantic 边缘图构建重要性分数，进行加权随机重采样与剪枝；训练损失联合深度、中值深度、强度、SSIM、畸变、射线丢失 BCE、点云 Chamfer 及正则项。
  • 原文未报告：变形网络的具体层数、隐藏维度等网络细节，以及各损失权重的具体取值。

Card 06 评估与结果

评估与结果

  • 评估基准：Waymo Open Dataset 与 KITTI-360 上的动态场景重建；对比方法包括 DyNFL、LiDAR-NeRF、LiDAR4D、LiDAR-GS、GS-LiDAR 和 LiDAR-RT。
  • 评估指标：2D 深度与强度的 RMSE、MedAE、LPIPS、SSIM、PSNR；3D 点云的 Chamfer Distance（CD）与 5 cm 阈值 F-Score；效率指标 FPS 与高斯基元数量。
  • 关键数值（Waymo）：URL-Sim 为 17.6 FPS、3.00M 基元，深度 RMSE 5.9844、MedAE 0.0184、LPIPS 0.2042、SSIM 0.7154、PSNR 22.5603；强度 RMSE 0.0503、MedAE 0.0052、LPIPS 0.1377、SSIM 0.8259、PSNR 26.5183；CD 0.0468、F-Score 0.9682。LiDAR-RT 为 20.1 FPS、3.17M 基元，深度 RMSE 6.3597，CD 0.0863、F-Score 0.9461。
  • 关键数值（KITTI-360）：URL-Sim 为 22.3 FPS、3.00M 基元，深度 RMSE 3.4700、MedAE 0.0277、LPIPS 0.0583、SSIM 0.9162、PSNR 27.3792；强度 RMSE 0.0844、MedAE 0.0233、LPIPS 0.1404、SSIM 0.7334、PSNR 21.5475；CD 0.0909、F-Score 0.9447。
  • 消融结果：Waymo 上移除非刚性建模（w/o NRM）后 F-Score 降至 0.9543；移除 RGD（w/o RGD）后 PSNR 与 CD 分别变差至 26.0181 与 0.0710；KITTI-360 上完整 RGD 在多项指标上最优（如 CD 0.0798、F-Score 0.9577 对应的 RGD 行）。
  • 评估条件：全部为数据驱动开环重建与仿真评估，原文未报告闭环规划评估或实车测试。
