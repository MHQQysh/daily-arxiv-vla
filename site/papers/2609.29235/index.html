Card 02 论文概述

论文概述

  • 论文针对自动驾驶中的相机-LiDAR 3D 目标检测任务，研究在传感器退化、恶劣天气和光照变化等不可靠感知条件下的鲁棒融合问题。

  • 核心研究问题是：现有融合检测器通常从紧耦合多模态表示中解码目标查询，形成较强跨模态依赖，在某一模态不可靠时会产生负迁移。

Card 03 核心贡献

核心贡献

  • 提出 SARFusion，一种面向鲁棒相机-LiDAR 3D 目标检测的场景感知分支路由框架，在相机分支、LiDAR 分支和相机-LiDAR 融合分支之间动态选择，而非依赖固定融合路径。
  • 引入 Scene Reliability Prior，从全局驾驶条件建模场景相关的模态可靠性，为退化环境下的路由提供条件感知指导。
  • 设计 Scene-Aware Branch Routing，将场景可靠性先验与目标查询周围的局部观测证据结合，执行查询级分支选择。
  • 报告 SARFusion 在多种传感器失效条件和极端天气场景下取得优于现有相机-LiDAR 融合方法的表现。
  • 作者声明代码将公开。
Card 04 方法描述

方法描述

  • 所属模块：相机-LiDAR 3D 目标检测中的多模态融合与鲁棒感知模块。
  • 输入传感器：多视角相机图像和 LiDAR 点云。
  • 场景表示：相机特征被展平为图像 token，LiDAR 特征被编码为 BEV token，并拼接为多模态上下文 token。
  • 模型结构：SARFusion 维护三个候选解码分支，即相机分支、LiDAR 分支和相机-LiDAR 融合分支；相机分支使用相机 token 解码目标查询，LiDAR 分支使用 LiDAR token，融合分支关注多模态 token。
  • Scene Reliability Prior：使用轻量 Transformer 聚合场景级信息，将可学习 scene token 前置到多模态 token 中，输出投影后得到场景可靠性先验；训练时用文本场景提示监督，例如“A {weather condition} driving scene at {time of day}.”，并采用对称对比损失；推理时不需要文本提示或场景标签。
  • Scene-Aware Branch Routing：对每个目标查询，将其参考点投影到相机特征平面和 LiDAR BEV 平面，构造局部注意力窗口；使用局部注意力掩码收集相机和 LiDAR 局部 token，得到查询特定局部区域；通过 masked attention 计算局部观测证据，并与场景先验拼接后经 MLP 和 Softmax 预测三分支概率；选择概率最大的分支进行最终解码。
  • 训练目标：包括三分支各自的检测监督、场景先验对比监督和路由监督；采用分阶段训练策略，先训练三个解码分支，再学习 Scene Reliability Prior，最后优化路由器。
  • 原文未报告：具体相机与 LiDAR 编码器骨干网络名称、模型参数量、特征维度 D 的取值、各损失权重 λ 的取值、局部注意力窗口大小等实现细节。

Card 06 评估与结果

评估与结果

  • 评估基准：nuScenes 验证集和测试集；退化条件评估在 nuScenes 验证集上进行，包括 clean、snow、rain、fog、strong sunlight。
  • 评估指标：官方 mAP 和 nuScenes Detection Score（NDS）。
  • 关键数值：SARFusion 在 nuScenes 验证集取得 71.1 mAP 和 73.7 NDS；在测试集取得 72.5 mAP 和 74.4 NDS。
  • 退化条件结果：相比最强竞争结果，SARFusion 在 clean 场景 mAP 提升 0.8，在 snow 下提升 1.3，在 rain 下提升 3.2，在 fog 下提升 7.8，在 strong sunlight 下提升 2.0。
  • 对比方法：包括相机方法 FCOS3D、PETR、BEVDet；LiDAR 方法 SECOND、CenterPoint、TransFusion-L；相机-LiDAR 融合方法 FUTR3D、PointAugmenting、UVTR、AutoAlignV2、TransFusion、MetaBEV、BEVFusion、DeepInteraction、SparseFusion、CMT；退化条件表中还包括 DETR3D、PointPillars 等。
  • 消融结果：单融合分支为 70.7 mAP、73.1 NDS；多分支无路由降至 52.4 mAP、62.8 NDS；加入 Scene-Aware Branch Routing 后为 70.8 mAP、73.1 NDS；再加入 Scene Reliability Prior 后为 71.1 mAP、73.7 NDS。
  • 场景先验监督消融：无场景先验监督为 69.6 mAP、72.1 NDS；有场景先验监督为 71.1 mAP、73.7 NDS。
  • 路由证据消融：仅局部证据为 70.8 mAP、73.1 NDS；场景先验加局部证据为 71.1 mAP、73.7 NDS。
  • 训练策略消融：直接训练为 65.7 mAP、69.6 NDS；分阶段训练为 71.1 mAP、73.7 NDS。
  • 开环、闭环、仿真或实车条件：论文报告的是 nuScenes 标准验证/测试集和退化验证条件下的评估；原文未报告闭环评估、仿真器评估或实车评估。
