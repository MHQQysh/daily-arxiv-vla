Card 01 研究单位

研究单位

  • 机构：Voyah Automotive Technology Co., Ltd., Wuhan, China；作者：Haoyu Xing, Shaobing Ding, Guanglei Zhao, Guanhua Zhao, Nawu Peng, Mingyang Hou
Card 02 论文概述

论文概述

  • 任务：端到端自动驾驶多模态轨迹规划与候选轨迹选择（依据预测分数从多条候选轨迹中选出一条执行）。
  • 应用场景：基于多相机图像与自车状态的联合感知–规划系统，评估场景为 NAVSIM 非反应式短时程仿真基准。
  • 研究问题：候选轨迹条件化的场景预测在不同候选之间可能对同一目标给出不一致的状态，缺乏共同的物体级参照；聚合式规划分数又不显式说明违规涉及哪个物体、在何时首次发生，难以诊断物体关联与事件时序错误。
Card 03 核心贡献

核心贡献

  • 提出与候选轨迹无关的 World Memory：维护共享的物体与地图槽位，估计场景结构和物体运动，每一轮细化都从原始视觉特征重新读取更新，避免世界状态随候选集合变化。
  • 提出残差式 Task 条件机制且不写回 World：将候选反馈表示为相对共享 World 槽位的残差，通过候选特定检索与门控视觉反馈引导轨迹细化，最终 Task 读出提供用于打分的候选条件特征，候选反馈从不写回 World Memory。
  • 提出结构化风险监督：从已有候选打分 rollout 中导出风险目标而无需额外仿真器调用，对自车责任碰撞与 TTC 违规编码事件是否存在、与共享物体槽位的关联、以及首次违规时间 bin。
  • 在 NAVSIM navtest 上报告 94.66 PDMS（v1）与 88.24 EPDMS（v2），分别比已发表 Drive-JEPA 值高 0.96 与 0.44 分，并开展候选级分析揭示候选质量与选择有效性之间的差距。
Card 04 方法描述

方法描述

  • 所属模块：端到端规划器，构建于 Drive-JEPA 之上（复用其预训练编码器、候选初始化、轨迹解码器、BEV refiner、候选间交换与多模态训练），新增 World/Task 分解与结构化风险头。
  • 输入传感器：多相机图像（左、前、右三路各两帧）与自车状态；v1/v2 对比表中 WTR-Drive 输入为纯相机（C）。
  • 场景表示：World Memory 为物体槽位（32 个）与固定栅格地图槽位（8×8）的拼接；物体参考依据当前 World 框估计，地图参考使用固定地面 BEV 单元；Task Memory 采用相同物体/地图布局但引入当前候选集合，以残差形式叠加于 World 槽位。
  • 模型结构：V-JEPA ViT-L 编码器将图像投影为 d=256 的视觉特征 F0；在 I=4 个共享参数轮次中，World 更新 W^(i)=W(W^(i-1),F0) 只读原始视觉特征；候选细化读取 M^(i)=W^(i)+Δ^(i-1)，输出 Q^(i)、Y^(i)，再由 Block_task 以 World 槽位为 query、全部候选 token 为 key/value 得到 T^(i) 与残差 Δ^(i)=T^(i)−W^(i)；门控 α=tanh(g) 控制视觉反馈 F_ctx^(i)=F0+α·MHA_vis(F0;T^(i))，门控 β=tanh(g_r) 与尺度 s∈[0,1] 控制最终读出 Q̂=Q^(I)+sβ·MHA_read(Q^(I);T^(I))，两个门初始化为 0.01。
  • 关键技术：候选间交互采用时间均值交换并广播到所有预测步；预测 P=32 条候选、T=8 个未来位姿（0.5 s 间隔）；结构化风险以匈牙利匹配（类别与框代价）将 GT 物体对应到 World 槽位，经 log-sum-exp 聚合关系 logits 得到物体关联分布与时间分布，并用独立 MLP 从时间最大池化特征预测事件存在性（focal 二值损失；关联与时间用交叉熵）。
  • 原文未报告：风险辅助头是否参与最终轨迹选择（原文明确其不选择轨迹）。
Card 05 数据集与资源

数据集与资源

  • 数据集：NAVSIM navtest split，共 12,146 个场景（含专家轨迹）；训练期候选诊断使用独立的 512 场景验证子集。
  • 仿真器：NAVSIM 非反应式短时程仿真；v2 采用 Drive-JEPA 的 expert-frame 序贯评估且不做 HPF 修正；未报告其他仿真器或实车平台。
  • 模型规模：V-JEPA ViT-L 骨干；特征维度 d=256；P=32 候选、T=8 位姿、I=4 轮、32 物体槽位、8×8 地图槽位；空间范围场景查询 [-8,56]×[-32,32]×[-2,6] m，地图 [0,56]×[-32,32] m。
  • 训练资源：50 个 epoch，Adam，学习率 1e-4，骨干乘子 0.1，混合精度；全局 batch size 576（9 节点 × 16 设备 × 4 样本/设备），无梯度累积；v1 梯度裁剪 1，v2 不裁剪；单种子（seed 0），验证选择 v1 第 41、v2 第 47 个（零基）epoch。
  • 实车平台：原文未报告。
Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM navtest，v1 报告 PDMS，v2 报告 EPDMS（另报告经 HPF 修正的 EPDMS_H）。
  • 评估指标：PDMS 及分量 NC、DAC、DDC、TLC、EP、TTC、C、LK、HC、EC；EPDMS 将 NC、DAC、DDC、TLC 相乘后与 EP、TTC、LK、HC、EC 的加权均值（权重 5,5,2,2,2）相乘。
  • 关键数值：v1 PDMS 94.66（NC 99.21、DAC 99.06、EP 92.33、TTC 96.52、C 99.89）；v2 EPDMS 88.24（NC 98.25、DAC 98.56、DDC 99.10、TLC 99.92、EP 89.86、TTC 97.78、LK 97.57、HC 98.04、EC 84.62）。v2 上 EP 高于 Drive-JEPA，但 NC（98.25 vs 98.40）与 EC（84.62 vs 84.80）更低，总分为安全、进度与时间一致性之间的折衷。
  • 对比方法：DiffusionDrive、GoalFlow、DiffusionDriveV2、iPad、DriveSuprim、Drive-JEPA；已发表 Drive-JEPA 为 v1 93.70 PDMS、v2 87.80 EPDMS。
  • 消融与干预（表 III，单种子）：场景查询基线 94.20 PDMS / 88.32 EPDMS / 91.59 EPDMS_H；加地图细化 94.43 / 88.45 / 91.84；无子分数损失（读出开）94.35 / 88.39 / 91.88；加排序损失 94.22 / 88.35 / 91.75；完整 WTR-Drive 94.66 / 88.24 / 91.55。无子分数损失模型关闭读出后为 94.48 / 88.46 / 91.95；完整模型关闭读出后为 94.65 / 87.89 / 91.26。完整模型中开启读出相对关闭使 PDMS +0.01、EPDMS +0.35、EPDMS_H +0.29。
  • 候选级诊断（512 场景子集）：完整模型平均最优候选分 96.63、平均选中候选分 89.11；无子分数监督时分别为 96.33 与 89.64，说明最优候选分更高不保证选中轨迹分数更高。
  • 条件：全部为 NAVSIM 开环/非反应式仿真评估（v2 为 expert-frame 序贯评估），未报告闭环实车结果；定性图（8 个场景）为人工挑选，不能估计基准上的发生频率；风险关联标签覆盖率在所选 v1/v2 epoch 为 71.24%/74.67%（按 batch 平均，非留出准确率）。
