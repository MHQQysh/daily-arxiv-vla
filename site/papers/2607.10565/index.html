Card 03 核心贡献

核心贡献

  • 提出基于桶（Bucket）的规划状态表示方法，将关键环境变量离散化为自适应区间（buckets），相比二值简化表示能捕获更丰富的场景语义，同时保持状态规模可控、维持压缩效率。
  • 设计安全感知的 waypoint 注意力机制，利用 TTC（Time-to-Collision）公式同时考虑障碍物距离与相对运动（是否接近、接近速度），以评估每个 waypoint 的风险等级，增强蒸馏过程中对安全关键行为的保留。
  • 在 CARLA 的 Bench2Drive 标准基准上开展大量对比实验，验证了 BucketKD 在规划精度和安全指标上均优于现有 SOTA 知识蒸馏方法，且在不同模型规模（16.6M、10.3M、5.4M 参数）下均保持一致的性能优势。
Card 04 方法描述

方法描述

  • 所属模块：知识蒸馏（Knowledge Distillation）框架，包含两个核心蒸馏模块：BPFD（Bucket-based Planning-relevant Feature Distillation）与 SWD（Safety-Aware Waypoint-Attentive Distillation）。
  • 输入传感器：原文未报告具体传感器类型，仅提及原始传感观测（如图像）作为输入。
  • 场景表示：BEV（Bird's-Eye-View）场景图像，格式为 B ∈ R^(C×H×W)，用于与 waypoint 计算注意力权重。
  • 模型结构：标准端到端运动规划网络由感知主干（perception backbone）与运动生成器（motion producer）组成；蒸馏中包括教师模型 F^T_θ 与学生模型 F^S_φ。
  • 关键技术：BPFD 模块基于信息瓶颈（IB）原理，将环境规划状态（如附近车辆、行人、交通灯、路口）与动作规划状态（如制动、油门、转向、变道意图）离散化为桶；SWD 模块采用 TTC 安全核函数 ψᵢ=Σⱼκ^proxᵢⱼ·Σⱼκ^ttcᵢⱼ，其中 κ^prox 为高斯邻近核（基于距离），κ^ttc 为 TTC 指数衰减核（基于相对运动速度），并通过 pairwise ranking loss 使注意力权重与安全核函数排序一致。总优化目标为 L = L_w + L_w* − L_IB + α_z·L_z + α_r·L_rank + α_e·L_e，其中 L_z 为特征对齐的 L1 损失，L_IB 为信息瓶颈下界，L_rank 为排序损失，L_e 为注意力熵正则项。
Card 05 数据集与资源

数据集与资源

Card 06 评估与结果

评估与结果

  • 评估基准：Bench2Drive 官方基准（采用 Roach Agent 按标准协议评估）；采用三个主要指标：Driving Score（= Route Completion × Infraction Score）、Route Completion、Infraction Score，以及两个安全指标：Collision Rate（次/公里）与 Infraction Rate（次/公里）。
  • 评估条件：均为闭环（closed-loop）仿真评估；对比方法为 TCP 基准的未蒸馏模型与 SOTA 知识蒸馏方法 PlanKD（作为教师与学生模型）。
  • 关键数值（16.6M 规模）：相比未蒸馏的 TCP，BucketKD 使 Driving Score 提升 25.8%（29.61 → 37.26），Route Completion 提升 14.6%（59.57 → 68.28），Infraction Score 提升 5.2%，Collision Rate 降低 18.2%；相比 SOTA 学生模型，Driving Score 提升 21.9%（30.57 → 37.26），Route Completion 提升 23.8%（55.13 → 68.28），Infraction Score 提升 25.1%，Collision Rate 降低 9.4%，Infraction Rate 降低 16.4%。
  • 关键数值（10.3M 规模）：相比未蒸馏 TCP，Driving Score 提升 83.5%（14.05 → 25.78），Route Completion 提升 29.1%，Collision Rate 降低 23.9%；相比 SOTA 学生，Driving Score 提升（19.31 → 25.78），Collision Rate 从 2.529 降至 1.487。
  • 关键数值（5.4M 规模）：相比未蒸馏 TCP，Driving Score 从 8.46 提升至 16.53（提升 95.4%）；相比 SOTA 学生，Driving Score 提升 60.8%（10.28 → 16.53），Route Completion 提升 64.3%，Collision Rate 降低 14.6%，Infraction Rate 降低 24.9%。
  • 消融实验：BPFD 模块（M1）在所有骨干规模下均提升规划性能，如 10.3M 下 Driving Score 提升 40.6%、Collision Rate 降低 53.7%、Infraction Rate 降低 37.4%；SWD 模块（M2）对安全指标贡献显著，如 7.4M 下 Collision Rate 降低 60.1%、Infraction Rate 降低 41.2%，13.6M 下 Collision Rate 降低 31.0%、Infraction Rate 降低 19.3%。
  • 结论：BucketKD 在 bench2drive 基准上，在规划精度与安全性方面均一致优于现有最先进水平，且在更小的模型规模下性能提升更为显著。
