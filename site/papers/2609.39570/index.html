Sparse Planner: A Hybrid Planner for Efficient Sampling via a Conditional Variational Autoencoder

论文面向自动驾驶轨迹规划任务，聚焦采样式运动规划（SBMP）在复杂交通场景下需要密集采样、计算开销大且运行时波动明显的问题。 应用场景为基于 Frenét 坐标的轨迹规划：以参考路径为基准，采样横向偏移 d、目标速度 ṡ 与规划时域 T（即 (d, ṡ, t) 参数），生成候选轨迹并进行可行性与代价评估。 研究问题是：如何在学习辅助下把传统均匀密集采样替换为稀疏、代价偏置的采样过程，从而在保持轨迹质量的同时降低采样密度、提升运行时间的确定性与可预测性。 论文提出的 Sparse Planner（SP）保持下游轨迹生成模块不变，仅用条件变分自编码器（CVAE）学习场景上下文与有效轨迹参数之间的条件分布。

Card 02 论文概述

论文概述

  • 论文面向自动驾驶轨迹规划任务，聚焦采样式运动规划（SBMP）在复杂交通场景下需要密集采样、计算开销大且运行时波动明显的问题。
  • 应用场景为基于 Frenét 坐标的轨迹规划：以参考路径为基准，采样横向偏移 d、目标速度 ṡ 与规划时域 T（即 (d, ṡ, t) 参数），生成候选轨迹并进行可行性与代价评估。
  • 研究问题是：如何在学习辅助下把传统均匀密集采样替换为稀疏、代价偏置的采样过程，从而在保持轨迹质量的同时降低采样密度、提升运行时间的确定性与可预测性。
  • 论文提出的 Sparse Planner（SP）保持下游轨迹生成模块不变，仅用条件变分自编码器（CVAE）学习场景上下文与有效轨迹参数之间的条件分布。
Card 03 核心贡献

核心贡献

  • 提出 SP，一种基于 CVAE 的混合规划器，在保持较低、有界且可预测运行时间行为的同时实现更低轨迹代价。
  • 提出一种 CVAE 架构，包含新的设计元素与定制化损失公式以提升采样有效性：在负 ELBO 损失基础上加入生成式 MSE 项，并将先验建模为以 BEV 上下文为条件的分布，而非标准正态先验。
  • 将所需采样数降至八分之一，并在可比轨迹代价水平下相较当前最优方法 FISS+ 取得 2.5 倍加速，同时减少碰撞导致的规划失败。
  • 由于学习到的分布隐式把样本集中到轨迹空间的无碰撞区域，SP 在障碍密集场景下展现出更好的距离保持能力。
  • CVAE 采样不严格保证可行性，因此引入回退机制：若无法生成可行轨迹则调用经典 FOP，实验显示回退率可忽略至收敛水平。
Card 04 方法描述

方法描述

  • 所属模块：轨迹规划模块中的采样模块，替换 Frenét 参数空间中的均匀密集采样，下游轨迹生成、可行性检查、碰撞规避与代价函数评估保持一致以保证公平比较。
  • 输入传感器：论文未报告真实传感器输入，实验假设输入 CVAE 的 BEV 图像由前置预测模块提供；该模块运行时间未计入 SP 运行时间。BEV 表示包含道路几何、障碍物信息与全局规划器提供的参考路径。
  • 场景表示：以自车为中心、航向与图像纵向轴对齐的 BEV 表示，覆盖自车前后左右各 50 m（总计 100 m × 100 m）；将连续三帧 BEV 沿通道维堆叠为 3×256×256 的条件张量以引入时序动态；自车始终位于图像中心并固定朝向。
  • 模型结构：CVAE 包含编码器 q_φ(z\|x,y)、解码器 p_θ(x\|z,y) 与以上下文为条件的先验 p_ξ(z\|y)。条件帧经预训练 ResNet18 生成 (64, 32) token；输入 x=(d, ṡ, T) 被 token 化为 (16, 32)；加入可学习位置编码。编码器以 token 化输入为 query 对 BEV 上下文做多头交叉注意力，池化后线性投影得到潜分布参数 μ 与 logσ²（64 维）。解码器将潜变量线性投影到 (16, 32) token 空间，经交叉注意力关注条件表示 y，再由可学习 (1, 32) query 向量聚合为单一表示并投影回输入空间。先验由两个线性层从 BEV 上下文计算 μ 与 logσ²。
  • 关键技术：重参数化技巧使潜变量采样可微；训练最大化 ELBO 并额外加入生成式 MSE 项；推理时用先验替代编码器，解码器保持不变；采样数 N 可配置，每个参数向量映射为 Frenét 候选轨迹后经坐标变换转至全局坐标，再评估代价并选取最小代价轨迹。
  • 训练数据构造：先在 Frenét 参数空间 (d, ṡ, T) 上用 FOP 进行密集均匀采样，采样范围为 d∈[−1.7, 1.7] m（34 个样本，0.1 m 分辨率）、ṡ∈[0, 14] m/s（28 个样本，0.5 m/s 分辨率）、T∈[3, 5] s（20 个样本，0.1 s 分辨率），每规划周期共 19040 个样本；以 FOP 选出的最优轨迹对应的终端采样参数作为 CVAE 学习目标。
  • 原文未报告：CVAE 的网络层数、通道数、参数量、学习率、优化器、批大小、训练轮数与训练时长等训练超参数细节。

Card 06 评估与结果

评估与结果

  • 评估基准：在 350 个测试场景上与 FOP、FISS+ 对比；由于 FISS+ 在 82 个场景中无法生成可行轨迹，性能对比在三种规划器均成功到达目标的其余 268 个场景上进行，FOP 与带 FOP 回退的 SP 成功完成全部 350 个场景。
  • 评估指标：平均轨迹代价 J̄、每规划周期平均运行时间 t̄ [ms]、平均回退率 p_B（%）、FISS+ 未到达目标的场景比例 N_fail（%）。轨迹代价采用与 FISS+ 相同的代价函数，权重为 w_V=0.1、w_A=10、w_J=10、w_D=100、w_dist=0.1、w_T=1、w_LC=10。
  • 关键数值（采样数 N）：SP 在 N=64 时 J̄=71.16、t̄=47 ms、p_B=4.0%；SP 在 N=1 时 J̄=72.50、t̄=11 ms、p_B=18.9%；SP 在 N=125 时 J̄=70.85、t̄=82 ms、p_B=4.3%。FOP 在 N=125 时 J̄=74.81、t̄=72 ms；FISS+ 在 N=125 时 J̄=72.75、t̄=57 ms。SP 在 N=1 时轨迹代价即优于 N=125 的 FOP 与 FISS+。
  • 采样密度与加速：SP 使用八分之一采样密度即可取得低于 FISS+ 的轨迹代价；在可比轨迹代价水平下相较 FISS+ 取得 2.5 倍加速；N=64 时 SP 平均每规划步 47 ms，其中 CVAE 推理 7 ms；N=125 时约 82 ms。
  • 对比方法与失效情况：随着 N 从 125 增至 216，FISS+ 的 N_fail 从 23.4% 降至 20.5%，之后维持在约 20%；FOP 与 FISS+ 的指标从 N=125 起报告，因为更小采样数无法在所有场景中稳定产生可行轨迹；N=216、512、1000 分别对应每个变量 6、8、10 个样本。
  • 消融结果：采用公式 4 的损失使 MSE 降低约 14%，使用上下文条件先验额外再降低 10%。
  • 运行时间稳定性：FISS+ 的跨场景平均运行时间与标准差分布范围很宽，最差场景平均运行时间超过 175 ms、标准差超过 300 ms；SP 的运行时间分布紧凑、方差低，在 268 个场景上表现出更确定性的运行时间。
