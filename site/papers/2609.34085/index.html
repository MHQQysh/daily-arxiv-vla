Card 02 论文概述

论文概述

  • 论文面向端到端自动驾驶（E2EAD）任务，目标是构建动作条件化的 JEPA 世界模型，用于理解物理世界、推理与规划。
  • 应用场景为基于前视相机的端到端驾驶：输入历史图像-位姿对，预测未来自车位姿轨迹。
  • 研究问题：现有 JEPA 世界模型（LeWM、DINO-WM、JEPA-WM）在自动驾驶中存在“精确但计算昂贵”或“高效但规划不足”的权衡。
  • 论文采用目标条件零样本规划设置，以真实未来观测作为目标，在不训练任何驾驶策略的前提下评估世界模型质量，从而将世界模型质量与策略学习解耦。
  • 此外研究自监督预训练投影器能否迁移到下游模仿学习。
Card 03 核心贡献

核心贡献

  • 首次将 JEPA 适配到 E2EAD 用于目标条件零样本规划，并在成功率之外报告规划效率、测地精度和可靠性等驾驶性能指标。
  • 揭示现有 JEPA 世界模型在规划中效率与性能之间的显著权衡：要么计算高效但规划不准确，要么准确但每场景规划需超过一分钟。
  • 提出 AD-E2E-JEPA，在 JEPA-WM 基础上引入 SIGReg 正则化的可学习投影器，将规划 patch 数量减少 16 倍、嵌入维度减少 4 倍，同时保持规划性能。
  • 在 NAVSIM 零样本规划中，相比 LeWM 在全部 12,146 个测试场景平均提升 23.7 EPDMS，同时比 DINO-WM/JEPA-WM 规划时间少 100 倍。
  • 证明自监督预训练投影器可有效迁移到下游模仿学习，将 EPDMS 从 80.2 提升到 85.4。
Card 04 方法描述

方法描述

  • 所属模块：动作条件化的 JEPA 世界模型，用于端到端自动驾驶的零样本目标条件规划与下游模仿学习迁移。
  • 输入传感器：前视相机图像；论文考虑仅前视相机设置，原文未报告其他传感器输入。
  • 场景表示：历史上下文为图像-位姿对 (I_{t-K:t}, P_{t-K:t})，位姿 P_j = [x_j, y_j, θ_j]^T 表示相对当前自车位的平面位置与航向角；动作为相邻帧相对位姿变化 a_t = [Δx, Δy, Δθ]^T。
  • 模型结构：冻结的 DINOv3 ViT-L 编码器分别编码历史帧与未来帧；AdaLN 风格预测器配 RoPE；线性层 E_a 产生动作嵌入。
  • 关键技术：引入可学习投影器 Proj(·)，由两层 stride 2×2 卷积组成，独立作用于历史与未来帧编码嵌入，将空间尺寸降低 16 倍，并将 ViT-L 嵌入维度从 D_enc=1024 降到 D_proj=256；预测器在投影后的嵌入上运行。
  • 训练目标：对投影嵌入的 MSE 预测损失（目标端施加 stop gradient），加 SIGReg 正则项；SIGReg 独立作用于每个 patch 位置和时间步的跨 batch patch 嵌入，并在所有时间步与 patch 位置取平均，鼓励嵌入服从各向同性高斯分布以防止表示坍缩。
  • 可选 rollout 训练：在完整未来时域 F 上加入 teacher-forcing 预测损失与自回归 rollout 一致性损失，并对 t-K 到 t+F 施加 SIGReg。
  • 零样本规划：不使用 CEM，而是在聚类驾驶轨迹词表（8192 条候选）中按角坐标排序并等间隔子采样得到候选集；以 F 帧后的未来图像 I_{t+F} 为目标，对每个候选轨迹自回归 rollout 世界模型，选择预测未来潜在嵌入与目标嵌入 L2 距离最小的轨迹。
  • 下游迁移：丢弃 patch 预测器，保留 DINOv3 编码器与投影器，接简单轨迹解码器并全量微调用于 E2EAD。
  • 原文未报告：实车平台、仿真器、模型参数总量等具体资源信息。
Card 05 数据集与资源

数据集与资源

  • 数据集：NAVSIM 数据集，评估使用最新 NAVSIMv2 基准。
  • 训练划分：navtrain 划分包含 10 小时、2 Hz 驾驶视频，用于 LeWM、DINO-WM、JEPA-WM 与 AD-E2E-JEPA 的公平对比；AD-E2E-JEPA 进一步扩展到 trainval 训练部分的 70 小时驾驶视频。
  • 模型规模：DINO、JEPA-WM 和 AD-E2E-JEPA 使用 DINOv3 ViT-L 骨干；LeWM 骨干为从头训练的 ViT-L；D_enc=1024，D_proj=256。
  • 训练配置：K+1=4 帧历史（2 秒上下文），F=8 帧未来（4 秒时域）；AdamW，30 个训练 epoch，1 个 warmup epoch 加 cosine annealing；默认 SIGReg 权重 λ=0.09。
  • 训练资源：LeWM 使用 4×A100、batch size 8、训练 1 天；DINO-WM 使用 4×A100、batch size 64、训练 11 小时；JEPA-WM 使用 4×A100、batch size 64、训练 13 小时；AD-E2E-JEPA（navtrain）使用 1×A100、batch size 128、训练 20 小时，加 rollout 为 1 天 22 小时；trainval 的 AD-E2E-JEPA 使用 4×A100、batch size 512、训练 2 天 5 小时，加 rollout 为 4 天 2 小时。
  • 仿真器与实车平台：原文未报告。
  • 开源源代码：https://github.com/HaoranZhuExplorer/AD-E2E-JEPA。
Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIMv2 navtest-stage-1 基准；零样本目标条件规划在 100 个采样子测试场景与全部 12,146 个测试场景上评估。
  • 评估指标：EPDMS（含乘性安全项）、EPDMS†（不含安全项）、规划时间（s/场景，A100 GPU）、几何/测地精度（FDE、Δx、Δy、Δθ）、可靠性（Top-1/Top-5 命中率）。
  • 零样本规划（100 子采样场景）：LeWM EPDMS 48.3、EPDMS† 73.9、时间 0.7 s；DINO-WM EPDMS 68.3、EPDMS† 91.4、时间 91.8 s；JEPA-WM EPDMS 74.2、EPDMS† 90.9、时间 101.0 s；AD-E2E-JEPA（navtrain）EPDMS 76.6、EPDMS† 92.4、时间 0.8 s；AD-E2E-JEPA + rollout EPDMS 70.4、EPDMS† 92.2、FDE 3.5 m、Top-1/Top-5 34%/67%。
  • 零样本规划（全部 12,146 测试场景，256 候选）：LeWM EPDMS 39.8、EPDMS† 66.7、FDE 14.6 m、Top-1/Top-5 5.7%/11.3%；AD-E2E-JEPA（navtrain）EPDMS 63.5、EPDMS† 80.1、FDE 6.3 m；+ rollout EPDMS 64.9、EPDMS† 83.1、FDE 4.5 m、Top-1/Top-5 42.6%/71.0%。
  • Trainval 训练的世界模型（256 候选）：AD-E2E-JEPA EPDMS 63.2、EPDMS† 80.1；+ rollout EPDMS 67.3、EPDMS† 84.1、FDE 4.0 m、Top-1/Top-5 53.8%/82.7%。
  • 扩大候选轨迹数量（trainval + rollout）：512 候选 EPDMS 69.2；1024 候选 70.5；2048 候选 71.5；4096 候选 72.1；8192 候选 EPDMS 72.9、EPDMS† 86.5、FDE 2.8 m、Δx 2.5 m、Δy 0.8 m、Δθ 2.0°；随候选数增加命中率下降，8192 候选为 15.3%/33.8%。
  • 论文摘要报告：世界模型本身在平均 20 米外的目标上分别达到 4.0/2.8
