Card 02 论文概述

论文概述

  • 论文面向自动驾驶（AD）任务，研究如何将通用视觉语言模型（VLM）适配为具备 3D 空间感知能力的驾驶 VLM。

Card 03 核心贡献

核心贡献

  • 提出 Triplet Incremental Training 框架，以自动构造的（图像, 深度, QA 对）三元组驱动增量训练，将显式几何约束与离策略语言蒸馏协同对齐，向 VLM 注入 3D 空间意识。
  • 提出非侵入式三流架构：可训练的主 VLM 流、训练时使用但在部署时丢弃的辅助深度流、以及冻结的孪生 VLM 正则流，部署时不增加架构与推理开销。
  • 在四类驾驶与推理范式上开展评测，报告在 3D 感知、语言推理与非反应式轨迹规划上取得最优性能，并有效缓解灾难性遗忘。
  • 通过消融实验说明几何监督与语义正则化的互补作用：深度监督提升几何探测与规划，KL 蒸馏恢复通用基准平均分。
Card 04 方法描述

方法描述

  • 所属模块：通用 VLM 的驾驶任务适配与几何感知注入，属于训练范式/训练框架层面，而非新的推理架构。
  • 输入传感器：驾驶图像 I 与稠密度量深度 D；深度由原始稀疏 LiDAR 点云投影到图像平面作为稀疏度量提示，经 Prompt Depth Anything 单次前向传播生成；训练平台为相机（图像）输入，部署为纯视觉。
  • 场景表示：使用稠密像素级度量深度图（H×W）作为几何表示，隐式嵌入视觉骨干的多尺度特征；原文未报告 BEV 等显式场景表示。
  • 模型结构：主 VLM 基于 InternVL3.5-4B（视觉编码器 InternViT + LLM，不冻结）；孪生 VLM 以相同权重初始化并全程冻结；辅助深度流在 InternViT 视觉编码器上挂接轻量 DPT 式深度头（30M 参数），输入第 4、8、16、24 阶段的多尺度特征，进行投影、融合与上采样，输出稠密度量深度；深度支路不接在 LLM 侧。
  • 关键技术：三元组自动构造（深度生成 + 用原始基础 VLM 生成符合其自身语言分布的描述性 QA 对）；三目标联合优化，包括深度 SiLog 损失、词表级 KL 蒸馏损失（掩码掉 prompt token）、自回归交叉熵任务损失，总损失为三项线性加权；训练顺序为先用深度损失初始化深度头（VLM 冻结），再解冻主 VLM 联合优化，随后丢弃深度头与孪生 VLM，在下游任务中于冻结的适配骨干上从零训练任务头（语言任务直接使用适配后的 VLM）。
Card 05 数据集与资源

数据集与资源

  • 数据集：nuScenes（深度估计与 3D 检测探测）、OmniDrive 与 nuInstruct（驾驶语言推理）、NAVSIM（非反应式轨迹规划）、MMMU / MMStar / POPE / OCRBench / ScienceQA（通用能力保持）。
  • 仿真器：使用 NAVSIM 非反应式离线仿真基准；未使用闭环仿真器。
  • 模型规模：主模型 InternVL3.5-4B；深度头 30M 参数；对比中出现 8B 规模模型（ReCogDrive、VGGDrive、AdaThinkDrive 等）。
  • 训练资源：16 块 NVIDIA A100 GPU（每块 80 GB），训练 2 个 epoch；三元组规模 170k（由 OmniDrive 与 nuInstruct 使用的 nuScenes 训练图像构造）。
  • 训练配置：AdamW，视觉编码器基础学习率 2×10⁻⁵、余弦衰减；α=0.25（深度）、β=0.20（KL）、γ=1.0（CE）；SiLog 损失 λ=0.85，有效深度范围 [0.5, 80] m；随机种子 42。

Card 06 评估与结果

评估与结果

  • 评估基准与指标：nuScenes 深度（δ₁↑、Abs Rel↓）与 3D 检测（mAP↑）；OmniDrive（BLEU、ROUGE、CIDEr、Average）与 nuInstruct（MAE↓、Accuracy、mAP、BLEU、Average*）；NAVSIM（NC、DAC、EP、TTC、Comf.、PDMS）；通用基准 5 项及平均。
  • 感知探测（冻结骨干）：深度 δ₁ 由 77.2% 提升至 80.6%，Abs Rel 由 19.1 降至 16.7；3D 检测 mAP 由 34.7 提升至 38.1，超过 OmniDrive（35.4）与 PETR（37.8）等领域专家模型；同表对比还包括 Metric3Dv2、UniDepth、UniDepthV2、VGGT 等。
  • 驾驶语言推理：OmniDrive 上 BLEU 42.55、ROUGE 36.80、CIDEr 92.09、Average 57.15（Baseline 54.47，VGGDrive 52.85，Specialist 46.40）；nuInstruct 上 MAE 1.44、Accuracy 58.29、mAP 39.46、BLEU 84.14、Average* 45.11（Baseline 44.83，VGGDrive 42.98）。
  • 非反应式规划（NAVSIM，纯视觉）：PDMS 89.10，NC 98.70、DAC 96.80、EP 83.90、TTC 95.80、Comf. 100；Baseline 为 83.30；接近 8B 的 ReCogDrive（89.60），优于 TransFuser（83.88）、WoTE（88.30）等含 LiDAR 的模型。
  • 通用能力保持：Ours-4B 平均 73.2（MMMU 59.1、MMStar 61.7、POPE 80.9、OCRBench 77.4、ScienceQA 87.1），相对未调优 InternVL3.5-4B（平均 73.6）仅下降 0.3；ReCogDrive 平均下降 34.8（MMMU 降至 7.6）。
  • 消融：SFT+Depth 使 3D 检测 mAP 提升 3.2、PDMS 提升 4.54；仅深度监督时通用平均为 21.8，加入 KL 后恢复至 73.2（各基准增益 +52.1、+57.2、+13.8、+56.4、+77.6，平均 +51.4）；完整框架通用平均 73.2。
  • 评估条件：全部为离线真实数据集上的开环/非反应式评测（NAVSIM 为非反应式离线基准），未报告闭环仿真或实车验证；论文在结论中将缺少闭环仿真验证列为局限。
