ReactBench-AD: Do Driving VLAs and World-Action Models React to Imminent Hazards in Their Path?

Card 03 核心贡献

核心贡献

  • 提出 ReactBench-AD，基于真实 NAVSIM 与 PhysicalAI-Autonomous-Vehicles 场景，构建像素级精确配对的反事实样本，并设计能刻画模型“是否反应”以及“如何反应”的指标。
  • 评测四种 VLA（Alpamayo 1.5、Alpamayo 2、AutoVLA、ReCogDrive）和两种 WAM（DriveWAM、SimWAM），发现它们面对插入路径的物体反应微弱、多数情况下未能避免碰撞。
  • 分析 Chain-of-Thought 推理与多阶段训练配方中各训练阶段对反应行为的影响，发现部分模型在 CoT 中识别到危险但未据此行动。
  • 仅对 ReCogDrive 的动作头在编辑场景上进行短时微调，即可学会对危险急刹，并能泛化到未见物体和完全真实场景，对常规驾驶性能影响很小。

  • 模型结构：评估对象为现有 VLA 与 WAM 架构，原文未报告其内部结构的自主设计；微调实验仅训练 ReCogDrive 的动作头。
  • 关键技术：跨所有相机视角与历史帧一致地合成物体、遮挡处理与接触阴影、基于相机标定的渲染、轨迹分段线性插值后以 100 Hz 检测碰撞、以编辑前后预测轨迹的差异定义 edit effect（ΔM）以隔离插入物体的因果效应。

Card 06 评估与结果

评估与结果

  • 评估基准：ReactNAV 与 ReactPAI 两个子集；每个原始场景对应插入过街行人、站立行人、静止车辆三类反事实变体。
  • 评估指标：安全分数 P（ReactNAV 上为 NC×DAC，ReactPAI 上为 NC）、平均接触速度 CS、轨迹不变率 TIR_ε，以及 edit effect ΔP 与 ΔCS；碰撞判定沿用 NAVSIM 的 at-fault 准则并做三处更严格修改，轨迹以 100 Hz 插值检测碰撞。
  • 关键数值：多数模型在插入物体可见时安全分数几乎不提升；Alpamayo 1.5 在 ReactPAI 上、站立行人 τ=2.0s 的最佳情况下不安全轨迹仍占 62.01%；排除以 8 m/s² 制动也无法避免碰撞的样本后 ΔP 几乎不变；表中给出各模型在各物体与 look-ahead 时间下的 ΔP（百分点，越高越好）与 ΔCS（km/h，越低越好），灰色表示配对 95% bootstrap 置信区间包含零。
