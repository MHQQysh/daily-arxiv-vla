Card 03 核心贡献

核心贡献

  • 提出 DIVA：将执行器级车辆动力学模型嵌入端到端驾驶网络训练回路，形成从感知到车辆状态的可微通路；并通过同策略重辨识保持模型与所学控制器一致。
  • 提出状态空间中的动力学在环模仿学习：以车辆状态监督绕开混叠的控制输入标签，配合可辨识性感知损失与梯度门控实现控制器与规划器联合训练。
  • 提出速率一致的控制输入参数化（控制结在标签率、以零阶/一阶保持插值到控制率），协调标签、感知与控制速率，并支持异步执行。
  • 通过在线扰动观测器向学习控制器显式提供模型失配估计，提升部署阶段对车辆动力学失配的鲁棒性。
Card 04 方法描述

方法描述

  • 所属模块：端到端驾驶栈中的规划器 + 学习式控制解码器 + 可微车辆动力学模块；训练与部署均在同一可微链上。
  • 输入传感器：相机与 LiDAR 经感知骨干融合为 BEV 感知 token（原文未报告具体传感器型号与数量）；另含状态反馈 token（纵向速度 v_x、一个标签周期平均横摆角速度 r_avg）与扰动估计 token（转向偏差、纵向加速度偏差）。
  • 场景表示：BEV 特征投影并位置编码为感知 token M，加车速与导航 token；规划 transformer 输出规划 token P，GRU 解码几何路径 R 与离散速度类别概率 p^v（路径与目标速度解耦）。
  • 模型结构：三层 transformer 控制解码器，记忆由感知特征、规划器中间特征、显式参考路径/速度、状态反馈、扰动估计五组 token 拼接，输出 K+1 个控制结（tanh 限幅），单一路径纵向输入经 [·]_+ 分解为油门/刹车。
  • 关键技术：一阶保持（FOH）插值到 20 Hz 控制率并在 20 Hz 积分；执行器级车辆动力学（滑移率限制、动力总成静态映射加一阶滞后、制动减速度、单轨模型加饱和轮胎力、低速与运动学模型融合、坡道、轮锁与驻车保持等离散工况）；非光滑环节用泄漏直通估计器（ε_st=0.1）保证驻车与死区处梯度；同策略重辨识（12 个标量修正）；模型失配参数化（k_s、b_s、b_t、k_d、k_b、k_m、k_μ、d_x）并归并为两个可观测集总偏差 b̄_s、d̄_x；风险敏感分位数损失（κ=3）、因果状态反馈、恢复样本、预览距离外参考扰动等闭环迁移机制；梯度门控 λ=0.1；异步执行（感知 token 缓存 + 坐标刚体变换 + 时延嵌入）与增广 UKF 在线扰动观测器。
  • 原文未报告：具体感知骨干网络层数/参数量等网络规模细节在提供的正文范围内未报告。

Card 06 评估与结果

评估与结果

  • 评估基准：Bench2Drive-220 闭环基准，官方指标为驾驶得分（DS）、成功率（SR）、效率、舒适度及五项能力分数；另用动力学指标（平均 jerk、平均 \|a_x\|、峰值减速度、横向加速度、侧偏角、舒适超限）与执行器活动/跟踪指标（WOT 占比、油门变化、刹车切换次数、转向速率、速度误差、横向偏移）。
  • 对比方法：TF++（基线规划器 + PID）、MPC+DOB（共享辨识模型与观测器的 MPPI-MPC，1024 次 rollout）、DIVA+PID、DOB-PID、DIVA w/o observer，以及控制输入行为克隆消融。
  • 关键数值（摘要报告）：Bench2Drive 闭环驾驶得分 86.7，比广泛采用的最先进方法高 3.3 分；平均 jerk 近乎减半；刹车切换减少 64%；控制专用周期 3.8 ms；在部署端显著车辆模型失配下仍保持更优路径跟踪精度。
  • 其他条件：Hard-52 上 DIVA 与 DIVA+PID 在剩余路线上接近（92.14 vs. 91.20 DS）；评估统计采用逐路线配对差异与 95% 置信区间。
  • 实验条件：全部为闭环仿真评估（Bench2Drive），原文未报告开环指标对比数值与实车实验；提供正文的 HTML 在表 I 数据处被截断，具体分项数值与消融/失配/时延实验的详细结果原文未完整给出。
