论文概述

  • 研究问题：早期感知无法利用下游推理、导航目标与预测行为等高层内部状态，导致感知编码无法提前关注与任务相关的线索。
  • 提出 PRIME，通过引入 Situational Memory 将过去多步的感知、推理、导航目标与预测行为潜表示反馈到感知前端，使感知查询具备意图驱动能力。
Card 03 核心贡献

核心贡献

  • 提出 Situational Memory 模块：在 L 步时间窗口内聚合并保留六类潜反馈源，覆盖场景感知（SA1）、情境理解与导航意图（SA2）、未来预测（SA3）。
  • 提出两个面向不同结构反馈源的集成模块：FiLMXAttn 用于紧凑反馈源，Attention Pooling 用于高基数结构化反馈源。
  • 提出一种轻量适配器式方法来研究 VLA 模型中的跨阶段反馈，可在基本冻结骨干的情况下隔离并评估不同潜表示反馈通路，降低端到端重训练成本。
  • 对 VLA 驾驶模型中的跨阶段反馈进行系统性实证研究，比较记忆模块应主要保留感知表示还是融合更高层推理/规划信息。
  • 在 Bench2Drive 闭环基准上验证端到端反馈可提升 VLA 驾驶性能，PRIME 相比 ORION 提升 Driving Score 与 Success Rate。
Card 04 方法描述

方法描述

  • 所属模块：PRIME 扩展 ORION 的三阶段流水线，即 QT-Former 编码器 → LLM 推理 → 轨迹规划器，在感知前端加入反馈路径。
  • 输入传感器：原文在方法中描述 QT-Former 将相机特征图转换为查询表示；所有实验为 camera-only 设置。具体传感器配置原文未报告。
  • 场景表示：QT-Former 使用 Box Decoder 生成对象中心表示 B 和 Map Decoder 生成语义场景结构表示 D，并拼接为联合查询表示 Q=[B;D] 作为 LLM 的主要接口。
  • Situational Memory：保存六类反馈源，包括 SA1 的 QT-Former Latents Q、Latent Motion Predictions M；SA2 的 Latent Reasoning Token R、Planning Command P；SA3 的 Predicted Ego-State Queries S、Predicted Ego Trajectory T。
  • 记忆机制：每个反馈源被 detach 后加入源特定 rolling buffer，最多保留 L 个有效条目，场景间重置或 mask；在时刻 t，QT-Former 解码器先检索上一时刻记忆 M_{t-1}，再关注相机特征。
  • FiLMXAttn：用于 R、P、T 等紧凑源，将当前查询和记忆投影到共享空间，通过 source-specific cross-attention 检索记忆，再经 MLP 生成 FiLM 仿射参数 γ、β 调制查询，最后经 MLP 输出反馈表示。
  • Attention Pooling：用于 Q、M、S 等高基数源，使用固定数量 learned Extraction Queries 对展平并加入时间与位置编码的记忆进行 cross-attention pooling，经 FFN 与 LayerNorm 得到紧凑反馈表示。
  • 反馈集成：各源反馈表示加入 learned source embedding 后拼接，当前查询投影后通过 cross-attention 检索聚合反馈，再经 gated residual 注入：Q̂ = Q + σ(α)U_Q；门控初始化为 σ(α)=0.1。
  • 时序与训练：使用 detached rolling buffers，不跨多时间步传播梯度；反馈注入发生在 QT-Former 解码查询处理视觉证据之前。
Card 05 数据集与资源

数据集与资源

  • 数据集与基准：Bench2Drive closed-loop benchmark；训练 demonstrations 来自 Think2Drive 专家。
  • 仿真器：CARLA simulator。
  • 模型规模：ORION 基础架构约 7.3B 参数；完整六源 Situational Memory 增加最多 29.7M 可训练参数，占基础模型约 0.41%。
  • 训练资源：原文报告了训练模式与 epoch 数，但未报告 GPU 型号、数量、训练时长等具体训练资源。
  • 训练模式：Adapter 训练 8 epochs；Alignment 训练 4 epochs，训练 QT-Former 与 Feedback；E2E 训练 6 epochs，训练 QT-Former、LLM（LoRA）、Planner 与 Feedback。
  • PRIME-Full 训练配方：先 4 个 Alignment epochs，再 6 个 E2E epochs，所有 Feedback Sources 激活。

Card 06 评估与结果

评估与结果

  • 评估基准：Bench2Drive closed-loop benchmark，CARLA 仿真环境；同时报告 NuScenes Detection Score（NDS）作为 open-loop 感知质量。
  • 评估指标：Driving Score（DS）、Success Rate（SR）、NDS、mL2，以及场景级 Success Rate，包括 Merge、Overtake、E. Brake、G. Way、T. Sign。
  • 主要结果：PRIME-Full 达到 DS 82.47、SR 60.00%、NDS 73.62、mL2 0.6788。
  • 与 ORION 对比：ORION baseline 为 DS 77.74、SR 54.62%、NDS 71.72、mL2 0.6757；PRIME-Full 相比 ORION DS +4.73、SR +5.38 个百分点。
  • 训练配方消融：PRIME-Align 为 NDS 72.60、mL2 0.9595、DS 59.74、SR 33.63；PRIME-E2E 为 NDS 70.33、mL2 0.6698、DS 70.96、SR 50.00；PRIME-Full 最佳，说明 Alignment→E2E 顺序训练有效。
  • 单源 adapter 消融：PRIME-R 在冻结 ORION 骨干下将 DS 从 77.74 提升到 79.31、SR 从 54.62% 提升到 56.36%；PRIME-Q 与 PRIME-S 改善 NDS，但闭环 DS/SR 明显下降。
  • 跨阶段源多样性消融：PRIME-SA1 仅使用 Q 和 M，DS 64.18、SR 42.27%、NDS 71.96、mL2 0.6114；PRIME-Full 使用完整六源，DS 82.47、SR 60.00%、NDS 73.62，显示跨阶段反馈优于仅感知记忆。
  • 与 SOTA 对比：在论文列出的 Think2Drive-trained VLA 中，PRIME-Full 报告最高 DS 82.47；GeRo 为 DS 81.90、SR 60.10%，AutoVLA 为 DS 78.84、SR 57.73%，SpaceDrive 为 DS 78.02、SR 55.11%；PRIME-Full SR 60.00% 与 GeRo 60.10% 接近。
  • 场景级结果：PRIME-Full 在 Merge 上为 47.50%，优于 ORION 25.00% 和 GeRo 40.06%；GeRo 在 Overtake、Emergency Braking、Traffic Sign 上报告更强结果。
  • 评估条件：主要为 Bench2Drive/CARLA 闭环仿真；NDS 与 mL2 为 open-loop 指标；原文未报告实车评估。
