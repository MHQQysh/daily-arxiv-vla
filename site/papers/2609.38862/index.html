Card 02 论文概述

论文概述

  • 面向自动驾驶的轨迹规划任务，目标是根据传感器观测预测自车未来 T 步轨迹（含位置与朝向）。
  • 应用场景为端到端自动驾驶中的多模态轨迹生成与轨迹选择，强调实时性与安全性。
  • 研究问题：现有端到端方法中，模仿学习存在因果混淆与分布偏移；基于规则评分的方法需要密集锚点、计算开销大且存在目标错配；基于偏好的方法依赖严格成对标注，数据利用效率低。
Card 03 核心贡献

核心贡献

  • 提出 EMPlan，一种由奖励引导微调驱动的多模态轨迹规划方法，可实现实时推理并提升整体规划精度。
  • 设计混合架构，将稀疏锚点与偏移精修模块结合，以较低计算成本缓解离散锚点覆盖间隙。
  • 引入无配对的奖励引导微调策略，将偏好学习适配到基于锚点的轨迹评估，使策略对齐多目标驾驶准则。
  • 在非反应式 NAVSIM 基准上取得最优 PDMS 89.6，并在效率对比中达到最低延迟 21.4 ms。
Card 04 方法描述

方法描述

  • 所属模块：整体为端到端规划框架，包含 Perception 模块与 Trajectory Decoder；规划被建模为在预定义轨迹锚点词表上的离散选择问题。
  • 输入传感器：多视角 RGB 图像；实验中使用拼接的 1024×256 多视角 RGB 图像，方法仅依赖摄像头输入（表中标注为 C）。
  • 场景表示：多视角图像特征被转换为两种尺度的 BEV 表示；一种用于 BEV 语义分割辅助监督，另一种与可学习位置嵌入结合形成场景 token E_env。
  • 模型结构：稀疏锚点经 k-means 在 NAVSIM 训练集上聚类得到，并经 Fourier 位置编码形成锚点嵌入；自车状态与高层驾驶命令也被编码并与锚点嵌入融合为 planning token E_plan；Planning Transformer 以 E_plan 为 Query、E_env 为 Key/Value 进行交叉注意力，输出场景条件 planning token；随后由 offset head 预测每个锚点的偏移以精修轨迹，并由 scorer head 输出模仿分数 S_im 与规则分数 S_sim，再经奖励聚合模块形成每条轨迹的单一奖励。
  • 关键技术：两阶段训练范式；第一阶段为 score-based policy learning，使用 winner-takes-all 轨迹回归损失、模仿分数损失、BEV 分割 focal loss、规则分数 Sigmoid Focal Loss，并对 EP 分数引入条件进度 mask；第二阶段为 reward-guided fine-tuning，使用 log 空间加权聚合的奖励 R(x,y)，并采用 KTO 进行无配对偏好优化，偏好样本按奖励阈值 τ_high=-0.6 与 τ_low=-1.0 划分为 D+、D-、D_ref。

数据集与资源

  • 数据集：NAVSIM，其由 OpenScene 重新分发的 nuPlan 构建；NAVSIM 提供 2 Hz 传感器输入、语义 BEV 地图与 3D 边界框标注；navtrain 划分包含 1192 个场景用于训练与验证，navtest 划分包含 136 个场景用于测试。

Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM navtest split，非反应式仿真设置。
  • 评估指标：主要指标为 Predictive Driving Model Score（PDMS），由 NC、DAC、EP、TTC、C 五个子指标计算；PDMS = NC × DAC × (5EP + 5TTC + 2C) / 12。
  • 关键数值：EMPlan 取得 PDMS 89.6、NC 98.4、DAC 97.5、EP 84.2、TTC 94.9、C 100.0；效率对比中延迟为 21.4 ms，优于 Hydra-MDP 的 104.7 ms 与 WoTE 的 28.3 ms。
  • 对比方法：Human、PDM-closed、Transfuser、UniAD、VADv2、PARA-Drive、LAW、DRAMA、DiffusionDrive、Hydra-MDP、WoTE；其中 WoTE 为之前的状态最优方法。
  • 对比结果：Transfuser PDMS 84.0，DiffusionDrive PDMS 88.1 且 EP 最高但 NC/DAC 低于 EMPlan，Hydra-MDP PDMS 86.5，WoTE PDMS 88.3。
  • 消融结果：无 offset 且无 SFLoss 时 PDMS 81.6；加入 offset 后为 87.8；再加入 SFLoss 后为 88.3；锚点数 N 从 128 增至 512 时 PDMS 从 88.2 微升至 88.4，但延迟从 17.5 ms 增至 24.8 ms；无微调 PDMS 88.3，KTO+Score Sup. 为 89.0，KTO+Reward Sup. 为 89.6。
  • 评估条件：全部为主要在非反应式 NAVSIM 仿真环境中的评估；原文未报告开环评估、反应式闭环评估或实车评估结果。
