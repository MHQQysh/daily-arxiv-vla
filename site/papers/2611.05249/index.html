Card 02 论文概述

论文概述

  • 任务：面向自动驾驶与机器人操作的视觉-语言-动作（VLA）模型训练方法研究，聚焦 Mixture-of-Transformers 架构中 VLM 与流匹配动作专家的训练耦合方式。
  • 应用场景：开环与闭环自动驾驶（轨迹预测、路线推进、驾驶推理文本生成），以及闭环机器人操作（PolaRiS 仿真任务）。
  • 研究问题：动作专家的流匹配损失是否应回传梯度更新 VLM（coupling 耦合 vs. insulation 绝缘），以及该选择与 VLM 上的离散动作 token 监督（action-token supervision）之间的交互；探讨绝缘是否应作为 VLA 的默认训练配方。
Card 03 核心贡献

核心贡献

  • 在自动驾驶与机器人操作中独立交叉变化“动作 token 监督”与“专家到 VLM 的梯度路由”，在数据、架构、优化和语义共训练保持一致的前提下隔离两者交互。
  • 发现开环驾驶中带动作 token 监督时绝缘与耦合差异很小；无动作 token 监督时耦合将轨迹预测误差降低约 25%（Public Golden 约 26%、OOD 约 24%）。
  • 发现并发训练下耦合提升闭环驾驶路线推进：带动作 token 约 17%（0.600→0.703），无动作 token 约 40%（0.425→0.601）；机器人操作在两种监督设置下也均提升。
  • 通过 VLM-First 与 Expert-First 两种分阶段训练日程表明：训练顺序改变路由效应的大小，但不消除其对动作 token 监督的依赖；并发训练取得最高绝对动作预测性能。
  • 结论指出梯度绝缘是有条件的训练选择而非默认配方，其对生成驾驶推理文本质量没有一致优势。
Card 04 方法描述

方法描述

  • 所属模块：Mixture-of-Transformers 式 VLA，VLM 主干（Qwen3-VL-2B-Instruct）与非因果流匹配动作专家同宽配对；专家逐层关注 VLM 的 key–value 表示，VLM 不关注专家的连续动作输入。
  • 输入传感器：自动驾驶任务输入当前时刻视觉观测、语言上下文与过去轨迹历史（原文未报告具体传感器型号与配置）；机器人操作输入原文该节未报告传感器细节，仅给出数据来源。
  • 场景表示与动作表示：专家预测 K 个未来控制对（加速度与曲率），从当前自车状态出发用离散化独轮车模型积分得到位置与航向路点；离散动作 token 与连续专家编码同一未来轨迹。
  • 模型结构与关键技术：联合目标 L = L_CE + L_flow，两项权重均为 1；VLM 用交叉熵训练（含 VQA、驾驶推理 rationale、轨迹分隔符等基础 token，动作 token 由指示函数 1_action 开关），专家用 rectified flow matching 训练；时间采样 b~Beta(1.5,1.0)、t=0.999(1−b)、ε~N(0,I)。
  • 梯度路由实现：耦合时 H̃_θ = H_θ；绝缘时 H̃_θ = sg(H_θ)，前向不变、仅阻断流损失梯度进入 VLM。关闭动作 token 监督时仅对动作值 token 屏蔽 CE，它们仍被 teacher forcing，N 固定为掩码前的监督 token 数，且未来动作 token 状态被排除在专家的 K/V 上下文之外。
  • 训练日程：并发训练（两模块同时从头训练）、Expert-First（专家先对冻结 VLM 训练 100k 步）、VLM-First（VLM 先单独训练 100k 步）；总步数均为 300k（并发 300k，或 100k 单模块 + 200k 联合）；含轨迹批次约占 48.5%。评估时 VLM 只生成 rationale 并在起始 token 停止，动作 token 不参与解码。

Card 06 评估与结果

评估与结果

  • 开环驾驶：指标为第一采样候选的 ADE（主指标）与 6 候选的 minADE（oracle 选择）；95% 置信区间由 10,000 次配对 clip-cluster bootstrap 得到。并发训练无动作 token 时，耦合相对绝缘降低 ADE 约 26%（Public Golden）与 24%（OOD）；有动作 token 时绝缘在 Public Golden 略低 ADE，OOD 差异较小。分段日程下无 token 时绝缘在所有历史中均升高 ADE。
  • 驾驶推理质量：第一样本 Lingo-Judge 通过率；并发训练有 token 时绝缘 0.647 vs 耦合 0.649（Public Golden），无 token 时耦合 0.635 vs 绝缘 0.566，OOD 差异小且方向相反；分段日程下无 token 时绝缘通过率反而更高，与 ADE 模式不一致。
  • 闭环驾驶：指标为 AlpaSim 路线推进（route progress）。并发训练：绝缘/有 token 0.600、绝缘/无 token 0.425、耦合/有 token 0.703、耦合/无 token 0.601；VLM-First：0.648 / 0.555 / 0.646 / 0.587；Expert-First：0.597 / 0.538 / 0.625 / 0.604。并发耦合+有 token 为总体最高。
  • 机器人操作：PolaRiS 三个任务（BlockStackKitchen、FoodBussing、PanClean），每条件每环境 50 次 rollout，指标为归一化任务进度。π0.5 复现：绝缘/FAST 开 19.5%、耦合/FAST 开 30.7%、绝缘/FAST 关 10.3%、耦合/FAST 关 32.9%；MolmoAct2：22.0% / 24.3% / 14.5% / 36.5%；参考值：公开 π0.5 checkpoint 40.0%（CoVeR 评测协议）、公开 MolmoAct2 checkpoint 32.9%。
  • 对比条件：四种条件（绝缘/耦合 × 动作 token 开/关）在相同数据混合、初始化与优化日程下比较；未与外部 SOTA 方法做受控对比，仅给出公开 checkpoint 的参考数值。
  • 评估条件：开环与闭环驾驶均为仿真评估（AlpaSim 闭环），机器人操作为 PolaRiS 仿真闭环；无实车验证。局限包括架构多样性有限、每条件仅一次训练运行、未刻画机制层面的因果解释。
