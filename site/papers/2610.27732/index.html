Prescribed Performance Guided Safe Reinforcement Learning for Roundabout Navigation of Autonomous Vehicles

2026-10-20 · 原文 · 翻译 · 2610.27732

论文研究自动驾驶车辆（CAV）在环岛场景中的安全导航问题，环岛交通交互密集、其他车辆行为难以预测，对规划与控制的自适应性和安全性要求高。 论文针对现有 RL 与 MPC 混合框架中的“结构性不匹配”问题：RL 输出逐点决策，而 MPC 在轨迹层面进行优化，导致 MPC 难以准确实现 RL 的规划意图，轨迹平滑性不足且缺乏严格安全保证。 论文提出一种分层框架，通过 RL 轨迹生成、带预设性能约束（PPC）的 MPC 以及 CBF 安全过滤器，实现安全、平滑且舒适的环岛导航，并将 CBF 的安全修正反馈给 RL 训练。

Card 03 核心贡献

核心贡献

  • 设计轨迹生成机制，将 RL 的单步输出转换为带自适应参数的参考轨迹供 MPC 跟踪，以缓解 RL 与 MPC 之间的结构性不匹配，并加速训练收敛。
  • 在 RL-MPC 分层框架中引入 PPC 来调节基于 RL 的规划与基于 MPC 的控制之间的耦合；据作者所述，这是该框架中首次采用该做法。
  • 通过 PPC 逐步缩小规划层与控制层之间的轨迹跟踪误差，在复杂场景适应性与系统安全性之间取得平衡，并通过更平滑的轨迹提升乘坐舒适性。
  • 引入基于 CBF 的安全过滤层，对 MPC 输出的潜在不安全控制进行实时修正，并将修正结果反馈到 RL 策略学习中。
Card 04 方法描述

方法描述

  • 所属模块：分层框架包含三层——高层 RL 决策层（RLTrajGen）、低层 MPC 控制层（PPMPC）和安全中介层（CBF 安全过滤器）。
  • 输入传感器：原文提到通过车载传感器（如 LiDAR）感知周围环境，并编码为 259 维观测向量；向量包含车速、转向角、上一时刻油门/制动命令、上一时刻转向角、横摆角速度、与车道航向差、左右车道边界距离、横向车道位置、沿车道航向投影距离、横向投影距离、车道曲率半径、转向方向标志、车道角度及周围 LiDAR 特征。
  • 场景表示：在二维环岛场景中，其他车辆随机出现；对进入控制区的车辆分配索引，车辆驶出后移除该索引，以维持动态索引映射。
  • 车辆模型：采用离散时间运动学自行车模型，状态为纵向/横向位置、速度、航向，控制输入为加速度与转向角。
  • RL 部分：采用 PPO 训练策略网络与价值网络，使用 GAE 计算优势函数；动作定义为 (q_t, w_t)，其中 q_t=[ν_t*, κ_t*] 指定轨迹生成器结构，w_t=[w_t^v, w_t^θ] 调节 MPC 中预设性能跟踪的严格程度；轨迹生成器按匀速剖面与连续分段线性航向演化生成参考轨迹。
  • MPC 部分：将 PPC 离散化并引入跟踪误差距离函数，目标函数包含状态误差、控制代价与终端代价，约束包括车辆动力学与控制输入上下界。
  • 安全过滤：将车辆近似为椭圆，基于椭圆间距离构造障碍规避函数 h(x)，求解以最小化与 MPC 控制偏差为目标、满足离散时间 CBF 约束的优化问题，得到修正控制。
  • RL 损失修正：当 CBF 修正状态与 MPC 状态偏差超过阈值 δ_z 时，用鼓励策略均值对齐 CBF 修正状态的损失项替代原 PPO 裁剪损失项，使策略学习 CBF 诱导的修正行为。
  • 奖励设计：r1 包含到达目标进展、速度调节、转向变化惩罚与到达终端奖励；r2 为碰撞惩罚。其中撞车惩罚为 -5，到达奖励为 10。
