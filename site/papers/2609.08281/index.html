Card 03 核心贡献

核心贡献

  • 提出零样本目标 OOD 检测方法 SAM3-O2D2，利用文本可提示的 SAM3-image 基础模型，并与目标检测器的预测进行比较。
  • 在预测层面而非抽象特征空间进行 OOD 判断，提升可解释性并增强对检测定位误差和外观变化的鲁棒性。
  • 不使用扩散模型推断，计算成本低于现有零样本 SOTA 方法 RONIN。
  • 无需针对不同数据集或检测器重新训练，可直接与任意目标检测器搭配，实施简便。
Card 04 方法描述

方法描述

  • 所属模块：目标级零样本 OOD 检测，作为目标检测器的后处理模块。
  • 输入传感器：单目 RGB 图像（原文未报告雷达、激光雷达等额外传感器）。
  • 场景表示：2D 目标边界框及其类别标签。
  • 模型结构：采用 DeformableDETR 作为对象检测器，配合 SAM3-image 模型；离线预先用 SAM3 文本编码器计算 ID 类别文本嵌入，推理时仅传递投影类别文本嵌入作为提示，SAM3 图像编码器和检测器共同处理输入图像。
  • 关键技术：用目标检测器预测的类别作为文本提示依次推理 SAM3 检测器；计算 SAM3 检测框与检测器预测框之间的 IoU（阈值固定），在一对多匹配后判断对象是否为 ID（存在超过分数阈值的 SAM3 匹配框）或 OOD。

评估与结果

  • 评估基准：目标级 OOD 检测任务，在 ID 数据集 Pascal-VOC 与 BDD100K 及 OOD 数据集 MS-COCO 与 OpenImages 上评测。
