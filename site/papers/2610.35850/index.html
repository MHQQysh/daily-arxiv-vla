Card 02 论文概述

论文概述

  • 论文面向自动驾驶与具身控制（embodied control）两类物理智能任务，研究世界动作模型（World Action Model, WAM）的实时部署问题。

Card 03 核心贡献

核心贡献

  • 提出 OSWAM，一个支持高质量单步动作生成的世界动作模型，通过从 Video DiT 学习紧凑的 imagination tokens 作为 Action DiT 的结构化起始点，单次前向获取、单步去噪解码。
  • 提出 privileged-information distillation：教师 Video DiT 在训练时关注完整未来时域视觉 token，学生（OSWAM）AIT 在测试时仅关注首帧，从而在不引入推理期未来特征的前提下迁移长时程上下文。
  • 提出 Role-aware 3D RoPE，为视频 token、AIT、SIT 分配不同空间锚点但共享时间坐标，显式区分角色并提供角色特定的位置线索。
  • 在自动驾驶与具身控制两类任务上验证：与多步 WAM 相比取得有竞争力或更优结果，同时相对 direct-policy WAM 基线约 3× 加速，编译推理延迟低至 40 ms（NVIDIA RTX 5090）。
Card 04 方法描述

方法描述

  • 所属模块：端到端规划/控制模块（direct-policy WAM），沿用 Fast-WAM 的世界模型骨干配置与 direct-policy 设定，视频建模仅作为训练信号，推理时不 rollout 未来视频。
  • 输入传感器：NAVSIM 使用单目前视相机（384×672 分辨率）并额外提供自车状态（ego state）与驾驶命令；RoboTwin 将头部视角与两个腕部视角拼接为 384×320 图像；原文未报告激光雷达作为模型输入（数据集含 LiDAR 观测，但方法部分仅描述相机输入）。
  • 场景表示：Video DiT（Wan2.2-5B 骨干，配预训练 T5 文本编码器与视频 VAE）形成 latent 视频 token 表示；Action DiT 由 Video DiT 权重插值与下采样初始化；整体为 Mixture-of-Transformer（MoT）结构，视频块与动作块共享注意力。
  • 模型结构与关键技术：

- Action Imagination Tokens（AIT）与 Scene Imagination Tokens（SIT）：均由噪声初始化加入 Video DiT；AIT 关注首帧视觉 token、SIT 与其他 AIT，并通过 cross-attention 接收任务语言与自车状态；AIT 经辅助解码器输出动作速度，得到结构化动作先验 ā=ε−v̂^A，再以固定噪声重加噪（σ_r=τ_r/t_max）作为 Action DiT 的单步去噪初始化。

- SIT 作为场景上下文聚合的 latent 槽位，锚定于视频网格中心，通过 AIT 的辅助损失与特征蒸馏间接学习。

- Role-aware 3D RoPE：视频 token 保留原始时空坐标；AIT 分配视频网格外的空间坐标；SIT 锚定网格中心；AIT 与 SIT 共享时间坐标 t_n = n·s_a/(s_v·d_t)。

- Privileged-information distillation：冻结教师 Video DiT 在训练时接收带噪的完整未来视频 latent（首帧干净，未来帧在固定时间步 τ_v^T 加噪），在若干 Video DiT 块 J 上对齐学生 AIT 特征；推理时丢弃教师。

- 训练目标：L = L_vid + L_AIT + λ_dist·L_dist + L_act，其中 L_act 以 (a_init_τr − a_gt)/σ_r 为回归目标，使一次 Euler 更新（步长 σ_r）直接到达真实动作。

  • 未报告项：原文未报告模型总参数量、推理时是否使用多相机融合的具体实现细节。

数据集与资源

  • 数据集：NAVSIM（真实驾驶数据，2Hz，8 相机 360° 视场与 LiDAR；1192 个训练场景、136 个测试场景）；RoboTwin 2.0（双臂操作基准，50+ 任务，多任务设定，2500 条干净场景演示与 25000 条强随机化场景演示）。

Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM navtest（自动驾驶开环/伪闭环评估）与 RoboTwin 2.0 仿真（Clean、Randomized 划分，每任务 100 次试验）。
  • 评估指标：NAVSIM 使用 PDMS 及其子项 NC、DAC、EP、TTC、C（Comfort），以及推理延迟；RoboTwin 使用平均成功率与延迟；消融中还报告 ADE。
  • 关键数值：

- NAVSIM：OSWAM 单步动作去噪、不 rollout 视频，PDMS 90.3，延迟 136 ms（NVIDIA H20）；与 SimWAM（10 步动作去噪，PDMS 90.3，410 ms）持平并取得 3.01× 加速；比 Metis（PDMS 89.1，440 ms）高 1.2 PDMS、3.24× 加速；比 DriveVA（PDMS 90.5，593 ms）仅低 0.2 PDMS 但有 4.36× 加速。

- RoboTwin 2.0：OSWAM 平均成功率 90.00%（Clean 90.04%，Randomized 89.96%），延迟 142 ms；相比 Fast-WAM（91.83%，397 ms）取得 2.80× 加速、平均成功率仅降 1.83%；相比单步 Flash-WAM 变体（81.41%，609 ms）平均成功率提升 8.59%、4.29× 加速；相比 Light-WAM（76.40%，107 ms）以额外 35 ms 延迟换取显著更高成功率。

- 推理效率（NVIDIA RTX 5090，缓存语言上下文）：RoboTwin 上相对 Fast-WAM 动作 GPU 时间由 67.61 ms 降至 6.78 ms，视觉 GPU 时间增加 5.48 ms，整体延迟由 323.67 ms 降至 95.35 ms（3.39× 加速），峰值显存约 12.75 GB 基本不变；NAVSIM 上相对 SimWAM 整体延迟由 330.8 ms 降至 99.70 ms（3.32× 加速）；使用 torch.compile 与 CUDA Graph 后延迟分别为 40.81 ms（RoboTwin）与 52.64 ms（NAVSIM），支持 10 Hz 以上推理。
