Card 03 核心贡献

核心贡献

  • 提出 Diffusion-2BC：在共享视觉编码器上联合扩散去噪目标与辅助确定性回归目标，辅助分支仅用于训练，推理仍为扩散式。
  • 在 Claw 基准以及 CARLA 的路线条件导航、无路线多路口导航和 Town01→Town02 跨地图设置中比较 MSE-BC、Diffusion-BC 与 Diffusion-2BC。
  • 分析路线进展、行为多样性、计算成本与失败模式之间的权衡，并界定所评估运行与基线支持的结论范围。
  • 表明辅助回归信号可在受控基准中保留多模态预测能力，同时提升扩散行为克隆的闭环可靠性。
Card 04 方法描述

方法描述

  • 所属模块：自动驾驶策略学习中的离线模仿学习/行为克隆，不进行在线环境交互更新策略。
  • 输入传感器：CARLA 实验使用车辆为中心的 192×192 RGB 鸟瞰图（BEV），包含可行驶道路、车道边界和可选规划路线通道；每帧转灰度并与前 3 帧堆叠、归一化，形成 192×192×4 输入。Claw 环境使用 32×32 RGB 俯视图像。原文未报告真实传感器输入或实车传感器配置。
  • 场景表示：CARLA 使用 BEV；路线条件实验保留黄色规划路线通道，无路线实验省略该通道，迫使策略在局部有效道路延续中自行选择。Claw 使用包含多个形状的俯视图像，动作是二维点，成功定义为落在任一目标掩码内。
  • 模型结构：所有策略共享视觉编码器，包含两个残差卷积块，每块两个 3×3 卷积、批归一化、GELU，输出通道为 64 与 128，残差和按 1/√2 缩放，后接 2×2 最大池化；再经 8×8 平均池化和展平得到表示。CARLA 中该表示维度为 4608。扩散去噪骨干遵循 Pearce 等人的 observation-to-action Diffusion-BC：视觉表示、噪声动作和归一化扩散时间步分别嵌入为 128 维并投影为三个 64 维 token，四个 Transformer 编码块处理，每块 16 个注意力头、残差连接、批归一化和 64→256 的前馈扩展。CARLA 中 MSE-BC 使用 MLP 4608–2304–1024–64–2；Diffusion-2BC 在扩散分支外增加辅助回归头 4608→2048→512→128→32→2，隐藏层后使用 BatchNorm、ReLU 和 dropout p=0.3，辅助头训练后丢弃。
  • 关键技术：前向扩散按方差调度加高斯噪声；条件去噪网络预测噪声，训练目标为 L_DBC。总目标为 L_D2BC = α L_MSE + (1−α) L_DBC；路线条件 CARLA 使用固定 α=0.3，多路口实验按 α_e=exp(−ke) 每 epoch 更新，k=−ln(0.01)/E，从 1.0 衰减至 0.01。扩散模型使用线性 β 调度，T=20（CARLA）或 50（Claw）。推理时辅助预测与回归损失不存在，Diffusion-2BC 与 Diffusion-BC 测试时计算结构相同。原文未报告其他未列出的传感器、实车平台或模型规模细节。

Card 06 评估与结果

评估与结果

  • 评估基准：Claw 受控多模态预测基准；CARLA 路线条件导航；CARLA 无路线多路口导航；Town01→Town02 跨地图评估。
  • 评估指标：Claw 使用采样动作到最近有效掩码点的平均欧氏距离（越低越好）。路线条件 CARLA 使用行驶距离（m）和 3,000 步horizon的相对完成比例。无路线 CARLA 使用由三维仿真坐标累计的路由自由距离，报告为 UoM，而非标准米；同时观察重复 rollout 的路径多样性。Town02 报告固定预选 checkpoint 中的最高均值与 min–max 范围。
  • 关键数值：Claw 全数据集下 MSE-BC 为 4.02，Diffusion-BC 为 0.68，Diffusion-2BC 指数 α 为 0.63，固定 α=0.3 为 0.61；90% 数据集下分别为 4.25、0.70、0.69 和 0.63。相对 Diffusion-BC 约降低 10% 平均掩码距离误差，相对确定性行为克隆约降低 85%。路线条件 CARLA 最佳完成导向 checkpoint：MSE-BC 1430.05±580.55 m、完成 0.83±0.26；Diffusion-BC 1339.85±150.60 m、完成 1.00±0.00；Diffusion-2BC 1498.09±74.81 m、完成 1.00±0.00。Diffusion-2BC 在 epoch 150 首次无违规完成所有评估 rollout，Diffusion-BC 在 epoch 300 达到完整完成。无路线 Town01 中，MSE-BC 峰值均值 124.945 UoM，Diffusion-BC 峰值均值 51.873 UoM，Diffusion-2BC 峰值均值 304.697 UoM，约为 MSE-BC 的 2.44 倍、Diffusion-BC 的 5.87 倍；其峰值 checkpoint 范围为 116.741–360.201 UoM。Town02 转移候选中，MSE-BC 最高均值 70.563 UoM，Diffusion-BC 为 165.717 UoM（范围 7.489–364.232 UoM），Diffusion-2BC 为 383.963 UoM（范围 150.107–429.379 UoM）。
  • 对比方法：MSE-BC、Diffusion-BC、Diffusion-2BC。
  • 评估条件：全部为离线训练策略后的开环训练评估与闭环仿真 rollout；无实车评估。CARLA 路线条件实验中每个架构训练三次，每 50 epoch 评估，每次用十条新随机路线，违规或 3,000 步终止。无路线实验中每个架构训练两个模型至 epoch 700，每 10 epoch 评估，每个模型从同一初始位置评估五次；Town02 使用 Town01 预选的五个候选 checkpoint 直接迁移评估，不进行 Town02 新 checkpoint 搜索。
