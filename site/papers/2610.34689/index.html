Card 03 核心贡献

核心贡献

  • 提出 RSKD 语义一致性引导的驾驶 VLM 蒸馏框架，显式识别任务关键语义短语，而不是对所有答案 token 统一处理。
  • 提出短语级语义一致性机制，将教师预测与真实答案语义比较，并据此自适应路由 JSD 蒸馏与真值监督；仅在语义一致处加强教师指导，在语义不一致处加强真值监督。
  • 在 DrivingVQA、LingoQA 与 MapLMv2 上评估，在两个 QA 基准上优于所比较的学生基线，在 MapLMv2 上保持竞争力。
  • 通过消融表明任务关键语义定位、语义一致性估计与 SFT 路由各自对性能有贡献。
  • 指出方法依赖教师短语抽取与冻结 MiniLM 编码器，且仅验证单一教师–学生组合等局限。
Card 04 方法描述

方法描述

  • 所属模块：面向自动驾驶多模态问答的知识蒸馏方法，包含语义定位、语义一致性估计与一致性感知知识路由三个模块。
  • 输入传感器：多模态输入 x（图文观测与问题）与真值答案 y；原文未报告具体传感器类型、相机数量或传感器配置。
  • 场景表示：以答案 token 序列及短语级语义片段为表示；未报告 BEV、3D 检测框等显式场景表示。
  • 模型结构：教师为基于 Qwen3-VL-30B-A3B-Instruct 内部微调的 XEmbodied；学生为 Qwen3-VL-4B-Instruct，使用 LoRA（rank 8、scaling factor 32、dropout 0.05）适配所有线性语言模型层，视觉编码器与 aligner 冻结；教师在整个语义抽取与蒸馏过程中保持冻结。
  • 关键技术一：教师引导的任务关键语义定位——提示教师从真值答案中抽取描述交通参与者、状态、空间关系、道路约束或所需行为的连续子串，形成短语集合 K，并通过精确 token 子序列匹配对齐到答案 token，得到关键 token 掩码 a_t。
  • 关键技术二：语义一致性估计——在教师强制下，于对齐位置取教师 argmax 并用 Qwen3 tokenizer BBPE 解码重建教师短语，使用冻结的 all-MiniLM-L6-v2 编码器计算余弦相似度 s_i，经阈值 τ_l=0.6、τ_h=0.8 线性裁剪得到短语级一致性 g_i；对预定义互斥驾驶关系（左/右、前/后、运动/停止、加速/减速）的矛盾赋 g_i=0，并将短语分数广播到对齐 token。
  • 关键技术三：语义一致性感知知识路由——按 w_t^JSD = 1−a_t + a_t[w_min^JSD+(w_max^JSD−w_min^JSD)g_t] 与 w_t^SFT = 1−a_t + a_t[w_min^SFT+(w_max^SFT−w_min^SFT)(1−g_t)] 对 JSD 蒸馏与真值监督反向加权；两分支各自按权重和归一化，最终损失为加权 JSD 项加 α 倍加权 SFT 项。
  • 基础蒸馏形式：采用 GKD 的广义 Jensen–Shannon 散度 D_JSD^β(p_t‖q_t^θ)=βD_KL(p_t‖m_t)+(1−β)D_KL(q_t^θ‖m_t)，m_t=βp_t+(1−β)q_t^θ。
  • 超参数：α=1、β=0.5、温度为 1，JSD/SFT 权重范围分别为 [0,2]/[2,4]，均在验证集上选取，未使用测试数据。
