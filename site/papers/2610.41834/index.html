Card 02 论文概述

论文概述

  • 任务：面向自动驾驶的在线矢量化鸟瞰图（BEV）地图预测，即从多视角环绕相机图像预测矢量化、实例级的地图元素（Lane Lines、Crosswalks、Curbs）。
  • 应用场景：自动驾驶感知流水线中的静态环境建图，服务于下游轨迹预测与规划控制。
  • 研究问题：现有 BEV 地图预测模型（如 Mask2Map、MapTRv2、BeMapNet）主要仅从图像可见证据推理地图几何，显式地与目标级场景理解解耦，因而在交通参与者造成遮挡、能见度差的场景中鲁棒性不足；论文希望利用环境中目标的信息作为几何与上下文先验，提升高遮挡场景下的地图预测鲁棒性。
Card 03 核心贡献

核心贡献

  • 提出多任务架构 ObjectGuidedMap，联合预测 3D 目标与矢量化 BEV 地图，显式利用目标级场景理解作为地图元素重建的几何与上下文线索。
  • 在 Mask2Map 基础上引入目标检测分支，并在 BEV 特征层（Deformable Latent Fusion，基于可变形注意力）与实例查询层（Cross-Task-Attention，基于多头跨注意力）实现跨任务特征融合。
  • 提出随训练轮次变化的注意力因子（epoch-dependent attention factor）α 及相应的残差连接，在训练中逐步增强跨任务交互，以稳定多任务联合训练。
  • 在 nuScenes 与 Argoverse 2 上验证方法有效性，并在高遮挡场景中取得显著增益（重度遮挡场景 mAP 最高提升 21%），支持“目标感知可提升遮挡鲁棒性”的假设。
Card 04 方法描述

方法描述

  • 所属模块：自动驾驶感知中的多任务 BEV 感知（目标检测 + 矢量化地图预测），以 Mask2Map 为主干基线，目标检测分支沿用 BEVFormer 方案。
  • 输入传感器：仅使用 c 路环绕视角相机图像（nuScenes 为 6 路，Argoverse 2 为 7 路）；LiDAR 点云仅在评估阶段用于量化遮挡程度，不作为模型输入。原文未报告使用 Radar。
  • 场景表示：两个任务各自维护网格状 BEV 隐表征，地图分支尺寸 [h_map, w_map]，目标分支尺寸 [h_obj, w_obj]，实验中 h_obj=w_obj=150，h_map=200、w_map=100；地图实例表示为折线点序列加类别标签。
  • 模型结构：

- 共享骨干网络对每张图像提取特征图。

- 地图编码器使用 Lift-Splat-Shoot 将图像特征提升到 3D/BEV；目标编码器使用 Deformable Cross Attention 从 BEV 网格单元采样图像特征。

- Deformable Latent Fusion（DLF）：以地图 BEV 特征为 query、目标 BEV 特征为 input 做可变形注意力，按 F_map^BEV = (1−α)·F̃_map^BEV + α·DefAttn(...) 融合；目标分支不接收地图信息（单向融合，双向性留作未来工作）。

- Epoch-Dependent-Attention Factor：α 在训练早期为 0，使地图分支相对独立学习，随后线性增大；nuScenes 上前 13 个 epoch 为 0、至第 16 个 epoch 线性增至 0.14，Argoverse 2 上在第 7 至第 10 个 epoch 完成同样增长。

- 目标解码器：n_obj 个可学习目标 query，经 6 层迭代细化，每层先自注意力、再对目标 BEV 特征做 Deformable Cross Attention，输出置信度、类别及位置、长宽高与偏航角。

- 地图解码器：每个地图实例的每个折线点对应一个 query，共 n_map = p·n′_map 个 query；先经 Mask-Aware Query Generator、Positional Query Generator、Geometric Feature Extractor 及跨注意力生成实例查询（与 Mask2Map 相同），再经过 6 层细化，每层包含自注意力、对地图 BEV 特征的可变形跨注意力、Cross-Task-Attention 与 FFN。

- Cross-Task-Attention：以多头注意力让地图 query 关注目标 query（q=地图 query，k/v=目标 query），输出按同一 α 加权残差融合；目标 query 不关注地图 query。

  • 损失函数：地图任务沿用 Mask2Map 的全部损失（记为 L_map）；目标任务在每一细化层加入 Focal Loss 与 L1 Loss（记为 L_obj），总损失 L = L_map + λ·L_obj，λ=3.0。
Card 05 数据集与资源

数据集与资源

  • 数据集：nuScenes（1000 个 20 秒场景，2Hz 关键帧，约 28K 训练帧、6K 验证帧，6 路相机；评估用 LiDAR 点云量化遮挡）与 Argoverse 2（1000 个 15 秒场景，10Hz，700 训练 / 150 验证，其余为测试集，7 路相机）。
  • 预测范围与类别：地图实例横向 ±15m、纵向 ±30m；目标检测感知范围 ±51.2m；地图类别为 Lane Lines、Crosswalks、Curbs。
  • 输入分辨率：nuScenes 由 1600×900 填充缩放至 800×480；Argoverse 2 前相机 2048×1550、其余 6 路 1550×2048，均填充缩放至 640×640。
  • 模型规模与算力：骨干为 ResNet50；n_obj=900 个目标 query，p=20 点/实例、n′_map=50 个实例，共 n_map=1000 个地图 query；模型 77.9M 参数（Mask2Map 为 60.4M），单次推理 885.15 GFLOPs（Mask2Map 为 727.36 GFLOPs，约增加 22%）。
  • 训练资源：单张 A100 GPU、batch size 4、AdamW（weight decay 0.01）、余弦退火；nuScenes 训练 24 个 epoch、初始学习率 6·10⁻⁴，Argoverse 2 训练 12 个 epoch、初始学习率 6·10⁻⁵。Mask2Map 基线复现亦在该单卡设置下完成（原 Mask2Map 为 4 卡、每卡 batch 4）。

Card 06 评估与结果

评估与结果

  • 评估基准与指标：nuScenes 验证集与 Argoverse 2 验证集上的矢量化地图预测；基于预测与真值实例的 Chamfer Distance，在 {0.5m, 1.0m, 1.5m} 匹配阈值下计算 AP，报告 Lane Line AP、Crosswalk AP、Curb AP 与 mAP；目标检测报告 nuScenes Detection Score（NDS）。评估为数据集上的离线（开环）评估，未报告闭环或实车实验。
  • nuScenes 主要结果：ObjectGuidedMap 取得 mAP 0.661（±0.008），相对复现的 Mask2Map 基线 0.629（±0.021）提升 4.99%；Lane Line AP 0.655（+4.47%）、Crosswalk AP 0.627（+6.97%）、Curb AP 0.699（+3.74%）；NDS 为 0.309（±0.006），与 BEVFormer+Mask2Map 骨干的单任务检测模型 NDS 0.304 大致相当，说明无负迁移。原文另指出 Mask2Map 原论文发表 mAP 为 0.716，提升结论以相同设置下复现的基线为对照。
  • nuScenes 对比方法：MapTR（mAP 0.503）、MapVR（0.512）、PivotNet（0.576）、BeMapNet（0.598）、MapTRv2（0.615）、Mask2Map*（0.629）。
  • Argoverse 2 结果（跨数据集消融）：完整模型 mAP 0.5090（+7.57%）、Lane Line AP 0.5339（+5.06%）、Crosswalk AP 0.4123（+11.16%）、Curb AP 0.5808（+7.46%）；去掉 DLF 为 mAP 0.4921（+3.99%），同时去掉 Cross-Task-Attn 与 DLF 为 mAP 0.4732。
