Card 02 论文概述

论文概述

  • 论文面向自动驾驶运动预测（motion forecasting）任务，在给定智能体历史与 HD 地图的条件下预测未来多模态轨迹。
  • 研究问题：即使强预测骨干也会在多模态提案中留下残余位移与排序误差；现有修正器压缩完整提案或用因果逐段扫描，导致完整未来不能作为显式关系上下文，且后段证据无法在单次扫描中修正前段。
  • 应用场景：作为与骨干无关的后处理修正模块，支持边缘（marginal）与联合（joint）运动预测。
Card 03 核心贡献

核心贡献

  • 提出 Proposal-to-Future-Graph Lifting：将与骨干无关的接口把多模态提案转换为异构未来图，支持时间、地图、模态以及仅在联合预测中启用的社会关系推理。
  • 提出 One-Shot Bidirectional Refinement：在固定图上单次遍历，使后段未来上下文可修正前段误差，无需重复因果扫描。
  • 建立接口兼容性与时间方向分析：在两个数据集、多种骨干以及边缘和联合任务上验证一致性增益，并在验证集上按时域分辨率分析反向时间信息的贡献。
  • 在 WOMD 测试集上，FutureLift 在比较的标准输入方法中 minADE 为 0.5049 m、minFDE 为 0.9942 m，排名第一；无 LiDAR 与集成，Soft mAP 为 0.4874。
Card 04 方法描述

方法描述

  • 所属模块：后处理轨迹修正模块（post-hoc refiner），接在冻结的提案骨干之后。
  • 输入传感器/信息：仅使用提案坐标、提案 logits 与原始场景输入（智能体历史、HD 地图）；原文未报告使用相机、LiDAR 等原始传感器数据，明确不使用骨干查询、解码器特征或中间激活。
  • 场景表示：将每条提案的预测时域划分为 R 个区间，每个智能体-模态-区间形成一个未来节点，共 AKR 个节点；节点锚定在提案区间端点，并保留区间内完整提案段在局部坐标系中的表示。
  • 模型结构：

- 使用 QCNet 场景编码器从原始场景输入编码历史智能体、车道元素与细粒度地图点，并由 FutureLift 自行训练。

- 采用 L 层边增强、关系特定的多头注意力，依次处理自身历史、双向未来时间、地图与社会关系；每种具体关系有独立注意力参数、门控、归一化层与 FFN。

- 跨模态注意力在最后一层社会算子之后应用；联合预测中另有未来到场景的注意力用于汇聚场景假设。

- MLP 头解码所有区间的局部坐标修正与 Laplace 不确定性参数，并解码置信度残差。

  • 关键技术：

- 未来节点以提案端点为中心，使用相对几何（极坐标、航向差、时间差）构造边特征，使图对全局平移与旋转等变。

- 时间边双向连接同一提案所有区间，后段到前段的边在单次传递中携带后段证据。

- 社会边仅在联合预测中启用；边缘预测中禁用，避免对独立模态施加不支持的交互。

- 输出为坐标与 logit 残差：Y~ = Y^ + ΔY，ℓ~ = ℓ + Δℓ，保留骨干模态身份。

- 训练采用 winner-takes-all 轨迹回归与基于似然的模态评分，坐标使用 Laplace 负对数似然；停止 winner 选择、提案坐标与提案 logits 的梯度。

Card 06 评估与结果

评估与结果

  • 评估基准：AV2 边缘验证集与测试集、AV2 联合验证集与测试集、WOMD 官方测试集与验证集。
  • 评估指标：AV2 边缘使用 b-minFDE6、minFDE6、minADE6、MR6；AV2 联合使用 avgBrier-minFDE6、avgMinFDE6、avgMinADE6、ActorMR6；WOMD 使用 Soft mAP、mAP、minADE、minFDE、minFDE@8s、MR、OR。
  • 关键数值：

- AV2 边缘（QCNet 提案）：FutureLift 将 minFDE 从 1.304 降至 1.124，minADE 从 0.729 降至 0.593，MR 从 0.164 降至 0.131，b-minFDE 从 1.912 降至 1.772。

- AV2 边缘（DenseTNT 提案）：minFDE 从 1.624 降至 1.382，minADE 从 0.964 降至 0.718，MR 从 0.233 降至 0.161。

- AV2 边缘（DONUT 提案）：minFDE 从 1.193 降至 1.097，minADE 从 0.728 降至 0.582，MR 从 0.146 降至 0.124。

- 相对未修正提案，FutureLift 在 QCNet、DenseTNT、DONUT 上分别降低 minFDE 13.8%、14.9%、8.0%，降低 minADE 18.7%、25.5%、20.1%。

- AV2 联合（FJMP）：avgMinFDE 从 1.921 降至 1.512，ActorMR 从 0.237 降至 0.187。

- AV2 联合（Forecast-MAE）：avgMinFDE 从 1.642 降至 1.391，ActorMR 从 0.195 降至 0.169。

- AV2 联合（DONUT）：avgMinFDE 从 1.262 降至 1.142，ActorMR 从 0.162 降至 0.146；加入社会关系进一步降低 avgMinFDE 1.3%、ActorMR 1.4%。

- WOMD 官方测试：FutureLift 取得 minADE 0.5049 m、minFDE 0.9942 m、minFDE@8s 1.6815 m、Soft mAP 0.4874、mAP 0.4780、MR 0.1146、OR 0.1283。

- WOMD 验证集时域分析：双向相对因果在 3 s 时 minADE/minFDE 增加 1.2%/0.2%，在 5 s 时降低 0.5%/2.7%，在 8 s 时降低 2.2%/4.5%。

  • 对比方法：AV2 边缘比较 None、Native、SmartRefine；AV2 联合比较 None、SRefiner；WOMD 比较 MTR++、ModeSeq、NDPNet、IMPACT、DONUT 等标准输入方法，并列出协议不同的排行榜上下文。
  • 条件：全部为离线数据集评估（验证集/测试集），未见闭环仿真或实车实验；AV2 排行榜已关闭，作者报告本地测试集比较。
