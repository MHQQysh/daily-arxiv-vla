Card 02 论文概述

论文概述

  • 本文提出 DecoupleGS，一个面向端到端（E2E）自动驾驶测试的交互式 3D 高斯泼溅（3DGS）框架。
  • 应用场景为自动驾驶闭环仿真测试，用于在仿真环境中完成高保真、强交互、实时性的 E2E 算法安全验证与动态多智能体评估。

Card 03 核心贡献

核心贡献

  • 提出了一个解耦的 3DGS 框架，将场景分解为静态背景和可操控的动态智能体（车辆），实现神经重建保真度与闭环 E2E 测试所需的交互性和吞吐量兼顾。
  • 系统性解决效率、几何和光度三类冲突，开发了求解器无关的模块：车辆资产压缩、地图引导几何配准、代理式重光照。
  • 验证了模块支持多车辆即插即用插入，并保持交互式渲染速率，可作为 E2E 算法的数据引擎。
  • 实验表明 DecoupleGS 在保真度-效率之间取得均衡折衷，改善了度量一致性和光度一致性，并提供实用的闭环传感器仿真平台。
Card 04 方法描述

方法描述

  • 所属模块：传感器仿真/神经渲染框架，面向 E2E 自动驾驶闭环测试。
  • 输入传感器：原文未明确报告具体输入传感器类型，但输出为多视角图像用于 E2E 策略评估。
  • 场景表示：采用解耦的双流表示，静态背景用世界坐标系中的高斯原语表示，动态智能体用本地坐标系中的规范化高斯体积表示；通过 SE(3) 刚性变换与世界坐标统一融合。
  • 模型结构：包含三大功能模块：(1) 资产压缩模块（显式重要性评分与剪枝、属性向量量化）；(2) 地图引导几何配准模块（语义拓扑/车道线对齐、DTW 序列对齐、SE(2) Procrustes 变换、不透明度累积垂直接地）；(3) 代理式重光照模块（局部探针采样、线性 SH 传递、代理接触阴影）。
  • 关键技术：统一栅格化（保守视锥剔除、排序基数解耦、批量空间更新）；Wigner D 矩阵实现 SH 旋转保持视相关反射；显式重要性分数 s_i（可见性、颜色对比、熵加权）用于剪枝；向量量化（颜色码本 1024、形状码本 512，EMA 优化）；无需在线神经网络推理的重光照离线最小二乘标定。

Card 06 评估与结果

评估与结果

  • 评估基准：资产压缩对比 Plenoxels、Vanilla 3DGS、LightGaussian；仿真器级对比 HUGSIM、OASim、RealEngine；下游策略测试使用 UniAD 和 VAD。
  • 评估指标：渲染保真度（PSNR-Veh、PSNR-All、SSIM、LPIPS）；运行时性能（FPS、VRAM）；几何一致性（轨迹 ADE、地面穿透率 GPR）；光度真实性（Masked PSNR、Peak Intensity Error PIE、Peak Angular Error PAE）；开环规划一致性（mADE、minTTC）；闭环 E2E（Driving Score DS、Success Rate SR、Route Completion RC、minTTC）。
  • 关键数值：在 6-10+ 车辆密度下，DecoupleGS 的 PSNR-Veh 25.24、SSIM 0.772、FPS 38.5、VRAM 1.1GB；开环 mADE 0.82 为最佳，minTTC 3.3s 最佳；闭环 DS 0.884、RC 0.956、minTTC 3.3s、渲染 45 FPS 均为最佳；消融中移除压缩后 FPS 从 35.4 降至 8.5，移除配准后 ADE 从 0.05m 升至 0.48m，移除重光照后 PAE 从 6.8° 升至 48.5°。
  • 开环/闭环/仿真/实车条件：开环 sim-to-real 一致性采用 UniAD 在真实图像与仿真渲染对比；闭环评估完全交互，规划器每步预测轨迹、背景智能体通过 IDM/MOBIL 在线反应，测试场景按难度（Easy、Medium、Hard、Extreme）划分；不涉及实车实验。
