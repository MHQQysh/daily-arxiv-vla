Card 02 论文概述

论文概述

  • 任务：面向自动驾驶的安全关键感知任务——紧急车辆分类，区分救护车（Ambulance）、消防车（Fire Engine）、警车（Police Car）与道路背景（Road）四类。
  • 应用场景：智能交通系统与自动驾驶中，当紧急车辆接近时附近车辆需要及时让行；要求在多样和不利真实条件下保持鲁棒。
  • 研究问题：现有方法只依赖单一模态（音频或视频），导致该模态退化时出现系统性失败——麦克风系统在嘈杂城市环境中失效，相机系统在夜间或被遮挡时失效；论文探索用音视频多模态融合并在推理时优雅处理任一模态缺失。
Card 03 核心贡献

核心贡献

  • 提出时间对齐的跨模态融合模块（temporally aligned cross-modal fusion），在音频频谱图 token 与视频帧 token 之间做秒级 cross-attention，利用二者精确的时间对应关系，无需任何学习式对齐机制。
  • 引入可学习的 null embeddings 替代缺失模态 token，使单一统一模型可在音频-only、视频-only 或音视频联合模式下工作，无需重新训练。
  • 提出知识蒸馏训练策略，由单模态专家教师模型通过软概率目标将类间“暗知识”迁移到多模态学生融合分支。
  • 在 Google AudioSet 的 281 个测试片段上，音视频模式取得 66.6% 总体准确率，比音频-only 分支高 +10.4%，比视频-only 分支高 +15.0%。
  • 在最困难类别 Ambulance 上取得最大类别增益 +29.5%（相对任一单模态分支），表明两种模态提供互补信息且被对齐 cross-attention 成功利用。
Card 04 方法描述

方法描述

  • 所属模块：整体框架包含三个组件——AST Branch（音频编码器）、ViT Branch（视频编码器）和 Aligned Cross-Modal Fusion 模块；每个分支独立处理其模态并输出单模态分类 logits 与送入融合模块的 token 序列。
  • 输入传感器：音频（log-mel 频谱图）与视频（RGB 帧）；原文未报告实车传感器配置细节。
  • 场景表示：音频侧为形状 (1,128,430) 的 log-mel 频谱图；视频侧为 10 帧、每帧 64×64 RGB 图像，表示为 (10,3,64,64)。
  • 模型结构：所有组件基于 Transformer block（多头自注意力 MHSA、GELU 两层 MLP，隐藏维度 4D，pre-LayerNorm 与残差连接）。
  • AST 分支：将频谱图沿时间轴填充至 432 后切成 8×8 非重叠 patch，得到 Nf=16 频率 patch、Nt=54 时间 patch、共 864 个音频 token；加入可学习 [CLS] token 与 (865,D) 位置嵌入，经 6 个 Transformer block；[CLS] 经线性层输出 (B,4) 单模态 logits，864 个 patch token (B,864,D) 送入融合模块。
  • ViT 分支：每帧切成 8×8 patch，每帧 64 个 patch，patch 维度 192；共享空间 Transformer（3 个 block）把 B×10 帧当作 batch 处理，取每帧 [CLS] 得到 (B,10,D)；加入 (10,D) 时间位置嵌入后经 3 个时间 Transformer block，再平均池化得视频级表示并线性投影为 (B,4) logits；送入融合模块的是池化前的 token 序列 (B,10,D)。
  • 对齐融合：对齐是精确且确定性的——帧 t 采样自视频第 t 秒，mel 频谱图约每秒 43 个时间步（22050×1/512≈43），对应每秒 5 个时间 patch×16 个频率 patch=80 个音频 token，因此与帧 t 对应的音频 token 恰为索引 [80t:80(t+1)]。对每秒 t=0,…,9，以视频 token v_t∈R^{1×D} 为 Query、对齐音频 token a_t∈R^{80×D} 为 Key/Value，得到融合 token f_t=CrossAttn(v_t,a_t)∈R^{1×D}；10 个融合 token 堆叠成 (B,10,D) 经 4 个时间 Transformer block，平均池化后线性分类得融合 logits (B,4)。
  • 缺失模态处理：使用两个可学习 null embedding，η_a∈R^{80×D} 在音频缺失时替换全部音频 token 序列，η_v∈R^{1×D} 在视频缺失时替换全部视频 token；训练时随机施加 modality dropout，推理时用相应 null embedding 替换缺失模态。
  • 知识蒸馏：动机是避免在三种模式上端到端联合训练造成的多目标优化困难；使用软标签传递类间暗知识。温度缩放 p̃_c(T)=exp(z_c/T)/Σexp(z_c'/T)，采用 T=4。蒸馏损失为 L_KD(s,t;T)=T²·D_KL(p̃^(t)‖p̃^(s))，T² 前置因子用于抵消温度缩放 softmax 反传中自然出现的 1/T² 因子。分类损失为带标签平滑（ε=0.1）的交叉熵，平滑标签 ỹ_c=(1-ε)·1[c=y]+ε/C。
  • 全损失：按输入模态配置三种损失——音频-only 为 L_CE(ast,y)+L_CE(fusion,y)+λL_KD(fusion,t_a)；视频-only 为 L_CE(vit,y)+L_CE(fusion,y)+λL_KD(fusion,t_v)；AV（两者）为 L_CE(ast,y)+L_CE(vit,y)+L_CE(fusion,y)+λ[L_KD(fusion,t_a)+L_KD(fusion,t_v)+L_KD(fusion,t̄)]，其中集成教师 t̄=½[σ(t_a/T)+σ(t_v/T)]，蒸馏权重 λ=1.0。
  • 训练流程：Phase 1 分别独立预训练两个专家教师（深度=6 个 Transformer block，空间与时间编码器各 6 个），音频教师与视频教师各训练 30 个 epoch，每 epoch 在对应单模态模式下评估融合分支测试准确率并保存最佳 checkpoint；Phase 2 冻结教师，训练完整学生 50 个 epoch，batch 按随机模态分配（25% 音频-only、25% 视频-only、50% 音视频），每 epoch 评估 AV 模式下融合分支测试准确率并保存最佳 checkpoint。
  • 超参数：优化器 AdamW，学习率 10⁻⁴，权重衰减 0.05，LR 调度 CosineAnnealingLR，梯度裁剪 1.0，batch size 8，嵌入维度 D=128，注意力头数 4，教师训练 30 epoch，学生训练 50 epoch，温度 T=4.0，标签平滑 ε=0.1，蒸馏权重 λ=1.0。D=128 是为适配 8 GB GPU 显存；原文未报告具体 GPU 型号与训练时长。
Card 05 数据集与资源

数据集与资源

  • 数据集：Google AudioSet（大规模弱标注音频事件数据集，每样本为 10 秒 YouTube 视频片段，标注来自 632 类层级本体，无事件时间戳）。使用的四类及 AudioSet 标签 ID 为：Ambulance /m/012n7d、Fire Engine /m/012ndj、Police Car /m/01jwx6、Road（由 8 个 AudioSet 标签合并，原文未逐一列出）。
  • 数据处理：片段用 yt-dlp 下载为 MP4，按固定随机种子以 90%/10% 划分为训练集和测试集；因 YouTube 视频被删除或不可用，有效训练集约 2,528 个片段，远小于完整 AudioSet。
  • 音频预处理：采样率 22,050 Hz，FFT 窗长 1024 样本，hop 长度 512 样本，128 个 mel 滤波器组，10 秒片段产生约 430 个时间步，输出张量 (1,128,430) 并归一化到 [-1,1]。
  • 视频预处理：每片段均匀采样 10 帧，时刻为 t=0.5,1.5,…,9.5 秒（每秒 1 帧，取该秒中点）；每帧缩放到 64×64 RGB，按通道使用 ImageNet 均值和标准差归一化，输出张量 (10,3,64,64)；64×64 分辨率是为在 GPU 显存约束下控制模型规模。
  • 仿真器：原文未报告使用任何仿真器。
  • 模型规模：嵌入维度 D=128，注意力头数 4；学生 AST 分支 6 个 Transformer block、ViT 分支空间 3 个 block + 时间 3 个 block、融合模块 4 个时间 Transformer block；教师为学生对应分支的更深版本（空间与时间编码器各 6 个 block）。参数量原文未报告
