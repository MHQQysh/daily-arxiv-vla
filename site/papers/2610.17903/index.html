Card 02 论文概述

论文概述

  • 面向自动驾驶的端到端轨迹生成任务：根据相机观测、历史轨迹、导航命令与自车状态生成未来轨迹。
  • 研究问题是如何在轨迹规划中同时利用视觉语言模型（VLM）的语义理解能力与世界模型的未来场景动态预测能力。
  • 指出既有方法多以“辅助目标”或“特征条件化”方式拼接两种能力，未显式建模语义表示与动态表示之间的交互与对齐，因而难以充分释放二者的互补信息。
Card 03 核心贡献

核心贡献

  • 提出统一的 World-Language-Action 框架 DriveWLA，基于 Mixture-of-Transformers（MoT）包含三个专用专家：World Expert（未来预测）、Language Expert（语义理解）、Action Expert（轨迹生成）。
  • 提出 Cross-Expert Attention，在保持各专家独立 Transformer 块的同时，通过可控可见性掩码显式规定专家间信息流，实现交互与表示对齐。
  • 在模仿学习之外引入 Flow-GRPO 强化学习后训练，并采用因子化优势估计（factorized advantages）与基于方差的收缩（variance shrinkage）以保留多维驾驶奖励信号、提升优化稳定性。
  • 在 NAVSIM v1 上取得 92.3 PDMS，在 VLM 类与世界模型类规划器中达到 SOTA，并在更紧凑的专家配置下超过更大的 VLM/WM 集成模型。
  • 无需特定微调即可零样本迁移到 HUGSIM、nuScenes 与 Bench2Drive，展示开环与闭环泛化能力。
Card 04 方法描述

方法描述

  • 所属模块：端到端自动驾驶轨迹规划；整体为三专家 MoT 架构加两阶段训练（轨迹模仿学习 + Flow-GRPO 强化学习精调）。
  • 输入传感器：相机观测（当前与历史帧）、历史自车轨迹、导航命令、自车状态；语言侧另输入由自车运动信息、导航命令与人类指令构造的驾驶提示。
  • 场景表示：World Expert 中由时空 VAE 将观测帧编码为时空隐变量，未来帧隐变量从高斯噪声初始化并与观测隐变量沿时间维拼接；Language Expert 使用驾驶预训练 VLM 最后一层有效输入 token 的隐状态，不进行自回归文本解码；Action Expert 以噪声轨迹状态、flow 时间与驾驶条件为输入预测速度场。
  • 模型结构：World Expert 由时空 VAE、文本编码器与 N 块 Diffusion Transformer（DiT）组成，初始化自大规模驾驶视频预训练的视频生成模型；Language Expert 为冻结的驾驶预训练 VLM 加 N 块 VLM Adapter Transformer；Action Expert 为轻量 28 块 DiT，以 flow matching 策略生成轨迹。
  • 关键技术一：Cross-Expert Attention——三专家输入投影到共享维度，各自产生 Q/K/V 后拼接，经带掩码 M 的注意力计算再拆回各分支；World 与 Language 双向可见，Action 可读取二者表示，但 Action 表示不回流至 World/Language。
  • 关键技术二：训练目标——模仿学习阶段 World Expert、VLM Adapter 与 Action Expert 以 flow-matching 行为克隆目标联合优化；强化学习阶段以 SDE 噪声引入探索采样多条轨迹，按驾驶奖励做组相对优化，并以行为克隆正则约束，仅更新 Action Expert 的 LoRA 参数；推理时去除探索噪声、沿确定性 flow ODE 生成轨迹，默认 10 步 Euler 采样。
  • 关键技术三：因子化优势估计——对各驾驶指标分别做组内标准化，加权聚合并除以聚合量方差，再乘以由 PDMS 组内方差与阈值控制的收缩因子。

数据集与资源

Card 06 评估与结果

评估与结果

  • 评估基准与指标：NAVSIM v1 使用 PDMS（聚合 NC、DAC、EP、TTC、Comfort）；NAVSIM v2 使用 EPDMS（额外含 DDC、TLC、LK、HC、EC）；HUGSIM 报告 NC、DAC、TTC、Comf.、PDMS、RC 及 Easy/Medium/Hard/Extreme 与平均 HD-Score；nuScenes 与 Bench2Drive 报告 1–3 秒 L2 误差与碰撞率。
  • 开环结果（NAVSIM v1）：DriveWLA 取得 92.3 PDMS，优于 SGDrive（91.1）1.2 分、SimWAM（91.5）0.8 分，并超过 DriveWAM（90.1）2.2 分与 BrainWAM（89.5）2.8 分；其语言/视频骨干为 2B/2B，小于 DriveWAM 的 8B/5B 与 BrainWAM 的 4B/5B。
  • 开环结果（NAVSIM v2）：DriveWLA 取得最高 EPDMS 90.1，并在 DDC、TTC、LK、HC 上最佳，TLC 并列最佳；对比方法包括 DiffusionDrive（84.5）、DiffusionDriveV2（87.5）、DriveWorld-VLA（86.8）、Latent-WAM（89.3）、CoWorld-VLA（90.0）、DriveFuture（89.9）。
  • 闭环零样本结果（HUGSIM，436 个场景）：平均 HD-Score 41.47，为对比方法最佳，NC 65.80、TTC 59.27、PDMS 54.92、RC 54.99 均为最佳；DrivoR 在 Easy 场景领先（78.00），但 DriveWLA 在 Medium（47.91）、Hard（31.41）、Extreme（15.87）场景更高。
  • 开环零样本结果：nuScenes 上在零样本方法中取得最低平均 L2 0.94 m 与最低平均碰撞率 0.09%；Bench2Drive 上取得最低平均碰撞率 1.06%，平均 L2 为 1.61 m（L2 不及 DriveVA 与 UNIVERSE 的 1.33 m）。
  • 消融结果（NAVSIM v1，PDMS）：去除 World Expert 为 86.2，去除 Language Expert 为 89.1，完整模型为 90.8；原文另报告了训练策略、注意力掩码与推理采样步数的消融，但所提供的 HTML 在相关表格处被截断，具体数值原文未完整给出。
