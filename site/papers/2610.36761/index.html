论文概述

Card 03 核心贡献

核心贡献

  • 提出由 LAM（Lab Action Model）、OpenSDL、Safe-SDL 和 L3-Bench 四部分构成的可追溯框架。
  • 提出 LAM 这一测量条件化策略架构设想，将视觉-语言-动作范式扩展为同时生成连续机器人轨迹与类型化仪器 API 调用。
  • 提出 OpenSDL 执行底座及初始控制实现，用于将角色级操作映射到异构设备、协调执行并记录带时间戳的因果事件。
  • 提出 Safe-SDL 运行时门控，结合派发前的 schema 与资源检查以及执行期间（包括延长等待期）的信号时序逻辑监控。
  • 提出 L3-Bench 的 episode 级评估协议，覆盖物理结果、时序、可复现性、安全违规与故障恢复。
Card 04 方法描述

方法描述

  • 所属模块：LAM 为策略接口模块，OpenSDL 为执行基础设施模块，Safe-SDL 为运行时安全门控模块，L3-Bench 为评估协议模块。
  • 输入传感器：任务语言指令、RGB/RGB-D 视觉观测、机器人本体感知状态、带时间戳的仪器遥测测量流；观测记为 {I_t, q_t, M_t}。
  • 场景表示：将实验室过程建模为部分可观测马尔可夫决策过程（POMDP），状态为潜在物理状态，动作为连续臂动作空间与离散仪器动作空间的笛卡尔积；状态、动作与事件共享统一时间线与事件账本。
  • 模型结构：LAM 由多模态上下文骨干（目标规模约 3B 参数）、连续运动专家（目标规模约 300M 参数，使用流匹配生成轨迹块）和离散函数调用头（生成 Role–Op–Parameters 调用）组成；可选的动力学头预测下一测量状态 M_{t+1}。
  • 关键技术：类型化测量 token（保留角色、单位、采样时间与数据质量）、缺失/过期状态嵌入、schema 约束的结构化解码、动作级置信度与设备质量摘要、流匹配训练目标、交叉熵调用监督与可选测量预测损失。
  • 执行与安全：OpenSDL 使用角色描述符与 DeviceProvider 契约、六类生命周期事件（proposal、gate、dispatch、acknowledge、complete、compensate）与因果父事件、单调时钟与设备时钟记录；Safe-SDL 定义 STL 安全规范（温度、接触力、器皿间距）与鲁棒度阈值门控，超时、测量退化或鲁棒度不足触发阻断与安全降级/中止。
  • 原文未报告：POMDP 的转移模型与奖励模型在当前实现中未指定；置信度估计器的具体构造、校准误差与弃权阈值原文未报告；跨模态一致性与安全监督辅助损失的具体定义原文未报告。

评估与结果

  • 评估基准：提出 L3-Bench（Level-3 Laboratory Benchmark），包含三类场景族（自适应稀释、测量条件化滴定、带恢复的故障注入）与四种评估设置：标称、测量偏移、故障注入、设备迁移。
