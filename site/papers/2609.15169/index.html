GRAVA: Grounded Reasoning-to-Action Representation and Learning for Autonomous Driving

2026-09-14 · 原文 · 翻译 · 2609.15169

论文面向自动驾驶中的视觉-语言-动作（VLA）模型，解决现有驾驶 VLA 在动作预测前的中间推理与物理场景证据关联较弱、且与可执行行为连接不一致的问题。 论文指出两类基本限制：一是语言推理与物理场景证据之间的“ grounding gap（G1）”；二是即使存在 grounding，其也常通过独立感知/问答任务引入，导致 grounding 与后续推理、决策、动作生成之间出现“reasoning-to-action fragmentation gap（G2）”。 论文提出以 Grounded Reasoning-to-Action（GRA）表示为中心的 GRAVA 框架，在单一自回归流中整合 grounding、推理与动作生成，用于自动驾驶运动规划与决策。 应用场景为自动驾驶闭环/伪闭环驾驶行为生成，强调在复杂和长尾场景中保留动作相关物理证据并贯穿到可执行动作。

Card 03 核心贡献

核心贡献

  • 提出 Grounded Reasoning-to-Action（GRA）表示：将语言指代绑定到 2D 视觉区域和自车坐标系物理状态，并在轨迹锚定的类型图中组织对象特定交互与驾驶决策；其动作相关结构被序列化为 grounded reasoning，随后生成 Executable Planner 动作。
  • 提出与 GRA 对齐的预训练与后训练策略：包括 grounded pre-training、planner warm-up、verified self-distillation 和 Active RL Loop，用于逐步学习并优化完整 reasoning-to-action 过程。
  • 提出工具增强的多智能体 GRA 数据构建流程，结合前向场景 grounding 与后向轨迹锚定，从同一 GRA 图派生出认知型问答监督和规划型 reasoning-to-action 监督。
  • 构建 GR-NavSim 数据集：基于 nuPlan 扩展，包含 2.2M grounded question-answer pairs 和 70K GRA reasoning traces；论文称其为目前最大的开放词汇、非模板化自动驾驶问答数据集。
  • 实例化 GRAVA-8B 并在 NAVSIM 与内部长尾基准上验证：在仅使用约 60% 可用人类驾驶演示进行动作监督的情况下，GRAVA-8B 在完整 NAVSIM 基准上于纯自回归驾驶模型中达到 state-of-the-art。
Card 04 方法描述

方法描述

  • 所属模块：论文属于自动驾驶 VLA 与运动规划方法，核心模块包括 GRA 表示、Executable Planner、agentic GRA 数据构建流程，以及分阶段训练策略。
  • 输入传感器：原文中模型输入为视觉观测 \(V_{\mathrm{env}}\)、自车状态 \(s_{\mathrm{ego}}\) 和导航指令 \(c\)；原文未报告具体传感器配置、相机数量、LiDAR/Radar 等细节。
  • 场景表示：使用 trajectory-anchored typed directed acyclic graph \(G=(V,E,\nu,\eta)\)。节点集合分解为场景/路线上下文节点 \(V^{S}\)、grounded object nodes \(V^{O}\)、interaction nodes \(V^{\Psi}\)、object-level decision nodes \(V^{D}\)，以及 ego-level decision node \(v^{\delta}\) 和 terminal action anchor \(v^{a}\)。
  • 对象表示：每个动作相关对象 \(i\) 表示为 \(o_i=(m_i,b_i,\sigma_i)\)，其中 \(m_i\) 为语言指代，\(b_i\in[0,1000)^4\) 为归一化 2D bounding box，\(\sigma_i\) 为自车坐标系物理状态，包含语义类别及相对位置、距离、速度、朝向等属性。
  • 图结构约束：每个保留的 interaction 或 object-level decision 必须可追溯到至少一个 grounded object；每个 object-level decision 必须贡献到 ego-level decision；ego-level decision 必须最终到达 action anchor。
  • 序列化与生成：从 action anchor 的严格祖先集合提取动作相关子图 \(G_a=G[\mathrm{Anc}_G(v^a)]\)，序列化为 grounded reasoning \(r=\mathrm{Ser}(G_a)\)；随后由同一自回归 VLM 生成 Executable Planner 动作 \(a=(p,g,\phi)\)，完整序列为 \(y=[r;a]\)，分解为 \(\pi_{\theta}(y\mid x)=\pi_{\theta}(r\mid x)\pi_{\theta}(a\mid x,r)\)。
  • Executable Planner：动作原语集合为 STOP、CRAWL、CURVE、CRUISE；档位 \(g\in\{D,R\}\)；参数 \(\phi\in\Phi_p\)。STOP 参数为 endpoint，形状 \(\mathbb{R}^{2}\)；CRAWL 参数为 8 个点，形状 \(\mathbb{R}^{8\times 2}\)；CURVE 参数为 \(p_1,p_2,p_3\)，形状 \(\mathbb{R}^{3\times 2}\)；CRUISE 参数为 progress_end、\(v_{\mathrm{end}}\)、lat_end，形状 \(\mathbb{R}^{3}\)。
  • 轨迹解码：固定几何解码器 \(\hat{\tau}=D_p(g,\phi;s_{\mathrm{ego}})\) 将动作转换为 4 秒时域上的 8 个 waypoint 轨迹 \(\hat{\tau}\in\mathbb{R}^{8\times 2}\)；解码器无可学习参数，动作选择保留在 \(\pi_{\theta}(a\mid x,r)\) 中。
  • 训练监督：认知预训练目标为 \(\mathcal{L}_{\mathrm{QA}}=-\mathbb{E}_{(x,q,u)}[\log\pi_{\theta}(u\mid x,q)]\)；规划目标为 \(\mathcal{L}_{\mathrm{plan}}=-\mathbb{E}_{(x,r^*,a^*)}[\log\pi_{\theta}([r^*;a^*]\mid x)]\)。
  • 分阶段学习：GRA pre-training 学习场景理解、指代解析、物理状态推理、交互和决策语义；planner warm-up 学习将 grounded reasoning 延续为可执行动作；verified self-distillation 根据解码轨迹的闭环驾驶奖励选择模型生成的 reasoning-to-action 序列；Active RL 使用轨迹级驾驶奖励优化完整 \([r;a]\) 序列。
  • Active RL 场景选择：先选出 greedy 输出仍不足的场景 \(\mathcal{D}_g(\theta)=\{x:s_{\mathrm{greedy}}(x)<\tau_g\}\)，再保留采样 rollout 中满足 \(\max_i s_i\geq\tau_{\mathrm{hi}}\)、\(\min_i s_i<\tau_{\mathrm{lo}}\)、\(\mathrm{std}_i(s_i)\geq\tau_{\sigma}\) 的 recoverable scenarios。
  • Active RL 优化：使用 normalized group-relative advantage \(\hat{A}_i=(s_i-\bar{s})/(\sigma_s+\epsilon)\)，采用 DAPO-style asymmetric clipping，token-level 目标结合 \(\rho_{i,t}(\theta)\hat{A}_i\) 与 clip 项，整体为 sequence-level Active RL objective。

Card 06 评估与结果

评估与结果

  • 评估基准：完整 NAVSIM 基准；内部长尾基准（Internal Long-Tail Benchmark）。
  • 评估指标：NAVSIM 使用 PDMS；内部长尾基准使用 Key-Object Compliance 和 Closed-loop Driving Score；grounded question-answering 评估中包含 scene and interaction（LLM judge）、object perception（3D localization）、decision（label accuracy）等评分定义。
  • 关键数值：GRAVA-8B 在完整 NAVSIM 协议下达到 90.48 PDMS，相较其 pre-RL checkpoint 提升 10.2%，并在论文比较的直接自回归驾驶 VLA 中取得最佳性能。
  • 长尾结果：在内部长尾基准上，完整 GRA 相对 action-only prediction 将 key-object compliance 提升 19.3%，将 Closed-loop Driving Score 提升 20.5%。
  • 监督效率：论文报告仅使用约 60% 可用人类驾驶演示进行动作监督。
  • 对比方法：论文比较对象包括直接自回归驾驶 VLA；相关工作中提及 EMMA、DriveLM、DriveV
