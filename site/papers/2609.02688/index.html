Card 03 核心贡献

核心贡献

  • 提出 PDT 框架，将未来感知规划声明转化为可审计链条：表征、评分、选择、支撑集、部署五个层面的测试，并引入两类互补模块。
  • 提出并实施两个诊断模块：Decision-Transfer Decomposition（决策传递分解）与 Reliability-Constrained Validation（可靠性受限验证），包含条件因子分解式、退化界限等理论支撑。
  • 通过代表性联合嵌入未来感知规划器与 NAVSIM-v1 的经验案例研究，展示多个证据层间的反转现象：组件代理改善、分数矩阵变化、规模扩大与聚合分数不可区分性、以及安全组件回归。
  • 提案级回放验证开关效用分解；揭示“名义最佳配置”通过双半/双种子稳健性门控的失败，验证 PDT 作为评估框架的判别力。

Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM-v1（PDMS、PDM 分数及其分解分量）；另进行固定验证一半、前缀扩展（512/2048 记录）及全量支持（12,146 条记录）的评估。
  • 评估指标：组件 BCE（代理）、未来时间损失（代理）、提议级选中 PDM（效用）、开关计数、ρ（切换速率）、μ（条件效用）、ΔJ（配对效用差）、R_support 与 R_selection（遗憾）、PDMS 及细分组件（碰撞、可行驶区域、TTC、驾驶方向、舒适度）；部分场景利用 10,000 次配对 bootstrap 获得 95% 百分位区间。
  • 关键数值：组件 BCE 改善 0.705→0.530，选中 PDM 却由 0.963 降至 0.961；候选的 512 记录前缀提升 0.00909（场景 bootstrap 95% 区间 [0.000744, 0.0177]）但 2048 记录及完整支持区间包含零；迭代线性配置 ρ=0.0625、μ=0.00170、ΔJ=1.06e-4 [0, 3.19e-4]；名义最佳配置种子 0 的 ΔJ=2.25e-4，种子 1 无切换；四种切换效用差异为 0.00681、0、0、0。

  • 评估条件：包含开环（NAVSIM 非反应式标定）与部分闭环仿真式评估；另含固定验证一半、前缀/全量级联、提案级 CPU 回放等手段；实车部分未报告。
