Card 02 论文概述

论文概述

  • 面向自动驾驶场景中的乘客危险感知解码任务，利用乘客脑电（EEG）信号识别道路风险。
  • 包含两个互补任务：风险预测（RP，使用事件前窗口评估潜在风险）与危险识别（DI，检测事件发生附近的实际危险），并支持 Risk-aware Sequential Labeling（RSL）让 RP 知识辅助 DI。
  • 研究问题：能否以参数高效的方式建模乘客 EEG，同时保留电极的真实头皮几何结构，并捕捉时间与特征模态之间的高阶交互，从而准确解码危险感知。
  • 指出既有方法（如 3D-CRNN）将 54 个电极映射到 6×9 人工网格、并用 GRU 将时间–特征表示当作序列处理，破坏了不规则的 10–20 电极几何与高阶结构。
Card 03 核心贡献

核心贡献

  • 提出基于头皮坐标的无向电极图，保留电极间真实的不规则空间关系，而非人为规则网格。
  • 提出 GraTED 图–张量解码架构，结合 Chebyshev 图滤波与张量分类，同时保留空间拓扑以及时间与特征模态的结构。
  • 采用 Tucker 低秩参数化的分类器（以及 Tucker 参数化的图级聚合），在不展平模态的前提下建模时间、特征与类别轴之间的交互并控制参数量。
  • 在 PassengerEEG 数据集上与七种最先进基线比较，在全部三种评估设置下取得最高 balanced accuracy，且可学习参数最少。
Card 04 方法描述

方法描述

  • 所属模块：乘客 EEG 解码/脑机接口（BCI）感知模块，包含 RP 与 DI 两个分支（DI 可选 RSL 融合）。
  • 输入传感器：54 个头皮电极的 EEG，采样率 250 Hz，试次对齐到交通事件起始点；完整试次为 X∈R^{54×750}（[-2,1] s）。RP 窗口为 54×375（[-2,-0.5] s），DI 窗口为 54×300（[-0.2,1] s）。
  • 场景表示：以电极节点构建无向图，边由 10–20 montage 归一化三维头皮坐标的测地距离 d_ij=arccos(p_i^T p_j) 定义，每节点连接 k=4 近邻并对称化，边权为指数核 exp(−d_ij²/2σ²)（σ 为中位成对电极距离），邻接矩阵加自环并对称归一化。
  • 模型结构：

- 时间编码：对每个电极独立做一维卷积、批归一化、逐元素平方、平均池化与对数变换；RP 映射为 R^{19×16}，DI 映射为 R^{5×16}，堆叠得到 H_RP^{(0)}∈R^{N×19×16}、H_DI^{(0)}∈R^{N×5×16}。

- 图编码：Chebyshev 图卷积（λ_max=2，化简为 L̃=−Â），阶数 Q=3，两层图卷积，含残差与 LayerNorm；滤波器参数 16×16。

- 图级聚合：用 Tucker 参数化的系数张量 W^{(agg)}∈R^{32×N×16}（Tucker 秩 (8,24,8)）对电极与图特征模态做收缩，得到每时刻 32 维表示 z_t，经 ELU；得到 Z_RP∈R^{19×32}、Z_DI∈R^{5×32}。

- 张量分类：对 RP、DI 无 RSL、DI 有 RSL 分别使用独立分类器；DI 有 RSL 时沿时间维拼接 Z_RSL∈R^{24×32}。系数张量 W^{(cls)}∈R^{T×32×C}（C=2）用 Tucker 分解参数化，logits 为 W^{(cls)}×_{1,2}Z+b，softmax 输出类别。

  • 关键技术：Chebyshev 谱图卷积、Tucker 张量分解与低秩参数化、RSL 跨任务表示拼接。
Card 05 数据集与资源

数据集与资源

  • 数据集：PassengerEEG，预处理后的乘客 EEG 数据集，11 名参与者、15 个交通场景，原文摘要称包含 45 小时记录；试次分为 safe、low-risk、high-risk 三类。
  • 标签设置：RP 中 safe 为非风险、low-risk 与 high-risk 为风险；DI 中 safe 与 low-risk 为非危险、high-risk 为危险；DI 有/无 RSL 使用相同标签。
  • 数据划分：每位参与者 60% 训练、40% 测试，训练数据中 30% 用于验证。
  • 训练配置：AdamW 优化器，批大小 1024，每任务最多 60 个 epoch，基于验证 balanced accuracy 早停；所有模型使用相同数据划分与训练设置。

Card 06 评估与结果

评估与结果

  • 评估基准：PassengerEEG 数据集；三种评估设置——RP、DI without RSL、DI with RSL。
  • 评估指标：Precision、Recall、F1-score（正类为 RP 的风险类与 DI 的危险类）、Balanced Accuracy（BA，主指标），结果为 11 名参与者上的均值±标准差。
  • 对比方法（七种基线）：EEGNet、ShallowConvNet、DeepConvNet、XGB-DIM、CTNet、DSC-ConvLSTM、3D-CRNN。
  • 关键数值：

- RP：GraTED 参数 6,388，Precision 0.977±0.034，Recall 0.913±0.044，F1 0.943±0.028，BA 0.946±0.026；最佳基线 ShallowConvNet BA 0.943±0.033、参数 89,002。

- DI 无 RSL：GraTED 参数 5,451，Precision 0.653±0.027，Recall 0.848±0.053，F1 0.737±0.023，BA 0.827±0.026；BA 相比 ShallowConvNet 与 3D-CRNN 分别提升 2.1% 与 2.4%。

- DI 有 RSL：GraTED 参数 12,805，Precision 0.660±0.015，Recall 0.894±0.031，F1 0.759±0.010，BA 0.848±0.012；相比最强基线 3D-CRNN（BA 0.838±0.035）提升 1.2%；RSL 使 GraTED 的 BA 由 0.827 提升至 0.848，F1 由 0.737 提升至 0.759。

- 参数效率：相比 3D-CRNN，三种设置参数量分别减少 80.9%、87.3%、83.9%；DI 有 RSL 时 Tucker 分类模块比 3D-CRNN 的 3,170 参数 GRU 融合模块少 69.5%。

  • 实验条件：全部为基于 PassengerEEG 的离线开环解码评估（按参与者划分训练/测试），原文未报告闭环控制、仿真器实验或实车实验。
