Card 02 论文概述

论文概述

  • 论文面向自动驾驶场景的前馈式驾驶场景重建与新视角合成任务。
  • 应用场景为由车辆环视六相机图像进行驾驶场景三维重建，并在单帧（SF）设定下合成未来帧 t+1 的环视视图。
  • 研究问题：前馈像素对齐 3D Gaussian Splatting 只在当前帧有观测像素处生成高斯，导致前进运动使被遮挡区域（树木、杆、围栏、建筑边缘后方）在 t+1 帧去遮挡时缺乏高斯支撑，产生空洞和拉伸的“橡皮膜”伪影；论文将其重新表述为遮挡感知的高斯致密化问题，目标是补全缺失的场景几何而非缺失的像素。
Card 03 核心贡献

核心贡献

  • 提出 OccSplat，一个前馈框架，将遮挡处理重新表述为 Occlusion-Aware Gaussian Densification，针对缺失场景几何预测新的高斯基元，而不是对渲染图像做图像空间修补。
  • 设计 Gaussian Occlusion Mapping 模块，通过双背景渲染识别缺乏高斯支撑的遮挡区域。
  • 设计 Gaussian Occlusion Completion 模块，为不支持区域生成新的高斯基元，并将其融合进原始表示。
  • 在 nuScenes 基准上相比对比的前馈方法取得提升，并在遮挡区域获得尤其大的增益。
  • 保持前馈推理，无需逐场景优化。
Card 04 方法描述

方法描述

  • 所属模块：基于前馈环视骨干（沿用 DrivingForward）构建，增加两个直接作用于高斯表示的遮挡处理模块。
  • 输入传感器：当前帧 t 的 N 路环视相机图像；原文未报告其他传感器输入（仅使用 RGB）。
  • 场景表示：像素对齐的 3D 高斯集合 S0，每个高斯包含中心、不透明度 α、各向异性尺度 s、旋转四元数 q 和球谐系数 sh。
  • 基础高斯重建：编码器提取多尺度图像特征，经 Volumetric Fusion Network (VFNet) 跨视图融合得到稠密深度图；每像素深度反投影得到高斯中心，轻量高斯头由特征与深度预测其余属性，形成 S0 并做可微光栅化。
  • Gaussian Occlusion Mapping：将 S0 渲染到目标视角 π_{t+1} 两次，背景分别设为全黑 [0,0,0] 与全白 [1,1,1]；由双背景响应的阈值不等式（阈值 ε）生成遮挡掩码，无额外可学习参数。
  • Gaussian Occlusion Completion：先用轻量编码器-解码器 U-Net（Pixel Refiner）对渲染的未来视角图像做残差修正；再以精修图像为查询、源帧深度与多尺度特征为键值，使用线性注意力的 Depth Attention 与 Feature Attention 两个分支分别推断未来视角深度与特征；由推断深度反投影初始化新高斯中心，并复用预训练高斯头预测新基元属性；掩码筛选后与 S0 合并为 S1 并渲染未来帧。
  • 训练目标：两阶段训练。Stage I 优化深度网络、位姿网络、高斯头与 Pixel Refiner（其余冻结），损失包含重投影、平滑、时空、gs 与精修损失（MSE 加 LPIPS）。Stage II 冻结 Stage I 模块，仅训练 Depth Attention 与 Feature Attention，额外加入新视角深度监督（以 Depth Anything V2 伪深度为目标）和新视角特征监督。
  • 原文未报告：可行驶区域的语义/地图输入、激光雷达监督、动态目标显式建模方式等细节。

Card 06 评估与结果

评估与结果

  • 评估基准：nuScenes 验证集，在 t 帧观测下于 t+1 帧评估新视角合成质量，分辨率 114×228；评估指标为 PSNR（↑）、SSIM（↑）、LPIPS（↓）。
  • 对比方法：SelfOcc、UniPad、EmerNeRF、DistillNeRF、MVSplat、DrivingForward。
  • 主结果（nuScenes 验证集，开环新视角合成）：OccSplat 取得最佳整体性能，PSNR 23.50 dB、SSIM 0.767、LPIPS 0.182；相比 DrivingForward（21.76 dB、0.767、0.194）PSNR 提升 1.74 dB，LPIPS 从 0.194 降至 0.182。MVSplat 为 20.23 dB / 0.479 / 0.366；DistillNeRF 为 20.78 dB / 0.590；EmerNeRF 为 20.95 dB / 0.585；SelfOcc 为 18.22 dB / 0.464；UniPad 为 16.45 dB / 0.375。
  • 消融结果：仅加 Gaussian Occlusion Completion（全图致密化）使 PSNR 降至 19.92 dB、SSIM 0.747、LPIPS 0.182；再加 Pixel Refiner 得 20.71 dB / 0.753 / 0.175；仅加 Completion 与 Occlusion Mapping 得 22.27 dB / 0.765 / 0.187；三者全用得 23.50 dB / 0.767 / 0.182。
  • 遮挡阈值影响：ε=0.99 为 22.91 dB / 0.764 / 0.187；ε=0.8 为 23.41 dB / 0.767 / 0.183；ε=0.7 为 23.50 dB / 0.767 / 0.182；ε=0.6 为 23.30 dB / 0.757 / 0.192；ε=0.5 为 22.55 dB / 0.741 / 0.204。
  • 去遮挡区域评估（统一遮挡掩码）：DrivingForward 为 11.498 dB / 0.759 / 1.178；MVSplat 为 18.606 dB / 0.509 / 0.620；OccSplat 为 18.602 dB / 0.763 / 0.465，SSIM 与 LPIPS 最优。
  • 效率：OccSplat 约 1.01 FPS、992.9 ms，对比 DrivingForward 1.74 FPS、574.7 ms；3DGS 每场景约 9 分钟优化。
  • 条件说明：所有结果均为 nuScenes 数据集上的开环离线评估与仿真式新视角合成评估；原文未报告闭环评测与实车实验。定性结果（图 3、图 4）显示 OccSplat 在去遮挡区域补全内容并保持已有结构，新增基元分布在场景上边界、道路前景等覆盖不完整区域。
