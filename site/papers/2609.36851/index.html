Card 03 核心贡献

核心贡献

  • 首次在 e2e 驾驶中显式评估长时域世界模型 rollout 的 action-vision faithfulness，用于量化因果误差并识别可靠 rollout。
  • 提出带几何感知轨迹监督的 action-vision faithfulness evaluator（AVFE），缓解逆动力学估计中的累积相对运动误差。
  • 提出 Dense Safety-Aware Scoring 与 Scene-level Closed-Loop GRPO 策略，在可靠 rollout 上提供稳定、细粒度的强化信号。
  • 视频扩散世界模型仅在后训练阶段使用，不增加部署时的额外推理成本。
  • 在公开 nuScenes 和包含 130K 训练场景、1K 测试场景的大规模内部数据集上验证方法，展示安全性与驾驶质量的一致提升。
Card 04 方法描述

方法描述

  • 所属模块：两阶段框架，包括 Model Pre-Training 与 Reinforcement Learning Post-Training；整体为 plug-and-play 闭环 RL 框架 RoXDrive。
  • 输入传感器：多视角视觉观测（multi-view visual observation）；AVFE 使用时间前视图图像序列；nuScenes 使用六相机视图。
  • 场景表示：状态表示为多视角视觉观测与驾驶上下文的组合；动作表示为相对 ego-motion，参数化为 3D 平移与 6D 旋转。
  • 模型结构：采用 action-conditioned 多相机视频扩散世界模型 X-World 作为交互环境；AVFE 基于 Cosmos3-Nano，使用 Rectified Flow 目标进行逆动力学估计；策略输出 K 个轨迹候选及 logits。
  • 关键技术：geometry-aware auxiliary trajectory supervision、Dense Safety-Aware Scoring、Scene-Level Closed-Loop GRPO、Hard-Scene Revision、动作熵正则与 KL 正则；世界模型采用 chunk-wise causal generator 进行流式推理。
  • 原文未报告：策略网络的具体骨干结构细节在给定原文中未完整报告。

Card 06 评估与结果

评估与结果

  • 评估基准：nuScenes 验证集与内部数据集；闭环评估基于 X-World 的 4 秒片段（4,675 个 4s clips，2 个 action steps）。
  • 评估指标：Object Collision、Lane Violation、Progress、Comfort、Clearance（内部数据集替换为 Centering）、Driving Score；逆动力学评估使用 3s ADE、6s ADE、6s FDE；action-following 评估使用 SE(2) ADE、SE(2) FDE、Rotation Mean、Rotation Final。
  • 关键数值：AVFE 在 nuScenes 逆动力学评估中达到 3s ADE 0.52、6s ADE 0.95、6s FDE 2.00，优于 Cosmos3-Nano Fine-Tuning（0.67/1.27/2.67）；Strict SE(2) 下为 0.51/0.93/1.92。摘要报告在 nuScenes 上使用 DiffusionDrive 减少安全违规 27.6%，在内部数据上使用 Qwen3-VL 减少 33.7%。
  • 对比方法：开环与闭环对比包括 TransFuser、ST-P3、UniAD、OccNet、VAD、SparseDrive、DiffusionDrive，以及 VLA 方法 Gemma-3、Qwen2.5-VL、Qwen3-VL；闭环 RL 后训练方法包括 CLEAR、Drive-r1；世界模型 action-following 对比包括 Cosmos3-Nano、Vista、Epona、X-World。
  • 评估条件：包括开环碰撞评估（2s）与基于 X-World 的闭环评估（4s，4,675 个 4s clips，2 个 action steps）；逆动力学与 action-following 评估在 nuScenes 生成视频上进行；未报告实车评估结果。
