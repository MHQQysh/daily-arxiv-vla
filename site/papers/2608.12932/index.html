Card 02 论文概述

论文概述

  • 解决自动驾驶中端到端驾驶的推理速度问题，聚焦于视觉-语言-动作（VLA）模型。
  • 针对多视角、多帧视频输入的全栈 VLA 推理流水线中的四个结构性瓶颈（视觉编码、语言预填充、自回归推理、流匹配轨迹生成）进行联合优化。
  • 研究问题：如何在不显著损失轨迹预测精度与驾驶安全性的前提下，将 10B 参数级别的推理型 VLA 模型从不可用的 1.4 Hz 控制频率提升到接近实时部署的水平。
Card 03 核心贡献

核心贡献

  • 提出 FlashDrive，一种算法-系统协同设计框架，将 VLA 推理分解为编码、预填充、解码与动作四个阶段，并分别针对性加速。
  • 提出流式推理（Streaming Inference）：仅编码最新帧并复用跨帧 KV 缓存，结合流式注意力掩码与预-RoPE 键存储，将有效序列长度缩短 75%。
  • 引入推测式推理（Speculative Reasoning）：采用 DFlash 扩散模型作为非自回归并行草稿器，平均接受长度达 5.6 个 token，解码提速约 2.9 倍（相对系统优化基线）。
  • 提出自适应步进流匹配（Adaptive-Step Flow Matching）：根据速度场 U 形非均匀结构缓存中间步骤速度，将动作模块延迟从 113.9 ms 降至 47.6 ms。
  • 结合 W4A8 量化、CUDA Graph 与内核融合等系统级优化，在单 GPU 上将端到端延迟从 717 ms 降至 151 ms（4.7 倍加速），且开环和闭环精度基本无损或有所提升。
Card 04 方法描述

方法描述

  • 所属模块：端到端自动驾驶 VLA 模型推理加速框架，覆盖编码器、语言模型、动作头与系统运行时。
  • 输入传感器：多视角、多帧相机图像（典型配置为 4 帧 × 4 视角的滑窗输入）。
  • 场景表示：原文未报告显式场景表示；方法直接处理视觉 token 序列与语言/推理 token。
  • 模型结构：基于 Alpamayo 1.5-10B 的 VLA 架构，包含视觉编码器、VLM 主干、链式因果推理 token 生成以及流匹配动作头；推测式草稿模型为两层的非自回归扩散语言模型。
  • 关键技术：

- 流式推理：跨帧 KV 缓存复用、流式注意力掩码、预-RoPE 键存储与即时旋转嵌入。

- 流式微调：冻结 VLM 主干，仅微调动作专家，采用基于真实帧的 rollout teacher-forcing 方案。

- 推测式推理：以 DFlash 为草稿器，仅融合目标模型最后 8 个 token 的隐藏状态，减少验证开销。

- 自适应步进缓存：在 8 步去噪中缓存 4 个中间步骤的速度，集中计算于端点步骤。

- W4A8 量化：VLM 主干 4-bit 权重（ParoQuant）+ 8-bit 激活（Marlin W4A8 内核），动作专家保留 BF16。

- 系统优化：各流水线阶段编译为 CUDA Graph，融合 Q/K/V 与门控/上投影内核并启用 max-autotune。

Card 06 评估与结果

评估与结果

  • 评估基准：NVIDIA Autonomous Vehicle Dataset（开环）；AlpaSim（闭环）。
  • 开环指标：minADE₁@6.4s、minADE₆@6.4s（基于 6 个轨迹样本的 6.4s 预测）。
  • 开环结果（RTX PRO 6000，单轨迹）：基线 minADE₁ 1.705 m、minADE₆ 0.767 m；FlashDrive minADE₁ 1.573 m（提升 0.13 m）、minADE₆ 0.844 m（退化约 0.08 m）。
  • 效率端到端：717 ms → 151.4 ms（4.7 倍），控制频率从 1.4 Hz 提升至 6.6 Hz。
  • 分阶段延迟（最终）：编码 12.0 ms、预填充 47.2 ms、解码 45.3 ms（326.9 tokens/s）、动作 46.9 ms。
  • 消融对比：系统优化单独 1.40 倍；流式推理编码 3.4 倍、预填充 3.2 倍；推测式推理解码 2.9 倍（相对系统优化基线）；自适应流匹配动作 2.4 倍；量化进一步减少 24.6 ms。
  • 跨设备部署：Jetson Thor 4.0 倍（943.6 ms）、RTX 3090 4.9 倍（382.3 ms）、RTX 4090 6.0 倍（217.2 ms）、RTX 5090 4.8 倍（183.7 ms）、RTX PRO 6000 4.7 倍（151.4 ms）。
  • 6 轨迹样本：Jetson Thor 9.6 倍、RTX 5090 10.0 倍、RTX PRO 6000 10.6 倍；RTX 3090 与 RTX 4090 上基线因 24 GB 显存不足 OOM，FlashDrive 分别运行于 694.8 ms 与 404.1 ms。
  • 闭环结果（AlpaSim，100 随机片段，单轨迹）：碰撞率 0.19 → 0.15、偏离道路率 0.41 → 0.32、计划偏差 0.24 → 0.16 均改善；D_traj 20.0 → 22.4 m 微降、D_loc 35.2 → 32.8 m 提升、P_rel 保持 0.85；错误车道率 0.45 → 0.51 略升。
  • 闭环滚动步延迟：从 1150 ms 降至 463 ms（2.5 倍加速）。
  • 额外验证：在 Alpamayo 1（R1）上取得 4.5 倍加速，minADE₁ 提升 0.21 m，minADE₆ 代价 0.11 m。
  • 评估条件：开环（离线轨迹误差）、闭环（AlpaSim 仿真）、跨设备（单 GPU 部署）；无实车实验。
