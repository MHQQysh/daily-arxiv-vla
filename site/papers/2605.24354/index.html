Card 03 核心贡献

核心贡献

  • 提出 SparseWorld，一种轻量级、视觉中心且基于稀疏场景表示的世界模型，仅对未来目标实例（agents 与地图元素）进行预测，并能为端到端驾驶系统提供未来场景信息，减少计算开销与冗余。
  • 引入 Sparse Dreamer（SPD）模块，通过自动回归的方式结合历史实例与动作条件，在潜在空间中预测未来场景。
  • 提出运动规划优化机制：将世界模型预测的实例信息反向输入运动预测器与轨迹规划器（“Motion Planning Refinement”），提高运动预测与规划轨迹的准确性与安全性。
  • 提出 Safety-Critical Loss 与 Adaptive Trajectory Selection（ATS）推理模块，过滤并筛选安全候选轨迹。
  • 在 nuScenes 与 Bench2Drive 基准的仿真/评测中，相比基线方法在运动预测、开环/闭环规划上均有提升。
Card 04 方法描述

方法描述

  • 所属模块：端到端自动驾驶中的世界模型、未来场景预测与轨迹规划。
  • 输入传感器：原文节选未明确报告，推测涉及视觉输入；原文未报告详细传感器配置。
  • 场景表示：稀疏实例集由 agent 边界框与地图元素组成，每个实例包含几何信息（中心点、长宽高、偏航角、速度等）与语义特征。
  • 模型结构：采用 Sparse Dreamer（SPD）中的 SparseWorld Decoder，为 N 层 transformer 解码器，内部含自注意力、时间交叉注意力、动作条件交叉注意力、FFN、分类与细化模块，并采用自动回归生成下一帧实例；同时包含 Instance Memory Queue（IMQ）存储历史与预测未来实例。
  • 关键技术：通过 Global Instance Alignment（GIA）进行坐标投影与运动补偿（旋转、位移）；注入时间位置与相对位置嵌入；引入 Fourier 编码的动作条件嵌入（参考 Drive-OccWorld）；通过 Safety-Critical Loss 进行损失计算与 Adaptive Trajectory Selection 推理轨迹选择。该模块也可作为插件集成到现有实例级端到端系统（本文验证了集成 SparseDrive-S 与 VAD-Tiny 的结果）。

Card 06 评估与结果

评估与结果

  • 评估基准：nuScenes（validation）；Bench2Drive 闭环/开环评估。
  • 评估指标：开环 L2（1s/2s/3s）、碰撞率（Col. Rate）；闭环 Driving Score（DS）、Success Rate（SR）、Comfortness（Comf）、Efficiency（Effi）；运动预测 EPA（End-to-End Prediction Accuracy）、MR（Miss Rate）、mADE、mFDE；检测 NDS，mAP。
  • 关键数值：

- 基于 SparseDrive-S 集成：开环平均碰撞率达 0.05%（0.08% -> 0.05%，降 37.5%），对应 SOTA；平均 L2 为 0.65m。

- 基于 VAD-Tiny 集成：L2 从 0.78m 降至 0.59m，碰撞率从 0.38% 降至 0.24%。

- 闭环 Bench2Drive：SparseWorld-S 取得 DS 48.95（相对 SparseDrive-S 提升 9.9%），SR 提高 9.1%。

- 运动预测：SparseWorld-S 取得 EPA 0.488，MR 0.128；SparseWorld-V 为 EPA 0.619，MR 0.113。

- 未来场景预测（nuScenes）：在 2s 时可达 3D 检测 baseline 性能的 82.8%（NDS 0.433 vs baseline NDS 0.523），画 mAP 的 86.4%（48.96 vs 56.66），优于 Copy&Paste 与 Projection 基准。

  • 对比方法：SparseDrive、VAD（上述两个基线）、UniAD、AD-MLP、Law、MomAD 等；主要进行开环（nuScenes）与闭环（Bench2Drive）对比。
  • 开环/闭环条件：基于 nuScenes 的 VAD 评测协议进行开环评测；利用 Bench2Drive 的闭环评测（CARLA Leaderboard v2.0 协议）；均为仿真环境评测，无本文报告指明实车测试。
