Card 02 论文概述

论文概述

  • 论文面向自动驾驶的视觉-语言-动作（VLA）规划任务，输入相机图像与语言驾驶指令，输出未来自车轨迹。
  • 应用场景为基于多模态大语言模型（MLLM）自回归解码的端到端自动驾驶规划，覆盖闭环仿真与开环真实驾驶基准。
  • 研究问题：驾驶指令通常描述“让行、保持、转向”等动作而非自车状态，而现有 VLA 规划器常将指令直接映射到最终连续轨迹，存在指令—连续轨迹之间的“表述鸿沟”。
  • 论文提出将离散轨迹作为“轨迹几何条件”（TrajCond）插入推理与最终连续轨迹预测之间，以兼顾离散动作 token 的指令对齐性与连续轨迹的输出精度。
Card 03 核心贡献

核心贡献

  • 提出 TrajCond：先预测离散轨迹，再以其几何-语义作为条件辅助最终连续轨迹预测，最终输出仍保持在连续轨迹空间。
  • 提出基于差分自车运动的 1D-Brohan 离散化动作 token：对 x、y、yaw 差分分别建立独立 Brohan 码本，相比 K-Means/K-Disks 共享码本取得最强 TrajCond 结果与最低重建误差。
  • 提出两阶段对齐训练框架：Stage 1 用动作 token 序列对齐视觉-语言输入以预热 TrajCond 语义；Stage 2 利用解码的 TrajCond 与推理上下文回归最终连续轨迹，将条件学习与最终轨迹预测分离。
  • 在 NAVSIM navtest、nuScenes、NeuroNCAP 上验证离散轨迹作为直接输出较弱、但作为 TrajCond 可一致提升最终连续轨迹预测的效果。
Card 04 方法描述

方法描述

  • 所属模块：自回归 VLA 规划器，基于 MLLM 的下一 token 解码接口，包含推理、TrajCond 动作 token 生成与最终连续轨迹生成。
  • 输入传感器：NAVSIM 与 nuScenes 使用单张前视图像；NeuroNCAP 使用左-前-右三视角图像（原文未报告其他传感器模态）。
  • 场景表示：自车坐标系下的未来轨迹 τ={(x_t, y_t, θ_t)}，连续轨迹以逐步归一化文本 waypoint token 表示（沿用 Curious-VLA 的逐步归一化）；TrajCond 为基于 t-1 时刻局部坐标系计算的差分运动 (Δx, Δy, Δθ)。
  • 模型结构：Qwen3-VL-4B（NAVSIM 及表示消融默认）；nuScenes/NeuroNCAP 报告 Qwen2.5-VL 与 Qwen3-VL 变体。
  • 关键技术一（动作 tokenizer）：按维度对训练集 1st–99th 分位区间均匀分箱，三个码本共 Q=ΣQ_i，默认 Q=768（每自由度 Q_i=256）。
  • 关键技术二（轨迹离散化）：从上一 token 化位姿渲染候选，按有序框角点平均距离 d_corner 选择最优 token 元组；每自由度先取绝对残差最小的 4 个 token，枚举 4×4×4 候选后选角点误差最小者。
  • 关键技术三（两阶段训练）：Stage 1 用 SFT 与自回归 token 损失学习 a=f^(1)(o,ℓ)；Stage 2 从 Stage 1 初始化，按 a→w 顺序用动作 token 损失与 waypoint token 损失联合优化，训练时对动作 token 采用 teacher forcing，推理时完全自回归。
  • 关键技术四（推理与 RFT）：NAVSIM 使用 Qwen3-VL-235B 标注的 CoT 推理监督；Stage 1 输出顺序 r→a，Stage 2 为 a→r→w，并增加第三阶段用 GRPO 进行强化微调（RFT）；nuScenes 与 NeuroNCAP 仅用 Stage-1/2 SFT、无 CoT。
  • 原文未报告：具体视觉编码器结构细节、轨迹预测时域 T 的数值、推理延迟等部署细节。
