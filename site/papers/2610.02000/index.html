Card 03 核心贡献

核心贡献

  • 提出 Weather-Aware ADDA（WA-ADDA）：在 ADDA 基础上引入天气条件化判别器，将特征与预测类别概率共同输入判别器，促使特征既域不变又对天气语义敏感。
  • 构建多数据集基准与标准化评估协议：将多个公开非街景天气数据集统一为源域，以真实街景图像为目标域，并使用 macro accuracy 作为主要评估指标以应对类别不平衡。
  • 进行较全面的 backbone 评估：在 ResNet-50、EfficientNet-B0、VGG16-BN、DenseNet-121 上比较有无域适应的方法，显示 WA-ADDA 在目标域性能上持续提升，并在雾、雨、沙尘等困难天气下获得较强逐类召回，同时保持晴天场景准确率。
  • 提供定性分析：通过 t-SNE 可视化源域与目标域特征分布，说明 WA-ADDA 相比 Source-Only 和 ADDA 产生更连贯、语义更合理的对齐。
Card 04 方法描述

方法描述

  • 所属模块：论文属于视觉感知中的天气识别模块，面向自动驾驶车载摄像头图像；不是检测、分割或控制模块。
  • 输入传感器：输入为 street-view 图像；论文未报告除摄像头图像外的其他传感器输入。
  • 场景表示：以图像级多类天气分类为任务，源域为带天气标签的非街景数据，目标域为无标签街景数据；训练中源域和目标域样本按天气类别重新加权以平衡损失贡献。
  • 模型结构：方法基于 Adversarial Discriminative Domain Adaptation（ADDA），包含源编码器 Ms、目标编码器 Mt 和 K 类分类器 C；WA-ADDA 将判别器变为天气感知判别器 Dφ，输入为特征 z 与类别概率 p=C(z) 的拼接向量 [z \|\|p]，输出样本来自源域的概率。
  • 关键技术：第一阶段在源域带标签数据上用交叉熵预训练 (Ms, C)，随后冻结 Ms 并以 Mt ← Ms 初始化目标编码器；第二阶段交替优化判别器 Dφ 和目标编码器 Mt，判别器损失使用源域与目标域的二元对抗对数似然，Mt 通过对抗损失、熵最小化和可选的不良天气风格一致性正则联合优化；推理时仅保留 (Mt, C)，预测为 ŷ = arg max_k C(Mt(x))_k。
  • 目标函数：源域分类损失 L_cls^s 为交叉熵；判别器损失 L_D 包含源域正确判别项和目标域正确判别项；目标侧包括对抗对齐项 L_adv^t、熵最小化项 L_ent^t、以及可选的一致性项 L_cons^t；总体目标为 L_Mt = L_adv^t + λ_ent L_ent^t + λ_cons L_cons^t。
  • 关键技术细节：一致性正则使用轻度、可微的不良天气扰动 A，例如轻雾/雨模糊、对比度降低；判别器条件化目标是促进“天气模式内”的域对齐，而不需要目标标签。
  • 原文未报告：未报告具体网络层数、特征维度 F、判别器层结构细节、是否使用 LiDAR/雷达/IMU 等额外传感器，也未报告实车部署结构。

Card 06 评估与结果

评估与结果

  • 评估基准：多源非街景天气数据集到 Street-View 目标域的天气分类基准；目标标签仅用于评估，符合无监督域适应设置。
  • 评估指标：macro accuracy、overall accuracy、per-class accuracy；macro accuracy 为主要指标，所有结果取三个随机种子的平均值。
  • 对比方法：Source-Only、ADDA、WA-ADDA（Ours）；所有方法共享相同的数据预处理、网络初始化和优化设置。
  • 源域结果：Source-Only 在源域上表现较高，例如 ResNet-50 macro 94.4、overall 95.5；DenseNet-121 macro 94.5、overall 95.7；EfficientNet-B0 macro 95.1、overall 96.3；VGG16-BN macro 93.7、overall 95.4，用于确认源模型训练充分。
  • 目标域结果：Source-Only 明显下降，例如 ResNet-50 macro 68.4、overall 68.5；DenseNet-121 macro 74.3、overall 74.2；EfficientNet-B0 macro 62.4、overall 62.1；VGG16-BN macro 58.3、overall 58.1。
  • ADDA 结果：ADDA 相比 Source-Only 有提升，例如 ResNet-50 macro 73.0、overall 73.1；DenseNet-121 macro 83.8、overall 83.9；EfficientNet-B0 macro 71.4、overall 71.5；VGG16-BN macro 81.5、overall 81.7。
  • WA-ADDA 结果：WA-ADDA 取得更强或更均衡表现，例如 ResNet-50 macro 85.2、overall 85.3；DenseNet-121 macro 83.7、overall 84.0；EfficientNet-B0 macro 79.1、overall 79.3；VGG16-BN macro 83.0、overall 83.1。
  • 逐类表现：WA-ADDA 在困难天气类别上表现突出，例如 ResNet-50 在 Fog 为 100.0、Rain 为 75.2、Sand 为 89.2、Snow 为 97.7；VGG16-BN 在 Rain 为 75.7；EfficientNet-B0 在 Snow 为 96.6；DenseNet-121 在 Fog 为 98.3、Snow 为 95.5。
  • 稳定性结果：Fig. 2 显示 WA-ADDA 在不同随机种子下 macro accuracy 方差较小；论文称其在 Street-View 目标集上表现稳定。
  • 条件类型：评估为开环图像分类基准，未报告闭环控制、仿真驾驶或实车测试结果。
