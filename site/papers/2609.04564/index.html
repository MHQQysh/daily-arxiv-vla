Card 02 论文概述

论文概述

  • 本文提出 La Agente Óptima，一个面向自主驾驶实验室（SDLs，Self-Driving Laboratories）的智能体框架，用于自主构建和监督跨计算与实验系统的贝叶斯优化（BO）闭环实验。
  • 应用场景覆盖化学与材料领域，包括有机固态激光分子发现、膦配体电子性质调优、倒置单重态-三重态间隙筛选、钴双膦催化剂调优、MOF 材料 Xe/Kr 分离，以及 RAISE 液体配方平台和 RoboChem-Flex 流动化学平台上的闭环物理实验。
  • 核心研究问题是：如何让非专业用户通过自然语言目标即可运行长期、可审计、可自愈的优化实验，同时避免将优化循环全部交给 LLM，从而结合 LLM 的化学知识与 BO 的数据驱动搜索优势。
Card 03 核心贡献

核心贡献

  • 提出“智能体推理与程序化执行分离”的架构：协调智能体（coordinating agent）负责目标解读与结果分析，BO 专家子智能体负责编写 Python 实验程序，两者共享文件系统工作区，降低 LLM 上下文负担。
  • 开发 BO-MCP，将 BO 封装为 MCP 与 REST API 服务，支持后端可替换（默认 BayBE，也可用 BoTorch），提供可查询、可解释的逐动作记录和 SHAP 特征重要性/核长度尺度等诊断信息。
  • 将框架与两套物理实验平台对接：通过 MQTT 桥接 RAISE 静态接触角平台，通过 RoBridge 认证 HTTP 服务接入 RoboChem-Flex 流动化学平台，实现真机闭环优化。
  • 通过后台监控与事件驱动机制实现长期运行的自动干预与自修复，如自动补丁评估器、处理超时与失败测量、机器人状态不一致时拒绝请求等。
  • 通过五个纯计算发现任务和两个物理平台的案例验证了框架的通用性，并报告了 BO 相对种子策略的超体积等改进数值。

Card 06 评估与结果

评估与结果

  • 评估包括架构消融基准（与对照组比较）、五个纯计算发现任务、以及在两个物理平台上的真机闭环优化。
  • OSL 数字发现（模拟评估）：BO 选择的 12 个候选产生累积超体积 3.76，高于 4 个种子的 2.78；共产生 38 个成功观测；总耗时约 3 天 22 小时（其中 16.0 小时为智能体运行时间），共 397 次 LLM 调用，总成本 24.40 美元。
  • 膦配体任务：超体积从 0.791 提升至 1.038，Pareto 集从 3 扩至 17；共 48 次成功评估；成本 7.08 美元。
  • 倒置间隙任务：最佳间隙从 0.227 eV 改进至 0.223 eV；44 次尝试中 39 次成功；成本 13.01 美元。
  • 钴双膦配体任务：可行超体积从 0.572 提升至 1.000；14 次成功评估；成本 53.29 美元。
  • Xe/Kr MOF 任务：期望度从 0.487 提升至 0.502，Pareto 集从 7 扩至 12；80 次成功评估中 65 次成功；成本 11.44 美元。
  • RAISE 平台闭环接触角优化（闭合回路真机实验）：在约 71.4° 目标实验中，智能体识别并修复了中途测量失败，最终接触角从 71.4 降至 67.8°，略超过 65°±1° 目标，并推断目标很可能无法在当前试剂条件下达成，建议更换配方。
  • RoboChem-Flex 多目标流动光化学（五日闭环真机实验）：产量从 30% 提升至 59% / 23 个实验；相比人工定向优化的对照，单次实验成本更低并显著减少起始材料用量，且选择了更高质量效率的运行点（推理成本虽高，总成本仍低于人工定向方案）。
