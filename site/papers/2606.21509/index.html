Card 02 论文概述

论文概述

  • 论文解决端到端自动驾驶系统中感知模型更新导致的潜表征漂移（distribution shift）问题，该漂移会使固定不变的下游策略（decision policy）性能下降。
  • 应用场景为端到端自动驾驶的长期维护与异步演进，即感知模块因重训练、传感器变更或数据集扩充而更新，而下游策略因安全与验证成本而保持固定。
  • 研究问题为：在不对下游策略重新训练或架构解耦的前提下，能否通过轻量级的潜空间对齐（model stitching）在更新后的感知模块与冻结策略之间恢复兼容性。
Card 03 核心贡献

核心贡献

  • 识别并形式化了端到端自动驾驶中感知与策略之间的异步演进问题，并提出“策略兼容表示可缝合性假设”（Policy-Compatible Representation Stitchability Hypothesis）。
  • 系统评估线性缝合（linear stitching）与卷积缝合（convolutional stitching）方法在多种感知更新条件下的有效性，包括传感器配置、表示模型与训练域的变化。
  • 在线性特征对齐目标之外还提供了可选的卷积缝合目标；实验表明轻量级潜空间对齐比重训练与微调更高效地恢复驾驶行为。
  • 在最难的跨域设置（nuScenes → CARLA）中，卷积缝合保留了超过 91% 的无漂移驾驶得分，同时将适应时间从 22.18 小时缩短至 0.91 小时。
  • 仅更新 0.001% 的下游参数，并消除对在线交互的需求。
Card 04 方法描述

方法描述

  • 所属模块：端到端自动驾驶系统中的感知-策略接口修复模块；作用于感知编码器输出到下游策略输入之间的潜空间。
  • 输入传感器：论文中模型跨多种传感器配置训练，包括相机、LiDAR 帧，以及相机+LiDAR 多模态组合；具体以“Image, LiDAR”表示多模态，并分别有“Image”或“LiDAR”单独模态。
  • 场景表示：BEV（鸟瞰图）语义分割与 3D 物体检测两种监督范式，分别为稠密场景级与稀疏物体中心级表示。
  • 模型结构：框架基于 RAMBLE（端到端自动驾驶架构），感知模块改编自 BEVFusion；VAE/AE 重建架构用于 BEV 语义分割，CNN+MLP 判别式管线用于 3D 检测；下游为 Transformer 动力学模型与 Soft Actor-Critic 策略网络。
  • 关键技术：线性缝合（仿射变换，由配对表示通过最小二乘闭式解求得）与卷积缝合（1×1 卷积+BatchNorm；冻结源编码器与目标解码器，仅优化缝合层）；损失函数包含任务损失与可选的表示对齐损失。

Card 06 评估与结果

评估与结果

  • 评估基准：CARLA Leaderboard 2.0 的 EnterActorFlowV2 场景（非信号右转后并入左侧密集车流）；每个路线约 300 米，含情景触发前后各 100–150 米与 150–200 米。
  • 评估指标：Route Completion (RC) 与 Driving Score (DS)；另报告更新效率相关指标（如更新参数数量、运行时等）。
  • 对比方法：无动作（No Action / 不做任何处理）、Retraining（重训练）、Full fine-tuning（全量微调）、Linear Stitching、Convolutional Stitching。
  • 评估规模：共 7 个案例，区分最小漂移（Case 1–2）、模态/传感器变化（Case 3–5）与跨域（Case 6–7）。
  • 关键数值（以 Driving Score / Route Completion 报告）：

- 无漂移基线：RC 100.0 / DS 98.58。

- Case 1（初始化差异）：No Action DS 34.91；Retraining DS 99.12；Fine-tuning DS 96.24；Linear Stitch DS 96.00 / RC 98.21；Conv Stitch DS 98.51 / RC 100.0。

- Case 5（传感器变化）：No Action DS 15.31；Retraining DS 97.56；Fine-tuning DS 97.97；Linear Stitch DS 43.79 / RC 63.59；Conv Stitch DS 91.19 / RC 97.11。

- Case 6（跨域 nuScenes→CARLA）：No Action DS 34.76；Retraining DS 35.10；Fine-tuning DS 31.35；Linear Stitch DS 35.63 / RC 36.91；Conv Stitch DS 89.88 / RC 92.23，保留无漂移得分占比 >91%。

  • 条件说明：驾驶性能评估为 CARLA 模拟器中的闭环评估；Case 6 为闭环鲁棒性评估，Case 7 因高维卷积特征图仅在稀疏 3D 检测监督下评估表示对齐，原文未报告其驾驶得分结果。
