Card 03 核心贡献

核心贡献

  • 提出 GeoCoTDrive，一个面向 VLA 端到端自动驾驶的显式几何思维链框架，遵循“先以 2D 思考、再用专用 3D 先验驾驶”的范式。
  • 提出“规划相关 grounding”（planning-relevant grounding）这一新的区域级 grounding 任务，关注直接影响自车规划决策的局部空间线索，并构建了含 146K 标注的 VQA 风格 dataset PlanningGrounding。
  • 提出自回归几何检索机制：依据预测的 grounding 区域从几何基础模型采样局部 3D 特征，并以几何 token 形式交错插入自回归上下文用于轨迹预测。
  • 在多个端到端自动驾驶基准上验证该显式几何思维链流程对安全关键规划性能的有效性。
Card 04 方法描述

方法描述

  • 所属模块：VLA 端到端规划框架，包含 VLM 主干、冻结的几何基础模型、轻量几何对齐头与自回归轨迹解码。
  • 输入传感器：前视图像、驾驶指令、自车状态及文本提示；原文未报告其他传感器输入（nuScenes/NAVSIM 实验为图像输入，对比表中其他方法列有 Image 或 Image+LiDAR）。
  • 场景表示：先生成规划相关的 2D 区域（归一化坐标的边界框集合），再从几何特征图在这些区域内采样局部 3D 几何特征，而非使用全局几何表示。
  • 模型结构：视觉-语言-动作模型以自回归语言建模方式生成 grounding 结果与轨迹；几何基础模型实例化为 Depth Anything V3 与 VGGT，取其中间 backbone 特征并保持冻结；采样特征经 MLP 对齐头投影到 VLM 隐藏维度后拼接为几何 token 序列。
  • 关键技术：①2D 规划相关区域 grounding；②基于规则网格 K 个采样点与双线性插值的区域级几何特征采样；③几何 token 交错插入自回归上下文的条件轨迹生成；④两阶段训练（Stage I 全量 QA 训练视觉编码器与 LLM 适配驾驶场景，Stage II 冻结视觉编码器、优化 LLM 与几何对齐头）；⑤训练目标为 teacher forcing 下的标准自回归语言建模损失，仅对 grounding 与轨迹响应 token 监督，用户提示、图像占位符与插入的几何特征被掩码。

Card 06 评估与结果

评估与结果

  • 评估基准：nuScenes valset 开环规划、NAVSIM navtest 闭环规划（非反应式仿真）、Bench2Drive 闭环规划、PlanningGrounding 测试集 grounding。
  • 评估指标：nuScenes 用 L2 距离误差、碰撞率（Collision）、交叉率（Intersection）；NAVSIM 用 PDMS 及其子项 NC、DAC、TTC、Comf.、EP；Bench2Drive 用 Driving Score（DS）与 Success Rate（SR）；grounding 用 Recall@0.3/0.5/0.7、AP、mIoU。
  • nuScenes 开环结果：GeoCoTDrive 的 L2 为 0.14/0.29/0.53 m（1s/2s/3s），平均 0.32 m；碰撞率 0.00/0.07/0.27%，平均 0.11%；交叉率 0.37/1.44/4.25%，平均 2.02%；对比方法包括 ST-P3、UniAD、VAD-Base、AD-MLP、BEV-Planner++、UAD、RDA-Driver、OmniDrive、ORION、VGGDrive、LaST-VLA、SpaceDrive。
  • NAVSIM 闭环结果：GeoCoTDrive 的 NC 98.4、DAC 95.6、EP 81.6、TTC 95.0、Comf. 100.0、PDMS 87.6；相比 Qwen2.5-VL baseline（PDMS 85.9）有提升，并在较小 VLM 主干下与 AutoVLA、ReCogDrive、LaST-VLA 等方法保持竞争力。
  • Bench2Drive 闭环结果：GeoCoTDrive 的 DS 78.68、SR 55.42，高于 ORION（77.74/54.62）与 SpaceDrive（78.02/55.11）。
  • Grounding 结果：GeoCoTDrive 在 PlanningGrounding 测试集上取得 R@0.3 56.82、R@0.5 42.73、R@0.7 21.04、AP 39.89、mIoU 38.93，优于 LLaVA1.5-7B、Qwen2.5-VL-3B、OmniDrive。
  • 消融：几何集成方式上，GeoCoT 相比 Baseline 与 Global geometry fusion 在 NAVSIM 与 nuScenes 指标上更优（如 PDMS 87.6 vs 85.9/85.8）；grounding 标注源上，PlanningGrounding 优于 perception label（如碰撞率平均 0.07% vs 0.12%）；另报告了几何基础模型、采样网格尺寸、训练阶段与场景级分析（部分数值在提供的原文中被截断，未报告完整结果）。
