IGSW: Multi-Weather Urban Scene Reconstruction with Intrinsic-Decoupled Gaussian Splatting

2026-11-03 · 原文 · 翻译 · 2611.04374

论文面向自动驾驶场景仿真与数据生成，研究多天气（雨、雪）条件下的城市动态场景重建与天气编辑。 任务是在给定标定的多视角驾驶图像序列及目标天气文本提示下，学习一个可渲染目标天气外观的动态 4D 高斯场景。 核心问题是：扩散式图像编辑生成的天气教师图像常含结构畸变（如云遮挡建筑、车辆细节不一致），直接拟合其外观会把误差传到 4D 场景，破坏原场景结构与时间连续性；而强锚定原始 RGB 又会削弱天气效果。 需同时回答两个耦合问题：哪些场景因素应随天气改变，哪些教师区域提供可靠监督。

Card 03 核心贡献

核心贡献

  • 提出内在解耦的 4D 高斯天气表示：把高斯外观分解为天气共享的反照率/法线与天气特定的辐照度/残差，赋予稳定内容与天气变化不同的表示角色。
  • 引入内在特征约束引导解耦高斯表示的迭代优化（特征级软监督），在建模天气光照变化的同时促进材质与结构一致性。
  • 提出内在保持的高斯天气细化方法：结构保持门融合语义冲突与跨天气反照率/法线差异，抑制教师图像结构误差向 3D 场景传播。
  • 在几何与共享内在表示固定后，用逐高斯天气传输变量与天气特定分支优化辐照度与残差，增强目标天气外观。
  • 在 nuScenes 与 Waymo 上做全序列雨/雪评估、视觉对比与消融，验证天气表达、内容/语义保持与时间连续性的平衡。
Card 04 方法描述

方法描述

  • 所属模块：两阶段框架 IGSW（Intrinsic Gaussian Splatting Weather），Stage I 为内在解耦 4D 高斯外观建模，Stage II 为内在保持的天气细化。
  • 输入传感器：标定多视角驾驶图像（nuScenes/Waymo 前置三相机同步时间戳）；原文未报告激光雷达、IMU 等其他传感器输入。
  • 场景表示：保留高斯几何表示（位置 μ∈R³、尺度 s∈R³、旋转四元数 q∈R⁴、不透明度 α∈[0,1]、32 维外观特征 f），背景外观解耦为反照率 A、法线 N（天气共享头）与辐照度 E、残差 R（天气特定头）；颜色 c = clip(A⊙E + λ_R·R)；含动态物体分支。
  • 教师与先验：用 Qwen-Image 以天气特定提示生成雨/雪教师图像；用 IntrinsicWeather 中基于 Stable Diffusion 3.5 的逆渲染器估计原图与教师的反照率、法线、辐照度。
  • 关键技术一：特征级内在约束——固定轻量编码器 Φ 提取平均池化低频颜色与 Sobel 边缘并拼接归一化，以 patch 级余弦距离约束反照率/法线（对原始与目标天气渲染均以原图内在图为参考），并以方向约束 L_dir 约束辐照度变化趋势而非逐像素一致。
  • 关键技术二：结构保持门——UPerNet–ConvNeXt-XL 语义预测，保护类别（墙、建筑、道路、人行道、人、车辆、房屋、摩天楼）发生类别变化构成语义冲突掩码；结合反照率 L1 与法线余弦差异构成内在差异 D，仅在语义冲突邻域内使用；经最大池化膨胀与平均池化得到软门 G∈[0,1]。
  • 关键技术三：安全教师——在可靠像素上按语义类别计算原图与教师的 RGB 通道均值/标准差做统计迁移（σ 比裁剪至 [0.65,1.35]，类别可靠像素少于 256 时用全局统计），T_safe = (1−G)⊙T^w + G⊙S_w(I^o)，保留原图空间内容与教师色调。
  • 关键技术四：逐高斯天气传输——每个背景高斯附加目标天气标量 u、v，E' = E·exp(2tanh(u))，R' = R + 2tanh(v)·1₃，零初始化，增益限幅 [e⁻²,e²]、残差增量限幅 [−2,2]，属低维无色度通道。
  • 训练目标：Stage I 为 L_I = Σ_{x∈{o,w}}(L_rec + L_content + λ_AN·L_AN + L_aux) + λ_dir·L_dir，含冻结 VGG-19 内容损失、稀疏深度、前景占用掩码、相机颜色校正、高斯形状与动态物体正则；Stage II 为 L_II = L_weather + λ_local·L_local + λ_edge·L_edge + λ_dir·L_dir + λ_uv·L_uv，其中天气重建损失结合全分辨率与低频 ℓ1，局部 VGG 特征匹配在有限邻域搜索以容忍教师微小错位，Sobel 边缘损失在门控区域保护轮廓。
  • 最终渲染：投影二维协方差 Σ²ᴰ = J W Σ Wᵀ Jᵀ，按深度排序 alpha 合成，并加入天气天空色 B 与相机仿射颜色校正 A_k。

Card 06 评估与结果

评估与结果

  • 评估基准：nuScenes 与 Waymo 上的全序列雨、雪场景编辑；每个场景分别训练 original/rain 与 original/snow 模型。
  • 评估指标：CLIP-S（与原图的图像特征相似度）、CLIP-DS（原图到天气图像变化与固定文本特征方向的一致性）、Sem-CS（频率加权语义 IoU）、E_warp（用相邻原帧 RAFT-Large 光流对齐天气帧后的 RGB 平方误差，时间一致性）；图像指标用全部 300 张图像，时间指标用全部 297 个相机内相邻帧对。
  • 对比方法：Qwen-Image、FRESCO、IntrinsicWeather、WeatherEdit、WeatherCity；场景级方法使用相同文本引导天气教师。
  • nuScenes 结果：IGSW 雨 CLIP-S 0.8718、CLIP-DS 0.1599、Sem-CS 0.8992、E_warp 0.0021；雪 CLIP-S 0.8782、CLIP-DS 0.2732、Sem-CS 0.8792、E_warp 0.0028；其中 CLIP-S、Sem-CS、E_warp 为最优，雨 CLIP-DS 低于 Qwen-Image（0.2090），雪 CLIP-DS 为最优。
  • Waymo 结果：IGSW 雨 CLIP-S 0.9031、CLIP-DS 0.2940、Sem-CS 0.8723、E_warp 0.0009；雪 CLIP-S 0.8971、CLIP-DS 0.2869、Sem-CS 0.8050、E_warp 0.0019；四项指标在雨雪下均为最优（原文表格加粗标示）。
