Valerant: An Automatic Navigable Game Map Generator via Action-Conditioned World Model Exploration

2026-09-08 · 原文 · 翻译 · 2609.09418

论文面向 3D 游戏地图自动生成任务，目标是仅从单张输入图像出发，自动探索并构建可导航的 3D 游戏地图。 应用场景为 3D 游戏（如第一人称射击游戏）中需要持久、可导航且具备显式几何的空间，用于支持相机运动、碰撞、可见性与物体交互的一致性解析。 研究问题在于：自动驾驶与机器人领域中物理环境本身独立存在，可作为持久 3D 世界的基底；而游戏没有这种外部基底，虚拟世界必须被生成。现有游戏导向方法多结合动作条件世界模型与外部策略/奖励函数，但主要在 2D 视觉观测空间中运行，不实例化持久 3D 几何，动作条件视频 rollout 只提供视觉观测而不提供空间表示。 论文提出 Valerant，将预训练的动作条件世界模型转化为 World Action Model（WAM），通过预测性视觉 rollout 与 SLAM 空间重建、探索驱动动作选择耦合，逐步把单张图像转化为持久 3D 游戏地图。

Card 03 核心贡献

核心贡献

  • 提出 Valerant，一个免训练的统一框架，将预训练动作条件世界模型转化为 WAM，并将其探索与基于 SLAM 的重建耦合，用于自动游戏地图生成。
  • 开发了反事实探索流程：从相同动作前状态出发，用有限候选动作查询世界模型生成替代性视频 rollout，并由探索策略根据建图效用进行动作选择，把视觉世界模拟与游戏所需的显式空间实例化连接起来。
  • 提出面向几何漂移与视觉幻觉的鲁棒探索机制，包括鲁棒地面估计、互补碰撞检测（点云碰撞与深度碰撞）以及死口袋回退（Dead-Pocket Rewind）。
  • 确立了一种新的游戏地图创作方向：单一视觉概念可被扩展为可导航 3D 几何，从而减少游戏开发者对人工密集地图构建流程的依赖。
Card 04 方法描述

方法描述

  • 所属模块：属于将动作条件视频世界模型、视觉 SLAM 与探索策略组合的级联式 WAM 框架，整个流程在推理时运行且世界模型保持冻结。
  • 输入传感器：输入为单张图像作为初始帧与单视图条件；实验输入图像来自 VALORANT 截图。原文未报告真实传感器数据。
  • 场景表示：以持久 3D 点云地图表示游戏地图；每个探索步维护视觉上下文、当前相机位姿与全局地图，并将选中的观测与重建几何融合进全局地图。
  • 模型结构：使用预训练动作条件视频扩散世界模型（实验中使用 Matrix-Game 3.0），采用流匹配（flow matching）形式建模条件速度场；使用视觉 SLAM（实验中使用 MASt3R-SLAM）估计相机轨迹与重建 3D 结构；可选使用 video2world 作为后处理全局细化重建点云。探索策略根据建图效用选择动作，效用由探索覆盖与前进进度组成，并在碰撞约束下进行选择。
  • 关键技术：反事实 rollout，即对五个候选动作序列（uw、jw、lw、jq、lq；三个前进候选和两个原地旋转候选）从同一动作前上下文分别生成未来视频 rollout；对每个 rollout 运行视觉 SLAM 得到相机轨迹与候选场景几何；选择后恢复到动作前状态、仅执行最高分动作，形成 branch–reconstruct–evaluate–commit 循环。
  • 关键技术：鲁棒地面估计，用局部自适应地面平面替代固定全局参考，并以相对地面高度进行归一化，归一化后局部地面高度为 0、相机中心高度为 1，以抵消重建漂移。
  • 关键技术：互补碰撞检测，包括点云碰撞（检测重建几何是否与沿采样轨迹的归一化圆柱体体积相交）和深度碰撞（直接使用 rollout 帧的未过滤深度估计，识别近距前向表面且轨迹仍前进的穿透事件）。
  • 关键技术：Dead-Pocket Rewind，维护 WM 与 SLAM 状态同步检查点，当进展持续不足时回退到更早检查点，并把丢弃路段的空间单元保留在失败区域记忆中，避免再次进入同一死口袋。

Card 06 评估与结果

评估与结果

  • 评估基准：任务为单图像 3D 游戏地图生成，属于开放式生成任务，单张输入图像可对应多种合理 3D 环境，没有唯一真值地图可用于参考式评估，因此采用感知指标评估。
  • 评估指标：Authenticity Score（AS，真实性分数，使用 VLM 作为评估器评估生成结果的感知真实性）与 User Preference（UP，用户偏好，报告成对比较中人类评估者更偏好各方法输出的比例）。
  • 关键数值：与 HY-World 2.0 对比，AS 上 HY-World 2.0 为 20.00%，Valerant 为 80.00%；UP 上 HY-World 2.0 为 16.67%，Valerant 为 83.33%。
  • 对比方法：HY-World 2.0，该方法同样从单张图像生成可导航 3D 世界，但采用显著不同的技术路线。

  • 定性结果：图 2 展示四个场景，从仅第一帧开始自动完成探索与重建，无需人工指定轨迹或中间干预；生成帧显示智能体平滑通过走廊、转弯和开阔区域并避免碰撞；最终俯视图显示沿执行轨迹具有较大空间覆盖。
  • 消融结果：图 3 对比三个鲁棒性模块。Heaven 场景中移除 RF 会使几何漂移下地面参考不稳定，限制探索进展，加入 RF 后可平顺前进进入开阔区域；Icebox 场景中无 COL 时生成轨迹会穿透橙色墙体，COL 能拒绝几何不可行候选；Split 场景中无 DP 时智能体会困在死口袋中反复左右转而无空间进展，DP 可恢复较早探索状态并重定向到替代路线。
