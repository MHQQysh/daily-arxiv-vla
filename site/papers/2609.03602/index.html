Card 03 核心贡献

核心贡献

  • 提出 SV-WAM，一种高效的环视世界-动作模型，采用 action-centered causal mask，在共享生成模型中联合去噪未来动作与环视未来视频潜变量，同时保留完整六视角条件下的 action-only 推理能力。
  • 引入可微分的 drivable-area compliance（DAC）正则项，通过惩罚车辆足迹角点接近或跨越可行驶边界，提升规划安全性与边界感知能力，且推理无额外成本。
  • 在 NAVSIMv2 闭环基准上实现最优 EPDMS 91.0，推理延迟低（342 ms on NVIDIA H20），优于近期基于世界模型的规划器。
  • 在 nuScenes 零样本迁移中达到最低平均 L2 误差 0.89 m 与碰撞率 0.16%，验证跨数据集泛化能力。
Card 04 方法描述

方法描述

  • 所属模块：端到端自动驾驶世界模型/规划模块，属于 driving world model for planning 方向。
  • 输入传感器：六相机环视图像（front-left, front, front-right, rear-right, rear, rear-left），历史帧数 H=4。
  • 场景表示：每帧各视角图像沿宽度方向拼接后，经 Wan2.2-TI2V-5B 的冻结 3D 因果 VAE 编码为潜变量，并在时间维拆分为历史参考潜变量 Z^ref 与未来视频潜变量 Z^fut，再经共享 video tokenizer 分块嵌入为 transformer token 序列；ego 状态历史经 MLP 映射为状态 token，未来动作序列经 MLP 映射为动作 token。
  • 模型结构：采用 Wan2.2-5B DiT（Diffusion Transformer）作为骨干网络；训练采用流匹配（flow matching），共享噪声时间 t 联合去噪动作与视频潜变量；总损失为动作流匹配损失与视频流匹配损失之和，另加 drivable-area 正则损失（log-mean-exp 聚合车辆四个角点到可行驶区域的符号距离惩罚，用 LQR tracker 进行模拟 rollout）。
  • 关键技术：

- Action-centered causal mask：state 与 reference-video token 作为条件前缀只互相注意；action token 可注意条件前缀与 action token，但禁止注意未来视频 token；未来视频 token 可注意前缀、动作与自身视频 token。由此将联合分布分解为 p(A\|Ω)·p(Z^fut\|Ω,A)，使动作预测不依赖未来视频 token，支持推理时丢弃视频分支。

- 训练流程：先在 NAVSIM trainval 上训练 10k 迭代，再微调 1k 迭代。

- 高效 action-only 推理：推理时将未来视频 token 从序列中移除，保留 [S, V^ref, A_t]，跨去噪步骤缓存并复用条件前缀，采用两步去噪。

Card 06 评估与结果

评估与结果

  • 评估基准：

- NAVSIMv2（闭环规划，navtest split，human penalty enabled），指标用 EPDMS（含 NC、DAC、DDC、TLC、EP、TTC、LK、HC、EC）。

- nuScenes（开环零样本），报告 1s/2s/3s 的 L2 轨迹误差与碰撞率及其平均。

  • NAVSIMv2 主要结果：SV-WAM（C×6）获得 EPDMS 91.0，为所有对比方法中最优；C×3 变体获得 90.5，C×1 变体获得 89.3；对比的一视角方法（如 EponaV2 88.9、PWM 88.2、DriveLaW 88.9）与本方法存在差距。原文将增益归因于环视输入与未来视频共训练、DAC 正则化的共同作用。
  • 消融结果：

- 无视频监督、无 DAC-reg、无 FT：DAC 93.4，EPDMS 83.1。

- 加入视频监督：DAC 95.6，EPDMS 87.7。

- 再加入 DAC-reg：DAC 98.6，EPDMS 90.1。

- 全组件加 FT：DAC 98.8，EPDMS 91.0。

  • nuScenes 零样本结果：平均 L2 0.89 m（1s 0.31 m、2s 0.80 m、3s 1.57 m），平均碰撞率 0.16%（1s 0.07%、2s 0.13%、3s 0.27%），低于 DriveVLA-W0（1.43 m、0.77%）与 PWM（3.99 m、0.36%）等零样本方法。
  • 评估条件说明：NAVSIMv2 为闭环评估；nuScenes 为零样本开环评估；存在对内测数据零样本迁移的定性实验，但原文未报告其定量指标。
