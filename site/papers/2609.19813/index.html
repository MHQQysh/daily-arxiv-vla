研究单位

Card 02 论文概述

论文概述

  • 任务：自动驾驶中周围车辆的未来轨迹预测，用于碰撞风险评估与自车安全路径规划。
  • 研究问题：基于神经网络的轨迹预测器（如 Trajectron++）虽能利用智能体历史、动态场景图和语义地图，但在加速、减速、转弯等特定运动模式下可能无法反映物理可行的轨迹。
  • 思路：将神经网络预测器输出与基于扩展卡尔曼滤波（EKF）的多条轨迹候选在后期阶段融合，兼顾神经预测器的上下文表示能力与物理模型在特定运动模式下的可行性。
Card 03 核心贡献

核心贡献

  • 提出一种将 Trajectron++ 输出与 EKF 多模式轨迹候选进行后期融合的框架，在不修改基线架构的前提下提升预测性能。
  • 设计基于 EKF 的多模式候选生成器，仅使用目标车辆历史轨迹，生成匀速、加速、减速、左转、右转五类候选，并输出模式概率与运动摘要特征。
  • 提出学习式融合模块：以特征构建器加 MLP 预测各候选的融合权重，最终预测为六个候选的凸组合。
  • 设计包含预测损失、交叉熵损失、基线保持损失和 guard 损失的四项训练目标。
  • 在 nuScenes 上将 Trajectron++ robot 基线的 ADE 与 FDE 分别降低 13.7% 与 14.6%，并在 CMT、LAformer、AgentFormer 上验证模型的通用适用性。
Card 04 方法描述

方法描述

  • 所属模块：轨迹预测（后处理/后期融合模块），不改变基线预测器本身。
  • 输入传感器：原文未报告原始传感器输入细节；输入为轨迹历史、动态场景图、语义地图和自车未来规划等抽象场景输入（nuScenes 提供）。
  • 场景表示：分支一使用 Trajectron++ 的动态时空图（节点与边）表示，编码目标历史、邻居交互历史、语义地图和自车未来规划；分支二仅使用目标车辆历史轨迹，采用目标中心相对坐标系表示。
  • 模型结构：

- 学习型分支：冻结的 Trajectron++ robot 配置，采用 RNN 编码目标与交互历史、CNN 编码语义地图、另一 RNN 编码自车未来规划，结合 CVAE 隐变量输入 GRU 解码器，逐时间步输出高斯混合分布；取最高概率轨迹作为基线候选 C0。

- 物理分支：EKF 估计当前状态（状态向量 [px, py, θ, v]，控制输入 [a, ω]，独轮车运动模型），由相邻时刻有限差分估计加速度与偏航率并做物理范围裁剪；以同一 EKF 估计状态为初始条件并行 rollout 五种模式控制，生成候选 C1–C5、模式概率 π 和运动摘要特征（速度、加速度、偏航率）。

- 融合模块：候选集合 C=[C0,…,C5]，特征 φ 为 99 维（基线 12、五条相对轨迹 60、加权均值差 12、模式概率 5、one-hot 模式 5、标量运动特征 5），经 MLP 与 softmax 得到权重 w，最终预测为凸组合 Σ wk Ck,t。

  • 关键技术：EKF 状态估计、独轮车运动模型、多模式候选 rollout、模式概率 softmax、基于 MLP 的学习式后期融合、凸组合约束、四项加权损失（SmoothL1 预测损失、oracle 标签交叉熵、基线保持、guard 损失）。
  • 关键超参数：预测时域 T=6，历史长度 8，过程/观测噪声协方差 Q=diag(0.25,0.25,0.0225,1.0)、R=diag(1.0,1.0,0.0625,2.25)，初始协方差 P0=diag(10,10,π,5)，观测矩阵 H=I4，加速/减速阈值 a=1.5 与 a=−2.0，转向偏航率阈值 ω=±0.18。
  • 原文未报告：融合 MLP 的具体层数、隐藏维度与参数量。

Card 06 评估与结果

评估与结果

  • 评估基准：nuScenes v1.0-trainval 官方验证集，VEHICLE 智能体；对比方法包括 Trajectron++ robot 基线、CMT、LAformer、AgentFormer。
  • 评估指标：平均位移误差 ADE 与最终位移误差 FDE（单位：米），以及各候选的 oracle 选择率与平均融合权重。
  • 关键数值（Trajectron++ 基线对比）：

- ADE 从 0.9035 m 降至 0.7793 m，相对改善 13.74%。

- FDE 从 1.8618 m 降至 1.5910 m，相对改善 14.55%。

  • 跨模型适用性（融合后相对误差下降）：

- CMT top-1：ADE 2.00±0.06%，FDE 2.07±0.06%（nuScenes val，9,041 样本）。

- LAformer top-1：ADE 1.68%，FDE 0.46%（场景不相交测试，1,947 样本）。

- AgentFormer K=5：ADE 0.45±0.01%，FDE 0.62±0.01%（nuScenes val，9,041 样本）。

  • Oracle 与候选分析：

- 多模式候选 oracle：ADE 0.7434 m，FDE 1.4475 m。

- 基线+多模式候选 oracle：ADE 0.4998 m，FDE 1.0042 m。

- 模式概率加权 EKF 平均为未学习组合，未优于基线；学习式 MLP 融合优于基线。

- EKF 候选在 76.78% 样本上优于基线，学习式融合在 67.55% 样本上优于基线。

- 各候选 oracle 选择率/平均融合权重/候选 ADE：Trajectron++ 23.22%/27.42%/0.9035；CV 50.22%/49.41%/1.1767；Accel 7.47%/5.96%/3.3062；Decel 12.48%/11.24%/1.9824；Left 3.27%/2.97%/1.6862；Right 3.34%/2.99%/1.7005。

  • 模式概率分析：CV 组平均概率 0.537，纵向组 0.279，转向组 0.184，非 CV 组合计 0.463 概率质量。
