Card 02 论文概述

论文概述

  • 任务：面向自驱动实验室（Self-driving Laboratories, SDLs）的机器人遥操作故障恢复，即人在回路（human-in-the-loop）干预机制。
  • 应用场景：实验室自动化中的流程中断、初始化错误、严重故障（如掉瓶、掉落样品）等异常，需要人工远程介入使实验流程恢复名义运行。
  • 研究问题：如何设计直观的遥操作接口与控制器映射，并评估不同控制策略与参考路径引导对操作员故障恢复绩效、碰撞与奇异风险的影响，从而提升 SDL 系统韧性。
Card 03 核心贡献

核心贡献

  • 搭建了一套面向 SDL 的遥操作框架：操作员端为 3Dconnexion SpaceMouse Pro，SDL 端为六自由度 UR3e 机械臂，配腕部相机与 Linux 工作站，通过 RTDE 与 ur_rtde 通信。
  • 提出并比较了两种基于速度的控制映射：耦合模式（六自由度全部映射到 3D 鼠标中央旋钮）与解耦模式（四自由度映射到旋钮，俯仰与偏航映射到外围按键）。
  • 通过用户研究在三种模拟 SDL 故障场景（PI、IE、EF）中量化比较两种控制模式的成功率、完成时间、平均旋转与路径长度。
  • 开展了参考路径引导研究（无引导、仅终点参考路径、多航点参考路径），分析轨迹偏差、执行序列与性能差异。
  • 基于记录的遥操作轨迹回顾性分析碰撞与奇异风险，使用 Yoshikawa 指数、雅可比条件数与最小连杆距离三项指标，并给出“Telerobotic Janitor”真实世界定性演示。
Card 04 方法描述

方法描述

  • 所属模块：遥操作干预/故障恢复模块，作为 SDL 自主流程的人在回路补充机制；原文强调并非提出全新遥操作算法。
  • 输入传感器：UR3e 腕部安装的视觉模块（Intel RealSense D435 或 Logitech C920e）提供实时视觉反馈；SpaceMouse Pro 提供六自由度输入与 15 个可编程按键。
  • 场景表示：原文未报告显式场景/环境表示模型；任务场景为玻璃瓶与瓶架、障碍物与 ArUco 标记等实物布置。
  • 模型结构：单边遥操作架构；SpaceMouse 输入以 500 Hz 采样并映射为末端执行器笛卡尔速度（式 1，含平移/角速度缩放因子 sv、sω）；本设置取加速度 1.2 m/s²、sv=0.1、sω=0.5；周边按键负责夹爪开合、模式切换、复位与操作象限切换；独立线程以 30 fps 录制腕部与环境相机视频，并以 20 Hz 记录关节位置、TCP 位置与夹爪状态。
  • 关键技术：速度控制映射（因机械臂与 SpaceMouse 耦合非相似而选用速度控制）、解耦控制降低跨轴干扰、直接演示方式给出参考路径、弧长对齐的轨迹偏差比较方法；统计上用 Wilcoxon 符号秩检验、配对 t 检验、Cohen's dz、10,000 次重采样的 bootstrap 95% CI、Fisher 精确检验与 Wilson 区间。

Card 06 评估与结果

评估与结果

  • 评估基准：三种模拟 SDL 故障场景 PI、IE、EF（运动学与认知复杂度 PI < IE < EF）；引导研究为绕障对准虚拟标记与物理 ArUco 标记的瞄准任务。
  • 评估指标：成功率、平均旋转、完成时间、平均路径长度；引导研究另含位置/姿态平均与最大偏差、总姿态变化、路径效率（参考路径长度与遥操作路径长度之比）、执行序列（Δx、Δy、Δz、Δrx、Δry、Δrz）；风险指标为 Yoshikawa 指数、雅可比条件数、最小连杆距离。
  • 关键数值：成功率 PI 由 71% 提升至 86%（解耦模式），IE 与 EF 分别提升 6% 与 22%；结论部分汇总为成功率提升 9.9%、完成时间减少 25.6 s；平均旋转配对差 -3.99 rad（bootstrap 95% CI: -6.59 至 -1.22 rad；Wilcoxon p = 0.094；Cohen's dz = -1.08）；完成时间配对差 -25.6 s（95% CI: -36.6 至 -14.2 s；p = 0.031；dz = -1.60）；多航点引导相对无引导时长差 -40.1 s（n = 7；95% CI: -55.9 至 -26.3 s；p = 0.016），路径长度差 -218 mm（95% CI: -365 至 -81 mm；p = 0.047）；参考路径长度 375.04 mm（仅终点）与 755.10 mm（多航点），对应引导执行路径长度 387.44 mm 与 373.29 mm、时长 42.78 s 与 38.52 s；无引导成功率前两次试验低于 50%，第 6 次达 100%，引导后第 7 次短暂下降，随后仅终点引导达 85%、多航点引导达 100%。
  • 对比方法：耦合控制模式 vs 解耦控制模式；无引导 vs 仅终点参考路径 vs 多航点参考路径。
  • 条件：全部为用户研究（受控实验）+ 真实 SDL 实机定性演示；无开环/闭环自动驾驶式评测、无仿真实验；风险指标分析为回顾性（离线）分析，未集成实时辅助控制；引导试验在无引导试验之后进行，存在练习效应，作者将其视为探索性结果。
