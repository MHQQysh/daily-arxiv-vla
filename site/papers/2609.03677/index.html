Card 02 论文概述

论文概述

  • 该论文研究自动驾驶数据集的内省（dataset introspection）问题，针对大规模图像数据集的构成理解困难、现有方法依赖元数据或人工检查、可扩展性差等挑战展开。

  • 该任务面向自动驾驶领域，用于检测分布偏移、数据偏差和罕见长尾视觉差异，支持跨地点部署时的安全与可靠性评估。
Card 03 核心贡献

核心贡献

  • 提出对象中心集合差异描述（object-centric set difference captioning）方法，通过对象检测生成的图像块代替完整图像进行比较，解决复杂交通场景下聚合并关注安全相关对象的难题。
  • 构建了首个面向自动驾驶领域的集合差异描述基准数据集 AD-Diff Bench，包含 Web 抓取、标注过滤和 CLIP 过滤三个划分，并提供评估协议。
  • 首次对高稀疏性（low-concentration）真实差异场景进行评估，探讨集合差异描述方法在现实应用中检测罕见或稀疏差异的适用性。
  • 对比了多种提议器（图像基础、描述基础、特征基础方案）及两阶段 vs 单阶段架构的表现，确认两阶段与特征排序器对稀疏差异更具鲁棒性。
Card 04 方法描述

方法描述

  • 模块结构：两阶段流程（分离的 proposer 和 ranker）及单阶段联合推理变体。
  • 输入传感器与场景表示：原文未报告具体传感器来源；将对象作为检测到的局部图像块（相对原始标注框扩大 50%，以红色框标记目标对象）来表示场景。
  • 模型结构：三种提议器均采用开权重模型 Qwen3-VL-30B-A3B-Instruct；图像法直接输入采样子集生成候选差异描述；描述法先对图像生成文本描述再交由大语言模型处理；特征法基于均值嵌入空间差并配合文本嵌入生成。排序器采用 SigLIP 2 Giant 模型计算图像-文本余弦相似度 AUROC 得分。评估用 gpt-oss-120b 作裁判。单阶段方法直接输入每个划分 100 张图像并生成候选与排名。
  • 采样子集规模：proposer 使用每轮每数据集 20 张图像，平均三轮，每轮给出十个候选；rank 基于完整目标/参考数据集评估所有候选。

Card 06 评估与结果

评估与结果

  • 评估基准：AD-Diff Bench；并另与 VisDiffBench 校准裁判一致性；采用 gpt-oss-120b 作 LLM 评判，与 1000+ 人工标注的一致性 80.3%，平均绝对误差 0.104。
  • 评估指标：top-1 与 top-5 准确率（Acc@1、Acc@5）（judge 语义等价格式），以及稀释浓度、纯度等参数化试验。
  • 关键数值（表 2，三次运行平均）：两阶段/图像法在 web-scraped 上 Acc@1=0.73、Acc@5=0.88；annotation-filtered-60 上 0.56/0.78；CLIP-filtered 上 0.64/0.80。两阶段/描述法与之相差不大且最优；特征法显著低于前两者。单阶段/图像法低于两阶段/图像法。
  • Web 抓取划分内按易/中/难分组的 Acc@1 依次 0.84/0.75/0.59；两阶段法的性能差异最小，annotation（最难）显著低于 web/clip 划分。
  • 稀释与噪声实验：annotation-filtered-39 上浓度和纯度在约 0.5 以下性能迅速下降，两阶段架构相对单阶段更稳；纯度 0 时单阶段仍可恢复到 35 %，两阶段排序器更低，但该差异被认为是误导性有效。
  • 实验均在离线/仿真数据上进行，原文未报告实车路测或闭环评估。
