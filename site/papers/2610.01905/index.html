MapLightning: Online Vectorized HD Map Construction with 1D Map Tokens

2026-10-01 · 原文 · 翻译 · 2610.01905

论文关注在线向量化高精地图（HD Map）构建任务，目标是从车载多视角图像实时构建包含车道线、人行横道、道路边界等静态道路元素的向量化地图。 应用场景为自动驾驶在线感知与局部地图构建，减少对离线 SLAM/SfM 地图构建与维护的依赖。 研究问题在于：现有方法通常依赖密集 BEV 网格作为中间表示，但向量化地图输出稀疏，在 nuScenes 上仅占栅格化感知范围的 4.27%、在 Argoverse 2 上占 2.65%，因此密集 BEV 表示对向量化地图任务并不高效。 论文提出用紧凑的 1D 可学习 map tokens 替代密集 BEV 网格，并研究从图像特征构建 map tokens 的注意力机制选择问题。

Card 03 核心贡献

核心贡献

  • 提出 MapLightning，首个用基于注意力的映射到紧凑 1D map tokens 取代密集 BEV 投影的在线向量化 HD 地图构建框架，宣称带来更高效率、更好的全局上下文和对相机外参扰动的鲁棒性。
  • 对比 cross-attention 与 self-attention 在从图像特征构建 map tokens 时的效果，表明 self-attention 更适合在线向量化 HD 地图构建。
  • 使用更少中间 tokens（相比密集 BEV 方法最多少 16.7 倍）、更少内存和更快推理。
  • 在在线向量化 HD 地图构建、不确定性感知地图构建、下游轨迹预测和 3D 目标检测上均报告优于先前方法。
  • 采用轻量设计，使 map decoder 可使用 full cross-attention 而非 deformable cross-attention，以获取更好的全局上下文和长程依赖。
Card 04 方法描述

方法描述

  • 所属模块：在线向量化 HD 地图构建框架，替代传统“图像编码器 + BEV 投影模块 + DETR 风格解码器”三阶段流水线中的密集 BEV 中间表示。
  • 输入传感器：多视角视频/多相机图像。原文未报告使用激光雷达等其它传感器作为输入。
  • 场景表示：使用一组紧凑的 1D 可学习 map tokens 作为中间场景表示；方法不使用相机投影参数。
  • 模型结构：包含图像 backbone、将 map tokens 与 image tokens 拼接的 transformer-based mapper、以及任务特定 decoder。
  • 关键技术：Self-Attention Mapper 对拼接后的 map 与 image tokens 施加 full self-attention，使 map-to-map、image-to-image、image-to-map 均可交互；最终 mapper 层后丢弃 image tokens，仅保留更新后的 map tokens 供解码。
  • 解码阶段：Map Decoder 使用 cross-attention，使 map queries 作为输出槽从固定的 map-token 表示中读取信息。
