Card 03 核心贡献

核心贡献

  • 提出 GeoUP（Geometry-grounded Unified 3D Perception）框架，将 VGGT 的重建导向潜在表示适配到自动驾驶，并在单一架构中支持度量深度估计、3D 物体检测和语义占用预测。
  • 引入面向驾驶的视觉几何基础模型适配策略，包括将全局跨图像注意力分解为自注意力、时间注意力与视角注意力，以建模结构不同的时间与跨视角对应关系。
  • 注入校准相关的 raymap 编码（由相机内参和全局相机位姿导出），使表示感知度量尺度与相机几何。
  • 提出联合多任务与多数据集训练策略，使几何接地表示能从异构标注中获益，并泛化到表面级、实例级与体素级三种不同粒度的 3D 感知任务。
  • 在多个公开驾驶数据集上验证 GeoUP 在检测、占用与深度估计上的 SOTA 性能，并评估其作为端到端规划器视觉骨干的迁移能力。
Card 04 方法描述

方法描述

  • 所属模块：统一 3D 感知框架，包含几何接地骨干网络（Geometry-Grounded Backbone）与多任务感知头（Multi-task Perception Heads）。
  • 输入传感器：仅相机（多视角环视相机，V 个相机，时间窗口 T 帧）；原文未报告激光雷达或其他传感器输入。
  • 场景表示：以 VGGT 的重建导向潜在表示为共享场景表示，解码为图像对齐深度、3D 物体框与体素占用三类输出。
  • 模型结构：输入图像按 patch size P 分块，经 DINOv2 编码器得到 patch tokens；叠加校准导出的 raymap 嵌入与相机 token，形成几何感知输入表示。骨干网络保留自注意力，将全局跨图像注意力分解为时间注意力（同一相机跨帧）与视角注意力（同一时刻跨相机）。输出 patch tokens 用于深度、检测与占用预测，相机 tokens 解码用于辅助相机位姿预测。
  • 关键技术：时间-视角注意力因子分解；校准感知 raymap 注入；历史 patch tokens 缓存（仅当前帧编码，避免冗余计算）；联合多任务-多数据集训练策略。
