Card 02 论文概述

论文概述

  • 研究面向自动驾驶的端到端规划与驾驶推理任务，聚焦“视觉焦点”（visual focus）在推理序列中的显式表达。
  • 应用场景包括驾驶注视点预测（gaze prediction）与基于 NAVSIM 的端到端轨迹规划（非反应式仿真）。
  • 研究问题：现有驾驶 VLA 的中间推理主要以自然语言表达，物体描述与输入图像具体区域之间的对应关系是隐式的；论文希望将决策相关物体与其图像 patch 显式关联，再基于该关联推理驾驶响应。
Card 03 核心贡献

核心贡献

  • 提出 FocusDrive，一个围绕显式视觉焦点组织的结构化多模态 CoT 框架，将物体识别与定位、响应推理和端到端规划串联起来。
  • 在 NAVSIM 现有训练场景内构建 driving-focus 标注，捕获人类选择的决策相关物体及其图像位置，用于在规划推理中学习焦点。
  • 采用“物体描述 + 生成式 patch 引用”的视觉焦点表达，并使用 PaDT 的动态视觉引用接口实现图像 patch 引用。
  • 在 W3DA 上展示有竞争力的注视点预测结果，在 NAVSIM 上达到 91.1 PDMS 与 91.1 EPDMS，并优于文本 CoT 基线。
  • 通过消融展示视觉焦点推理相对文本 CoT 的提升，以及 patch 引用与 reference warm-up 的作用。
Card 04 方法描述

方法描述

  • 所属模块：视觉-语言-动作（VLA）驾驶推理与端到端规划；同时用于驾驶注视点预测。
  • 输入传感器：规划输入 front-camera 图像（1920×1080）、导航命令以及 ego 速度与加速度；注视点预测输入驾驶图像与任务 prompt。原文未报告激光雷达等其他传感器。
  • 场景表示：将图像划分为 patch 网格，规划时为 34×60，注视点预测时为 18×32；每个参考指向图像网格中的一个合并单元，携带由视觉编码器上下文化的视觉表示。
  • 模型结构：基于 Qwen3-VL-2B；使用 PaDT 的动态视觉引用机制实现图像 patch 引用；视觉引用投影器采用 LayerNorm 加低秩残差投影（瓶颈宽度 r=64，无偏置线性层 W_down∈R^{r×d}、W_up∈R^{d×r}）；输出端将文本词表与图像相关参考集合并做自回归解码，生成参考 token 时以对应 patch 原型作为输入嵌入。
  • 关键技术：视觉焦点以“物体描述 d_o + patch 引用 v_j”表示；注视点预测通过 gaze adapter 将参考分数 z 做 patch 间 z-score 归一化、reshape 到空间网格，再经五层卷积与双线性上采样解码为密集 gaze map；规划序列形式为 [d_o, v_j] → action plan → waypoint text，使用 <focus>、<plan>、<answer> 分隔符；训练包含视觉引用 token（VRT）warm-up、规划 SFT（token 级交叉熵）与基于 GRPO 的强化微调，以 PDMS 作为奖励并加入 KL 正则。
  • 训练目标：注视点预测联合语言建模损失与 gaze 损失（BCE + KL，λ_g=3，λ_KL=0.5）；VRT warm-up 与规划 SFT 使用 token-level cross-entropy；GRPO 使用 group-relative advantage 与 KL 估计器。原文未报告其他未列出的训练细节。
Card 05 数据集与资源

数据集与资源

  • 数据集：W3DA（含 Normal：DR(eye)VE 与 LBW；Safety：BDD-A；Accident：DADA-2000），使用 G-W3DA 数据准备，39,673 训练帧与 21,985 测试帧；NAVSIM 使用 Navtrain 训练、12,146 个 Navtest 场景评估。
  • 仿真器：NAVSIM 非反应式仿真；NAVSIM v1 的 PDMS 与 v2 的 EPDMS。原文未报告其他仿真器。
  • 模型规模：Qwen3-VL-2B；视觉引用投影器瓶颈宽度 r=64。
  • 训练资源：注视点模型在 2 张 GPU 上训练；规划器在 16 张 GPU、每张 96 GB 内存上训练。
  • gaze 训练配置：3 个 epoch，每 GPU batch size 12，学习率 VLM 10^{-5}、adapter 10^{-4}，AdamW。
  • 规划训练配置：对 Navtrain 中 13.1% 的场景添加 focus 标注，完整 Navtrain 保留规划监督；stage-specific 优化、rollout 与奖励设置在附录 A.3.3。原文未报告具体训练时长、功耗或实车平台（论文为仿真/数据集评估，未报告实车部署平台）。
Card 06 评估与结果

评估与结果

  • 评估基准：W3DA 用于驾驶注视点预测；NAVSIM（PDMS、EPDMS）用于端到端规划。
  • 评估指标：注视点预测报告 KLdiv、CC、SIM、AUC-Judd/AUC-Borji；规划报告 PDMS 与 EPDMS，并分析 NC、TTC、TLC 等子指标。
  • 关键数值：规划达到 91.1 PDMS 与 91.1 EPDMS，在文中比较的显式 CoT 规划器中领先；相对文本 CoT 基线在 SFT 阶段提升 1.3 PDMS 与 1.4 EPDMS，强化微调后仍保持 0.9 与 1.0 点提升；patch 引用相对 Text-2D 在无 warm-up 时两项指标各高 0.4 点，有 warm-up 时各高 0.6 点；reference warm-up 进一步带来 0.3 PDMS 与 0.2 EPDMS 提升；image-conditioned patch 引用相对 learned reference-ID embedding 每项再提升 0.3 点；注视点预测在 Normal、Safety、Accident 三组中取得最强 KLdiv、CC、AUC，并在 Normal 与 Accident 中取得最高 SIM。
  • 对比方法：显式 CoT 规划器包括文本推理、自适应思考、探索导向训练与空间提示等（如 AdaThinkDrive、Curious-VLA、DriveTeach-VLA、AutoDrive-p3 等）；注视点预测对比包括 DualGaze-VLM 等。论文报告在安全关键场景中相对 DualGaze-VLM 的 correlation 增益最大。
  • 评估条件：NAVSIM 为非反应式仿真评估（开环/非闭环仿真条件）；W3DA 为数据集基准评估。原文未报告闭环实车测试或实车条件。
