DTP-Attack: A decision-based black-box adversarial attack on trajectory prediction

Card 03 核心贡献

核心贡献

  • 提出针对轨迹预测的决策型黑盒攻击框架，仅依赖二元判定输出，不依赖模型内部信息或梯度。
  • 设计无固定物理约束的边界行走（boundary walking）算法，通过保持邻近性与轨迹真实性实现自然约束。
  • DTP-Attack 同时支持意图误分类和预测精度降级两种不同攻击目标。
  • 在 nuScenes 与 Apolloscape 数据集、及 Trajectron++ 与 Grip++ 模型上，实现了 41%-81% 的意图误分类成功率，扰动幅度低于 0.45 米；预测误差提升 1.9-4.2 倍。

方法描述

  • 输入传感器：原文未明确报告。
  • 场景表示：以历史轨迹序列（空间坐标）和上下文信息构成的场景表示。

Card 06 评估与结果

评估与结果

  • 评估测试模型：Trajectron++、Grip++，以及带语义地图信息的 Trajectron++(m)，共五种实验设置，每种设置使用 100 个随机场景。
  • 评估基准：nuScenes 与 Apolloscape。
  • 评估指标：

- 意图误分类：左/右/前/后方向偏移量及攻击成功率（ASR）。

- 预测精度降级：ADE、FDE、MR、ORR 和 MSE。

  • 关键数值：意图误分类 ASR 为 41%-81%；预测误差 ADE 提升 1.9-4.2 倍，FDE 提升 1.8-3.9 倍；扰动幅度 MSE 介于 0.12-0.45 米。在 Apolloscape 上，Grip++ 的 MR 从 8% 增至 61%，Trajectron++ 从 3% 增至 55%。
