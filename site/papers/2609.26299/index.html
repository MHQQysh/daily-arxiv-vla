Card 02 论文概述

论文概述

Card 03 核心贡献

核心贡献

  • 提出 ForeDrive，学习规划相关的潜在表示，并将多时域潜在预测与轨迹生成进行非对称耦合：规划梯度更新共享在线编码器，而 stop-gradient 路由阻止规划梯度更新潜在预测器，从而减少预测—规划梯度干扰。
  • 引入面向规划的接口，包括门控视觉融合（gated visual fusion）、未来状态注入（future-status injection）与轨迹自适应偏置（Trajectory-Adaptive Bias, TAB），把预测未来动态注入扩散规划过程，并保持当前观测为主要证据。
  • 使用 JEPA 风格的在线/EMA 预测器估计多时域视觉与自车状态潜在表示，无需像素重建，也不需要单独训练阶段。
  • 在 NAVSIM v1 与 v2 上以 camera-only、纯模仿学习协议取得 89.9 PDMS / 90.0 one-stage EPDMS，推理时仅使用单张前视图图像。
  • 通过零样本迁移到 nuScenes，验证跨数据集泛化能力。
Card 04 方法描述

方法描述

  • 所属模块：包括规划相关的潜在世界模型模块与基于 DiT 的生成式规划器模块，二者通过非对称潜在优化联合训练。
  • 输入传感器：默认骨干为 DINOv3 ViT-B/16，输入 256×512 前视图像；推理时仅使用当前前视图图像。未来图像仅在训练时用于构造目标，推理时不可用。
  • 场景表示：采用潜在表示而非像素重建；在线编码器将当前前视图图像映射为 N 个 patch token，配合自车状态 token；未来时域 t∈{1,2,3,4}s 使用可学习 query token。
  • 模型结构：

- 规划相关潜在世界模型：JEPA 风格在线/EMA 编码器，EMA 目标编码器仅复制视觉编码器；Transformer 预测器在帧级块因果掩码下单次前向预测多时域潜在与状态；监督包含时域加权潜在回归 L1 与状态预测（导航命令 CE + 自车运动 MSE）。

- 未来引导生成规划：当前 token 保持在残差路径，未来潜在经门控视觉融合（sample-shared gate）与未来状态注入构成规划器记忆；采用粗到细 DiT 解码器、截断扩散与固定轨迹锚点（20 个锚点，4s 时域，输出 τ∈R^{8×3}）；训练损失为 sigmoid focal 分类损失与 L1 回归损失之和，推理使用两步截断 DDIM 并按分类头 argmax 选择模式。

- Trajectory-Adaptive Bias（TAB）：将每个模式的 BEV 轨迹候选投影到前视图，构建视觉 token 上的软高斯邻近场，并将其 log affinity 加入交叉注意力 logits；在去噪阶段边界重算，应用于两个解码器阶段的所有层。

- 非对称潜在优化：规划损失更新共享编码器 E_θ、融合模块 F 与规划器，但不更新潜在预测器 P_ψ；潜在与状态目标训练 P_ψ；EMA 目标编码器通过指数移动平均跟踪 E_θ；注入的未来潜在保持 stop-gradient；总损失为 L = λ_traj L_plan + λ_z L_lat + λ_s L_status，单阶段联合优化。

  • 关键技术：多时域潜在预测、门控融合、未来状态注入、TAB、stop-gradient 非对称优化、截断扩散 DiT。

Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM v1 navtest（PDMS 主指标，含 NC、DAC、TTC、Comf.、EP 子指标）；NAVSIM v2 navtest（one-stage non-reactive EPDMS 主指标，含 NC、DAC、DDC、TLC、EP、TTC、LK、HC、EC 子指标）；nuScenes 验证集（VAD / ST-P3 协议，L2 与碰撞率）。
  • 评估条件：NAVSIM 为非反应式仿真；nuScenes 为零样本开环评估。未报告闭环或实车实验。
  • 关键数值（NAVSIM v1）：ForeDrive（ViT-B/16）取得 89.9 PDMS，NC 98.6、DAC 97.6、TTC 95.6、Comf. 100.0、EP 83.8；ViT-L/16 达到 90.4 PDMS；三个随机种子 PDMS 在 89.7–89.9，标准差 0.1。
  • 关键数值（NAVSIM v2）：ForeDrive（ViT-B/16）取得 90.0 one-stage EPDMS，NC 98.6、DAC 97.6、DDC 99.6、TLC 99.8、EP 87.6、TTC 97.9、LK 97.9、HC 98.3、EC 87.5；ViT-L 达到 90.6 EPDMS。
  • 关键数值（nuScenes 零样本）：ForeDrive 平均 L2 0.48 m、平均碰撞 0.11%，优于 DriveLaW（0.54 m / 0.19%）与 nuScenes 训练的 PWM (FT)（0.78 m / 0.16%）；DriveLaW 在 collision@3s 更低（0.19% vs. 0.23%）。
  • 对比方法：NAVSIM v1 包括 UniAD、TransFuser、PARA-Drive、DRAMA、ReCogDrive-IL、PRIX、DiffusionDrive、MeanFuser、DiffRefiner-R34、LAW、Epona、DriveVLA-W0、PWM、WoTE、DriveLaW；NAVSIM v2 包括 TransFuser、ReCogDrive-IL、PRIX、DiffusionDrive、DiffRefiner-R34、MeanFuser、World4Drive、Epona、DriveVLA-W0、WorldRFT、Drive-JEPA、Latent-WAM；nuScenes 包括 PWM (FT)、Epona、DriveLaW。
  • 消融结果：Base 88.9 PDMS，Base+TAB 89.5（+0.6），Base+WM 89.6（+0.7），Base+WM+TAB 89.9（+1.0）；未来表示组件消融中 Full WM 为 89.6（+0.7）；训练范式对比中 Full joint (ours) 取得 89.9 PDMS，优于 two-stage/freeze WM（87.9）与 Joint + detach encoder（88.6）；潜在融合策略中 Gated fusion 为 89.4，Current only 为 88.9（-0.5），Future only 为 84.2（-5.2）。
