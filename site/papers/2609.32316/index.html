Card 02 论文概述

论文概述

  • 论文面向城市信号交叉口的自动驾驶场景，研究交通信号的感知与下游规划之间的语义断层问题。
  • 论文指出，现有交通信号感知主要以实例级检测或颜色识别来表述，只能回答“信号灯在哪里、是什么颜色”，无法直接说明“哪一盏信号灯控制自车的哪一种机动动作”。
  • 论文将任务重新表述为 Directional Traffic Signal Understanding，即从单张前视图像出发，为直行、左转、右转、掉头四种自车机动动作预测结构化的信号状态。
  • 每个方向的信号状态包含关联的信号颜色（none/red/green/yellow）以及信号所隐含的可通行性（go/stop），预测的是信号层面的许可，而非最终机动的可行性。
  • 下游规划器可将该信号层面的意图与车道拓扑、路线约束、周围智能体及其他交通规则进一步融合。
Card 03 核心贡献

核心贡献

  • 首次将 Directional Traffic Signal Understanding 表述为一个统一任务，把交通灯定位、状态识别、方向解释和信号—机动关联整合到机动级可通行性预测中。
  • 基于 OpenLane-V2 构建了方向级交叉口基准，提供机动级监督，并设计了覆盖信号识别、机动级可通行性、结构化一致性和安全关键错误的统一评测协议。
  • 提出方向感知基线模型，融合全局场景上下文、局部交通灯证据和机动专属表示，无需在推理时依赖精确的静态道路拓扑。
  • 通过实验表明方向级建模在可通行性预测上优于图像级分类器和面向检测的流水线，尤其在复杂多信号交叉口处表现更明显。
  • 提供了一种直接、可解释、面向规划的交通信号接口，可与拓扑、路线和周围智能体信息一起供下游规划使用。
Card 04 方法描述

方法描述

  • 所属模块：面向决策的交通信号感知模块，位于交通灯感知与下游规划之间的接口层，不构建完整规划系统。
  • 输入传感器：仅使用自车前视相机图像，不需要毫米波雷达、激光雷达等其他传感器；原文未报告多传感器融合设置。
  • 场景表示：以自车为中心的机动方向集合 D={straight, left, right, U-turn}，每个方向表示为 y^d=(c^d, p^d)，其中 c^d 为信号颜色、p^d 为信号隐含可通行性；预测输出为 Ŷ=(ŷ^s, ŷ^l, ŷ^r, ŷ^u)。
  • 模型结构：视觉骨干网络加 FPN 提取多尺度特征 F=FPN(Backbone(I))；对特征金字塔做池化得到全局 token g，表示整体交叉口上下文；使用轻量 DETR 风格检测器生成交通灯边界框，对每个框 b̂_j 通过 RoIAlign 提取局部外观并结合空间信息构造 ROI token t_j=φ_r(RoIAlign(F,b̂_j))+φ_b(b̂_j)；将全局 token 与所有 ROI token 拼接成统一 token 序列 T=[g,t_1,…,t_K]。
  • 方向感知预测：引入四个可学习方向查询，分别对应直行、左转、右转、掉头，每个查询对统一 token 序列做多头注意力 h^d=MHA(q^d,T,T)；再由颜色头预测 {none,red,yellow,green}、通行性头预测 {stop,go}，即 ĉ^d=Head_color(h^d)、p̂^d=Head_pass(h^d)。
  • 关键技术：方向查询注意力实现信号证据与自车机动的关联，避免推理时手工设计信号—机动分配；颜色与可通行性双头输出结构化状态。
  • 训练目标：颜色交叉熵损失 L_color、可通行性交叉熵损失 L_pass，以及 DETR 二部匹配检测损失 L_det（含分类、框回归和 GIoU 损失），总损失为 L=λ_c L_color+λ_p L_pass+λ_d L_det。
  • 原文未报告各项损失权重的具体取值、检测器层数、FPN 之外的具体网络超参数。
Card 05 数据集与资源

数据集与资源

  • 数据集：基于 OpenLane-V2 构建方向级机动可通行性基准，使用其前视图像、交通元素、车道结构和拓扑标注。
  • 数据规模：训练集 23,904 帧、验证集 5,147 帧，对应 95,616 和 20,588 个方向级状态。

  • 数据分布特点：直行、左转、掉头方向具有密集有效信号监督，右转方向更多被标为 none。
