Card 02 论文概述

论文概述

  • 论文面向自动驾驶场景中的未来 3D 几何预测任务，基于 VGGT / VGGT-World 几何世界模型展开研究。
  • 应用场景为自动驾驶车辆在城市道路（NAVSIM/OpenScene，2 Hz）中，根据历史观测、给定自车轨迹与驾驶语义预测未来两帧的几何 token、深度与 3D 结构。
  • 研究问题：VGGT-World 的未来演化主要由历史观测决定，未显式以驾驶意图与自车动作为条件，因而难以区分车道保持、变道、让行等不同行为导致的不同物理未来；同时语义 token、动作 token 与几何 token 处于不同表示空间，难以直接融合。
Card 03 核心贡献

核心贡献

  • 在 VGGT-World 上引入语义与动作条件，实现可控的未来 3D 世界演化，使同一观测在不同自车动作下可产生不同的未来几何预测。
  • 提出几何–语言–动作桥（geometry–language–action bridge），适配历史几何特征、VLA 语义特征以及多表示（maneuver + 轨迹）自车动作，用于未来几何预测的联合条件化。
  • 设计动作–语义 3D 世界演化模块，在流变换器的每个双流块后依次注入动作与语义交叉注意力条件，并采用条件流匹配与未来深度监督进行训练。
  • 在 NAVSIM 上验证潜在预测质量、未来深度 RMSE 与阈值精度的提升（相对 VGGT-World RMSE 降低 13.7%，δ1 提升 4.11 个百分点），并通过动作表示消融与动作输入干预实验支持模型对场景对齐动作信息的利用。
Card 04 方法描述

方法描述

  • 所属模块：几何–语言–动作桥与动作–语义 3D 世界演化两大模块，世界模型主干沿用 VGGT-World（冻结的 VGGT 几何 token + 流变换器），预测结果由预训练 VGGT 解码器解码为未来深度与 3D 几何。
  • 输入传感器：几何分支输入单一相机流的两个历史帧；语义分支输入条件时刻的多相机观测与文本提示；动作输入为给定的自车轨迹（8 个自车坐标系航点）及其 maneuver 描述符。具体相机数量、分辨率等原文未报告。
  • 场景表示：以 VGGT 几何 token（1,024 通道）表示场景，世界模型在 token 空间而非 RGB 空间预测未来；预测未来 token 与历史 token 拼接后经 VGGT 第二阶段聚合器与深度头解码。
  • 模型结构：流变换器内部宽度 512、8 个注意力头，包含 8 个双流块与 8 个单流块；每个双流块后依次接动作交叉注意力与语义交叉注意力（各自独立、逐层参数），再进入单流块。动作编码器将 one-hot maneuver、航点位置、位移与归一化时间索引组合为 8 个航点 token 加 1 个 summary token；语义分支取 Qwen2.5-VL 第 22 层隐状态，经归一化与线性投影后用 16 个可学习 query 做 8 头交叉注意力压缩为定长语义 token（构建语义输入时移除 assistant 侧回答）。
  • 关键技术：条件流匹配（插值状态 x_t=(1−t)x_0+t x_1，端点预测参数化，速度场回归，推理 10 步 Euler 采样）；未来几何监督使用冻结 VGGT 教师对完整真实四帧序列生成未来深度伪目标，采用 log 深度 Smooth L1 损失，世界模型目标为 L_world = L_flow + λ_d L_depth；深度损失直接作用在采样流时刻的预测上。轨迹监督仅作为联合微调中的辅助项，姿态与点输出不额外加损失。

数据集与资源

Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM 3,000 clip 运动子集，stride 1、10 步流采样，指标在 clip 上平均；所有方法使用相同 clip，并与预训练 VGGT 由真实未来图像生成的伪真值比较。
  • 评估指标：深度 AbsRel、RMSE、δ1；潜在表示 Token MSE、余弦相似度；3D 点 Point EPE 与相对 Point EPE。评估为离线开环几何预测评估，非闭环规划评估，非实车。
  • 关键数值（主结果，Table 1）：VGGT-World 为 Token MSE 0.011065、Cosine 0.769799、AbsRel 0.385980、RMSE 0.426050、δ1 0.418000；VGGT-World-N（NAVSIM 视觉条件续训）为 0.010620、0.781621、0.376136、0.436463、0.348113；本方法为 0.010459、0.785120、0.392457、0.367831、0.459124。相对 VGGT-World RMSE 降低 13.7%、δ1 提升 4.11 个百分点；相对 VGGT-World-N RMSE 降低 15.7%、δ1 提升 11.10 个百分点；AbsRel 略有上升，VGGT-World-N 的 AbsRel 最低。
  • 对比方法：原始 VGGT-World、在 NAVSIM 上视觉条件续训的 VGGT-World-N；以及动作表示消融中的 One-hot、Trajectory、Trajectory + velocity、Joint，和 Joint 与 Joint + VLM 的对比。
  • 消融结果：Joint 动作表示在深度与点误差上最优（AbsRel 0.39320、RMSE 0.37093、Point EPE 0.35807、Point Rel. EPE 0.36842），One-hot 的 Token MSE（0.01019）与 δ1（0.45279）最优；动作输入干预中，正确动作在 Token MSE、AbsRel、RMSE、Point EPE 上最低（0.010459、0.392457、0.367831、0.354330），错 maneuver 输入退化最大；Joint + VLM 相对 Joint 在所有报告指标上均有小幅提升（如 RMSE 0.370929→0.367831）。定性上，固定历史、语义与初始噪声时，左转输入使场景结构右移、右转使其左移。
  • 局限（原文报告）：语义信息带来的增益有限，VLA 模块带来额外计算开销可能限制实时推理频率；未来工作计划探索多动作 rollout 与闭环规划评估。
