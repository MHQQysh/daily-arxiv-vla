WM-Cov: Test Adequacy for Interactive World-Model-Style Autonomous Driving Simulation

2026-07-31 · 原文 · 翻译 · 2608.00298

论文研究交互式世界模型（World-Model）风格的自动驾驶仿真测试充分性（Test Adequacy）问题。 该任务用于安全验证与仿真测试场景覆盖评估，研究对象是“交互式场景族”（interactive scenario family），即由地图、路线、初始条件、环境条件、背景代理策略、提示词和种子分布构成的场景集合，其演化依赖被测的自我规划器。 研究问题是：在交互式世界模型仿真中，需要多少闭环证据才能支持停止或继续测试的决策，而不仅仅是能否生成危险场景。

Card 02 论文概述

论文概述

  • 论文研究交互式世界模型（World-Model）风格的自动驾驶仿真测试充分性（Test Adequacy）问题。
  • 该任务用于安全验证与仿真测试场景覆盖评估，研究对象是“交互式场景族”（interactive scenario family），即由地图、路线、初始条件、环境条件、背景代理策略、提示词和种子分布构成的场景集合，其演化依赖被测的自我规划器。

Card 03 核心贡献

核心贡献

  • 将交互式世界模型风格的自动驾驶测试形式化为关于场景族的充分性与停止问题，区别于固定回放轨迹。
  • 提出 WM-Cov：一个与提供者无关（provider-agnostic）的评估层，跟踪请求覆盖、实现覆盖和有效实现覆盖。
  • 定义包含覆盖增长、有效失败发现、失败模式多样性、伪像剔除、重复计数、真实性、有效证据精度等内容的充分性报告。
  • 在多种数据来源（执行的 TeraSim/SUMO 日志、混合轨迹池、DriveArena 轨迹）和真实闭环 DriveArena–WorldDreamer 提供者矩阵上评估该框架，使用 UniAD 和 VAD 规划器。
Card 04 方法描述

方法描述

  • 所属模块：世界模型或生成式模拟器之上的评估层，不修改生成器本身。
  • 输入传感器：原文未报告具体传感器输入。
  • 场景表示：交互场景族 ℱ(q) = {m, ρ, x₀, e, π_bg, p, 𝒵}，每条轨迹映射为特征向量 φ(τ) = (o, u, r, b, f, v)，分别对应 ODD、交互类型、风险分箱、行为类别、失败模式、有效性标签。
  • 模型结构：WM-Cov 由 Trace Adapter（轨迹适配器）、Feature Taxonomy（特征分类）、Validity Ledger（有效性账本）、Budgeted Selector（预算选择器）和 Adequacy Report（充分性报告）组成；四个模块流程为轨迹摄入、特征分类、有效性审计、预算选择。
  • 关键技术：区分请求覆盖 C_req→real、实现覆盖 C_real→valid、有效覆盖 C_valid；用有效性账本区分有效失败、有效安全临界、有效安全、重复失败、条件失败、伪像/无效事件；提供停止准则（覆盖增长、失败发现和不确定性低于阈值）；预算化选择采用贪心策略，选择得分最大的轨迹或滚动请求。

Card 06 评估与结果

评估与结果

  • 评估基准：DriveArena–WorldDreamer 矩阵，评估 2 个规划器（UniAD、VAD）、2 个水平（horizon）、6 个提示条件、360 个 ego 路线请求；此外用 80 个分离路线切片检查判断会计行为是否在同一的 ego 路线切片之外持续。
  • 评估指标：覆盖增长、有效失败发现（VF）、失败模式多样性（FM）、伪像计数（AI）、重复计数、真实性（Q）、风险（R）、有效证据精度 Πv = VF/(VF+AI)。
  • 关键数值：主矩阵中 304 次尝试成为完全实现的证据，56 次保持部分实现；分离切片中 80 次中有 74 次完全实现、6 次部分实现；1219 个 TeraSim/SUMO 事件中 529 个有效、690 个伪像失败；在 B=100 预算下选中候选的 99/100 和 76/100 为有效失败、零伪像。
  • 对比方法：随机选择、仅风险选择、仅真实性选择、仅覆盖选择作为基线与预算化选择进行对比。
  • 开环/闭环/仿真/实车条件：所有评估均在闭环世界模型仿真条件下进行（DriveArena/TeraSim/SUMO），未涉及实车测试；部分使用日志回放作为受控代理。
