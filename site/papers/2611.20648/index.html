Card 02 论文概述

论文概述

  • 论文面向自动驾驶中视觉–语言–动作（VLA）模型的交通规则合规性问题：准确的动作预测并不等同于遵守交通法规。
  • 应用场景为基于 CARLA 仿真器采集的自动驾驶场景，涵盖住宅区、城市、高速公路、多车道、晴天/雨天以及行人过街等条件。
  • 研究问题为：如何将英国《Highway Code》中选定的条款形式化为可执行的一阶逻辑规则，并把符号规则反馈引入 VLA 策略优化，从而在保持与专家动作一致性的同时提升规则合规性。
Card 03 核心贡献

核心贡献

  • 提出一个 VLA 微调框架，将符号交通规则反馈纳入策略优化，同时通过与专家动作的模仿惩罚项鼓励行为一致性。
  • 将选定的英国《Highway Code》条款（限速适应、安全跟车距离、道路使用者优先权）形式化为可执行的一阶逻辑规则，并构建符号评估器，对候选动作进行上下文相关的合规性判定。
  • 在离线评测中比较 GRPO、GDPO 与 Dr. GRPO 三种基于组的强化学习方法，考察其对动作预测精度与编码规则合规性的影响。
  • 通过逐规则消融实验分析各条符号规则对策略改进的单独贡献。
Card 04 方法描述

方法描述

  • 所属模块：规则引导的 VLA 学习框架，包含监督微调（SFT）与规则引导强化学习微调（RLFT）两阶段，以及独立的符号交通规则评估器。
  • 输入传感器：前视 RGB 图像作为视觉观测；自车状态与遥测信息（速度、朝向、加速度等）转为文本提示；高层导航指令作为文本输入。
  • 场景表示：由冻结的 Qwen2.5-VL-7B-Instruct 从图像中抽取布尔谓词（环境能见度、道路几何、障碍物类别、弱势道路使用者等），再经 PyReason 逻辑推理得到上下文因素，用于参数化规则阈值。
  • 模型结构：以 Qwen3-VL-2B-Instruct 为骨干；视觉与文本 token 构成共享多模态序列，并加入可学习的 [ACT_TOKEN]；动作头为带 GELU 的 MLP 输出油门（sigmoid，[0,1]）与转向（tanh，[-1,1]），语言头自回归生成推理文本。
  • 关键技术：SFT 联合优化动作 MSE 损失与推理文本的下一 token 预测损失；RLFT 从高斯分布采样一组候选动作，用运动学自行车模型在短时域 Δt 内投影自车状态，再由符号评估器给出满足（+1）、不满足（-1）或未激活（0）的评分，形成含规则项与模仿惩罚项的复合奖励，采用无 critic 的裁剪组相对策略优化；比较 GRPO、GDPO、Dr. GRPO 三种优势构造方式。
  • 原文未报告：运动学自行车模型的具体参数、状态投影时域 Δt 的具体数值、动作采样协方差 Σ 的具体取值。
Card 05 数据集与资源

数据集与资源

  • 数据集：在 CARLA 仿真器多地图、多天气条件下采集的前视 RGB 图像，SFT 使用约 20,000 张图像并按 80/20 划分训练/验证；评测使用约 3,600 张图像的留出测试集；测试集覆盖行人过街、雨天、高速公路等场景。
  • 仿真器：CARLA。

Card 06 评估与结果

评估与结果

  • 评估基准：CARLA 仿真器采集的约 3,600 张留出图像上的离线评测；每个样本预测未来五个时间步的车辆轨迹。未进行闭环或实车评测（原文为离线评估）。
  • 评估指标：油门与转向的 MAE/RMSE、欧氏 MAE/RMSE；总体规则通过率与违规率；逐规则符号合规分数（-1 到 +1，仅在规则激活帧上平均）；条件级场景合规率；以及逐规则消融。
  • 对比方法：SFT 基线，以及 GRPO、GDPO、Dr. GRPO 三种 RLFT 变体；每个方法用三个随机种子报告均值±标准差。
  • 关键数值：Dr. GRPO 取得最佳总体通过率 97.59%±0.50（SFT 92.93%±1.00，GRPO 97.34%±0.50，GDPO 97.39%±0.50），违规率 2.41%±0.50；油门 MAE 19.16%±0.02、转向 MAE 5.36%±0.20、欧氏 MAE 40.57%±0.05、欧氏 RMSE 45.01%±0.10，均为最优。
  • 逐规则合规分数：安全速度规则 SFT 0.9200，三种 RLFT 均达 1.0000；安全距离规则 SFT 0.7468，GDPO 与 Dr. GRPO 为 0.7975；道路使用者优先权规则 SFT 为 -1.0000，GRPO 与 GDPO 为 0.8820，Dr. GRPO 为 1.0000（评估样本中未观察到该规则违规）。
  • 训练动态：Rule H 违规率由 SFT 的近 100% 降至 Dr. GRPO 接近零并保持；安全速度规则初始违规率仅 2–3%，Dr. GRPO 多数时间低于 0.1%；安全距离规则三种方法在约 8%–16% 间持续波动，无明显收敛。
  • 条件级结果：安全速度在结冰路面场景 SFT 仅 43.6%，RLFT 提升 56.4 个百分点至完全合规；道路使用者优先权在 SFT 下所有行人相关场景合规率为零，Dr. GRPO 在所有评估条件下达到完全合规。
  • 行为分布：Dr. GRPO 直行时制动比例由 GRPO/GDPO 约 30% 升至 38.7%，加速比例由约 10% 降至 4%。
  • 消融结果（Dr. GRPO）：移除 Rule H 使其违规率由 0.0% 升至 6.1%；移除 Rule 126 使安全距离违规率由 5.9% 升至 8.0%；移除 Rule 125 影响很小；移除单条规则对油门/转向 MAE 影响很小。
