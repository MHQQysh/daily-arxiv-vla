Card 02 论文概述

论文概述

  • 论文构建了名为 AnchorReasoning 的视觉 grounding 与因果推理数据集，面向长尾自动驾驶场景。
  • 任务面向 Vision-Language Models（VLMs），为其提供连接决策关键视觉证据与推理、规划过程的监督。
  • 应用场景为长尾自动驾驶，即罕见且复杂、需要深入理解驾驶上下文并进行审慎推理的情形。
  • 研究问题在于：现有驾驶数据集在将决策关键视觉证据与推理及规划相连接方面监督有限，缺乏细粒度、以决策为中心且带视觉 grounding 的推理标注。
Card 03 核心贡献

核心贡献

  • 提出 AnchorReasoning，一个面向 VLM 训练的长尾驾驶数据集，提供决策相关视觉 grounding、细粒度元素属性与语义，以及结构化推理标注，使模型能够识别、定位并正确解释真正影响驾驶决策的元素。
  • 提出一种基于课程的 Supervised Fine-Tuning（SFT）策略，遵循 VG-CoT 结构，使模型逐步获得视觉 grounding、元素含义、驾驶动作理由、行为规划与轨迹生成能力。
  • 提出一种物体尺寸感知的视觉 grounding 指标，使用尺度自适应的 point-to-mask 距离评估预测 grounding 点，为不同尺寸元素提供一致的定位质量度量。
  • 数据集基于 WOD-E2E 构建，包含 416,119 个标注帧与 395,379 个决策关键元素，覆盖 4 个大类与 19 个细粒度类型。
Card 04 方法描述

方法描述

  • 所属模块：面向 VLM 的数据集构建、视觉 grounding 与因果推理监督，以及课程式监督微调（Curriculum-Based SFT）。
  • 输入传感器：原文报告使用三摄像头图像（three-camera images）进行 grounding 定位；其他传感器信息原文未报告。
  • 场景表示：每一帧组织为 VG-CoT（visually grounded chain-of-thought），依次包含观察与 grounding、元素含义、驾驶动作理由、驾驶动作与轨迹规划。
  • 数据集标注内容：包含场景级上下文与事件级交通信息；决策关键元素分为 vehicles、vulnerable road users（VRUs）、obstacles、traffic-control elements 四类；元素属性包括 type、location、state、intention、impact rank，交通控制元素还包括交通灯状态、标志语义与临时交通控制描述；每个元素关联 implication，最终推理与规划阶段整合多个元素级 implication 生成横纵向动作与未来轨迹。
  • 标注流程：采用 human-in-the-loop 混合流程，结合人工判断、VLM 辅助标注、promptable segmentation 与规则方法；Qwen3-VL 生成场景上下文标签，人工标注交通事件；每帧最多保留 5 个决策关键元素；人工提供 point prompts，SAM3 生成实例 mask 与 bounding box；复杂场景使用 GPT-5.2，简单场景使用本地部署 Qwen3-VL；交通灯状态使用 HSV 规则判断。
  • 课程式 SFT：Stage I 聚焦感知与 grounding，含 phase a（场景上下文、交通事件、二值决策关键元素存在性）与 phase b（元素识别、视觉 grounding、impact ranking、属性理解）；Stage II 从 Stage I 最优 checkpoint 初始化，监督完整 VG-CoT 链，冻结视觉编码器，并对子集样本施加 trajectory-only 监督。
  • 训练目标：结合 VG-CoT 链损失与轨迹损失，公式为 L = L_chain + λ L_traj，λ 设为 1；Stage I 仅优化 L_chain，Stage II 联合优化两者；使用课程感知权重 w_t = m_t^(s) W_φ(t) ρ_t，其中 m_t^(s) 为阶段相关监督门控，W_φ(t) 为字段基础权重，ρ_t 调整信息性或欠代表目标贡献。

Card 06 评估与结果

评估与结果

  • 评估基准：基于 WOD-E2E 的长尾驾驶数据；评估场景级语义、决策关键元素理解、推理、轨迹预测与推理效率；同时评估视觉 grounding 消融。
  • 评估指标：Context Acc.、Traffic Event F1、Presence Acc.、Element Recall、Rank-1 Recall、Element Type Acc.、Point-in-Mask Rate、Element State Recall、Element Intention Recall、Traffic Control-Content Recall、R/G Conf.、Element Implication、Driving Action Rationale、ADE@1s/3s/5s、FDE@5s、RFS Frame、RFS Cluster、平均 tokens、推理延迟（s/frame）。

  • 对比方法：Base 表示在原始 WOD-E2E 数据上训练的领域适应模型，VG-CoT 表示同一模型使用 AnchorReasoning 的 VG-CoT 监督训练；Table 2 与 Table 3 均报告 Base / VG-CoT。
  • 评估条件：论文报告的是基于 WOD-E2E 数据集的模型评估，未报告闭环仿真或实车评估；Base 与 VG-CoT 的对比属于在相同模型基础上的监督效果比较，原文未明确说明为开环、闭环、仿真或实车条件，若需区分则原文未报告。
  • 主要结论：VG-CoT 监督使多个 Base 模型具备场景级与元素级预测能力，并提升决策关键元素识别与 grounding；Element Implication 持续高于 Driving Action Rationale，说明理解单个元素影响比整合多因素形成最终驾驶决策更容易；动态行为理解（Element State 与 Intention Recall）仍比身份与交通控制语义识别更难。
