DPA-I2P: Depth-Guided Projective Alignment for Image-to-Point-Cloud Registration in Autonomous Driving

Card 02 论文概述

论文概述

  • 本文解决自动驾驶中的图像到点云（Image-to-Point Cloud，I2P）配准任务，即估计给定图像在三维场景点云中的相机位姿。
  • 该任务属于自动驾驶中的视觉定位、相机重定位、SLAM、运动规划与三维重建等应用的基础问题。
  • 研究问题在于密集二维图像观测与稀疏三维点云表示之间存在固有的模态差异，导致跨模态对应学习不稳定，进而影响位姿估计精度。
Card 03 核心贡献

核心贡献

  • 提出 DPA-I2P，一个深度感知的隐式对应学习框架，用于鲁棒的端到端图像到点云配准，通过集成度量深度与投影感知的视觉线索构建更具判别性的跨模态特征空间。
  • 引入 Ray-Conditioned Metric Depth Encoding（RMDE），以结构化、几何感知的方式将单目度量深度线索注入图像特征，增强图像侧的几何感知能力。
  • 引入 Projection-Consistent Vision Lifting（PVL），在粗位姿先验下将投影一致的视觉信息转移到点特征中，改善跨模态几何一致性。
  • 提出 Cross-Modal Query Pruning（CQP），在早期细化阶段抑制不可靠的对应查询，提高对应细化的稳定性与鲁棒性。
  • 在 KITTI 上 DPA-I2P 的 RTE 和 RRE 分别比最强隐式基线降低 45.0% 和 55.6%，在 nuScenes 上也提升了配准精度，展现出良好的跨场景迁移能力。
Card 04 方法描述

方法描述

  • 所属模块：图像到点云配准中的隐式对应学习框架。
  • 输入传感器：单目相机图像与 LiDAR 点云。
  • 场景表示：三维场景点云与二维图像特征的多尺度特征金字塔表示。
  • 模型结构：4 阶段 ResNet 与 FPN 作为图像骨干，4 阶段 KPFCNN 作为点云骨干，两者均输出 128 维特征；使用 4 头注意力，对应查询数 N_q=128，细化深度 L=3。
  • 关键技术：

- RMDE：利用冻结的 UniDepthV2 生成度量深度图与置信度图，沿每条视角射线基于预测深度表面采样 N 个候选点，结合射线方向、三维位置、深度偏移与置信度构造几何描述子，通过置信度加权聚合与门控残差更新注入图像特征。

- PVL：利用粗位姿先验将三维点投影到图像特征平面，收集对应图像特征并经投影层转换后以有界残差更新方式注入点特征，仅在早期阶段启用。

- CQP：基于前序位姿估计构建密集投影支撑先验，在早期细化阶段抑制支撑度极低的区域中的不可靠查询，并配合支持引导的正则化损失。

- 损失函数：包含位姿回归损失（平移 L1 与旋转测地线距离）和支持引导的 KL 散度正则化损失，先独立优化粗位姿分支再端到端训练。

Card 05 数据集与资源

数据集与资源

  • 数据集：KITTI（22 个同步图像–LiDAR 序列，其中 11 个提供真值标定）、nuScenes（官方 150 个测试场景）。
  • 数据集配置：KITTI 图像调整为 160×512，点云下采样至 40,960 点；nuScenes 图像调整为 160×320，点云从相邻帧累积后均匀下采样至 40,960 点。
  • 度量深度估计器：UniDepthV2，预计算深度与置信度图并冻结，不进行微调。
  • 模型规模：图像与点云骨干均输出 128 维特征。
  • 训练资源：单张 NVIDIA RTX 4090 GPU，训练 40 个 epoch，batch size 4，初始学习率 2×10⁻⁴，权重衰减 10⁻⁶，Adam 优化器。

Card 06 评估与结果

评估与结果

  • 评估基准：KITTI（序列 0–8 训练，9–10 评估）、nuScenes 定性评估。
  • 评估指标：平均相对平移误差（RTE）、平均相对旋转误差（RRE）、配准准确率（Acc，定义为 RTE<2m 且 RRE<5° 的比例）。
  • 关键数值（KITTI）：DPA-I2P 的 RTE 为 0.11±0.12 m，RRE 为 0.55±0.67°，Acc 为 99.70%，优于所有对比方法。
  • 关键数值（nuScenes）：DPA-I2P 的 RTE 为 0.54±0.37 m，RRE 为 1.92±3.81°，Acc 为 92.02%，优于评估的基线方法。
  • 对比方法：Grid Cls.+PnP、DeepI2P(3D)、DeepI2P(2D)、CorrI2P、VP2P-Match、ICLI2P。
  • 与最强隐式基线 ICLI2P 相比，RTE 从 0.20 m 降至 0.11 m，RRE 从 1.24° 降至 0.55°，Acc 从 97.49% 提升至 99.70%。
  • 消融实验（KITTI）：去除 RMDE 后 RTE 升至 0.12 m，RRE 升至 0.58°，Acc 降至 99.61%；去除 PVL 后 RRE 升至 0.74°（最大退化）；去除 CQP 后 RTE 升至 0.18 m，Acc 降至 98.82%（最显著退化）。
  • RMDE 组件分析：直接拼接深度图仅将 RRE 从 0.58° 降至 0.57°，Acc 从 99.61% 提升至 99.63%；加入射线方向后 RRE 为 0.57°，Acc 为 99.64%；编码表面点后 RRE 为 0.56°，Acc 为 99.66%；沿射线多点采样进一步提升至 RRE 0.56°、Acc 99.67%；去除置信度感知聚合后 Acc 降至 99.66%。
  • 实验条件：开放集评估（KITTI 定量与定性、nuScenes 定性），未涉及闭环或仿真实验。
  • 定性结果：在 KITTI 和 nuScenes 上通过将预测位姿投影点云至图像空间进行可视化，DPA-I2P 的投影点与图像结构对齐更准确；2D–3D 对应可视化表明其能建立更可靠的对应关系。
