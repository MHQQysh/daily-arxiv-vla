论文概述

  • 任务：端到端（E2E）自动驾驶的轨迹规划，在基础规划器输出的候选轨迹基础上进行后验反思与轨迹改进。

Card 03 核心贡献

核心贡献

  • 提出 EvoAD 自进化自动驾驶框架，通过后验反思使系统在部署后改进，而无需重新训练或替换基础模型。
  • 重新定义世界模型的角色为后验反思评估器，在紧凑的规划导向潜空间中想象候选轨迹的未来后果，用于轨迹评估而非直接规划。
  • 引入基于 BEV 特征的情节记忆与检索机制，存储场景表示、轨迹、未来潜变量与评估反馈，并按几何与语义相似度检索相关经验以支持后续决策改进。
  • 构建未来感知轨迹评估器（FAE）与检索引导的规划感知精修器（PAR），将执行的驾驶结果转化为可复用的改进信号，形成多轮迭代自进化推理循环。
Card 04 方法描述

方法描述

  • 所属模块：规划后处理/轨迹评估与精修模块，包含场景编码器、安全过滤器（SF）、带未来感知评估器（FAE）的潜世界模型、规划感知精修器（PAR）与情节记忆。
  • 输入传感器：观测由传感器观测、原始自车状态、地图上下文与导航命令组成；原文未报告具体传感器类型与配置。
  • 场景表示：以 BEV 特征表示场景，记忆条目包含场景嵌入、选中轨迹、实测反馈总分与子分数、以及每条轨迹的未来潜变量。
  • 模型结构：

- 基础规划器 π 生成 K 个候选轨迹；安全过滤器先剪除明显不可行候选。

- 潜世界模型 LatentWM 以观测与候选轨迹为条件输出未来潜表示，并与自车状态、候选轨迹拼接为未来潜增强表示。

- FAE 依次进行候选内自注意力编码、以骨干场景特征做跨注意力融合（带残差与可学习门控）、集合级候选交互自注意力，再由排序头与辅助分数头解码；训练损失为列表排序损失、子分数损失与分数损失的加权和。

- PAR 将轨迹、场景特征、自车状态与规划反馈嵌入为四个 token 经轻量自注意力融合，用 FiLM 将反馈注入轨迹表示，MLP 解码残差修正与置信门控，通过门控残差更新得到精修轨迹；训练使用弱/强轨迹对与 L1/朝向回归损失，并随机丢弃反馈以支持推理时无分类器引导（CFG）。

- 情节记忆按余弦相似度 TopK 检索；每个场景至多保留一条记录，仅在分数提升时覆盖。

  • 关键技术：多轮迭代自进化推理，第 n 轮由 SF、FAE、执行后反馈与记忆写入构成，从第 2 轮起 PAR 利用检索记忆对上一轮选中轨迹进行修正并重新评估；最终输出第 N 轮轨迹。

Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM v1（PDMS）与 NAVSIM v2（EPDMS），另有 NavHard 反应式闭环评估。
  • 评估指标：NC（无责任碰撞）、DAC（可行驶区域合规）、TTC（碰撞时间）、Comf.（舒适性）、EP（自车进度）、PDMS、EPDMS。
  • 关键数值：

- 基于 WoTE 规划器，EvoAD 将 NAVSIM v1 PDMS 从 88.3 提升至 93.4，将 NAVSIM v2 EPDMS 从 84.2 提升至 91.5。

- 逐轮结果：R1 为 90.6 PDMS，R2 为 92.6 PDMS（EP 从 85.7 到 88.3，DAC 从 96.4 到 97.8），R5 达到 93.4 PDMS 与 91.5 EPDMS。

- 消融（NAVSIM v1 navtest，PDMS）：WoTE 88.33；GTRS+Memory 为 90.27/90.35/90.44（R1/R2/R5）；WoTE+SF+Memory 为 89.05/89.94/90.87；仅加 FAE 为 90.58/91.58/92.76；再加 PAR 为 90.58/92.61/93.36。

- 不同基础规划器 R2 相对原始输出的 PDMS 提升：TransFuser 84.24→89.79（+5.55）、DiffusionDrive 88.19→91.33（+3.14）、WoTE 88.33→91.24（+2.91）、iPad 91.91→94.02（+2.11）。

- 跨域记忆：navval 记忆在 18k 验证集经验时把 R2 PDMS 从 92.09 提升至 92.44；navtrain 记忆在 34k 样本规模达到 92.56。

- 反应式闭环：NavHard 上 EPDMS 从 R1 的 31.31 提升至 R11 的 41.37。

- 定性案例：信号化多车道路口 PDMS 从 58.3 提升至 98.4；右侧停车的窄街从 0.0 提升至 100.0；跨场景检索将信号化路口轨迹从 85.8 提升至 96.3，开放 T 型路口从 0.0 提升至 93.3。

  • 对比方法：UniAD、PARA-Drive、DRAMA、TransFuser、Hydra-MDP++、DiffusionDrive、WoTE、iPad、DrivoR、SparseDriveV2，以及消融中的 GTRS+Memory 等基线。
  • 评估条件：主要为 NAVSIM 开环/非反应式基准评估；NavHard 为周围智能体可响应自车的反应式闭环评估；原文未报告实车实验。
