Card 02 论文概述

论文概述

  • 任务：面向四足机器人（Unitree Go2）的城市导航，进行短时域、目标条件（goal-conditioned）局部轨迹规划。
  • 应用场景：人行道、道路与混合城市环境，缺少车道中心线与固定路线几何，需要处理障碍物、行人、地面变化以及下游运动控制的可跟踪性限制。
  • 研究问题：如何将面向车辆的端到端轨迹规划框架 DrivoR 适配到四足机器人场景，即在不大改核心解码器的前提下引入局部子目标条件化，并重新定义“可行驶区域合规”与“自车进展”两项评分准则，实现基于仿真的训练与零样本 sim-to-real 迁移。
Card 03 核心贡献

核心贡献

  • 提出 Go2-DrivoR：以目标 token 将轨迹生成条件化于当前自车坐标系下的局部前视路点（4 秒前视），保留 DrivoR 的视觉特征提取器、轨迹解码器、评分解码器与 winner-takes-all 轨迹目标。
  • 将原车辆中心的可行驶区域合规（DAC）重定义为面向人行道的语义区域评分（人行道=1，含道路但不越界=0.5，否则=0），并采用四足机器人足迹进行碰撞与 TTC 评估。
  • 将原始自车进展（EP）项改写为目标条件自车进展（GEP），融合原 EP 与目标指向进展（α=0.5），并将评分组件从六项减为五项（去掉驾驶方向合规 DDC）。
  • 仅在 TartanGround 仿真数据上训练，在未见仿真地图上提升路径点条件规划性能，并零样本迁移到真实 Go2 日志的开环轨迹预测。
Card 04 方法描述

方法描述

  • 所属模块：端到端轨迹规划（感知编码 + 轨迹候选生成 + 解耦评分排序）；输入为四路环视鱼眼图像、机器人本体状态、高层四向方向指令以及当前自车坐标系下的二维目标。
  • 场景表示：基于 DINOv2 预训练 ViT-S 骨干（LoRA 微调）与相机特定 register token，将每路相机图像压缩为紧凑场景 token 集合 F ∈ R^{Nc×Nr×D}；原文未报告 Nr、D 的具体数值。
  • 输入处理：本体状态（相对位姿、线速度与角速度、加速度、指令）经线性层得到 ego token；目标 (x,y) 以 d_scale=4 m 归一化后经线性层得到 goal token；两者拼接后再投影融合，并以残差方式加到每个可学习轨迹查询上，送入未改动的轨迹解码器。
  • 输出：K=64 条候选轨迹，每条为 4 秒时域内 0.5 秒间隔的 n_p=8 个 (x,y,θ) 路点，按预测综合得分选出最高分轨迹。
  • 关键技术：GEP 中目标进展项按候选轨迹端点位移在目标方向上的投影计算并裁剪到 [0,1]，再以 (1-α)·ep + α·goal 融合；综合评分在对数域组合（NOC 与 DAC 取对数相加，5·TTC+5·GEP+2·Comfort 取对数后相加）；评分头以逐组件 BCEWithLogits 独立监督，评分梯度不回流到轨迹解码器。
  • 原文未报告：模型参数量、推理是否含运动控制接口的闭环实现细节。
Card 05 数据集与资源

数据集与资源

  • 数据集：TartanGround 仿真数据集（多相机针孔图像重投影为前/左/右/后四路鱼眼、IMU、稠密语义点云），训练集含 14,192 个局部规划样本；评估使用已见 6 张地图/2,554 个场景与未见 3 张地图/2,707 个场景。

  • 训练资源：3 张 NVIDIA H200 GPU，全局 batch size 48，训练 20 个 epoch，AdamW，学习率 5×10⁻⁴，2 个 epoch 预热后余弦退火；开环推理单张 H200，batch 1 延迟 10.8 ms、batch 16 延迟 94.1 ms。

Card 06 评估与结果

评估与结果

  • 评估基准：TartanGround 开环（非反应式）评估（已见/未见地图划分）与真实 Go2 日志零样本开环评估；均为开环，原文未进行闭环或实车在线导航实验。
  • 仿真指标：NOC、TTC、DAC、GEP、Comfort 及改编的 PDMS 式综合分（式 9）；对比方法为恒速外推、零样本 iPlanner 与 GT Agent 参考。已见划分上 Go2-DrivoR 综合分 0.8368（恒速 0.6953、iPlanner 0.7344、GT 0.9304），NOC 0.9397、TTC 0.9391、DAC 0.9869、GEP 0.7875；未见划分上综合分 0.8512（恒速 0.7425、iPlanner 0.7721、GT 0.9269），NOC 0.9579、TTC 0.9539、DAC 0.9888；未见的 GEP 为 0.7757，略低于 iPlanner 的 0.7827。
  • 真实世界指标：ADE、FDE@1s/2s/4s、Heading MAE，对比恒速基线。行人场景 ADE 0.200 m vs 0.785 m，FDE@1s 0.149 vs 0.318，FDE@2s 0.233 vs 0.672，FDE@4s 0.209 vs 1.470，Heading MAE 5.79° vs 8.94°；道路场景 ADE 0.213 vs 0.824，FDE@1s 0.164 vs 0.333，FDE@2s 0.263 vs 0.704，FDE@4s 0.186 vs 1.542，Heading MAE 6.81° vs 9.22°。
  • 消融（真实日志开环，α 与 goal token 变体）：完整模型 ADE 0.202、FDE@4s 0.207、GP 0.988、EP 0.976；仅 EP（α=0）ADE 0.251、FDE@4s 0.239；无 goal token（α=0.5）ADE 4.364、FDE@4s 7.766、GP 0.718；仅 goal（α=1）ADE 0.325、FDE@4s 0.463。
  • 定性结果：仿真示例中选中轨迹与专家路径不同，但 oracle 评分达 0.933（图注另一处报综合分 0.959，各分项 NOC 0.993、DAC 1.000、TTC 0.994、GEP 0.924、Comfort 1.000）；真实示例选中轨迹综合分 0.693，在路口选择朝目标的转向轨迹而恒速基线沿原航向直行。
