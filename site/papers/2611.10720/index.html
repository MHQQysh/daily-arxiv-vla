Card 02 论文概述

论文概述

  • 任务：面向以视觉语言模型（VLM）作为端到端轨迹规划器的自动驾驶系统，研究并缓减跨城市部署时的域偏移（domain shift）。
  • 应用场景：同一 VLM 规划器在源城市数据上训练/微调后，迁移到目标城市（如 Boston→Singapore）进行未来自车轨迹预测。
  • 研究问题：(Q1) VLM 轨迹规划器中的跨城市域偏移具有怎样的结构形式；(Q2) 基于该结构，何种修复策略优于统一的域适应对齐。
  • 核心观察：作者通过激活修补（activation patching）发现域偏移沿“模态（图像 vs. 文本）”与“层”两个轴呈结构化分布，而非单一标量，因此提出“先定位、再修复”的框架 MoLaRx（Modality–Layer Repair）。
  • 论文明确指出统一 MMD 对齐在全部六个主表设置中均失效，从而论证结构引导修复的必要性。
Card 03 核心贡献

核心贡献

  • 发现：揭示跨城市域偏移的模态–层结构，图像与文本 token 在不同 VLM 中呈现不同的逐层偏移模式；(F2) 层分区与架构相关但在不同数据集上稳定，据作者称为 VLM 轨迹规划器中首个联合模态–层的跨城市偏移刻画。
  • 工具：提出 Causal Importance Score（CIS），一种基于激活修补的诊断量，逐 (modality, layer) 切片测量源域激活替换对目标域预测轨迹的因果影响，形成 2×L 的模态–层张量并用 Hoeffding 不等式给出估计置信界。
  • 方法：提出 MoLaRx 定位–修复框架，CIS 定位偏移来源并将层划分为 Φ_align、Φ_tune、Φ_freeze 三个功能分区；CISR 为每个分区匹配修复算子（MMD 分布对齐 / LoRA 选择性再训练 / 冻结），算子组合随架构自动适配。
  • 实验：在三种架构不同的 VLM（LFM2-VL-1.6B、Qwen2-VL-2B、PaliGemma2-3B）与两个跨城市基准（nuScenes、Argoverse 2）的全部六个主表设置中取得最小的跨城市轨迹误差差距，同时可训练参数减少 50–60%、推理时延降低 8.4–10.9 ms。
Card 04 方法描述

方法描述

  • 所属模块：VLM 端到端轨迹规划器的跨域适配模块，包含定位模块 CIS 与修复模块 CISR 两部分。
  • 输入传感器：多模态输入 x ∈ X = I × C，即图像与文本上下文；图像 token 与文本 token 在隐藏状态中按位置索引区分为两个模态块。原文未报告具体相机数量、分辨率等传感器配置细节。
  • 场景表示：以层 l 的隐藏状态 H^(l)(x) ∈ R^{T×d} 表示，并按模态切分为 H^(l)_{M_m}(x)；输出为 K 个自车 2D 位置（K=6 个 waypoint）。
  • 模型结构：L 层堆叠骨干 + 解码器 Dec；跨域分布以“场景匹配对” P_paired 定义（按任务相关内容向量 k(·) ∈ R^3 做源域最近邻匹配），域偏移差距 G(f) 为配对样本预测轨迹的逐 waypoint 平均 ℓ2 距离。
  • 关键技术一（CIS）：对每个 (m,l)，将目标域 H^(l)(x_t) 中模态 m 的 token 行替换为源域 H^(l)(x_s) 对应行，继续前向传播得到反事实轨迹，计算与未修补目标预测的逐 waypoint ℓ2 距离，在 N=100 个配对上取蒙特卡洛平均得到 Ψ̂[m,l]；据 Hoeffding 不等式（η=0.05、R≈20 m、N=100）给出约 0.6 m 的 95% 半宽。
  • 关键技术二（分区）：以各模态排序后 CIS 值的拐点作为阈值 τ_img、τ_txt，按 Eq.11–13 划分 Φ_align（图像 CIS 高）、Φ_tune（文本 CIS 高且不属于 Φ_align）、Φ_freeze（其余层）。
  • 关键技术三（CISR 算子）：Φ_align 上最小化源/目标图像 token 平均池化表示的多尺度 RBF 核 MMD²，并在注意力投影（Q、K、V、O）上挂 rank-r LoRA；Φ_tune 上以源域监督轨迹损失（下一 token 对数似然）驱动 rank-r=16、α=32、作用于全部线性投影的 LoRA；Φ_freeze 上零梯度冻结。
  • 优化目标：最小化 G(f_{Θ′+Δ})，并约束源域误差不增长超过 ε（原论文 Eq.7）。

Card 06 评估与结果

评估与结果

  • 评估基准：三种 VLM × 两个跨城市数据集，共六个主表设置（(VLM, dataset) 单元）。
  • 评估指标：域偏移差距 G(f)（配对样本预测轨迹的逐 waypoint 平均 ℓ2 距离）、跨城市轨迹误差、位移（displacement）、最近模态准确率（closest-mode accuracy）、Partition Consistency Score（PCS），以及可训练参数量与推理时延。
  • 关键数值：摘要报告 MoLaRx 在六个主表设置中均取得最小跨城市轨迹误差差距；可训练参数比对比方法少 50–60%；推理时延低 8.4–10.9 ms；正文引言示例给出域偏移导致轨迹误差从 0.15 m 增至 1.13 m（+653%）。
  • 对比方法：无适配参考、统一/标量视角域适应（如统一 MMD、对抗对齐、CorAL、LoRA 适配器、测试时归一化）、层选择性非因果域适应（如按层带选择的 Surgical FT）、locate-then-edit 类方法（如 ROME / MEMIT / MMEdit 思路）；其中统一 MMD-only 适配在全部六个设置中均崩溃。
  • 补充实验：消融研究、CIS 阈值（τ_img、τ_txt）敏感性、MMD 损失权重 λ_MMD 敏感性、时间帧数 N_frame 敏感性、CIS 配对预算 N 敏感性、计算效率、归纳协议控制、长尾压力测试、反向迁移（target→source）实验、跨城市视觉相似性不变性定性案例。
  • 条件：评估为离线跨城市基准上的开环轨迹评估（对比预测轨迹与配对预测），原文未报告闭环仿真或实车测试结果。
