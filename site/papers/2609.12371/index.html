Card 03 核心贡献

核心贡献

  • 提出显式、与规划对齐的风险表示 READ，将经典场式安全建模与现代数据驱动规划衔接，实例化为超越占据栅格的连续、行为感知时空风险场。
  • 通过几何与行为约束（地图不可行驶区域、未来智能体占据、专家轨迹、运动学残差等）以部分安全约束方式学习风险场，而非预设完整解析曲面。
  • 证明 READ 可跨规划器类型迁移：既可作为端到端 BEV 规划器的辅助结构化监督，也可作为 VLA 模型的风险结构化潜在监督。
  • 利用连续可微场对轨迹进行评估与可选的可微轨迹细化，且无需重新训练规划器。
  • 在 NAVSIM 上验证：匹配的端到端骨干与 VLA 设置下均取得一致增益，并在 NAVSIM v2 上取得有竞争力的结果。
Card 04 方法描述

方法描述

  • 所属模块：规划中间表示学习，作为辅助监督与潜在结构化表示，与轨迹解码器共享场景表示。
  • 输入传感器：NAVSIM 设置下为多视角相机观测、自车状态与高层导航指令；VLA 设置下使用前视图图像与导航文本。原文未报告激光雷达或其它传感器。
  • 场景表示：自车中心 BEV，风险场定义为时空连续函数 R(x, y, t)；场覆盖 x∈[0,80] m、y∈[-32,32] m，1 m 分辨率，预测 4 s 时域内 8 个 0.5 s 间隔切片。
  • 模型结构：采用各向异性高斯基元放置于 H×W 网格，中心固定，权重 w∈[0,1] 与对角尺度由网络预测，场为加权高斯和，保证光滑可微；端到端设置中卷积解码器从共享 BEV 状态预测参数，轨迹查询交叉注意该状态；VLA 设置中风险潜在 token 与视觉/语言 token 联合处理，输出状态解码为风险场，轨迹查询同时关注上下文 token 与风险潜在状态。
  • 关键技术：五类部分安全约束损失——静态不可行驶约束、动态智能体约束、全局稀疏正则、专家路径约束、运动学残差约束；总场损失为加权和。端到端总损失为轨迹损失加 α 倍场损失；VLA 总损失为轨迹损失加 β 倍场损失。可选可微轨迹细化仅在初始平均风险超过阈值 ρ 时优化风险项与轨迹项，直接优化路点位置与航向，不重新查询或训练策略。

Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM（原始协议）与 NAVSIM v2。
  • 评估指标：NAVSIM 原始协议使用 PDMS，由 NC、DAC、EP、TTC、C 组合而成；NAVSIM v2 使用 EPDMS，额外包含 DDC、TLC、LK、HC、EC。所有子分数归一化到 [0,1]。
  • 关键数值：NAVSIM 原始协议下，TransFuser 加 READ 的 PDMS 从 84.0 提升至 84.6；Drive-JEPA 加 READ 的 PDMS 从 89.1 提升至 90.0，且 NC、DAC、TTC、EP 均提升。VLA 设置下 READ 达到 90.7 PDMS，EP 为 85.5，为所列 VLA 方法中最高。NAVSIM v2 下 READ 达到 90.1 EPDMS；匹配 ViT 设置下，以场学习替代 BEV 监督使 EPDMS 提升 0.7、TTC 提升 0.4，同时改善 NC、DAC、DDC、LK，EP、TLC、EC 接近。
  • 对比方法：传统端到端方法包括 TransFuser、Hydra-MDP、DiffusionDrive、WoTE、Drive-JEPA；VLA 方法包括 AutoVLA、Percept-WAM、DriveVLA-W0、AdaThinkDrive；NAVSIM v2 还包括 Ego Status MLP、HydraMDP++、MeanFuser 等。
  • 评估条件：全部为 NAVSIM 基准上的开环规划评估（非闭环、非实车）；受控的表示与约束消融在原始 NAVSIM 协议下进行，以保证监督变化在同一评估器下比较。原文未报告闭环或实车评估结果。
