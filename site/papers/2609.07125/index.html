A Two-Stage Framework for Ego-Centric Key Object Identification via Object State Prediction

2026-09-07 · 原文 · 翻译 · 2609.07125

解决自动驾驶场景下的关键物体识别（Key Object Identification）任务。 应用场景为城市复杂交通环境下的自动驾驶感知与决策解释，旨在提升自动驾驶系统对于环境影响自身驾驶行为的关键物体的识别能力，增强决策透明度。 研究问题为现有方法仅独立检测物体或依赖视觉关系建模，未充分显式考虑以自车为中心的物体重要性判断。针对此提出两阶段框架：第一阶段推断周围物体相对于自车的动态状态，第二阶段利用物体状态与时空关系识别最关键物体。

  • 应用场景为城市复杂交通环境下的自动驾驶感知与决策解释，旨在提升自动驾驶系统对于环境影响自身驾驶行为的关键物体的识别能力，增强决策透明度。

Card 03 核心贡献

核心贡献

  • 提出两阶段框架，引入虚拟自车表示，为物体状态估计提供一致的空间参考，增强以自车为中心的物体重要性判断。
  • 提出模块化的物体状态预测器，为不同类别物体（行人、车辆、交通灯、停车标志）分别训练模型，相较于单一统一模型显著提升分类精度。
  • 摒弃仅依赖视觉关系的方法，物体重要性判定基于预测的物体状态与相对于自车的空间时-空动态信息。
  • 基于预测物体状态与时空变化特征，通过空间-时序推理细化关键物体识别，优先考虑物体状态与相对空间信息而非视觉关系。
  • 在基于BDD100K、Argoverse 2 与 Rank2Tell 构造的1,500段视频数据集上验证，方法在关键物体识别精度上均超过基于CNN的对象诱导模型与基于Transformer的DRUformer基线，并系统评估特征表示与模块化训练机制的消融效果。
Card 04 方法描述

方法描述

  • 所属模块：自动驾驶场景理解中的关键物体识别模块；模型由两个分离训练的阶段组成。
  • 输入传感器：单目视觉相机图像（原文未报告其他传感器输入）。
  • 场景表示：每帧目标物体表示为空间特征（2D位置 + 深度）与视觉特征（检测框裁剪区域经MobileNetV2提取的表征）的组合。
  • 模型结构：预处理阶段采用YOLOv8进行物体检测，DeepSORT进行多目标跟踪。第一阶段（物体状态预测器）：将空间与视觉特征拼接，输入到两层LSTM网络（隐层维度128和64）以捕捉时序依赖后进行分类，损失函数为分类交叉熵。第二阶段（关键物体识别器）：将每个物体的预测状态、物体类别以及2s时间窗内位置和深度变化量组合为特征向量，输入两层Transformer编码器，通过自注意力捕捉物体间关系，后接全连接打分层生成重要度分数，损失函数为二元交叉熵。
  • 关键技术：引入自车虚拟表示，假设自车位于帧底部的中间位置；采用相对位置表达优于绝对位置；使用深度估计的两类替代方案：基于预训练MiDaS深度估计模型或依据图像中占面积大小推断；单独为不同类别物体训练状态预测模型。

Card 06 评估与结果

评估与结果

  • 评估基准：自定义数据集，分成不同类别（Car、Person、Traffic Light、Stop Sign）。
  • 评估指标：关键物体识别精度（准确率）、物体状态预测精度与F1分数。
  • 数值结果：关键物体识别精度方面，本方法Car达到0.78±.02、Person达到0.76±.02、Traffic Light达到0.71±.01、Stop Sign达到0.94±.01，均高于对比基线。
  • 对比方法：基于CNN的对象诱导模型（深度重新训练并调整输出）、DRUformer（调整输入预处理后重新训练）。
  • 运行条件：开环离线评估，采用真实驾驶数据测试；实际部署时状态预测与关键识别阶段约≤0.10 ms/帧。
  • 实验条件：采用Adam优化器、学习率1×10⁻⁴、状态预测器batch size 32、关键物体识别器batch size 16，训练100轮并采用早停机制（patience 10）；状态预测器使用随机搜索做超参数调优（最大20次试验）。文中未报告闭环仿真测试或实车道路测试。
