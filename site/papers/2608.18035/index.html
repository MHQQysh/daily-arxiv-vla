Plug-and-Play Traffic Element Awareness for End-to-End Autonomous Driving

Card 03 核心贡献

核心贡献

  • 首次系统研究并量化交通元素感知对端到端自动驾驶性能的影响，填补领域空白。
  • 构建统一研究基础设施，为多个公开驾驶数据集补全交通元素标注，并设计 3D 交通元素提取流水线。
  • 提出一种最小化、通用的即插即用集成机制，通过轻量级 3D 交通元素辅助监督及可选的拓扑条件注入（语言引导拓扑编码），无需大幅修改现有架构即可应用。
  • 在多项范式与多个基准上验证一致性能提升，并在 NAVSIM-v2 上显著提升最先进架构与数据流水线性能，取得新最优结果。
  • 通过针对性消融实验揭示交通元素感知有效性的原因，如显式 3D 表示优于 2D、交通标志（不仅限于交通灯）至关重要、独立预测头与焦点损失对稀疏目标十分关键等。
Card 04 方法描述

方法描述

  • 所属模块：端到端自动驾驶规划模块中的感知辅助任务与拓扑条件注入模块。
  • 输入传感器：多视角摄像头图像（多视角图像），前视图像用于 2D 检测与单目深度估计，并利用 LiDAR 点云几何辅助 3D 定位。
  • 场景表示：以 OpenLane-V2 风格的中心线、交通元素、LCTE（车道中心线-交通元素）拓扑与 LCLC（中心线-中心线）拓扑为场景表示，并结合 BEV 查询与拓扑查询。
  • 模型结构：在原有规划器（如 VAD、Orion 等基线）基础上附加 3D 交通元素检测任务（L1 定位损失 + 焦点分类损失）；拓扑信息经 2D 检测与深度估计后生成 3D 中心点，再经拓扑预测模块（TopoMLP）估计邻接矩阵，并转化为语言描述后由冻结 BERT-base 编码器生成拓扑查询，与 BEV 查询拼接输入规划解码器。
  • 关键技术：即插即用集成设计、3D 交通元素伪标签构建（2D YOLO 检测 + 单目深度模型 UniDepthv2 + LiDAR 融合）、ego-centric 拓扑过滤、语言引导拓扑条件编码、焦点损失与最大保留池化处理稀疏目标。
Card 05 数据集与资源

数据集与资源

  • 数据集：nuScenes（含 OpenLane-V2 子集标注）、NAVSIM-v1（navtest）、NAVSIM-v2（navhard）、Bench2Drive（闭环 CARLA 场景）。
  • 仿真器：CARLA（用于 Bench2Drive 闭环评估）；NAVSIM-v1/v2 采用数据驱动非反应式与两阶段伪闭环评估。
  • 模型规模：语言编码器采用 BERT-base（约 110M 参数）；拓扑预测采用轻量 TopoMLP。
  • 训练资源：nuScenes 与 Bench2Drive 上使用 8×A100、batch size 1；NAVSIM 上使用 4×RTX 3090、batch size 32。
  • 实车平台：原文未报告。
Card 06 评估与结果

评估与结果

  • 评估基准：nuScenes（开环）、NAVSIM-v1（开环/仿真评分）、NAVSIM-v2（开环/两阶段伪闭环）、Bench2Drive（闭环 CARLA）。
  • 评估指标：nuScenes 使用 L2 轨迹误差和碰撞率；NAVSIM-v1 使用 PDMS；NAVSIM-v2 使用 EPDMS 及 Stage 1/Stage 2 分解；Bench2Drive 使用 Driving Score、Success Rate、Efficiency、Comfortness 及 open-loop Avg. L2。
  • 关键数值（nuScenes）：VAD–Base 基线 L2 Avg. 0.72、CR Avg. 0.22；VAD + TE 为 L2 Avg. 0.63、CR Avg. 0.17；VAD + Topo 为 L2 Avg. 0.62、CR Avg. 0.16；VAD + Ours 为 L2 Avg. 0.60、CR Avg. 0.17。Orion† 基线 L2 Avg. 0.34、CR Avg. 0.37；Orion† + TE 为 L2 Avg. 0.29、CR Avg. 0.27；Orion† + Topo 为 L2 Avg. 0.27、CR Avg. 0.25；Orion† + Ours 为 L2 Avg. 0.26、CR Avg. 0.23。
  • 对比方法（nuScenes）：NMP、FF、EO、ST-P3、UniAD、VAD-Tiny、BEV-Planner、PARA-Drive、LAW、GenAD、SparseDrive、UAD、MomAD、Qwen-2.5-VL、Senna、DriveVLM、OmniDrive、EMMA、ImpromptuVLA 等。
  • 结果条件：nuScenes 为开环评估；NAVSIM 为开环仿真评分；Bench2Drive 为 CARLA 闭环评估；所有实验均未见实车部署。
