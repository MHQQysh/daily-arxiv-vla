Card 02 论文概述

论文概述

  • 任务：面向自动驾驶的相机图像目标检测（car、bus、truck、person 四类）跨天气鲁棒性评测。
  • 应用场景：自动驾驶感知系统在雾、雨、雪、夜间等恶劣天气与照明变化下的部署可靠性。
  • 研究问题：仅用晴天日间数据训练、不做任何域适应或合成天气增强时，检测模型在未见恶劣天气下（RQ1）性能退化程度、（RQ2）哪种天气退化最大、（RQ3）哪类目标最脆弱、（RQ4）不同检测架构在 Drop (%) 与 WRI 上的鲁棒性保持差异，并额外考察置信度校准可靠性。
Card 03 核心贡献

核心贡献

  • 提出基于 BDD100K 晴天日间场景训练、ACDC 雾/雨/雪/夜场景测试的受控 source-only 跨天气评测协议，不引入域适应或合成增强，以隔离环境域偏移效应。
  • 采用面向部署的鲁棒性指标：性能退化 Drop (%) 与天气鲁棒性指数 WRI，用于量化恶劣天气下的定位稳定性。
  • 使用 Expected Calibration Error (ECE) 评估环境域偏移下的预测置信度可靠性。
  • 对 car、bus、truck、person 进行天气条件与目标类别层面的敏感性分析，并在单阶段、两阶段与 Transformer 检测器之间做架构级鲁棒性对比。
Card 04 方法描述

方法描述

  • 所属模块：感知中的 2D 相机图像目标检测模块（不涉及 LiDAR/雷达融合）。
  • 输入传感器：车载相机图像；原文未报告具体相机型号与内参。
  • 场景表示：逐帧 2D 图像，输出类别与边界框；训练源域为 BDD100K 晴天日间帧，测试目标域为 ACDC 雾、雨、雪、夜间子集。
  • 模型结构：五个检测器覆盖三类范式——YOLOv8n（轻量单阶段）、YOLOv8m 与 YOLO11m（中等规模单阶段）、Faster R-CNN（两阶段）、DETR（Transformer 检测）。
  • 训练设置：统一 100 epochs、输入分辨率 768 像素（DETR 使用默认预处理）、AdamW 优化器、初始学习率 0.001、随机种子 42；Faster R-CNN 与 DETR 批大小为 8，YOLO 系列批大小为 20。
  • 关键技术指标：mAP50 及 precision/recall（类别级与宏平均）；Drop (%) = max(0, (mAP_clear − mAP_weather)/mAP_clear × 100)；WRI = ACDC 平均 mAP50 / 晴天 mAP50，并按 ≥0.90、0.80–0.89、0.70–0.79、<0.70 分级解释；ECE 以 M 个等宽置信度分箱计算，IoU>0.50 且类别一致视为正确。
  • 原文未报告：推理速度、模型参数量、具体 ECE 分箱数 M 的取值、RPN/检测头的细节改动。

Card 06 评估与结果

评估与结果

  • 评估基准：源域 BDD100K clear 测试集（in-domain 基线）+ ACDC 雾/雨/雪/夜（跨天气目标域）；纯离线数据集评测，非闭环、非实车。
  • 评估指标：Precision、Recall、mAP50（类别级与宏平均）、Drop (%)、WRI、ECE。
  • 基线 in-domain（BDD100K clear，mAP50）：YOLO11m 的 car 最高 0.8314；YOLOv8m car 0.8233；YOLOv8n car 0.7760、bus 0.5370、truck 0.5640、person 0.5317；Faster R-CNN car 0.7560（recall 0.8063 高但 precision 0.4835 低）；DETR car 0.3889、bus 0.2593、truck 0.2826、person 0.1870，整体定位精度最低。
  • 各天气宏平均 mAP50（Avg ACDC）：YOLO11m 0.5094、YOLOv8m 0.5010、Faster R-CNN 0.4498、YOLOv8n 0.4373、DETR 0.1917；Clear 分别为 0.6818、0.6698、0.5594、0.6022、0.2795。
  • 天气层面：夜间退化最大，雾几乎不退化（YOLO 系列与 Faster R-CNN 雾 Drop 为 0.00，YOLOv8m 为 0.15，DETR 为 2.97）；夜间 Drop 依次为 DETR 62.90%、YOLOv8n 57.51%、YOLO11m 53.58%、YOLOv8m 52.76%、Faster R-CNN 50.39%；雨 Drop 为 YOLOv8n 29.38%、YOLOv8m 24.57%、YOLO11m 24.11%、Faster R-CNN 19.15%、DETR 35.39%；雪 Drop 为 YOLOv8n 23.53%、YOLOv8m 23.32%、YOLO11m 24.36%、Faster R-CNN 16.05%、DETR 24.40%。
  • 类别敏感性：car 最稳定（雾/雪 mAP50 约 0.7743–0.8352，夜间 0.5620–0.6517）；bus 最脆弱（雾 0.6561 → 雨 0.2002 → 夜 0.0652）；truck 夜间降至 0.0573；person 在雨与夜间下降（0.3108–0.4178）。
  • 架构级：DETR 的 WRI 最低为 0.6859，属严重退化；YOLO 系列校准失配最小（ECE 最低），DETR 与 Faster R-CNN 存在过置信等问题；原文未报告具体 ECE 数值。
