Vision-Language-Action Autonomous Driving Agent with Language-based Memory

Card 02 论文概述

论文概述

  • 论文面向自动驾驶中的 Vision-Language-Action（VLA）驾驶智能体任务，研究如何让 VLA 在有限视觉输入时间跨度下具备记忆能力。

Card 03 核心贡献

核心贡献

  • 提出 AD-Memo，作者称其为第一个使用语言式 in-episode memory 的通用 VLA 驾驶智能体，具备可扩展、可解释、可移植的特点。
  • 提出 Da Capo，一种半闭环 RL 算法，结合逐步 driving reward 与依赖未来的 episode-level memory reward，在避免完全闭环 RL 昂贵环境仿真的同时缓解记忆暴露偏差。
  • 构建新的 agentic 数据流程，并整理具有挑战性的记忆依赖数据集，包括 all-way stop 数据集和通用驾驶数据集。
  • 在多个驾驶场景中评估 AD-Memo，证明其不仅改善驾驶性能，还提升场景理解与 VQA，并可作为 plug-and-play memory 模块辅助其他模型。
Card 04 方法描述

方法描述

  • 所属模块：AD-Memo 是一个通用 VLA 驾驶智能体，联合学习驾驶、VQA 和 memory writing 三类任务。
  • 输入传感器：原文报告输入包括 past trajectory、visual input（按时间排序的过去相机图像）和 language input；基础模型为 2B、single camera-focused 的 Alpamayo 2 checkpoint。
  • 场景表示：模型以 streaming video agent 方式运行，在关键帧上切换 driving mode 与 VQA mode；驾驶模式下输出 CoT、memory 和未来轨迹。
  • 语言记忆：memory 作为 CoT 的扩展子串生成，并被附加到未来关键帧输入；原文关注约 10 秒记忆跨度，关键帧间隔由视觉输入跨度 t 决定。
  • VQA 机制：在 clip 末尾，模型输入当前视觉、最多 T 个先前 memory 和多项选择题 Q，并生成答案；训练时模型不知道 Q，因此需记录重要道路对象。
  • 模型结构：以 VLA backbone 为基础；原文未报告更细的完整网络层数、视觉编码器结构等细节。
  • 训练方法：两阶段训练，先 SFT，再使用 semi-closed-loop RL；SFT 联合优化 driving、memory writing 与 VQA 损失。
  • Da Capo：对同一 clip 采样 K 条 rollout，视觉输入与过去轨迹来自 ground truth replay，而 memory 使用同一 rollout 前序步骤自生成结果；对 driving、Memory、VQA 定义不同 return 和 advantage。
  • 关键技术：用 trajectory-level advantage 处理 memory，用 step-level advantage 处理 driving；作者称 causal advantage 去掉条件独立项以改善 credit assignment，并使用 standard-deviation normalization 平衡不同奖励尺度。
  • 若原文未报告某项信息：原文未报告完整模型结构细节、具体视觉编码器组成、仿真器内部实现细节。
Card 05 数据集与资源

数据集与资源

  • 数据集来源：基于 NVIDIA Physical-AV dataset 整理数据集。
  • 数据集类型：all-way stop 数据集和 general driving 数据集；每个数据集按 3:1:1 划分为 SFT 训练集、RL 训练集和测试集。
  • 数据形式：数据集由 triplets (V, Q, y^VQA) 组成，V 为 clip，Q 为问题，y^VQA 为答案。

Card 06 评估与结果

评估与结果

  • 评估基准：all-way stop 数据集、general driving 数据集；memory portability 使用 LingoQA 和 WaymoQA。
  • 评估指标：minADE、Avg. ADE、ML. ADE、minFDE、Avg. FDE、ML. FDE、corner distance、Stop SR、Go SR、Δpos、Δdur、Roll、MCQ Accuracy。
  • 对比方法：Base Model、Alpamayo 2 Super 34B、No memory、CoT-as-memory、AD-Memo；RL 部分还比较 Da Capo、Capo no std、Capo + const. scaling、trajectory-level GRPO。
  • all-way stop 关键结果：AD-Memo 达到 minADE 0.951、Avg. ADE 1.866、ML. ADE 1.915、Stop SR 89.26%、Go SR 45.01%、Δpos 1.070、Δdur 1.183、Roll 5.26%、MCQ Acc. 51.66%。
  • all-way stop 结论：AD-Memo 在 SFT 和 RL 后均优于所有其他 baseline，甚至优于 Alpamayo 2 Super 34B；RL 后三类 memory 均有明显提升。
  • all-way stop Da Capo 消融：Da Capo 的 Avg. ADE 1.866、ML. ADE 1.915、Stop SR 89.26%、Go SR 45.01%、Δpos 1.070、Δdur 1.183、MCQ Acc. 51.66%；trajectory-level GRPO 为 minADE 1.007、Avg. ADE 2.113、ML. ADE 2.194、Stop SR 87.11%、Go SR 40.94%、Δpos 1.312、Δdur 1.392、Roll 6.28%、MCQ Acc. 48.16%。
  • general driving 关键结果：AD-Memo 达到 minADE 1.091、Avg. ADE 1.864、ML. ADE 1.869、minFDE 3.027、Avg. FDE 5.512、ML. FDE 5.576、corner 1.066、MCQ Acc. 65.51%。
  • general driving 结论：AD-Memo 优于其他 baseline；RL 改善 Avg. ADE 和 ML. ADE 等平均/最可能误差，但不一定改善 rollout 最小值，作者解释为 RL 后策略分布更集中。
  • memory portability 结果：GPT-5.6 Luna 使用 Our memory + last frame 在 WaymoQA 达 71.65%、LingoQA 达 67%；Unmerged memory + last frame 为 68.3% 和 60.4%；Only last frame 为 66.63% 和 62.6%；Full video 为 75% 和 70%。
  • memory portability 结论：AD-Memo 生成的 memory 可作为 plug-and-play 信息提升其他模型 VQA；merged memory 明显优于 unmerged memory。
  • 开环/闭环/仿真/实车条件：SFT 阶段为监督训练；Da Capo 为 semi-closed-loop RL，即控制开环、memory 闭环；评估主要为数据集上的开环轨迹预测与 VQA，原文未报告实车测试。
