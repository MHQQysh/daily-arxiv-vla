ODPure: Backdoor Purification for Object Detection via Ensemble Corruption Consensus

2026-09-23 · 原文 · 翻译 · 2609.28239

论文面向自动驾驶等安全关键感知场景中的目标检测模型，研究其后门攻击防御问题。 解决的问题是：现有目标检测后门防御（输出扫描如 DetectorCleanse、模型检查如 ODSCAN）主要是“检测并丢弃”恶意输入或模型，无法对受污染样本进行净化，从而难以维持连续、准确的感知流。 论文关注的后门行为包括目标误分类（OMA）、目标消失（ODA）和目标生成（OGA），这些行为都由输入中嵌入的触发器等单一根因驱动。 论文提出首个针对目标检测的输入阶段净化防御，即 Corruption-Reconstruction-Selection（CRS）范式，并在 ODPure 中实现，目标是在不牺牲多目标检测精度的同时中和触发器。 关键观察是鲁棒性不对称：良性目标特征在不同损坏下表现出一致脆弱性，而后门触发器作为人工捷径对特定扰动类型高度敏感、表现可变脆弱性，从而可通过一致性共识过滤触发器。

Card 02 论文概述

论文概述

  • 论文面向自动驾驶等安全关键感知场景中的目标检测模型，研究其后门攻击防御问题。
  • 解决的问题是：现有目标检测后门防御（输出扫描如 DetectorCleanse、模型检查如 ODSCAN）主要是“检测并丢弃”恶意输入或模型，无法对受污染样本进行净化，从而难以维持连续、准确的感知流。
  • 论文关注的后门行为包括目标误分类（OMA）、目标消失（ODA）和目标生成（OGA），这些行为都由输入中嵌入的触发器等单一根因驱动。
  • 论文提出首个针对目标检测的输入阶段净化防御，即 Corruption-Reconstruction-Selection（CRS）范式，并在 ODPure 中实现，目标是在不牺牲多目标检测精度的同时中和触发器。
  • 关键观察是鲁棒性不对称：良性目标特征在不同损坏下表现出一致脆弱性，而后门触发器作为人工捷径对特定扰动类型高度敏感、表现可变脆弱性，从而可通过一致性共识过滤触发器。
Card 03 核心贡献

核心贡献

  • 提出 CRS 范式，这是首个面向目标检测的输入阶段净化框架，用于解决攻击破坏与多目标保持之间的固有权衡，支持连续且准确的感知流。
  • 提出 ODPure，一个黑盒、模型无关的防御方法，通过组合多样化损坏、生成式恢复和基于共识的选择实现 CRS 框架，适用于 MLaaS 等无法访问模型内部信息的场景。
  • 通过大量实验表明 ODPure 打破了分类净化方法所受的权衡限制，将触发器中和与多目标保持解耦，在不损害检测效用的情况下取得先进性能。
  • 论文报告在 COCO 上 OMA 攻击使模型效用崩溃至 0.4% mAP 时，ODPure 将 mAP 恢复到 52.0%，并将 ASR 抑制到 1.5%，显著优于 ZIP 等分类净化基线。
  • 论文提供了代码开源链接：https://github.com/Alex66366/ODPure。
Card 04 方法描述

方法描述

  • 所属模块：输入阶段、黑盒、模型无关的净化防御，位于检测器推理之前，不修改检测器内部结构。
  • 输入传感器：原文未报告具体传感器类型；方法处理的是输入图像 I，未限定可见光、激光雷达等具体传感器。
  • 场景表示：输入为二维图像，检测输出为边界框、类别标签和置信度集合，即 M(I)={r̂_j}={(b̂_j, l̂_j, ŝ_j)}。
  • 威胁模型：假设后门通过数据投毒植入；防御者攻击无关、严格黑盒（仅查询模型并获得边界框与类别分数）、数据无关（无法访问训练集、干净集或孤立触发器样本），必须在推理时仅基于当前输入进行防御。
  • 关键技术一（Corruption）：对输入应用多样化损坏函数集合 F={f_{i,j}}，包含 n=15 种损坏类型、m=3 个严重程度，将单张输入转换为损坏变体集合 I_corr={f_{i,j}(I)}，以利用触发器的可变脆弱性破坏其结构完整性。
  • 关键技术二（Reconstruction）：使用基于 DiffBIR 的预训练图像恢复模型作为通用去噪器，分两阶段进行：先由 Restoration Module（RM）去除内容无关退化，再由 Generation Module（GM）利用冻结的 Stable Diffusion 生成先验重建高频边缘与纹理，避免过度平滑，同时将触发器视为分布外噪声选择性消除。
  • 关键技术三（Selection）：聚合所有净化变体的检测结果，按类别分组，使用复合距离度量 D=d1+d2（d1=1-IoU，d2 为归一化中心欧氏距离）进行 DBSCAN 聚类，以 MinPts 作为共识阈值过滤不稳定的触发器异常，再在每个有效聚类内按置信度投票选出最终检测框。
  • 原文未报告：具体检测器内部结构细节、传感器融合方式、实时性指标、模型参数量与推理延迟。
