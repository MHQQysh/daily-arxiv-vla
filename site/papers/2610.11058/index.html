Refine Connections, Close the Gap: A Reliable Enhancement Framework for Driving Scene Topology

2026-10-08 · 原文 · 翻译 · 2610.11058

Card 02 论文概述

论文概述

  • 论文针对自动驾驶中驾驶场景拓扑理解任务，即检测车道与交通元素并推理车道-车道、车道-交通元素连接关系，生成用于下游路径规划与运动控制的拓扑图。
  • 研究问题一：现有方法在已知检测结果下的拓扑连接推理性能显著低于理论 Oracle 上界，存在可利用的潜在提升空间。

Card 03 核心贡献

核心贡献

  • 识别出“决策用拓扑质量”这一常被忽视的问题，并指出现有方法与理论 Oracle 上界之间存在显著性能差距。
  • 提出首个驾驶拓扑增强框架 TopoEnhance，将拓扑细化建模为去噪过程，从含噪拓扑中恢复更可靠的决策用拓扑图。
  • 设计前向过程“拓扑噪声模拟”，通过假阳性检测合成、拓扑增广、几何定位抖动和自适应噪声课程，模拟真实预测误差分布。
  • 设计后向过程，采用轻量异构图 GNN 区分建模车道-车道与车道-交通元素关系，并通过关系归一化 BCE 进行训练。
  • 大量实验表明，TopoEnhance 作为与来源无关的框架，无需针对具体基线重训练，即可同时提升连续拓扑指标（TOP_ll、TOP_lt）和离散拓扑指标（TJS）。
Card 04 方法描述

方法描述

  • 所属模块：面向已有拓扑推理方法的独立后处理增强模块，位于检测与拓扑预测之后、下游规划之前。
  • 输入传感器：原文未将 TopoEnhance 本身绑定到特定传感器；其输入为已有方法输出的检测节点与原始拓扑分数。实验涉及的基线中，除 SMART 使用 SD 地图和卫星影像等附加数据外，其余方法仅使用透视相机图像。
  • 场景表示：将驾驶场景拓扑表示为异构图，节点包括以 3D 折线表示的车道实例和以 2D 边界框表示的交通元素；边包括车道-车道关系（如后继、汇入、分叉）和车道-交通元素关系（车道与交通标志分配）。
  • 问题形式化：学习映射 f_θ，从受损坏的检测与原始拓扑分数中恢复校准后的拓扑分数，使阈值化后的离散拓扑更接近真值图。
  • 前向过程：对真值拓扑图注入三类误差，包括假阳性检测合成（按类别距离阈值采样远离真值实例的检测）、拓扑增广（构建候选边并将涉及假阳性节点的边标为负）、几何定位抖动（在类别距离阈值内扰动真值检测）；同时采用自适应噪声课程，令真阳性噪声方差从近零逐步增至距离阈值、假阳性噪声方差从较大值逐步降至距离阈值。
  • 后向过程：使用轻量两层异构图注意力网络（GAT），以关系特定变换对车道-车道和车道-交通元素邻域分别进行消息传递；节点特征由车道 3D 折线坐标和交通元素 2D 框视觉特征初始化；最终通过 sigmoid 激活的余弦相似度输出细化分数。
  • 损失函数：基于反向过程的条件独立伯努利分解推导出 BCE，并采用按关系体积归一化的 BCE，分别计算车道-车道与车道-交通元素损失后相加，以避免候选空间较大的关系主导梯度。
  • 推理融合：将细化分数与原始分数按关系特定融合权重加权融合，再经阈值化得到最终离散拓扑；原文未报告融合权重与阈值 τ 的具体取值。
  • 原文未报告：融合权重、阈值、节点特征维度、GAT 隐藏维度等具体超参数取值。
