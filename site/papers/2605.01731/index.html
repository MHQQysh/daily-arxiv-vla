Lateral String Stability for Vehicle Platoons: Formulation, Definition, and Analysis

2026-05-03 · 原文 · 翻译 · 2605.01731

解决自动驾驶车队（vehicle platoons）在横向控制中的横向弦稳定性（lateral string stability）问题。 研究任务与场景：连接自动驾驶车辆队列在跟随同一期望路径行驶时，路径跟踪误差（尤其是横向/侧向误差）如何在车队中沿车辆传递与放大，重点是传感器遮挡（sensor occlusion）和地图无关导航（map-free navigation）条件下的安全风险。 研究问题：缺乏对横向弦稳定性的严格定义与通用分析框架；传统的时间域比较无法反映同一点位的空间误差传播；同时需探究仅靠车载感知与依赖车车通信（V2V）两种信息获取方式在误差衰减能力上的差异。

Card 02 论文概述

论文概述

  • 解决自动驾驶车队（vehicle platoons）在横向控制中的横向弦稳定性（lateral string stability）问题。
  • 研究任务与场景：连接自动驾驶车辆队列在跟随同一期望路径行驶时，路径跟踪误差（尤其是横向/侧向误差）如何在车队中沿车辆传递与放大，重点是传感器遮挡（sensor occlusion）和地图无关导航（map-free navigation）条件下的安全风险。
  • 研究问题：缺乏对横向弦稳定性的严格定义与通用分析框架；传统的时间域比较无法反映同一点位的空间误差传播；同时需探究仅靠车载感知与依赖车车通信（V2V）两种信息获取方式在误差衰减能力上的差异。
Card 03 核心贡献

核心贡献

  • 提出基于路径弧长（arc-length，欧拉视角）重参数化的车队横向控制问题系统化建模框架，以便在相同空间点上比较不同车辆的跟踪误差。
  • 提出车辆队列横向弦稳定性的形式化定义——ℒ₂ 横向弦稳定性，并给出其充要条件。
  • 提出一种新型“向前车学习”（learn-from-predecessor）控制策略，利用 V2V 通信传递前车输出与学习控制项，用于提升误差衰减能力。
  • 系统分析比较了两种跟踪方案（predecessor-tracking PT 与 desired-path tracking DT）、两种控制策略（反馈-前馈 FF 与 LFP）以及两种误差度量（跟踪误差向量与横向误差），得出仅靠车载感知无法保证误差衰减的不可行性结论，并识别出控制器结构上必要的反馈需求。
Card 04 方法描述

方法描述

  • 所属模块：车队横向路径跟踪控制与弦稳定性分析，非端到端自动驾驶全栈方法。
  • 输入传感器：车载感知模式依赖立体视觉、LiDAR 跟踪或相机-LiDAR 融合及 GNSS 位姿估计来记录前车行驶路径；V2V 模式利用车车通信接收期望路径与前车输出数据。具体传感器型号原文未报告。
  • 场景表示：将各车相对期望路径的跟踪误差沿路径弧长重参数化，以弧长 l_d 作为空间坐标，实现跨车辆一致比较。
  • 模型结构：采用自行车动力学模型，结合路径跟踪误差（横向误差 e_lat 与航向误差 θ̃）动力学；对误差模型进行弧长重参数化后，形成基于期望路径弧长的线性定常空间域方程；在此基础上分别建立 FF 控制器与 LFP 控制器（包含 PD 反馈与学习/前馈项等结构）。
  • 关键技术：弧长重参数化（欧拉视角）、反馈-前馈控制、V2V 通信下的前车学习控制、ℒ₂ 横向弦稳定性分析及其充要条件推导。
