Card 02 论文概述

论文概述

  • 任务：面向推理型视觉–语言–动作（VLA）驾驶策略，控制其推理痕迹（Chain-of-Causation，CoC）对最终轨迹解码的影响强度，而非判断推理是否正确。
  • 应用场景：自动驾驶端到端规划。VLM 先写出推理痕迹并存入键–值缓存，再由 flow-matching 动作专家经若干 Euler 步解码轨迹。
  • 研究问题：错误推理痕迹会导致错误规划，且即使读起来正确的痕迹全强度跟随也可能偏离记录轨迹；现有方法（RL 后训练、幻觉检测器）只做“保留或丢弃”，无法处理“看似正确却误导”的情形。论文因此将问题重构为“每步应以多强的权重让推理引导动作”。
Card 03 核心贡献

核心贡献

  • 提出 CoC-CFG：在策略完整上下文与“仅移除推理片段、其他不变”的参考上下文之间做 classifier-free guidance，每个 Euler 步用一个权重 w_k 衰减或放大推理影响，w=1 精确还原原策略。
  • 将逐步引导权重的选择建模为有限时域马尔可夫决策过程，终局奖励为完整规划的评分；由于专家冻结、噪声固定、生成可重置，单步分支即可“测量”而非“自举”动作价值。
  • 提出 Q-adaptive guidance：用小 critic 拟合带锚点偏离代价与裁剪的测量优势标签，并对历史各代标签按年龄折扣联合重拟合，逐阶段迭代改进控制器。
  • 在冻结的 Alpamayo 1.5 上给出开环/闭环仿真、Waymo 端到端驾驶 held-out 与隐藏测试集的证据，报告在隐藏测试集上取得已发表方法中的新最优。
Card 04 方法描述

方法描述

  • 所属模块：推理型 VLA 的解码/采样阶段控制模块，作用于 flow-matching 动作专家的 Euler 积分过程，VLM 与动作专家均保持冻结。
  • 输入传感器：原文在方法部分未逐项列出传感器配置；Waymo 部分说明使用相机图像并经规则化转换映射到 Alpamayo 1.5 的相机几何，Alpasim 部分说明在真实驾驶的神经重建中进行闭环渲染。
  • 场景表示：上下文 C 为 VLM 的键–值缓存，包含观测、指令与推理痕迹；推理痕迹占据 C 中一段连续 token 区间（reasoning span）；C_ref 为移除该区间且保持其余条目位置不变的参考上下文；状态 s_k=(k, x_k, w_{k-1}, C)，w_{-1}:=a_0。
  • 模型结构：两阶段 VLA（VLM 写推理痕迹 + flow-matching 动作专家）；CoC-CFG 的引导 Euler 步为 x_{k+1}=x_k+Δt(v(x_k,t_k,C_ref)+w_k[v(x_k,t_k,C_full)−v(x_k,t_k,C_ref)])；Q-adaptive guidance 使用小型 critics Q_m，部署时取均值 Q̄ 并做带偏离惩罚的 argmax：w_k=argmax_{a∈A}(Q̄(s_k,a)−η\|a−a_0\|)。
  • 关键技术：动作集 A 为有限离散权重集合且含 1，锚点 a_0 为训练场景上最优固定权重（Alpasim 为 w=0.5）或骨干默认 w=1（Waymo）；标签为成对单步分支的优势 A(s_k,a)=G^π(s_k,a)−G^π(s_k,a_0)，无自举、无对下一动作取 max；拟合目标对离开锚点施加固定代价 λ_c 与比例代价 λ_m\|a−a_0\|并裁剪到 [−τ, τ]；多阶段损失按 ρ^{n−j} 折扣累加历史标签；推理时不使用评分参考与分支 rollout。
  • 原文未报告：critic 的具体网络层数、参数量、特征维度等架构细节；λ_c、λ_m、τ、η、ρ 的具体取值；动作集 A 的具体元素列表（除示例性提到的 0、0.25、0.5、0.75、1.0、1.25、1.5、2.0 等固定权重用于对比外，未明确 A 的完整定义）。
