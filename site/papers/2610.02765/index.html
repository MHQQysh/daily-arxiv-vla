Card 02 论文概述

论文概述

  • 任务：为自动驾驶规划器输出的候选轨迹设计安全监视器，在执行前判断该轨迹在其固定时间视界内是否会导致碰撞（safe / unsafe）。
  • 应用场景：自动驾驶车辆执行规划轨迹前的安全筛查，输入为前视 RGB 相机图像叠加候选轨迹以及描述安全监控任务的提示词，可与任意黑盒规划器解耦、后处理式部署。
  • 研究问题：VLM 虽具备常识推理能力，但其原始 safe/unsafe 预测过度自信、可靠性不足，无法直接用于安全关键场景；同时真实场景中不安全样本稀少、预测难度随场景变化，需要在有限样本下对 VLM 预测做概率校准，保证低漏报率的同时尽量抑制误报。
Card 03 核心贡献

核心贡献

  • 提出 Split Label-Localized Conformal Prediction（SLLCP）：在冻结 VLM 之上做后处理校准，将不可靠预测转化为概率校准的安全预测集，在可交换性假设下提供标签条件、有限样本、无分布假设的覆盖率保证。
  • 提出场景自适应的局部化流程：在 VLM 隐状态投影空间中，对与测试输入相近的校准经验加权，以计算不确定性阈值，从而应对不同驾驶场景下安全估计难度的差异。
  • 用逻辑回归探针替代原始 VLM 布尔 token 概率来构造非一致性分数，并使用 UMAP 降维获得局部表示，实现按标签分别校准以应对数据类别不平衡。
  • 在 CARLA 的 15k 条未见场景轨迹上验证漏报不安全轨迹与误报之间的权衡，用同一组超参数同时显著改善两个开放权重 VLM 的校准效果。
Card 04 方法描述

方法描述

  • 所属模块：规划器无关（planner-agnostic）的后处理安全监控层，位于规划模块之后、轨迹执行之前，不更新任何 VLM 权重。
  • 输入传感器：前视 RGB 相机图像（叠加候选轨迹）与固定安全提示词；原文未报告其他传感器输入。
  • 场景表示：VLM 在布尔答案 token 之前、经冻结语言模型最终 RMSNorm 后的隐藏状态 e_VLM(x)，再经 UMAP 投影到二维潜在表示 z(x)=g(e_VLM(x))；轨迹足迹在图中以蓝色显示，黄色路点间隔 0.5 s。
  • 模型结构：冻结的基座 VLM（Qwen3-VL-8B-Instruct、Cosmos-Reason2-8B），线性逻辑回归探针 Ŷ(x)=σ(wᵀe_VLM(x)+b) 用于估计不安全概率，二维 UMAP 投影用于局部化，拉普拉斯核 κ(u)=exp(−u) 与带宽 h 计算局部权重，按标签计算局部加权分位数与留出修正量，最终预测集为 Ĉ(x)={y∈𝒴: r(Ŷ(x),y) ≤ q̂_loc,y(x)+q̂_corr,y}。
  • 关键技术：Split Conformal Prediction、Label-conditional Conformal Prediction、Split Localized Conformal Prediction 的组合；校准集先划分为 D_cal^local（用于学习分数 r 并拟合 q̂_loc）与 D_cal^CP（用于按标签计算修正量 q̂_corr,y）；监视器在 unsafe∈Ĉ(x) 时报警。
  • 原文未报告：网络训练的损失细节、探针训练的具体优化设置、推理时延与算力开销。
Card 05 数据集与资源

数据集与资源

  • 数据集：CARLA 仿真器中采集的 40,455 帧、90 个 episode、30 个底层场景 ID，来自 Fail2Drive 的三个场景族 HardBrake、PedestriansOnRoad、Wall；轨迹与前视图像由 SimLingo 规划器采集；轨迹若用 PID 控制器跟踪 2.5 s 后与车辆、行人或其他物体碰撞则标为 unsafe。
  • 数据划分：D_cal^local 为 19,528 帧（2,615 unsafe），D_cal^CP 为 5,606 帧（856 unsafe），评估集为 15,321 帧（2,489 unsafe；12,832 safe）；同一场景 ID 的所有随机种子位于划分同一侧。
  • 仿真器/平台：CARLA 仿真器；原文未报告实车平台。
  • 模型规模：Qwen3-VL-8B-Instruct 与 Cosmos-Reason2-8B（均为开放权重、未微调、接收相同固定二值安全提示与轨迹图像）；原文未报告其他模型规模、训练资源（GPU 型号、数量、训练时长）与实车资源。
Card 06 评估与结果

评估与结果

  • 评估基准：CARLA 中未见的 Fail2Drive 场景 ID（HardBrake、PedestriansOnRoad、Wall）。
  • 评估指标：unsafe 标签覆盖率（越高越好）、报警误报率 Alarm FPR（越低越好）、歧义率 Ambiguity（预测集同时包含两个标签的比例，越低越好）；统一设置 α=0.1，用 90% Beta-binomial 置信区间判断经验覆盖率是否落在名义覆盖率区间内。
  • 对比方法：Raw VLM (binary)、Raw VLM (0.1/0.9)，以及四个消融——去掉局部性（全局标签条件 CP）、去掉逻辑探针（用原始 VLM 分数）、去掉 UMAP 投影（用原始嵌入距离）、去掉按标签修正（使用与标签无关的阈值）。
  • 关键结果（15,321 帧评估集）：原始 VLM 二值判断仅覆盖 4.6%（Qwen）与 39.1%（Cosmos）的不安全轨迹；SLLCP 将 unsafe 覆盖率提升至 89.6%（Qwen）与 88.4%（Cosmos），落在用户设定要求的有限样本 Beta-binomial 置信区间内，相对原始 VLM 分别提升 85.0 与 49.3 个百分点；对应报警 FPR 为 51.8% 与 44.5%，歧义率为 37.6% 与 33.6%。
  • 消融结果：去掉逻辑探针时覆盖率近 99%（Qwen 99.2%、Cosmos 99.6%），但 safe 帧误报至少 95.6%/99.0%，不具实用性；去掉 UMAP 投影后覆盖率降至 84.3%（Qwen）与 82.4%（Cosmos）；去掉按标签条件 CP 后覆盖率进一步降至 70.9%（Qwen）与 66.7%（Cosmos）；去掉局部性时覆盖率为 77.5%（Qwen，FPR 27.7%）与 80.5%（Cosmos，FPR 30.4%）。相比无探针消融，SLLCP 将报警 FPR 分别降低 43.8 与 54.5 个百分点，同时保持 unsafe 覆盖率接近 90%。
  • 评估条件：全部为 CARLA 仿真中的开环评估（对候选轨迹进行安全性判定），原文未报告闭环驾驶评测与实车验证。
  • 局限性：结果对 UMAP 投影与核超参数敏感；数据为完整 episode 的连续视频帧，帧间相关破坏了可交换性；D_cal 与测试之间的场景偏移也会影响经验性能。
