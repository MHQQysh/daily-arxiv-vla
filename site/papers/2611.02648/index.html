Card 02 论文概述

论文概述

  • 论文研究自动驾驶风险感知中的三维道路异常分割任务，即在稀疏 LiDAR 点云上对未见过的道路危险物（如掉落货物、车辆部件、碎片）进行逐点异常评分与定位。

  • 核心研究问题是：如何将全景环视相机的互补语义证据引入逐点 LiDAR 异常排序流程，同时不破坏 LiDAR 定义的点级度量支撑与已校准的冻结异常评分接口；即同时解决“哪些视觉证据与每个被占用 LiDAR 区域相关”和“该证据可对点特征施加多大影响”两个耦合问题。
Card 03 核心贡献

核心贡献

  • 提出将相机辅助逐点道路异常分割形式化为两个耦合要求：为每个被占用 LiDAR 区域选择场景相关的视觉证据，并限制其对冻结异常评分器所消费点特征的影响幅度。
  • 提出 ReinSeg 框架，将免标定输入的全景视觉记忆检索与相对范数约束的特征精化结合，保留 LiDAR 定义的度量支撑和原始 LIDO 异常评分接口，且仅用已知类别标签优化。
  • 在 STU 基准上证明 ReinSeg 显著提升逐点危险排序并降低高召回虚警负担；通过匹配接口、组件隔离和传感器干预实验验证增益来自检索到的场景证据、相对范数约束不可或缺，且退化相机输入不会使系统低于纯 LiDAR 性能。
  • 实验显示相对 REL 提升 24.99 个 AP 百分点、FPR95 降低 0.99 个百分点，并在 21.8 帧/秒下运行。
Card 04 方法描述

方法描述

  • 所属模块：风险感知感知模块中的逐点三维道路异常分割；以 LIDO 逐点异常评分器为参考接口，视觉路径仅精化中间点特征。
  • 输入传感器：单帧同步样本包含 LiDAR 点云 P={(x_i, r_i)} 与 8 路环视 RGB 图像；检索模块不接收相机内参、相机–LiDAR 外参、自车位姿变换、射线、深度提升或投影点坐标。
  • 场景表示：LiDAR 点体素化为 5 cm，稀疏卷积编码器 E_L 输出 96 维体素特征；体素特征沿高度平均并散射到 400×400 BEV 网格（0.25 m 单元），仅保留被占用单元作为查询；每路图像经 Swin-T + FPN 融合后自适应池化为 8×14 网格（每视角 112 个 token，共 T=896 个 token）构成共享视觉记忆。
  • 模型结构与关键技术：

- LiDAR 参考评分接口：冻结的 E_L 与 LIDO 语义/对比投影、类均值激活向量及异常方程 g_LIDO，分数写回原始点索引，保持 STU 评估点集不变；参考适配分两阶段（已知类目标联合训练、类条件虚拟离群点辅助头后丢弃），均仅用 ID 标签，适配后冻结。

- 免标定输入视觉检索：图像 token 由线性投影、二维傅里叶位置编码与学习到的相机身份嵌入组成；被占用 BEV 单元以 LiDAR BEV 特征加 BEV 傅里叶位置编码形成查询，经 4 头缩放点积交叉注意力（d_k=16）从 896 个 token 中检索上下文，再经拼接投影、层归一化与 FFN 得到 64 维单元视觉表示。

- BEV 融合：检索特征与 LiDAR BEV 特征散射到同一网格（未占用处置零），经 160 通道拼接、3×3 卷积+BN+ReLU 与两层 96 通道 3×3 卷积残差块融合；每个点取所在单元的融合特征。

- 有界多模态精化：两层适配器（96 维隐藏层、层归一化、GELU）由 [LiDAR 特征; 检索上下文] 提出修正方向 δ_i；修正幅度为 β‖f_i^L‖₂，其中 β=ρ·tanh(a)，ρ=0.10，a 初始化为 0，从而严格满足 ‖Δf_i‖₂ ≤ ρ‖f_i^L‖₂；精化特征由未改动的 g_LIDO 评分。

- 仅已知类优化：总损失 L = L_sem + 2L_fp + 0.1L_cons，其中 L_sem 为加权交叉熵加 1.5 倍 Lovász–Softmax，L_fp 为单向惩罚（阻止 ID 点异常响应升高），L_cons 为与参考分数的 SmoothL1 一致性项；梯度只更新视觉路径，LiDAR 编码器与评分接口冻结。

Card 06 评估与结果

评估与结果

  • 评估基准：STU 官方验证集，使用官方点级评估器，分数在所有有效点上汇总；另在 227 个选择扫描上测已知类 mIoU；逐序列 AP 在 19 个评估序列上独立计算并做序列级 bootstrap。
  • 评估指标：AP（主指标）、AUROC、FPR95（95% 异常召回下的 ID 点保留比例及绝对筛查点数）、已知类 mIoU、延迟/FPS/推理内存。
  • 关键数值：

- 相对 LIDO：AP 从 27.54% 提升至 35.67%，AUROC 从 95.05% 升至 97.24%，FPR95 从 34.85% 降至 10.61%；95% 召回下筛查 ID 点数从 6754 万降至 2055 万，其中路面点从 6552 万降至 1984 万。

- 相对 REL：AP 从 10.68% 提升 24.99 个百分点，AUROC 提升 0.12 个百分点，FPR95 降低 0.99 个百分点。

- 相对共享编码器与评分器的冻结 LiDAR 参考：AP 从 30.02% 升至 35.67%，AUROC 从 97.09% 升至 97.24%，mIoU 从 47.62% 升至 53.42%，FPR95 从 12.87% 降至 10.61%；平均逐序列 AP 增益 3.07 点，bootstrap 95% 区间 [1.81, 4.48]，19 个序列中 16 个提升，各距离段均提升（2.5–10 m 和 10–20 m 分别 +6.0 和 +6.3 AP）。

- 匹配视觉接口：投影局部 31.76% AP、投影+全局 33.38% AP，ReinSeg 免标定检索 35.67% AP，分别高出 3.91 和 2.29 点。

- 组件隔离：无图像 LiDAR 适配器 32.99% AP；常量视觉记忆 33.48% AP；全局池化 RGB 32.76% AP；去掉相对范数约束后 AP 崩溃至 18.43%、FPR95 升至 77.77%；用参考异常分数门控修正降至 32.02% AP；无 BEV 融合器下降 2.54 点；解冻 LIDO 后 mIoU 升至 79.34% 但 AUROC 降至 91.00%、FPR95 升至 51.81%。
