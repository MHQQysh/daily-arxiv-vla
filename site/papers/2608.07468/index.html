SimWAM: A Simple World Action Model for End-to-End Autonomous Driving

Card 02 论文概述

论文概述

  • 解决自动驾驶中的端到端轨迹规划任务，面向实时、高效的规划应用场景。
  • 研究问题：现有 World-Action Models（WAMs）在推理时依赖显式未来场景生成，导致推理延迟高，且轨迹规划与未来视频生成强耦合。SimWAM 旨在利用训练时的未来视频预测作为监督信号，提升共训练表示学习，同时保持推理时无需未来帧生成的直接轨迹预测能力，兼顾性能与效率。
Card 03 核心贡献

核心贡献

  • 提出 SimWAM，一种简洁有效的 World-Action Model，将未来视频预测用作训练时监督信号，通过联合流匹配（joint flow matching）使预训练视频专家与轻量动作专家协同训练。
  • 设计隔离注意力掩码（isolated attention mask），使动作预测与未来帧表示解耦，推理时无需显式生成未来帧，显著降低推理延迟。
  • 架构解耦支持视频骨干可替换、动作专家可独立缩放，无需修改学习目标或推理流程，具备良好的可扩展性。
  • 将确定性流 ODE 转化为边缘保持的 SDE，并采用 GRPO 强化学习，在轨迹模仿之外进一步优化组合式驾驶奖励。
Card 04 方法描述

方法描述

  • 所属模块：端到端轨迹规划（World-Action Model）。
  • 输入传感器：仅使用单个前置摄像头，分辨率 384×672。
  • 场景表示：视频专家使用预训练视频 VAE 将驾驶帧映射为潜在 token；动作专家直接预测 ego 坐标系下的轨迹航点（8 个航点，4 秒，2 Hz）。
  • 模型结构：

- 视频专家：视频 Diffusion Transformer（DiT），初始化为 Wan2.2-5B，配套视频 VAE 和 T5 文本编码器。

- 动作专家：轻量 Diffusion Transformer，隐藏维度 1024，含小 MLP 嵌入 ego 状态。

  • 关键技术：

- 两专家通过共享注意力交互，视频专家与动作专家采用联合流匹配进行共训练，目标函数为动作流匹配损失加视频流匹配损失的加权和。

- 隔离注意力掩码使动作 token 与未来帧 token 相互不可见，动作专家只依赖当前观测表示 z(o_t)、ego 状态和导航指令。

- 强化学习阶段将流 ODE 转换为 SDE，采用 GRPO 采样 G=8 条候选轨迹，使用 NAVSIM PDM 奖励计算组相对优势，仅更新动作专家注意力投影上的 rank-32 LoRA 适配器。

Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM navtest 闭环节点仿真基准；nuScenes 开环规划基准（零样本迁移）；附录含 NAVSIM-v2 与 PhysicalAI-Autonomous-Vehicles。
  • 评估指标：NAVSIM 主要指标为 PDMS（由 NC、DAC 二元惩罚因子与 EP、TTC、C 加权质量项组成）；nuScenes 采用 L2 误差（米）与碰撞率（%）。
  • 关键数值：

- NAVSIM navtest：SimWAM 达到 91.5 PDMS，超越最强 VLM 规划器 SGDrive（91.1）约 0.4 点，优于 ExploreVLA（90.4）约 1.1 点，优于 DriveLaW（89.1）约 2.4 点、DriveWAM（90.1）约 1.4 点。

- 组件分析：Action-only PDMS 86.6，+Video 90.3，+RL（最终）91.5。

- 注意力掩码：隔离掩码 PDMS 90.3，优于双向掩码（90.2）与 action→video 掩码（90.1）。

- 视频骨干替换：LTX 88.7，Wan2.1-1.3B 90.2，Cosmos-Predict2.5 90.4，Wan2.2-5B 90.3。

- 动作专家规模：0.21B PDMS 89.9，0.45B 90.1，1.02B 90.3。

  • 对比方法：UniAD、TransFuser、ARTEMIS、WorldRFT、DiffusionDrive、WoTE、SeerDrive、UniWorldVLA、DriveDreamer-Policy、Vega、ImagiDrive、AutoVLA、ReCogDrive、ExploreVLA、DriveVLA-W0、SGDrive、Epona、PWM、DriveLaW、DriveWAM 等。
  • 开环/闭环/仿真/实车条件：NAVSIM 采用闭环（非反应式）仿真；nuScenes 采用开环规划评价；均为仿真数据集，无实车验证。
