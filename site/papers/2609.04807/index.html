Card 02 论文概述

论文概述

  • 该论文解决多车协同自动驾驶中的决策协商问题，任务为多智能体路径规划与意图协商。

Card 03 核心贡献

核心贡献

  • 提出 CoLMIN，一个基于 LLM 的多决策路径协商框架，通过生成多个候选驾驶意图并进行联合评估，实现稳定鲁棒的决策共识。
  • 设计 LLM-based Multi-Intent Negotiation Module (LMin)，采用 Negotiator–Evaluator 范式，在单轮协商中生成并评估多个可行候选意图，扩大协商空间。
  • 提出 Evaluation-based Shallow Reflection Module (ESRM)，针对低分候选方案生成短期改进建议并反馈到下一轮协商，加速局部共识收敛。
  • 提出 LLM-based Deep Reflection Module (LDRM)，对多轮协商历史进行长期反思，识别过度自信与推理固化，抑制认知僵化，避免收敛到次优解。
  • 在 CARLA 仿真环境中完成大量实验，在多个具有挑战性的交互驾驶场景下取得最先进性能，代码发布于 https://github.com/HuangZhe885/CoLMIN。

方法描述

  • 所属模块：感知模块、意图预测器、协商决策模块（LMin、ESRM、LDRM）以及低级控制模块组成的完整决策管线。

  • 场景表示：BEV 感知特征、BEV occupancy 地图用于规划任务的辅助输入；对象级 3D 感知结果与交互相关信息转化为文本描述用于 LLM 协商。
  • 模型结构：LMin 采用 Negotiator–Evaluator 双重结构；Negotiator 通过语言交互顺序发言并生成多个候选方案；Evaluator 将意图分发给各车、利用低层规划生成未来 waypoints，并综合安全性、效率与共识三个维度打分（S_score = w_S·S + w_E·E + w_C·C）。
  • 关键技术：多轮迭代协商，协商终止条件为最佳分数超过阈值 τ 或达到最大轮数 R_max；ESRM 在每轮评估后对低分方案生成安全性与效率方面改进建议；LDRM 在协商超过预设轮数 k 后触发，依据重复率高、评估分数低、表达过度自信、偏离群体共识四条标准检测长期认知偏差并生成纠正性指导；低级控制模块采用 CoLMDriver [25] 的低级控制设计，仅在检测到意图冲突时介入控制管线。
  • 目标函数：协商建模为带约束的迭代共识优化问题，优化联合策略以在满足安全约束下提升效率与共识质量。
