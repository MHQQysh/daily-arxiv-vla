DVD: Dynamic Vector Decoding for Efficient MLLM-based Perception

2026-10-08 · 原文 · 翻译 · 2610.12266

论文面向自动驾驶、机器人、人机交互等场景中的多模态大模型（MLLM）感知任务。 解决的核心问题是：现有 MLLM 感知方法要么使用文本坐标表示导致 token 开销过大，要么使用固定范围量化导致空间范围与精度受限，尤其难以适配 3D 空间无界且定位精度要求高的场景。 论文提出动态向量解码（DVD），统一 2D 与 3D 感知输出（2D 框、2D 掩码、3D 框）的表示方式，在少量 token 下实现无范围限制、高精度的感知表示。

Card 02 论文概述

论文概述

  • 论文面向自动驾驶、机器人、人机交互等场景中的多模态大模型（MLLM）感知任务。
  • 解决的核心问题是：现有 MLLM 感知方法要么使用文本坐标表示导致 token 开销过大，要么使用固定范围量化导致空间范围与精度受限，尤其难以适配 3D 空间无界且定位精度要求高的场景。
  • 论文提出动态向量解码（DVD），统一 2D 与 3D 感知输出（2D 框、2D 掩码、3D 框）的表示方式，在少量 token 下实现无范围限制、高精度的感知表示。
Card 03 核心贡献

核心贡献

  • 提出 DVD，将 3D 框、2D 框和 2D 掩码统一转换为 1D 向量序列，并在高维空间中学习统一 codebook，将序列投影为紧凑离散 token，提升推理效率并提供内在压缩能力。
  • 引入任务无关的几何损失，基于双向 chamfer 距离，在几何层面对解码表示进行监督，使统一 codebook 能捕捉异构 2D/3D 感知任务的几何结构。
  • 设计了 1D 编码器-解码器架构与统一向量自编码器，支持多感知任务联合训练，并在推理时仅需一个轻量 de-tokenizer 将 MLLM 输出的感知 token 还原为原始 2D/3D 表示。
  • 在 3D grounding、2D grounding 与 2D 指代分割（RES）基准上验证了方法的有效性与通用性，并报告了 token 开销与推理时延的显著降低。
Card 04 方法描述

方法描述

  • 所属模块：MLLM 感知输出表示与解码模块，作为 MLLM 输出 token 与感知表示之间的桥接。
  • 输入传感器：原文未报告具体传感器配置；仅说明使用 Qwen3-VL（SigLIP2 视觉编码器、MLP 投影器、Qwen3 LLM）作为预训练 MLLM，数据集层面涉及 RGB-D、RGB 图像与 3D 标注。
  • 场景表示：将 2D 框表示为左上与右下角点展平序列 (x1,y1,x2,y2)；2D 掩码沿边缘从左上点顺时针均匀采样固定点 (x1,y1,…,xN,yN) 并按图像宽高归一化；3D 框使用 (x,y,z,w,h,l,R) 表示，其中 (x,y,z) 为中心、w,h,l 为尺寸、R∈R^{3×3} 为旋转矩阵，因 3D 场景无界而直接使用原始数值。
  • 模型结构：统一向量自编码器由 1D 编码器、可学习 codebook 与 1D 解码器组成；编码器将长度 L 的 1D 序列映射为潜变量 z∈R^{B×L/K×C}，K 为下采样因子、C 为特征维度；通过欧氏距离在 codebook 中选取最近量化向量；对称 1D 解码器上采样重建原始 1D 序列。
  • 关键技术：扩展 MLLM 词表加入 M 个新 token 对应 codebook 的 M 个码向量，训练沿用标准 MLLM 范式且不修改骨干；推理时以预训练 1D 解码器作为轻量 de-tokenizer 完成离散 token 到 1D 序列再到 2D/3D 表示的还原。
  • 训练损失：L1 重建损失、VQ 损失（含 stop-gradient 与超参 β）以及基于双向 chamfer 距离的几何损失（2D 计算预测点集与目标点集间平均最小 L1 距离，3D 计算 3D 框顶点间平均最小 L1 距离），总损失为三者加权和。
Card 05 数据集与资源

数据集与资源

  • 数据集：3D grounding 使用 SUN-RGBD、Hypersim、KITTI、nuScenes，并在对比中涉及 ARKitScenes；2D grounding 与 RES 使用 RefCOCO、RefCOCO+、RefCOCOg。
  • 训练数据规模：约 1.98M 3D 框、2.31M 2D 框、1.52M 2D 掩码，按 1:1:1 比例收集；MLLM 训练使用 2.0M 由 2D/3D 感知标注构建的 QA。
  • 模型规模与超参：下采样尺度 K=2，codebook 大小 4096，潜变量隐藏通道 16，损失权重 λ1=λ2=λ3=1；自编码器学习率 1e-3 训练 24 epoch；MLLM 使用 Qwen3-VL（含 2B 与 8B 规模版本，对应 DVD-2B 与 DVD-8B）。
  • 训练资源：8 块 NVIDIA A100 GPU；MLLM 训练 batch size 64，AdamW 优化器，数据打包策略，基础学习率 5e-5、视觉编码器学习率 5e-6，全量微调 264K 迭代。
  • 仿真器与实车平台：原文未报告。
Card 06 评估与结果

评估与结果

  • 评估基准与指标：3D grounding 使用 Omni3D 定义的 AP3D@15；2D grounding 使用 Precision@0.5；RES 使用 cIoU；所有任务使用同一个训练模型评测。
  • 3D grounding 结果：DVD-2B 在 SUN-RGBD、Hypersim、nuScenes 上分别达到 40.0%、15.7%、19.8% AP3D；DVD-8B 分别达到 40.3%、18.4%、24.4% AP3D。与 VST-3B 相比，DVD-2B 在 SUN-RGBD 和 ARKitScenes 上分别高 2.7% 与 10.7% AP3D；DVD-8B 在 SUN-RGBD 与 nuScenes 上分别为 40.3% 与 24.4% AP3D。表中另报告 DVD-2B 在 ARKitScenes 62.4%、KITTI 31.4%。
  • 2D grounding 结果：DVD-2B 在 RefCOCO val/testA/testB 为 93.5/95.5/90.7，RefCOCO+ 为 87.7/92.9/82.4，RefCOCOg val/test 为 89.9/90.0；DVD-8B 为 RefCOCO 93.0/95.2/89.7，RefCOCO+ 87.7/92.9/82.7，RefCOCOg 88.7/89.8。DVD-2B 在 RefCOCOg test 上的 90.0% Precision 比 Rex-Omni 高 3.2%。
  • RES 结果：DVD-2B 在 RefCOCO 为 69.9/70.7/69.7，RefCOCO+ 为 64.2/68.2/61.8，RefCOCOg 为 70.4/71.0；DVD-8B 在 RefCOCO 为 75.4/76.9/74.6，RefCOCO+ 为 70.1/74.7（原文表格在 testB 处被截断），RefCOCOg 为 88.7/73.4（Table 1 报告值）；论文称 2D RES 保持有竞争力性能。
  • 对比方法：GroundingDINO、VistaLLM-7B、LISA-7B、Text4Seg、Qwen2.5-VL-3B/7B、Rex-Omni、Seed1.5-VL、Qwen3-VL-2B/8B、VST-3B、Gemini 2.0 Pro、Gemini 2.5 Pro、InternVL3.5-8B、UFO-8B、VLT、LAVT、M²SA、PixelLM-7B、PerceptionGPT-7B。
  • 效率结果：论文报告 DVD 显著降低 token 开销与推理时延，并在 2D 与 3D 任务上带来一致的时延下降；原文未给出具体时延与 token 数量的完整数值表。
  • 评估条件：全部结果在数据集基准上进行，原文未报告闭环仿真或实车测试。
