Card 02 论文概述

论文概述

  • 解决自动驾驶任务：长时域（long-horizon）端到端自动驾驶规划。
  • 应用场景：城市道路环境，需要应对加速、巡航、制动、停车、重新起步和跟车等纵向运动状态转换。
  • 研究问题：自动驾驶系统在规划中过度依赖历史规划状态，而过期的历史先验可能引入不可靠的时序信息，导致规划误差累积，尤其在纵向运动状态转换时问题更突出；现有方法未明确判断自生成的历史规划状态何时仍值得信任。
Card 03 核心贡献

核心贡献

  • 提出 StableDrive 框架，用于可靠的端到端长时域规划，解决过期历史先验和纵向运动阶段转换导致的规划误差。
  • 引入 Selective Momentum Memory (SMM)，基于 Mamba 选择性状态空间算子，跨规划周期建立因果记忆通路，并抑制过期历史先验。
  • 引入 Motion-Stage Training Scaffold (MSTS)，通过运动阶段、长时域轨迹和纵向运动监督指导阶段感知的未来运动学习，训练后移除，不增加推理开销。
  • 提出固定中点检查点构建方法（Fixed Midpoint Checkpoint Construction），融合两个互补训练端点的参数，无需模型集成或额外推理计算，得到单一可部署的 SMM 规划器。
  • 提出 LT-nuScenes 基准子集，用于评估纵向运动转换下的规划鲁棒性。
Card 04 方法描述

方法描述

  • 所属模块：端到端规划模块（稀疏感知与规划管线，继承 MomAD 与 SparseDrive 结构）。
  • 输入传感器：多视角相机图像（camera-only input）。
  • 场景表示：稀疏场景表示（sparse agent and map instances），联合场景交互生成命令条件和模式条件下的规划槽位。
  • 模型结构：SMM 采用 Mamba 选择性状态空间算子处理因果序列；MSTS 采用共享的 Horizon Mamba 块（训练期间使用）；部署时仅保留 SMM 计算图。
  • 关键技术：

- SMM：将前一周期自预测规划查询与分数缓存，经 sigmoid 分数调制后与当前查询拼接为因果序列，由 Mamba 算子处理，以接近恒等的残差读出（初始学习权重初始化）注入当前查询；缓存仅由历史预测构成，不依赖未来信息或真值。

- MSTS：利用运动阶段分布（stationary/accelerating/cruising/decelerating）、长时域轨迹累积位置监督和纵向运动监督引导阶段感知的未来运动学习。

- 端点构建：从相同 SMM 初始化出发，在匹配优化预算下训练 SMM-only 与 MSTS 两个端点；MSTS 端点训练后丢弃脚手架参数，保留共享规划器参数。

- 中点构建：对两个架构对齐端点（由名称、形状、类型匹配）取固定 α=0.5 的欧氏中点，得到单一部署检查点。

- 其他细节：SMM 缓存为 rank-local 且 scene-isolated，历史缺失或场景变化时重置；MSTS 中残差头初始化为零，规划损失仅通过 MSTS 反向传播进入共享规划头与上游表示；真值轨迹仅用于监督，不进入 SMM 缓存、阶段头输入或时域令牌。

Card 06 评估与结果

评估与结果

  • 评估基准：nuScenes（MomAD 评估协议）、LT-nuScenes、NAVSIM v1/v2。
  • 评估指标：L2 误差 (m)、碰撞率 (Col. Rate, %) 、TPC（横向变道指标，%）；NAVSIM 对应 PDMS/EPDMS。
  • 关键数值（nuScenes，1–6s 全时域，SOTA）：

- 平均碰撞率较此前最优降低 23.3%；TPC 降低 30.9%；L2 降低 11.8%。

- 4–6s 时域内：L2 降低 4.59%–5.83%，Col. Rate 降低 13.11%–27.10%，TPC 降低 9.51%–11.34%。

- 与本地复现的 MomAD 对比，6s L2、Col. Rate、TPC 分别提升 5.83%、13.11%、11.34%。

  • 关键数值（LT-nuScenes）：6s 碰撞率降低 23.81%，TPC 降低 10.90%，L2 降低 6.37%。
  • 关键数值（NAVSIM v1 和 v2）：在所有三个报告设置中实现最高 PDMS/EPDMS；其中 v2 navhard 的 EPDMS 较此前最优提高 5.7 点。
