Grounding What Shapes the Plan: Rethinking Groundedness for Physical Intelligence in Autonomous Driving

2026-10-05 · 原文 · 翻译 · 2610.07521

Card 02 论文概述

论文概述

  • 论文聚焦自动驾驶规划任务，指出驾驶模型的最终输出是动作/轨迹，因此需要重新思考“groundedness”在动作输出语境下的含义。
  • 研究问题：正确 grounded reasoning 不会自动带来理想的驾驶结果，即存在从 grounding 到 plan 的 transfer gap；论文以 PAI-AV 安全性样本上的碰撞率来衡量这一差距。
  • 论文提出 GroundAct，核心思想是以物理实体及其交互作为 grounding 单元，通过 reference token 保持连续实体状态可寻址，并让被引用实体与演化中提案的交互选择性修正规划。
  • 应用场景包括正常、分布外、安全关键的开环规划，以及 AlpaSim 闭环仿真驾驶。
Card 03 核心贡献

核心贡献

  • 提出 grounded planning，建立从推理中所 grounding 的实体到动作后果之间显式且可追踪的路径。
  • 提出 Token-as-Reference，用轻量符号引用让连续实体状态保持在模型中，同时由推理选择规划关键实体。
  • 提出 interaction-driven selective correction，使用被引用实体与演化 ego 提案之间的预测交互指导选择性精修。
  • 在 PAI-AV 的开环 Normal、OOD、Safety-Critical 基准以及 AlpaSim 闭环驾驶基准上评估 GroundAct。
  • 通过受控消融测试 reasoning-selected physical states 是否对规划有实质影响，并分析 GroundAct 是否能在修正不安全规划的同时保留已安全规划。
Card 04 方法描述

方法描述

  • 所属模块：GroundAct 覆盖连续多模态编码、离散自回归推理和迭代连续动作生成，包含 Physical AI reasoner 与 action expert。
  • 输入传感器：原文报告使用 temporal observations and driving context O；prefill-time grounding 中学习式 query 聚合 temporal visual features；实现中预测 clearance 时使用 four observed frames；原文未报告更细粒度传感器类型、分辨率或完整传感器配置。
  • 场景表示：以物理实体为 grounding 单元；向多模态 prefill 追加 K=64 个 entity tokens q_1,...,q_K，每个 token 的 Transformer 输出 M_i 作为可在模型中按索引寻址的连续实体状态。
  • Reference-based reasoning：离散 reference e_i = <\|entity i\|> 绑定到连续 prefill 状态 M_i；解码时通过 gate π_t 和 entity pointer 分配概率质量，pointer softmax 在存在非空候选时排除 detector-null slots；解析 reference 时读取原始 prefill 状态 M_i，并通过输入嵌入 u_{t+1} 供下一步解码使用。
  • Reference-driven planning：action expert 是 flow-matching trajectory generator，保留完整场景上下文；只有 reasoning sequence r 中被引用的实体集合 R(r) 的状态 M_R 进入显式 physical prediction 和 interaction modeling。
  • 交互与修正：对每个被引用实体预测运动 \hat{S}_i^{(k)}，并计算 proposal-relative interaction C_i^{(k)} = Interact(\hat{P}^{(k)}, \hat{S}_i^{(k)})；集合编码器聚合 M_i、\hat{S}_i^{(k)}、C_i^{(k)}，residual adapter R_φ 在 gate γ^{(k)} 下修正 base field；当没有有效实体被引用或 gate 不活跃时，该通路被 bypass，恢复 base field。
  • 训练目标：entity states 使用类别/null 预测、BEV box 回归和语言建模损失；physical references 使用 masked token prediction、matched-entity association 和 reference timing gate 损失；selective correction 使用 forecast 或 proposal-relative clearance 监督、field/raw/off/reg 残差损失，并与冻结的 base action expert 配合。
  • 原文未报告：更具体的网络层数、视觉骨干结构、推理文本模板、完整超参数设置在提供文本中未报告。
