Card 03 核心贡献

核心贡献

  • 提出 WALT，据原文表述为首个在不修改冻结预训练驾驶世界模型的前提下，从该世界模型迁移信息来学习紧凑生成式轨迹隐空间的框架。
  • 构建双分支轨迹自编码器，在保留度量的同时从冻结世界模型表征中迁移语义知识，并系统研究 JEPA 式与 REPA 式的纯轨迹表征设计。
  • 在 NAVSIMv1 与 NAVSIMv2 上验证方法的有效性与效率：相对原始航点基线实现 0.4 PDMS 增益、0.6 EPDMS 提升以及 30.5% 轨迹生成 FLOPs 降低。
  • 通过纯轨迹表征学习对照（JEPA-Traj、REPA-Traj）说明仅依赖轨迹本身的表征学习不足以显著提升规划器，世界模型对齐带来的场景语义监督是关键。
Card 04 方法描述

方法描述

  • 所属模块：动作侧轨迹规划接口，包含轨迹分词器（Stage 1）与轨迹规划头（Stage 2）两阶段流程；世界模型主干保持冻结。
  • 输入传感器：原文报告使用前视图图像作为可视化的世界模型视觉输入；完整传感器配置原文未报告。
  • 场景表示：使用冻结预训练驾驶世界模型 EponaV2 的隐藏状态/世界状态 token 作为教师表征，不修改世界模型本身。
  • 模型结构：双分支轨迹自编码器，两分支共享编码器并使用独立 refiner 产生语义特征 z_sem 与重建特征 z_rec，沿通道拼接得到 z_A = [z_sem; z_rec]，再由解码器还原轨迹；Stage 2 使用 rectified-flow 轨迹头，以条件流匹配目标生成 K 个拼接隐 token。
  • 关键技术：对语义分支施加世界模型对齐损失 L_WALT（CLIP 式对称对比目标，基于 K×M token 对余弦相似度平均并按帧/样本配对正负样本，使用跨 GPU gather 与可学习 logit 尺度 α=exp(s)）；重建分支使用 ℓ1 重建损失 L_rec，并以概率 p_sem 对语义分量做掩码，促使重建分支独立保留几何信息。
  • 关键技术：训练目标为 L_tokenizer = λ_rec L_rec + λ_align L_WALT；Stage 2 冻结分词器，仅微调轨迹头，流匹配目标由 P 个原始航点 token 改为 K 个隐 token；推理时从高斯噪声积分至 t=1 后由解码器输出航点。
  • 关键技术：额外设计并比较 JEPA-Traj（轨迹子段隐预测 + SIGReg 防坍缩）与 REPA-Traj（保留原始航点生成，并对轨迹流中间特征施加余弦对齐辅助损失）两种纯轨迹表征方案。
  • 原文未报告：完整传感器套件、世界模型内部具体网络层细节、隐 token 数 K 的具体取值。
Card 05 数据集与资源

数据集与资源

  • 数据集/基准：NAVSIMv1 navtest（官方规划协议）与 NAVSIMv2，均使用官方 benchmark 数据划分与评估协议。
  • 仿真器：NAVSIM 基准评估框架；其他仿真平台原文未报告。
  • 模型规模：以 EponaV2 作为预训练驾驶世界模型，保留其默认模型与规划器训练设置，仅替换轨迹表征与相关对齐模块；双分支分词器将轨迹压缩为 2 个 32 维 token（每个含 24 语义通道 + 8 重建通道）；每条轨迹为 8 个自车坐标系 (x, y, yaw) 航点，采样间隔 0.5 s。
  • 训练资源：Stage 1 在 32 张 H20 GPU 上训练 100 个 epoch，固定学习率 1×10⁻⁴；语义掩码概率 0.5，对齐权重 λ_align 为 0.1；JEPA-Traj 的 SIGReg 权重为 5×10⁻⁴，REPA-Traj 余弦对齐权重为 0.1。

Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIMv1 与 NAVSIMv2；评估条件为基准数据集上的开环规划评估（仿真/数据集评测），未报告闭环或实车测试。
  • 评估指标：NAVSIMv1 报告 PDMS 及 NC、DAC、EP、TTC、C；NAVSIMv2 报告 EPDMS 及 NC、DAC、DDC、TLC、EP、TTC、LK、HC、EC，所有指标 0–100 越高越好。
  • 关键数值（NAVSIMv1）：WALT 取得最优 PDMS 89.8，NC 99.1、DAC 97.0、EP 83.6、TTC 96.3、C 100；相对纯重建自编码器基线（PDMS 89.48）、JEPA-Traj（89.46）、REPA-Traj（89.49）与原始航点基线（89.42，NC 98.62，TTC 95.26）均有提升。
  • 关键数值（NAVSIMv2）：WALT 取得最优 EPDMS 87.9；相对无 RL 的 EponaV2（EPDMS 87.3），NC、DAC、TTC、HC 提升，EC 由 68.3 提升至 73.4，DDC 与 TLC 保持不变并匹配最佳报告值，EP 与 LK 分别小幅下降 0.2 与 0.1。
  • 关键数值（效率）：单步去噪轨迹生成成本由原始航点的 297.47 GFLOPs 降至含解码的隐生成 206.88 GFLOPs，减少 30.5%，压缩比 4×；冻结世界模型计算未计入。全 rollout 成本约为 N 倍该值加一次性解码开销。
  • 对比方法：NAVSIMv1 对比 LAW、DrivingGPT、World4Drive、Epona、PWM、TISA(w/o MOPT)、AdaThinkDrive(w/o RL)、Mimir、PRIX、ARTEMIS、DriveVLA-W0、DriveLaW、EponaV2(w/o RL) 及 Human；NAVSIMv2 对比 DriveVLA-W0、ARTEMIS*、PRIX*、DriveWorld-VLA、EponaV2(w/o RL) 及 Human；同时消融对比原始航点基线、纯重建自编码器、JEPA-Traj、REPA-Traj。
  • 表征分析：在 NAVSIMv1 相同样本上对 6 类驾驶行为（左变道、左转、右变道、右转、起步、正常直行）比较原始航点、JEPA-Traj 语义隐与 WALT 语义隐的类内/类间余弦相似度与 t-SNE；WALT 六类类内相似度均高于 JEPA-Traj，同时保留部分跨类相似性，说明世界模型对齐并非单纯最大化行为标签分离。
