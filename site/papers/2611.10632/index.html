Card 02 论文概述

论文概述

  • 任务：端到端自动驾驶规划，即在给定多视角相机图像与自车状态的条件下直接输出未来自车轨迹。
  • 应用场景：城市/结构化道路驾驶场景下的规划，基于 NAVSIM v2 非反应式仿真评测与 HUGSIM 零样本闭环评测。
  • 研究问题：现有世界动作模型（WAM）主要监督未来状态或最终动作，连接预测与规划的中间世界表示与动作表示仅被间接约束，导致表示学习效率低、规划性能次优；核心问题是“如何联合塑造世界表示与动作表示以更好支持 WAM 规划”。
Card 03 核心贡献

核心贡献

  • 将 WAM 规划中的联合表示塑造形式化为“角色匹配的表示目标 + 视觉-动作接口显式正则”的组合。
  • 提出 Latent-WAM++，包含三个协同组件：WoRC 构建可预测、非退化、几何感知的世界表示；TrajMF 通过一步多模态生成产生轨迹预测性动作特征；VARA 以非对称方式将该动作特征与视觉语义对齐。
  • 在 NAVSIM v2 上取得 90.1 EPDMS 的最优结果，并在零样本 HUGSIM 上取得平均 RC 47.0、平均 HD-Score 30.1。
  • 将规划器端到端训练成本从 Latent-WAM 的 1,600 GPU-hours 降至 190 GPU-hours，减少 88.1%。
Card 04 方法描述

方法描述

  • 所属模块：表征中心的世界动作模型（WAM）框架，由 World Representation Construction（WoRC）、Trajectory MeanFlow Planner（TrajMF）、Visual-Action Representation Alignment（VARA）三部分组成。
  • 输入传感器：多视角相机图像与自车状态（ego state）；推理阶段仅使用模态编码器与 TrajMF，所有输入来自相机图像和自车状态，不引入额外传感器模态；占用（occupancy）信息由冻结的占用提取器在训练/构建阶段提供，原文未报告其额外传感器来源。
  • 场景表示：世界表示 W_t_cur 由当前帧自车 token、视觉 token、经交叉注意力检索的占用 token 拼接构成；训练时动态世界模型在隐空间对未来 scene-ego latent 进行时序预测。
  • 模型结构：

- WoRC：DINOv2 编码器与投影器将多视角 patch token 与可学习 query 转成视觉 token；冻结 WorldMirror 教师提供 stop-gradient 几何蒸馏目标；冻结占用提取器输出占用单元并经 MLP 投影为占用 token；自车编码器产生 ego token；动态世界模型为带 3D 旋转位置编码与逐帧 teacher-forcing 掩码的 Transformer 解码器，预测未来 latent 并监督 ego 速度/加速度与命令；SIGReg 通过特征经验特征函数匹配标准高斯实现特征分布稳定化，无需 EMA 目标编码器。

- TrajMF：规划条件解码器用可学习动作 query 对世界表示做交叉注意力得到条件；以线性 flow 路径与 K_p 分量高斯混合先验构建轨迹流匹配，网络直接预测去噪轨迹并在诱导速度空间用 Improved MeanFlow 目标（JVP 计算方向导数、stop-gradient 处理导数项）优化，采样时每个先验分量各取一个噪声、一次性评估即生成 K_p 条多模态轨迹提案，再由 D_refine 条件聚合成最终轨迹；提案前的特征 H_a 定义为动作表示。

- VARA：将动作特征投影并平均得 z_a，对当前帧视觉 token 取平均并加 stop-gradient 得 z_v，用 1−cos(z_a,z_v) 进行非对称对齐，阻止梯度经视觉目标回传。

  • 关键技术：SIGReg 分布正则、几何蒸馏、占用上下文交叉注意力、Improved MeanFlow 一步多模态轨迹生成、stop-gradient 非对称表示对齐；总损失由世界损失（几何蒸馏+DWM+SIGReg，λ1=0.2）、动作损失（MeanFlow+轨迹聚合，λ2=20.0、λ3=7.0）与对齐损失（λ4=2.0）组成。

评估与结果

  • 评估基准：NAVSIM v2（开环/非反应式仿真）与 HUGSIM（零样本闭环仿真，分 easy/medium/hard/extreme 四档）。
