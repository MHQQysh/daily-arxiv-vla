Card 03 核心贡献

核心贡献

  • 提出面向标准 VLM 架构离散扩散 token 生成的多阶段协同优化流水线，在监督微调（SFT）、GRPO 强化学习与推理三个阶段分别引入优化方法，无需额外动作专家或专用 MoE Transformer。
  • 在 SFT 阶段提出轨迹离散化策略，将连续轨迹坐标与航向角等属性映射到一维码本 token，抑制文本序列化带来的噪声并增强输出结构约束。
  • 在 RL 阶段提出基于通过率指标（pass@1 与 pass@n）的多样性过滤机制，筛选精度与多样性兼具的 SFT 检查点作为 GRPO 起点，并过滤简单样本以聚焦中/难场景。
  • 提出动态自动驾驶解码策略 DAD，依据近端与远端累积置信度自适应选择“由近及远”或“由远及近”的解码顺序。
  • 构建 MD-Drive 系统，并在 NAVSIM、nuScenes、DriveCoT 上验证，报告相较未优化模型提升 29.7%。
Card 04 方法描述

方法描述

  • 所属模块：规划/轨迹生成模块，嵌入标准 VLM 的离散扩散生成范式；模型由视觉编码器、连接器和语言骨干三部分组成。
  • 输入传感器：原文在实验中以相机（C）为主，表格中标注 MD-Drive 使用相机、不使用 LiDAR；具体相机数量与配置原文未报告。
  • 场景表示：将轨迹规划段离散化为 token。每个 2D 坐标 (x,y) 通过量化器 Q 映射到一维均匀码本 Traj={v1,…,vK}，空间范围 [-M,M]、分辨率 Δg；完整 N 点轨迹展平为 token 对序列 Q(τ)={(v_x,n,v_y,n)}；航向角 γ 等其他规划属性同样映射到各自一维码本。
  • 模型结构：采用掩码离散扩散（absorbing state [MASK]），前向过程按转移矩阵 Q_t=(1-β_t)I+β_t·1m^T 逐步加噪，边缘分布 q(x_t\|x_0)=α_t x_0+(1-α_t)m；反向过程学习 p_θ(x_{t-1}\|x_t)；训练损失为 ELBO 导出的重加权交叉熵 L_D=E_t[L_t]，L_t 仅在掩码位置计算。
  • 关键技术一（SFT 轨迹离散化）：坐标 x 范围 [-5,70]、分辨率 0.25；y 范围 [-20,25]、分辨率 0.25；转向角 γ 范围 [-2,2]、分辨率 0.04。
  • 关键技术二（RL 多样性过滤）：在候选 SFT 策略集 P_cand 上计算 Acc_i=pass@1(π_i) 与 Div_i=pass@n(π_i)，选取满足 \|Acc_π*−Acc_j\|≤ε 且 Div_π*≥Div_j 的策略 π*；并对 RL 数据按 n 次随机 rollout 的众数划分 easy/mid/hard，仅保留 mid 与 hard 样本构成 P(Q)*；GRPO 目标以 π* 初始化并含 clip 与 KL 正则。原文给出理论分析：过拟合检查点使 rollout 同质化，σ_r≈0 导致优势 Â_i≈0 与策略梯度趋零。
  • 关键技术三（DAD 推理）：对长度 N 的 token 序列计算各位置置信度 C_i=max Softmax(ℓ_i)_v，累加近端 Φ_prox=Σ_{i=1}^{⌊N/2⌋}C_i 与远端 Φ_dist=Σ_{i=⌊N/2⌋+1}^{N}C_i；若 Φ_prox≥Φ_dist 采用 Near-to-Far 顺序 (1,2,…,N)，否则采用 Far-to-Near 顺序 (N,N−1,…,1)；解码模式在整次推理中固定。每步解码 token 数 n_k=⌈\|S_k\|(1−t_{k+1}/t_k)⌉。
  • 训练配置：bf16 精度；RL 每 rollout 组响应数为 8，LoRA rank 为 8；推理迭代步数 32，temperature=1，top_p=1。
  • 原文未报告视觉编码器与语言骨干的具体型号与参数量细节（仅说明以 DreamVL 为基础）。

Card 06 评估与结果

评估与结果

  • 评估基准与指标：

- NAVSIM-v1 闭环：NC、DAC、TTC、Comf.、EP、PDMS（均越高越好）；另有 DPP=(V_SFT+V_RL)/PDMS 衡量数据效率（越低越好）。

- nuScenes 开环：L2-1s/2s/3s、平均 L2、失败率 FR（均越低越好）。

- DriveCoT 开环：SL、FA、SD、SA、CT、BR 的 F1 与加权 F1（W-F1）。

  • NAVSIM 关键数值：MD-Drive PDMS=88.9，NC=97.1、DAC=94.0、TTC=92.2、Comf.=99.2、EP=90.3；相较 DrivingGPT（82.4）与 FSDrive（85.1）分别高 6.5 与 3.8 点；吞吐 243.9 tokens/s、推理频率 13.35 Hz，伴随 2.0 点性能下降。
  • 数据效率对比：MD-Drive DPP=2.37，低于 WAM-Flow（8.54）、WAM-Diff（17.26）、ReCogDrive（35.08），约比 WAM-Flow 数据效率高 3.6 倍；PDMS 略低于 WAM-Flow（90.3）、WAM-Diff（91.0）、ReCogDrive（90.8）。
  • nuScenes 关键数值：MD-Drive L2-1s=0.42、L2-2s=0.71、L2-3s=1.21、平均 L2=0.78、FR=0.00%；平均 L2 比最强自回归基线提升 1.68，比最佳离散扩散对比方法 MVLAD-AD 优 0.50。对比方法包括 LLaVA-1.6-7B、Llama-3.2-11B、Qwen2-VL-7B、ViLaD 系列、MVLAD-AD、DreamVL-Zero 等。
  • DriveCoT 关键数值：MD-Drive W-F1=0.81，高于自回归 SFT 的 Qwen2.5-VL-7B（0.73）0.08，与端到端 DriveCoT-Agent（0.82）相差 0.01；SL=0.87、FA=0.80、SD=0.55、SA=0.79、CT=0.47、BR=0.84。
  • 消融结果：轨迹离散化、DAD、GRPO 各阶段均一致提升性能；非过拟合 Checkpoint-5318 与过拟合 Checkpoint-10636 相比，pass@8 为 96.72% vs. 95.99%，经 GRPO 后 PDMS 为 88.9 vs. 85.
