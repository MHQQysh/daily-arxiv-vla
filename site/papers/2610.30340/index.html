Foundation4D: Towards a unified perception and reconstruction model for autonomous vehicles

2026-10-21 · 原文 · 翻译 · 2610.30340

论文面向自动驾驶多相机视频，提出统一的自动驾驶感知与重建模型 Foundation4D。 解决的任务包括：几何估计（相机位姿、位姿标定、度量深度）、3D 目标检测与跟踪、语义占据预测、以及基于 3D 高斯泼溅的场景重建与渲染。 应用场景为自动驾驶行车环境的理解（感知）与面向仿真的可渲染场景重建。 研究问题：如何用一个前馈共享模型，在多相机、多时间戳的驾驶视频上同时完成上述多种输出；如何高效融合跨相机与跨时间信息；如何将窗口级预测拼装为长视频级几何与轨迹；以及联合训练不同任务时的收益与干扰。

Card 03 核心贡献

核心贡献

  • 提出 Foundation4D：一个前馈感知与重建模型，通过共享多相机视频特征，并经由任务特定解码头输出几何、语义、目标、占据与高斯重建。
  • 提出视频级推理流程，对窗口级几何进行对齐并组装目标轨迹，从而在长驾驶序列上改进轨迹估计。
  • 提出数据标注流程，考虑传感器时序、自车与目标运动以及可见性，从驾驶记录中生成深度与语义占据标签。
  • 发布 PAI–Foundation4D 基准，包含密集标注与评测协议，可在同一组驾驶场景上比较几何、检测与占据方法。
  • 实验中展示联合训练对检测与几何的收益，并将预测几何与轨迹作为无 LiDAR NuRec 的先验，用于仿真场景重建。
Card 04 方法描述

方法描述

  • 所属模块：统一的多任务前馈模型，包含共享图像编码器与时空聚合器，以及几何、目标检测、语义占据、高斯重建等任务分支。
  • 输入传感器：多相机视频（多时间戳、多相机图像），训练与推理中还使用相机内参、镜头模型与静态相机-车体标定；检测/占据分支使用相机内外参进行采样投影；语义占据监督使用 LiDAR 派生几何与图像派生语义标签。
  • 场景表示：

- 几何分支输出各图像的相机 z 深度、窗口参考系下的辅助点图、相机位姿（分解为固定 rig 变换与随时间变化的参考相机轨迹）。

- 检测分支输出稀疏 3D 框（中心、尺寸、偏航、平面速度）及类别。

- 占据分支在车体 rig 坐标系下输出 0.2 m 体素的二值占据与语义标签，中间特征保持 BEV，仅在输出端引入高度维。

- 高斯分支输出静态高斯、与目标关联的高斯以及天空立方体贴图组成的场景表示。

  • 模型结构：

- 共享 DINOv2 ViT-L/14 图像编码器，特征宽度 d=1024；1036×1036 图像产生 74×74 编码网格，双线性下采样到 37×37 后再进行时空聚合。

- 采用分解的时空注意力：每层依次执行图像内自注意力、固定时间索引下的跨相机自注意力或固定相机下的跨时间自注意力，二者在层间交替，共 16 层聚合。

- 每个图像 patch 序列携带 rig token、ego token 与 4 个 register token，全部参与注意力；聚合后拼接最后图像内与时间注意力块输出，得到宽度 2d 的上下文 token 序列。

- 几何解码：rig head 读取第一时序组所有相机的 rig token，ego head 读取参考相机跨时间的 ego token，分别经 Transformer 头与 MLP 回归平移与四元数；按 T_{t,c}=T^ego(τ_{t,c})T^rig_c 组合位姿，ego 轨迹按各图像采集时间做平移线性插值与旋转最短弧球面插值；独立 DPT 解码器输出深度、辅助点图与辅助图像语义，最终点图由预测深度与相机位姿反投影构造。

- 检测解码：共享特征金字塔融合高分辨率图像特征与聚合器上下文特征；解码器遵循 DETR3D 结构，交替 query 自注意力、多尺度可变形跨注意力与前馈层；query 内容零初始化，位置嵌入由学习的 3D 参考点计算；参考配置为 900 个 query、6 层解码器、宽度 256。

- 语义占据：Deformable DETR 启发的 BEV 投影模块，每个 BEV 单元沿竖直柱布置 4 个参考点，经自注意力与可变形跨注意力细化；跨注意力使用内参与静态 rig 到相机外参投影，无需 ego 运动估计；随后经 2D 转置卷积逐步上采样，分别输出 V_z 个二值通道与 V_z·K_occ 个语义通道，通过通道到高度重排得到二值 logits 与语义 logits。

- 高斯重建：DPT 解码器预测深度、颜色残差、法线与高斯属性（中心、RGB、尺度、四元数、不透明度与辅助监督用单位法线），中心、朝向与法线表达在由预测轨迹定义的 clip 世界系；高斯深度解码器由几何深度头初始化但参数独立。

  • 关键技术：

- 分解时空注意力降低全窗口注意力的二次复杂度。

- 位姿分解为 rig 标定与 ego 轨迹，支持异步采集时间插值。

- 视频级推理流程包括序列窗口拼接、全局位姿图优化与离线多目标跟踪。

- 离线跟踪采用基于检测头预测速度的卡尔曼滤波与匈牙利关联逐帧关联，并在第二遍重连碎片化轨迹，使用 RTS 平滑器结合后续观测精化轨迹。

- 训练损失包括几何损失（深度、辅助点图、rig、ego、相对位姿、辅助语义）、检测损失（6 层监督、query 去噪、辅助 2D 检测）、占据损失（BCE、Lovász 二值、体素 CE/Dice、BEV CE/Dice）与重建损失。
