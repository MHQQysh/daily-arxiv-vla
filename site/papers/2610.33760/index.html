Card 02 论文概述

论文概述

  • 论文面向基于仿真的自动驾驶感知验证与确认（V&V）任务，解决真实图像与其合成对应图像在冻结被测系统（SUT）上输出相似、但系统依赖的视觉证据不一致的问题。
  • 应用场景为配对真实—合成数据评估，具体使用 KITTI ↔ Virtual KITTI 2 克隆数据对，检验仿真图像是否保持“机制一致性（mechanism parity）”。
  • 研究问题：如何将原始决定性证据图（decisive map）之间的差异转化为可解释、可指导工程行动的语义概念层诊断；输出一致是否足以证明机制一致。
Card 03 核心贡献

核心贡献

  • 提出概念层机制一致性诊断指标 C-DFF：将冻结 SUT 上的决定性证据通过现成分割器投影到共享语义概念空间，并用概念重要性向量之间的距离度量真实与合成输入的机制差异。
  • 提出可行动的概念漂移诊断：定义逐对概念漂移向量与数据集级平均漂移、Top-k 增/减概念、概念级分位数包络等汇总，用于识别合成图像中哪些场景概念变得更/更不决定性。
  • 给出面向验证流程的操作化方案：将 C-DFF 作为标量门限加排序语义诊断，用于筛选、分诊与需求式监控，并提供阈值校准与通过率定义。
  • 在 2126 对 KITTI ↔ Virtual KITTI 2 匹配帧、三个冻结 SUT（转向回归、YOLOP 可行驶区域、YOLOP 车道线）上开展多 SUT 实证研究，并报告任务特定输出值上下文指标，说明输出一致不等同于机制一致。
  • 补充诊断分析：利用 VKITTI2 真值标签对合成侧标签来源敏感性进行单侧界定，并报告校准阈值与测试集分位数。
Card 04 方法描述

方法描述

  • 所属模块：验证与确认中的感知模型诊断层；不修改、不重训练 SUT，也不引入生成器校准目标。
  • 输入传感器：KITTI ↔ Virtual KITTI 2 前视单目相机图像，分辨率 1248×376。
  • 场景表示：概念空间。用语义分割器得到逐像素概念标签图 S(x)，采用 Cityscapes-19 分类体系（K=19），概念如 road、sidewalk、building、sky 等。
  • 模型结构：

- 决定性证据图：M(x)=H(F, T_sut(x))，在 SUT 输入几何上定义；H 采用直接图像空间扰动优化（CF-XAI），目标函数包含输出标量摘要与目标值差平方、扰动幅度惩罚（权重 w_t）与总变分正则（λ_TV），用 Adam 并裁剪到 [0,1]；优化后以通道均值绝对扰动作为决定性图。

- 语义分割：现成 Mask2Former（Cityscapes 训练检查点），不训练、不微调。

- 几何对齐与池化：概念标签经与 SUT 完全相同的预处理变换 T_sut 以最近邻插值变换；决定性图平均池化到 16×16，标签图最近邻缩放到 16×16。

- 概念重要性向量：对每个概念 k，计算池化决定性质量 B_k 与面积 A_k，取 c_k(x)=B_k(x)/max(1,A_k(x))，不做跨概念归一化，得到 c(x)∈R^K。

- C-DFF 距离：D_c 采用均方误差，C-DFF(x_r,x_s;F)=D_c(c(x_r),c(x_s))。

- 阈值与通过率：在校准划分上取 90/95 百分位作为 ε_90、ε_95，在留出测试集上报告通过率。

- 诊断：概念漂移向量 Δc(x_r,x_s)=c(x_s)−c(x_r)，并报告 Top-k 增减、数据集级平均漂移、概念级分位数包络。

  • 关键技术：扰动式反事实解释（CF-XAI）、现成语义分割作为可解释脚手架、确定性几何对齐、概念空间距离度量与概念漂移汇总。
  • 原文未报告：论文未报告 C-DFF 对决定性图估计器替换的鲁棒性实验、未报告替代分割器或替代距离度量的系统性比较。
Card 05 数据集与资源

数据集与资源

  • 数据集：KITTI ↔ Virtual KITTI 2，按共享序列 ID 与帧索引构造帧级配对（示例：KITTI tracking sequence 0001 → V-KITTI Scene01）；使用 2126 对评估帧，覆盖五个配对序列（Scene01/02/06 用于校准，Scene18/20 用于留出评估）。
  • 冻结 SUT：

- Steering：PilotNet 风格 CNN 回归（3 个卷积层 + 2 个全连接层），输入 200×66 RGB，在 Udacity steering-angle 数据集（Challenge 2）上训练。

- YOLOP 可行驶区域头（DA）：YOLOP 多任务网络共享编码器加任务头，输入 640×384 RGB。

- YOLOP 车道线头（LL）：同骨干的任务头。

  • 预处理：Steering 缩放至 200×66 并归一化到 [0,1]；YOLOP 缩放至 640×384 并归一化到 [0,1]；推理无数据增强；所有 SUT 权重冻结。
  • 分割器：Mask2Former，Cityscapes 训练检查点，Cityscapes-19 分类体系（K=19），未训练或适配。
  • 超参数搜索：Optuna，每个 SUT 20 次试验，调参子集与留出评估划分不相交。
  • CF-XAI 配置：Steering 80 步、YOLOP 头 60 步；Adam 并裁剪到 [0,1]；目标侧裕度 τ=0.1；λ_TV=1×10^-3；池化网格 16×16；扰动幅度权重前一半 w_t=0.1，后一半 Steering 为 0.5、YOLOP 头为 0.3；收敛诊断阈值 0.8τ=0.08。

Card 06 评估与结果

评估与结果

  • 评估基准：KITTI ↔ Virtual KITTI 2 留出评估划分（Scene18/20），校准划分（Scene01/02/06）；共 2126 对匹配帧；三个冻结 SUT。
  • 评估指标：

- 主指标 C-DFF（MSE，越低越好），报告均值、中位数、标准差、P@ε_90、P@ε_95。

- 上下文指标（仅同一 SUT 内解释，不跨 SUT 排名）：Steering 为 exp(−\|θ_r−θ_s\|/0.2)；YOLOP-DA 为二值可行驶区域掩码 IoU；YOLOP-LL 为 0.4·Chamfer_score + 0.6·F1（容差 3 px）。

  • 关键数值（留出划分）：

- Steering：C-DFF 均值 3.12×10^-4，中位数 2.94×10^-4，标准差 1.71×10^-4，P@ε_90=77.1%，P@ε_95=92.8%，OV 上下文 0.3742。

- YOLOP-DA：C-DFF 均值 1.25×10^-4，中位数 1.00×10^-4，标准差 1.03×10^-4，P@ε_90=97.0%，P@ε_95=100.0%，OV 上下文 0.4518。

- YOLOP-LL：C-DFF 均值 3.90×10^-5，中位数 3.20×10^-5，标准差 3.30×10^-5，P@ε_90=66.9%，P@ε_95=74.7%，OV 上下文 0.0730。

- 结论：C-DFF 能区分三个冻结 SUT；OV 指标与 C-DFF 表现不一致
