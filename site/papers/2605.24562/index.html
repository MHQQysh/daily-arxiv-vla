Card 02 论文概述

论文概述

  • 解决自动驾驶中的行人意图预测（PIP）与行人轨迹预测（PTP）任务，属于安全关键的行人行为建模与可解释性研究。

Card 03 核心贡献

核心贡献

  • 构建 PedestrianQA 数据集：一个大规模基于视频的多模态问答数据集，将行人意图与轨迹预测与细粒度、基于推理的问答注释统一起来，每个序列包含问题、答案及五类结构化推理依据。
  • 建立基线：通过参数高效 LoRA 微调 Qwen2.5-VL-3B-Instruct，在不做架构改动的前提下，展示 VLM 可同时用于意图预测、轨迹预测与推理依据生成。
  • 提供基准评测：实验证明在 PedestrianQA 上微调的 VLM 在行人意图分类、轨迹预测精度及推理依据质量上均优于零样本基线及其它对比模型。
  • 数据生成管线：提出可扩展的以 LLM 驱动的注释生成流程，将多源数据集的真值与企业级元数据整合为统一的自然语言 Q-A-R 三元组。
Card 04 方法描述

方法描述

  • 所属模块：数据构建与 VLM 微调范式；将行人预测重构为视频问答与解释任务，无需专用任务架构。
  • 输入传感器：单目车载摄像头视频帧（来自 JAAD、PIE、TITAN、IDD-PeD 四个公开为第一视角数据集的视频；原文未报告雷达或 LiDAR 等其它传感器）。
  • 场景表示：以 TSV 表格式的结构化元数据表示目标行人、交互行人/车辆的边界框、行为标签、自车运动与场景上下文；配合以目标行人为中心的 448×448 裁剪帧叠加红色边界框的视觉输入。
  • 模型结构：以 Qwen2.5-VL-3B-Instruct 为基座进行 LoRA（rank=8, α=16）参数高效微调，训练与零样本评估在全部数据集上进行；数据注释生成阶段使用 claude-sonnet-4 LLM API 和另一个 SOTA VLM 生成运动化描述。
  • 关键技术：时间到事件采样（TTE 1–2 s）、结构化多类推理依据生成（空间、时间、数学、自车、场景上下文、最终目的地预测与结论）、双人注意力合规清单强制规则、以及用裁剪序列代替全帧以提升生成质量。
Card 05 数据集与资源

数据集与资源

  • 数据：由 JAAD、PIE、TITAN（结构化）和 IDD-PeD（非结构化）四个公开数据集整合，训练集包含 10,251 条样本，测试集 4,059 条样本。
  • 每条样本含目标行人及其交互行人、交互车辆、交通控制元素（交叉口、信号灯），辅助以自动生成的运动字幕（14 个分类提示驱动）。
  • 模型：基线模型为 Qwen2.5-VL-3B-Instruct（LoRA rank=8, α=16），对比模型有 Dolphins-9B、InternVL3-8B/2B-Instruct、Kwai-Keye-8B、LLaVA-NeXT-7B、Qwen2.5-VL-7B-Instruct。
  • 训练资源：2×Nvidia RTX-A6000 GPU，3 epoch（15 帧观测为约 0.5 s，TITAN 用 10 帧约 1 s）；原文未报告具体训练总时长或其他算力明细。
  • 数据集和模型发布：可在 github.com/botmahn/PedestrianQA 获取。
Card 06 评估与结果

评估与结果

  • PIP 评估：在 PIE、JAAD、TITAN、IDD-PeD 上以 Accuracy 和 F1 作为指标，与其他 VLMs 做零样本对比；微调模型“Ours (All Datasets)”在 PIE 获得 0.633 Acc、0.709 F1，JAAD 0.531 Acc、0.497 F1，TITAN 0.808 Acc、0.201 F1，IDD-PeD 0.880 Acc、0.205 F1，总体 0.783 Acc、0.542 F1（表格中加粗部分标注为最优，下划线部分标注为次优）。
  • PTP 评估：在 PIE、JAAD、TITAN、IDD-PeD 上以像素空间（图像坐标）的 ADE 与 FDE 作为指标，与 InternVL3、Kwai-Keye、LLaVA-NeXT、Qwen2.5-VL-7B 对比，Dolphins 被排除因无法生成轨迹框；微调模型“Ours (All Datasets)”整体 ADE=37, FDE=68（PIE ADE=41, FDE=70；JAAD ADE=41, FDE=87；TITAN ADE=31, FDE=60；IDD-PeD ADE=46, FDE=80）。
  • Rationale 生成评估：在 7 类推理依据（SR、TR、MR、EVR、SCR、FDP、C）上以 Claude-Sonnet-4 评定 0–100 分，微调模型表现优于零样本模型；Dolphins-9B 仅生成简短结论而未生成分类专属推理依据，其列为 0.00。
  • 评估条件：PIP、PTP 及 Rationale 均在真实行车视频数据集上以开环方式评估（非闭环仿真），部分基线模型为零样本，微调模型以各数据集独立微调或跨全数据集微调进行评估；原文未见闭环驾驶仿真评测或实车平台部署记录。
