Card 02 论文概述

论文概述

  • 任务：面向端到端自动驾驶的视觉-语言-动作（VLA）模型轨迹生成，即给定前视驾驶图像与结构化驾驶上下文，自回归输出文本形式的未来自车轨迹。
  • 应用场景：自动驾驶规划，特别是常规场景与需要多步推理的复杂场景（如无保护路口、密集汇入、部分遮挡危险）。
  • 研究问题：VLA 模型过度调用思维链（CoT）推理，即“过度思考”，带来额外计算开销并可能反而降低规划性能；核心是决定“何时”调用显式推理。
  • 关键问题：已有显式路由方法依赖场景难度标注来监督路由选择，而此类标注费力、难扩展、主观且与推理的实际效用未必对齐；论文探索在无场景难度标签条件下实现显式路由优化。
Card 03 核心贡献

核心贡献

  • 识别 VLA 自动驾驶中的“过度思考”问题，并首次探索能否完全从比较性任务结果中学习显式路由偏好，而无需任何场景难度标注。
  • 提出 STEER，一种通用的过度推理缓解策略，包含路由均衡监督微调、路由不确定性感知 rollout 与跨路由优势信用分配三个组件。
  • 路由均衡 SFT 通过路由校准与长度归一化保持双路由先验，避免模型在 RL 前过早坍缩到较短直接响应。
  • 路由不确定性感知 rollout 根据初始路由分布的二元熵动态分配采样，实现同提示下推理与直接路由的对比探索。
  • 跨路由优势信用分配引入差分度量，以环境奖励而非主观标签强化最优路由决策，并从期望更新分析上说明其提升高期望奖励路由的概率。
  • 在 NAVSIM v1/v2 上取得与先进方法有竞争力的结果，并同时改善规划质量、路由质量与推理效率的 Pareto 前沿。
Card 04 方法描述

方法描述

  • 所属模块：端到端 VLA 驾驶框架，包含显式路由决策模块与轨迹生成模块；不额外使用规划器，直接自回归文本航点轨迹。
  • 输入传感器：前视驾驶图像（1x C）与结构化驾驶上下文组成的多模态驾驶提示；原文未报告其他传感器输入的详细配置。
  • 场景表示：以多模态驾驶提示表示场景，输出为文本形式的未来自车轨迹；未使用显式 BEV 或栅格场景表示（原文未报告）。
  • 模型结构：基于自回归视觉语言模型 Qwen2.5-VL-8B；响应分布分解为路由策略 pθ(R\|x) 与条件轨迹生成 pθ(y\|x,R)。
  • 路由形式：首步为离散路由决策 R∈{reason, direct}；推理路由格式为 <answer> trajectory </answer>，直接路由格式为 <answer> trajectory </answer>。
  • 训练流程：三阶段，包括驾驶中心预训练、路由均衡监督微调、路由感知策略优化。
  • 路由均衡 SFT：每个提示同时提供推理与直接两个目标，损失包含路由校准项（对初始路由决策做均匀分布正则）与按路由长度归一化的下一词损失，并用 α 平衡两路由。
  • 路由不确定性感知 rollout：以路由特殊 token 的首 token 概率归一化得到 p_reason 与 p_direct，计算二元熵 H(x) 与少数路由概率 p_min；按阈值 ε、τ_low、τ_high 分为模式 A（各半强制对比）、模式 B（对比加 on-policy 混合）、模式 C（标准 on-policy）。
  • 跨路由优势信用分配：对推理与直接 rollout 子集分别以对方路由平均奖励为基线构造 A_route，在初始路由位置额外施加裁剪代理目标；其余响应 token 使用组相对归一化优势 A_content。
  • 优化目标：L = L_content + λ_r L_route + β_KL L_KL，基于序列级 RL（如 GRPO）并加入 KL 正则。

Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM v1 navtest 与 NAVSIM v2 navtest。
  • 评估指标：规划指标包括 PDMS（v1）与 EPDMS（v2），以及 NC、DAC、EP、TTC、C（v1）和 DDC、TLC、LK、HC、EC（v2）；路由指标包括 RouteAcc、AUC、AvgRegret（以 oracle route 为参照），并报告平均路由概率与路由不确定性、平均响应 token 数。
  • 开环/闭环条件：论文在 NAVSIM 官方模拟器上评估，表 1 标注为 closed-loop metrics；未报告实车实验。
  • NAVSIM v1 关键结果：STEER 取得 91.2 PDMS，优于 AdaThinkDrive 的 90.3（后者依赖场景难度标注），并略高于 SGDrive 的 91.1；Best-of-N（6 候选）下 STEER† 达 93.4 PDMS。
  • NAVSIM v2 关键结果：STEER 取得最佳 87.2 EPDMS，比 SGDrive 的 86.2 高 1.0，并获得最佳 DAC 97.6 与 EP 95.6。
  • 自适应路由对比（NAVSIM v1，RL 后）：强制直接 89.9 PDMS/156 token，强制推理 90.8 PDMS/415 token，自适应 91.2 PDMS/315 token；SFT 后自适应仅 86.5 PDMS，说明该阶段主要保留双路由能力。
  • 路由优化消融：同时启用不确定性感知 rollout 与跨路由优势时 RouteAcc 81.1%、AUC 79.1%、AvgRegret 0.018、平均响应 315 token、PDMS 91.2；单独启用任一组件均更差（如仅跨路由优势为 77.5%/76.5%/0.024/350/89.9）。
  • SFT 消融：无长度归一化与路由校准时推理概率 26.6%、PDMS 86.4；两者均启用时推理概率 49.1%、PDMS 86.5。
  • 训练流程消融：无预训练且无 RL 为 85.9 PDMS；仅预训练为 86.5 PDMS；预训练加 RL 的完整流程为 91.2 PDMS（表中 STEER 行数值与表 1 一致）。
  • 对比方法：包括 Ego-MLP、UniAD、PARA-Drive、Hydra-MDP、DiffusionDrive、DiffusionDriveV2、ImagiDrive-S、ReCogDrive、SGDrive、Qwen2.5-VL、InternVL3、AutoVLA、AdaThinkDrive、Curious-VLA，以及 NAVSIM v2 上的 VADv2、TransFuser、HydraMDP、HydraMDP++、ARTEMIS 等。
  • 效率分析：论文以平均响应 token 数刻画推理开销，并声称在推理效率 Pareto 前沿上优于固定路由与既有自适应推理方法；原文未报告具体延迟或 FLOPs 数值。
