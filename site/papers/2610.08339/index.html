Digital Twin-Driven Real2Sim2Real: Simulator-Conditioned Generation via Paired Driving-Scene Reconstruction

Card 03 核心贡献

核心贡献

  • 构建 DT-R2S2R 流水线，将几何配对的驾驶场景重建 DT-R2S 与空间一致的图像翻译 DT-S2R 结合。
  • 在数字孪生中基于真实世界建模道路网络、建筑、地形与车辆资产，使重建片段与真实记录在几何上配对，并输出低成本标注。
  • 使用数字孪生渲染图作为 Sim2Real 生成的条件，获得地理空间锚定的逼真驾驶图像，并支持在已重建和未见模拟器场景中生成数据。
  • 在多种 3D 检测器上验证生成数据作为训练数据引擎的有效性；DETR3D 在不使用目标区域图像训练检测器的情况下，达到目标区域真实数据 oracle 的 93.18% mAP。
  • 实验表明，与现有目标区域外真实数据简单共训练可超过 oracle，并展示生成数据在场景级多样性和长尾场景增强中的价值。
Card 04 方法描述

方法描述

  • 所属模块：论文方法包含 DT-R2S 与 DT-S2R 两个模块；DT-R2S 负责配对驾驶场景重建，DT-S2R 负责照片级真实感增强。
  • 输入传感器：真实驾驶片段来自 AI-Hub，包含五路环视相机与一个 128 通道 LiDAR；DT-R2S 使用 GNSS 轨迹、LiDAR 点云、3D 边界框以及 LiDAR 到 GNSS 外参等。
  • 场景表示：将真实驾驶片段嵌入 MORAI SIM 数字孪生模拟器，使用基于 HD map 的道路网络、建筑、地形和车辆资产库；任务集中在韩国 Sangam 与 Pangyo 两个城区。
  • DT-R2S 结构：首先通过 UTM 投影将 GNSS 轨迹转换到地图坐标系并定位片段；随后将标注动态车辆替换为库资产；再恢复 LiDAR 相对自车坐标系的位姿。
  • 资产匹配：对物体框尺寸按各轴历史最大值聚合，并按长宽高加权代价排序；权重为长度 0.35、宽度 0.24、高度 0.41；再对前 5 个候选使用 SAM 分割裁剪与 DINOv3 特征余弦相似度进行外观重排。
  • 物体放置：使用每个物体 BEV 四角中离 LiDAR 最近角作为物理测量参考，并在模拟器中以近角位置放置资产。
  • 位姿恢复：将模拟器自车参考帧锚定到 GNSS 轨迹，通过最小化真实与模拟 3D 框八个角点在 LiDAR 坐标系下的几何差异优化 LiDAR-to-ego 6-DoF 位姿。
  • 位姿优化细节：使用 RANSAC 拟合真实点云地平面以获得 LiDAR 安装高度估计，使用 CMA-ES 迭代优化；随后基于地平面进行 roll、pitch 和 z 修正；最后按四类传感器配置分组，对平移取算术平均、旋转用 SLERP 平均。
  • DT-S2R 结构：冻结扩散骨干、VAE 和文本编码器，仅训练三个条件分支；条件包括深度、语义和模拟器 RGB 渲染图。
  • 条件注入：每个条件驱动一个 ControlNet 分支，即骨干 down 和 middle blocks 的可训练副本；每个 ControlNet 返回各 skip connection 的残差和 middle block 残差，并通过加法残差注入骨干。
  • 训练目标：总损失由 LDM 噪声预测损失和动态物体区域加权噪声预测损失组成；动态区域权重为 w_u = max(d_u, 0.02)，随归一化深度增加。
  • 多视图生成：引入 cross-view blocks，对每个相机的隐藏状态与其左右邻居进行 cross attention；W_0 零初始化，使该项在初始化时消失。
  • 关键技术：数字孪生地理锚定、配对 Real2Sim 重建、基于 ControlNet 的多条件扩散 Sim2Real、多视图 cross-view 一致性、动态物体深度加权损失。
  • 原文未报告：论文未报告 DT-S2R 的具体模型参数量、扩散骨干名称与版本、ControlNet 分支层数等完整网络规模信息。
Card 05 数据集与资源

数据集与资源

  • 数据集：AI-Hub 真实驾驶数据集，包含韩国城市道路，五路环视相机和一个 128 通道 LiDAR；按数字孪生覆盖划分为 In-Twin 与 Off-Twin。

Card 06 评估与结果

评估与结果

  • 评估基准：在 D^{Real}_{InTwin} 验证集上评估，另有 D^{Real}_{All} 用于部分实验；DT-S2R 可扩展到 ADC25 的纯模拟器生成片段，并包含未见路线。
  • 图像质量指标：PSNR、SSIM、LPIPS、FID。
  • 下游感知指标：mAP 与 NDS，覆盖 car、bus、truck 类别；使用 FCOS3D、DETR3D、PETR 三类 3D 检测器。
  • DT-R2S 消融：Baseline 达到 57.5% 2D IoU、0.581 m 3D Corner Error、0.3427 SSIM、0.6836 LPIPS；加入外观重排后为 56.7%、0.632、0.3420、0.6849；加入地平面修正后为 59.4%、0.582、0.3430、0.6809；加入聚类平均后最佳，为 60.4%、0.565、0.3458、0.6804。
  • DT-S2R 图像质量对比：DT-S2R Stage1 为 PSNR 11.778、SSIM 0.452、LPIPS 0.509、FID 13.5；DT-S2R Stage2 为 PSNR 12.104、SSIM 0.461、LPIPS 0.493、FID 12.7。对比中 FDA 为 10.168、0.414、0.682、117.8；VSAIT 为 9.478、0.391、0.648、85.1；SODA-CAM 为 10.094、0.409、0.649、93.5；SimGen 为 12.040、0.440、0.527、21.3；SDEdit 为 9.458、0.397、0.650、57.2；T2I-Adapter 为 9.890、0.367、0.634、22.1。
  • 检测器读取生成帧结果：重建本身已恢复同一检测器在对应真实帧上
