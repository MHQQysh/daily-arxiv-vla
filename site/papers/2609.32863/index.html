Card 03 核心贡献

核心贡献

  • 构建了 SV2V-RSim：首个面向 V2V 协同感知、支持动态协作者选择的大规模仿真数据集，基于 Unreal Engine 5，采用高保真资产、真实场景、程序化内容生成与多样渲染条件以兼顾真实性与可扩展性。
  • 提出 Select Vehicles Adaptively (SVA) 模块，利用低级协同车辆数据，优先传输对自车感知关键的特征，实现资源感知且随上下文自适应的协同感知策略，平衡检测性能与带宽效率。
  • SV2V-RSim 支持多种协同任务，论文在 3D 目标检测、分割、深度估计等任务上使用该数据集对多个先进协同感知方法进行了基准评测。
  • 通过 sim-to-real 实验与无参考图像质量评估验证了数据集的真实性与泛化能力。
Card 04 方法描述

方法描述

  • 所属模块：数据生成部分为基于 Unreal Engine 5 的仿真数据采集管线；感知部分为 Select Vehicles Adaptively (SVA) 协同感知基线模块。
  • 输入传感器：所有车辆配备相机、LiDAR、GPS、IMU。每车配置前后两个相机（RGB、深度、语义分割），分辨率 1600×900，频率 5Hz；顶部 1 个 LiDAR（语义与实例分割），频率 5Hz，测距 ≤ 200m，32 线，每环 1080 点，32 通道，水平 FOV 360°。LiDAR 与相机配置基于 nuScenes 设置。传感器采用条件激活策略：仅当车辆位于自车 70 米半径内才激活。
  • 场景表示：SVA 中每辆车将原始点云 L_j 经 PointPillars 编码为 BEV 特征 f_j = Φ_enc(L_j) ∈ R^(C×H×W)。
  • 仿真结构：UE5 结合 Nanite 与 Lumen 实现实时全局光照与几何细节；3D 资产品类为 91 种机动车、9 种非机动车、10 种静态物体、17 种行人类型，材质通过程序化内容生成（PCG）随机化；HD 地图覆盖城市中心、郊区道路与高速公路；天气与天空系统支持晴天、多云、阴天、雨天四种天气与从日出到夜晚六个时段，并与车辆系统耦合（如低光照自动开启车灯）；渲染采用异步多 GPU 框架，每个 GPU 分配独立渲染器并通过独立端口与仿真器通信。
  • SVA 关键技术：两阶段通信协议。第一阶段 Spatial Confidence Estimation，各车预测轻量空间置信图 m_j ∈ [0,1]^(H×W)，连同 6-DoF 位姿 P_j 作为元数据包传输给自车；第二阶段 Adaptive Feature Selection，自车以 query 向量 q = attn(q_init, f_ego) 结合对齐后的置信图与位置嵌入，通过 M_{i→ego} = σ(MLP(Concat(q, m̃_{i→ego}, Embed(P_i)))) 计算空间选择掩码；随后 Point-wise Feature Integration，自车将掩码非零区域坐标广播给协作者，协作者仅传输这些空间区域的特征 f̃_{i→ego} = Warp(f_i) ⊙ M_{i→ego}，最终 F_fuse = Φ_fusion(F_ego, {f̃_{i→ego}}_{i=1}^N)，再由检测头 Y' = Φ_dec(F_fuse) 输出 3D 框。
  • 原文未报告 SVA 的具体网络层数、参数规模与推理时延。

  • 评估指标：检测使用 AP_M、AP_N、AP_P、AP_S（分别在 IoU 0.3 与 0.5 下，对应机动车、非机动车、行人、静态物体），并报告通信带宽（以 log2 尺度衡量平均通信带宽）；sim-to-real 使用 mAP@0.3 与 mAP@0.5；图像质量使用 MUSIQ↑、MANIQA↑、NIQE↓、ILNIQE↓ 四种无参考图像质量指标。
