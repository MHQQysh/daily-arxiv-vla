Card 02 论文概述

论文概述

  • 研究任务：面向自动驾驶的多模态交通标志检测（2D 检测）、跟踪与语义属性分类。
  • 应用场景：在全球范围、远距离（最远 200 m）及恶劣环境条件下的自动驾驶感知系统。
  • 研究问题：解决视觉方法在跨区域泛化、远距离小目标检测、以及车辆接近标志时产生的非线性透视畸变导致的时间跟踪不稳定三大局限。
Card 03 核心贡献

核心贡献

  • 提出几何鲁棒的多模态检测框架，通过 Intensity-Aware Deformable Fusion 模块将 LiDAR 的几何深度与反射率同相机特征融合，以几何不变性替代区域特定外观，实现区域无关检测并将有效检测范围扩展到 200 m。
  • 提出双运动模型跟踪算法，并行运行二阶（恒定加速度）与三阶（恒定加加速度）卡尔曼滤波器，显式建模车辆接近时的非线性透视变换，提升时间稳定性并减少轨迹碎片化。
  • 开发语义属性分类流水线，联合估计遮挡程度、可读性、嵌入式（embeddedness）和道路相关性四种属性，为下游规划提供可操作上下文并过滤无效检测。
  • 在大规模 Qualcomm 内部数据集（覆盖 60+ 国家、2,500+ 小时驾驶数据、221,068 个评估序列）上验证，实现 0.49% 的对象漏检率（OMR）。
Card 04 方法描述

方法描述

  • 所属模块：多模态交通标志检测与跟踪流水线，包含检测器、跟踪器、语义属性分类器三个阶段；另含初始 3D 检测实验（DAL-Large 架构）。
  • 输入传感器：相机（RGB 图像）与 LiDAR（点云，含强度信息）。
  • 场景表示：2D 图像平面为主；利用 LiDAR 点云经时间累积（基于自车位姿的帧间累积）投影生成稠密深度图和强度图，作为补充通道。
  • 模型结构：

- 检测器：SwinTransformer 骨干网络 + transformer 锚驱动多尺度检测头，采用 Co-DETR 风格协同混合分配训练方案。

- 融合：Intensity-Aware Deformable Fusion，使用几何注意力与强度注意力双重注意力机制，并结合强度约束的偏移预测。

- 跟踪器：双运动模型（二阶恒定加速度、三阶恒定加加速度）并行卡尔曼滤波，多阶段数据关联（复合匹配代价含马氏距离、形状相似度与 IoU）。

- 属性分类：DINOv2 骨干 + LoRA 适配器，采用三阶段流水线（RoI 提取、特征适配、分类）。

  • 关键技术：利用交通标志逆反射涂层产生的高 LiDAR 强度作为类别先验；时间点云累积提升远距离点密度；嵌入式属性通过 2D 包含、3D 邻近、朝向一致性判定。

Card 06 评估与结果

评估与结果

  • 评估基准与条件：在 Qualcomm 内部数据集上评估（不含 ZOD 对比部分）；所有对象评估至 200 m，无过滤；手动标注先在 LiDAR 坐标系标注再投影至图像平面。
  • 检测指标（COCO 协议）：AP、AP50、AP75、APs、APm、APl。
  • 检测结果（Qualcomm 数据集上训练）：AP 0.65（较 ZOD 训练直接推理提升 0.27）、AP50 0.86、AP75 0.73、APs 0.51、APm 0.80、APl 0.90；ZOD 上训练结果为 AP 0.55、AP50 0.78、AP75 0.60；ZOD 训练直接推理于 Qualcomm 时 AP 降至 0.38。
  • 跟踪指标：Recall 与 Precision（IoU 匹配阈值 0.5）。
  • 跟踪结果（消融，以 BoostTrack++ 为基线）：单帧检测器 Recall 0.73 / Precision 0.66；OC-SORT 0.68 / 0.70；BoostTrack++（默认参数）0.69 / 0.72；基线跟踪器（调参后）0.71 / 0.71；+插值 0.72 / 0.70；+二阶模型 0.73 / 0.71；+三阶模型（最终）Recall 0.74 / Precision 0.71。
  • 遮挡分类指标：按类别 Precision (P) 与 Recall (R)，LoRA 秩 r=16、缩放 α=16；ViT-Base 从零训练（类 0：P 0.61 / R 0.74；类 1：P 0.93 / R 0.87），ViT-Base + LoRA（类 0：P 0.64，类 1 数值未完整报告）。
  • 端到端指标：OMR 0.49%，对应 221,068 个评估序列。
