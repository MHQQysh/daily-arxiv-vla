Card 02 论文概述

论文概述

  • 论文面向端到端自动驾驶中的 Vision-Language-Action（VLA）规划任务，目标是在已有专家演示模仿学习基础上，利用策略自身 rollout 暴露的安全关键失败继续后训练。
  • 应用场景为基于 NAVSIM/OpenScene/nuPlan 的自动驾驶规划评测，输入当前驾驶上下文并直接预测未来轨迹。
  • 研究问题在于：现有 failure-learning 方法存在失败诊断不可靠、纠正目标与失败不匹配（易过度纠正）、奖励信号过于粗糙三类限制。
Card 03 核心贡献

核心贡献

  • 提出 RefineDrive，一个 failure-guided post-training 框架，显式利用模型自身 rollout 产生的失败来改进自动驾驶 VLA。
  • 提出 Reliable Diagnosis，从 simulator states 中导出结构化、可验证的失败反馈，针对 at-fault collisions 与 drivable-area violations。
  • 提出 Minimum-Correction Target Retrieval，在聚类的人类轨迹库中检索满足硬安全约束且接近失败预测的纠正轨迹，减少不必要行为改变与过度纠正。
  • 提出 Safety-Layered Reward，并在 GRPO 中使用，严格优先 hard-safe trajectories，同时保留连续安全反馈，并只在满足硬安全后奖励驾驶进展。
  • 在 NAVSIM v1 上将 4B base SFT policy 从 87.7 PDMS 提升到 91.7 PDMS；同一 checkpoint 在原始 NAVTEST scenes 上用 NAVSIM v2 extended metrics 得到 89.4 EPDMS。
Card 04 方法描述

方法描述

  • 所属模块：训练/后训练框架，包含 Failure Discovery、Structured Failure Correction、Correction SFT、Safety-Layered Reinforcement Learning 四个阶段；推理时不做显式 diagnosis 或 repair。
  • 输入传感器：原文报告在评估与训练中使用 current front-view image、ego state、historical trajectory；模型直接预测 eight (x, y, heading) waypoints，0.5 s 间隔，4 s horizon。
  • 场景表示：原文未报告完整的统一场景表示细节；失败发现使用 NAVSIM PDM Simulator 对预测轨迹重执行以获得可复现安全结果。
  • 模型结构：以 Qwen3.5-4B 实例化 RefineDrive，先进行 trajectory SFT，再进行 Correction SFT 与 Safety-Layered GRPO；其余模型结构细节原文未报告。
  • 关键技术：Failure Discovery 聚焦 at-fault collisions 与 departures from drivable area；Reliable Diagnosis 提取首次 ego at-fault collision 的时间、对象类别、相对位置，并投影到当前前视图图像得到 2D bounding box，或定位首次离开可行驶区域的左右边界；Counterfactual Minimal Correction 使用 K-Means 聚类人类轨迹库，按运动模式优先搜索同簇，再按簇中心距离搜索其他簇，并用 hard-safety feasibility 约束筛选。
  • 关键技术：Correction SFT 以 driving context q 和 failed trajectory τ⁻ 为条件，目标为 structured diagnosis 加 retrieved correction τ*，采用标准自回归损失；Safety-Layered Reward 由 hard safety F(τ)、continuous safety score S(τ) 与 Ego Progress P(τ) 组成，参数 (λF, λS, λP)=(2.0,1.0,0.25)，η=0.5。

Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM v1 主结果；另有原始 NAVTEST scenes 上的 NAVSIM v2 extended metrics 评估。
  • 评估指标：PDMS、NC、DAC、TTC、EP、C；NAVSIM v2 extended metrics 包含 NC、DAC、DDC、TLC、EP、TTC、LK、HC、EC、EPDMS；所有指标均为 higher-is-better。
  • 关键数值：NAVSIM v1 上 RefineDrive 达 91.7 PDMS、98.7 NC、98.2 DAC、95.9 TTC、87.2 EP、100 C；Base SFT 为 87.7 PDMS。NAVSIM v2 extended metrics 原始 NAVTEST scenes 上，同一 checkpoint 无额外训练达 89.4 EPDMS，NC 98.7、DAC 98.2、EP 90.5、TTC 98.2。
  • 对比方法：NAVSIM v1 上与 UniAD、TransFuser、DiffusionDrive、Base SFT (Qwen3.5-4B)、AutoVLA、SafeAlign-VLA、DriveVLA-W0、ReCogDrive、ELF-VLA、DriveTeach-VLA、DriveMA、Qwen-Drive-1.0-RL、ReflectDrive、DriveFine 等比较；NAVSIM v2 extended metrics 上与 ReCogDrive、DiffusionDriveV2*、DriveVLA-W0*、DriveSuprim (ViT-L)、ExploreVLA*、DriveFine† 比较。
  • 评估条件：主要为 NAVSIM 开环/仿真评测；原文未报告闭环实车评估。消融显示 Human GT 监督将 PDMS 从 87.7 提到 88.2，Minimal 从 88.2 提到 88.6；去掉 diagnosis 后从 88.6 降到 88.3。RL 消融中，Direct PDMS Reward 将 EP 从 82.0 提到 87.2，但 NC 从 98.7 降到 98.2、TTC 从 95.9 降到 94.9；Safety-Layered Reward 达 91.7 PDMS，并保留 pre-RL NC 与 TTC，且 DAC 提升到 98.2。最终策略消融中，Full Correction-SFT 相对 w/o Correction SFT 的 NC、DAC、TTC 分别提升 0.9、0.5、1.8 个百分点，但 EP 从 88.8 降到 87.2。
