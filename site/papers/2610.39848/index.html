Card 03 核心贡献

核心贡献

  • 提出模型无关的评估架构，通过最小 REST 接口将对抗评估与目标模型解耦，消除手工环境重建与模型专用胶水代码。
  • 提供同时覆盖 3D 语义分割与 3D 物体检测的统一工作流，在单一框架内完成两大 LiDAR 感知任务的直接鲁棒性评估。
  • 实现任务感知的先进攻击套件以暴露异构 LiDAR 骨干的薄弱点：分割使用 PGD 与 Square Attack；检测使用点扰动、点移除、点注入与 LiDAttack。
  • 提供完全 Docker 化的部署模式，隔离数据处理、模型执行与攻击编排，把对抗鲁棒性测试的工程开销降低为即插即用的系统组件。
  • 给出跨数据集的实证结果，显示集成攻击能在异构骨干上暴露显著脆弱性。
Card 04 方法描述

方法描述

  • 所属模块：框架由三个 Docker 化组件构成——User Client / Data Adapter（负责数据集交互与样本封装）、Assessment Engine（负责对抗协议、扰动状态维护、干净/对抗前向协调与任务感知控制逻辑）、Model Service（负责网络执行、模型构建、检查点加载、任务损失定义及模型相关前后处理）。
  • 输入传感器：LiDAR；分割模型输入为距离视图（range-view）张量，检测模型输入为原始点云。具体传感器型号/通道数原文未报告（仅实验数据集处说明 KITTI 为 64 线、SemanticPOSS 为 PANDORA 40 线、SemanticKITTI 为 Velodyne HDL-64E）。
  • 场景表示：分割任务以距离视图张量表示（H 为垂直光束数，W 为水平角分辨率）；检测任务以点云 P={p_i∈R^3} 表示。
  • 模型结构与关键技术：采用服务导向设计，目标模型保留在原生环境中，通过三个 HTTP 端点通信——/info 返回模型与任务元数据，/forward 返回任务原生预测，/gradient 返回白盒攻击所需的输入梯度。框架由两个契约约束：数据契约（任务标签的样本载荷，含编码后的模型输入、监督信息与元数据）与模型契约（三端点接口）。新骨干只需实现 load_model(device) 返回 (model, criterion, info, device)，其中 info 含模型标识、类别数、输入形状等任务级属性。引擎每个模型会话查询一次 /info，获取干净参考预测后实例化攻击并迭代至生成对抗输入，再经同一服务边界执行并收集输出；黑盒仅用 /forward，白盒额外调用 /gradient，编排层在两种威胁模型下不变。
  • 分割攻击：在距离视图上加扰动 Δ（‖Δ‖_p≤ε），最大化分割损失；PGD 迭代含步长 α、投影到 ℓ_p 球与 p∈{2,∞} 的梯度归一化；Square Attack 为仅用 /forward 的 ℓ_∞ 随机搜索黑盒基线。
  • 检测攻击：点扰动为每点施加 ℓ_2 约束（‖δ_i‖_2≤ε）的位移并用 PGD 迭代优化；点移除按检测损失梯度 ℓ_2 范数排序做显著性贪心删除；点注入按 P={p_i+δ_i} 之外的 P_adv=P∪Z 方式在最高显著性位置初始化注入点并在 Chamfer 距离约束下仅优化 Z；黑盒使用 LiDAttack（遗传算法结合模拟退火，仅前向查询）。
  • 原文未报告：检测攻击目标函数的具体闭式表达、分割模型的网络内部结构细节（除引用的 LENet/CENet/FIDNet 简介外）。

Card 06 评估与结果

评估与结果

  • 评估基准与条件：全部为数字域对抗攻击评估（非闭环、非实车）；检测在 KITTI 与 CARLA 上进行，分割在 SemanticKITTI 与 SemanticPOSS 上进行。
  • 评估指标：检测使用绝对 mAP 与 mAP 比值 (mAP_adv/mAP_clean)×100（越低表示退化越强），并用对称 Chamfer Distance（CD）衡量几何可感知性（越低越几何合理）；分割使用全类平均 mIoU。
  • 对比方法/被评估模型：检测评估 SECOND（稀疏卷积体素）与 PointPillars（pillar 编码伪图像）；分割评估 LENet、CENet、FIDNet；攻击包括白盒 PGD（分割 ℓ_2/ℓ_∞；检测 ℓ_2）与黑盒 Square Attack、LiDAttack。
  • 攻击配置：检测点扰动为无目标 ℓ_2 PGD，ε∈{5,7,10} cm，40 次迭代，α=ε/30，随机初始化；点移除为 10 次迭代显著性贪心，移除比例 {0.5,1.0,1.5}%；点注入注入 300 个点，位移预算 ε∈{0.3,0.5,0.7} m；LiDAttack 用 K=20 个对抗点、目标框 0.5 m 边界内、每目标最多 1000 次前向查询，在 KITTI 的 SECOND 上评估。分割 PGD 在 ℓ_2 下 ε∈{3,6,9}、ℓ_∞ 下 ε∈{0.1,0.3,0.5}，T=40 次迭代，α=ε/T；Square Attack 为 ℓ_∞、ε=0.3、1000 次查询、一次随机重启、p_init=0.4，在 SemanticKITTI 的 LENet 上评估。
  • 检测关键数值：点扰动退化最强且随位移预算一致加重，PointPillars 在 ε=10 cm 时 mAP 比值降至 KITTI 10.59%、CARLA 3.46%；SECOND 相对保持更高（KITTI ε=5/7/10 cm 分别为 90.91/83.10/65.48%，CARLA 为 89.06/82.80/73.21%）。点移除退化较缓，最高移除比例下 SECOND 保持 KITTI 67.98%、CARLA 85.32%，PointPillars 保持 57.40% 与 80.02%，CD 随移除比例上升。点注入退化适中且 CD 较低：KITTI 上 SECOND 在 ε=0.5 m 降至 65.28% 但在 ε=0.7 m 回升至 71.12%，PointPillars 呈类似行为。黑盒 LiDAttack 使 KITTI 上 SECOND 的 mAP 从 70.43 降至 52.51（相对下降约 25%）。
