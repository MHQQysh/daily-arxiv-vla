Card 03 核心贡献

核心贡献

  • 提出基于查询的代价学习框架，在动态可达的自车轨迹查询上估计有界代价，而非在密集 BEV 单元或少量回归轨迹集合上估计代价。
  • 构建紧凑的联合场景 token，用多模态一致未来场景模式对自车代价进行条件化，以支持 contingency planning。
  • 提出代价引导的簇内 MPPI 式混合，使规划在意图簇内覆盖连续可达空间，并避免仅依赖 top-k 选择造成多样性坍塌。
  • 提出由专家轨迹、碰撞风险和越界违规驱动的基于排序的代价学习目标，利用安全感知 margin 分离安全候选与不安全困难负样本。
  • 在 nuScenes 上优于 ST-P3、NMP 等代价估计规划器，并在不微调的情况下于真实驾驶日志上相对 SparseDrive 与 Alpamayo 降低碰撞率，同时保持候选轨迹多样性。
Card 04 方法描述

方法描述

  • 所属模块：规划模块，作为端到端驾驶系统中的决策与运动规划接口；论文整体包含稀疏感知编码、联合场景预测、可达自车查询与代价估计、代价排序与候选监督、推理时代价修复。
  • 输入传感器：使用多视角环视相机图像队列；nuScenes 使用六路环视相机，真实驾驶日志也选取六路环视相机；未使用 LiDAR 作为本文方法自身输入。
  • 场景表示：使用向量化地图与智能体表示，而非密集 BEV 特征图；地图元素编码为地图特征与折线锚点，动态智能体编码为智能体特征与 3D 锚点。
  • 模型结构：基于 SparseDrive 图像编码器和对称稀疏感知模块；图像编码器为 ResNet-FPN；使用 900 个智能体锚点、100 个地图锚点和 256 维实例特征。
  • 联合场景表示：引入 N_s 个联合场景模式，每个模式由可学习嵌入表示，并通过模式条件智能体 token 和多头交叉注意力生成场景 token；场景概率由轻量场景 logit 头 softmax 得到，联合预测分支以负对数似然训练。
  • 可达自车查询：由运动学 rollout 采样器生成 N 个动态可行自车轨迹，并分配到 N_g 个意图簇；每条轨迹通过坐标与时间嵌入投影为查询特征。
  • 代价估计：将轨迹时间步特征、自车上下文 token 和场景模式 token 相加形成代价查询，通过轻量代价头映射到有界代价 [C_min, C_max]；代价表示仅定义在可执行自车轨迹流形上。
  • 风险感知聚合：设置分支时间 T_b；在分支索引之前使用最坏场景模式代价，之后使用按学习场景概率加权的期望代价。
  • 代价引导簇内混合：在每个意图簇内，将代价 profile 转为 MPPI 风格权重，对采样控制序列加权得到混合控制，再通过自车运动学 rollout 得到精炼候选；每个意图簇保留一个候选，并用负簇代价 softmax 得到候选概率。
  • 代价排序与候选监督：规划损失由排序损失、分类损失和回归损失组成；排序损失使用安全感知 margin，margin 随与专家距离增大而增大，并在碰撞或越界时显著增大；训练中取 top-k_h 违规进行平均，以扩散梯度。
  • 推理时代价修复：引入外部惩罚 E_i,t，将外部不安全查询状态代价向最大代价饱和，再用修复后的代价执行簇内混合；可用于交通规则监控或 V2X 交通灯数据等外部信号。
  • 原文未报告：论文未给出完整的网络层数、每层维度配置细节在正文中未能完整呈现，附录标题显示有网络结构细节，但正文截断部分未提供完整数值。
