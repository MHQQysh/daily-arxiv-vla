Card 02 论文概述

论文概述

  • 论文面向自动驾驶世界模型（World Model, WM）任务，目标是生成超出真实日志记录的驾驶场景，用于自动驾驶系统的训练与评估。
  • 应用场景为闭环交互式驾驶场景生成：背景车辆（BV）需对自车行为做出反应，自车则基于渲染图像做出反应。
  • 研究问题：现有世界模型难以同时保证 BV 行为真实性与视觉保真度，因为它们忽视了车辆交互与自车视觉观测之间的耦合关系。
  • 具体表现为三方面：BV 行为模型只基于车辆状态、未学习视觉观测波动下的交互变化；交互暴露的新视角渲染质量差、现有方法整体替换高斯资产导致已拟合区域被破坏；信号灯被烘焙为静态颜色、无法随交互意图变化。
Card 03 核心贡献

核心贡献

  • 提出视觉反馈驱动的交互学习以实现行为真实性：风格条件混合专家策略先经模仿学习获得多样行为，再在闭环中结合视觉反馈与多智能体强化学习，校准至真实世界交互特征分布。
  • 提出交互引导的选择性高斯资产增强：闭环交互暴露的视角引导逐高斯诊断，仅对诊断不足的区域用多视图扩散生成的供体高斯修复，保留与真实图像良好拟合的区域。
  • 提出基于反事实微调的意图触发车辆信号灯：扩散编辑器生成日志中未发生意图对应的灯态，并由灯态判别器监督输出是否匹配意图。
  • 将行为建模与视觉渲染耦合为闭环交互世界模型，在长尾闭环场景中降低与真实交互行为的偏差并提升新视角车辆 PSNR。
  • 揭示 BV 信号灯在世界模型中的重要性：渲染的信号灯间接影响自车驾驶行为，在四分之一场景中产生作用。
Card 04 方法描述

方法描述

  • 所属模块：闭环交互式世界模型，离线阶段构建 3D 高斯资产与初始 BV 策略，在线阶段渲染意图触发信号灯并闭环精炼 BV 策略。
  • 输入传感器：环视相机、LiDAR、跟踪框；每个场景先用 MTGS 重建为静态背景与可移动车辆资产，车辆以自身框坐标系下的高斯表示以便重定位和渲染。
  • 场景表示：3D Gaussian Splatting（3DGS），结合 MTGS 的多轨迹高斯表示；信号灯通过 3D 灯锚点投影为灯图与掩码。
  • 交互引导高斯资产增强：定义高斯在方位角上的支撑与饱和度，按探测视角计算逐高斯缺陷度，按缺陷度缩放球谐系数并保留基色，未观测表面由 Asset Harvester 生成的供体高斯按未覆盖贡献比例填补，最后进行颜色标定与由轻量 U-Net 预测的有界融合图像空间精炼。
  • 风格条件模仿学习：预训练风格编码器将 BV 近期运动编码为风格潜变量并归入 3 个风格簇，路由器在簇内选择 3 个专家之一，将场景特征解码为 K 步位移并累积为规划；损失包含位移回归、平滑、道路与安全项。
  • 意图触发信号灯：状态机依据规划减速度阈值激活刹车灯、依据变道意图侧提前激活转向灯并以 1 s 周期闪烁；以 LoRA 微调一步扩散模型 Difix 为编辑器，输入渲染车辆裁剪、同车参考视图及其观测灯态、灯图与状态图，输出仅在灯掩码内合成；采用反事实微调，对事实输出施加重建损失、对翻转灯态输出施加灯态分类损失与颜色损失。
  • 视觉反馈交互学习：将闭环建模为马尔可夫游戏，BV 为共享策略的智能体，渲染器与自车规划器属于环境；冻结 IL 策略并附加零初始化均值的残差头；以分布级奖励鼓励覆盖不足的交互特征区间并惩罚碰撞、越野与进度偏差；采用多智能体组相对策略优化（MAGRPO）的裁剪目标并对初始策略加 KL 正则。

Card 06 评估与结果

评估与结果

  • 评估基准：288 个长尾闭环场景用于交互真实性与信号灯评估；11 个 nuPlan 日志的 1,184 张留出图像与 365 个车辆区域用于新视角保真度。
  • 评估指标：交互真实性使用 TTC_t0、带符号 a_max、v_rel_t1 的直方图重叠与 JS 散度，以及 BV 碰撞率与路线进度；新视角使用 PSNR、SSIM、LPIPS；信号灯使用 VLM 读出的灯态正确率、灯区相似度与车身保持度；置信区间由场景级或车辆级配对 bootstrap 获得。
  • 交互真实性关键数值：相比 World Engine，平均 JS 散度降低 85%；三项特征重叠分别为 0.9775、0.8719、0.9102，均值 0.9198，JS 为 0.0074；BV 碰撞率 9.74%，路线进度 28.10 m，GT 为 3.50% 与 27.66 m；对比方法包括 RealEngine、OmniNWM、World Engine。
  • 新视角保真度关键数值：车辆区域 PSNR 17.97、SSIM 0.438、LPIPS 0.448；全图 PSNR 19.01、SSIM 0.584、LPIPS 0.432；车辆 PSNR 比 World Engine 高 2.0 dB；对比方法包括 MTGS、Difix3D+、DiffusionHarmonizer、Asset Harvester、World Engine。
  • 信号灯真实性关键数值：刹车灯 mF1 0.839、开/关召回 95.0%/75.5%；转向灯 mF1 0.769、开启召回 94.9%、错误/漏检 19.5%/5.1%；对比原始渲染与 InstructPix2Pix、MagicBrush、FLUX。
  • 评估条件：全部为闭环仿真评估；自车规划器为 Alpamayo 1.5，仅输入前视相机、2 Hz、不微调；各方法共享场景、规划器、增强资产与信号灯，仅改变被评估组件。
