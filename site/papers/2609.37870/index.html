Card 02 论文概述

论文概述

  • 任务：单张图像中附着式雨滴（adherent raindrop）的检测与去除。
  • 应用场景：雨天附着在相机镜头或车辆挡风玻璃上的雨滴会遮挡、形变和模糊背景场景，影响自动驾驶等户外视觉系统（特征检测、跟踪、立体匹配等）。
  • 研究问题：雨滴外观受过多参数影响，难以用基于模型的方案解决；深度学习方法缺乏足够大且逼真的训练数据；已有真实雨滴数据集场景为晴天、规模小且缺少像素级掩码。
Card 03 核心贡献

核心贡献

  • 提出物理感知的端到端神经网络，联合进行雨滴检测与去除，网络结构依据雨滴成像物理特性设计。
  • 构建首个带像素级二值掩码的光真实感合成附着雨滴数据集，基于 Cityscapes，覆盖自动驾驶场景，包含约 30K 训练图像与 1525 张测试图像。
  • 提出由雨滴检测网络、雨滴区域重建网络和精修网络组成的三子网络框架，并提出膨胀掩码（dilated mask）减少雨滴边缘残留。
  • 在现有数据集和真实雨天图像上，所提方法在定量与定性上显著优于现有方法。
Card 04 方法描述

方法描述

  • 所属模块：图像复原/图像到图像去雨滴，包含检测与去除两阶段多任务网络。
  • 输入传感器：单张图像（单目图像，原文以相机—玻璃平面—背景平面成像模型描述；未报告实车传感器具体型号）。
  • 场景表示：成像模型为 O = (1 − M)B + R，其中 M 为雨滴二值掩码，B 为清晰背景图像，R 为雨滴层。
  • 关键技术：

- 雨滴检测网络：输出像素级二值掩码，参考 I-CNN，含 5 个卷积层与 6 个残差块，第二个卷积层 stride 为 2 将特征图分辨率降为输入一半，1×1 卷积将通道数从 64 增到 256，残差块采用 bottleneck 形式（两个 1×1 与一个 3×3 卷积），所有卷积后接 BN 与 ReLU，使用二值交叉熵损失。

- 雨滴区域重建网络：结构与检测网络类似但残差块从 6 增至 8；将输入图像与其边缘图组合为 4 通道张量作为输入；边缘图由 RGB 邻域差分计算；损失为加权 L1，雨滴像素权重 λ 设为 20，否则为 1。

- 精修网络：输入为按公式 B = M̂Î + (1 − M̂)R 融合的混合图像，含 2 个卷积层和 2 个残差块；损失为 SSIM 损失与 ℓ1 损失的加权组合，α = 0.3。

- 膨胀掩码：在检测网络输出后加入无参数膨胀层，缓解雨滴边缘召回率低导致的边缘像素残留。

- 训练策略：两阶段训练，第一阶段分别训练检测网络与重建网络，第二阶段固定二者仅更新精修网络参数以防过拟合。

- 数据增广：在线增广，256×512 图像与掩码随机水平翻转后裁剪为 100×100。

Card 05 数据集与资源

数据集与资源

  • 数据集：自建光真实感合成雨滴数据集，基于 Cityscapes 训练集生成约 30000 张训练图像、基于 Cityscapes 测试集生成 1525 张测试图像，包含像素级雨滴二值掩码；每张图像含 50 至 70 个雨滴，半径 r ∈ [0.8, 1.5] 厘米，模糊核直径 7~20 像素。
  • 数据集生成参数：N ∈ [20, 40]，T ∈ [800, 1500]，r ∈ [0.8, 1.5]，ψ ∈ [30°, 45°]，τ ∈ [30°, 45°]。
  • 其他数据集：Qian 等人提出的真实雨滴数据集（原文称其含 1119 对图像，缺少像素级掩码）。
  • 仿真器：原文未报告使用通用仿真器，数据集通过基于光线追踪的几何渲染与物理成像模型合成。
  • 模型规模：检测网络 5 卷积层 + 6 残差块；重建网络 8 残差块；精修网络 2 卷积层 + 2 残差块；总参数量原文未报告。
  • 训练资源：单块 NVIDIA TITAN Xp GPU（12GB 显存），TensorFlow 实现，Xavier 初始化，batch size 32，训练 50 epochs（每 epoch 50K steps），Adam 优化器，初始学习率 0.001，第 20 至 40 epoch 线性衰减至 0.0001。
  • 实车平台：原文未报告。
Card 06 评估与结果

评估与结果

  • 评估基准：自建合成数据集（1525 对雨天/清晰图像及掩码）与 Qian 等人真实数据集。
  • 评估指标：PSNR、SSIM；检测网络额外报告平均精度（AP）。
  • 合成数据集定量结果（PSNR / SSIM）：

- Eigen：29.02 / 0.9560

- Pix2Pix：31.00 / 0.9471

- DID-MDN：31.32 / 0.9576

- Qian：37.79 / 0.9692

- 本文（仅 3RN）：37.73 / 0.9852

- 本文（3RN + RDN + RFN）：39.24 / 0.9848

- 本文（3RN + Dilated RDN + RFN，完整模型）：41.29 / 0.9921

  • 雨滴检测结果：检测网络平均精度 AP = 0.9973，其他方法不输出掩码故未比较。
  • Qian 数据集定量结果（PSNR / SSIM）：

- Eigen：28.59 / 0.6726

- Pix2Pix：30.14 / 0.8299

- DID-MDN：27.06 / 0.8830

- Qian：30.82 / 0.9050

- 本文（仅 3RN）：29.28 / 0.9016

- 本文（粗糙掩码）：30.17 / 0.9128

  • 消融实验：以 3RN 为基线，加入检测网络与精修网络后 PSNR 与 SSIM 均提升；使用膨胀掩码后取得最高 PSNR 和 SSIM；完整架构相较仅 3RN 提升 PSNR 9.4%。
  • 效率：单张 256×512 图像推理时间，本文 69.74ms，Pix2Pix 79.1ms，Qian 97.16ms，Eigen 107.712ms，DID-MDN 133.64ms；均在单块 TITAN Xp GPU 上测试，取 20 次重复平均。
  • 评估条件：主要为合成数据上的定量与定性评估，以及 Qian 真实数据集上的评估；原文未报告闭环评估或实车实验。
