Card 03 核心贡献

核心贡献

  • 提出 EventDrive，首个全栈式的事件-视觉-语言自动驾驶基准数据集，统一感知、理解、预测与规划四个维度的语言接地任务，共 17 个子任务。
  • 提出 EventDrive-VLM，一个统一的事件驱动视觉-语言模型，可在多模态推理中自适应编码和融合异步事件与RGB帧信息。
  • 提出 Dynamic Horizon Event Encoder，通过多时域体素化与 MoE 门控自适应选择信息最丰富的时序表示。
  • 提出 Event Q-Former Alignment 模块，通过跨注意力将事件特征对齐到 LLM 语义空间，支持与文本和帧的联合推理。
  • 建立涵盖帧式、事件式与融合式的统一评测协议，揭示事件与帧在驾驶推理中的互补性，并公开数据集与工具包。
Card 04 方法描述

方法描述

  • 所属模块：端到端事件驱动视觉-语言模型，面向自动驾驶推理（感知、理解、预测、规划）。
  • 输入传感器：事件流（异步亮度变化）、同步 RGB 帧、文本指令；训练数据还使用 LiDAR 与 ego-pose 作为标注来源。
  • 场景表示：事件被体素化为多时域（temporal bins{20,50,100}）的 4D voxel tensor，RGB帧采用原始帧表示。
  • 模型结构：以 Qwen2.5-VL-7B-Instruct 为 LLM 主干，RVT 作为事件编码器；事件编码器+Event Q-Former+线性投影构成事件通路，RGB 视觉编码器保持冻结。
  • 关键技术：Dynamic Horizon Encoding（多时域体素化+moE噪声门控 softmax top-k gating）；Event Q-Former 交叉注意力提取运动感知 token；两阶段训练课程（事件-语言预适应 + 指令微调），采用 packed sequences、FlashAttention 2 与 bf16 混合精度。

Card 06 评估与结果

评估与结果

  • 评估基准：主要在自建的 EventDrive 基准（感知、理解、预测、规划）与事件聊天（Event-Chat）基准上评估。
  • 评估指标：感知用 QA Accuracy（分别报告在 DSEC、M3ED、PKU 数据子集上的指标）；理解用 QA Accuracy、Top-1 grounding Accuracy（IoU≥0.6）与 mIoU；预测与规划分别报告 Speed Accuracy 与 Path Accuracy；规划额外报告 mean L2 Error（单位米）。
  • 对比方法：帧式方法包括 LLaVA-1.5/1.6/OneVision、InternVL2.5/3、Qwen2-VL/Qwen2.5-VL（含微调版）；事件式方法为 EventGPT；融合式为 EventDrive-VLM。
  • 关键结果（自建基准，括号内为最优值）：EventDrive-VLM 在了解任务上的 Acc@D/Acc@M/Acc@P 达到 85.44/86.64/78.89；在理解任务上 Acc 为65.46，Acc@60（IoU0.6）为72.86，mIoU最高为72.56；在规划 Path Accuracy 上达92.35，L2误差采用最低值3.66米。
  • 评估条件：融合模型精度在若干指标上为最优；Qwen2.5-VL-7B 微调版与 InternVL3 在部分指标上为第二名。比对方式包含 zero-shot 与微调、开环/闭环与仿真/实车条件原文未另外报告。
