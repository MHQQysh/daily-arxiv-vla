Card 03 核心贡献

核心贡献

  • 提出一种分解式未来建模范式：保留正常预测作为基础，并选择性修正其未解释的特征变化。
  • 通过候选特定的修正未来特征连接世界模型与规划：每个候选轨迹使用其自身的正常预测与学习到的事件修正作为评估证据。
  • 在全部 12,146 个 NAVSIM navtest 场景上系统评估；未来特征预测 MSE 降低 5.35%，并在 83.54% 的场景中取得更准确的未来预测。
  • 完整系统在官方 EPDMS 评估器上取得 91.05 EPDMS，显示在已发表领先方法中具有竞争力。
  • 通过候选特定未来特征增强轨迹打分，使世界模型预测参与计划选择，而非仅作为辅助表示。
Card 04 方法描述

方法描述

  • 所属模块：世界模型与轨迹评估/选择模块，服务于端到端自动驾驶规划。
  • 输入传感器：多视角图像历史；每个时刻由冻结的 DINOv2-based encoder 编码为视觉 token。输入还包括 ego state 和候选轨迹。
  • 场景表示：紧凑视觉特征空间；DINOv2 表示包含 64 个 learned slots、256 通道，四个相机视角每视角 16 个 slots；每帧含 N 个 d 维 visual tokens。
  • 模型结构：

- 正常演化预测器：基于 WoTE 的 state–action Transformer 设计，历史编码器初始化共享场景状态，轨迹与 ego embedding 初始化候选动作；Dθ 为共享 Transformer，经 M 次 transition 后由 Pθ 将终端状态映射为相对当前特征 Zt 的变化，得到正常未来 \hat{Z}_{i}^{N}。

- 事件驱动增量修正：冻结正常预测器后，用其未解释残差 R 作为监督；修正解码器以正常预测、rollout 状态和 history–action memory 为输入，通过 self-attention、cross-attention 和 FFN 产生修正；两个头分别预测 gate 与 bounded jump，最终 \hat{Z}_{i}^{\mathrm{EditWM}}=\hat{Z}_{i}^{N}+\alpha g_i \odot \Delta Z_i。

- 轨迹打分：候选特征 ci 通过候选–未来 cross-attention 关注候选特定未来记忆 \mathcal{V}_i，输出九分量 logits，并用 EPDMS 组件组合规则形成分数并选择最高分轨迹。

  • 关键技术：正常预测与修正解耦、冻结正常预测器提供残差监督、学习 gate 控制有界修正、候选特定 cross-attention、staged learning。
  • 训练阶段：先训练 Normal prediction，再冻结 Normal 训练 gated correction，最后冻结世界模型训练 trajectory scoring。
  • 原文未报告：实车平台、仿真器、模型总参数量、推理延迟/FLOPs 等效率指标。

Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM navtest 全部 12,146 个场景；世界模型未来特征评估在 expert trajectory 条件下与真实终端未来特征比较。
  • 评估指标：EPDMS 及九个 0–100 分量：NC、DAC、DDC、TL、EP、TTC、LK、HC、EC；未来特征预测使用 MSE 和 cosine similarity。
  • 关键数值：

- 完整系统取得 91.05 EPDMS；高于 SparseDriveV2 的 90.1 0.95 分，高于 DrivoR 的 88.40 2.65 分。

- EC=96.6；DDC=99.6；TL=99.9；HC=98.3；DAC=98.8；EP=87.5。

- 未来特征 navtest MSE 从 0.39352 降至 0.37246，降低 5.35%；cosine 从 0.95078 升至 0.95355。

- 验证集 MSE 从 0.32490 降至 0.29693，降低 8.61%。

- EditWM 在 83.54% 场景降低 MSE，剩余 16.46% 增加。

- 按 Normal MSE 五分位分组，Q1–Q5 相对降低分别为 9.41%、8.40%、6.86%、5.15%、2.06%。

- 前、后、左、右相机相对 MSE 降低分别为 4.95%、2.14%、6.23%、9.32%。

- 同候选池消融：w/o Future Features 90.84 EPDMS，Normal-only 90.51 EPDMS，Ours 91.05 EPDMS；Oracle 97.73 EPDMS。

- 定性三场景中，expert-conditioned future MSE 分别为 0.3109→0.2872、0.3400→0.3349、0.3489→0.3061；Ours EPDMS 分别为 93.75、94.09、87.16。

  • 对比方法：Hydra-MDP++、DiffusionDrive、WoTE、iPad、DriveSuprim、DiffusionDriveV2、DrivoR、SparseDriveV2、CLOVER；消融中与 w/o Future Features、Normal-only、Oracle 比较。
  • 评估条件：开环 NAVSIM navtest 评估与官方 EPDMS 评估器；世界模型评估为 expert-trajectory-conditioned 未来特征预测；原文未报告闭环或实车评估。
