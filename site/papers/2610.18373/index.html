DR-VLA: Learning Human-Like Quadruped Navigation from Egocentric Web Videos via Domain-Invariant Scene Representations

Card 03 核心贡献

核心贡献

  • 提出领域不变场景表示（DISR），将人类与机器人观测抽象为共享的语义、空间与关系结构，使社会合规等人类导航先验可从大规模第一视角视频蒸馏并跨具身迁移。
  • 提出 DR-VLA，一种 Mixture-of-Transformers 潜在世界动作模型，其理解、世界与动作专家解耦不同数据来源的监督，并可扩展到多种导航场景。
  • 构建 EgoLynx 数据集，将 1 万小时第一视角网络视频与 2,000 段遥操作四足机器人片段按统一标注格式（指令、描述、DISR 目标）配对，支持无动作预训练后进行数据高效适配。
  • 提出四足导航分数（QNS），一种伪闭环指标，综合评估安全性、指令合规性、舒适性与行进进度。
  • 在真实四足导航上 QNS 相对最优对比结果提升约 5%，在 NAVSIM 上达到 92.1 PDMS，说明该表示跨具身具有通用性。
Card 04 方法描述

方法描述

  • 所属模块：策略分解为跨具身共享的场景演化预测器 Ψ（由理解专家与世界专家共同实现）与具身特定动作生成器 π_e（动作专家）。
  • 输入传感器：四足机器人为 4 路环视鱼眼相机，指令为自然语言路线描述；机器人动作块覆盖 1 秒，N_a=10，δ=0.1 秒。驾驶场景指令为四类高层命令，动作块覆盖 4 秒，N_a=8，δ=0.5 秒。
  • 场景表示：DISR 为紧凑时空隐变量 z，沿语义、空间、关系三轴刻画场景。语义来自冻结的 SAM 3 概念分割（固定类别词表的多通道类别掩码），空间来自冻结的 Depth Anything 3 相对深度（丢弃绝对尺度以缓解相机高度差异）；二者拼接后经 L_rel 层因果时空自注意力编码，由轻量解码器重建，构成自编码器。编码器仅接收 (S_i, D_i) 而不接收 RGB，从构造上排除纹理、光照、成像风格等外观因素。
  • 模型结构：理解专家基于 Qwen3-VL-2B，编码多视角图像与指令生成前缀 token，并以场景布局、周围智能体、潜在危险与自车运动的描述作为链式辅助监督；世界专家在世界 token 上预测 K 个未来帧的 DISR 隐变量，损失为 smooth-L1 与余弦相似度组合；动作专家以条件流匹配生成轨迹，每个路点一个动作 token，自车状态额外一个 token，推理时用 4 步 Euler 积分。
  • 关键技术：三位专家参数独立、通过共享注意力交互；采用块级注意力掩码，世界与动作 token 不关注描述，动作 token 对前缀与世界 token 不可见，因此前缀与世界隐状态在推理时只计算一次并在积分步间复用；图像 token 加入可学习视角嵌入以区分四路鱼眼视图而无需矫正。
  • 训练流程：两阶段。阶段一在 EgoLynx-Web 上仅训练理解与世界专家（L1 = L_cap + λ_w L_world），刻意不从视频估计伪轨迹；阶段二在 EgoLynx-Robot 上初始化动作专家与四路相机视角嵌入，并以 L2 = L1 + λ_a L_act 微调全部参数，保留描述与世界损失以防能力退化并吸收残余视角差异。
  • 原文未报告：网络层数、隐变量维度 N_z 与 d_z、损失权重 λ_w 与 λ_a 的具体取值、世界专家预测的未来帧数 K 的具体取值。
Card 05 数据集与资源

数据集与资源

  • EgoLynx-Web：约 1 万小时第一视角网络视频，采集自 YouTube，覆盖步行、骑行等人类导航形式，含城市与乡村、不同时段与天气；经多阶段清洗后保留，约为 Sekai 的两倍、Ego4D 的三倍；每条片段由 Gemini 3.1 Flash-Lite 生成指令与描述。

Card 06 评估与结果

评估与结果

  • 评估基准：留出的 EgoLynx-Robot 测试划分（真实世界四足导航）与 NAVSIM v1（自动驾驶）。
  • 评估指标：开环平均/最终位移误差（ADE/FDE）、平均/最终航向误差（AHE/FHE）；伪闭环指标包括无碰撞（NC）、可行走区域合规（WAC）、碰撞时间（TTC）、间隙（CL）、自车进度（EP）、指令合规（IC）与四足导航分数（QNS）；驾驶使用 PDMS。
  • 关键数值：在 EgoLynx-Robot 测试划分上，QNS 相对该指标最强对比结果提升约 5%，最终航向误差 FHE 降低 14.6%；与八个导航及视觉-语言-动作基线对比。NAVSIM v1 上（无 EgoLynx-Web 预训练、独立训练）达到 92.1 PDMS，移除世界专家后降至 89.5。
  • 消融结论：网络视频预训练提升留出机器人数据上的表现；DISR 作为未来预测目标优于五种通用视觉表示；与任务特定 3D 感知相比，DISR 在无 Box/Line 标注、无点云构建目标的情况下取得接近的目标端性能；将感知作为在线策略输入可提升 QNS 但增加计算开销。
  • 对比方法：VLN 类策略包括 InternNav、NaVILA 等（原文表格另含其他导航与视觉-语言-动作基线，正文截断处未完整列出）。
  • 评估条件：四足导航结果基于真实世界遥操作数据的开环位移/航向误差与伪闭环 QNS 评估；驾驶结果为 NAVSIM 基准上的开环/伪闭环评测。实车在线闭环部署结果原文未报告；仿真条件原文未报告。
