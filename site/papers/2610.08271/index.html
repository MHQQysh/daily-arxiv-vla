Reinforcement Learning with Segment Reward Feedback under Linear Function Approximation

2026-10-06 · 原文 · 翻译 · 2610.08271

论文研究线性函数近似下的分段奖励反馈强化学习（RL with segment reward feedback under linear function approximation）。 解决的问题是：经典 RL 假设每个访问到的状态-动作对都能立即观察到奖励，但在自动驾驶等真实应用中，细粒度奖励代价高、难收集，而轨迹级反馈又过于稀疏，因此需要介于两者之间的分段反馈模型。 应用场景包括自动驾驶中按安全性、舒适性、效率等多准则评估每个状态-动作对较困难，以及机器人操作中更易判断任务是否成功而非给每个动作可靠奖励。 研究问题包括：分段反馈的粒度（segment granularity）和分段选择（choice of segmentation）如何影响学习性能；分段级奖励信息能否在线性 MDP 中被高效利用；按状态-动作特征选择分段是否能可证明地带来收益。 论文采用 episodic linear MDP 框架，考虑 binary feedback 与 sum feedback 两种反馈类型，并覆盖已知转移与未知转移设置，以及 equal-length 与 variable segment 设置。

Card 02 论文概述

论文概述

  • 论文研究线性函数近似下的分段奖励反馈强化学习（RL with segment reward feedback under linear function approximation）。
  • 解决的问题是：经典 RL 假设每个访问到的状态-动作对都能立即观察到奖励，但在自动驾驶等真实应用中，细粒度奖励代价高、难收集，而轨迹级反馈又过于稀疏，因此需要介于两者之间的分段反馈模型。
  • 应用场景包括自动驾驶中按安全性、舒适性、效率等多准则评估每个状态-动作对较困难，以及机器人操作中更易判断任务是否成功而非给每个动作可靠奖励。
  • 研究问题包括：分段反馈的粒度（segment granularity）和分段选择（choice of segmentation）如何影响学习性能；分段级奖励信息能否在线性 MDP 中被高效利用；按状态-动作特征选择分段是否能可证明地带来收益。
  • 论文采用 episodic linear MDP 框架，考虑 binary feedback 与 sum feedback 两种反馈类型，并覆盖已知转移与未知转移设置，以及 equal-length 与 variable segment 设置。
Card 03 核心贡献

核心贡献

  • 研究线性函数近似下的分段奖励反馈 RL，提供一种统一反馈范式，将逐状态-动作反馈与轨迹级反馈作为两个极端，覆盖 binary 与 sum 反馈以及已知/未知转移。
  • 对 equal-length segments 且已知转移的情况，提出 binary feedback 算法 SegBiTS-d 和 sum feedback 算法 E-LinUCB-d；SegBiTS-d 使用 posterior sampling with planning，E-LinUCB-d 使用 E-optimal experimental design，前者 regret 含 exp(Hr_max/(2m)) 依赖，后者在忽略对数因子时 regret 不依赖 m。
  • 为已知转移下 binary 与 sum segment feedback 建立 dimension-dependent regret lower bounds；binary 下通过 Bernoulli KL-divergence 分析表明 H/m 的指数依赖不可避免，sum 下验证上界近最优且 m 不影响 regret（至对数因子）。
  • 对 equal-length segments 且未知转移的情况，提出统一 Seg-LSVI-TS 框架，并给出 binary 与 sum feedback 的计算与样本高效实例；该框架将奖励参数 posterior sampling 与 optimistic least-squares value iteration 结合，解决段级奖励不确定性与状态-动作级值迭代不匹配的问题。
  • 研究 variable and binary segment feedback with known transitions，提出允许任意分段（包括自适应、episode 相关分段）的算法 Uneq-SegBiTS-d；其 regret bound 表明在常用 elliptical potential 分析下，状态-动作特征影响仅进入对数因子，feature-dependent segmentation 不会显著提升学习，equal segmentation 达到最佳性能。
Card 04 方法描述

方法描述

  • 所属模块：论文属于强化学习算法与理论分析工作，提出面向线性 MDP 的分段奖励反馈学习算法，并给出 regret 上界与下界；原文未报告其属于自动驾驶系统中的具体感知、规划或控制模块。
  • 输入传感器：原文未报告具体传感器输入；论文使用抽象的 MDP 状态、动作、特征映射 ψ(s,a) 与奖励反馈，不报告相机、激光雷达等传感器配置。
  • 场景表示：采用 episodic linear MDP M=(S,A,H,r,P,ρ)；状态空间可为可测或大/连续空间，动作空间有限，episode horizon 为 H，初始状态分布为 ρ；奖励函数与转移核通过已知 d 维特征映射 ψ(s,a) 线性表示，即 r(s,a)=<ψ(s,a), θ*>，P_h(·\|s,a)=<ψ(s,a), μ_h*(·)>；奖励参数 θ* 未知，转移 P 在已知转移设置中已知，在未知转移设置中需学习。
  • 反馈模型：episode 被划分为若干 segment，agent 只观察每个 segment 的奖励反馈；equal-length 设置将 episode 分为 m 个长度为 H/m 的等长 segment；binary feedback 中每个 segment 观察 Bernoulli 结果，其参数为 segment 累积奖励的 sigmoid；sum feedback 中观察 segment 累积随机奖励的和，包含零均值、1-sub-Gaussian 噪声；variable binary feedback 中 segment 数量和划分可由算法在观察到轨迹后自适应决定。
  • 模型结构：线性函数近似；聚合特征定义为 φ^τ = Σ_{(s,a)∈τ} ψ(s,a)；策略为 π={π_h}，学习目标是使累计 regret R(K)=Σ_{k=1}^K E[V_1^*(s_1^k)-V_1^{π^k}(s_1^k)] 最小。
  • 关键技术：对 binary feedback 的已知转移设置，SegBiTS-d 使用正则化 logistic regression 估计奖励参数，构造 segment covariance matrix，采样高斯噪声并形成 posterior estimated reward parameter，再利用线性 MDP planning 求解策略；对 sum feedback 的已知转移设置，E-LinUCB-d 使用 E-optimal experimental design 改善 covariance matrix conditioning；对未知转移设置，Seg-LSVI-TS 将 posterior estimated reward parameters 融入 least-squares value iteration；对 variable binary feedback，Uneq-SegBiTS-d 允许任意分段并考虑每个 segment 的 sigmoid curvature。
  • 原文未报告：神经网络结构、模型层数、参数量、训练超参数、感知输入编码方式、具体线性 MDP planning 实现细节等均未在给定 HTML 中报告。
