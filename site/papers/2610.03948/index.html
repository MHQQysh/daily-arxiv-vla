Card 02 论文概述

论文概述

  • 任务：面向自动驾驶的闭环决策，在复杂交通交互中由 LLM 生成驾驶动作。
  • 应用场景：Highway-env 仿真器中的多车道高速公路驾驶任务（highway-v0）。
  • 研究问题：现有基于数值优化、序列预测和 LLM 的自动驾驶决策方法对哲学与伦理价值关注有限；文献尚未确立如何将基于文化的哲学原则表示为可复用、场景级的驾驶示例，从而限制了抽象价值原则在具体交通交互中的系统化应用。
  • 解决思路：提出 CPW-Drive，一个闭环检索增强生成（RAG）框架，将源自中国哲学（以儒家思想为知识源）的价值引导融入自动驾驶决策。
Card 03 核心贡献

核心贡献

  • 提出 CPW-Drive，作者称其为首个将源自中国哲学智慧的驾驶相关价值原则融入 LLM 自动驾驶决策的框架。
  • 从儒家经典中提炼驾驶相关价值原则（共十项：Wisdom、Righteousness、Respect、Adaptability、Benevolence、Courage、Moderation、Propriety、Empathy、Trustworthiness），并将其组织为可检索、场景化的案例。
  • 提出 Physics-aware Spatial Similarity Retrieval（PSSR），用于基于车辆空间布局与速度外推状态的历史场景检索。
  • 在三种交通配置的闭环实验中，报告了更高的成功率、更多无碰撞步数以及更克制的驾驶行为，同时存在效率方面的权衡。
Card 04 方法描述

方法描述

  • 所属模块：整体为基于 LLM 的闭环驾驶框架，包含四个主要组件——驾驶相关价值原则构建、哲学驾驶知识库构建、历史场景检索、闭环 LLM 决策。
  • 输入传感器：原文未报告传感器层面的输入；场景编码器将环境状态转换为结构化自然语言场景描述，系统保留车辆物理状态供 PSSR 检索。
  • 场景表示：以自车为中心的坐标系表示，形式为 Z = (v_ego,x, {(x_i, y_i, v_i,x)}_{i=1}^{N_Z})，其中 x、y 为周围车辆相对自车的纵向与横向位置，v_x 为纵向速度；自车为坐标参考但不纳入空间密度场，其速度用于刻画周围车辆相对运动。
  • 模型结构：LLM 对当前场景描述、检索到的案例与可用驾驶动作进行推理，生成推理过程与驾驶动作；决策编码器处理生成的决策以在环境中执行，更新后的环境状态进入下一步。提示模板与闭环决策示例见附录 B。
  • 关键技术一（价值原则推导）：使用 131 部儒家经典作为知识源，切分为文本块，由 LLM 提取关键词，跨经典与文本块聚合、去重、按识别频率排序得到 40 个候选关键词；再根据与源文本一致性、概念重叠和驾驶决策相关性人工筛选与概念整合，并由一位拥有中国哲学博士学位的作者最终审阅，得到十项价值原则。
  • 关键技术二（知识库）：知识库为历史驾驶案例集合，每个案例含四个字段：scenario、value principles、reasoning process、driving action，表示为 C=(S,V,R,A)。从 Highway-env 不同车道配置、车辆密度和随机种子下采集超过 3000 个候选场景，剔除局部交通构型高度相似的场景；对保留场景由 LLM 识别相关原则并生成推理过程与驾驶动作，经人工审阅修正/删除后，最终知识库含 135 个历史驾驶案例。
  • 关键技术三（PSSR）：受 Smooth Overlap of Atomic Positions（SOAP）启发，将连续密度重叠思想适配到自车中心驾驶场景，引入各向异性纵横向空间尺度，并由当前速度估计短期未来车辆位置。以二维各向异性高斯密度表示周围车辆位置，纵向与横向空间尺度分别为 σ_x 与 σ_y，车辆级空间核 K_space(i,j) 为高斯密度重叠按公共因子 πσ_xσ_y 重缩放；场景级原始空间重叠 S_space(X,Y) 对所有车辆对求和，无需显式一一对应；归一化形式 K_space^0(X,Y)=S_space(X,Y)/sqrt(S_space(X,X)S_space(Y,Y))。
  • 关键技术三参数：Δt=1.0 s 用于位置外推（仅纵向，横向不变）；σ_x=5 m，σ_y≈1.1533 m（由空间核在一个车道宽 L=3.5 m 处衰减至 0.10 确定）；组合权重 w_cur=0.7、w_ext=0.3，作者说明因可用调参样本有限未做广泛超参搜索，采用该启发式设置；最终相似度位于 (0,1]。取相似度降序 Top-k 个案例作为参考，主实验中 k=3。
  • 未报告信息：模型规模、训练资源（是否训练/微调）原文未报告；原文说明所有方法通过同一 API 使用 DeepSeek-V4-Pro 且未额外微调。

Card 06 评估与结果

评估与结果

  • 评估基准：Highway-env highway-v0 多车道高速公路驾驶任务，三种交通配置——四车道密度 2.0、五车道密度 2.5、五车道密度 3.0。
  • 评估协议：每种配置 10 轮评估，每轮 20 次不同随机种子运行；每次运行 30 个决策步，仿真策略频率 1 Hz；完成全部 30 步且无碰撞视为成功；主结果与消融结果报告为 10 轮的均值与标准差。
  • 动作空间：离散元动作，共五种——向左变道、保持当前状态、向右变道、加速、减速。
  • 评估指标：成功率（SR）、无碰撞步数（CFS）、效率分数（ES，来自 KoMA，基于自车速度与周围车辆平均速度之比，自车速度达到或超过平均值时为 10，否则按比例缩放）、变道频率（LCF，作为描述性行为指标，不作单调偏好排序）。
  • 对比方法：DriveLikeAHuman、DiLu、LimSim++，均使用 DeepSeek-V4-Pro 同一 API、无额外微调，保留原始提示模板与方法特定设置。
  • 开环/闭环与实车条件：全部为仿真闭环评估，未报告开环评估或实车实验。
  • 主结果（闭环仿真）：CPW-Drive 在三种配置下 SR 分别为 93.0%、86.0%、72.0%，相较各配置最强 SR 基线分别提升 8.0、22.5、25.0 个百分点；在所有配置下取得最高 SR 与 CFS；LCF 整体保持较低；但 ES 在三种配置下均低于最优基线（CPW-Drive ES 为 8.38、8.32、8.47）。
  • 消融设置：No RAG（去除历史案例检索）、Text RAG（用文本向量检索替换 PSSR，同库同检索数）、RAG w/o Philosophy（保留 PSSR 与相同历史场景但去掉价值原则）、Philosophy in Prompt（十条价值原则直接放入系统提示、无检索）、Conservative Prompt（非哲学历史案例加通用保守驾驶指令）。
  • 消融结果要点：相较 CPW-Drive，No RAG 降低 SR 与 CFS 并提高 LCF；Text RAG 同样降低 SR 与 CFS，说明 PSSR 通过建模空间关系与运动状态检索到更匹配案例；RAG w/o Philosophy 在各配置下 SR 与 CFS 更低但 ES 与 LCF 更高，说明哲学内容带来更安全克制行为但以效率为代价；Philosophy in Prompt 的 SR 与 CFS 接近完整模型但 ES、LCF 进一步降低；Conservative Prompt LCF 最低但效率损失更大，且随交通复杂度提高退化更明显
