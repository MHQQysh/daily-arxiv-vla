论文概述

Card 03 核心贡献

核心贡献

  • 提出 Visibility-Driven Data Partitioning（可见度驱动数据分区）策略，显式建模相机分布与场景结构的关系，实现更合理的数据分区和更均衡的训练。
  • 设计面向低可见度锚点的梯度补偿与致密化机制，缓解弱约束区域的欠拟合，提升复杂场景重建鲁棒性。
  • 在多个大规模航拍数据集上验证：在视角分布不均条件下显著优于现有方法，在视角较均匀场景中保持竞争力。
Card 04 方法描述

方法描述

  • 所属模块：基于锚点（anchor-based）的 3DGS 框架，包含可见度驱动数据分区与可见度引导锚点生成两大模块。
  • 输入传感器：原文未报告具体传感器类型；实验使用 COLMAP 估计的相机位姿与稀疏点云作为输入。
  • 场景表示：在 Scaffold-GS 式锚点结构上，每个锚点持有可学习特征，经 MLP 解码出 k 个神经高斯（位置偏移、不透明度、尺度、旋转、颜色等），用标准 3DGS 光栅化渲染。
  • 关键技术一：可见度驱动分块。先在全场景训练固定迭代得到粗模型；将归一化平面锚点坐标 (x, y) 与归一化可见度 V̂ 加权组合成聚类特征，在联合空间聚类；保留每簇最大连通分量，用 α-shape 构建 2D 边界并扩张。
  • 关键技术二：基于重渲染误差的相机分配。渲染全场景图与块级图，计算像素差图与归一化覆盖比，超过阈值则将相机分配给该块。
  • 关键技术三：可见度引导锚点生成。按周期统计每个高斯被当前周期相机视锥观测的比例，低于阈值 T_low 的归为低可见度集合；用全局缓存 g_k 累积历史梯度并按指数补偿更新，densification 时叠加到原始梯度统计上。
  • 训练与块合并：子块多 GPU 并行训练，训练时抑制块边界梯度更新并冻结 MLP 解码器参数；训练完成后按可见度覆盖合并核心锚点。

Card 06 评估与结果

评估与结果

  • 评估基准：五个大规模航拍场景（Residence、Sci-Art、Rubble、Building、Block-All）。
  • 评估指标：PSNR（↑）、SSIM（↑）、LPIPS（↓），测试视图上评估，并采用与先前工作相同的颜色校正策略。
  • 对比方法：Switch-NeRF、3DGS、Scaffold-GS、DOGS、Octree-GS、HUG、Momentum-GS、MixGS。
  • 关键数值（Residence / Sci-Art / Rubble / Building / Block-All PSNR）：VDGS 为 24.03 / 26.94 / 26.67 / 23.73 / 28.74；其中 Sci-Art PSNR 明显高于现有 3DGS 类方法，Block-All PSNR 为次优。
  • 对比结果：在视角分布不均的 Residence 与 Sci-Art 场景优势显著；在较均匀的 MatrixCity、Building、Rubble 场景保持竞争力。
  • 消融结果（Residence）：完整模型 PSNR 24.01、SSIM 0.845、LPIPS 0.188；去掉 Blocking 降 0.62 dB；去掉锚点生成同样导致性能下降；分块数增加到 8/16 后指标趋于饱和；超参数在测试范围内稳定，λ_vis=0（纯空间分区）性能下降。
  • 效率结果：8 块 Residence 场景渲染速度 42.96 FPS。
  • 评估条件：均为开环新视角合成评估（基于图像指标），原文未报告闭环或实车实验。
