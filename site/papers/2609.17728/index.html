Card 02 论文概述

论文概述

  • 论文面向端到端自动驾驶的规划任务，提出基于 VLA（Vision-Language-Action）框架 RAF-VLA。
  • 应用场景为自动驾驶中的轨迹规划：输入前视图像序列、导航指令与驾驶状态，输出未来自车轨迹航点。
  • 研究问题：现有“世界建模型 VLA”通过显式预测未来驾驶场景作为密集监督来学习规划相关内部表示，但带来两个问题：额外的训练负担与推理延迟。
  • 论文提出在表示层面而非生成层面利用未来场景监督，通过 Future-Aligned 监督微调直接对齐策略隐状态与未来帧表示，从而避免未来生成。
Card 03 核心贡献

核心贡献

  • 提出 RAF-VLA，一种在表示层面利用未来场景监督的 VLA 自动驾驶框架，使驾驶策略直接学习规划相关的内部表示。
  • 提出 Future-Aligned Supervised Fine-Tuning，通过在动作学习上施加简单正则化，将策略隐状态与未来帧表示对齐，避免未来生成带来的训练负担与推理延迟。
  • 在 NAVSIM 基准上进行实验，显示在显著更少训练样本的条件下取得与最新 VLA 规划器相当的规划性能，训练开销低、推理开销可忽略。
  • 论文报告 Future-Aligned SFT 仅带来 3.8% 训练开销，推理开销为 1 ms。
  • 论文给出定性结果与受控对比实验以支持方法有效性。
Card 04 方法描述

方法描述

  • 所属模块：端到端自动驾驶规划中的 VLA 策略学习，包含表示对齐与动作预测；训练分为 Future-Aligned SFT 与基于 GRPO 的 RFT 两阶段。
  • 输入传感器：时间步 t 的前视图像序列 I_t = {I_{t-T}, ..., I_t}，当前导航指令 ℓ_t，驾驶状态 s_t（近期自车位姿与当前导航命令的 one-hot 编码）。
  • 场景表示：输入 q_t = (I_t, ℓ_t, s_t)；输出为未来航点轨迹 τ̂_t = π_θ(q_t) = {p̂_{t+h}}_{h=1}^{H}，每个航点包含位置与朝向 (x̂, ŷ, θ̂)。
  • 模型结构：采用 Mixture-of-Transformers（MoT）架构，包含 Vision-Language Expert 与轻量 Action Expert；两个专家在每层通过 joint attention 交互。
  • Vision-Language Expert：基于预训练 VLM 构建，输入图像序列与导航指令分别由视觉编码器和 tokenizer 编码；在图像和语言 token 之后附加可学习的 world queries 作为未来对齐的表示槽。
  • Action Expert：结构与 Vision-Language Expert 类似但隐藏维度更小；输入为可学习 action queries 与由驾驶状态经 MLP 投影得到的 status token。
  • Joint Attention：两个专家各自计算 Q、K、V，在 token 序列维度上拼接；Action Expert 内部（status token 与 action queries）使用全双向注意力，允许 Action Expert 注意 Vision-Language Expert，反向被 mask；注意力输出再拆分回对应专家。
  • 动作解码：使用基于 query 的 action head 与多个轨迹锚点，将最终动作表示解码为自车轨迹；轨迹预测损失记为 L_act。
  • Future-Aligned SFT：为每个选定的未来规划步 h ∈ H_F 分配 K 个可学习 world queries；world queries 可注意图像与语言 token，采用块状因果注意力（同一 horizon 的 K 个 query 内部双向，屏蔽更晚 horizon）。
  • 表示对齐：冻结的预训练 world encoder f 从未来帧 I_{t+h} 提取目标表示，仅作为训练对齐目标，不作为策略输入；可训练两层 MLP projector（GELU 激活）g_φ 将 world-query 隐状态映射到目标特征空间；通过最小化均方误差实现对齐。
  • 训练目标：L_SFT = L_act + λ_align · L_align；world encoder 在 SFT 期间冻结。
  • 训练后处理：Future-Aligned SFT 后移除 world encoder 与对齐 projector，但保留学习到的 world queries；Action Expert 通过 joint attention 直接关注其上下文化隐状态。
  • RFT：使用 GRPO 进行强化微调，旧策略采样一组 G 个候选输出，用组内归一化优势 A_i 优化当前策略，包含裁剪代理目标与对参考策略 π_ref 的 KL 惩罚；规划奖励 r_i 使用 NAVSIM PDMS；RFT 阶段不再使用未来帧监督。
  • 原文未报告：具体传感器安装参数、相机内参/外参细节、world encoder 的具体网络结构细节等。
Card 05 数据集与资源

数据集与资源

  • 数据集：NAVSIM v1 与 NAVSIM v2 基准；NAVSIM 基于 OpenScene，提供真实传感器观测与标注驾驶场景；训练使用 navtrain 划分，评估使用 navtest 划分。
  • 仿真器/平台：NAVSIM 为基于真实数据的闭环评估基准；原文未报告实车平台信息。
  • 模型规模：Vision-Language Expert 使用 Qwen2.5-VL-7B-Instruct；Action Expert 为 embedding dimension 1024 的轻量 transformer；对齐 projector 为两层 MLP，GELU 激活；world encoder 来自 Cosmos world model。
  • 训练配置：Future-Aligned SFT 训练 4 epochs，AdamW，global batch size 144，学习率 1×10^{-5} 余弦衰减，冻结 VLM vision encoder 与 world encoder；默认对齐 1 s 与 4 s horizon，每个 horizon K=4 个 world queries，λ_align=1。
  • RFT 配置：GRPO 训练 1.5 epochs，global batch size 288，学习率 2×10^{-6}，group size G=8，KL 系数 β=0.04；移除 world encoder 与 alignment projector，冻结 VLM vision encoder、world queries 与 action head。
  • 训练资源：4×H200 GPUs；SFT 约 11 小时，RFT 约 7 小时；vanilla SFT 为 10.56 h（42.2 H200 GPU-hours），Future-Aligned SFT 为 10.96 h（43.8 H200 GPU-hours）。
  • 推理测量：单张 NVIDIA H200 GPU，batch size 1。
Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM v1 与 NAVSIM v2 闭环指标评估。
  • 评估指标：NAVSIM v1 使用 PDMS = NC × DAC × (5EP + 5TTC + 2C)/12，其中包含 No At-Fault Collision（NC）、Drivable Area Compliance（DAC）、Ego Progress（EP）、Time-to-Collision（TTC）、Comfort（C）；NAVSIM v2 使用 EPDMS，额外包含 Driving Direction Compliance（DDC）、Traffic Light Compliance（TLC）、Lane Keeping（LK）、History Comfort（HC）、Extended Comfort（EC）。
  • NAVSIM v1 主要结果：仅使用单前视相机时 RAF-VLA 达到 PDMS 90.0；使用 best-of-N（N=6）策略时 PDMS 提升至 94.2，同时取得最佳 DAC 99.6 与 EP 89.8；对比方法包括 UniAD、TransFuser、LAW、Epona、Hydra-MDP、DiffusionDrive、WoTE、DriveLaW、AutoVLA、ReCogDrive、AdaThinkDrive、DrivingGPT、FSDrive、PWM、DriveVLA-W0、ExploreVLA、SGDrive 等。
  • NAVSIM v2 结果：Future-Aligned SFT 模型达到 EPDMS 86.2，与最佳已报告 SFT 结果相当；对比方法包括 TransFuser、VADv2、Hydra-MDP、Hydra-MDP++、ReCogDrive、DiffusionDrive、DriveVLA-W0、SGDrive。
  • 对齐有效性：无对齐 SFT PDMS 为 87.92；Future-Aligned SFT 为 89.13（+1.21）；经过 RFT 后，由 Future-Aligned SFT 初始化的模型 PDMS 为 90.03，由无对齐 SFT 初始化的模型为 88.85（+1.18）。
  • 训练开销：Future-Aligned SFT 相对 vanilla SFT 训练时间从 10.56 h（42.2 H200 GPU-hours）增至 10.96 h（43.8 H200 GPU-hours），增加 3.8%。
  • 推理开销：对齐使预测 4 秒轨迹的延迟从 0.152 s 变为 0.153 s，Δ 为 +0.001 s（1 ms），推理开销可忽略。
