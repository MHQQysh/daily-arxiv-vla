Card 02 论文概述

论文概述

  • 论文针对自动驾驶端到端轨迹规划任务，解决视频基础模型（world-action model）在每次决策时重复编码历史帧和迭代生成未来视频所导致的高延迟问题。

  • 研究问题包括：在已有视觉历史缓存后，测试时未来预测对决策的贡献有多大；以及如何在不迭代去噪未来视频的前提下，用一次前向传播获得未来预测特征来条件化轨迹生成。
Card 03 核心贡献

核心贡献

  • 提出 AR-WAM，一种因果世界-动作模型，从增量更新的观测历史缓存和单次预测前向传播中规划轨迹。
  • 设计使缓存可复用的机制：自我状态与驾驶指令仅进入每次决策的预测段，不进入历史缓存；决策相对注意力让轨迹专家可在流中任意位置读取缓存特征与预测特征。
  • 研究在已有视觉历史后测试时未来预测的作用，并将其以“对纯噪声未来 token 的单次骨干前向传播”形式集成到自回归世界-动作建模中。
  • 展示单相机规划性能：监督训练后 NAVSIM-v1 PDMS 为 91.5，强化学习后为 94.0；在动态连续驾驶设置中得分高于对比的世界-动作模型且延迟更低。
Card 04 方法描述

方法描述

  • 所属模块：端到端轨迹规划；以预训练因果视频扩散 Transformer（OmniDreams）为骨干，配合层间轨迹专家。
  • 输入传感器：单前视相机图像序列；另有时变输入向量 q（自我状态、近期自车位姿、驾驶指令）。原文未报告其他传感器。
  • 场景表示：因果视频潜变量序列，历史以固定大小 chunk 的分块因果注意力处理，缓存最近 W 个 chunk 的 K/V；每决策构造世界段，包含当前帧潜变量与 F 个未来槽（部署时取 τ=1 的纯噪声），带时间位置 n−F,…,n。
  • 模型结构：视频骨干每个决策只执行一次前向传播，输出每层历史 token 与世界 token 的 K/V（视觉上下文 cτ）；轨迹专家与骨干逐层对应，通过决策相对旋转位置偏移 Δ=n−F 读取历史 K/V 与世界 K/V，并加入动作 token 和辅助 token（当前图更高分辨率特征与 q 嵌入）；动作采用 flow matching 的 Euler 积分 K 步。
  • 关键技术：增量视觉历史缓存与滑动窗口；单次预测前向传播替代迭代未来视频去噪；q 仅注入世界段和专家以保持缓存有效；联合训练动作流匹配损失与视频流匹配损失，未来槽采用混合噪声调度；使用 Flow-GRPO 式随机采样与规则驾驶奖励进行策略精炼，并采用共享奖励尺度替代分组奖励标准化。

Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM-v1 PDMS 及其分项、NAVSIM-v2 EPDMS、两阶段 NAVHARD 分数、nuScenes 零样本 L2 与碰撞率；另有动态连续驾驶设置（138 个 NAVTEST 源日志按时间顺序、2 Hz、持久历史缓存，47,220 个非等待帧）。
  • 评估指标：PDMS、EPDMS、NC、DAC、TTC、Comfort、EP、L2、碰撞率、每决策中位延迟。
  • 关键数值：监督 AR-WAM 在 NAVTEST 上 PDMS 91.5；RL 后 PDMS 94.0；EPDMS 奖励精炼后 NAVTEST EPDMS 92.2、NAVHARD EPDMS 42.3。单次预测传播相对无未来变体在 NAVHARD 上 EPDMS 提升 1.3（37.3→38.6），延迟从 0.8× 增至 1.0×；清晰未来去噪仅再增 0.2 EPDMS 但耗时超过四倍（4.2×）。动态设置中 AR-WAM 延迟 146.3 ms、EPDMS 91.5，RL 后 132.8 ms、EPDMS 92.2，高于 SimWAM（499.1 ms，90.4）、UNIVERSE（256.9 ms，88.3）、DriveVA（258.8 ms，87.4）、DriveWAM（895.7 ms，90.9）。nuScenes 零样本全样本平均 L2 0.87 m，非等待样本与 DriveWAM 迁移最佳。
  • 对比方法：SimWAM、UNIVERSE、DriveVA、DriveWAM、WA-JEPA、Epona、PWM、DriveLaW、GeoWAM、SUV、DA-WAM、DrivoR、DiffusionDrive、ReCogDrive、DriveVLA-W0、人类驾驶员及恒速参考等。
  • 条件：主要为开环基准评估与日志回放式动态设置；原文未报告闭环仿真或实车实验。
