Card 02 论文概述

论文概述

  • 论文提出 PixelPilot，一种面向端到端自动驾驶的可扩展视觉-语言-动作模型（VLA）。
  • 解决的任务包括端到端场景理解、2D 轨迹规划、元动作预测，以及开环和闭环轨迹规划。
  • 核心研究问题为：现有 VLA 直接从 2D 图像预测 3D 轨迹，导致传感器耦合、数据可扩展性受限，并易退化为依赖自我状态而非视觉推理的平凡解。
  • 应用场景为多视角相机输入的自动驾驶规划，覆盖开环评估（nuScenes、Waymo）与闭环仿真（Bench2Drive/CARLA）。
Card 03 核心贡献

核心贡献

  • 提出解耦规划与提升（decoupled planning and lifting）范式，将 VLA 优化完全迁移至图像空间进行 2D 到 2D 任务，从而支持跨异构驾驶数据集的数据扩展，并优先视觉推理而非平凡自我状态。
  • 引入知识注入式策略学习（knowledge-instilled policy learning），通过两阶段训练（SFT + GRPO）在可验证输出上施加密集中间奖励，缓解长时域信用分配问题，强化从视觉感知到最终空间规划的因果链。
  • 引入带边界框推理机制，使模型显式关注视觉锚点进行语义推理，建立可解释的感知-推理-动作-规划因果链。
  • 提出自我中心一致性预处理，将后视旋转 180° 以构造连续的 2D 规划表面，避免多视角拼接导致的轨迹断裂。
  • 大量实验表明 PixelPilot 在开环和闭环设置下均达到最先进性能，验证了解耦范式的可扩展性与视觉推理能力。
Card 04 方法描述

方法描述

  • 所属模块：端到端视觉-语言-动作模型，包含感知、推理、元动作预测与轨迹规划模块。
  • 输入传感器：多视角摄像头图像（原文未明确报告具体相机数量）。
  • 场景表示：2D 图像平面，规划表面为自我中心的 2D 图像空间；3D 轨迹仅在推理阶段通过确定性的局部平面假设提升。
  • 模型结构：基于 Qwen2.5-VL 作为基础 VLM，采用自回归生成，依次输出 2D 检测框、带框推理、元动作（横向：TURN LEFT/TURN RIGHT/FORWARD，纵向：ACCELERATE/DECELERATE/KEEP/STOP）及未来 2D 航点。
  • 关键技术：

- 规划阶段：2D 到 2D 预测任务，完全传感器无关，可合并 nuScenes、Waymo 等异质数据集统一训练。

- 提升阶段：利用局部平面假设（高度 Z=-h），通过单应变换或光线投射确定性地将 2D 航点投影至 3D 世界坐标，仅发生于推理时。

- 训练策略：两阶段，第一阶段多任务 SFT 注入基础驾驶知识；第二阶段使用 GRPO 强化学习，对格式、感知（IoU 匈牙利匹配）、元动作（F1）和轨迹（L1 阈值 + sigmoid L2 + PDMS）施加密集奖励。

- 推理时解码温度 1.0、top-p 0.5、top-k 20。

Card 06 评估与结果

评估与结果

  • 评估基准：

- 开环：nuScenes、Waymo Open Dataset。

- 闭环：Bench2Drive（CARLA 仿真器）。

  • 评估指标：2D 检测 mAP、元动作 F1、开环 L2 误差（米）、碰撞率、越界率；闭环驾驶分数、成功率、效率、舒适度。
  • 关键数值：

- 开环规划（nuScenes）：PixelPilot 平均 L2 为 0.30 m（1s/2s/3s 分别为 0.13/0.26/0.51），平均碰撞率 0.25%，平均越界率 1.77%。

- 与 AutoVLA 相比 L2 从 0.40 降至 0.30 m（相对降低 25%）。

- 2D 检测 mAP 为 54.2，优于 StreamPETR（46.5）、MV2D（52.3）、DeformableDETR（50.2）、SimPB（54.1）。

- 元动作预测各横向和纵向 F1 均优于基础 Qwen2.5-VL-7B。

- 闭环（Bench2Drive）：PixelPilot 驾驶分数 79.14、成功率 58.87%、效率 153.26、舒适度 38.01，驱动分数和成功率均优于对比方法（含 Orion、AutoVLA 等）。

- 对比传统规划器 VAD，PixelPilot 驾驶分数提升 36.79，成功率提升 43.87。

  • 消融实验：

- 仅 SFT 平均 L2 为 0.46，仅 RL 为 0.49，两者结合为最优；移除 ego 一致性预处理或多任务训练均导致 L2 上升。

- 移除轨迹奖励、感知奖励或动作奖励均使 L2 增加（0.44/0.41/0.40）。

- 数据扩展：移除 Waymo 数据导致平均 L2 增加 0.06。

- 泛化：在 nuScenes 训练后在 Waymo 上零样本评估，平均 L2 为 0.40 m；仅图像输入时 PixelPilot 的 L2 为 0.71，优于 OmniDrive（1.98）和 Imprompt-VLA（2.39），显示不依赖自我状态。

  • 对比方法：DriveVLM、EMMA、OmniDrive、OpenDriveVLA、Imprompt-VLA、FSDrive、AutoVLA、AutoDrive-R2、DrivePI、AD-MLP、UniAD-Base、VAD、TCP-traj、DriveAdapter、Orion。
  • 开环、闭环、仿真和实车条件：开环评估在 nuScenes 与 Waymo 上进行；闭环评估在 CARLA 的 Bench2Drive 基准上进行；未报告实车测试。
