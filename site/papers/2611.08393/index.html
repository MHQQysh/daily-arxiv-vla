Card 02 论文概述

论文概述

  • 研究面向自动驾驶与 ADAS 的道路异常（坑洼、减速带）视觉检测任务，重点面向尼日利亚等西非道路场景。
  • 关注的应用场景为夜间无照明道路、雨季以及 Harmattan 沙尘雾霾等低照度与不良天气条件下的边缘端部署。
  • 研究的核心问题是：前端低照度增强是否能作为实时感知恢复手段；以及统一（无差别）应用增强是否会对下游检测产生负面影响。
  • 论文在多种检测架构上开展退化条件基准测试，并提出无需训练的亮度自适应路由策略，兼顾检测精度与 Jetson Nano 边缘端实时性。
Card 03 核心贡献

核心贡献

  • 构建了四种检测架构（YOLOv8n、YOLOv12n、RT-DETR、Faster R-CNN）在物理建模的光照与天气退化下的统一基准测试。
  • 发现统一应用 SCI 低照度增强在黄昏级光照下对检测有害，mAP@50 下降 16.1% 至 30.7%。
  • 提出轻量、无需训练、无需标签的 RGB 亮度自适应路由器，在“不增强、中等 SCI、去噪+强 SCI”三支路间按帧选择，恢复大部分黄昏性能损失。
  • 在 NVIDIA Jetson Nano 上对完整流水线（亮度计算、增强、检测）进行逐阶段延迟与端到端 FPS 基准测试。
Card 04 方法描述

方法描述

  • 所属模块：检测前端感知恢复流水线，包含亮度计算、低照度增强（SCI）与检测器三部分。
  • 输入传感器：原文未报告具体传感器型号，输入为道路图像帧（合并数据集图像，统一缩放至 640×640 像素）。
  • 场景表示：单帧 RGB 图像；亮度用 Rec. 601 加权公式 L(I)=0.299R+0.587G+0.114B 计算。
  • 退化建模：光照退化用 gamma 压缩叠加信号相关（类泊松）噪声，分 clean（γ=1.0，均值亮度≈0.462）、dusk（γ=1.6，σ=0.025，≈0.332）、night（γ=2.8，σ=0.060，≈0.207）、severe（γ=4.2，σ=0.110，加 5 像素水平运动模糊，≈0.141）四级；天气退化独立模拟为小雨（400 条雨痕，7 px）、大雨（700 条雨痕，10 px）和基于 Koschmieder 大气散射方程的 Harmattan 雾（深度梯度透射图与暖尘色调 [1.0,0.97,0.92]）。
  • 检测器结构：YOLOv8n 与 YOLOv12n（nano 级一阶段 CNN）、RT-DETR（Transformer 端到端无锚框）、Faster R-CNN（ResNet-50 FPN，两阶段）；前三者用 Ultralytics 训练，后者用 torchvision 训练；全部仅在干净训练集上训练，退化测试集上不重训。
  • 增强模块：SCI（Self-Calibrated Illumination），L=H_θ(I)，R̂=clip(I/L,0,1)；使用原作者发布的 medium.pt 与 difficult.pt 预训练权重，作为固定、不微调的前端；参数量 0.0003 M，0.0619 GFLOPs。
  • 路由器：规则式三支路决策，L≥0.40 直接旁路（Branch A）；0.20≤L<0.40 用中等 SCI（Branch B）；L<0.20 先去噪再强 SCI（Branch C）；阈值取各退化级均值亮度的圆整边界，未针对检测指标搜索，无学习参数、无需训练。
Card 05 数据集与资源

数据集与资源

  • 数据集：合并 Rajdalsaniya Pothole Detection Dataset（Kaggle，2022，2,077 张，单类“pothole”）与 speed-unmarked-bump dataset v3（Roboflow Universe，2023，2,367 张，“pothole”与“speed bump”两类，排除井盖变体），共 4,444 张、两类，按 70/15/15 划分为训练/验证/测试（667 张验证、666 张测试）；退化流水线与路由阈值仅在验证集上开发。
  • 仿真器：原文未报告使用仿真器，退化由自建物理建模流水线生成。
  • 模型规模：SCI 为 0.0003 M 参数、0.0619 GFLOPs；检测器为 nano 级与 ResNet-50 骨干，具体参数规模原文未报告。
  • 训练资源：原文仅报告 SCI 约 1.7 ms/帧（TITAN X 上），未报告检测器训练所用 GPU、时长等资源。
  • 实车平台：未进行实车测试；边缘平台为 NVIDIA Jetson Nano，测速采用每配置 50 次计时、10 次预热后统计。
Card 06 评估与结果

评估与结果

  • 评估基准：合并后的坑洼/减速带数据集（验证集与留出测试集），退化条件包括四级光照与三种天气。
  • 评估指标：mAP@50（IoU=0.5），并按干净条件 mAP@50 的百分比保留率报告；边缘端指标为逐阶段延迟（ms）与端到端 FPS。
  • 对比方法/配置：baseline（无预处理）、统一 SCI（plain SCI）、提出的亮度自适应路由器三种配置，跨四种检测器。
  • 开环/闭环/仿真/实车：全部为仿真退化图像上的开环离线评测与 Jetson Nano 硬件延迟测试，无闭环与实车实验。
  • 关键数值：

- 基线退化：RT-DETR 在黄昏保留 98%、severe 保留 37%；Faster R-CNN severe 仅 28%；小雨保留 90–100%，Harmattan 雾 50–70%，大雨所有架构崩溃至 24–31%。

- 统一 SCI 在黄昏使 mAP@50 下降 16.1%（RT-DETR）至 30.7%（Faster R-CNN）；在夜间/severe 对 RT-DETR 与 YOLOv12n 有增益（如 RT-DETR 夜间 +0.067、severe +0.063；YOLOv12n 黄昏 −0.161、severe +0.063）。

- 自适应路由器：黄昏残差损失缩小至低于基线 0.001–0.073 mAP@50；验证集恢复 plain-SCI 黄昏损失的 71–90%；留出测试集上 RT-DETR、YOLOv12n、YOLOv8n 黄昏与基线差距在 0.007 以内；RT-DETR 夜间在路由器下 +0.045（验证）、+0.071（测试）；YOLOv8n 与 Faster R-CNN 在夜间出现额外损失（Faster R-CNN 超过其 plain-SCI 损失）。

- 边缘端：YOLOv8n 各支路 15–25.8 FPS，YOLOv12n 11.4–18.6 FPS；RT-DETR 6.69–8.23 FPS，Faster R-CNN 3.81–4.42 FPS；SCI 固定开销约 16 ms（Branch B）、36 ms（Branch C），亮度计算约 1.2 ms。

  • 结论性发现：仅 YOLOv8n 接近实时、YOLOv12n 次之，RT-DETR 与 Faster R-CNN 在该硬件层级不满足实时；增强效果依赖光照条件与检测器架构，并非普遍有益。
